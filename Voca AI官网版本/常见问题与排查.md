## 一、装不上

装不上集中在四类原因：未知来源没放行、安装包没下完整、与已装的同一个包签名冲突、系统或机型本来就不支持。所以别急着反复重装，先看你见到的是哪一句提示——三种提示的处理方式完全不同。

**情况 A：提示「不允许安装未知来源的应用」**

系统默认拦截，按 [下载与安装教程.md](下载与安装教程.md) 第三节放行一次即可。

**情况 B：提示「解析包时出现问题」「应用未安装」**

| 原因 | 怎么判断 | 处理 |
| --- | --- | --- |
| 安装包没下完整 | 文件大小明显小于 22.09 MB | 删掉重下，别续传；在电脑上下一份再用数据线拷过去更稳 |
| 系统版本过低 | 手机系统低于安装包标注的要求（这一版标的是安卓 5 系及以上） | 装不上只能换设备 |
| 签名冲突 | 手机上装过别的渠道的同一个包（包名同为 `com.pointone.voca.ai`） | 先卸载旧的那一份再装；卸载会清掉本地设置，动手前先确认账号状态 |
| 存储空间不足 | 到设置里看剩余空间 | 至少留出安装包体积两倍以上的空闲空间 |
| 包本身不对 | 包名、大小、MD5 与这一版对不上 | 按 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md) 第四节核对，换一个包再装 |

**情况 C：提示「应用与你的手机不兼容」「此应用无法安装」**

| 原因 | 怎么判断 | 处理 |
| --- | --- | --- |
| 只支持 64 位处理器 | 手机是较老的 32 位机型（同一个包在 Google Play 页面上标注「仅 64 位 ARM」） | 这份包在这台机器上装不了，换设备 |
| 系统拒绝过旧的安装包 | 手机系统较新（安卓 14 及以上），要装的包编译目标较老 | 改从应用商店装官方最新版 |
| 系统版本低于包的要求 | 手机系统很老 | 换设备，或换系统要求更低的一份版本 |

反复失败时最省时间的做法，是重新取一份安装包，先把「手里的包坏了」这个可能性排掉——入口见本篇开头那条网盘链接。

## 二、打开闪退、用起来卡

按顺序试，前三步能解决大部分情况：

1. **重启应用**：从最近任务里划掉，重新打开。
2. **重启手机**：系统级的网络或音频服务出错时，这一步最有效。
3. **清缓存**（不是清数据）：`设置 → 应用 → Voca AI → 存储 → 清除缓存`。清缓存一般不动收藏和设置。
4. **覆盖安装新版本**：不要先卸载，直接装一次新包覆盖，能修掉一部分文件损坏类的问题，同时保住本地数据。
5. **看是不是固定操作才崩**：只在进某个页面、或只在某段对话里崩，说明是那条功能路径的问题，先绕开，等版本更新。

各家手机厂商的入口不太一样，照着找比在设置里瞎逛快：

| 机型 | 应用信息入口 |
| --- | --- |
| 华为 / 荣耀 | 设置里搜「应用管理」→ 找到 Voca AI → 强行停止；HarmonyOS 4.x 及以下还能在「权限管理」里补齐权限 |
| 小米 / Redmi | 设置 → 应用设置 → 应用管理 → Voca AI → 强行停止 / 清除缓存 |
| OPPO / realme / 一加 | 长按桌面图标 → 应用信息 → 存储占用 → 清理缓存 |
| vivo / iQOO | 长按桌面图标 → 应用信息 → 存储 → 清除缓存 |

顺带一个常被忽略的点：**可用存储长期紧张时，这类实时语音应用更容易卡和闪退**。留出足够空闲空间（一般建议可用空间不低于 20%）再排查别的原因。

## 三、对话没声音，或者它像没听见你

这两类现象的成因完全不同，先分清是哪种：

| 现象 | 多数是什么问题 | 处理 |
| --- | --- | --- |
| AI 的声音放不出来 | 音频输出 | 媒体音量被静音；声音被蓝牙耳机/车机接走了；开了免打扰；切一下输出设备再试 |
| 它像没听见你，界面一直停在等你说 | 麦克风 | 见下 |
| 它听到的是别的声音/识别成一堆乱词 | 环境噪声与说话方式 | 见 [识别不准与发音评分怎么排查.md](识别不准与发音评分怎么排查.md) |

「它像没听见你」按这个顺序排：

1. **看权限**：`设置 → 应用 → Voca AI → 权限 → 麦克风`，必须是「允许」。安卓 11 及以上还有「仅本次允许」这种一次性授权，退到后台再回来会失效，改成「使用应用时允许」更稳。另外，安卓对长期没打开过的应用会自动收回麦克风权限——**「上次还好好的、这次突然不灵」时，先回这一页看一眼。**
2. **看有没有被别的应用占用**：通话、录音、会议、相机类应用正在前台或后台收音时，麦克风会被抢走。关掉它们再回来说话。
3. **看是不是外设的问题**：`设置 → 应用 → Voca AI → 权限` 里蓝牙也放行一下，再确认耳机是真连上了；连接不稳时声音会走耳机、麦克风却还在手机上，两边错位就会出现「它听不见」。
4. **强制停止再打开**：`设置 → 应用 → Voca AI → 强制停止`，然后重开一次应用，重新进对话。
5. **确认网络通**：识别是把你的声音传到云端处理的，断网或弱网时会出现「说完了但一直没反应」。浏览器能正常打开网页，再回来查应用。

## 四、登录不上、忘了用哪个账号

- **登录方式**取决于你装的那一版：这一版支持用第三方账号（如 Google 账号）快速登录，部分功能不登录也能直接体验。界面上的登录选项以你手机上显示的为准。
- **登不上**：先确认网络正常，再去对应的第三方应用里确认账号本身能登录（比如浏览器里能不能正常登录 Google 账号）。第三方那边掉登录态时，这款应用里点多少次都一样。
- **忘了当初用的哪个账号**：挨个试你常用的账号即可；订阅是在商店账号上，找回的优先级是先确认**扣费的那个商店账号**（见 [免费能用多少与会员怎么取消.md](免费能用多少与会员怎么取消.md) 第五节）。
- **退出登录前想清楚**：退出会回到登录页，重新登录一般能把记录拉回来；但如果之前一直处在未登录状态，退出等于本地记录没了。

## 五、练习记录、收藏不见了

| 情况 | 原因 | 处理 |
| --- | --- | --- |
| 换手机后记录不在 | 记录跟账号走，新手机没登录或登了另一个账号 | 用原来那个账号登录；具体能恢复多少以应用内说明为准 |
| 收藏列表空了 | 清过数据或卸载重装过 | 本地记录被删了，云端同步到什么程度以账号为准 |
| 某次对话的反馈找不到了 | 部分版本的反馈只在当次会话内展示 | 想留就当场截图或把表达抄进收藏 |
| 记录显示不全 | 那一版还没同步完 | 保持联网，隔几分钟重进一次 |

**结论很简单：换机、清数据、卸载重装之前，先确认账号能登、记录能同步。** 顺序错了就是白练。

## 六、清缓存和清数据，删的到底是什么

| 操作 | 会删掉 | 不会删掉 | 什么时候用 |
| --- | --- | --- | --- |
| 清除缓存 | 临时文件、语音缓存、图片缓存 | 收藏、设置、登录状态 | 闪退、界面显示异常、列表过期 |
| 清除数据 / 清除存储 | 全部本地数据：设置、登录状态、未同步的记录 | 账号云端已同步的部分（重新登录后可拉回） | 应用状态彻底异常，且已确认数据在账号里 |

**卸载重装等同于清除数据。** 所以遇到问题的处理顺序应该是：重启应用 → 清缓存 → 覆盖安装 → 最后才考虑卸载重装。真要整装一遍，安装包入口见本篇开头那条网盘链接，步骤见 [下载与安装教程.md](下载与安装教程.md)。

如果问题出在付费上（扣了钱功能没开、重复扣费、想退款），看 [免费能用多少与会员怎么取消.md](免费能用多少与会员怎么取消.md) 第五节，那里按渠道给了处理路径。
