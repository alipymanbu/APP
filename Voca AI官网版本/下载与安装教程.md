## 一、装之前先对一遍这几项

Voca AI 是安卓端的 AI 口语练习应用：你对着手机开口说外语，AI 接话回应，再从发音、语法、流利度几个方面给你反馈，题材覆盖日常闲聊、职场交流、出国旅行和考试类场景。公开渠道里能装到的都是手机版（安卓一套、iPhone/iPad 一套），没有独立的电脑客户端。

| 核对项 | 这一版（1.4.0） |
| --- | --- |
| 适用设备 | 安卓手机 / 安卓平板 |
| 系统要求 | 安装包标注的是「安卓 5.2 以上」 |
| 包名 | `com.pointone.voca.ai` |
| 版本号 | 1.4.0 |
| 安装包大小 | 22.09 MB |
| 安装包 MD5 | `01A536595DD77DF5C84CB84F518F5510` |
| 是否必须联网 | 是，对话和反馈都在线完成，断网练不了 |

三点必读：

1. **系统要求这类标注不必逐字较真，但「64 位」这一条要当真。** 这一版页面上写的是「安卓 5.2 以上」，而安卓公开版本只有 5.0、5.1，之后直接跳到 6.0，没有 5.2，按「安卓 5 系及以上」理解即可；同一个包名在 Google Play 的页面上标的又是「安卓 8.0 以上、**仅 64 位 ARM**」。两条标注并不一致，其中后一条更硬：2016 年前后那批 32 位老机型装不了，会直接提示「应用与你的手机不兼容」（处理见 [常见问题与排查.md](常见问题与排查.md) 第一节）。想知道自己这台是不是 64 位，最快的办法不是翻参数，而是把包拷进去点一次安装，系统会直接告诉你。
2. **网盘里发出去的那一版，和线上商店的最新版未必是同一个版本。** 所以判断「我装的对不对」，看的是包名和版本号能不能对上这一版（`com.pointone.voca.ai` / 1.4.0），而不是跟某篇介绍里写的版本号去比。
3. **想在电脑上练，只能借安卓模拟器。** 这个应用没有电脑客户端（公开渠道里只有安卓和 iPhone/iPad 两套）；电脑上要练，得先装一个安卓模拟器，再把这个 `.apk` 装进模拟器里。装的时候记得单独把模拟器的「麦克风」直通打开，并且用耳机接电脑——否则电脑扬声器放出来的 AI 声音会被模拟器麦克风收回去，两边互相打断。

## 二、从网盘把安装包取到手机

1. 用手机打开 [Voca AI 安装文件资源（夸克网盘）](https://pan.quark.cn/s/cc7ad58e75ef)。手机浏览器或夸克 App 都行，**建议在夸克 App 里打开**——浏览器下载大文件容易被打断。
2. 点「保存到我的网盘」，把文件转存到自己账号下。转存过之后，以后再取就不依赖原分享是否还在。
3. 进自己的网盘找到这个 `.apk`，点下载，等它落到手机的「下载」目录。
4. 下完核对两件事：文件名是不是以 `.apk` 结尾；**大小是不是 22.09 MB 左右**。差得多的多半是没下完整，删掉重下，别续传。

习惯在电脑上操作的：先在电脑端把包下载下来，用数据线拷进手机的 `Download` 目录，再从手机的「文件管理」里点它安装，效果一样。

## 三、安装：放行一次「未知来源」

这个应用不在手机自带的应用商店里，安装时系统会拦一下，这是默认行为，不代表文件有问题。

1. 打开「文件管理」，进 `Download` 目录，点刚下好的安装包。
2. 弹出「不允许安装来自此来源的应用」时，点提示里的「设置」，打开**允许安装此来源的应用**开关。部分机型要逐个体检：`设置 → 应用 → 特殊应用权限 → 安装未知应用`，找到你刚才用来打开文件的那个 App 再放行。
3. 回到安装界面点「安装」，等进度条走完。
4. 出现「打开 / 完成」时**先点「完成」**，下一步统一把权限一次给对，省得进去之后反复弹窗。

## 四、首次打开要处理的两件事

**权限。** 这个应用的练习方式是「你说话 → AI 回应」，所以麦克风是刚需：

| 权限 | 用途 | 建议 |
| --- | --- | --- |
| 麦克风 / 录音 | 收你的声音，对话与发音反馈都靠它 | 必须给，拒了就练不了 |
| 网络 / 后台数据 | 对话、反馈、每日内容都在线请求 | 必须给 |
| 通知 | 每日练习提醒一类 | 想清静就先拒绝，不影响练习 |
| 与练口语无关的项（通讯录、短信、位置等） | — | 先拒绝，再看功能有没有受影响 |

之前手滑拒过麦克风的，去 `设置 → 应用 → Voca AI → 权限 → 麦克风` 里补开，回到应用重新进一次对话即可生效。

还有一个**系统级开关**容易被忽略：部分机型（安卓 12 及以上居多）在隐私设置里有麦克风访问总开关，路径大致是 `设置 → 安全与隐私 → 隐私 → 隐私控制 → 麦克风访问`。这个开关关掉时，单个应用那页显示「允许」也照样收不到声音——应用权限看着没问题、它就是听不见你，先回来这一层确认。

**声音。** 练之前先确认媒体音量没静音（安卓的媒体音量和铃声音量是两路，按音量键展开齿轮图标才看得到是哪一路）。蓝牙耳机、车机、有线耳机还连着的话，声音会走那一边；不想外放就戴上耳机——耳机上的麦克风离嘴更近，识别通常比免提稳，这一点在 [识别不准与发音评分怎么排查.md](识别不准与发音评分怎么排查.md) 里展开讲。

## 五、装完先做三步自检

不用急着挑话题，先花一分钟确认这三件事，后面出问题也好定位：

1. **能打开、不闪退**：图标点进去能正常进首页。反复闪退就去看 [常见问题与排查.md](常见问题与排查.md) 第二节。
2. **听得见**：随手进一段对话，AI 的语音能正常放出来。这一步同时验证了网络和媒体音量。
3. **收得到你的声音**：对着麦克风说一句话，界面上能立刻出现你说的话，或者对话能接得下去。完全没反应，是麦克风权限或占用问题，先看 [常见问题与排查.md](常见问题与排查.md) 第三节。

三步都过就可以正式开始练了，从哪儿下手见 [怎么和AI练口语.md](怎么和AI练口语.md)。

## 六、升级与卸载时要注意的

- **升级**：新版本会换一个安装包文件名，直接装上去覆盖即可，不用先卸载；先卸载反而会清掉本地设置和缓存。
- **卸载**：会清掉应用私有目录里的本地记录和设置。要换机、要留住收藏，先确认登录账号的状态。
- **卸载不等于退订**：订阅挂在商店账号上，把应用删了钱照扣。取消的方法单独写在 [免费能用多少与会员怎么取消.md](免费能用多少与会员怎么取消.md) 里。
- **找不到安装包了**：任何时候都可以回到本篇开头那条网盘链接重新取一份，转存过的版本不受原分享影响。
