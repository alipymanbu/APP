# Flipboard 通知与广告怎么控制

> Flipboard 的通知能关，广告关不掉 —— 但按来源分一分，能处理掉很大一部分。本篇讲推送在哪关、两类广告各归谁管、以及看到不想看的内容该用哪个按钮。

## 一、推送通知：在哪关，能关多细

入口在 Profile 里：

1. 底部进 **Profile**。
2. 上方切到 **Notifications** 这一栏。
3. 点右上角的设置，管理推送偏好。

能做的三档处理：

- **全关**：把推送总开关关掉。最干脆，代价是错过突发新闻提醒。
- **只留要的**：逐类关掉不关心的提醒，保留突发新闻这类。
- **系统级兜底**：如果应用内关了还在响，去手机的 设置 → 应用 → Flipboard → 通知，把通知权限关掉，这是最终生效的那一层。

反过来，如果你**收不到**通知，先查两处：应用内的推送开关，以及系统的电池优化/后台限制有没有把 Flipboard 掐掉 —— 后者在国产系统上更常见。

## 二、两类广告，处理方式完全不同

Flipboard 里的广告来自两个地方，混着看会以为「怎么关都关不掉」：

| | Flipboard 投放的广告 | 文章里的广告 |
| --- | --- | --- |
| 出现在哪 | 信息流中间，长得也像一张卡片 | 点进文章后的那个网页里，是发布方自己的广告 |
| 能不能去掉 | **不能**。官方帮助中心明确写着目前没有隐藏的办法，也没有付费隐藏广告的选项 | 能大幅减少，切阅读视图/浏览器简化视图即可 |
| 你能做什么 | 对单条广告点 ⋮ 提交反馈（选一个理由），让官方少投这类 | 用阅读视图把网页杂物剥掉 |

所以「广告太多怎么办」的正确答案是先看你在哪里被烦到：

- 烦的是**文章读起来磕磕绊绊**（弹出、浮层、上下跳）→ 这属于第二类，去 [深色模式与阅读视图怎么设置.md](深色模式与阅读视图怎么设置.md) 把阅读模式切成 Legacy web view，用阅读视图看；或者留在 custom tabs，用浏览器自带的简化视图。
- 烦的是**刷信息流时插进来的广告卡片**→ 这一类没有开关，只能靠单条反馈，以及下面第三节讲的「少看这个来源」。

## 三、个性化广告与隐私选项

官方说明里提到，注册账号后会与广告伙伴合作投放第三方广告。关于**基于兴趣的广告**以及怎么退出，官方指向的是行业自律页：

- 美国用户可参考 `http://www.aboutads.info/choices/` 与 `http://www.aboutads.info/appchoices`；
- 欧盟用户可参考 `http://www.youronlinechoices.eu/`。

这些页面由广告行业组织维护，针对的是「跨应用的兴趣广告标识」，不是 Flipboard 应用内的开关；能不能生效还取决于系统和地区，别指望它把广告变没有。

## 四、不想看的内容：三个按钮的取舍

看到不该出现在你信息流里的东西，按性质选按钮，比一气之下卸了重装有效：

| 遇到的情况 | 用什么 |
| --- | --- |
| 这一类内容不想多看 | 文章 ⋮ → **Show less**（只降权重，不静音来源） |
| 这个来源一条都别出现 | 文章 ⋮ → **Mute**（全站屏蔽；想恢复去 Settings → Muted Sources 取消勾选） |
| 内容违规、标题党造假 | 文章 ⋮ → **Report**（提交审核，并从你的流里移除） |
| 某个用户一直骚扰你 | 在该用户资料页里屏蔽（Block a profile），屏蔽后互相看不到 |
| 杂志里出现不合适的评论 | 你是杂志所有者时可直接删掉该评论 |

「假新闻」这一类内容官方专门做了举报入口，从文章的 ⋮ 菜单里就能提交。

## 五、移动数据下的两个注意点

- **视频是真耗流量的**。信息流里的视频不点不播，点了却会按清晰度实打实走流量；视频广告虽然没有声音，同样会加载。
- **没连 Wi-Fi 时先看字**。文字内容流量很小，视频和图片才是大头；如果你套餐流量有限，把「随手点开视频」这个习惯改掉，一个月的差别不小。
