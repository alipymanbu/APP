## 一、装之前先对一下版本

网上能搜到的是各渠道自己更新的最新版，这里给出的安装包固定是下面这一版，两者不一定是同一个版本号。文档里出现版本号、包名、体积，一律以这张表为准：

| 项目 | 值 |
| --- | --- |
| 版本 | 1.0.9 |
| 包名 | `com.jrceuao.ypchi` |
| 安装包体积 | 61.43 MB（64,418,039 字节） |
| MD5 | `C3B85D745D4C487386BAE00D92EE64D0` |

作为对照：腾讯应用宝的详情页上当时显示的版本号是 1.1.0（以该页面当时显示为准），比这里这一份新。所以如果你在网上看到「最新版 1.1.0」的说法，和这里并不矛盾 —— 只是版本不同。

装完想确认拿到的是不是这一版，看两处就够：

1. 「设置 → 应用 → 应用管理 → V浏览器」的详情页里能看到版本号；
2. 用文件管理器长按那个 APK，看体积是不是 61.43 MB 左右。

注意一点：这款软件的宣传语里有「小体积」，但**一个完整的浏览器内核本来就不小**，这里这一份是 61 MB 上下。如果你的文件只有一两兆，那多半是别的浏览器（名字相近的几款体积差得很远，见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)）。

## 二、把安装包取到手机上

包在 [V浏览器 安装文件资源（夸克网盘）](https://pan.quark.cn/s/f35f15247059) 里，手机或电脑打开都能转存。取包和传包有两条常见走法，选顺手的：

- **手机直接下**：在手机上打开网盘页面，转存后从网盘 App 里下载。下载完成后在网盘 App 的「传输」列表里点开文件，系统会直接问你要不要安装。
- **电脑下了再传**：电脑下载后用数据线、微信文件传输助手或局域网工具把 APK 传到手机，再用系统自带的文件管理器找到它，点一下发起安装。

那份 APK 的文件名形如 `V浏览器_v1.0.9.apk`，版本号写在文件名里，下完可以先看文件名对不对。

传输过程中最容易出问题的地方是**文件名后缀被改掉**。有些传输工具会把 `.apk` 变成 `.apk.1` 或干脆去掉后缀，这类文件点开不会触发安装。遇到就用文件管理器把后缀改回 `.apk` 再点。

## 三、安装：绕不过的「未知来源」

这款软件不在手机自带应用商店里，所以第一次装一般会遇到系统的安全提示，这是正常流程，不是安装包出错：

1. 点击 APK，系统弹出「禁止安装未知应用」类的提示，选择**设置**；
2. 在跳转过去的页面里，把**当前这个来源**（文件管理器或网盘 App）的「允许安装未知应用」打开；
3. 返回，重新点一次 APK；
4. 安装界面会列出它申请的权限，确认后点**安装**。

各家系统（小米、OPPO、vivo、华为、荣耀等）的入口名字不一样，但都在「设置 → 应用 → 特殊应用权限 / 安装未知应用」这一带，找不到就在设置里搜「未知应用」。

## 四、首次打开会碰到的授权

装上之后第一次运行，一般会碰到两类授权，处理方式不一样：

| 提示 | 该不该给 | 说明 |
| --- | --- | --- |
| 存储 / 文件和媒体 | 建议给 | 不给的话在浏览器里下载文件、保存网页这类操作会失败 |
| 通知 | 看需要 | 与浏览网页本身无关，不想收推送可以直接拒绝 |

官方说明里强调「更少权限」，你正好可以在安装页顺手看一眼权限清单：**与浏览无关的权限（通讯录、短信、通话记录）没有理由给，直接拒绝**，拒绝不影响输入网址浏览网页。

还有一条值得留意：**无障碍（辅助功能）权限对浏览网页这件事来说是多余的**。这类权限能读取屏幕上的内容、代替你点按界面，属于安卓里权限最大的一档；如果安装过程中或运行时被引导去开启它，先拒绝，想清楚再决定。同理，悬浮窗、后台弹窗这类权限与浏览无关，一律可以先不给。

如果当时手滑点了「拒绝」，之后到「设置 → 应用 → V浏览器 → 权限」里重新打开即可，不需要重装。

## 五、装不上，或者装完打不开

按现象对号入座：

- **提示「解析包错误」**：APK 没下完整（传输中断）。删掉重下，核对上面表格里的体积和 MD5。
- **提示「应用未安装」**：手机里已经有一个签名不同的同包名版本。先卸载旧的 `com.jrceuao.ypchi`，再装这一版。卸载前先把要留的网址抄出来。
- **提示「与系统不兼容」**：你的安卓版本低于这款软件的要求。这款软件在应用市场的登记信息里写作「安卓系统 5.2 以上」，而安卓 5.x 实际只到 5.1，这种写法本身不严谨，只能当参考 —— 真实门槛以你手机上的安装提示为准。
- **装上了但一点就闪退**：先在「设置 → 应用 → V浏览器 → 存储」里清一次缓存再打开；仍然闪退就卸载重装。完整的排查顺序写在 [常见问题与排查.md](常见问题与排查.md)。

想提前知道自己这台机器行不行，先看一眼系统版本：`设置 → 关于手机 → 版本信息`（有的品牌写作「关于设备」「系统信息」），里面能看到安卓版本号。看完再对上面的几种提示，比装完了再遇到报错省事。

## 六、覆盖安装与卸载

从 APK 装上去的这一份，不会自己跟着手机自带的应用市场更新 —— 应用市场只负责更新它自己装的那些。想换版本的唯一办法是**下载新的 APK 覆盖安装**。

覆盖安装能否成功，取决于两次安装包的签名是否一致：

- 签名一致 → 覆盖成功，书签与设置保留；
- 系统报「应用未安装」 → 签名对不上，只能先卸载再装，本地数据会一起清掉。

所以换版本之前，先把手动保存过的网址导出或抄出来。

想卸干净，除了常规卸载，再看一眼这两处：

- 「设置 → 应用 → V浏览器 → 存储」里是否还留着数据（常规卸载后系统一般会一并清除）；
- 用文件管理器检查内部存储里是否残留它创建的下载文件夹，需要就手动删。
