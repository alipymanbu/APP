TOP论坛 的账号以手机号为核心凭证，登录方式分短信登录与密码登录两种；官方登录页还区分「个人会员 / 学员」与「企业会员」两类入口。本篇讲注册、登录、解锁、验证码排查，以及换号时最容易被忽略的那一步。

## 一、账号是怎么建立的

官方用户协议写得很直白：账号**应当使用手机号码绑定注册**，且手机号不能是已被本平台绑定或封禁过的号码。实测流程就三步：

1. 打开应用，点登录位的「注册」；
2. 填入手机号，点发送验证码，把短信里的验证码填回去；
3. 设置登录密码，完成后直接进入学习页。

如果你拿到的是**企业会员账号**，登录页要切到「企业会员」标签再登，账号一般由所在机构统一开通，密码规则也与个人账号不同——这种情况直接找机构的培训负责人，比在应用里试更快。

## 二、登录与密码

| 场景 | 怎么做 |
| --- | --- |
| 记得密码 | 选「密码登录」，填手机号 + 密码 + 图形验证码 |
| 忘记密码 | 用手机号收验证码走「忘记密码」重设；也可以直接用「短信登录」先看课 |
| 输入密码报错多次后登不上 | 官方客服口径：密码连续输错 5 次以上会锁账号，**20 分钟后自动解锁**，解锁后可用短信登录或忘记密码进入 |

登录后建议先在「我的」里把手机号核对一遍——换设备、找客服处理权益时，客服都是以手机号认人的。

## 三、验证码收不到

按这个顺序试，绝大多数能解决：

1. 看短信的**骚扰拦截 / 垃圾箱**文件夹，部分手机会把验证码类短信折叠进去；
2. 等一两分钟后重新点「发送验证码」，不要连点（连点容易触发频控，反而更久收不到）；
3. 换网络环境再取一次，Wi-Fi 与移动数据互换；
4. 检查手机是否欠费或短信中心被设置异常；
5. 都试过仍收不到，通过应用内的意见反馈或官方公众号联系客服，让对方从后台重发。

## 四、一个账号能在几台设备上用

官方客服给过明确口径：**一个账号最多在两台设备登录，且两台设备不能同时在线**。所以会出现两种典型现象：

- 在新手机上登录后，旧手机上继续播放会提示账号异常或被挤下线——这是设备数限制，不是账号被盗；
- 想把账号同时给同事一起看，是做不到的，只能各自开通。

如果怀疑账号被他人登录，先改密码（走「忘记密码」），再在「我的」里核对手机号是否为本人号码。

## 五、换手机号：别直接把旧号丢掉

手机号就是账号的唯一凭证，这意味着**换号不等于改个字段**，而是要把旧账号的课程权益搬到新号码上。正确的做法是：

1. **先用新手机号注册一个新账号**（不要用旧号停用后的号码池回收号，容易撞到别人的账号）；
2. **通过官方客服申请账号权益合并 / 转移**：从应用内的意见反馈或官方公众号提交，说清「旧号、新号、两边各自的课程」，客服会核实是否为本人（两个入口怎么用、要带什么材料，见 [遇到问题怎么找客服.md](遇到问题怎么找客服.md)）；
3. **等待处理结果**：官方客服的历史口径是 1~2 个工作日，结果会推送到应用内的消息位置，处理期间不要在新旧账号上重复购买或充值；
4. **处理完成后只用新账号**，旧号停止使用。

两个坑提前避开：

- **别在换号后再买课**。权益合并是按当时的购买记录搬的，处理期间新买的课容易算在错的一边。
- **旧号停用前先办事**。号码一旦被运营商回收重新放号，后任机主可能用短信登录的方式进入你的旧账号，那时再想证明归属会麻烦很多。

## 六、登录不进去先排除这几种

| 现象 | 处理顺序 |
| --- | --- |
| 提示密码错误 | 确认输入法没有自动加空格；仍不行就走「忘记密码」 |
| 提示账号被锁定 | 等 20 分钟自动解锁，之后用短信登录进入 |
| 提示账号在其他设备在线 | 在另一台设备退出登录，或直接改密码后重登 |
| 验证码一直收不到 | 按本篇第三节的顺序排查 |
| 换了手机号，旧号已停用 | 走本篇第五节的账号合并流程，注意客服需要核实身份 |

登录后如果发现课程列表是空的，先确认是不是登进了另一个账号（比如把手机号填成了别人的），再看 [课程购买与有效期.md](课程购买与有效期.md) 里「买完在哪里看」一节。
