TOP论坛 是面向寿险行业从业人员的在线学习平台，课程按「系统课程 / 推荐单课 / 精品专题」三类组织，买课之后在应用里看。它只有手机版，安装包要自己装进手机。本篇只做一件事：把网盘里这份包装好并正常打开。

## 一、先弄清网盘里这份包是哪一版

网上搜到的版本信息通常是官方当时的最新发布版，与网盘里这份未必是同一个版本号——官方应用市场现在的版本号已经走到 4.x，网盘里放的是 3.1.0。本文涉及版本号、包名、体积的地方，一律以下表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | TOP论坛 |
| 版本号 | 3.1.0 |
| 包名 | `com.firststate.top.framework.client` |
| 安装包体积 | 135.96 MB |
| MD5 | `D591C72D9ADCDCC502D6E586CB35C96C` |
| 适用平台 | Android（手机端 APK） |

装之前先弄清两件事：

- **官方渠道与网盘这份不是同一条路。** 官方现在的主渠道是国内主流安卓应用市场，以及官方公众号 `zlgjtopforum` 里的「发现更多 → APP下载安装」，版本更新也走那里。网盘里这份是 3.1.0，属于偏早的版本，如果你手机里已经装了更高版本，先想清楚是保留新版还是回装这一份。
- **系统要求。** 官方应用页标注的是 Android 5.0 以上。老机型先确认系统版本，低于这个门槛装上也未必能正常播放课程。

## 二、从网盘取安装文件

1. **打开分享页**：点开 [TOP论坛 安装文件资源（夸克网盘）](https://pan.quark.cn/s/4bb6cff9a2b8)，在手机夸克 App 里打开最省事。
2. **先转存再下载**：选中安装包，转存到自己的网盘目录，再下载到本机。分享链接以后可能失效，转存过的那份不受影响。
3. **确认下载完整**：下载完成后看一眼体积是否约 135.96 MB。中途断网重连后体积偏小，安装时会直接报「解析包错误」。
4. **想校验完整性**：把包放到电脑上算一遍 MD5，结果应当与上表一致。

```cmd
certutil -hashfile TOP论坛_v3.1.0.apk MD5
```

（文件名随版本变化，以网盘里实际提供的为准。）

## 三、安装步骤

1. **让文件管理器拿到安装权限**：在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，把用来打开 APK 的那个应用（文件管理器或浏览器）的开关打开。国产定制系统这一项常收在「安全」或「隐私」分类下。
2. **点击 APK 开始安装**：系统提示「来自未知来源」或「未经安全检测」时选择继续——这是侧载安装包的常规提示，不代表文件有问题。
3. **回装低版本前先卸载**：安卓不允许用更低版本覆盖更高版本，会直接报「应用未安装」。手机里若已有 4.x，装这份 3.1.0 之前必须先卸载；卸载会一并清掉只存在本机的离线课程。
4. **权限尽量一次给全**：官方客服口径是安卓手机安装时需要允许各项权限，应用才能正常用。各项权限对应什么用途，见下表。

| 权限 | 官方给出的用途 |
| --- | --- |
| 存储 | 下载课程、缓存离线内容 |
| 通知 | 接收课程更新与开课提醒 |
| 日历 | 预约课程、把开课时间写进日历 |
| 摄像头、麦克风 | 参与直播课程的连麦 |
| 电话 | 在应用内直接联系老师 |

（以上用途取自官方应用页的权限说明，具体以你手机上安装时的提示为准。）

## 四、第一次打开要确认的三件事

1. **能联网**：课程列表、章节、播放地址都在服务端，打开后如果停在加载状态，先在浏览器里确认手机能正常上网。
2. **能登录进去**：TOP论坛 的账号以手机号为凭证，第一次进入需要用手机号收验证码注册，再设置密码。收不到验证码的排查见 [注册登录与换手机号.md](注册登录与换手机号.md)。
3. **能看到课程**：首页刷得出推荐单课与课程版块，说明数据侧通了；再随便点进一门课，看章节能不能展开，就算装好了。课程各版块分别是什么，见 [课程版块与怎么找课.md](课程版块与怎么找课.md)。

## 五、装不上时的常见处理

| 现象 | 多半是什么原因 | 怎么处理 |
| --- | --- | --- |
| 提示「解析包错误」 | 安装包下载不完整 | 核对体积与 MD5，按上面第二节的步骤重新下载一次 |
| 提示「应用未安装：签名不一致」 | 手机里已装同包名的另一个版本 | 先卸载旧包再装；卸载前确认离线课程是否需要重新下载 |
| 安装被安全中心拦截 | 侧载安装包被系统安全策略拦下 | 在安全中心的拦截记录里选「继续安装」 |
| 装上后开屏就闪退 | 系统版本过低或安装残缺 | 先重启手机；仍闪退就卸载重装一份完整包 |
| 装上后课程打不开、提示权限相关 | 关键权限没给 | 到「设置 → 应用 → TOP论坛 → 权限」里补齐存储、通知等权限后重启应用 |

其余与账号、付费、播放相关的问题，汇总在 [常见问题与排查.md](常见问题与排查.md)。
