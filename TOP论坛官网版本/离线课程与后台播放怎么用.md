# TOP论坛 离线课程与后台播放怎么用

TOP论坛 支持把已购买的课缓存到手机上离线看，入口在底部「学习」页的「离线课程」里。本篇讲缓存怎么下、下完在哪找、空间怎么管，以及出差路上常用的后台播放怎么设置。

## 一、把课程缓存到本机

1. **先给存储权限。** 官方权限说明里，存储权限的用途就是「下载课程观看」；没给这项权限，点下载不会有反应。补齐路径：设置 → 应用 → TOP论坛 → 权限 → 存储。
2. **进课程的小节页再下载。** 缓存是按小节走的，进课程目录点到你要的那一节，在播放页找缓存 / 下载入口。整门课一次性缓存的按钮因版本而异，找不到就按小节逐个下。
3. **留在应用里等它下完。** 下载过程建议保持应用在前台、Wi-Fi 环境，切到后台时间久了可能被系统掐断。
4. **确认下完再出门。** 有的课程分节多、单节体积不小，出门前翻一遍「离线课程」，确认状态是已完成而不是暂停。

## 二、下载好的课在哪看

官方客服给出的路径是：**点应用底部「学习」按钮 → 选「离线课程」 → 进「最近下载的课程」**。已经缓存完的课都按最近下载的顺序排在那一列，点开就能看不耗流量。

同一位置通常也放着「已购课程」列表——那是你在有效期内可以**在线**看的全部课程。两者的区别值得记一下：

| 入口 | 内容 | 断网能不能看 |
| --- | --- | --- |
| 已购课程 | 所有买过且在有效期内的课 | 不能，要联网 |
| 离线课程 | 已经缓存到本机的那部分 | 能 |

## 三、占多少空间、怎么清

课程缓存是体积大户，一节视频课动辄几十兆到上百兆。管理方式很直接：

1. 到「离线课程」里查看各门课已占用的空间；
2. 看完不再需要的，在离线课程里删除对应课程或小节；
3. 手机存储紧张时，优先清「已看完」的那几门，不要把正在学的课一起删掉；
4. 清完回系统「设置 → 应用 → TOP论坛 → 存储」核对一下占用是否降下来。

注意：**删掉离线缓存不影响购买记录**，课还在，需要时重新下就行。

## 四、后台播放与音频模式

通勤、开车这种场景，用音频模式更合适：

- **音频 / 视频切换**：同一节内容可以在音频与视频之间切，切到音频后不看画面也能听；
- **后台播放**：退出播放页、锁屏之后课程继续出声，需要应用有通知 / 后台运行相关权限；
- **小窗播放**：边看课边翻资料时用，需要给到系统设置相关权限，权限没给全时小窗会起不来。

如果锁屏后就没声了，先去系统里检查 TOP论坛 的**后台运行**和**通知**权限有没有被省电策略限制，再看应用设置里是否开了后台播放。

## 五、离线缓存会失效的几种情况

| 情况 | 结果 |
| --- | --- |
| 课程有效期到期 | 已缓存的课也会看不了，续购后才能继续 |
| 换设备登录 | 缓存只在本机，换机要重新下 |
| 卸载重装 | 缓存随之清空，且新装的包需要重新给权限；手上没有安装包时，从 [TOP论坛 安装文件资源（夸克网盘）](https://pan.quark.cn/s/4bb6cff9a2b8) 取一份 |
| 应用大版本更新 | 部分旧缓存可能需要重新下载才能正常播放 |

## 六、能下载，不等于能导出

这条要分清楚：**应用内缓存是为了让你离线观看，不是把内容搬出去用的授权**。官方对「课程能否下载」的答复是——出于知识产权保护，未经授权课件不可随意下载传播；购买有效期内可以在应用内反复学习。

所以这些做法都别碰：把缓存文件导出成通用视频文件往外发、录屏后上传到公开平台、把课件截图拼成长图分发。个人的正常使用没问题，凡是让内容脱离账号、流向第三方的操作都在这条线之外。
