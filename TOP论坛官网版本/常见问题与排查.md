## 一、装不上，或装上打不开

| 提示 / 现象 | 处理顺序 |
| --- | --- |
| 解析包错误 | 核对安装包体积是否约 135.96 MB、MD5 是否为 `D591C72D9ADCDCC502D6E586CB35C96C`；对不上就从 [TOP论坛 安装文件资源（夸克网盘）](https://pan.quark.cn/s/4bb6cff9a2b8) 重新下载 |
| 应用未安装（签名不一致） | 手机里有同包名 `com.firststate.top.framework.client` 的另一个版本，先卸载再装；卸载会清掉离线缓存 |
| 安装被系统拦截 | 在安全中心的拦截记录里选「继续安装」，或临时关闭安装拦截 |
| 一打开就闪退 | 先重启手机；仍闪退就卸载重装一份完整包；官方客服对闪退的答复也是卸载后用新包重装 |
| 点下载课程没反应 | 存储权限没给，去「设置 → 应用 → TOP论坛 → 权限」补齐 |

完整步骤见 [下载与安装教程.md](下载与安装教程.md)。

## 二、收不到短信验证码

按顺序试：看短信的骚扰拦截 / 垃圾箱文件夹 → 等一两分钟后重新点发送（别连点）→ 换 Wi-Fi 与移动数据再取一次 → 确认手机没欠费、短信中心正常 → 都不行就通过应用内意见反馈或官方公众号让客服从后台重发。

细节写在 [注册登录与换手机号.md](注册登录与换手机号.md)。

## 三、账号被锁，或提示在别处登录

- **密码连续输错 5 次以上**会锁账号，官方客服口径是 **20 分钟后自动解锁**；解锁后用短信登录或「忘记密码」进去。
- **提示账号在其他设备在线**：一个账号最多在两台设备登录，两台不能同时在线。不是被盗号，但如果你确认只有自己用，建议先改密码再说。
- **想把账号给同事共用**做不到，这是账号规则限制，不是网络问题。

## 四、付了钱，课还是看不了

1. **先退出登录再登一次**，让应用重新拉一遍课程权益；
2. **确认买的是哪个版块**：推荐单课、系统课程、精品专题互不相含，买 A 看不了 B 是正常的；
3. **确认课程还在有效期内**，到期后已购列表里的课会失效；
4. **可能是支付未到账**（苹果内购偶发）。准备好账号截图、扣款截图、苹果收据三样，提交官方客服处理，处理期间**不要重复付款**。

购买与退费口径见 [课程购买与有效期.md](课程购买与有效期.md)。

## 五、能不能投屏到电视上

**应用本身不提供大屏投放功能。** 官方客服给过的口径是：TOP论坛 是移动学习平台，目前不支持大屏幕直接投放；组织团队学习时建议各自装应用学习、再集中讨论。

如果你还是想在电视上看，只能用**手机系统自带的无线投屏 / 屏幕镜像**把手机画面整体投上去（前提是手机与电视在同一个 Wi-Fi 下）。这只适用于自己买过的课、在自己家里看的场景——投屏不等于获得授权，不要配合录屏把内容再传播出去。

投屏连不上的常见原因也就那几条：手机与电视不在同一 Wi-Fi、路由器开了 AP 隔离、电视侧投屏开关没打开、老电视不支持无线投屏需要投屏盒子。逐个排除即可。

## 六、能不能把课件下载下来

不能对外下载传播。官方答复是：出于知识产权保护，未经授权课件不可随意下载传播；购买有效期内可在应用内反复在线学习。

应用里确实有「离线课程」缓存功能，那是给没网时看课用的，**缓存文件不等于通用视频文件**，导出、录屏外传都在授权范围之外。缓存的用法与边界见 [离线课程与后台播放怎么用.md](离线课程与后台播放怎么用.md)。

## 七、课程列表是空的

先排除三类原因：**没登录**（未登录看不到已购课程）、**登错账号**（换过手机号的尤其容易）、**课程已过期**。都不成立再考虑是应用没拉到数据——退出登录重进、或清一下应用缓存后重试。

## 八、播放卡顿、黑屏、锁屏后没声

1. 换网络试一次，Wi-Fi 与移动数据互切，排除单个网络的问题；
2. 确认手机剩余存储空间充足，空间不足会影响缓存与播放；
3. 关掉省电模式，或把 TOP论坛 加入电池优化白名单，锁屏后没声多半是被省电策略掐了后台；
4. 检查系统时间是否准确，时间偏差过大会让部分接口校验失败；
5. 都不行时错开高峰时段再试，服务端偶发拥塞也会表现为长时间转圈。

## 九、换手机号怎么办

手机号是账号唯一凭证，换号要**先用新号注册，再找官方客服做账号权益合并 / 转移**，处理期间不要重复购买。官方客服的历史口径是 1~2 个工作日，完整步骤见 [注册登录与换手机号.md](注册登录与换手机号.md)。

## 十、想彻底清干净重装

1. 先在应用内确认要留的课都已购且在有效期内（离线缓存会在卸载时清空，需要重新下）；
2. 在「设置 → 应用 → 应用管理」里卸载 TOP论坛；
3. 重新装一份包（取包与安装步骤见 [下载与安装教程.md](下载与安装教程.md)）；
4. 用原手机号登录，回到「学习」页确认课程都在，再按需重新缓存离线内容。
