## 一、装之前先核对这四项

同一个应用在不同渠道给出的包，版本号与体积可能不一样，装之前先对照清楚：

| 项目 | 值 |
| --- | --- |
| 版本号 | 2.3.2 |
| 安装包体积 | 69.95M |
| 包名 | `com.nhpl.aiwnwrite` |
| MD5 | `8b932ff6f45812d604025646e394ce3f` |

四项里最有用的是**包名**和 **MD5**：

- 包名 `com.nhpl.aiwnwrite` 是判断「是不是同一个应用」最可靠的依据，同名应用遍地都是（见 [同名应用与版本怎么认.md](同名应用与版本怎么认.md)）；
- MD5 用来确认文件在下传过程中没损坏。手机端可以直接跳过这一项，电脑上核对一次更稳妥。

应用商店里的版本会持续更新，官方页面显示的版本号可能已经高于上表，**以应用内「关于」页面和官方页面当时的显示为准**。

## 二、两条获取途径

按你的习惯选一条，别两条叠着用：

1. **网盘转存**：网盘里这份对应上表的 2.3.2 版本，入口是 [AI万能写作 安装文件资源（夸克网盘）](https://pan.quark.cn/s/5eb9b4b03a0f)。转存到自己的网盘后再下载，链接长期有效，版本固定，装完不会被商店自动改版本；
2. **官方应用商店**：在应用宝（[sj.qq.com/appdetail/com.nhpl.aiwnwrite](https://sj.qq.com/appdetail/com.nhpl.aiwnwrite)）或豌豆荚（[www.wandoujia.com/apps/8388629](https://www.wandoujia.com/apps/8388629)）里搜「AI万能写作」，**认准开发者是「合肥你好漂亮网络科技有限公司」**。这条路的版本跟随官方，总是最新。

**两条路不要混着装**：包名相同，后装的会覆盖先装的，登录状态与本地草稿都可能对不上。已经装了商店版、又想换成网盘版，先卸载再装。

网盘那条路是三步：**点开链接并登录 → 保存到自己的网盘 → 在网盘 App 里下载到手机**。直接点「下载」也能拿到文件，但先转存一遍的好处是链接失效后你手上还有一份。

## 三、安装步骤

1. 下载得到 `.apk` 文件（网盘里文件名形如 `AI万能写作_v2.3.2.apk`）；
2. 用手机自带的文件管理器点开这个 apk；
3. 如果提示「禁止安装未知来源应用」，按提示跳到系统设置里，**只给当前这个文件管理器（或浏览器）开一次「允许安装未知应用」**，装完可以关掉；
4. 系统弹出权限与版本信息确认页时，核对一下应用名与开发者，再点安装；
5. 安装完成后桌面会出现图标，首次打开需要登录（见 [常见问题与排查.md](常见问题与排查.md) 第六节）。

## 四、系统要求与首次打开要开的权限

豌豆荚页面标注的要求是 **Android 7.0 以上**。系统版本低于这个值，安装阶段就可能直接报「解析包错误」。

首次使用会陆续申请下面这些权限，逐条对照着理解再决定给不给：

| 权限 | 官方说明的用途 |
| --- | --- |
| 存储 | 读取文件识别文字、保存生成结果 |
| 摄像头 | 反馈问题时拍摄相关照片 |
| 读取听觉媒体 | Android 13 上读取本地音频识别文字 |
| 麦克风 | 联系客服时发送语音 |
| 读取视觉媒体 | Android 13 上读取本地视频识别文字 |
| 通知 | 消息提醒 |
| 系统设置 | 读取文件识别文字、保存生成结果 |

两点提醒：

- **存储权限建议给**。不给的话，「文档解读」「保存生成结果」这类功能会直接不可用，而不是降级；
- **麦克风、摄像头不给也能正常写作**。这两个主要服务于客服与识别类功能，写作主流程不依赖它们。

在 Android 13 及以上，媒体类权限被拆成了「听觉媒体」和「视觉媒体」两项，两个是独立弹的，只给其中一个时另一类文件读不出来。

## 五、装不上 / 装完打不开，先查这几条

| 现象 | 先查什么 |
| --- | --- |
| 提示「解析包错误」 | 系统版本是否低于 Android 7.0；apk 是否下完（体积明显小于 69.95M 就是没下完，重下） |
| 点安装没反应 | 文件管理器没有被授予「安装未知应用」权限，或系统安全设置里拦截了 |
| 装完桌面找不到图标 | 部分机型的应用抽屉需要手动添加；也可能被安全管家类工具限制了桌面快捷方式 |
| 打开后闪退 | 先清一次该应用的数据与缓存再开；仍闪退则卸载后换官方商店那一版重装 |
| 商店里搜不到 | 该应用在部分渠道下架或地区不可见，改用另一条途径 |

更细的现象对照见 [常见问题与排查.md](常见问题与排查.md) 第一节。

## 六、装完之后建议做的两件事

**第一件：决定要不要关自动更新。** 装的是网盘那份 2.3.2，又想留住这一版的话，到应用商店里把这个应用的自动更新关掉；步骤通常在各商店的「我的 → 设置」里，找到「自动更新应用」一项，改成按应用单独设置后再关掉这一个。不关的话，系统静默更新会把版本升上去，你手上核对过的版本号就对不上了。

**第二件：记一次版本号。** 打开应用，在「关于」或「设置」里看一眼当前版本，记下来。日后遇到功能对不上、界面和文档描述不一致时，先比对这一项，能省掉一大圈排查。

这一版装的是固定的安装包，**应用内的数据与账号不随版本走** —— 换版本、换渠道不会丢账号，但本地未上传的草稿可能会丢，重装前先复制走。
