自己写的稿子不满意，或别人给的材料需要加工，用的就是这一组功能。它们的共同点是**都要你先粘贴或输入一段原文**，区别在于加工的方向：变短、变长、换说法、还是修毛刺。本篇按用途把这几件事分开讲清楚。

## 一、先说哪件事该用哪个功能

| 你的处境 | 该用 |
| --- | --- |
| 一份长材料，只要核心几句 | 要点提炼 |
| 一个题目太大，不知道从哪切 | 主题拆解 |
| 写到一半接不下去 | 续写 |
| 内容太干，需要铺开讲 | 扩写 |
| 意思对但说法不合适 | 改写（换种表达） |
| 读起来别扭、有语病 | 润色 |

选错功能的典型表现是「越改越不对」：想让文章更丰满却点了要点提炼，结果越改越短；句子读着不顺却一直点扩写，只是把别扭的句子变得更长。**先判断是「长度问题」还是「表达问题」，再选按钮。**

## 二、要点提炼：怕丢重点就先把全文保住

提炼会压缩信息，压过头就会丢结论。做法上有两个保险：

1. **原文单独留一份**。提炼结果不满意时，重新粘一遍原文比在压缩后的文字上恢复更省事；
2. **先指定用途再提炼**。是拿去做会议纪要、还是拿去当汇报开头，两种用途该保留的内容不一样 —— 在指令里写一句「保留时间、数字与责任人」，比直接点按钮稳。

材料特别长时，分段提炼再合并，通常好过一次性丢进去。

## 三、主题拆解：把一个大题目变成能动手的小节

主题拆解适合写论文、写策划这类需要先搭结构的场合。用法上有个顺序：

1. 先让它拆出**一级结构**（通常 3~6 个方面）；
2. 你自己判断哪几个不用，删掉；
3. 再对保留下来的每个方面单独展开。

跳过第二步直接让它拆到底，会得到一份看起来很全、但每节都用不上的目录。**拆解的价值在于给你一个可以删的初稿，而不是给你一个照抄的框架。**

## 四、续写与扩写：都是变长，但入口不同

- **续写**适合接在你已经写完的一段后面。粘上已有内容，再写一句你想往哪个方向走（「接着写这个方案的落地步骤」），它才会顺着你的意图走；只粘内容不给方向，它容易另起一个话题。
- **扩写**适合已有的句子太概括。扩写时明确要补什么最有效：补例子、补数据、补步骤还是补对比。含糊地说「写详细点」，得到的通常只是同义句的堆叠。

两者都有同一个坑：**越长越容易夹带不准确的内容**。扩写出来的具体数字、案例，一律要自己核实后再用。

## 五、改写与润色：改的是表达，不是事实

改写（换一种表达）和润色的区别在于改哪一层：

| | 改写 | 润色 |
| --- | --- | --- |
| 动的部分 | 句子结构、用词、语气 | 语病、搭配、标点、长句 |
| 结果 | 同一件事换种说法 | 同一句话读起来更顺 |
| 什么时候用 | 表达重复、语气不对 | 读起来拗口、有错别字 |

用法建议：

- **分段改，别整篇扔进去**。整篇改写后你会很难判断哪一句被改动了原意；
- **改写强度别一上来拉满**。强度高时它会替换掉你的专有名词和行业说法，反而更不像你写的；
- **改完逐段对照原文**。改写最容易出问题的地方是**把限定条件改掉**（「一般不」变成「不」），这类偏差看着不刺眼，用起来会出事。

要提醒一句：这一组功能是用来加工**你自己的文字**的。把别人的原创内容改头换面当成自己的成果发表或提交，涉及版权与学术诚信问题，属于你自己的责任范围，工具本身不承担这件事。生成内容的权利归属与商用边界，见 [生成的内容能不能商用.md](生成的内容能不能商用.md)。

## 六、一条稳的做法

手上有一篇稿子要打磨时，按这个顺序走一遍，返工最少：

1. 先看**要点提炼**，确认全文的核心结论是不是你想说的；
2. 再看**主题拆解**，确认结构有没有缺项；
3. 然后逐段做**润色**；
4. 最后才考虑对个别段落**扩写**；
5. 全文通读一遍，把专有名词、数字、限定词逐个核回原文。

顺序反着来（先扩写再提炼）会白干一轮 —— 你花力气铺开的内容，很可能在提炼那一步就被砍掉了。

## 七、长文怎么处理

原文很长时一次性丢进去，容易遇到后半段没改到、结果被截断的情况。按章节分开处理更稳：

1. 先按小标题把原文切成几段；
2. 每段单独做一次润色或改写，改完立刻贴回你自己的文档；
3. 全部改完再通读一遍，专门检查段与段之间的衔接词有没有对不上。

顺序不要反：**先分章改、最后统一通读**。反过来做，等于每改一段都要重新通读全文一次。

生成阶段的操作见 [怎么用它写出第一篇内容.md](怎么用它写出第一篇内容.md)；处理长文时出现卡住、超时、结果被截断，见 [常见问题与排查.md](常见问题与排查.md)。
