AI万能写作把「输入一个主题、拿到一篇能改的初稿」这件事做成了首页最显眼的入口，适合要交周报、写文案、凑一篇作文大纲的人快速起步。本篇不讲它有多少功能，只讲第一次用怎么把一篇东西真正写出来。

## 一、两条入口，先想清楚走哪条

打开应用后，首页有两条创作路径，区别在**你手上有没有素材**：

| 入口 | 什么时候用 | 你要提供的 |
| --- | --- | --- |
| 直接创作 | 只有一个题目，什么都没有 | 一句主题 + 字数 + 风格 |
| 模板创作 | 知道要写「哪一类」东西 | 选领域与模板，再补具体信息 |

判断标准很简单：**能说清「写什么类型」就先去模板里找**。短视频文案、日报周报、求职简历、活动策划这些都有现成分类，选完它会把该填的空摆在你面前，比对着空白输入框硬想省事。

## 二、主题这一栏怎么写，结果差得最多

主题不用写得漂亮，但要写清楚三件事：

1. **给谁看**（客户、同事、老师、粉丝），这决定用词深浅；
2. **要什么文体**（纪要、提案、种草笔记、演讲稿），这决定结构；
3. **大概多长**（字数别丢给默认值，见下一节）。

反例是「帮我写一篇关于 AI 的文章」——它什么都没限定，生成结果只能是一篇正确的废话。改成「给公司同事看的、介绍我们部门这季度引入 AI 工具后的变化，偏汇报口吻，800 字」，结果会具体得多。

### 一个能直接套的写法

把要求拆成五段写，比堆形容词有效得多：

```text
角色：你是一位有 10 年经验的公司内刊编辑
任务：写一份部门季度情况汇报
对象：不熟悉技术的同事
长度：800 字左右，分 3 个小节
要求：开头一句话给结论；数字留出空位由我填；不要用「赋能」「抓手」这类词
```

五段里最容易被忽略的是**最后一段**（不要什么）。写清楚不要哪类词、哪类句式，比写十句「写得好一点」都有用。

## 三、模型、字数、风格三个开关

生成前通常能调这几项：

- **模型**：应用里可以在多个大模型之间切换。同一段主题换个模型，措辞与结构会明显不同 —— 这是遇到「生成得很死板」时最快的一个尝试；
- **字数**：这是**最该手动设的一项**。默认值往往偏短，写汇报、写论文大纲时一定要往上调，否则出来的更像提纲；
- **风格**：口语/正式、活泼/严肃这类选项，影响的是句式，不影响事实。
- **联网与深度思考**：需要引用近期信息时打开联网；需要它多想一层（比如列论据、做对比）时打开深度思考。两个开关都会让等待时间变长。

写长文时不要指望一次到位。**先用 300 字以内试一次，确认方向对了，再把字数调上去重生成**，比一上来就要 2000 字划算得多。

### 结果不对时，按这个顺序调

一次只动一项，否则你不知道是哪一项起的作用：

| 现象 | 先调什么 |
| --- | --- |
| 内容太空、全是套话 | 改主题（补「给谁看」和具体场景），其次才动风格 |
| 篇幅不够 | 调字数；还短就补要求（多举例子、多分小节） |
| 语气不对 | 换风格；再不行就在主题里直接写「用 XX 口吻」 |
| 结构不像这类文体 | 改走模板创作，别在直接创作里硬拧 |
| 内容过时 | 打开联网；仍不对则自己把最新事实补进主题 |
| 完全跑偏 | 换模型重生成，比继续追加要求更快 |

## 四、生成之后，先做三件事再复制走

生成结果直接复制去用，多半会出问题。至少做三件：

1. **改首尾两段**。AI 写的开头结尾最容易套话，换成你自己的说法，整篇的「AI 味」会明显下降；
2. **核事实与数字**。凡是生成内容里出现的具体数据、时间、人名，一律当作待核实项，而不是事实；
3. **看有没有硬凑的小标题**。字数不够时它常把一句话拆成两节，该合并就合并。

改法上的更多手段（扩写、改写、润色）见 [改写润色与续写扩写.md](改写润色与续写扩写.md)。

## 五、一次验收清单

生成完对一遍，能挡掉大部分返工：

- [ ] 主题里的三个限定（给谁看 / 什么文体 / 多长）都落实了吗
- [ ] 字数是否达到你要的量，还是需要重新设置后再生一次
- [ ] 出现的数字、时间、名称是否已自行核实
- [ ] 首尾段是否已换成自己的表达
- [ ] 有没有明显重复的段落

## 六、结果存在哪，怎么带走

生成的结果会在应用内保留，可以从历史记录里再打开继续改。要拿到别处用，走复制或导出即可。

需要留意的是：**生成内容与应用内的历史记录通常与账号绑定**，换手机、退出登录前，把要留的内容先复制到自己的笔记工具里，比事后去找更稳。具体保存与导出入口在不同版本里位置略有差异，以你手机上这一版的实际界面为准；找不到入口属于使用层问题，可对照 [常见问题与排查.md](常见问题与排查.md) 第五节。
