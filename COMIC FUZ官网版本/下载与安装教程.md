COMIC FUZ 是日本芳文社（HOUBUNSHA CO., LTD.）做的漫画应用，2019 年 3 月上线，收录《まんがタイムきらら》系列杂志、《週刊漫画TIMES》等刊物的连载以及平台独占的原创作品，界面与正文都是日文。本篇讲把网盘里这份包装进安卓手机、确认版本，以及第一次打开要做什么。

## 一、先确认网盘里这份包是哪一版

网上能搜到的版本号是官方当时的最新发布版，网盘里这份是做文档时核对过的那一版，两者不一定是同一个。本文出现的版本号、包名、体积，一律以下表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | COMIC FUZ |
| 版本号 | 2.33.0 |
| 包名 | `com.comic_fuz` |
| 安装包体积 | 10.01 MB |
| MD5 | `02FCE508AC6D0F118A8D3B4022237CD4` |
| 核对日期 | 2026-09-24 |

核对办法：把下载好的 APK 放到电脑上，用任意一个能算哈希的小工具算一遍 MD5，再与上表对照。值一致，说明文件完整、和文档里描述的是同一份；对不上就是下载过程中断了包，重新下一遍。

## 二、装之前要核对的两件事

**第一，这是安卓包。** 网盘里给的是安卓安装包，iPhone 与 iPad 装不了。iOS 版本要在苹果应用商店的日本区找，与这份包不是一个渠道，版本号也不会一致。

**第二，系统版本别照字面理解。** 这份包的运行要求被标注为「需要支持安卓系统 5.2 以上」。安卓并没有 5.2 这一档公开版本号，这类标注多来自打包工具的编译口径，当参考就好，不必当精确门槛。真正的判断办法是装上试：

- 安装时弹「应用未安装」「解析包错误」；
- 或者装完一打开就闪退、停在启动页不动；

出现这两种情况，多半是手机系统版本太低，而不是包本身坏了。官方在应用商店页面上标注的系统要求会随版本更新变动，装之前想确认就去看一眼商店页面当时的写法。

## 三、安装步骤

1. **转存并下载**：从 [COMIC FUZ 安装文件资源（夸克网盘）](https://pan.quark.cn/s/a525584a4e9f) 把 APK 转存到自己的网盘，再下载到手机上；
2. **允许安装未知来源的应用**：在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给用来打开安装包的那个应用（文件管理器或浏览器）打开开关，否则点安装包不会有反应；
3. **先卸掉签名不同的旧版**：手机里若已装过同包名 `com.comic_fuz`、但来源不同的版本，安装会直接失败。先把旧的卸载掉再装，不要覆盖安装；
4. **跟随系统提示走完**：国产手机会在安装过程中弹「安全检测」「外部来源应用」之类的提醒，选择继续安装即可，中途不要返回。

## 四、第一次打开要做的三件事

**第一，联网。** 首页、作品列表、漫画正文都是实时拉取的，断网打开只会停在加载状态。

**第二，注册一个账号。** 账号入口在应用右下角的「マイページ」（我的页面）里，用邮箱与密码就能建。不注册可以先翻一翻，但阅读进度、看广告领到的奖牌这些都挂在账号上，换手机就找不回来了 —— 具体走法与注意事项见 [注册登录与换机迁移.md](注册登录与换机迁移.md)。

**第三，把更新通知打开。** 这个平台的作品多按月更、周更，隔一段时间不打开很容易错过更新（如果不想开，至少把常看的作品加进收藏，方便自己回来看）。

## 五、装完做一次最小验证

1. 在首页或搜索框里搜一部作品，比如 `ゆるキャン△`；
2. 从结果里点开作品页，再点开第 1 话；
3. 能正常出图，就说明安装没问题。

如果一直转圈、白屏，或者提示加载失败，转到 [看不了或读不了怎么排查.md](看不了或读不了怎么排查.md) 按顺序排一遍。如果只是某一部作品点开有问题、换一部就正常，那更可能是那部作品本身的资源问题，不必怀疑安装包。
