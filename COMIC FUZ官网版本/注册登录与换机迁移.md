COMIC FUZ 不登录也能翻作品，但阅读进度、已获得的奖牌、收藏与订阅状态都挂在账号上。本篇讲账号怎么建、换手机时靠什么把东西带过去，以及注销账号前要知道的事。

## 一、不注册会丢什么

先明确代价，再决定要不要注册：

| 不注册时的情况 | 后果 |
| --- | --- |
| 阅读进度（读到第几话） | 换机、卸载重装后归零 |
| 黑牌、银牌、金牌的余额 | 一并归零 |
| 收藏 / 本棚 | 丢失 |
| 月额订阅状态 | 无法在别的设备上继承 |

结论很直接：**只要你打算长期看，就先把账号建起来**，越早越好 —— 奖牌是按时间累积的东西，注册前的积累带不走。

## 二、账号怎么建

入口在应用右下角的「マイページ」（我的页面）：

1. 打开应用，进入「マイページ」；
2. 选「新規会員登録」（新会员注册）；
3. 填邮箱与密码，按提示走完；
4. 回到「マイページ」，看到已登录状态就成功了。

几条经验：

- **邮箱要用你能长期用的那个**。它是找回账号的唯一凭据，用一次性邮箱日后会很麻烦；
- **密码别和邮箱密码一样**，这是外部平台账号，没理由共用；
- 注册后建议顺手在同一页面把作品更新通知的开关打开，追月刊时有用。

## 三、换手机、重装后怎么恢复

不需要「导出」什么文件，**用同一个邮箱和密码在新设备上登录就行**：

1. 新设备装好 COMIC FUZ（装法见 [下载与安装教程.md](下载与安装教程.md)）；
2. 打开应用，进「マイページ」；
3. 选登录（页面右上角通常有登录入口），输入注册时的邮箱与密码；
4. 登录后核对一下：奖牌余额、收藏、订阅状态是否都回来了。

注意两点：

- **新旧设备不要同时挂着同一个账号操作**，尤其是订阅和购买相关，容易出状态不同步；
- 旧设备如果还留着，处理完新设备后把旧设备上的登录退掉再送人/回收。

## 四、网页版和手机版是同一个账号吗

是。COMIC FUZ 除了手机应用，还有一个网页版，用同一套邮箱密码登录，收藏、阅读进度、奖牌、订阅状态都是通的 —— 想在电脑大屏上看，不必装模拟器。网页版能做什么、和手机版差在哪、退订路径为什么不通用，都在 [在电脑上用网页版看.md](在电脑上用网页版看.md) 里，这里只提一句最要紧的：**在网页上订的订阅要去网页退，在手机应用里订的要去 App Store 或 Google Play 退，两条路不能互换。**

## 五、退出登录与注销

**只想退出**：在「マイページ」里找登出（ログアウト）即可，数据和奖牌都还留在账号上，下次登录还在。

**想彻底注销**：申请退会（退会申請）的入口在「マイページ」页面的最下方，点进去读完说明、确认后提交即可。注销前先想清楚两件事：

- 账号里剩下的奖牌、点数和订阅**不会退钱、也无法找回**；
- **如果还有没到期的月额订阅，要先解约再注销**，否则订阅可能继续扣费。解约路径见 [每月订阅计划怎么选.md](每月订阅计划怎么选.md)。

## 六、登录不上先查这几点

按顺序排，多数问题在前两步就能解决：

1. **邮箱是否写错**：常见的是把注册时的邮箱记混了，或用了带别名的写法（`abc+1@` 与 `abc@` 在不同服务里不一定等价）；
2. **大小写与输入法**：密码区分大小写，检查输入法有没有把符号打成全角；
3. **是不是注册成了网页版账号**：两边账号是通的，但极少数情况下你可能注册在另一个邮箱上；
4. **网络是否稳定**：日本服务对链路稳定性敏感，换个网络再试一次；
5. 以上都排完仍登录不上，在应用内的客服 / 咨询入口提交问题，写清邮箱和大致注册时间。

更多打不开、读不了的情况，集中在 [看不了或读不了怎么排查.md](看不了或读不了怎么排查.md) 里按现象分好了类。
