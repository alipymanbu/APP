## 一、能用什么账号登录

登录用的是你**游戏平台的账号**，不是在应用里另注册一个：

| 平台 | 登录凭证 |
| --- | --- |
| PC（Warframe 账号） | 官网注册的邮箱与密码 |
| PlayStation Network | 走 PSN 授权页登录 |
| Xbox Live | 走微软账号授权页登录 |
| Nintendo Switch | 走任天堂账号授权页登录 |

较新的版本另外接入了 Steam 与 Apple 的登录入口。这里有两个容易踩的点：

- **默认各平台是各自独立的角色。** 你在 PC 的战甲进度和在 PSN 的进度本来是两份数据，用哪个平台登录就显示哪个平台的角色。官方另外提供**以账号绑定方式实现的跨平台存档**：在官网把多个平台的账号绑到同一个主账号上，就能跨平台共用一份进度；但绑定后主账号的进度与仓库会覆盖被绑定的账号，且绑定是永久的，动手前先想清楚让哪个当主账号。
- **国服账号登不进来。** 国内发行的《星际战甲》由腾讯运营、只支持 QQ 账号登录；而这个应用的登录选项只有国际版 PC 账号、PlayStation Network、Xbox、Nintendo（较新版本另加 Steam、Apple），没有 QQ 入口。用国服账号的话，这一套登录流程走不通。

## 二、登录要经过哪几步

1. 在主界面点登录，选你所在的平台；
2. 应用跳到对应平台的授权页，输入该平台的账号密码；
3. 按平台规则完成二次验证 —— PC 账号如果开了 TennoGuard 双重验证，这一步要收一封含验证码的邮件并填进去（见第三节）；
4. 回到应用，开始同步你的角色数据。

登录之后的第一次数据同步要等一会儿。同步没跑完时，铸造厂、采集机这些绑定账号的页面会是空的或一直在转圈，属正常，别急着重登。

## 三、TennoGuard 双重验证（PC 账号）

- 它加在邮箱加密码之外：登录时多一步邮件验证码，验证码每隔几分钟变化、只能用一次。
- **每换一台你用来登录的电脑，都要重新验证一次。**
- 开启入口在**官网**的账号管理页，不在这个手机应用里：登录 [warframe.com/user](https://www.warframe.com/user) 打开双重验证选项，点邮件里的确认链接即完成。
- 两个附带影响值得提前知道：开启之后游戏内的**玩家间交易**才被允许；开启之后登录游戏，收件箱里会收到 Ordis 发来的 3 天经验加成。
- 已经无法访问绑定邮箱时，改邮箱这一步只能通过官方客服处理，客服在审核通过后才会协助启用双重验证。
- 主机平台（PlayStation、Xbox、Switch）的双重验证由各自平台提供，入口不在 Warframe 官网，这里开启的是 PC 账号的那一份。

## 四、登录失败按这个顺序排

1. **先确认账号本身没问题。** 到官网 [www.warframe.com/login](https://www.warframe.com/login) 用同样的邮箱密码登一次（登录前先在页面退出已有登录状态）。官网能登、应用登不上，说明问题出在你当前的网络出口，而不是账号密码。
2. **换网络出口。** 关掉 VPN 或加速器再试；把手机从 Wi-Fi 切到流量，或换一个不同运营商的 Wi-Fi 再试。官方文档说明过原因：部分运营商让很多用户共用同一批 IPv4 地址，同段里有人触发了安全策略，同一段的其他人就会一起被拦。
3. **条件允许就把接入方式换成 IPv6。** 官方文档提到使用 IPv6 的玩家通常不会碰到这一类问题，可以联系运营商把接入方式从 IPv4 改为 IPv6。
4. **前三步都无效再报工单。** 官方支持入口是 [support.warframe.com](https://support.warframe.com/hc/zh-cn)，提交时把下面四项写全，能省一轮来回：

   - 手机型号与系统版本；
   - 应用内的版本号（如 `5.3.6.3`）；
   - 网络连接方式（Wi-Fi 还是数据流量）；
   - 具体报错原文。

不要在短时间内反复连点登录 —— 密集重试通常只会让你当前的 IP 更容易被拦。

## 五、隔几天就要重新登录一次

应用通常不会长期保留登录状态，隔一段时间打开就需要重新验证一遍；也有用户反馈这一步出现得比较频繁。可以先按下面几项把「本机原因」排掉：

| 检查项 | 怎么改 | 为什么相关 |
| --- | --- | --- |
| 手机时间与时区 | 系统设置里打开「自动设置时间」「自动设置时区」 | 设备时间偏差会让服务器认为你的登录凭证已失效 |
| 电池优化 | 把 Warframe助手 设为「不受限制」或「不优化」 | 后台被冻结时登录状态无法续期 |
| 后台数据 | 允许该应用在后台使用数据 | 后台被断网同样续不了状态 |
| 勿扰模式 / 省电模式 | 临时关掉再试一次 | 会抑制应用的联网与提醒 |

改完这几项后重新登录一次，放着几分钟再打开，看是否还掉。

⚠️ 排查时不要随手点「清除数据 / 清除存储」：**它会把应用里的登录状态一并清掉**，等于强制你重新登录一遍，而密码、绑定邮箱、双重验证都在手上的话倒是能重新登回来。安卓上的「清除缓存」才是相对安全的那一项。

## 六、账号安全上要守住的两条

- **账号密码不对外提供。** 包括一切声称能代打、代买、代登的人。共享账号本身违反官方用户协议，真出了事客服也可能帮不回来。
- **密码只给这个账号用。** 不要与其它网站或游戏同密码，避免一处泄露、处处被撞。

怀疑账号已经异常时：先到官网改密码 [warframe.com/resetpassword](https://www.warframe.com/resetpassword)，然后尽快带着尽可能多的信息联系客服说明情况。
