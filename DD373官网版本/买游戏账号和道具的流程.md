# DD373 买游戏账号和道具的流程

## 一、买家这条链一共几步

平台给出的买家流程是固定的：选择商品 → 支付订单 → 等待收货 → 收货确认无误 → 交易成功 → 评价/打赏。中途出问题则转入「申请部分完成 / 取消 / 查看退款」。

看起来简单，容易翻车的地方在中间那两步 —— 收货和确认之间的窗口期。

## 二、找商品

- **按游戏进**：首页按游戏分类浏览，游戏多的时候可以切「图标模式」按图标认，也可以点首字母快速跳到对应字母下的游戏。
- **按关键词搜**：搜索框里输游戏名或商品关键词。
- **按条件筛**：商品列表支持排序与高级筛选，按区服、类型、价格段缩小范围。
- **只想要有保障的**：在筛选栏勾上「只显示找回包赔」，列表就只剩带包赔标识的商品。

挑账号类商品时，别只看价格。同一款号在列表里会有几十条，建议横向比 3~5 条，重点看段位/装备描述是否写全、卖家信用分高低、有没有包赔标识。

## 三、下单与支付

1. 在商品列表、商品详情或购物车里把商品加入订单，点提交。
2. 进入**确认订单页**：选接手客服、填写购买信息（购买件数、常用联系手机、常用联系 QQ）。这些联系方式在「账户设置 → 基本信息」里设过之后会自动带出来。
3. 账号类担保订单要勾选并同意对应的买家协议，再点「提交订单」。
4. 进入收银台支付。支持银行卡 / 信用卡、支付宝、花呗、微信支付，部分订单可以用账户余额兑换的钻石支付。
5. 支付页面中途关掉没付成，订单会停在那里 —— 到「我的 DD373 → 我是买家 → 我购买的商品 → 待支付」里找回来继续付即可。

## 四、付完之后去哪看

两个入口都能进订单详情：

- 「我的 DD373 → 我是买家 → 我购买的商品」，点对应订单的「查看详情」。
- 「订单处理中心」，按订单状态（待付款、待发货、待收货等）分类查看。

订单详情页里能看到：订单状态、商品信息、卖家信息、聊天窗口，以及最下面的「联系接手客服」按钮。

## 五、联系接手客服

接手客服是**只处理这笔订单**的客服，不是万能的咨询入口。联系方式：

1. 订单详情页往下拉到最下面，点「联系接手客服」。
2. 或者从首页的「订单聊天」进去，在聊窗里切到「联系客服」选项卡。

两个限制要知道：

- **订单未支付时，联系不上接手客服** —— 还没付钱，客服不会介入，只能走咨询客服。
- **订单交易结束后，也联系不上接手客服** —— 事后再有问题，走咨询客服或申诉入口。

## 六、收货与确认

- 卖家发货后会把订单置为「发货完成」，这时你会收到通知。
- **先上号或者进游戏核实**：账号类商品要确认装备、等级、绑定信息与描述一致；道具类要确认数量、区服正确。核实没问题再点「确认收货」。
- 点确认收货后，货款按订单类型结算给卖家（带包赔的订单，货款要等包赔期满才放行，见 [寄售和担保有什么区别.md](寄售和担保有什么区别.md) 第五节）。
- 确认收货前发现问题，**不要点确认**，直接在订单里申请客服介入。

账号类商品还有一件事必须尽快做：拿到账号后马上改密码、换绑手机与安全信息，把它绑成自己的。不换绑，等于账号还挂在别人手里。

## 七、出问题怎么申请介入

1. 在订单详情页找「申请接手客服介入」。
2. 选择与你情况相符的原因项。
3. 上传证据：聊天记录截图、账号现状截图、录屏、发货凭证等，能证明「收到的和描述不一致」的材料越多越好。
4. 之后由接手客服跟进，涉及资金纠纷的会按平台规则裁定。

平台对纠纷的处理强调证据，所以从下单开始就养成交互留痕的习惯：聊天走站内、付款走平台、截图存着。

## 八、买家最容易犯的三个错

1. **脱离平台交易**。卖家说「加我 QQ 便宜点」就直接转账 —— 这类交易平台不认，钱要不回来，而且平台明确禁止双方在订单里索要站外联系方式，查到会封停账户。
2. **没验号就确认收货**。确认之后再想撤销，就得走纠纷流程，比事前核验麻烦得多。
3. **账号到手不换绑**。原卖家或第三方随时能把号拿回去，包赔虽然是兜底，但前提是你要能证明是找回行为，流程比换绑麻烦。

关于假客服、假链接的识别，见 [订单安全与防骗怎么把握.md](订单安全与防骗怎么把握.md)。
