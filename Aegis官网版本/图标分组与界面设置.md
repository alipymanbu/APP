# Aegis 图标分组与界面设置

> 条目攒到几十条之后，靠翻单子找码会很慢：这一篇讲排序、搜索、分组、图标包和主题怎么配。

条目少的时候什么都不用配，几十条之后就得靠排序、搜索和分组把这堆码管起来。这一篇只讲界面和查找相关的设置，不解锁流程（那是 [保险库密码与生物识别.md](保险库密码与生物识别.md) 的事）。

## 一、排序：五种方式按习惯挑

主界面顶部有排序入口，可选的方式有：

| 排序方式 | 什么时候合适 |
| --- | --- |
| 发行人（A→Z / Z→A） | 默认思路；找某个网站的码时最快 |
| 账户（A→Z / Z→A） | 同一个网站有多个账号时，按账号名排更顺 |
| 使用次数 | 常登的那几个会被顶到前面 |
| 最近使用 | 按最近用过的顺序排，适合集中处理几个账号 |
| 自定义 | 手动把常用的拖到固定位置，顺序由你定 |

固定用某一种都行，但**别把「自定义」当成临时手段**：一旦手动排过，之后新增条目不会自动插到合适的位置，得再拖一次。

## 二、搜索：按发行人还是按账户名

- 搜索框默认按**名称和发行人**匹配，输网站名或邮箱片段都能命中；
- 设置里可以改搜索行为的范围（例如只在当前分组里搜），条目多、分组又细的时候能少出一堆无关结果。

跟排序配合用效率最高：先按分组或排序把范围收窄，再输关键词。

## 三、分组：把「工作」「个人」「家人的」分开

分组是长按/编辑条目时指定的，主界面上可以按分组过滤：

- **新建分组**：在条目的编辑界面直接输入分组名，或用设置里的「编辑分组」统一管理；
- **不分组也有一处**：没指定分组的条目会归在「无分组」下，不会消失；
- **同时看多个分组**：设置里有「分组多选」开关，打开后可以一次选中好几组一起看；
- **清理空组**：设置里有「删除未使用的分组」，会把没有任何条目在用、但名字还留在列表里的组删掉；
- **删分组不等于删条目**：移除某个分组后，原本在该组里的条目会回到「无分组」，码本身还在。

## 四、图标包：让每条码一眼能认出来

Aegis 支持导入图标包，给条目指定图标后列表扫一眼就能认出来。官方没有自己出图标包，社区维护的资源里比较常提到的是 [aegis-icons](https://github.com/aegis-icons/aegis-icons)。

用法：

1. 在 **设置 → 图标包** 里点加号，导入一个图标包文件；
2. 到条目的编辑界面，给这一条指定图标；不指定就继续用自动生成的字母图标；
3. 同一个图标包重复导入会问你「是否覆盖」；不需要了可以在同一页删掉；
4. 删除图标包**不会**影响已经用上该图标的条目 —— 它们会保留当前的图标，只是以后不能再从这一包里挑了。

## 五、主题、码位显示和其他外观项

- **主题**：内置多套（浅色 / 深色 / 纯黑 AMOLED 等）。纯黑在高对比度的屏上更省电，夜里看也不刺眼；
- **码位分组**：可以把 6 位码按几位一组显示，肉眼核对时不容易串位；
- **条目视图**：列表式和卡片式两种展示方式，条目少用卡片、条目多还是列表一屏看得更多。

这些项都在设置里，改完立刻生效，不影响保险库内容，可以放心试。

## 六、编辑条目和重复条目的处理

长按条目进编辑界面，能改发行人、账户名、图标、分组，也能看到算法/位数/周期这几个参数。

新增时如果和已有条目同名同发行人，Aegis 会先弹窗问怎么处理，其中「覆盖」是不可撤销的：它会把原有的同名条目替换掉。**两个不同账号恰好用了同一个发行人名字时最容易误点**，遇到这个弹窗先看清楚再选。

排序、分组都配好了还是找不到码、或者找到了但码不对，那是另一类问题，见 [验证码不对怎么办.md](验证码不对怎么办.md)。
