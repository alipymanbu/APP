电视端侧载应用遇到的问题来来回回就那么几类，大部分不用重装就能解决。本篇按现象分类，每条只给该查的顺序 —— 从最常见的开始往下试，别一上来就重装。

## 一、装不上，或者装完找不到图标

| 现象 | 先查这里 |
| --- | --- |
| 提示「暂不支持未知来源应用安装」 | 先把电视系统升到最新（设置 → 系统 → 软件更新）再重试 |
| 文件管理器里进 U 盘看不到 apk | 换一个 USB 口、U 盘拔下重插；确认 U 盘是 FAT32 格式 |
| 提示解析包错误、应用未安装 | 安装包在拷贝过程中可能损坏，从电脑重新拷一次；若网盘里仍是本文列的那一版，再按 [下载与安装教程.md](下载与安装教程.md) 的 MD5 核对文件 |
| 装完在首页找不到 | 图标多半在「全部应用」这个二级页里，找到后长按或按菜单键可以固定到首页 |

## 二、打开黑屏，或者只有画面没声音

黑屏按这个顺序查（多数是第一条）：

1. **信号源没切对**：用电视遥控器按「信号源 / 信源 / 输入选择」，切到盒子实际插着的那个 HDMI 通道，等两三秒；
2. **HDMI 线松了或坏了**：两端都重新插紧，仍不行就换一根线、换电视上另一组 HDMI 口；
3. **分辨率不兼容**：盒子之前接别的电视时被设成 4K、高帧率，换到分辨率低的电视上就会黑屏无信号。长按盒子机身上的复位键或待机键 10~15 秒强制重启，回到默认分辨率；
4. **输出进程卡死**：拔掉盒子电源，断电静置 3 分钟以上再上电，比普通重启更彻底。

只有画面没声音时：先看电视音量与静音状态，再确认音频输出设备选对了（如果声音已经被引到外接音响，音响得开机并切到正确输入）。

还有一种不算故障的情况：唱歌时自己听到的人声比嘴上慢半拍。这是无线麦克风和数字音频链路带来的延时，不是应用或设备坏了，压下去的办法见 [唱歌时的声音延时怎么减少.md](唱歌时的声音延时怎么减少.md)。

## 三、MV 转圈、播放卡顿

按从易到难的顺序：

1. 查网络 —— 换 5GHz Wi-Fi 或直接插网线，同时关掉在跑下载、在线的别的设备；
2. 清理应用缓存，再关掉后台正在运行的其他应用；
3. 重启电视或盒子；
4. 还不行就卸载后重新安装一次。

配置偏低的盒子上，可以顺手把界面里能关的展示项关掉（轮播图素材、歌曲片头字幕），减少界面本身的负担，路径见 [界面设置与曲库更新.md](界面设置与曲库更新.md)。

## 四、遥控器点不动、搜歌打字太慢

- 遥控器按键没反应：先换电池；蓝牙遥控器则重新配对一次，并确认遥控器和盒子之间没有遮挡；
- 用屏幕键盘一个字母一个字母选太慢：外接一个 USB 无线键盘或鼠标，输入方式切到「系统输入」直接打字，速度差很多；
- 手写输入在遥控器上写不顺：换回 ABC 字母方式，或接键盘。

## 五、搜不到想唱的歌

- 先更新曲库：设置 → 数据设置 → 更新曲库，很多「搜不到」都是曲库没更新；
- 换一条路找：歌名可能记错或有繁简差异，改用歌星名、只输首字母再试；
- 曲库有自己的更新节奏，刚上线的热歌不一定会立刻收录，过一阵再搜。

## 六、断网之后哪些功能会受影响

点歌和 MV 播放都依赖网络，断网之后语音点歌的识别精度也会下降，部分语音功能受限。所以 K 歌之前先把网络确认一遍，比唱到一半才发现要省事。

## 七、同名的电视 K 歌应用怎么区分

电视 K 歌这一类应用名字很接近，界面布局也相似，光看图标容易装错。可靠的两个判别点是：

| 判别点 | 值 |
| --- | --- |
| 包名 | `com.huiaichang.mars.desktop` |
| 版本号写法 | 形如 20250801.8.1 的「日期 + 序号」，渠道上也能见到 20260520 这类短写法的版本号 |

装之前对一下包名，对不上就不是本文这一份。安装包本身的版本、大小、MD5 以**网盘里那一份的实际信息**为准 —— [下载与安装教程.md](下载与安装教程.md) 的表格只是核对时那一版的记录，网盘里的文件更新之后，这几项都会跟着变。

## 八、唱完的歌能不能录下来或导出

本文核对的资料里，演唱相关的能力只写到调音、声场模式、评分和分段练歌这几块，**没有提到录音、作品保存或导出**。所以：

- 不要指望在应用里留档自己的演唱 —— 本文核对的资料里没有出现过这样的入口；
- 需要留档的话，只能另想办法（外接录音设备，或改用带录音保存的 K 歌应用）；
- 唱完想看的是音准、节奏、气息那几项数据，当次看掉即可。
