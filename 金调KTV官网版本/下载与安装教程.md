想在客厅用电视唱歌，第一步是把安装包送进电视里。本篇按顺序讲三件事：从网盘取到安装包、用 U 盘侧载到安卓电视或盒子、第一次打开要确认的设置。手机和平板也能装，但界面是按遥控器操作设计的，电视上的体验最完整。

## 一、先确认设备合不合适

| 项目 | 说明 |
| --- | --- |
| 支持的设备 | 安卓智能电视、安卓电视盒子；手机与平板同样能安装 |
| 操作方式 | 以遥控器方向键加确认键为主，界面按大屏排版 |
| 安装渠道 | 电视自带应用市场一般搜不到，需要 U 盘侧载安装包 |
| 网络 | 首次打开要联网才能拉到曲库，日常播放 MV 也需要联网 |

应用信息里没有标注明确的最低安卓版本，能不能装以设备能否识别安装包为准。安装过程中被系统直接拦下，多半是系统版本偏低或权限没放开，按第四节的顺序处理。

## 二、从网盘取安装包

1. 打开本篇头部的[金调KTV 安装文件资源（夸克网盘）](https://pan.quark.cn/s/2ebcc83de495)，先把文件转存到你自己的网盘；
2. 在电脑上从网盘把安装包下载下来 —— 不要直接用电视浏览器下，电视端下载慢，而且下完往往找不到文件存在哪；
3. 下载完成后核对一下文件信息：

| 项目 | 值 |
| --- | --- |
| 文件名 | 金调KTV_v20250801.8.1.apk |
| 版本号 | 20250801.8.1 |
| 包名 | `com.huiaichang.mars.desktop` |
| 安装包大小 | 59.75M |
| MD5 | `761F988C1D4078751A0E2C83EF768811` |

版本号是「日期 + 序号」的写法 —— 20250801 表示 2025 年 8 月 1 日出的这一版，后面的 .8.1 是内部序号。这个应用按日期持续发版，网盘里的文件名日期比本文列表里的新，说明资源已经更新过，直接装新的那份即可，不必再找旧版。

## 三、U 盘侧载到电视

1. 准备一个 U 盘，格式化成 FAT32 —— 电视对 FAT32 的兼容性最好，exFAT、NTFS 在部分机型上认不出来；
2. 把 apk 文件复制到 U 盘根目录，不要放进多层文件夹里；
3. U 盘插到电视的 USB 口。优先插标着「USB」的口，标着「HDD」「服务」的口有的机型不识别普通存储设备；
4. 在电视上打开文件管理器（各家叫法不同：媒体中心、本地媒体、文件管理、高清播放器），进 U 盘找到这个 apk；
5. 点安装，系统提示「未知来源」时选允许或继续安装；
6. 装完在「我的应用 / 全部应用」里找到金调KTV的图标，把它移到首页，以后省得每次翻列表。

各品牌电视的入口位置差别不小，常见机型的走法如下：

| 品牌 | 操作路径 |
| --- | --- |
| 小米 | 设置 → 账号与安全 → 安装未知来源的应用 → 允许；再从「应用 → 高清播放器 → 设备 → 移动存储设备」进 U 盘 |
| 海信 | 设置 → 更多设置 → 通用 → 商场模式（开启）；再进「应用 → 我的应用 → 媒体中心」 |
| 创维 / 酷开 | 先在应用里搜「当贝市场」（首字母 DBSC）装上，再在当贝市场搜「安装小助手」（首字母 AZXZS）装上，用它选 U 盘安装 |
| TCL / 雷鸟 | 我的 → 电视卫士 → 应用管理 → 极速安装 |
| 索尼 | 安全和限制 → 未知来源（开启）；再进「应用助手 → USB 路径 → USB1」 |
| 华为 / 荣耀 | 全部应用 → 媒体中心 → U 盘 → 文件 |
| 海尔 | 主页 → 本地媒体 → 全部 → 选中 U 盘 |
| 长虹 | 系统 → 媒体中心 → 设备 |
| 康佳 | 应用 → 电视管家 → 安装包管理 |

菜单名称会随机型和系统版本变化，以电视上实际显示的文字为准。

## 四、装不上时的三个备选做法

- **提示「暂不支持未知来源应用安装」**：先把电视系统升到最新（设置 → 系统 → 软件更新）再重试，部分华为、荣耀机型是这个原因；
- **文件管理器里看不到 apk**：换一个 USB 口、U 盘拔掉重插，或者把 U 盘重新格式化成 FAT32；
- **电视上没有可用的文件管理器**：改用电视盒子安装，或在电脑上用厂商的推送工具把安装包推到电视上（如「欢视助手」一类）。

## 五、第一次打开要做的事

1. 确认电视或盒子已经连好网络 —— 曲库和 MV 都在线取，没网打开是空的；
2. 首次运行如果弹出存储权限申请，选允许；
3. 进设置里手动点一次「更新曲库」，把曲库拉到最新，位置见 [界面设置与曲库更新.md](界面设置与曲库更新.md)；
4. 随手点一首歌试播，同时确认声音从哪里出来 —— 电视自带喇叭通常偏小，要不要接音响见 [麦克风与音响怎么接.md](麦克风与音响怎么接.md)。

打开后不要求注册账号，进主界面就能点歌。
