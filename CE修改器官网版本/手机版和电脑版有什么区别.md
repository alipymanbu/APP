搜「CE修改器」会同时出来两个方向的结果：电脑上的 Cheat Engine，和安卓手机上的这一套。它们同名、同源概念，但不是同一个程序，安装包体积、版本号、操作方式都不一样。本篇把两条线并排放清楚，免得你照着电脑版教程在手机上找按钮。

## 一、两条线对照

| | 手机版（本文这一套） | 电脑版 Cheat Engine |
| --- | --- | --- |
| 运行平台 | Android | Windows；另有 Linux 与 macOS 版本 |
| 本文对应的版本 | 6.0 | 官方下载页当前提供 7.x |
| 安装包体积 | 2.37M | 百兆量级 |
| 安装方式 | 手动安装 APK | 运行安装程序 |
| 操作位置 | 悬浮窗叠在游戏上，切来切去搜 | 桌面窗口，扫描时游戏在另一侧 |
| 是否需要额外权限 | 悬浮窗权限、后台保活 | 一般需要用管理员身份运行 |
| 功能深度 | 内存搜索、改值、锁定、地址列表 | 在前者基础上还有反汇编器、调试器、指针扫描、训练器制作、CT 表加载等 |
| 源码与发布 | 应用市场分发的独立安卓应用 | 开源项目，源码在 [cheat-engine/cheat-engine](https://github.com/cheat-engine/cheat-engine)，官方站 [cheatengine.org](https://www.cheatengine.org) |

## 二、版本号为什么对不上

这是最容易让人以为「装到了假货」的一点：**手机版是 6.0，电脑版已经到 7.x。**

原因是两条线的版本号各自独立演进，手机版并没有跟着电脑版的发布节奏走。所以：

- 在网上看到「CE 最新版 7.7」指的是电脑版，和手机上的 6.0 不冲突；
- 手机版内部也没有你熟悉的 7.x 界面，按电脑版的截图在手机上找按钮会找不到；
- 判断手上这一版是不是新的，看的是它自己的版本号与包名，对照表在 [下载与安装教程.md](下载与安装教程.md) 第五节。

官方下载页另外还提供一组叫 **CEServer** 的服务端文件（含 linux 与 android 平台）。那是给电脑版做**远程扫描**用的服务端程序，不是给手机日常使用的一体化应用，别把它当成手机版来装。

## 三、手机上能不能用电脑版

不能。电脑版的安装程序只能在桌面系统上运行，安卓上没有对应的可执行环境。想在手机上获得「更多功能」，现实做法只有两个：

1. 用本文这一套手机版，接受它功能较少、操作要来回切换的限制；
2. 把游戏放到电脑上跑（模拟器或原生电脑游戏），在电脑上用 Cheat Engine。

## 四、想在电脑上改手游：用模拟器

如果你要改的是安卓游戏，但想要电脑版更强的工具，常见做法是**把游戏装进模拟器，在电脑上操作**。这条路要做三件手机版上不存在的事：选中模拟器的**宿主进程**而不是游戏进程、在 CE 的 Extras 里开启内存读写相关开关、以及接受部分游戏会识别出模拟器环境。完整步骤与两个必开的设置见 [在电脑模拟器上改手游.md](在电脑模拟器上改手游.md)。

无论走哪条路，**能改的仍然只是本地数值**，服务端数据在两条线上都一样改不了，详见 [联网游戏为什么改不了.md](联网游戏为什么改不了.md)。

## 五、该装哪一个

按你的实际场景选，没有「哪个更好」的问题：

- 在手机上边玩边改、图省事 → 手机版，走 [下载与安装教程.md](下载与安装教程.md)；
- 要改电脑上的单机游戏、需要反汇编与指针扫描这类进阶功能 → 电脑版，从官方站获取；
- 要改安卓游戏又想要电脑版功能 → 走模拟器路线，见 [在电脑模拟器上改手游.md](在电脑模拟器上改手游.md)；
- 只是想在手机上试一次搜索改值是什么体验 → 手机版就够了，操作流程见 [搜索数值并修改怎么操作.md](搜索数值并修改怎么操作.md)。
