CE修改器是装在安卓手机上、给单机游戏改数值用的内存修改工具，改的是金币、血量、道具数量这类本地数字。它不是应用商店里直接能搜到的应用，得自己下载 APK 手动安装，装完还必须单独给它悬浮窗权限才能正常用。本篇从拿到安装包讲到第一次成功启动。

## 一、先确认你要装的是哪一套

「CE修改器」在不同人嘴里可能指两个东西：电脑上的 Cheat Engine，和手机上的这一套。两者界面、版本号、操作位置都不一样。

- 你要的是**在手机上边玩边改**，用手机版，看本篇就够了；
- 你要的是**在电脑上改单机游戏或模拟器**，那一套在本篇之外，先看 [手机版和电脑版有什么区别.md](手机版和电脑版有什么区别.md) 分清。

本文这一套是手机版，安装包只有 2M 出头；电脑版的安装包在百兆量级，两者体积差得很远，拿错了很容易看出来。

## 二、拿到安装包

CE修改器 安装包在夸克网盘里：[CE修改器 安装文件资源（夸克网盘）](https://pan.quark.cn/s/103dad461ce7)。按下面两步走，别只在网盘里点预览：

1. 打开分享链接，把里面的文件**转存到你自己的网盘**，再从手机端下载到本地存储。分享页直接预览是打不开 APK 的，必须落地成文件。
2. 手机上没网络或嫌慢，也可以先在电脑上下载好，再用数据线、微信文件传输、局域网工具传到手机。传到手机上时选「文件」而不是「图片/视频」，否则部分聊天工具会重新压缩，装的时候会报解析错误。

下载完成后，文件管理器里应该能看到一个扩展名为 `.apk` 的文件，大小约 2.37M。如果只有几百 K 或者几兆不到就断了，是没下载完，删掉重下。

## 三、允许「安装未知应用」

系统默认不允许安装从浏览器、聊天工具里点开的 APK。这一步的入口按系统版本差别很大：

| 你的系统 | 打开方式 |
| --- | --- |
| Android 8.0 及以上 | 设置 → 应用 → 找到**你用来打开这个 APK 的应用**（文件管理器、浏览器或聊天软件）→ 安装未知应用 → 允许 |
| Android 7.x 及更低 | 设置 → 安全 → 未知来源 → 勾选 |

Android 8 之后授权是**跟着「来源应用」走的**，不是全局开关。你可能用文件管理器打开时能装、用浏览器打开时又被拦，就是因为在浏览器那里没授权。较新的系统点安装包时会直接弹「去设置」，跟着提示点一次即可。

## 四、安装与首次启动

1. 在文件管理器里点中那个 `.apk` 文件，选「安装」。
2. 系统会列出该应用要用的权限，点「安装」确认；装完一般会提示「打开」或「完成」。
3. 首次打开时，应用会请求**在其他应用上层显示（悬浮窗）**权限。这个权限不要拒 —— 拒绝之后主界面能进，但搜索框弹不出来，等于没法用。各家系统的开启路径见 [悬浮窗权限与后台保活.md](悬浮窗权限与后台保活.md)。
4. 按一次主页键，让 CE修改器 留在后台。它的用法是「挂在后台 → 打开游戏 → 回来看进程列表」，关掉它进程列表就是空的。

顺带说清一件常被问到的事：**用手机版不需要 root**。未 root 的手机就能完成上面这些步骤和后续的搜索改值。免 root 环境里能被附加的进程范围会比 root 设备窄一些，个别游戏可能列不出来或搜不到，这部分属于排查范围，见 [搜索不到数值怎么排查.md](搜索不到数值怎么排查.md)；不要为了这件事去 root 主力手机。

## 五、核对装的是不是同一版

不同来源分发的同名应用版本很杂，装完对一下这一版的特征值，能避免「照着教程做，界面却对不上」：

| 项目 | 本文对应这一版 |
| --- | --- |
| 版本号 | 6.0 |
| 包名 | `com.charles.gebukhmer` |
| 安装包大小 | 2.37M（约 2 481 247 字节） |
| MD5 | `c7d7b8ef323f01d82f0828d015906e00` |

版本号在「设置 → 应用 → CE修改器」里能看到；包名和 MD5 需要借助文件管理器或把它传到电脑上核对。MD5 对不上说明文件和这里说的不是同一个包，功能界面可能有出入，以你手上那个版本为准。

## 六、装不上的几种提示

| 提示 | 大概率原因 | 怎么办 |
| --- | --- | --- |
| 解析软件包时出现问题 | 文件没下完，或传输时被改名、被压缩过 | 重新从网盘下载，不要经过聊天软件的图片/视频通道 |
| 应用未安装 / 与现有应用冲突 | 手机上已装过同包名的版本，签名不一致 | 卸载旧的同名应用后再装 |
| 已阻止安装 | 来源应用没有「安装未知应用」权限 | 回到第三节，给**当前这个来源应用**授权 |
| 系统版本过低，无法安装 | 系统低于该版本要求的下限 | 换一台设备。不同来源标注的下限不一致（Android 4.x 到 5.x 都有），以安装时的系统提示为准 |
| 装上了但一打开就退出 | 缺少悬浮窗权限，或系统拦截了后台 | 见 [悬浮窗权限与后台保活.md](悬浮窗权限与后台保活.md) |

另外两类和安装步骤无关、但常常一起出现的提示：

- **系统安全中心提示「风险应用」**。这类工具要读写其他应用的内存，行为特征会被部分机型的安全中心标记，安装或首次运行时弹提示属于常见情况。**不要用「先关掉安全中心/关闭安全防护再装」的办法处理** —— 如果系统明确判定它是恶意程序，那就不要装；临时关掉防护去装一个来源不明的包，风险比这个提示本身大得多。
- **浏览器或聊天工具提示「该文件可能有害」**。同上，属于对这类工具的常规拦截，换一个来源往往会再有同样的提示。真正要做的是确认来源可信，而不是想办法绕开提示。
