# CE修改器 在电脑模拟器上改手游

> 把安卓游戏装进电脑模拟器、用电脑版 CE 扫描模拟器进程来改数值：附加哪个进程、要开哪个选项、两类典型失败。

这条路适合「想改安卓游戏、但手机版工具不够用」的人：游戏照旧装在模拟器里跑，扫描和改值的动作交给电脑上的 Cheat Engine。电脑版工具链完整，代价是多一层模拟器，并且部分游戏会识别出模拟器环境、或者把改动弹回原值。本篇只讲怎么把两者接上，扫描本身的操作不重复。

## 一、准备两样东西

1. **一个安卓模拟器**。主流模拟器都行，只要能把 APK 装进去、能正常跑起目标游戏。
2. **电脑版 Cheat Engine**。从官方站 [cheatengine.org](https://www.cheatengine.org) 获取，不要用来路不明的第三方安装包。安装时若杀毒软件报毒，官方下载页对此有说明 —— 那是误报，但要确认下载源确实是官方站再用。

手机上那一套不用装，这条路线全程在电脑上操作。

## 二、附加到哪个进程

这一步做错的话，后面搜什么都是 0 条：

1. 在模拟器里把游戏装好并启动，进到能看到目标数值的界面。
2. 打开电脑版 CE，点左上角的进程选择按钮，弹出进程列表。
3. **不要找游戏自己的进程名**。模拟器通常把游戏跑在自己的宿主进程里，要选的是**模拟器本身那个进程** —— 例如 BlueStacks 常见的是 `HD-Player.exe`，其他模拟器则是以品牌命名的宿主进程，一般在列表里能一眼认出。各模拟器版本不同，名称可能变化。
4. 选中后点打开。列表里进程很多，逐个试一遍是正常做法 —— 选对的那个才会搜出结果。

## 三、搜不到内存时先改这一处设置

默认设置下 CE 只扫描本机物理内存，模拟器里的数据不在这个范围里，表现是「进程选上了，但搜任何值都是 0 条」。

到 CE 的 **设置 → Extras** 里，把内存相关的那几项开关打开（查询进程、读写进程内存、进程监视这一类），然后回到主界面**重新选一次进程**再搜。这是走模拟器路线必须先做的一步，不打开的话后面所有步骤都是白做。

## 四、之后的搜索流程与手机版一致

搜当前值 → 回游戏让这个数字变化 → 再搜新值 → 反复缩小范围 → 加入地址列表 → 改值并锁定。这一段操作与手机版完全相同，只是搜索框在电脑窗口里，游戏在模拟器窗口里，不用来回切设备，可以两个窗口并排放。逐步说明见 [搜索数值并修改怎么操作.md](搜索数值并修改怎么操作.md)。

## 五、两类典型失败

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 搜索始终 0 条 | 进程选错，或没开第三节那几项设置 | 回第二节重新选进程，再确认设置已开 |
| 改了值，一两秒后弹回原值 | 数值由服务端下发，或改到的是只读副本 | 先确认游戏是不是离线单机；是联网游戏就看 [联网游戏为什么改不了.md](联网游戏为什么改不了.md) |
| 游戏一启动就提示不支持模拟器 / 直接退出 | 游戏检测运行环境，拒绝在模拟器里跑 | 换一个模拟器试；仍不行就放弃这条路线 |
| 同一台电脑上还开着带内核反作弊的网游 | 部分反作弊会在系统里扫描这类工具的存在 | 不要在同一台电脑上同时做这两件事，理由见 [联网游戏为什么改不了.md](联网游戏为什么改不了.md) |

第三条是模拟器路线独有的麻烦：能不能在模拟器里跑起来，取决于游戏本身怎么判环境，换 CE 的版本或设置都解决不了。

## 六、什么时候值得走这条路

- 你需要的是**电脑版才有的那部分工具** —— 指针扫描、反汇编、加载现成的 CT 表；
- 你想两个窗口并排看游戏与搜索结果，手机上做不到；
- 你只是练手，不想在主力手机上反复装、卸这类工具。

如果目标只是在手机上改一个金币数量，那手机版本身就够了，不必多搭一层模拟器。两条线的差别见 [手机版和电脑版有什么区别.md](手机版和电脑版有什么区别.md)。
