# CE修改器 搜索不到数值怎么排查

「搜不到」在 CE修改器 里其实是好几种不同的问题，处理办法完全不同。先按你看到的现象对到下面这张表，再去对应小节，比从头把教程重做一遍快得多。

## 一、先对现象

| 你看到的 | 卡在哪一步 | 去哪一节 |
| --- | --- | --- |
| 进程列表里根本没有那个游戏 | 没识别到进程 | 第二节 |
| 输入数字点搜索，结果 0 条 | 搜索条件不对 | 第三节 |
| 结果几百上千条，筛不下去 | 数值没变过或没变对 | 第四节 |
| 只剩一两条，改了游戏里没反应 | 地址不对或类型不对 | 第五节 |
| 改完游戏直接退出 | 改到了关键数据 | 第六节 |
| 上面都正常，就是某些游戏不行 | 游戏做了防护 | 第七节 |

## 二、进程列表里没有这个游戏

按可能性从高到低查：

1. **游戏没真的在跑**。挂在后台的游戏进程有时会被系统回收，回到游戏确认它还在前台且没被重启。
2. **CE修改器 自己不在后台**。切回 CE修改器，按一次主页键再回来，让进程列表重新扫描一次。
3. **游戏用了多进程 / 分包结构**。列表里可能显示的是另一个名字（启动器、更新器）。逐个进去试，哪个里面有你要的数字就是哪个。
4. **游戏的进程名被隐藏**。部分系统或游戏会把进程名对第三方隐藏，只能看到图标，按图标认。
5. **设备环境的限制**。少数机型与系统版本下，允许被第三方附加的进程范围更窄；也有第三方教程提到要把游戏放进自带 root 环境的虚拟空间里运行、或在已 root 的设备上操作，才能附加到某些游戏。这类说法没有官方页面可以佐证，只能当方向参考 —— 不要为了一个游戏去 root 主力手机。
6. **游戏侧有防护**。见第七节。

如果列表里连一个游戏都看不见，先回到 [悬浮窗权限与后台保活.md](悬浮窗权限与后台保活.md) 检查权限与保活，这两项不满足时进程列表是空的。

## 三、搜出零条

搜索结果为空，基本都是**搜索条件与内存里的实际存储形式对不上**：

- **类型选错**。金币这类计数用整数；带小数的血量、倍率、百分比用浮点。用整数搜一个浮点值，一条都不会剩。同一个目标换类型重搜是常规做法。
- **数值显示的和存储的不一样**。常见三种：
  - 界面显示 `200`，内存里存的是 `2000`（显示时除了 10）——按 2000 搜；
  - 界面显示 `2.5K`，内存里是 `2500` ——按 2500 搜；
  - 显示的是四舍五入后的结果，实际带小数 ——改用范围搜索或按就近整数搜。
- **数字在变**。金币在自动增长、倒计时在跳动这一类，等你输完数字它已经不是那个值了。选一个**稳定的量**（等级、已购数量、装备属性）先练手。
- **数值是贴图或服务器下发的**。界面上的数字不在本地内存里，怎么搜都搜不到。判别方法见 [联网游戏为什么改不了.md](联网游戏为什么改不了.md)。

## 四、结果太多，筛不下去

「再次搜索」的正确用法只有一个前提：**这个数值得真的变过**。

- 数值没变 → 再搜一次等于用同一个条件筛同一批数据，范围不会缩小。必须回游戏让它变化。
- 变了但你又改回原值 → 同样无效。**让它在两次搜索之间有明确的、可读的差值**，比如从 200 变成 175。
- 变化幅度太小查不出效果 → 一次买掉能买的最多数量、放一次大招，让差值明显。
- 反复两三轮还是几百条 → 换一个变化幅度更大的数值来试，先拿单个属性练手，不要一上来就改一整套属性。

一页页翻结果没有意义，缩小范围只能靠「变化 → 再搜」这个循环。

## 五、只剩一两条，改了却没用

这一类是**地址选对了范围、但选错了具体那一条**：

- 内存里同一个数字常有多份副本（显示用、逻辑用、缓存用）。把结果里的条目**一次改两条以上**，或逐条试。
- 改完一瞬间生效、随后回弹，说明改到的是副本。回游戏里让数值再变一次，看哪条没跟着变，就是真正的那个。
- 类型可能仍然选错：整数类型下数值会被截断，明明改成了 9999 却显示成别的数，就换成浮点重来。

## 六、一改就闪退

改到了游戏用来做数组下标、循环上限、资源计数的字段，游戏一读就越界。

- 立刻关掉该条的锁定，把值改回原值。
- 闪退之后先确认存档有没有损坏，重要存档提前备份。
- 换一条结果试，不要在同一批结果里连改。

这类风险在**没有存档备份**的情况下尤其要小心，改之前先确认游戏有云存档或本地存档可以复制。

## 七、上面都正常，某些游戏就是不行

有些游戏会主动检测调试器、内存读写，或者对关键数值做了加密与混淆：

- **检测到调试行为**：表现为一附加就崩、或在搜索结果界面的瞬间被踢出。这类游戏不要再反复试，反复触发对账号和设备都没好处。
- **数值加密 / 多级指针**：看到的数字是变换后的结果，搜原值搜不到。定位这种目标需要指针扫描与逆向分析，手机版提供的工具不完整，通常做不了。
- **服务端校验**：本地明明改了、功能也生效了，一刷新就被拉回。详见 [联网游戏为什么改不了.md](联网游戏为什么改不了.md)。

以上三类都不是操作问题，换一个目标游戏比继续和它较劲划算。
