## 一、装之前先对一下版本

网上搜到的「Instagram 最新版」和这里发出去的安装包常常不是同一版：官方渠道版本更得快，而这份包固定是下面这一版。文档里凡是出现版本号、包名、体积，都以它为准。

| 项目 | 值 |
| --- | --- |
| 版本 | 438.0.0.19.88 |
| 包名 | `com.instagram.android` |
| 安装包体积 | 110.74 MB |
| MD5 | `08E51A962735745BB2A950D7D10BC143` |

装完想确认拿到的是不是这一版，看两处就够：

1. 打开 Instagram，进主页 → 右上角菜单 → 设置，拉到最底部能看到版本号（有的版本写作「关于」）；
2. 或者到系统「设置 → 应用 → 应用管理 → Instagram」的详情页看版本号。

体积对不上（差得远）就说明包没下完整，删掉重下。Instagram 的版本号是五段式（如 `438.0.0.19.88`），后两段变化最频繁；官方发新版不会单独通知你，想知道当前最新版只能看官方商店页面，**以官方当页显示为准**。

**关于「最低要安卓几」**：不同渠道对系统要求的标注并不一致（常见的两种说法是安卓 8.0 与安卓 9.0，且这条线会随版本上调），哪一个都不能当硬标准。可靠的做法是先看自己手机的系统版本（`设置 → 关于手机 → 版本信息`），真装的时候若被系统拦下，按屏幕提示判断即可。

## 二、把安装包取到手机上

安装包在 [Instagram 安装文件资源（夸克网盘）](https://pan.quark.cn/s/4faa617876e0) 里，手机或电脑打开都能转存。两条常见走法，选顺手的：

- **手机直接下**：在手机上打开网盘页面，转存后从网盘 App 的「传输」列表里点开文件，系统会直接问你要不要安装。
- **电脑下了再传**：电脑下载后，用数据线、微信文件传输助手、局域网工具把 APK 传到手机，再用系统自带的文件管理器找到它点一下。

传的过程中最容易坏在**后缀被改掉**。有些传输工具会把 `.apk` 变成 `.apk.1` 或干脆去掉后缀，这类文件点开通常不会触发安装，用文件管理器把后缀改回 `.apk` 再点。

110.74 MB 是这一版的正常体积。如果下到一半就停住（比如只有几十 MB），说明传输断了，重新下一遍。

## 三、安装：绕不过的「未知来源」

Instagram 不在多数国产手机自带的应用商店里，所以第一次装会碰到系统的安全提示，这是正常流程，不是安装包有问题：

1. 点击 APK，系统弹出「禁止安装未知应用」类的提示，选择**设置**；
2. 在跳转过去的页面里，把**当前这个来源**（文件管理器或网盘 App）的「允许安装未知应用」打开；
3. 返回，重新点一次 APK；
4. 安装界面会列出它要的权限，确认后点**安装**。

各家系统（小米、OPPO、vivo、华为、荣耀等）入口名字不同，但都在「设置 → 应用 → 特殊应用权限 / 安装未知应用」这一带；找不到就在设置里搜「未知应用」。

## 四、首次打开会要的权限

| 提示 | 该不该给 | 说明 |
| --- | --- | --- |
| 照片和视频 / 存储 | 建议给 | 不给的话发帖选不了相册里的图，也保存不了自己的内容 |
| 相机 | 看需要 | 只用来拍快拍、拍 Reels；不打算在 App 里拍可以拒绝 |
| 麦克风 | 看需要 | 录带声音的视频才用得上 |
| 通知 | 看需要 | 与能不能用无关，不想收推送可以拒绝 |

当时手滑点了「拒绝」不用重装：到「设置 → 应用 → Instagram → 权限」里重新打开即可。

## 五、装不上、装完打不开怎么办

按现象对号入座：

- **提示「解析包错误」**：APK 没下完整。删掉重下，核对上面表格里的体积与 MD5。
- **提示「应用未安装」**：手机上已有一个签名不同的同包名版本（最常见的是之前从应用商店装过官方版）。先卸载旧的再装这一版；卸载后原来的登录状态会清掉，装完重新登录一次即可。
- **提示「与设备不兼容」**：系统版本低于这款 App 的要求。Instagram 官方商店页的系统要求会随时间上调，不同渠道的页面标注还不一致，**以你手机上安装时的提示与官方商店页为准**。
- **装上了但一打开就闪退**：先到系统「设置 → 应用 → Instagram → 存储」清一次缓存再打开；仍然闪退就卸载重装，完整排查顺序见 [常见问题与排查.md](常见问题与排查.md)。

想提前知道这台机器行不行，先看一眼系统版本：`设置 → 关于手机 → 版本信息`（有的品牌写作「关于设备」「系统信息」），里面有安卓版本号。

## 六、换版本与彻底卸载

用 APK 装的这一份不会被应用商店接管，想换版本就是**下载新的 APK 覆盖安装**。覆盖安装的前提是两份包签名一致，签名对不上会报「应用未安装」，这时只能先卸载再装。

卸载不会删掉账号和已发布的内容 —— 它们都在服务端，重新装上登录同一个账号就都回来了；但**草稿、App 内的缓存、没同步的设置**会一起清掉。换设备前想留个底，见 [换手机与账号迁移.md](换手机与账号迁移.md)。

想清得更干净，除了常规卸载，再看一眼内部存储里有没有它生成的文件夹（如 `Android/media/com.instagram.android`），需要就手动删。
