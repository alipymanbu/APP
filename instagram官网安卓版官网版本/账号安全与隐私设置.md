## 一、先看一眼「谁登录过」

主页 → 右上角菜单 → **账户中心** → **密码和安全** → **你登录的位置**（不同版本写作「登录活动」）。这里按账号列出最近登录过的设备、大致地点和时间。

- 看到不认识的设备 → 直接把它退出登录，并立刻改密码；
- 拿不准是不是自己 → 结合设备型号和地点判断，宁可错退，事后自己重新登录一次。

同一个页面里还能看到**已保存的登录信息**和**受信任设备**。受信任设备一旦被勾上，之后登录可以跳过验证 —— 借别人手机登录时**不要**勾这一项。

## 二、双重验证（2FA）怎么开

路径：账户中心 → **密码和安全** → **双重验证** → 选你的 Instagram 账号 → 选验证方式。

| 验证方式 | 特点 | 建议 |
| --- | --- | --- |
| 验证应用 | 本地生成六位码，不依赖短信 | 最稳，推荐首选 |
| 短信 / WhatsApp | 收验证码，依赖手机号可用 | 方便，但换号后就麻烦 |
| 登录请求 | 在已登录设备上点「是我」批准 | 适合当补充，不适合当唯一方式 |

开完之后**一定把备用码存下来**（同一页面「其他方法 → 备用码」，共十个，每个只能用一次）。手机丢了、验证应用没备份时，就靠这十个码进去。

## 三、私密账号、拉黑与限制的区别

| 设置 | 效果 | 在哪 |
| --- | --- | --- |
| 私密账号 | 只有你批准的人能看你的帖子和快拍 | 设置 → **账号隐私** |
| 拉黑（Block） | 互相看不到内容，对方也发不了消息 | 对方主页 → 三点 → 拉黑 |
| 限制（Restrict） | 对方的评论只有他自己看得见，私信进请求箱，**对方收不到通知** | 对方主页 → 三点 → 限制 |

不想把关系彻底闹僵、又不想被打扰，用「限制」；完全不想再有交集，用「拉黑」。设置里还能单独控制**谁能评论、谁能给你发消息、谁能 @你**，以及自动**隐藏包含特定词的评论**，把骚扰挡在前面。

## 四、评论、快拍与在线状态

- **谁能评论 / 谁能看到你的快拍**：设置里逐项可调，可以只留「我关注的人」；
- **活动状态**：设置 → 消息和故事回复 → 关掉**显示活动状态**，别人就看不到你「在线」「刚刚活跃」；代价是你也看不到别人的；
- **已读回执**：私信里读完会显示「已查看」，这个开关和活动状态是联动的。

## 五、账号被盗后的抢救顺序

发现账号被盗或登不上，按这个顺序做，别乱试：

1. **走找回流程**：登录页 → 忘记密码 → 用注册的邮箱或手机号重置；
2. **改密码，顺带改绑定的邮箱 / 手机**：把攻击者可能还留着的找回入口一起换掉；
3. **退出可疑设备**：账户中心 → 你登录的位置 → 逐个退出不认识的那几条；
4. **处理被冒用的内容**：冒充、盗图、假账号，走 App 内的举报入口；
5. **别信「代申诉」**：网上收费帮你找回账号的，绝大多数是再骗一次。

**记住一条**：Instagram 官方**不会**通过私信对你发出警告或要求验证。真正来自官方、与你账号有关的信息，只会出现在设置里的「来自 Instagram 的邮件」页面。
