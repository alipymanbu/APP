## 一、注册前必须满足的三条

Instagram 的注册门槛不高，但下面三条任一不满足，会在提交时直接失败，而且**不会告诉你具体卡在哪**：

| 条件 | 具体要求 |
| --- | --- |
| 年龄 | 至少 13 岁，部分地区法定下限更高。填的生日不达标会被直接拦下 |
| 联系方式 | 一个能收验证码的邮箱**或**手机号，二选一即可 |
| 用户名 | 只能包含字母、数字、句点和下划线，不能有空格，且全网唯一 |

已经被别的账号占用的邮箱或手机号，就不能再拿来注册新号了 —— 如果提示「邮箱已被占用」「手机号已被使用」，换一个没注册过 Instagram 的邮箱或号码，或者先把它从旧账号上解绑。

## 二、注册的实际步骤

1. 打开 App，选**新建账号**；
2. 输入邮箱或手机号（用手机号就切到手机号那一栏，注意区号要选对）；
3. 收验证码并填入，或直接按提示确认；
4. 设置密码 —— 太短、太简单的会被拒；建议 8 位以上，混用大小写字母、数字与符号；
5. 填生日 —— 填真实的。为了绕过年龄限制改大或改小，反而可能触发年龄核验，把流程卡住；
6. 起用户名，不想要系统推荐的就在输入框里自己写一个；
7. 完成后可以关注推荐的账号，也可以直接跳过。

注册流程里通常不要求填身份证、实名信息之类，只要联系方式能收验证码就行。

## 三、验证码收不到怎么办

这是注册和登录里最常见的卡点，按这个顺序排：

1. **先等够 1~2 分钟**，别连着点重发 —— 频繁请求会被限流，越点越收不到；
2. **看拦截**：手机自带安全中心 / 骚扰拦截、短信 App 的「垃圾信息」分类翻一遍；邮箱就看垃圾邮件文件夹；
3. **换通道**：手机号收不到就改用邮箱注册，反之亦然；
4. **确认联系方式本身可用**：虚拟号、一次性邮箱、绑过太多账号的号码常被系统直接拒；
5. **别反复提交**：短时间内失败多次会进冷却，等一段时间再试。

## 四、登录与多账号切换

- **登录**：输入注册时用的用户名 / 邮箱 / 手机号加密码即可。不想输密码就选「用验证码登录」。
- **多账号**：Instagram 支持在一个 App 里保存并切换多个账号（常见口径是上限 5 个，具体以 App 内提示为准）。入口在主页点左上角账号名，选**添加账号**；之后点头像长按或点账号名切换。
- **退出**：设置里「退出登录」，或在切换账号界面选择要退出的那一个。

多账号切换很方便，但也要留意：设备被记住之后，别人拿到这台手机可能直接进你的账号。怎么管已登录设备见 [账号安全与隐私设置.md](账号安全与隐私设置.md)。

## 五、密码忘了、账号进不去

| 现象 | 处理 |
| --- | --- |
| 忘了密码 | 登录页点「忘记密码」，用注册时绑定的邮箱或手机号收链接 / 验证码重置 |
| 提示密码错误但确信没记错 | 先用验证码登录一次；能进去就在设置里重设密码 |
| 提示登录异常 / 要求验证身份 | 按屏幕提示走（一般是收验证码或确认登录请求），别换设备反复试，越试越容易触发风控 |
| 提示账号被停用 | 按 App 内提示走申诉流程；被盗相关处理见 [账号安全与隐私设置.md](账号安全与隐私设置.md) |
| 一直转圈登不上 | 先确认当前网络能否正常访问 Instagram 的服务，再按 [常见问题与排查.md](常见问题与排查.md) 逐项排 |

## 六、一条必须记住的安全常识

**Instagram 官方不会通过私信联系你。** 凡是私信里说「你的账号将被封禁」「点这个链接验证」「帮你申诉」「送你福利」的，都是骗子。官方与你账号有关的沟通，正式入口主要就两个：App 内的通知，以及设置里的「来自 Instagram 的邮件」页面。这类陌生消息直接举报、拉黑，不要点链接，更不要把密码和验证码给对方。
