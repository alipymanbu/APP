Battery Guru 是装在安卓手机上的电池信息读取工具，开发者是 Paget96。它只读不写：把系统里的电量、电流、电压、温度、容量与循环数据读出来展示，不修改电池、不加速充电。本篇只处理「怎么装到手机上、装完要开哪些权限」这一段，怎么看数据见 [电池容量和健康度怎么看.md](电池容量和健康度怎么看.md)。

## 一、先核对网盘里这份包

网上搜到的通常是官方当前最新版，和网盘里这份往往不是同一个版本号。本篇出现的版本、包名、体积一律以下表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | Battery Guru |
| 版本号 | 2.5.0.5 |
| 包名 | `com.paget96.batteryguru` |
| 安装包体积 | 8.36 MB |
| MD5 | `3624e4f3900e04c2a0eeec7d58cb62e8` |
| 开发者 | Paget96 |
| 记录时间 | 2026-09-23 |

安装包本体在 [Battery Guru 安装文件资源（夸克网盘）](https://pan.quark.cn/s/f4171e2c6c85) 里，转存到自己的网盘再下载到手机。

几点要分清：

- **官方渠道在哪**：官网是 [paget96projects.com](https://paget96projects.com/applications/batteryguru)，应用商店页是 [play.google.com/store/apps/details?id=com.paget96.batteryguru](https://play.google.com/store/apps/details?id=com.paget96.batteryguru)，官网还单独放了一个社区版安装包。想确认手上这份是不是同一款，认包名 `com.paget96.batteryguru` 最快。
- **版本会往前走**：本文按 2.5.0.5 写。2.5 之后官方仍在继续发版，新加的项只在更新版本里才有；哪天是哪一版以官方商店页当时显示的为准，个别菜单位置在不同版本里可能不一样。
- **MD5 怎么用**：下载完用文件管理器看文件详情，或用任意校验工具算一次 MD5，与上表一致说明传输没损坏；体积明显小于 8.36 MB 就是没下完，别装。
- **名字相近的应用有好几个**：应用商店里搜「Battery Guru」会一起出现「电池检测」「电池健康」这类汉化名，认开发者 Paget96 与包名，避免装成别的应用。

## 二、装之前先确认两件事

1. **系统版本**：官方商店页给出的最低系统版本是 Android 7.0 及以上（各商店与机型显示可能略有差异，以官方商店页当时显示的为准）。低于这个版本装不上，别硬试。
2. **手机上有没有同包名的旧版**：如果你之前从别的渠道装过 Battery Guru，两份包的签名通常不同，直接覆盖会报「应用未安装」。先卸载旧版再装新包。

## 三、安装步骤

1. 把安装包下载到手机。在电脑上下载的话，用数据线或任意传输工具拷进手机存储都可以。
2. **允许安装未知来源应用**：在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给用来打开安装包的那个应用（文件管理器或浏览器）打开开关。国产定制系统常把这一项收在「安全」「隐私」「更多安全设置」下面。
3. **点开 APK 完成安装**：系统提示「应用未经过安全检测」时选继续安装，这是从商店外安装安装包的常规提示。
4. **装完先别急着开**：如果手机上同时有应用商店版本，两个渠道的版本号往往不同步，留一个就行。

安装被拦下时，不同提示对应的情况不一样，按这张表对：

| 系统提示 | 原因 | 处理 |
| --- | --- | --- |
| 解析包错误 / 解析包时出现问题 | 下载不完整或文件损坏 | 重新下载，下完核对体积是不是 8.36 MB、MD5 是否与上表一致 |
| 应用未安装 | 手机上已有同包名、签名不同的版本 | 先卸载旧版再装；卸载会清掉应用内的历史记录 |
| 已阻止安装 / 安全提示 | 未知来源开关没打开 | 回到第 2 步，给打开安装包的那个应用开权限 |
| 提示版本过低无法安装 | 系统版本低于 Android 7.0 | 换一台系统版本达标的手机 |

## 四、首次启动要开的三项权限

打开后先别急着看数，有三项授权关系到后面能不能持续读到数据：

| 权限 | 用于什么 | 不授权会怎样 | 一般在哪开 |
| --- | --- | --- | --- |
| 通知 | 电量、温度、充电状态的常驻通知与告警 | 状态栏看不到数值，各项告警不会弹 | 首次启动时弹窗；漏点了到「设置 → 应用 → Battery Guru → 通知」补开 |
| 显示在其他应用上层（悬浮窗） | 悬浮窗实时数据 | 悬浮窗加不上，其余功能正常 | 「设置 → 应用 → Battery Guru → 显示在其他应用上层」 |
| 不受电池优化限制 | 息屏后继续读取与记录 | 息屏一段时间后曲线断档、数据不再更新 | 「设置 → 应用 → Battery Guru → 电池 → 不受限制」（各系统入口名略不同） |

通知那一项在 Android 13 及以上是独立弹窗，不允许就不会有任何提醒。国产系统还会额外有一层「自启动」「后台运行」开关，一并打开更稳。

## 五、为什么过一会儿数据就不动了

这是这类应用最常被当成「坏了」的现象，实际多半是系统把后台进程收掉了。

1. 先把上面表格里的「不受电池优化限制」打开。
2. 在系统的应用管理里找到 Battery Guru，把「自启动」「关联启动」「后台运行」这类开关打开（不同厂商叫法不同，位置在应用详情或系统管家的省电设置里）。
3. 在最近任务里下拉这个应用，给它加锁（厂商系统常见的长按加锁或下拉锁定），避免一键清理时被清掉。
4. 做完这三步，息屏放置半小时后回来，看主界面的曲线是不是连续的。还是断，按 [常见问题与排查.md](常见问题与排查.md) 里那几条逐一排。

## 六、卸载与重新安装

- **卸载**：在「设置 → 应用」里找到 Battery Guru 点卸载。卸载会一并删掉应用内的历史充电记录与健康曲线。
- **重装**：包名相同、签名相同可以直接覆盖安装，**不需要先卸载**，历史记录会保留。系统提示「应用未安装」说明两份包不是同一把密钥签的，只能先卸载再装。
- **装完核对一次**：在应用信息里看版本号是不是 2.5.0.5；打开主界面，等 1~2 分钟看电量、温度有没有正常刷新，有刷新说明权限都到位了。
