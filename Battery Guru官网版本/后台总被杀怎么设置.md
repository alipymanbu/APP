# Battery Guru 后台总被杀怎么设置

> 本篇处理「数据和提醒时有时无」的根因：按机型把电池优化、自启动、后台加锁三项配对，并用一次熄屏测试验证有没有生效。

监测类应用的数据是「一直记着」才有意义，而它在后台的存活完全由系统的省电策略决定。国内厂商的定制系统在原生 Android 的 Doze 之上又叠了一层更激进的管理，同一台手机装同一个应用，有人曲线连着、有人一段段断，差别多半就在这几项开关上。

## 一、先确认：是不是后台被杀了

不要凭感觉判断，用这三条对照：

| 观察点 | 被系统杀掉的表现 |
| --- | --- |
| 时间轴曲线 | 有整段空白，空白起点就是你熄屏后过一段时间 |
| 状态栏常驻通知 | 不知什么时候消失了，重新打开应用才回来 |
| 再次打开应用 | 出现启动画面、重新加载，而不是直接接上上次的界面 |

三者同时出现，就是进程被回收，不是应用出问题。如果通知一直在、只是个别读数有偏差，那是另一类情况，按 [常见问题与排查.md](常见问题与排查.md) 里对应现象处理。

## 二、通用三步（所有安卓机型都要做）

这三项做完，多数机型就能稳住：

1. **电池优化设为「不优化」**：系统搜索「电池优化」，找到本应用改设为「不允许优化」或「无限制」。
2. **允许自启动与后台活动**：系统搜索「应用启动管理」，关掉本应用的「自动管理」，再手动打开「允许自启动、允许关联启动、允许后台活动」。
3. **多任务界面给卡片加锁**：进入最近任务列表，把这个应用的卡片下拉（或长按）到出现锁定图标，这样一键清理时不会被一起清掉。

## 三、按机型的常见路径

各家把这几项放在不同位置，下面是常见入口（**以你系统当时显示的菜单名为准**，版本更新会调整位置）：

| 机型 / 系统 | 电池优化 | 自启动 | 其他要点 |
| --- | --- | --- | --- |
| 华为 / 荣耀（HarmonyOS） | 设置里搜「电池优化」→ 选所有应用 → 把本应用设为「不允许」 | 设置里搜「应用启动管理」→ 关掉自动管理 → 勾选允许自启动、关联启动、后台活动 | 另开「设置 → 电池 → 更多电池设置 → 休眠时始终保持网络连接」；关闭省电模式 |
| 小米 / 红米（MIUI、HyperOS） | 设置 → 应用 → 应用管理 → 本应用 → 省电策略 → 无限制 | 安全中心 → 自启动 → 打开本应用；或应用详情里的「后台自启动」 | 系统重启后部分设置可能被重置，重启后要复查一次 |
| 三星（One UI） | 设置 → 电池 → 后台使用限制 → 从「已休眠的应用」里移除本应用 | 电池设置里的自启动相关开关 | 关闭「自适应电池」对本应用的影响需单独确认 |
| OPPO / 一加 / realme（ColorOS、OxygenOS） | 设置 → 电池 → 应用耗电管理 → 允许后台运行 | 应用详情里的自启动开关 | 系统自带的「后台冻结」会额外限制，逐个开放 |
| vivo / iQOO（OriginOS、Funtouch） | 设置 → 电池 → 后台耗电管理 → 允许后台高耗电 | 设置 → 应用管理 → 权限管理 → 自启动 → 打开 | 该品牌默认限制最严，自启动必须逐个手动开 |
| 原生 Android / Pixel | 设置 → 应用 → 本应用 → 电池 → 不受限制 | 一般不单独设自启动 | 关闭「自适应电池」的自动限制倾向 |

同一品牌不同系统大版本的位置可能变，路径对不上时按关键词在系统设置里搜「电池优化」「自启动」「后台」三个词，基本都能搜到对应入口。

## 四、两种会反复失效的情况

- **重启后设置被重置**：部分机型在每次开机后会恢复默认的省电策略（小米、vivo 上比较常见）。习惯是重启手机后打开一次应用，确认常驻通知回来了。
- **被第三方管家清掉**：装了清理类、加速类工具时，它们会绕过系统设置直接杀进程。把本应用加进它的清理白名单；加了还杀，就换成系统自带的手机管家。

## 五、验证有没有生效

别靠猜，用一次测试确认：

1. 打开应用，确认状态栏常驻通知在。
2. 熄屏放置 30 分钟，中间不要点亮。
3. 回来打开应用看时间轴：这 30 分钟有连续记录、没有空白，就说明配置生效了。
4. 再重启一次手机，重复第 1 步 —— 通知还在，说明不会被开机重置。

第 3 步的空档如果还在，回到第二节把三项逐个再核一遍，尤其是「允许后台活动」这种被自动管理默认关掉的分项。数据连续之后，告警才会按 [电量和温度告警怎么设置.md](电量和温度告警怎么设置.md) 里设的条件正常触发。
