电池监测类的应用大多是「基础读数免费 + 长期数据收费」的结构，Battery Guru 也是。付费项集中在广告和长周期记录上，不在读数本身。本篇把免费与 Pro 的分界说清楚，省得装完发现想看的东西被锁住。

## 一、免费版能用到哪一步

不付费也能用的部分，基本覆盖日常全部需求：

| 能力 | 免费版 |
| --- | --- |
| 实时电流、电压、功率、温度 | 有 |
| 当前容量、健康百分比 | 有 |
| 充放电告警（充满、低电、温度、异常耗电） | 有 |
| 状态栏常驻通知与图标切换 | 有 |
| 桌面小组件 | 有 |
| 短周期充电与放电记录 | 有 |
| 广告 | 有 |

也就是说，**只是想随时看一眼温度和充电速度，免费版就够**。判断充电器与线材好坏这种一次性排查，也不需要 Pro。

## 二、Pro 多出来的是什么

Pro 的差异集中在这几项：

- **没有广告**：免费版的广告出现在应用界面里，不影响读数，但会占位置。
- **完整的历史记录**：长期曲线、往期充电会话的完整留存。免费版的记录窗口更短，想对比「三个月前这块电池什么样」就需要 Pro。
- **悬浮窗的进阶用法**：更完整的悬浮显示与可自定义项。基础悬浮窗免费版也能用。
- **完整的健康历史**：容量与磨损的长周期趋势，这块数据和上一条的历史记录是绑在一起的。

一句话概括：**Pro 买的是「记得久」和「没有广告」，不是买新的测量能力。**

## 三、官方给的临时 Pro 体验

官方在应用内提供了一种不付费体验 Pro 的方式：看一段激励广告，获得 24 或 48 小时的 Pro 权限，可以反复使用。适合两种人：

- 想买之前先确认完整历史那部分对自己有没有用；
- 偶尔需要翻长期记录（比如二手手机验机时对比电池这些年的衰减）。

具体时长与入口以应用内当时显示的为准，会随版本调整。

## 四、要不要买

按用途分：

| 你的用途 | 建议 |
| --- | --- |
| 只想看当前电量、温度、充电速度 | 免费版足够，不必付费 |
| 想排查充电器和线材 | 免费版足够，一次性用不上长期历史 |
| 需要跟踪几个月到一年的容量衰减 | 值得上 Pro，长期曲线是它的主要价值 |
| 二手手机验机、写报告 | 先用官方的临时 Pro 导出/查看完整历史即可 |

有一类需求它解决不了：付费也换不来「让电池更耐用」。Pro 解锁的是数据留存范围，不会改变充放电行为，判断「衰减是真实的还是读数偏了」的方法在 [电池容量和健康度怎么看.md](电池容量和健康度怎么看.md) 第五节。

## 五、付费前先确认两件事

1. **确认装的是官方包**：付费是在应用内通过官方商店渠道完成的，从非官方渠道装的包往往不支持内购。本文表格里的包请以 [下载与安装教程.md](下载与安装教程.md) 第一节的包名与校验值为准。
2. **确认账号能正常内购**：应用内购买依赖商店账号与所在地的支付方式，环境不齐时会点了没反应。这与应用本身无关。

订阅或一次性购买的形式、价格与退订方式**以应用内购买页面和官方商店页当时显示的为准**，会随地区和版本变化，这里不写死。
