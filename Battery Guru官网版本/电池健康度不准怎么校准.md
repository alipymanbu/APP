安卓的电量百分比是系统按电压曲线和使用记录估出来的，长期不做完整充放，这个估算会逐渐偏移。表现出来就是：显示还有 15% 却突然关机、充到 100% 后掉得特别快、同一次充电的健康度忽高忽低。这时候要做的是让系统重新对齐一次电量刻度，也就是常说的「校准」。

## 一、什么情况该校准

不是定期必做，碰到下面这几种再动手：

| 情况 | 为什么 |
| --- | --- |
| 刚换了新电池 | 旧电池的刻度还在，新电池的实际容量对不上 |
| 二手手机刚到手 | 上一任的使用记录与这块电池的实际状态不一致 |
| 百分比跳电（15% 直接关机、40% 掉到 20%） | 电压曲线与百分比映射偏了，最典型的校准场景 |
| 长时间只做浅充浅放 | 系统缺少完整段落样本，估算模型得不到修正 |
| 充电时百分比长时间卡住不动 | 读数卡死，需要一个完整循环解开 |

反过来说：**读数正常、续航手感也正常时，不必校准**。完整充放本身对电池有轻微损耗，做成日常习惯反而得不偿失。

## 二、完整校准怎么做

下面这套做法是通用的电池刻度重对齐流程，一次一到两轮即可，**不要天天做**：

1. 正常使用，让手机**自己用到关机**，不要提前手动关机 —— 这样系统才能看到低电量的真实电压点。
2. 关机后**静置 30~60 分钟**，让电压稳定下来。
3. 用**可靠的原装或认证充电器**，一次性连续充到 100%，中途不要拔插。充电期间尽量别重负载使用手机。
4. 到 100% 后**再保持插着 30 分钟**，让末端电压充分稳定。
5. 之后正常使用。如果读数还是明显偏，隔几天再做一轮，**最多两轮**就够了。

电池校准这套说法在 iFixit 的维护说明里有正式描述，思路就是「满充保持 + 放空」；现代新机型基本不用做，老机型或换过电池的机型才用得上（以 iFixit 当时的说明为准）。

## 三、校准期间应用这边配合什么

- **保证记录连续**：校准要跨一整个充放周期，中途进程被杀就会断档，前功尽弃。先按 [后台总被杀怎么设置.md](后台总被杀怎么设置.md) 把保活配好。
- **别中途看数据下结论**：第 1 步走到一半时的健康度数值不可信，等整轮走完再看。
- **设计容量要填对**：校准只是修「当前容量」这一侧的偏差，分母（设计容量）填错了照样算不准，见下面第四节。

## 四、校准能修什么、修不了什么

| 问题 | 校准能否解决 |
| --- | --- |
| 百分比跳电、显示与实际不符 | 能解决，这是它的主要用途 |
| 健康百分比波动大 | 通常能收敛，整轮回合让样本变干净 |
| 设计容量读不到 | 不能。要在设置里手动填机型标称容量 |
| 电池实际容量衰减 | 不能。校准是修正读数，不恢复容量 |
| 低温下电量显示不准 | 不能。温度回升后自己会恢复 |
| 电池鼓包、发烫 | 不能，也不该靠软件处理，送修 |

一句话：**校准只重对齐刻度，不改变硬件状态**。校完如果健康度依旧很低、续航依旧短，那说明衰减是真实的，判断方法在 [电池容量和健康度怎么看.md](电池容量和健康度怎么看.md) 第五节。

## 五、设计容量那一半怎么补

校准修的是「当前容量」，健康百分比还要除以设计容量。部分机型固件不上报这个值，需要手动填：

1. 查这块电池的标称容量：手机参数页、厂商官网的机型规格、或电池标签上的 mAh，**认型号查，别按同系列的别的机型猜**。
2. 在应用的容量设置里填入，再走一轮完整充放让它重算。
3. 填错的影响很直接：填大则健康度显示偏低，填小则偏高。拿不准就先留空，只读其余数据。

## 六、校准后怎么判断有没有起效

看两个地方，别看单点数值：

- **跳电现象没了**：故意用到 15% 附近，看是不是平顺下降而不是直接掉到 0。
- **充电曲线变得规整**：从低电量到满电的过程是连续上升，不再长时间卡在某个百分比。

两条都改善，说明刻度对齐生效了。只有一条改善、或者健康度数值变了但跳电照旧，说明问题不在刻度，回到 [常见问题与排查.md](常见问题与排查.md) 第二节里按读数与系统不一致那条继续排。
