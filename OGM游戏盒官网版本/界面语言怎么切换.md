# OGM游戏盒 界面语言怎么切换

> OGM游戏盒自带中英两套界面。本篇只解决一件事：打开以后界面是英文的，怎么切回中文，以及切换后哪些地方会跟着变、哪些不会。

## 一、为什么一打开是英文

这个应用自带中英两套界面，**默认不一定跟着你的手机系统语言走**。所以出现下面这两种情况都算正常，不需要重装：

- 系统是中文，装完打开却是英文界面；
- 一开始是中文，用着用着又变回英文（多见于更新之后）。

两种都按下一节切回来即可。

## 二、切换步骤（四步）

1. 点底部的「我的」（英文界面下是 `Mine` 或 `Profile` 一类的入口）。
2. 在页面里找到齿轮图标，点进「设置」（英文界面下显示 `Setting`）。
3. 在设置列表里找到带「中 / EN」字样的那个按钮 —— 它通常是一个开关或一行切换项。
4. 点它，界面文字立刻变成中文，不用重启应用。

用一张表对照着找，避免在英文界面里迷路：

| 你要找的 | 中文界面下显示 | 英文界面下显示 |
| --- | --- | --- |
| 底部个人页 | 我的 | Mine / Profile |
| 设置入口 | 齿轮图标 + 设置 | 齿轮图标 + Setting |
| 语言开关 | 中 / EN | ZH / EN |

## 三、切换之后哪些会变，哪些不会

| 项目 | 会不会跟着变 |
| --- | --- |
| 底部导航、按钮、菜单这些界面文字 | 会，立刻变 |
| 已下载游戏的名称 | 部分会跟着界面语言变，部分保持原样 |
| 游戏内的语言 | **不会**。那是游戏自己的设置，要在游戏里单独改 |
| 账号、收藏、签到记录 | 不受影响，语言只是显示层的开关 |

所以如果切完中文后，某个游戏的标题还是英文，那是这条资源的陈列名本来就写的英文，不是没切成功。

## 四、找不到那个开关怎么办

按可能性从高到低排查：

- **先看版本**。语言开关是在较新的版本里补上的，如果你装的是很旧的版本，设置里可能根本没有这一项。网盘里这份是 3.1.0，对照 [下载与安装教程.md](下载与安装教程.md) 第一节核一下版本号，装错包就重装。
- **确认进对了页面**。「我的」页面里可能同时有多个入口，设置在最下面或右上角的齿轮里，逐个点开看。
- **界面文字太小看不清**，先把手机系统的显示缩放调大一点再找。

如果版本对、路径也对，但设置里就是没有语言项，用应用内的反馈入口提一下，并写明手机型号和系统版本。
