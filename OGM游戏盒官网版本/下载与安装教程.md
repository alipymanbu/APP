## 一、装之前先对一遍这份包的信息

下表是网盘里那份安装包的实际信息。网上搜到的「最新版」经常已经是另一个版本号，装之前以这张表为准，装完也能拿它核对。

| 项目 | 值 |
| --- | --- |
| 应用名 | OGM游戏盒 |
| 包名 | `cc.oogm` |
| 版本 | 3.1.0 |
| 安装包大小 | 33.28M |
| 安装包 MD5 | `9AC01C65605D2F26903AD81B797D3126` |
| 形态 | 安卓手机应用（APK） |
| 界面语言 | 中文，可在应用内切换为英文 |

三条判断：

- 这个包是安卓的，**iPhone 和 iPad 装不了**。公开渠道也查不到它的 iOS 版本，苹果设备上想用就别在这上面费时间了。
- 官方公开页面没有列出最低安卓版本要求。装的时候如果系统直接提示「不兼容」「无法安装」，就是这台机器装不上，换设备比反复重试有用。
- 33.28M 只是安装包本身。应用内下载游戏会再占空间，手机的可用空间要按「安装包 + 打算下的游戏」一起留。

## 二、从网盘把安装包取到手机

1. 手机浏览器或夸克 App 里打开 [OGM游戏盒 安装文件资源（夸克网盘）](https://pan.quark.cn/s/1eaaad2657f9)。
2. 先点「保存到我的网盘」，再下载。直接下载也能用，但转存到自己网盘后，原分享链接以后失效也不影响你。
3. 等文件下完，记下它存在哪，多数浏览器放在「下载」或 `Download` 目录。
4. 文件名一般形如 `OGM游戏盒_v3.1.0.apk`，以网盘里实际显示的名字为准。

打开链接提示失效或要提取码，说明这条分享已不是当前状态，换最新的那条再试。

## 三、装之前花半分钟校验一下包

安装包从网络传到手机，中途出错的话，装的时候会报「解析包错误」。先校验能省掉后面一堆莫名其妙的排查。

把 APK 拷到电脑上，在文件所在目录执行：

```powershell
certutil -hashfile "OGM游戏盒_v3.1.0.apk" MD5
```

输出的十六进制串去掉空格后，应与第一节表里的 `9AC01C65605D2F26903AD81B797D3126` 完全一致（大小写不敏感）。手机上也可以用带 MD5 校验功能的文件管理器做同样的事。对不上就重新下载一次，别将就着装。

## 四、先去系统里放行「未知来源」

网盘里的包不是从应用商店装的，安卓默认会拦一次。要给下载它的那个应用（浏览器或夸克）开安装权限，各品牌路径不同：

| 品牌 | 大致路径 |
| --- | --- |
| 小米 / 红米 | 设置 → 应用设置 → 应用管理 → 权限管理 → 安装未知应用 |
| 华为 / 荣耀 | 设置 → 安全 → 更多安全设置 → 安装外部来源应用 |
| OPPO / 一加 / realme | 设置 → 安全 → 安装外部来源应用 |
| vivo / iQOO | 设置 → 安全 → 更多安全设置 → 安装未知应用 |
| 三星 | 设置 → 生物识别和安全 → 安装未知应用 |
| 原生安卓 | 设置 → 应用 → 特殊应用权限 → 安装未知应用 |

记不住路径就在设置顶部搜索框里搜「未知应用」或「外部来源」，基本都能跳到同一页。找到负责下载的那个应用，把开关打开。

## 五、安装与第一次打开

1. 从通知栏点刚下完的文件，或打开文件管理器找到那个 `.apk` 点它。
2. 弹出安装界面点「安装」，等进度走完，桌面出现图标。
3. 首次启动会依次弹权限申请。真正影响功能的几项如下：

| 权限 | 不给会怎样 |
| --- | --- |
| 存储 / 照片和视频 | 游戏包下不下来、缓存写不进去 |
| 网络 | 打开后拉不到内容 |
| 安装其他应用 | 游戏下完后点安装会没反应，需要你手动去文件管理器装 |
| 通知 | 只影响下载完成提醒，不影响使用 |

具体弹哪几项、叫什么名字，以你手机上实际弹出的为准。

4. 启动后如果直接要求登录，正常 —— 下载、签到、收藏这些动作都挂在账号上，见 [注册登录与账号设置.md](注册登录与账号设置.md)。
5. 如果界面是英文的，不用重装，在「我的 → 设置」里点一下中/EN 就能换过来，见 [界面语言怎么切换.md](界面语言怎么切换.md)。

## 六、装不上或者装完打不开

按这个顺序自查，比反复重装有效：

- 提示「解析包错误」「应用未安装」→ 回第三节重新校验 MD5，文件多半没下完整。
- 提示「已被阻止安装」→ 第四节的未知来源权限没开，或开了但给错了应用。
- 装好后点图标闪一下退回桌面 → 先确认系统版本是否过旧；仍不行的，到 [常见问题与排查.md](常见问题与排查.md) 第三节按「闪退」一条排查。
- 提示空间不足 → 先清出不小于安装包大小再加余量的空间，安卓安装时还要额外留一点。
- 提示「与已有应用冲突」→ 手机上已有同包名（`cc.oogm`）的另一份，先卸载旧的再装，卸载前确认里面没有想保留的记录。
