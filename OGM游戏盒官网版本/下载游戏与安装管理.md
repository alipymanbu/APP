# OGM游戏盒 下载游戏与安装管理

> OGM游戏盒把游戏的下载与安装都收在应用里完成。本篇讲点下「下载」之后会发生什么：进度在哪看、断了怎么办、装完的游戏去哪找、不玩了怎么清干净。

## 一、从详情页到装上，中间有四步

1. 在详情页点「下载」，任务进入下载队列，页面会切到进度条。
2. 下载可以在后台进行，你退出这个页面去看别的不会中断。
3. 下完后应用会引导你安装，会调起系统的安装界面，点「安装」走完即可。
4. 装完桌面上出现该游戏的图标，之后直接点图标玩，不需要再回游戏盒里点。

第 3 步在有些手机上不会自动跳出来。原因通常是**没给它「安装其他应用」权限**，这时候任务列表里会停在「已下载、待安装」，你可以手动去文件管理器里点那个包，或者去系统设置里把权限补上（路径见 [下载与安装教程.md](下载与安装教程.md) 第五节）。

## 二、下载队列在哪、能同时下几个

下载中的任务在应用里的下载 / 任务列表里看，入口一般在「我的」页面里，也可能在首页顶部。列表里每一条能看到已下大小、总大小和当前速度，长按或点右侧按钮可以暂停、继续、删除。

可以同时挂多个下载任务，但**同时下的任务越多，每个分到的带宽越少**。想快就一次只留一两个，其余排队。

## 三、断了、慢了、失败了

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 进度卡在 0%，几秒不动 | 直连资源没连上 | 等十几秒；还不动就切到流量再试 |
| 下到一半停住 | 网络切换（WiFi 与流量互换）导致连接断了 | 在任务列表里点继续，多数能接着下 |
| 速度很慢 | 同时下的任务太多，或当前网络本身慢 | 减少并行任务数，或换到更快的网络 |
| 反复失败 | 这一条资源本身有问题，或手机空间不够 | 先看剩余空间；空间够就删掉任务重新添加一次 |
| 下完装不上 | 包不完整，或手机上已有同名同包名的版本 | 删掉重下；有旧版本的先卸载旧的 |

断点续传在多数任务上是有效的 —— 同一个任务中途断了，继续的时候从断点接着下，不用从头来。但如果任务被你手动删除，已下部分会一起清掉。

## 四、装完以后：游戏去哪了

- **桌面图标**：安装完成后单独出现在桌面，和游戏盒是两回事。
- **别把游戏盒卸了**：卸掉游戏盒不影响已经装好的游戏，但下次想再下别的游戏就得重新装回来。
- **游戏内更新**：有些游戏的更新要回游戏盒里下新包，遇到「请前往平台更新」的提示就回详情页再下一次。

## 五、不玩了怎么清干净

按这个顺序删，能真正把空间收回来：

1. **先卸载游戏本体**：长按桌面图标卸载，或在系统设置的「应用管理」里找到它卸载。
2. **再清游戏盒自己的缓存**：系统设置 → 应用管理 → OGM游戏盒 → 存储占用 → 清缓存。**注意区分「清缓存」和「清除数据」**：清缓存只删临时文件，清数据会连登录状态、收藏记录一起抹掉。
3. **最后检查安装包残留**：应用下载的安装包有时会留在手机存储里，文件名和游戏名对应，确认游戏已经装好或不再需要再删。

删之前先看一眼剩余空间变化：如果卸载完空间没回来多少，说明大头在游戏本体的数据目录里，手动把那个以游戏名命名的文件夹删掉即可。
