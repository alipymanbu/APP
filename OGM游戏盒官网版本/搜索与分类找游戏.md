## 一、四条找路，按效率排

| 方式 | 入口 | 什么时候用 |
| --- | --- | --- |
| 直接搜名字 | 底部的搜索入口 | 已经知道要玩哪个游戏，最快 |
| 看排行榜 | 游戏库里的排行榜分区 | 只想找个热门的，没具体目标 |
| 按分类翻 | 游戏库里的分类分区 | 想按玩法类型挑，比如模拟、解谜、动作 |
| 首页推荐 | 打开应用的第一屏 | 纯逛，看它今天推了什么 |

四条路的落点都是一样的：进到某个游戏的**详情页**，再从那里下载。下载环节的细节放在 [下载游戏与安装管理.md](下载游戏与安装管理.md)。

## 二、按名字搜：关键词怎么写

搜索框吃的是游戏名关键词，输入后回车或点搜索图标出结果。搜不到的时候，八成不是库里没有，而是词不对，按这个顺序换：

1. **先去掉后缀**。官方名常带副标题或版本词，用主体部分搜，比如带上「手游」「官方版」「最新版」这类尾巴反而搜不到。
2. **中文名搜不到就换英文名**，反过来也一样。同一个游戏在不同渠道的陈列名不统一，两种都试一遍比反复改错别字有用。
3. **别带空格和符号**。名称里本来有的空格、横杠、斜杠都可以先去掉再搜。
4. **只记得一个字的**，先用一两个字搜出候选列表，再在结果里翻。

搜出来的结果列表里能看到图标和名称，点一项就进详情页。

## 三、按分类和排行榜逛

- **分类分区**：按玩法类型划分，进去以后是一列游戏。适合「想玩点什么呢，但说不上来」的时候。
- **排行榜**：按热度排的列表，通常分榜单或类型。它反映的是平台里的下载情况，不代表游戏本身的口碑好坏 —— 值不值得玩还是得看你自己的口味。

这两个列表在页面上是往下拉的，翻页或滚动到底会自动加载更多；加载不出来时先看网络，再看是不是该下拉刷新一次。

## 四、详情页上该看什么

决定下不下之前，这一页有三处信息值得花十秒：

| 位置 | 看什么 |
| --- | --- |
| 名称与版本 | 和你听说的那个游戏是不是同一个，版本是不是你要的 |
| 包体积 | 决定这次下载要不要找 WiFi，几十兆和几个 G 差别很大 |
| 简介与截图 | 确认玩法是不是你想的那种，同名不同游戏在游戏盒里很常见 |
| 评论 | 有则参考，评论少说明这条资源上得比较新 |

同名游戏的坑在这里最集中：搜到一个名字对得上的，不等于就是你要的那个。拿简介和截图对一下才稳。

## 五、搜索出不来结果时

先分清是「搜不到」还是「搜到了点不进去」：

- **完全没结果** → 按第二节换关键词；仍没有就是库里确实没有。
- **有结果但列表一直转圈** → 网络问题，切流量试一次。
- **点进详情页空白** → 这条资源在维护或被下掉了，换另一个同名结果试。
- **搜索框里的历史词删不掉** → 是本地缓存，不影响使用，重开一次应用通常会清掉。

如果你要的游戏搜不到、但确实想反馈，用应用内的反馈入口说明游戏名，比在评论里留言更容易被处理。
