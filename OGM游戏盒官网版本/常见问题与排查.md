## 一、先确认你装的是这个应用

游戏盒类应用同名的很多，装错一个，本篇后面的条目基本都对不上。核这三项就够：

- 包名应为 `cc.oogm`；
- 安装包大小 33.28M，MD5 为 `9AC01C65605D2F26903AD81B797D3126`；
- 网盘里那份的版本号是 3.1.0。

装完之后想核对，在手机「设置 → 应用 → 应用管理」里找到它，进「应用信息」看包名（部分系统要借助第三方应用信息工具）。包名对不上，你装的就是另一个软件。

## 二、安装环节

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 提示「已被阻止安装」 | 系统没给下载它的应用开安装权限 | 见 [下载与安装教程.md](下载与安装教程.md) 第四节，给对的 App 开「安装未知应用」 |
| 提示「解析包错误」 | 安装包没下完整或被动过 | 重新下载一次，再按教程第三节校验 MD5 |
| 提示「应用未安装」「与已有应用冲突」 | 手机上已有同包名的另一个版本 | 先卸载旧的再装，卸载前确认不需要保留里面的记录 |
| 下载时被要求输手机密码 | 系统对非应用商店来源安装做的安全验证，不是应用要的 | 输一次即可；想少弹这一步，在设置里搜「验证」调窄范围，各品牌选项名不同 |
| 装完桌面没图标 | 被归进了应用抽屉，或安装其实没完成 | 去应用抽屉翻一遍；找不到就重装一次 |

## 三、启动与应用本身

| 现象 | 依次做这几步 |
| --- | --- |
| 点图标闪退 | ① 重启手机、清一次应用缓存；② 检查存储空间是否几乎满了；③ 卸载重装网盘里那一版 |
| 卡在启动页不动 | 换成流量 / 另一个 WiFi 再开一次——启动时要联网拉数据；仍不行就清缓存重进 |
| 打开一片空白 | 同上，先换网络；再确认手机时间是否与网络时间一致（时间偏差会让接口校验失败） |
| 用一会儿又要求重新登录 | 到系统设置的应用管理里，把它的省电策略设为「无限制」并允许后台活动 |
| 发热、耗电快 | 挂着下载时属于常态；下完从多任务里划掉，别让它长期驻留后台 |

## 四、账号环节

| 现象 | 处理 |
| --- | --- |
| 收不到验证码 | 查短信拦截名单、核对号码、隔几分钟重试，别连着猛点 |
| 提示「该手机号已注册」 | 改用「登录」进去；密码忘了走登录页的「找回密码」 |
| 绑定手机号失败 | 换网络重试；仍失败就把应用更新一版再绑 |
| 换了手机想用回原账号 | 用原手机号 + 密码登录即可；换号的需求目前只能重注册，详见 [注册登录与账号设置.md](注册登录与账号设置.md) 第四节 |
| 登录后收藏还在不在 | 收藏、签到这类记录挂在账号上，登回同一账号就能看到；本地缓存不跟着走 |

## 五、下载游戏环节

| 现象 | 先做这一步 |
| --- | --- |
| 进度一直 0% | 等十几秒；不动就切网络重试 |
| 下到一半停了 | 在下载任务列表里点「继续」，多数能断点续传 |
| 速度慢 | 先减少同时下载的任务数；再到「我的 → 设置」里找和下载加速有关的开关打开，回列表重试；仍慢就是网络本身的问题 |
| 反复失败 | 看剩余空间是否够；够就删掉任务重新添加 |
| 下完不自动弹安装 | 补「安装其他应用」权限，或去文件管理器手动点那个包 |
| 装完提示「请前往平台更新」 | 回详情页重新下一版安装包 |
| 已装的游戏想更新或卸载 | 在盒子内的游戏管理列表里直接操作，或按 [下载游戏与安装管理.md](下载游戏与安装管理.md) 第五节清理 |

完整的队列管理与清理步骤在 [下载游戏与安装管理.md](下载游戏与安装管理.md)。

## 六、语言与显示

界面是英文，或某处文字显示不全 —— 切语言的方法、切换后哪些会变，都在 [界面语言怎么切换.md](界面语言怎么切换.md)。只想记一句：进「我的 → 设置」，点中/EN 即可，不用重装。

## 七、关于更新和卸载

- **提示更新**：如果应用内弹更新提示，更新后版本多半不再是 3.1.0，那就不是本篇描述的这一版了。想保持在网盘里那一版，就别点更新。
- **卸载**：在系统设置的应用管理里卸载。卸载会清掉它的缓存与本地记录，里面有下好的东西就先确认不再需要。
- **卸载不干净**：卸载完看剩余空间回来多少；少了好几个 G，多半是游戏数据目录没清掉，手动删掉以游戏名命名的文件夹即可。

## 八、还是没解决的

按这个思路缩小范围，比在本篇里反复找条目有效：

1. **分清是个别还是普遍**——换个游戏、换个网络各试一次。换个游戏就好了，那是那条资源的问题，不是你手机的问题。
2. **分清是应用还是系统**——打开手机里另一个同类应用，它也不正常就说明问题在系统或网络。
3. **分清是不是版本问题**——如果你点过更新，先卸载再装回网盘里那一版（3.1.0），看现象是否消失。
4. **确认真的是账号问题**——用同一账号在另一台设备上试；那边正常，问题就在这台设备上。

到这里仍解决不了的，走应用内的客服 / 反馈入口，一次性写清：手机型号、系统版本、应用版本号、具体现象和复现步骤。信息给全了，一次就能定位，比来回问快得多。
