## 一、先确认你要装的是哪一个哈基米

「哈基米」这三个字在网上被好几款不同的东西共用。本套文档对应的这一款，是**北京星之脉科技有限公司**发布的 AI 玩梗社区：打开后是一个以梗话题和圈子为主的社区，带 AI 做梗图的功能。

认它看三个标识就够：

| 核对项 | 本应用 |
| --- | --- |
| 开发商 | 北京星之脉科技有限公司 |
| 安卓包名 | `com.xmax.hajimiai` |
| 官网 | [www.ducduc.fun](https://www.ducduc.fun/zh) |

如果你装完发现打开是一个语音聊天室、或者一个纯粹的 AI 对话工具，那不是这一款，卸载后按上面的标识重新找。同名情况的完整说明见[同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。

| 来源 | 拿到的是什么 | 适合谁 |

## 三、安卓手机上的安装步骤

1. 把下载好的 `哈基米AI_v1.0.1.apk` 放进手机存储，用系统自带的文件管理器找到它。
2. 点它开始安装。首次安装时系统会拦一下，提示「禁止安装未知应用」或「此来源不允许安装应用」。
3. 顺着提示进系统设置，给**当前这个来源**（文件管理器，或你用的浏览器）打开「允许安装应用」的开关，再退回安装页继续。
4. 安装完成后点「打开」。
5. 第一次打开会出现用户协议与隐私政策，同意后才能进入登录页。

第 3 步的开关是**按来源分别授权**的：用浏览器下包就授权浏览器，用文件管理器打开就授权文件管理器，不要给不相关的应用乱开。

## 四、装完先核对是不是同一份包

装好后在系统「设置 → 应用管理 → 哈基米AI」里能看到版本号。想更确定，可以拿它跟安装文件的校验值对一遍：

| 核对项 | 本资源的值 |
| --- | --- |
| 版本号 | 1.0.1 |
| 包名 | `com.xmax.hajimiai` |
| 安装包大小 | 87.82 MB（92,082,314 字节） |
| MD5 | `998c876829038cf9bdabfe59177a9f59` |

包名和版本号在应用信息页直接能看；MD5 需要在电脑上算——把 apk 拷到电脑，用支持校验的工具（如 7-Zip 的属性页、或命令行校验工具）算出 MD5，与上表逐位比对。三个值都对得上，说明文件在下载和转存过程中没有损坏、也没有被换过。

## 五、第一次打开会遇到的两件事

- **协议确认**：首次进入必须先同意用户协议与隐私政策，这是绕不过去的一步。
- **网络**：这是一款社区类应用，动态、圈子、AI 生成都在服务端完成，**离线状态下基本没有可用内容**，只有已缓存的图片能看。装完连上 Wi-Fi 再打开，省得把「加载不出来」误当成装坏了。

## 六、装不上或装完打不开的排查

| 现象 | 先查什么 |
| --- | --- |
| 提示「解析包错误」「应用未安装」 | 安装包没下完整。重新下载一次，再核对第四节的 MD5 |
| 提示「已安装了签名冲突的应用」 | 手机上已经有另一个渠道装的同包名应用。先卸载旧的，再装这一份 |
| 提示「版本号低于已安装版本」 | 手机上装的是更新的版本。想装 1.0.1 就得先卸载当前版本 |
| 安装按钮点了没反应 | 回系统设置确认「允许安装未知应用」那个开关是不是给了正确的来源 |
| 装好点图标闪一下就退 | 先在系统里给它开存储与网络权限；仍然闪退见[常见问题与排查.md](常见问题与排查.md) |
| 打开一直停在启动画面 | 关掉再开一次；仍不行时检查网络，或换一个网络重试 |

卸载重装不影响账号：登录信息在服务端，用同一个手机号登回来，发过的动态和收藏都还在。

## 七、关于系统和机型

官方商店页面写的是手机端（Android 与 iOS）可用。各下载渠道对「最低安卓版本」的写法并不一致，**这类要求会随版本更新变化，以你所用商店页面当时显示的系统要求为准**。手机系统过于老旧时，最直接的办法是先装、看能不能正常打开，不行再考虑换设备或等商店版本。

想在电脑上用，不必装模拟器——官方有网页版 [www.ducduc.fun](https://www.ducduc.fun/zh)，能做的创作类操作见[AI做梗图与二创怎么玩.md](AI做梗图与二创怎么玩.md)。
