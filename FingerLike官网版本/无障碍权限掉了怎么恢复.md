# 无障碍权限掉了怎么恢复

> 安卓端关掉应用后无障碍权限会失效，这是 FingerLike「明明装了却点不动」最常见的原因。本篇讲怎么判断、怎么恢复、怎么少掉几次。

## 一、先确认是不是权限掉了

这几条里中任意一条，基本就是无障碍权限失效了：

- 应用能正常打开、能填次数、能拖出光点，确认之后**屏幕上没有任何点击发生**；
- 关过应用（包括用了「结束运行 / 强行停止」，或系统自己把它清掉）之后再打开，就变成上面那种状态；
- 手机重启过，第一次打开 FingerLike 点击就没反应。

判断办法很直接：进「设置 → 无障碍 → 已安装的服务」，看 **FingerLike** 那一项是开还是关。关着就是它的问题。

## 二、为什么连点器一定要这个权限

FingerLike 要在别的应用上面代替你点屏幕，用的是系统给「无障碍 / 辅助功能」留的那条通道。这条通道的定位就是**代替用户操作界面**，所以它不需要 root、也不需要管理员权限 —— 官方把「无需管理员权限」写在自己的功能特点里。

也正因为这条通道权限很大，安卓不允许应用自己给自己开，必须由你手动去系统设置里点一次。所以它「每次关掉应用就掉」不是 bug，而是这类权限的常规行为。

## 三、恢复步骤

路径和第一次开权限完全一样，照着走一遍即可：

1. 打开「设置 → 无障碍」（部分系统叫「辅助功能」，小米系在「更多设置 → 无障碍」）；
2. 进「已安装的服务 / 已下载的应用」，找到 **FingerLike**；
3. 把开关打开，弹窗里选**允许**；
4. 回到应用，确认状态已恢复，再重新发起任务。

各系统入口叫法不一样，对照这张表找：

| 系统 | 大致路径 |
| --- | --- |
| 原生 Android / 类原生 | 设置 → 无障碍 → 已下载的应用 |
| 小米 / 红米（MIUI、HyperOS） | 设置 → 更多设置 → 无障碍 → 已下载的应用 |
| 华为 / 荣耀 | 设置 → 辅助功能 → 无障碍 → 已安装的服务 |
| OPPO / 一加 / realme | 设置 → 系统设置 → 无障碍 → 已安装的服务 |
| vivo / iQOO | 设置 → 快捷与辅助 → 无障碍 → 已安装的服务 |
| 三星 | 设置 → 辅助功能 → 已安装的应用程序 |

菜单名会随系统版本变化，找不到时直接在设置里搜「无 障碍」或「辅助功能」。

第一步的完整上下文（装包、首次授权、最小验证）见 [下载与安装教程.md](下载与安装教程.md)。

## 四、怎么少掉几次

- **别用「结束运行 / 强行停止」关它**：官方明确写了，安卓端关闭应用后需要重新开启无障碍权限。从最近任务里划掉、在应用详情页点强行停止，都会让权限失效。
- **把电池优化设为不受限制**：在「设置 → 应用 → FingerLike → 电池」里选不受限制 / 允许后台活动，减少系统在后台把它清掉的概率。
- **别用第三方「一键清理 / 加速」工具清后台**：这类工具通常会连无障碍服务一起停掉。
- **重启手机之后，先开权限再发起任务**：重启后无障碍服务需要重新进入已开启状态，顺序别弄反。

权限是开着的却依然点不动，那就不是这一项的问题了，转 [常见问题与排查.md](常见问题与排查.md) 按现象查。
