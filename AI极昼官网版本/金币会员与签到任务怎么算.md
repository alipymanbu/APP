AI极昼 里同时存在好几种和「额度」有关的说法：聊天次数、金币、极钻、VIP 卡。它们不是同一样东西，混着看很容易对不上账。本篇按「分别是什么—从哪来—花在哪」讲一遍，最后说明为什么不同渠道的说法会互相矛盾。

## 一、四种额度分别是什么

| 名称 | 大概是什么 | 从哪来 |
| --- | --- | --- |
| 聊天次数 | 每天能与角色对话的额度 | 签到与做任务免费领 |
| 金币 | 应用内的软性货币 | 签到、任务、参与活动 |
| 极钻 | 应用内的虚拟币，App Store 上以「极钻」打包售卖 | 内购获得 |
| 极昼VIP | 按周 / 月 / 年计的套餐卡 | 内购获得 |

具体每项在当前版本里的名字与入口，以应用内实际显示为准；新旧版本改过命名的情况很常见。

## 二、签到与任务：免费额度从哪来

1. 进「我的」页面，找任务中心或签到入口，点签到。
2. 完成聊天、浏览社区、发布动态这类简单任务，能再拿一次奖励。
3. 连续签到有额外奖励，公开资料里提到连签 7 天会给一份大额礼包。
4. 每日任务按时刷新，第二天可以重新领一遍。

签到奖励到底给的是次数还是金币、每天给多少，各版本调整频繁，以应用内当天显示的数字为准。

## 三、金币花在哪

从公开资料看，金币主要用在三处：

- 解锁限定人设与部分剧情章节；
- 复刻广场上别人公开的人设模板（见 [怎么创建自己的AI角色.md](怎么创建自己的AI角色.md) 第五节）；
- 参与限时活动时的消耗。

反过来，**普通角色的日常聊天通常不需要消耗金币**——这部分有免费额度兜着，签到与任务就够用。

## 四、极钻与 VIP：App Store 上的内购

App Store 详情页挂着内购项，这是 iOS 侧的定价。截至 2026-09 在页面上看到的是这样，价格一定会变，**以你打开时页面上显示的为准**：

| 内购项 | 页面上标注的价格 |
| --- | --- |
| 140 极钻 | ¥2.00 |
| 420 极钻 | ¥6.00 |
| 1260 极钻 | ¥18.00 |
| 2660 极钻 | ¥38.00 |
| 6860 极钻 | ¥98.00 |
| 极昼VIP 周卡 | ¥6.00 |
| 极昼VIP 月卡 | ¥19.00 |
| 极昼VIP 年卡 | 以页面当时显示为准 |

安卓端的内购价格与档位跟 iOS 不一定相同，以应用内购买页显示为准。

## 五、为什么「免费」和「内购」两种说法都在

公开资料里能看到两类说法，互相矛盾：

- 一类说这款应用基础聊天永久免费、不设会员专属；
- 另一类是 App Store 详情页上确实挂着极钻与 VIP 的内购项。

两边都不算错——它们说的不是同一件事：日常聊天走免费额度，而额外的虚拟币与套餐是可选消费。**不替你选边**：想知道自己会碰到哪种，装上之后看应用内购买页与额度页最准。

## 六、想少花钱的四个做法

1. **先把免费额度用满**：签到与任务给的那部分够日常用，先按这个节奏用一段时间再判断要不要买。
2. **只在应用内或官方商店里买**：应用内购买页与 App Store / 安卓应用商店是唯一的正规入口。第三方网站上出现的「极钻充值」「会员卡」没有官方授权，别在那里付款。
3. **看清是买断还是订阅**：VIP 卡按周 / 月 / 年计，属于订阅，续费规则在购买页上有说明。买之前先按第七节把取消入口找一遍，避免忘了取消。
4. **卸载应用不等于取消订阅**：订阅是跟着 Apple ID 或支付渠道走的，把应用删掉之后照样会扣费。要停就按第七节走流程取消。

## 七、自动续费在哪关

VIP 周卡 / 月卡 / 年卡这类按周期计费的套餐，取消入口不在应用里，而在你当初付款的那个渠道：

| 付款渠道 | 取消路径 |
| --- | --- |
| iOS（App Store） | 「设置」→ 点最上方的 Apple ID → 「订阅」→ 找到 AI极昼 → 取消订阅 |
| 微信支付 | 「我」→「服务」→「钱包」→「支付设置」→「扣费服务」→ 找到该项 →「关闭扣费服务」 |
| 支付宝 | 「我的」→「设置」→「支付设置」→「免密支付 / 自动扣款」→ 找到该项 →「关闭服务」 |

三条实务提示：

- **购买后立刻去找一遍取消入口**，确认自己能走通，再决定要不要留着。这一步只花两分钟，事后能省很多事。
- **卸载前先处理订阅**：很多人是删了应用之后才发现还在扣费，扣费记录在支付渠道的账单里能查到。
- **按现行规定，自动续费应当在扣款前显著提醒**（《消费者权益保护法实施条例》2024 年 7 月起施行）。没收到提醒却被扣款、或者取消入口走不通，可以留好订单截图，通过 12315 或全国消协渠道反映。

安卓侧如果走的是各应用商店的内购，取消入口在对应商店的「订阅 / 订单管理」里，路径同 iOS 那一行类似。
