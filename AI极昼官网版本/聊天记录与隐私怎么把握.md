# AI极昼 的聊天记录与隐私怎么把握

> 本篇讲两件事：你和角色的聊天记录存在哪、换手机之后还在不在；以及哪些内容是你主动公开出去的、别人能看到什么。末尾给出权限与年龄两条边界。

这类应用里，聊天记录既是「回忆」也是隐私。哪些存在本地、哪些跟账号走、哪些会被别人看到，三件事容易混。本篇把它们分开讲，再看权限和适用年龄这两条边界。

## 一、聊天记录存在哪

- **本机数据**：应用每次运行都会在手机存储里写一份本地数据，卸载应用会一并清掉。
- **账号数据**：登录后产生的内容与账号绑定。公开资料里提到聊天记录会随账号保存、登录后能看到过去的对话，同时也有资料称存在本地的备份文件。

两种说法并不冲突——本地和账号侧各存一份是常见做法。要确认自己这一份具体怎么存，以应用内隐私政策里写的为准（入口在应用设置或商店详情页的隐私政策链接）。

## 二、换手机、重装之后还在不在

- **换手机**：装同一份安装包（见 [下载与安装教程.md](下载与安装教程.md)），用**原来那个手机号**登录，跟着账号走的内容会回来。
- **换手机号**：账号换了，旧账号里的内容不会跟着新号过来，换号前先想清楚。
- **卸载重装**：本机那份会没，账号侧那份跟着登录回来。公开资料里有「重装登录后完整保留聊天剧情」的说法，但这是单一来源，实际以前后两次登录后看到的内容为准。
- **没有导出入口时**：应用内是否提供聊天记录导出，以当前版本应用内为准；不提供就没法把记录搬到别处，重要内容只能手动截图或复制。

## 三、多设备与同时登录

同一个账号在新旧设备上都登录，内容是否能实时同步，公开资料里的说法不一致。自己这台的实际情况，用「在 A 设备发一句、到 B 设备刷新看有没有」验证一次最快。同时登录会不会把另一边挤下线，也以实测为准。

## 四、你主动公开出去的东西

这是最容易被忽略的一块。自建角色一旦选择公开，下面这些内容就出现在广场与搜索结果里，别人点进来就能读到：

| 内容 | 公开后谁能看到 |
| --- | --- |
| 角色名称、头像、开场语 | 所有用户 |
| 你写的身世背景、性格标签、与你的人物关系 | 所有用户 |
| 你在角色下的评论与互动 | 所有用户 |
| 你和该角色的具体对话 | 只有你自己（对话内容不随人设公开） |

由此有两条建议：**写公开人设时别放真实身份信息**（真实姓名、工作单位、住址、学校、联系方式、照片里可辨认的门牌与工牌），也别把只属于你个人的经历写进去；**评论区里同样别留联系方式**。

只想自己用，就别把角色设为公开，做法见 [怎么创建自己的AI角色.md](怎么创建自己的AI角色.md) 第四节。

## 五、权限：哪些必须给，哪些可以不给

安装后应用会陆续申请几类权限，作用大致如下：

| 权限 | 作用 | 建议 |
| --- | --- | --- |
| 网络 / WLAN | 取角色列表、收发消息 | 必须给，不给就打不开内容 |
| 录音（麦克风） | 语音消息与语音通话 | 用语音就给，不用可以不给 |
| 照片与文件 | 上传头像、保存图片 | 用上传功能时给 |
| 通知 | 角色主动消息、任务提醒 | 想收提醒就给 |
| 振动、防止休眠、前台服务 | 通话与提醒时的辅助 | 按需给 |

商店详情页的权限列表里没有定位类权限，可以在装之前先对一眼。给权限的原则很简单：**用不到的功能对应的权限可以不给**，少掉对应功能而已。

## 六、年龄与内容边界

App Store 上这个应用的年龄分级标的是 **18+**。这一点值得装之前先看一眼，尤其是共用手机、给家里人装的情况——应用里的内容以情感陪伴与恋爱演绎为主，不适合未成年人使用。

## 七、想清干净怎么办

1. **先备份再动手**：确认账号里那份记录还在（换一台设备登录看一眼），再考虑清本机。
2. **清本机数据**：进「设置 → 应用 → 应用管理 → AI极昼」，先试「清除缓存」，这一步只清临时文件、不动账号数据；确实要清干净再用「清除数据」或直接卸载。
3. **云端那份**：注销账号与删除账号数据的渠道写在应用内的隐私政策里，按其中说明的入口申请。
