# qBittorrent Controller 添加磁力链接与种子任务

> 用这个应用加任务有三条路：菜单里粘贴磁力链接或下载地址、从手机里挑一个 `.torrent` 文件、或者在浏览器里直接点种子链接交给它。三条路都是把任务「送」给服务端，之后下载就不归手机管了。本篇讲三条路各自的入口、填写项与常见卡点。
> **相关文档**：[连接服务器怎么设置.md](连接服务器怎么设置.md) · [任务列表与详情怎么用.md](任务列表与详情怎么用.md) · [下载与安装教程.md](下载与安装教程.md)

## 一、三条路各适合什么

| 方式 | 入口 | 适合 |
| --- | --- | --- |
| 粘贴链接 | 菜单里的「添加种子链接」（Add torrent link） | 手上已经有磁力链接或 `.torrent` 的下载地址，直接粘 |
| 选本地种子文件 | 菜单里的「添加种子文件」（Add torrent file） | 种子是从电脑上下好的，已经传进手机；需要存储权限 |
| 从浏览器直接交给它 | 在浏览器里点磁力链接或 `.torrent` 链接，系统问用什么打开时选本应用 | 逛站点时顺手加，不用回应用里粘贴 |

第三条能成立，是因为安装包注册了磁力链接（`magnet:`）与 `.torrent` 的打开方式。一般来说，在系统弹出的「打开方式」里选过一次本应用并勾上「默认」之后，再点种子链接就会直接进来；不同安卓版本对「默认」的处理略有差别，若没生效，就回应用里用前两条方式添加。

## 二、添加时能顺手填的东西

默认情况下，加任务就是粘上链接点确认，一步到底。如果想把保存路径、分类、限速一次定好，先回 `Settings` → 外观，把「保存路径与分类对话框」打开（默认是**关**的）。打开之后再添加，就会多出一个对话框，里面可以：

- 指定这个任务的**保存路径**（是服务端那台机器上的路径，不是你手机里的路径）；
- 指定**分类**，方便之后在抽屉的分类里筛；
- 给这个任务单独设上传 / 下载**限速**（单位 KiB/s）。

保存路径这一项要填服务端上真实存在的目录。手机上看不到那个目录，填错的表现是任务加进去了却立刻报错或停在 0，遇到就回服务端确认路径写法。

顺手设的单任务限速想改回来，不必删掉任务重加：在服务端的 qBittorrent（桌面版或 Web UI）里找到这个任务，把它的下载 / 上传限速清空或改掉，手机端刷新一次就会同步。注意这与 `Options` 里的**全局**限速是两回事，全局那几项见 [连接服务器怎么设置.md](连接服务器怎么设置.md) 第六节。

## 三、加完之后进度是 0，是正常的

磁力链接里没有文件名清单，只有一段哈希。客户端要先靠 DHT、Tracker、其他 Peer 找到做种的人，把元数据取回来，才知道这个任务有哪些文件、多大。这段过程在 qBittorrent 里显示为「正在检索元数据」，在手机上看到的就是：

- 有这一行任务，名字可能是 `[磁力链接]` 之类；
- 大小、进度都是 0 或未知；
- 详情里的文件列表是空的。

**这不是应用的问题。** 判断办法：

1. 等几分钟再刷新一次；
2. 一直停在检索状态，说明暂时没找到能做种的人 —— 冷门资源可能几小时才通，也可能始终通不了；
3. 换一份 `.torrent` 种子文件重新添加。种子文件里本来就带着完整的文件清单，跳过检索这一步，加进去就能开始。

所以同一条资源既给磁力又给种子时，优先用种子文件。

## 四、加错了怎么删

在任务上长按或用菜单，删除有两个不同选项，别点错：

| 选项 | 结果 |
| --- | --- |
| 删除种子（Delete torrent） | 只把任务从列表里去掉；已经下载到服务端的文件仍然留在硬盘上 |
| 删除种子与数据（Delete the torrent and its data） | 任务和已经下载的文件一起去掉，服务端磁盘空间释放 |

两个都会在服务端生效。删之前的确认框里已经写清了哪一种，看清再按。

## 五、RSS 自动下载（可选）

菜单里还有「添加 RSS」。填 RSS 地址之后可以给它起个名字、设一条过滤规则，并勾选两件事：

- **自动下载新种子**：该源里出现新条目时自动加进任务列表；
- **新种子通知**：只是提醒你去看看，不会自己下载。

这两项都依赖手机的「开机自启」权限与后台定时检查，否则手机重启后就不再为你盯着。日常要不要开，取决于你信不信得过那个源的条目。

## 六、几条常见现象

- **提示需要存储权限**：用了「添加种子文件」这条路，但没给读写存储的权限。去系统设置里补上，或改用粘贴链接。
- **提示「种子已发送」**：这只是说请求已经交给服务端了，不代表开始下载。进度要看列表，元数据检索阶段见第三节。
- **添加后服务端列表里没有**：先刷新一次列表；仍然没有，说明请求没到服务端，回 [连接不上与报错排查.md](连接不上与报错排查.md) 对一下报错文案。
- **任务加进去马上又消失**：服务端可能配了分享率限制并选了「删除」，或者任务被排队规则拦下后又被别的动作清理。到 `Options` 里核对排队与分享率那两组设置。
