# qBittorrent Controller 同名应用与官方渠道怎么认

> 名字里带 qBittorrent 的东西至少有两个：一个是电脑上真正下载的桌面客户端 qBittorrent，一个是本文档讲的安卓遥控器 qBittorrent Controller。网上还散着好几个同类遥控应用。本篇讲怎么靠包名把这一款认准、免费版与 PRO 版差在哪、官方渠道去哪找。

## 一、先分清「下载的」和「遥控的」

| 你看到的名字 | 是什么 | 装在哪 |
| --- | --- | --- |
| qBittorrent | 真正干活的 BT 下载客户端，开源，有 Windows / macOS / Linux / FreeBSD 版 | 电脑、NAS |
| qBittorrent Controller（本文档讲的） | 安卓端遥控器，通过 Web UI 管上面那个客户端 | 安卓手机、安卓平板 |
| qBittorrent PRO | 同一个作者发布的付费版安卓遥控器，包名与免费版不同 | 安卓手机、安卓平板 |
| 其他第三方遥控应用 | 名字里常带 qBit / Torrent / Remote 的应用，各自独立开发 | 安卓手机 |

最容易走错的一步：**在手机上搜「qBittorrent 下载」**，结果拿到的是一个遥控器，于是找不到「下载」按钮。遥控器本来就没有下载功能，任务要交给电脑那台机器，见 [连接服务器怎么设置.md](连接服务器怎么设置.md)。

## 二、这一款的身份信息

安卓应用真正认身份的是**包名**，不是桌面上显示的名字。本文档配套的这份安装包：

| 项目 | 值 |
| --- | --- |
| 应用名 | qBittorrent Controller |
| 桌面图标名 | qBController（安装包里显示名与图标名不同，是同一个应用） |
| 开发者 | Luis M. Gallardo D. |
| 包名 | com.lgallardo.qbittorrentclient |
| 版本号 | 4.9.2 |
| 安装包大小 | 2.75 MB（2,885,454 字节） |
| 安装包 MD5 | 844B674215D069B3DB0D5D6D71E0FF74 |

网盘里那份文件名可能只写着 `qbittorrent`，也可能是 `qbcontroller` 之类。**文件名不作数，包名对得上才是同一款。**

## 三、免费版与 PRO 版差在哪

两个版本由同一位作者维护，包名不同，可以同时装在一台手机上：

| 对比项 | 免费版（本文档配套） | PRO 版 |
| --- | --- | --- |
| 包名 | com.lgallardo.qbittorrentclient | com.lgallardo.qbittorrentclientpro |
| 服务器配置槽位 | 只有 `Server 1` 可用 | `Server 1` / `Server 2` / `Server 3` 都可用 |
| 广告 | 界面里有广告位 | 去掉了广告位 |

所以在免费版里点 `Server 2`、`Server 3`，或者看到抽屉里的 `Get Pro`，都是正常现象 —— 那是这一版的边界，不是包残缺。只有一个服务器要连的话，免费版够用。

## 四、官方渠道在哪

- **应用商店条目**：Google Play 上的条目可以直接用包名核对 —— `play.google.com/store/apps/details?id=com.lgallardo.qbittorrentclient`。
- **作者的代码仓库与发布页**：`github.com/lgallard/qBittorrent-Controller`。发布页（Releases）里按版本号列出历史版本，可以对照自己的版本号。
- **应用内的「关于 / 帮助」页**：里面写了版本号、贡献者、许可说明，还给了在线文档入口，是最不用猜的一处。

一件需要知道的事：**这个仓库已经归档（只读），不再接受改动，也没有再发布新版本。** 最后一个版本号就是 4.9.2 这一档，发布于 2021 年初。也就是说本文档配套的这份安装包已经是最新的一版，不是「旧版」；仓库页面上的归档提示不等于应用不能用：它走的仍是 qBittorrent 的 Web API v2，只要服务端版本提供这套接口就能连（服务端版本要求见 [连接服务器怎么设置.md](连接服务器怎么设置.md) 第一节）。

## 五、「官网」与「开源许可」这两项别照抄

- **官网**：公开页面里这一栏经常直接写「暂无」或者指向商店页面不同，光看域名判断不了真假。要判断是不是同一款，用第二节那张表里的**包名 + 版本号 + MD5**。
- **许可**：这一项各处说法不一致 —— 仓库元数据标的是 MIT，应用内「关于」页写的是 GPL v3，源码文件头写的是 LGPL v3。三者互相冲突，所以不要采信任何一个单一口径，也不必把它当作判断真假应用的依据。

## 六、在自己手机上核对

1. 设置 → 应用 → 应用管理，在列表里找 **qBittorrent Controller**（图标名可能是 qBController）；
2. 点进应用信息页看版本号，是否是 `4.9.2`；
3. 包名有的机型直接显示，有的要点开「应用详情」或右上角菜单才看得到，是否是 `com.lgallardo.qbittorrentclient`。

两条都对，说明装的就是本文档配套的这一版。版本号对不上但包名一致，是同一款应用的另一个版本，界面可能略有差别，本文档里对照设置项时以你屏幕上的实际文字为准。

## 七、装错了会怎样

装成 PRO 版、或装成别的第三方遥控应用，最常见的两个后果：一是设置项的名字与位置对不上本文档，二是报错文案不同，排查时对不上号。真遇到界面与本文档明显不一致，先回本节第 6 条核对包名，再决定要不要重装。
