# qBittorrent Controller 任务列表与详情怎么用

> 主界面那张列表是服务端任务的一份视图：抽屉按状态分组筛，长按/菜单对单个或一批任务下指令，点进详情看四个页签。手机上的每一次操作都会实时落到服务端的 qBittorrent 上。本篇讲清每个分组筛什么、每个操作做什么、详情页该看哪一栏。

## 一、抽屉里那几行分别筛什么

左侧抽屉按状态把同一份任务列表切开，切过去只是换个筛选条件，不会改变任务本身：

| 分组 | 筛出来的 |
| --- | --- |
| All | 全部任务 |
| Downloading | 正在下载的 |
| Completed | 已下完的 |
| Seeding | 下完还在继续上传（做种）的 |
| Paused | 被暂停的 |
| Active | 当前有上传或下载流量的 |
| Inactive | 在跑但此刻没有流量的 |

`Active` 与 `Inactive` 最容易被误会：它们看的是**此刻有没有流量**，不是任务好坏。一个正在做种但没人来取的种子就会落在 `Inactive` 里，属于正常。

任务带分类之后，抽屉里还会出现分类相关的行（如 `All`、`Uncategorized` 与你自己建的分类），用法和上面一样，只是换成了按分类筛。

还有一种容易被当成故障的显示：任务一直在「排队」、速度长时间为 0。这是服务端的排队规则在起作用 —— `Options` 里的任务排队限制了同时活动的任务数，超出的任务就停在队列里等。调大上限的做法见 [连接服务器怎么设置.md](连接服务器怎么设置.md) 第六节。

## 二、对一个任务能做什么

在列表里选中任务（长按或点开菜单）后，可用的动作是这些：

| 操作 | 作用 | 什么时候用 |
| --- | --- | --- |
| 暂停 / 继续 | 停止或恢复这个任务的传输 | 临时让出带宽 |
| 强制继续 | 跳过排队规则立刻开始 | 任务排在队列后面、想优先跑它 |
| 删除种子 | 只去掉任务，已下载的文件留着 | 不想再做种，但文件要留 |
| 删除种子与数据 | 任务与文件一起删 | 下错资源了，顺手清磁盘 |
| 强制重新校验 | 重新核对已下载分片与哈希 | 怀疑文件损坏、或从别处拷回来接着下 |
| 优先级 | 提高 / 降低 / 置顶 / 置底 | 队列很长时挑先跑的 |
| 分类 | 设置或删除该任务的分类 | 把同类资源归到一起 |
| 添加 Tracker | 给这个任务补一条 Tracker 地址 | 列表中不动、想加做种者来源 |
| 顺序下载 | 按文件顺序依次下载 | 边下边放、视频预览 |
| 首尾分片优先 | 先下文件的开头与结尾 | 让播放器能先读出头部信息 |

多个任务可以一起选中，批量暂停或批量删除；批量删除时同样要看清是「只删任务」还是「连数据一起删」。

## 三、详情页的四个页签

点开一个任务进详情，里面分四栏：

| 页签 | 看什么 |
| --- | --- |
| 属性（Properties） | 大小、保存路径、进度、分享率、剩余时间、优先级、当前上传/下载速度、做种数、连接数、状态、种子哈希 |
| 文件（Files） | 这个任务包含的文件清单，每个文件可以单独设下载优先级 |
| 服务器（Trackers） | 该任务用到的 Tracker 列表与各自状态 |
| 常规信息（General info） | 创建日期、注释、已用时间、总上传/总下载、浪费量、单任务限速等汇总项 |

「文件」那一栏最实用：一个大包里有几十个文件、你只要其中几个时，把不需要的文件设成「不下载」，其余给「普通 / 高 / 最高」，就能只拉想要的部分。设成「不下载」的文件不会占用服务端磁盘。

「常规信息」里的**浪费量**值得看一眼：它统计的是重复下载、校验失败等白花的流量，数字异常大通常说明任务反复重试或资源本身不稳定。

## 四、排序、搜索与表头

- **排序字段**：名称、大小、剩余时间、优先级、进度、分享率、下载速度，以及按添加时间与完成时间排序；
- **倒序**：配合上面任一项使用，改成正序或反序；
- **搜索框**：只在当前列表里筛，不会去服务端搜资源，也不会改变任务；
- **表头**：「显示速度与合计」默认是开的，列表顶部会带一行上传/下载速度与总量；任务多、屏幕小时可以关掉换更多行。

## 五、外观

- **深色主题**：默认关闭，打开后**需要重启应用**才生效，这是它自己的说明里写明的一点；
- 列表里的图标、颜色只影响显示，不改变任何服务端状态。

## 六、两个容易踩的认知

1. **改的是服务端，不是这台手机。** 在手机上暂停、删除、改限速，电脑上的 qBittorrent 会同步变成这样；反过来你在电脑上改了，手机刷新后也一样。两边不会各记一套。
2. **看不到文件不等于没在下。** 手机只拿到服务端给出的列表与统计，服务端的下载目录、磁盘剩余空间这些，仍然要在那台机器上看。
