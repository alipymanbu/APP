## 一、先接受一件事：没有中文可切

这份安装包内置的语言只有英文以及西班牙语、法语、日语、俄语、葡萄牙语等若干种，**没有简体中文**；设置里也找不到「Language」这一项。所以：

- 不要花时间去找语言开关，找不到是正常的；
- 下面的对照表就是替代方案，按界面位置分组，用的时候直接来这里查。

表里的英文是这一版应用上的原文写法，换一个版本可能有一两个词不同，含义不变。

## 二、左侧抽屉（最常看的一栏）

| 英文 | 含义 |
| --- | --- |
| All | 全部任务 |
| Downloading | 正在下载 |
| Completed | 已下载完成 |
| Seeding | 下完还在上传（做种） |
| Paused | 已暂停 |
| Active | 当前有上传或下载流量 |
| Inactive | 在跑但当前没有流量 |
| Options | 服务端的参数设置 |
| Settings | 本应用的设置 |
| Get Pro | 升级到付费版（免费版才会有） |
| Help | 帮助 / 关于 |

## 三、任务列表上的操作

| 英文 | 含义 |
| --- | --- |
| Add torrent link | 添加种子链接（粘贴磁力链接或下载地址） |
| Add torrent file | 添加种子文件（从手机里选 `.torrent`） |
| Add RSS | 添加 RSS 订阅 |
| Search | 在当前列表里搜索 |
| Pause / Resume | 暂停 / 继续 |
| Force resume | 强制继续（跳过排队立刻开始） |
| Delete torrent | 删除种子（保留已下载的文件） |
| Delete torrent and its data | 删除种子与数据（连文件一起删） |
| Force recheck | 强制重新校验 |
| Priority | 优先级（可提高、降低、置顶、置底） |
| Category | 分类（设置或删除分类） |
| Add tracker | 补一条 Tracker 地址 |
| Sequential download | 顺序下载 |
| First and last pieces | 首尾分片优先 |
| Do not download / Normal / High / Maximum | 文件优先级：不下载 / 普通 / 高 / 最高 |

组里的具体项：

| Data timeout | 数据超时（秒） |

| Use dark theme | 使用深色主题（需重启应用） |
| Show speeds and totals | 列表顶部显示速度与合计 |
| Save path and category dialog | 添加任务时弹出「保存路径与分类」对话框 |

## 五、任务详情页的四个页签

| 英文 | 含义 |
| --- | --- |
| Properties | 属性（大小、路径、进度、分享率、速度等） |
| Files | 文件（可逐个设下载优先级） |
| Trackers | 服务器 / Tracker 列表 |
| General info | 常规信息（哈希、创建日期、总量、浪费量等） |

页签里常见的字段：

| 英文 | 含义 |
| --- | --- |
| Size / Progress / State | 大小 / 进度 / 状态 |
| Save path | 保存路径（服务端上的路径） |
| Download Speed / Upload Speed | 下载速度 / 上传速度 |
| Seeds / Leeches | 做种数 / 下载者数 |
| Ratio / Share Ratio | 分享率 |
| ETA | 预计剩余时间 |
| Priority | 优先级 |
| Category | 分类 |
| Added on / Completed on | 加入时间 / 完成时间 |
| Time Elapsed | 已用时间 |
| Total Downloaded / Total Uploaded | 累计下载 / 累计上传 |
| Total wasted | 累计浪费（重复下载、校验失败等白花的流量） |
| Num. Connections | 当前连接数 |
| Torrent Hash | 种子哈希 |

## 六、报错与提示那几句

界面上弹出来的英文提示，含义与处理办法统一放在另一篇里，不用在这里猜：

- `Torrent sent!`、`Torrent added!` 这类是**操作成功**的回执，不是报错；
- `No torrents found` 是列表为空；
- 真正连不上时的那几句（地址不可达、401、403、证书错误）逐条对照见 [连接不上与报错排查.md](连接不上与报错排查.md) 第一节。

## 七、只记三个词其实就够用

刚开始不用背全表。下面三个词覆盖了八成操作：

- `Settings` —— 所有填地址、改密码、调刷新间隔的事都从这里进；
- `Add torrent link` —— 加任务的主入口；
- `All` —— 迷路时回这里看全部任务。

其余的词在上表里按位置查即可。
