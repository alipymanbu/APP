# qBittorrent Controller 下载与安装教程

> qBittorrent Controller 是安卓端的远程控制客户端，用手机管理运行在电脑或 NAS 上的 qBittorrent 下载任务：看队列、暂停续传、加磁力链接。它本身不下载任何文件，真正的下载在服务端那台机器上跑。本篇讲清装之前要先具备什么、安装包怎么取怎么装、装完第一次打开先做什么。
> **相关文档**：[连接服务器怎么设置.md](连接服务器怎么设置.md) · [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md) · [界面是全英文的怎么对照.md](界面是全英文的怎么对照.md) · [连接不上与报错排查.md](连接不上与报错排查.md)

## 一、先对一下这张表

| 项目 | 这一版的情况 |
| --- | --- |
| 应用名 | qBittorrent Controller（装好后桌面图标显示为 qBController） |
| 开发者 | Luis M. Gallardo D. |
| 版本号 | 4.9.2 |
| 包名 | com.lgallardo.qbittorrentclient |
| 安装包大小 | 2.75 MB（2,885,454 字节） |
| 安装包 MD5 | 844B674215D069B3DB0D5D6D71E0FF74 |
| 适用设备 | 安卓手机 / 安卓平板 |
| 系统要求 | 安装包声明支持 Android 4.0 及以上 |

三件事先说在前面：

1. **版本号、包名、大小以本表为准。** 网上能搜到这款应用的其他版本号与体积，与这里给的往往不是同一份包；冲突时以你手上这个安装包为准，核对方法见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。
2. **网盘里那份文件可能只写着 `qbittorrent`。** 文件名不是判断依据，包名 `com.lgallardo.qbittorrentclient` 对得上就是它。
3. **它替代不了下载器。** 它没有自己的下载引擎，必须有一台长期开着的电脑或 NAS 在跑 qBittorrent，否则装完打开也是空的。

## 二、装之前先准备好服务端

这一步不做，装完也连不上。需要同时具备：

| 条件 | 怎么确认 |
| --- | --- |
| 一台跑着 qBittorrent 的电脑或 NAS | 机器上能正常打开 qBittorrent 主界面 |
| 服务端已打开 Web UI | 工具 → 选项 → Web UI，勾选「Web 用户界面（远程控制）」 |
| 服务端版本能提供 Web API v2 接口 | qBittorrent 4.1 及以后都提供；更老的版本这个应用连不上 |
| 手机和服务端在同一个局域网 | 手机连的 Wi-Fi 与电脑连的路由器是同一台 |

服务端的 Web UI 具体怎么开、账号密码怎么设，见 [连接服务器怎么设置.md](连接服务器怎么设置.md)。想人不在家也能连，见 [在外网连接家里的服务器.md](在外网连接家里的服务器.md)。

## 三、从网盘把安装包取出来

1. 打开 [qBittorrent Controller 安装文件资源（夸克网盘）](https://pan.quark.cn/s/e4b246e6f7a6)。手机、电脑上都能操作，用夸克 App 打开更顺。
2. 点「保存到我的网盘」，把文件转存到自己账号下。转存之后，下载就不再依赖原分享链接是否还在。
3. 取包分两种情况：
   - **直接装到手机上**：在网盘 App 里下载，文件会落到手机的「下载」目录。
   - **先存电脑再传手机**：安卓安装包在电脑上不能双击运行，传过去之后仍然要在手机上点安装。
4. 下完核对两件事：文件名结尾是不是 `.apk`；MD5 是不是 `844B674215D069B3DB0D5D6D71E0FF74`。对不上就删掉重下 —— 安卓装到一半报「解析包错误」，多数是包没下完整或被传坏。

## 四、手机上的安装步骤

这份安装包不是从手机自带软件商店下的，系统会拦一下，属于正常现象。

1. 打开手机「文件管理」，进 `Download`（下载）目录，找到刚下好的安装包，点它。
2. 弹出「不允许安装来自此来源的应用」这类提示时，点提示里的「设置」，打开**允许安装此来源的应用**开关。
   - 部分机型要绕一层：设置 → 应用 → 特殊应用权限 → 安装未知应用，找到你刚才用来打开文件的 App，单独放行。
3. 回到安装界面点「安装」，等进度条走完。
4. 出现「打开 / 完成」时先点「完成」，把权限一次给对再进应用，省得进去之后反复弹窗（见第六节）。

## 五、装完第一次打开会看到什么

1. **主界面是空的。** 会提示你先把 qBittorrent 服务器的设置填上，这是设计如此，不是装坏了。
2. **左侧抽屉是整个应用的主干**，里面按行分成几组：
   - 任务分组：`All`、`Downloading`、`Completed`、`Seeding`、`Paused`、`Active`、`Inactive`；
   - 分类：在开启分类之后才会出现 `Categories` 相关的行；
   - 功能入口：`Options`（服务端参数）、`Settings`（本应用设置）、`Get Pro`、`Help`。
3. **列表里显示 `No torrents found` 不等于连不上** —— 这只说明这个分组下暂时没有任务。真连不上的报错文案是另一套，见 [连接不上与报错排查.md](连接不上与报错排查.md) 第一节。
4. **先去填服务器。** 抽屉 → `Settings` → 账户，把主机、用户名、密码、端口填上，逐项说明见 [连接服务器怎么设置.md](连接服务器怎么设置.md)。

## 六、权限给哪几个，各自为什么

安装时或首次使用时，系统会按需索要下面这些权限。给全了才不会中途卡住：

| 权限 | 这个应用拿它做什么 |
| --- | --- |
| 网络访问 / 网络状态 / Wi-Fi 状态 | 连服务端的 Web UI；判断当前连的是哪个 Wi-Fi，用于「本地网络」那组地址切换 |
| 读取与写入存储 | 用「添加种子文件」时读手机里的 `.torrent`；也用于把种子文件发出去 |
| 开机自启 | 重启手机后继续做「下载完成提醒」的后台定时检查，不给你通知就说明这一项被拦了 |

存储权限被拒时，用「添加种子文件」这条路会直接提示需要存储权限；改用粘贴磁力链接的方式不受影响，见 [添加磁力链接与种子任务.md](添加磁力链接与种子任务.md)。

## 七、装不上时先看这几处

- 提示「解析包错误」→ 包没下完整，回网盘重下并用 MD5 核对。
- 提示「应用未安装」→ 设备上可能有同包名的旧版且签名不一致，先卸载旧版再装。
- 提示「系统版本过低」→ 这台设备的安卓版本低于 Android 4.0，换设备。
- 点安装包完全没反应 → 打开安装包的那个 App 没拿到「安装未知应用」权限，见第四节第 2 步。
- 装好了但一直连不上 → 不是安装问题，按 [连接不上与报错排查.md](连接不上与报错排查.md) 从第一节的报错对照表查起。
