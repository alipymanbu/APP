DNF助手最有用的部分，是把游戏里查起来费劲的数据搬到手机上：绑定角色后，不上号也能看装备、名望值和战绩。这篇按「先绑定、再看数、最后对比」的顺序讲清楚每个入口在哪、每项数据是什么。只想知道怎么绑定的话，看第二节即可。

## 为什么必须先绑定角色

助手里的资讯、社区不登录游戏账号也能看，但角色卡、装备、名望值这些属于你的个人数据，要先绑定对应区服的角色才会显示。绑定的是「哪个区服的哪个角色」，同一个账号在不同区的角色需要分别绑。

## 绑定角色的步骤

1. 打开 DNF助手，点右下角「我的」。
2. 在个人中心找到「端游角色」或「手游角色」，点「绑定角色」。
3. 选择要绑定的游戏账号，再选区服和角色。
4. 核对角色信息无误后，点「确认完成」。
5. 端游与手游是分开绑定的，两边都要看就各绑一次。

部分版本支持在同一个助手账号下绑定多个游戏账号的角色，绑定后可以一键切换查看。

## 角色卡里能看什么

绑定完成后，在「我的」页面点角色卡，进入角色详情页：

| 数据 | 说明 |
| --- | --- |
| 装扮形象 | 角色的时装外观预览 |
| 装备列表 | 当前穿戴的装备，点单件可看强化、附魔等详情 |
| 强化 / 增幅 | 各部位的打造等级 |
| 附魔 / 徽章 | 打造细节 |
| 名望值 | 综合数值，通常越高代表打造越好 |
| 抗魔值 | 与副本准入相关的数值 |
| 战绩 / 周报 | 近期的游戏表现统计 |

这里显示的都是你账号自己的数据，助手只负责展示，改动不了游戏内的数值。

## 名望值排行榜怎么看

1. 在「我的」页面点击角色下方的名望值，进入名望值详情。
2. 点右侧的「已超过玩家」，进入名望值排行榜。
3. 默认展示全服排名；点右上角的区服切换选项，可以只看自己所在的区服。

排行榜反映的是某一时刻的统计，别人的数值随时会变，过一阵刷新结果就不同了。

## 数据多久刷新一次

角色数据的同步有明显延迟，不是实时的：

- 刚在游戏里换了装备或提升了打造，助手上一般要等几分钟（常见说法约 5 分钟）才更新。
- 进副本后看到的面板数值可能偏高，助手不跟随这种临时变化，仍显示原本的数值。
- 新增的装备或系统，可能要等助手版本更新后才会纳入计算。

数据一直不更新时的排查见[常见问题与排查.md](常见问题与排查.md)；想看一周的表现汇总，见[周报与战绩怎么看.md](周报与战绩怎么看.md)。
