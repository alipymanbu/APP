# 常见问题与排查

> 角色数据不更新、装备不显示、助手闪退或登录白屏、周报空白，这些高频问题按顺序排查，大多能自己解决。

这篇把 DNF助手 最常见的几类问题集中起来，按「先判断是不是正常现象，再做操作」的顺序排。多数情况并不是应用坏了，而是同步延迟或授权没开。逐类往下看，先试最省事的那一步，不行再往下加码。

## 角色信息、战力不更新

先分清三种情况，多数不用处理：

| 情况 | 原因 | 处理 |
| --- | --- | --- |
| 刚换装备立刻看助手 | 数据同步有延迟 | 等几分钟再刷新 |
| 进图后面板数值偏高 | 助手不跟随临时的进图面板 | 等同步，或参考正常的站街面板 |
| 新装备、新系统查不到 | 尚未纳入计算 | 等助手版本更新 |

等过一轮还是老数据，再按顺序试：下拉刷新角色页 → 退出重登 → 清除缓存后重开。

## 装备不显示

按成本从低到高试：

1. 切换网络，Wi-Fi 与移动数据互切一次，然后退出重进。
2. 退出当前账号重新登录。长时间不登录后授权可能已失效。
3. 清除应用缓存后重开。
4. 前面都不行，卸载后重新安装，再绑定角色。

## 周报或角色数据是空的

- 页面上若有刷新按钮，先点一次刷新。
- 本周刚开始时数据本来就少，属正常。
- 确认绑定的角色是不是你想看的那个，端游和手游要分别绑。

具体到周报的板块含义与分享入口，见[周报与战绩怎么看.md](周报与战绩怎么看.md)。

## 登录白屏、闪退或卡顿

1. 清除应用缓存（设置 → 应用管理 → DNF助手 → 清除缓存）后重开。
2. 重启手机。
3. 更新到最新版本再试。
4. 仍然白屏时，换一个网络环境登录。

## 装不上、提示解析包错误

这类问题属于安装环节，完整排查见[下载与安装教程.md](下载与安装教程.md)里「装不上或打不开怎么办」一节，重点看三处：文件是否完整（对一下包名与 MD5）、纯净模式是否关闭、存储空间是否足够。

## 找不到某个功能

- 功能入口会随版本调整，先确认你装的是不是较新的版本。
- 「我的」和「设置」这两个入口基本固定，先在它们里找；活动类功能多在首页或侧边菜单。
- 有些功能只在绑定角色后才会出现，比如角色卡、周报，绑定方法见[绑定角色与查看装备战力.md](绑定角色与查看装备战力.md)。
