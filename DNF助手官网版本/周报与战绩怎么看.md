# 周报与战绩怎么看

> 周报把一周的输出、副本进度和资源获取汇总成一页，适合回顾这一周干了什么、和上周比有没有变化。

周报是 DNF助手把角色一周的游戏记录整理出的汇总页，内容包括伤害统计、副本通关记录和资源获取情况，并支持和历史数据对比。这篇讲周报从哪里打开、每一块在说什么、数据空白或分享按钮找不到时怎么处理。

## 从哪里打开周报

1. 点右下角「我的」，进入角色信息界面。
2. 点角色卡进入角色详情页。
3. 找到「周报」入口，点开查看。

端游与手游角色的周报分别挂在各自绑定的角色下，先切换角色再看。

## 周报里都有什么

| 板块 | 能看到什么 |
| --- | --- |
| 伤害统计 | 本周的输出表现 |
| 副本记录 | 本周通关了哪些地下城与团本 |
| 资源获取 | 本周获得的材料、道具等 |
| 历史对比 | 与之前的数据对比，看战力有没有变化 |

周报关注的是趋势而不是某一刻的精确数值，用来判断这一周有没有白打比较直观。

## 分享周报

想把周报发出去时，分享按钮不一定在第一屏：

- 较旧的周报页要往下翻，看右下角显示所在页码，翻到最后一页才会出现「立即分享」。
- 较新的版本可能在页面顶部或右上角直接给分享入口。
- 找不到就完整翻一遍页面，入口一般在内容末尾。

## 数据是空的或没更新

- 个人用户看到数据不显示时，页面上一般有刷新按钮，点一下重新拉取。
- 刚打完副本就立刻看周报，通常要等同步完成，隔几分钟再看。
- 周报按周统计，本周刚开始时数据少属正常。

周报里的数字与游戏内对不上时，先判断是不是同步延迟；排除延迟后仍对不上，可按[常见问题与排查.md](常见问题与排查.md)里的顺序排查。周报的分享动作本身也算编年任务，想顺带攒经验见[编年有礼与每日签到.md](编年有礼与每日签到.md)。
