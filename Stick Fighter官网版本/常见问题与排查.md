## 一、装不上、点开就退

这一类基本跟设备环境有关，先用包信息对一次胃口：版本 7.1.1、包名 `com.tweber.stickfighter.activities`、大小 2.06 MB。

| 现象 | 排查顺序 |
| --- | --- |
| 提示「解析包错误」 | 1）文件没下完 → 删掉重下；2）下到的是半成品 → 重下后核对大小；3）系统版本低于包内要求（标注 Android 5.2 及以上） |
| 提示「应用未安装」 | 手机里已有签名不同的同包名版本，先卸载旧的再装 |
| 点安装没有任何反应 | 「安装未知应用」权限没给当前文件管理器，或被安全类应用拦了安装行为 |
| 装好点开一闪就退 | 系统版本过低；或安装中权限被中断，卸载后重装一次 |

取包与授权的完整步骤见 [下载与安装教程.md](下载与安装教程.md)。

## 二、新建与素材

- **点「+」进不了编辑页** → 标题没填或填了不合适的字符，把标题换成普通文字再创建；
- **素材库空着或加载不出来** → 退出编辑页重新进一次；仍不行就重启应用；
- **放了角色却拖不动** → 角色没被选中。先点一下角色，等关节点显示出来再拖；
- **武器不跟手** → 武器没和手部关节合在一起，重新把它放到手上（见 [素材库与角色形状怎么调.md](素材库与角色形状怎么调.md)）。

## 三、摆帧与预览

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 翻页后角色回到初始姿势 | 每一页是独立摆的 | 属正常，翻页后重新摆姿势 |
| 预览时动作一跳一跳 | 页数太少，或两页差别太大 | 补中间页，或用补帧功能（见 [关键帧与自动补帧怎么用.md](关键帧与自动补帧怎么用.md)） |
| 补帧后画面更怪 | 两页之间变化太大 | 删掉过渡页，改手动摆中间帧 |
| 改了速度却没变化 | 改的不是播放速度那一项 | 回设置里确认改的是速度/帧率项，再预览 |

## 四、导出与文件

- **导出像卡住不动** → 页数多时本来就慢；长时间无变化就退出重导，导的时候别切后台；
- **导出后找不到文件** → 用文件管理器按修改时间排序找最新的视频，或搜导出时的文件名；
- **导出后和预览不一样** → 有页没保存，或画布没调好，回编辑页核对后重导。

更多导出细节见 [导出视频与作品导入.md](导出视频与作品导入.md)。

## 五、兼容与设备

- **换手机后作品不见了** → 应用内的工程不一定随账号同步，重要作品要导出视频、工程单独备份；
- **系统版本太老装不上** → 这份包标注要求 Android 5.2 及以上，低于这个版本会装不上或闪退；
- **免费版有广告** → 免费版本带广告位，另有付费去广告版本，功能本身不受影响；
- **播放卡、操作延迟** → 页数与素材多时对设备有压力，导出时尤其明显；先关掉别的后台应用。

如果确认操作没问题、现象却反复出现，可以用 [Stick Fighter 安装文件资源（夸克网盘）](https://pan.quark.cn/s/a34056077463) 里的包卸载重装一次，再按上面的分类排查。
