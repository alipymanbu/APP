# JoiPlay 提示缺少运行包（RTP）怎么补

> 本篇讲什么情况下游戏会向你要运行包、RPG Maker 各版本分别对应哪个文件、怎么导入，以及导入失败时的处理。

运行包（RTP）是 RPG Maker 官方的共享素材包。老版本的 RPG Maker 游戏可以把图形、音乐当成公共素材而不打进游戏本体，发布包因此小很多；代价是你的机器上得有一份对应的 RTP。所以启动 RPG Maker 老游戏时弹出「需要运行包」，不是你装错了什么，是还缺这一份。

## 一、先判断是不是真缺 RTP

出现下面这两种现象之一，才需要处理运行包：

- 游戏加进列表、启动后弹出选择运行包的提示框，让你指定一个文件；
- 游戏能进到画面，但提示缺素材、人物与地图一片空白。

如果是「提示缺插件」或者直接黑屏，那是另外两条路 —— 缺插件看 [插件怎么装与哪个引擎配哪个.md](插件怎么装与哪个引擎配哪个.md)，黑屏看 [游戏打不开与报错排查.md](游戏打不开与报错排查.md)。**RTP 解决的是「缺素材」这一类问题，脚本错误、加密素材读不出来不在它的射程内。**

另外两类游戏不需要 RTP：RPG Maker MV 与 MZ 的游戏（素材走 HTML 那套，打包方式和老版本不同），以及素材已经打进游戏本体的老 RPG Maker 游戏。后者在公开的发布包里占多数，所以这个提示并不是每次都会出现 —— 弹了才装。

## 二、按引擎版本下对应的那一个

RTP 要跟游戏使用的 RPG Maker 版本对上，下错版本导入也会失败。三个文件名是不同的：

| 游戏引擎 | 要下的 RTP 文件 | 从哪下 |
| --- | --- | --- |
| RPG Maker XP | `xp_rtp104e.exe` | RPG Maker 官方运行包页面 |
| RPG Maker VX | `vx_rtp102e.zip` | 同上 |
| RPG Maker VX Ace | `RPGVXAce_RTP.zip` | 同上 |

官方运行包页面在 [www.rpgmakerweb.com/run-time-package](https://www.rpgmakerweb.com/run-time-package)，页面里按 VX Ace、VX、XP 分了标签，点开对应标签就能拿到下载链接，文件名与上表一致（**具体文件名与链接以官方页面当页为准**，这里只是帮你认哪个是哪个）。

游戏属于哪个版本看不出来时，看游戏目录里的 DLL 名字：`RGSS102E.dll` / `RGSS103E.dll` 是 XP，`RGSS202E.dll` 是 VX，`RGSS300.dll` / `RGSS301.dll` 是 VX Ace。完整对照见 [插件怎么装与哪个引擎配哪个.md](插件怎么装与哪个引擎配哪个.md) 第三节。

## 三、两种导入方式

**方式一：顺着游戏弹出的提示走。** 启动游戏时弹出选择文件的界面，点「选择」（Choose），在手机存储里找到刚下载的那个 RTP 文件并选中，剩下的解压与安装由主程序自己做，等它跑完。

**方式二：在主程序里手动添加。** 右上角菜单 → 设置，找到运行包（Runtime Package）这一类选项：

1. 点添加运行包；
2. 弹出选择界面后指向你下载的 RTP 文件；
3. 界面若要求授权存储访问，点允许；
4. 等提示跑完，把游戏完全关掉重新启动。

有的版本让你直接选下载到的压缩包，有的版本让你先解压、再指向解压出来的目录 —— 两种描述都对，取决于主程序版本，**按界面上给的提示做**，两种都试一次也不算折腾。

## 四、导入成功的标志与失败的处理

成功时会看到类似 `Runtime Package extracted successfully` 的提示。这时要把游戏完全关掉再重开（不是重启手机），新导入的素材才会被用上。

导入失败最常见的三个原因，按顺序排除：

| 现象 | 处理 |
| --- | --- |
| 提示无法解压运行包 | 选的不是下载到的原始文件。如果之前自己手动解压过一层，删掉重来，直接选那个 `.zip` 或 `.exe` 原件 |
| 选对了文件仍然报错 | 文件下载不完整，删掉重新下载。用手机浏览器下载大文件中断很常见，也可以在电脑上下好再传进手机 |
| 提示运行包不对 / 装完仍然缺素材 | RTP 版本与游戏版本没对上。回去看第二节的表，确认游戏是 XP、VX 还是 VX Ace |

如果之前装过一个运行包、怀疑它装坏了，可以在运行包相关的设置里先清空（有的版本叫清除运行包），再重新导入一份干净的。同一台手机上，同一个版本的 RTP 只需要一份，多个 RPG Maker VX Ace 游戏共用它。

## 五、把 RTP 文件留好

RTP 文件建议一直留在手机里，别导入完就删：换手机、重装主程序、或者以后又加了一个依赖 RTP 的游戏，都要用它。把它和游戏放在同一个自建目录（例如 `内部存储/JoiPlayGames/_RTP/`）里，比散在下载目录里好找。
