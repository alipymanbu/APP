PC 游戏本来是给键盘鼠标做的，搬到手机上之后，能不能玩下去主要看虚拟按键摆得顺不顺手。这里最省事的做法不是「调成最好看的样子」，而是照着这款游戏在电脑上的默认键位摆 —— 游戏里的教学提示、攻略里写的按键，都对应那套默认值。

## 一、照着游戏在电脑上的默认键位摆

不同引擎的游戏，默认键位不一样，先认清你要对付的是哪一套：

| 引擎 | 电脑版的常用默认键 | 手机上要保证能按到 |
| --- | --- | --- |
| RPG Maker XP / VX / VX Ace | `Z` 或回车为确定、`X` 或 Esc 为取消与菜单、方向键移动、`Shift` 为跑步 | 方向键、确定、取消/菜单，最好再给一个跑步键 |
| Ren'Py | 空格与回车推进、`Ctrl` 跳过已读、`Esc` 打开游戏菜单、`Tab` 切换跳过 | 一个「推进」键（两个更顺手）、菜单键、跳过键 |
| RPG Maker MV / MZ | 与老版本大致相同，方向键加确定键是核心 | 方向键、确定、取消 |
| HTML5 / TyranoBuilder | 主要靠点击，少量键盘操作 | 位置放一个点击键即可，多数时候直接点屏幕 |

摆键位在游戏运行时调：把按键布局调出来（界面里一般是一个编辑或布局的入口），方向键放到左手拇指够得到的位置，确定键放右手边，确定与取消别挨太近 —— 手机上误触取消、把菜单按出来是最影响体验的两种小事故。

摆完之后**在游戏里实际走两步**验证一下，很多游戏的前几屏就要用方向键加确定键，正好用来试。

## 二、外接手柄

蓝牙手柄连上系统之后，多数游戏能直接读到，不用额外设置；个别游戏要在它自己的设置里把输入方式切过去。手机手柄尤其适合 RPG Maker 这类长时间跑图、方向键按得多的游戏，能明显减少虚拟按键的误触。

手柄认不到时按这两步看：先在系统的蓝牙设置里确认已连接（而不是只配对没连上），再回到游戏里退出重进一次。手柄与虚拟按键可以同时存在，不冲突 —— 想用虚拟按键按菜单、用手柄走路这种混搭也行。

## 三、每个游戏都有自己的设置

游戏列表里每个游戏条目都有自己的设置，改它只影响这一个游戏。这一点很重要：某个游戏需要换个引擎类型或渲染方式才能进，**不要动全局设置**，只改这一个游戏。全局设置改了，本来正常的其他游戏反而可能出问题。

那个游戏自己的设置里常见这几类项：

| 设置类别 | 什么情况下要动 |
| --- | --- |
| 引擎类型 | 同一个游戏用默认引擎进不去、黑屏，换成另一个可选项再试 |
| 渲染方式 | 画面显示异常、有声音没画面时，换一个渲染选项试 |
| 运行包（RTP） | 游戏提示缺素材时，在这里加运行包，见 [RTP运行库缺失怎么补.md](RTP运行库缺失怎么补.md) |
| 按键布局 | 照第一节调，每个游戏的键位需求不一样 |

## 四、卡顿与画面问题的调整方向

按从省事的到麻烦的顺序试：

1. **关掉省电模式**，有性能模式或游戏加速的打开它。省电模式压着 CPU 频率，跑游戏会一顿一顿；
2. **清掉后台应用**，尤其是同时在跑的大应用；
3. **打开目录缓存**。这个选项能改善游戏读取文件的速度，公开的排查记录里把它列在解决卡顿的头几条；
4. **降低游戏内的分辨率或画质选项**，有些游戏自己在设置里提供；
5. **换渲染选项**试一轮（放在该游戏自己的设置里）；
6. 换完了还是卡，那就是这款游戏在这台设备上的实际表现了 —— 屏幕大、分辨率高的手机跑老 RPG Maker 游戏，未必比小屏机流畅。

画面显示不对还有几种情况要分清：黑屏但有声音，优先怀疑渲染方式；贴图错位、字变成方框，多为字体或素材问题，可以试着在插件的字体设置里指定一个字体文件；画面被拉伸变形，找全屏与显示比例的选项调。

## 五、改完不生效怎么办

设置类的改动大多要**重新启动游戏**才生效，改完退出游戏再进，比在运行中反复切换可靠。在游戏自己的设置里改、不要动全局设置，这一条在任何一次调整里都适用。

按键摆好了、游戏也能正常进，接下来最容易被忽略的是存档 —— 存不上、换机搬不过去都属于可以提前处理的事，见 [存档位置与备份怎么弄.md](存档位置与备份怎么弄.md)。
