游戏起不来的时候，人第一反应是「重装一遍」，而实际问题常常在游戏文件本身、插件权限或者少装的一个运行包上。下面这份顺序是有意排的：从改动成本最低、最容易验证的一步开始，避免东改一处西改一处，最后连原来哪里是对的都不知道了。

## 一、固定的排查顺序

1. **看游戏文件**：解压是否完整、入口文件是不是选对了。压缩包解压中断、分卷缺卷、多套了一层目录，都会以各种报错的形式出现，而它们跟设置无关；
2. **看插件**：这个引擎的插件装了吗、装的是不是对的那支（Ren'Py 尤其容易装错分支）；
3. **看权限**：主程序的「所有文件访问」「读取已安装应用列表」，以及插件自己的「所有文件访问」；
4. **看运行包**：RPG Maker 老版本做的游戏经常需要额外补一个 RTP，缺了就跑不起来；
5. **看版本**：主程序与插件都升到官方下载页当时的最新版，两边版本差太多会互相认不出；
6. **最后才怀疑设备**：设置里换个引擎类型或渲染选项试试，仍有问题再判断是不是这款游戏本来就不兼容。

## 二、报错对照表

| 报错 / 现象 | 大概率原因 | 怎么处理 |
| --- | --- | --- |
| 提示找不到 RPG Maker 插件，但你确实装了 | 主程序没有「读取已安装应用列表」的权限（小米 MIUI / HyperOS 默认不给）；或主程序与插件版本差太多 | 给主程序开「读取已安装应用列表」并设为始终允许（HyperOS 还要进「其他权限」确认），完全关掉主程序再开；两边都升到最新版；仍不行就卸载插件重装 |
| 提示需要 RPG Maker Plugin / `You need RPG Maker Plugin` | 这个引擎的插件没装，或者装的是给别的引擎用的插件 | 认引擎、装对应的那一个，见 [插件怎么装与哪个引擎配哪个.md](插件怎么装与哪个引擎配哪个.md) |
| 检查插件配置时报错 | 插件缺「所有文件访问」，或缺「照片和视频」「音乐和音频」权限 | 在系统设置里把这几项都给 RPG Maker 插件开上 |
| 无法解压运行包 | 选的不是下载到的那个 RTP 原始文件（自己先解压过一层），或文件本身下坏了 | 用下载到的那个 `.zip` / `.exe` 原件去选，不要先自己解压；仍报错就重新下载 |
| 提示设备是 Android 11 或更高 | 只是提醒性能可能受影响 | 直接忽略，这条不是错误 |
| 无法访问游戏文件 | 游戏文件夹被移动或删除；存在存储卡上而卡没被识别 | 用文件管理器确认路径还在；把游戏挪到内部存储再试 |
| 弹出 `解決?` 或 `解?` | 错误来自主程序一侧，报错信息本身给不出细节 | 重新解压游戏再试；把主程序与插件升到最新；都做过还这样，基本是这款游戏与工具不兼容 |
| `No game scripts specified (missing Game.ini?)` | 游戏目录里的 `Game.ini` 丢了 | 重新解压一次；确认发布包里本来就没有这个文件时，可以自己补一个（见下） |
| `Failed to read script data` | `Game.rgssad` / `Game.rgss2a` / `Game.rgss3a` 丢了，或游戏用了特殊加密方式 | 重新解压；文件确实在还报这个错，说明加密方式不被支持，没有别的办法 |
| `Script error` | 游戏脚本与这个工具不兼容，或者 PC 版本本身就有这个 bug | 这类错误要去问游戏的作者，换插件、重装都解决不了 |
| `Read-only file system` | 游戏目录被系统当成只读，写不进存档 | 按「存不上档」那一行处理 |
| 存档存不上，或重启后看不到存档 | 缺「所有文件访问」权限；游戏放在 `Android`、`Download` 这类受限目录；或存在存储卡上 | 给主程序与 RPG Maker 插件开「所有文件访问」；把游戏挪到自建目录（如 `内部存储/JoiPlayGames/`）；从存储卡挪回内部存储 |
| 游戏素材图出现在手机相册里 | 系统把游戏目录当成图片库扫描 | 在游戏目录（或游戏总目录）里建两个空文件，分别命名为 `.nomedia` 和 `.nosearch`。多数文件管理器默认不显示点号开头的文件，建成功一次即可 |
| `The webpage at … could not be loaded` | 游戏目录里 `index.html` 或 `www` 目录缺失；开着 VPN 或私有 DNS；系统 WebView 版本过旧 | 重新解压；关掉 VPN 与私有 DNS；更新「Android System WebView」；最后手段是在设置里把 HTML Settings 的 `Use HTTP Server` 关掉（可能让别的游戏反而出错） |
| `Your browser does not support WebGL` | HTML 系游戏的 WebGL 开关没开 | 进右上角菜单 → 设置 → HTML Settings，打开 WebGL 选项 |
| `Loading Error (Failed to load)` / 文件找不到 | 游戏的资源文件没解压全 | 重新下载、重新解压；反复出现就去找游戏作者确认发布包是否完整 |
| `require is not defined` | 游戏脚本用了 Node.js 专有功能，安卓端没有这个环境 | 换插件、重装都不解决，这款游戏在这条路上跑不通 |
| 一直黑屏 | 可能是启动慢，也可能是插件配置、游戏文件、运行包、渲染方式中的任一环 | 先多等一会儿（老设备初始化更慢）；再按第一节那个顺序，从游戏文件、插件、权限一路过到运行包；最后在该游戏自己的设置里换一下引擎类型或渲染选项 |
| 黑屏但有声音 | 游戏其实在运行，只是画面没渲染出来 | 优先怀疑设备与渲染方式的兼容性，换渲染选项试，别在游戏文件上反复重下 |
| 高配手机也卡 | 省电模式压着频率、后台程序抢占资源 | 玩之前关掉省电模式、开性能模式（部分机型叫游戏加速），清掉后台应用 |
| 安装时提示「应用未安装」 | 手机里已有更高版本的同一个应用；空间不够；APK 下载损坏；或是 32 位机型装了只支持 64 位的包 | 先卸载旧版再装；清出空间；按 [下载与安装教程.md](下载与安装教程.md) 第二节的 MD5 重新核对下载 |

## 三、自己补一个 Game.ini（最后手段）

只在确认发布包里本来就没有 `Game.ini`、而且你愿意试的时候做。在游戏目录里新建 `Game.ini`，内容按游戏实际的文件名改：

```ini
[Game]
Library=RGSS202E.dll
Scripts=Data\Scripts.rvdata
Title=游戏名
```

三处要跟着改：

- `Library`：填游戏目录里那个 `RGSS` 开头的 DLL 的实际文件名（RPG Maker VX 是 `RGSS202E.dll`；VX Ace 常见 `RGSS300.dll` 或 `RGSS301.dll`；XP 是 `RGSS102E.dll` / `RGSS103E.dll`）；
- `Scripts`：XP 的游戏写 `Data\Scripts.rxdata`，VX 写 `Data\Scripts.rvdata`，VX Ace 写 `Data\Scripts.rvdata2`；
- `Title`：填游戏名，写什么都行。

自己补的这个文件与原版不一定完全等价，能进游戏就算成功，进不去就别在这上面耗时间，去找发布者要完整包更省事。

## 四、这几种情况别再折腾

- 报错是 `Script error`、`require is not defined`，或者加密的 `.rgssad` 读不出来 —— 属于游戏本身与这条运行路径不匹配；
- 引擎不在官方支持列表里（Unity、Unreal 等）；
- 换了两支 Ren'Py 插件、也确认过权限与运行包，游戏仍然在同一个位置崩 —— 这种情况报给游戏作者，比继续在自己手机上试有效率。
