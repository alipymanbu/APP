JoiPlay 是一个在安卓手机上启动 PC 独立游戏的工具，支持 RPG Maker、Ren'Py、TyranoBuilder、Construct、Godot（GDScript）、Flash 与 HTML5 这几类引擎做的游戏，不是 Windows 模拟器，能跑什么取决于有没有对应插件。本篇只解决一件事：把主程序装进去，并配好第一次启动要用的权限。

## 一、先确认它跑不跑得了你想玩的游戏

同一个 PC 游戏，在 JoiPlay 上装好就能进，换一个就提示缺插件或者干脆黑屏，这是常态，不是装坏了。原因在于 JoiPlay 走的是「按引擎适配」这条路：只有官方做了对应插件的那几类引擎的游戏才有机会跑起来。

官方下载页给出的引擎覆盖与大致兼容度如下（截至 2026-09，**以官方页面当页显示为准**）：

| 引擎 | 官方标注的兼容度 | 说明 |
| --- | --- | --- |
| RPG Maker MV / MZ | 约 95% | 走 HTML 那一套，找 `www/index.html` 作为入口 |
| RPG Maker XP / VX / VX Ace | 约 90% | 老 RGSS 引擎，对应 `Game.exe` |
| Ren'Py | 约 90% | 视觉小说主力引擎，插件按 Ren'Py 版本分好几支 |
| TyranoBuilder | 约 95% | HTML 系视觉小说 |
| HTML5 游戏 | 约 95% | 入口是 `index.html` |
| Construct 2 / Construct 3 | 约 75% / 约 70% | 兼容度偏低，能不能进要试 |
| Adobe Flash | 约 60% | 靠 Ruffle 插件，只有 `.swf` 类游戏用得上 |
| Godot | 约 50% | 只支持用 GDScript 写的项目，3 与 4 是两个不同的插件 |

跑不了的情况有两类，事先知道能省下折腾的时间：一类是引擎不在上表里，另一类是游戏本身靠 Windows 专有接口或 Node.js 专有功能（例如脚本里出现 `require`），后者在安卓上不会因为换了插件就好。另外，加密方式特殊的 RPG Maker 游戏也会卡在读脚本这一步，具体报错见 [游戏打不开与报错排查.md](游戏打不开与报错排查.md)。

## 二、网盘里这一份是哪一版

网上搜出来的版本号是搜索当时官方的发布版本，网盘里这份是文档制作时核对过的那一份，两者经常不是同一个版本。本篇涉及的版本、包名、体积都以这张表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | JoiPlay |
| 版本号 | 1.21.000-patreon |
| 包名 | `cyou.joiplay.joiplay` |
| 安装包体积 | 26.44 MB |
| MD5 | `0c8866c8bf07cc8ecc0f328911f26774` |
| 开发者 | JoiPlay |

版本串末尾的 `-patreon` 是官方构建渠道的标记，不是「版本更高」的意思。官方下载页当前列出的主程序版本是 `1.21.000`（26.4 MB），与这一份体积一致；下载页上的版本号会随时间往前走，**以官方页面当时显示的为准**，这里不预判。

包名 `cyou.joiplay.joiplay` 是认正身最靠得住的一项：安卓的「应用信息」页会写出包名，对一眼就知道装的不是别的什么启动器。体积 26.44 MB 只是主程序本身 —— 引擎插件是独立的安装包，不在这份里，要按你要玩的游戏另外装，见 [插件怎么装与哪个引擎配哪个.md](插件怎么装与哪个引擎配哪个.md)。

MD5 用来确认文件下完整了。手机端多数文件管理器在文件详情里能看到 MD5；在电脑上算的话：

```bat
certutil -hashfile joiplay模拟器官网_v1.21.000-patreon.apk MD5
```

算出来与上表一致，说明文件没下坏、没被中途改动过。

## 三、认准官方渠道

JoiPlay 的官方站点是 [joiplay.net](https://joiplay.net/)，主程序与各插件在下载页里分开列出，更新说明放在官方自己的发布渠道。搜索「joiplay 官网」时，前面几条常常是拼写相近的第三方域名（例如 `joiplay.online`、`joiplay.org`、`joiiplay.com`）—— 这些都不是官方站点，实测 `joiplay.online` 已经换成了「域名出售」页。这类站点上的安装包多是二次打包的，拿来装的风险由你自己承担，能用官方渠道就别用它们。

判断手里那个包是不是原版，看两处就够：包名是 `cyou.joiplay.joiplay`，版本号能在官方下载页或更新说明里对得上。

## 四、装之前先准备好这几样

| 准备项 | 为什么 |
| --- | --- |
| 允许「安装未知来源应用」 | 网盘拿到的 APK 不走应用商店，系统默认拦一次，见下一节第 2 步 |
| 一个解压工具（ZArchiver、RAR 之类） | 手机上的游戏基本是压缩包，没有解压工具连游戏文件夹都打不开 |
| 至少预留两三倍于游戏的剩余空间 | 压缩包和解压出来的文件夹要同时存在，装完再删压缩包 |
| 想清楚要玩哪一类引擎的游戏 | 决定你要不要额外装插件；插件装错是「游戏不启动」最常见的原因 |

## 五、安装步骤

1. **转存并下载**：打开 [JoiPlay 安装文件资源（夸克网盘）](https://pan.quark.cn/s/a6220da85e0b)，登录夸克账号后先把文件**转存到自己的网盘**，再下载到手机。文件夹名里的「先保存再下载」就是这个意思 —— 分享链接可能失效，转存之后才长期属于你。
2. **允许安装未知来源应用**：在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给打开安装包的那个应用（文件管理器或浏览器）打开开关。国产定制系统的这一项常收在「安全」或「隐私」下面。
3. **点 APK 完成安装**：系统若提示「应用未经过安全检测」或来源未知，选择继续安装即可，这是第三方渠道安装包的常规提示。
4. **留意版本高低**：手机里如果已经装了更高版本的 JoiPlay，系统会直接报「应用未安装」，因为安卓不允许用低版本覆盖高版本。这时先卸载旧版再装；卸载不影响手机上的游戏文件夹，游戏与存档都还在原地。
5. **先装主程序，再装插件**：插件是独立的 APK，单独安装即可，不需要在主程序里做什么操作。装插件的顺序与选法见 [插件怎么装与哪个引擎配哪个.md](插件怎么装与哪个引擎配哪个.md)。

## 六、第一次打开要给的三项权限

| 权限 | 不给会怎样 |
| --- | --- |
| 所有文件访问 | 权限面板在主程序首次启动时会自己弹出来。不给的话，游戏能加进来、能启动，但**存档写不进去**，重启后看不到存档 |
| 读取已安装应用列表 | 主程序靠它找到你装好的插件。小米 MIUI 与 HyperOS 默认不给，表现是「插件明明装了却提示找不到」，见 [插件怎么装与哪个引擎配哪个.md](插件怎么装与哪个引擎配哪个.md) |
| 照片和视频、音乐和音频 | 部分游戏读取素材时要用；RPG Maker 插件也要这两项，缺了会在检查插件配置那一步报错 |

「所有文件访问」不在普通的权限列表里，路径是「设置 → 应用 → 特殊访问（有的机型叫权限管理）→ 所有文件访问」，把 **JoiPlay 与 RPG Maker 插件都打开**。这项如果第一次启动时被你划掉了，之后按这个路径补上就行。

## 七、装完做一次最小验证

不用急着找游戏，先确认主程序本身是好的：

1. 打开 JoiPlay，界面能正常出来（而不是一闪就退），说明主程序装对了；
2. 点右上角的 `+`，能弹出「添加游戏」之类的选项，说明文件访问这块通了；
3. 进右上角菜单 → 设置，能看到 RPGM、HTML、Ren'Py 这些分区的设置项 —— 分区在不在，只代表主程序正常，**不代表对应插件装了**；
4. 这时再按 [把电脑上的游戏导入手机.md](把电脑上的游戏导入手机.md) 加第一个游戏。

第一条就过不去（点图标就闪退、装的时候提示解析包出错），先回到第二节核对 MD5 重新下载；加游戏之后卡住、黑屏、报错，直接看 [游戏打不开与报错排查.md](游戏打不开与报错排查.md)；界面还是英文、或者游戏里的文字显示成方框，看 [界面语言与字体显示怎么设置.md](界面语言与字体显示怎么设置.md)。
