在这个工具上跑的游戏，存档不像手机游戏那样挂在账号里：多数情况下它是一个文件，跟着游戏目录走（Ren'Py 与 HTML 系游戏的落点例外，见第一节的表格）。这条设定有好有坏：好处是能直接拷走、不依赖网络；坏处是手机丢了、目录被误删、或者系统不让写，进度就真的没了 —— 所以备份这件事在前，抢救在后。

## 一、存档在哪里

多数游戏自己带存档界面，你在游戏里存档就行，但要找存档文件的时候，按引擎去这几个位置看：

| 引擎 | 存档放在哪 | 文件长什么样 |
| --- | --- | --- |
| RPG Maker XP | 游戏目录里 | `Save1.rxdata`、`Save2.rxdata` 这样递增 |
| RPG Maker VX | 游戏目录里 | `Save1.rvdata` |
| RPG Maker VX Ace | 游戏目录里 | `Save1.rvdata2` |
| Ren'Py | 游戏目录下的 `saves` 文件夹（个别版本会放在插件自己的目录下，两处都看一眼） | 后缀是 `.save` |
| RPG Maker MV / MZ、HTML 系 | 多数靠浏览器式的本地存储，文件位置不固定 | 优先用游戏自带的存档功能，别去找文件 |

所以「存档跟着游戏目录走」是绝大多数情况下的规律 —— Ren'Py 与 HTML 系除外，它们的落点见上面表格那一行。你把游戏目录整个搬到别的地方，存档通常也跟着搬走了 —— 这既是备份的便利，也是风险：**删除或移动游戏目录时，先想一眼存档在不在里面。**

## 二、存档存不上，改这三项

「存不上」有两种表现：游戏里保存时报错；当时看着存上了，重启游戏后存档列表是空的。两者处理方式相同，按下面的顺序试：

1. **给权限。** 主程序与 RPG Maker 插件都需要「所有文件访问」。路径是「设置 → 应用 → 特殊访问（有的机型叫权限管理）→ 所有文件访问」，两个应用都打开。这项没给，游戏能跑但写不进文件；
2. **把游戏移出受限目录。** `Android`、`Download` 这两个目录在较新的安卓版本上限制很严，游戏放在里面容易出现只读的情况。移到自建目录（例如 `内部存储/JoiPlayGames/`）再试；
3. **从存储卡挪回内部存储。** 一部分机型对外置存储卡的写入有限制，表现正好是「能玩、存不上」。把游戏目录复制到内部存储，删掉卡上那份，再启动游戏。

报错信息里出现 `Read-only file system` 时，也是这三条。做完这三步仍然存不上，按 [游戏打不开与报错排查.md](游戏打不开与报错排查.md) 第二节表里「存档存不上」「`Read-only file system`」这两行的处理，以及它第一节那个排查顺序往下走。

## 三、怎么备份

最省事也最不容易出岔子的备份方式：**把整个游戏目录复制一份到别的地方**。不需要在几百个文件里挑存档，游戏配置、素材、存档一次全带走，恢复的时候也整目录放回去，不会出现版本与存档对不上的问题。

三个可选的存放处，按可靠性排：

| 存放处 | 说明 |
| --- | --- |
| 电脑 | 数据线连上，把游戏目录整个拷到电脑上，按游戏名建文件夹归档。最稳，也最方便同时管多台设备 |
| 云盘 | 手机端直接上传游戏的存档文件夹；小体积的存档文件上传很快，适合隔几天存一次 |
| 手机内部另一个目录 | 能防误删，防不了手机丢失或损坏 |

备份时机不用太频繁，但这几个点值得存一次：刚开始玩、快到关键剧情、准备换设备、以及每次更新游戏版本之前。游戏版本更新与老存档不一定兼容，更新前留一份旧存档能救回进度。

还有一条只要顺手就能做到的防护：**把游戏目录加进手机清理软件的白名单**。手机管家那类工具的「一键清理」会把游戏目录里的 `Game.ini`、存档文件当成垃圾文件删掉，结果就是游戏突然报错、或者进游戏发现存档列表空了 —— 这类事故社区里反馈得不少，加白名单比事后修复便宜得多。

如果只想存最小的那一份，就把上面第一节表里对应的存档文件（或 `saves` 文件夹）单独复制出来，文件名保持原样，恢复时放回同一位置。

## 四、换手机怎么搬

1. 在新手机上把主程序与插件按 [下载与安装教程.md](下载与安装教程.md) 装好；
2. 把旧手机上的游戏目录整个搬到新手机，路径尽量保持一致（例如两边都用 `内部存储/JoiPlayGames/`）；
3. 新手机上打开主程序，游戏列表可能是空的 —— 这正常，游戏条目属于旧手机的安装，重新把游戏加一遍即可，存档不受影响，因为它在游戏目录里；
4. 加完启动游戏，进存档界面确认进度还在。

换了手机之后按键布局要重摆一遍（那是每个游戏条目的设置，跟着应用数据走，不是跟着游戏目录走），按 [虚拟按键手柄与画面设置.md](虚拟按键手柄与画面设置.md) 调一次就行。

## 五、存档已经没了怎么办

实话是：**没备份过就基本找不回来。** 这个工具自己不提供云存档，存档文件被删掉或被覆盖后，能在手机文件管理器的回收站里找到就是运气好 —— 部分机型删除文件会先放进回收站，保留一段时间；用云盘传过的，可以看云盘的历史版本功能。

所以别等出事再想这件事：玩到一个阶段，就把游戏目录拷一份出去。前面第三节那三个存放处里，电脑那一份是性价比最高的。
