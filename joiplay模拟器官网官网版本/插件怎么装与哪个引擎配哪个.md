# JoiPlay 插件怎么装，哪个引擎配哪个插件

> 本篇给出一张「游戏引擎 → 该装哪个插件」的对照表，教你怎么从一个游戏文件夹判断它用什么引擎做，以及插件装了却找不到时的处理顺序。

插件是这个工具里最容易出错的一环：主程序只负责界面、游戏列表和一部分 HTML 游戏，真正把某个引擎的游戏跑起来的是对应的插件，而插件与主程序是两个独立的安装包。装完主程序、把游戏加进列表，点开提示缺插件 —— 这不是装坏了，是还差一步。

## 一、官方下载页上列了哪些插件

官方下载页把主程序和插件并列列出，每一条都会标引擎、版本号、体积和更新日期。下表是 2026-09 抓取时各条目的样子，**实际以官方页面当页显示为准**，插件更新比主程序频繁：

| 下载页条目 | 版本 | 体积 | 用在哪 |
| --- | --- | --- | --- |
| RPG Maker Plugin | 1.22.00 | 80.0 MB | RPG Maker XP / VX / VX Ace 游戏 |
| Ren'Py 8.5 Plugin | 1.01.00 | 53.4 MB | Ren'Py 8 及以上做的游戏 |
| Ren'Py 7.7.1 Plugin | 1.00.60 | 38.0 MB | Ren'Py 7 系列做的游戏 |
| Ren'Py 8.3.7 / 8.2.3 / 8.1.3 Plugin | 1.00.x | 40~46 MB | 可选，用于改善这几个具体版本的兼容 |
| Ruffle Plugin | 1.02.00 | 26.0 MB | Adobe Flash 游戏 |
| Godot 4.3 Plugin | 1.00.60 | 73.5 MB | Godot 4 且是 GDScript 项目 |
| Godot 3.6 Plugin | 1.00.50 | 49.5 MB | Godot 3 且是 GDScript 项目 |
| JoiPlay（主程序，必需） | 1.21.000（下载页标注的公开构建） | 26.4 MB | 界面、游戏列表、HTML 游戏支持 |

主程序那一行写的是官方下载页上的公开构建版本 `1.21.000`；网盘里这一份的版本串是 `1.21.000-patreon`，末尾后缀是官方构建渠道的标记，两者指的是同一时期的主程序，不是两个不同的版本。

体积加起来不小：RPG Maker 与 Ren'Py 两个主力插件各几十兆，两个都装就超过 100 MB。所以不要「全下一遍」—— 先看你要玩的游戏是什么引擎，只拿那一个。

## 二、按游戏引擎对号入座

| 游戏引擎 | 要装的插件 | 入口文件长什么样 |
| --- | --- | --- |
| RPG Maker XP / VX / VX Ace | RPG Maker Plugin（一个覆盖这三个） | `Game.exe`，旁边有 `Game.rgssad` / `.rgss2a` / `.rgss3a` |
| RPG Maker MV / MZ | 不需要额外插件 | `www/index.html` |
| Ren'Py | Ren'Py 插件（按游戏版本挑分支） | 一个与游戏同名的 `.exe`，旁边有 `renpy` 目录 |
| Adobe Flash | Ruffle Plugin | `.swf` |
| Godot 3 / Godot 4 | 对应大版本的 Godot 插件 | `.pck`、`.tscn`，且是 GDScript 项目 |
| TyranoBuilder、Construct 2/3、HTML5 | 官方下载页当前没有单独的插件条目，走主程序的 HTML 支持 | `index.html` |

最后一行的意思是：这类游戏加进去能跑就跑，跑不动时先回头确认官方下载页那几天有没有新增条目，别去第三方站点找一个「某引擎专用插件」。

## 三、怎么判断一个游戏是什么引擎

不用猜，打开解压好的游戏文件夹看几个文件就能定：

| 看到这些文件 | 引擎 | 加游戏时选哪个入口 |
| --- | --- | --- |
| `Game.exe` + `Game.ini` + `RGSS300.dll` 或 `RGSS301.dll` | RPG Maker VX Ace | `Game.exe` |
| `Game.exe` + `Game.ini` + `RGSS202E.dll` | RPG Maker VX | `Game.exe` |
| `Game.exe` + `Game.ini` + `RGSS102E.dll` / `RGSS103E.dll` | RPG Maker XP | `Game.exe` |
| `www` 目录里有 `index.html`、`js`、`audio` | RPG Maker MV / MZ | `www/index.html` |
| 有 `renpy` 目录、`.rpy` 或 `.rpa` 文件、`lib` 目录 | Ren'Py | 与游戏同名的 `.exe` |
| 有 `tyrano` 目录、`.ks` 文件 | TyranoBuilder | `index.html` |
| 只有 `.swf` | Adobe Flash | 那个 `.swf` 文件 |
| `index.html` 旁边有 `data.js` 或 `c3runtime` | Construct 2 / Construct 3 | `index.html` |

Ren'Py 的版本分支怎么挑：先装最新的 8.5 那支试；游戏起不来或者一进去就报奇怪的脚本错误，再换 Ren'Py 7.7.1 那支（Ren'Py 7 及更早做的游戏属于这一支）。游戏文件夹里通常能找到写着自己 Ren'Py 版本的文本（`renpy` 目录下、或游戏自己生成的日志首行），找得到就照着挑，找不到就按上面的顺序试。

## 四、装插件的步骤与顺序

1. **先装主程序**。插件要靠主程序来调度，主程序没装就装插件，等于白装；
2. **判断引擎**（上一节的表），去官方下载页拿对应的那一个插件 APK；
3. **像装普通 APK 一样装它**：上一次给文件管理器开的「安装未知来源应用」权限这里继续用得上，插件装完**不会在桌面多出一个图标**，这是正常的；
4. **重启一次主程序**，让它重新读一遍已安装的应用；
5. **验证**：主程序里加游戏、启动，不再提示缺插件即为通过。第一次真正启动某个引擎的游戏时，系统可能还会再弹一次权限面板（例如 RPG Maker 插件要「所有文件访问」），全部允许，见 [下载与安装教程.md](下载与安装教程.md) 第六节。

## 五、插件不对时的典型症状

| 现象 | 大概率是哪一步错了 |
| --- | --- |
| 启动游戏时提示 `You need RPG Maker Plugin` | RPG Maker XP/VX/VX Ace 的游戏，但 RPG Maker Plugin 没装 |
| 提示找不到 RPG Maker 插件，可你明明装了 | 权限或版本问题，见下一节 |
| Ren'Py 游戏黑屏、或报看不懂的脚本错误 | 装错了 Ren'Py 分支，换上与游戏版本匹配的那支 |
| 加了游戏但提示不支持这个引擎 | 引擎不在支持列表里（Construct 兼容度本就偏低、Godot 只支持 GDScript），换插件没用 |
| 检查插件配置时报错 | 插件缺「所有文件访问」「照片和视频」「音乐和音频」权限 |
| Flash 游戏打不开 | 缺 Ruffle 插件；`.swf` 类游戏才用得到它 |

## 六、提示「找不到已安装的插件」怎么处理

按下面顺序做，通常第一条或第二条就能解决：

1. **给主程序「读取已安装应用列表」的权限**。小米的 MIUI 与 HyperOS 默认不给，表现就是插件装了却看不见。路径是「设置 → 应用 → JoiPlay → 权限」，找到「读取已安装应用列表」设为始终允许；HyperOS 还要在同一页点进「其他权限」里再确认一遍。改完把主程序完全关掉重开。
2. **确认两边都是最新版**。插件更新比主程序频繁，插件拿了新的、主程序还是旧的（或者反过来），会出现互相认不出的情况。
3. **卸载插件后重新装一次**。安装过程中被系统拦截、或 APK 传到手机时损坏，都会留下一个装上了但不完整的状态。
4. **检查有没有被你自己的设置挡掉**：部分系统的「应用隐藏」「隐私空间」会把插件藏起来，主程序自然读不到。

这些都做过还是找不到，那就是这个游戏的引擎没被支持，别再花时间在插件上，回头看 [下载与安装教程.md](下载与安装教程.md) 第一节那张兼容表。
