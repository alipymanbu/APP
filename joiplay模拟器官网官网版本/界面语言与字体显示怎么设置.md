# JoiPlay 界面语言与字体显示怎么设置

> 本篇讲两件常被混在一起的事：主程序界面怎么切成中文，以及游戏里的文字变成方框、缺字时怎么换字体 —— 这两处的操作结尾正好相反。

主程序的界面语言和游戏里显示的字体是两套独立设置：前者在「设置 → 语言」里，后者在「设置 → RPGM 设置」里。麻烦的地方在最后一步 —— 界面语言要**点保存**才生效，游戏字体反而**不能点保存**，点错就等于白选一次。菜单措辞会随版本变化，位置按本篇描述的找。

## 一、把主程序界面切成中文

1. 点右上角的三点菜单，选「设置」（Settings）；
2. 找到「语言」（Language）这一项，点它旁边的「选择」（Choose）；
3. 在列表里选简体中文；
4. **点右下角的保存**，然后回到主界面。

第 4 步是关键：不点保存就返回，界面还是原来的语言，得再进来一次。改完语言后，游戏列表里的游戏名不受影响（那是你自己添加时填的）。

## 二、游戏里的文字变成方框、缺字怎么办

这是 RPG Maker 系游戏最常见的显示问题：游戏自带的字体在你的手机上没有对应字形，汉字就显示成方块或干脆缺字。换一个手机上有完整中文字形的字体即可：

1. 先把一个中文字体文件（`.ttf`）放到好找的位置，例如自建的 `内部存储/JoiPlayGames/_fonts/`，文件放哪儿不影响使用，只是为了下次好找；
2. 主界面右上角三点菜单 → 「设置」；
3. 进「RPGM 设置」（RPGM Settings）一栏，找到「自定义字体」（Custom Font），点旁边的「选择」（CHOOSE）；
4. 在文件选择器里定位到第 1 步那个 `.ttf` 文件，选中；
5. 点「好的 / OK」确认，**然后直接返回，不要点右下角的「保存」**。

第 5 步的提醒来自社区教程里一致的说法：这个界面上的「保存」会把设置恢复成默认值，按下去刚选的字体就没了，方框还是方框。以你手机上界面实际显示的按钮为准，只确认、不保存。

## 三、字体怎么挑

| 挑法 | 原因 |
| --- | --- |
| 选笔画细一点的无衬线中文字体 | 部分字体线条过粗时同样会显示成方框，细一点的更稳 |
| 一份字体留一个固定目录 | 换字体、换手机都要再选一次，放固定位置省事 |
| 优先带完整中日韩字形的字体 | 只有拉丁字形的英文字体装上去，汉字照样是方框 |

改完之后**完全退出游戏再启动**。如果还是方框，换一个字体文件重试一次 —— 上一节的第 4、5 步每次都要重走一遍。

## 四、两处「保存」正好相反，别记混

| 想改什么 | 路径 | 收尾动作 |
| --- | --- | --- |
| 主程序界面语言 | 设置 → 语言 → 选择 | 必须点右下角「保存」 |
| 游戏内文字字体 | 设置 → RPGM 设置 → 自定义字体 | 只点「好的 / OK」，**不要**点「保存」 |

## 五、这一项管不到的情况

「自定义字体」在 RPGM 设置里，针对的是 RPG Maker 系游戏。另外两种情况要分开处理：

- **Ren'Py 与 HTML 系游戏出现方框字**：先看游戏自己的设置里有没有字体或语言选项；游戏目录里如果有字体文件夹，多半是发布者已经带上了字体，缺的是手机上的显示权限或版本差异；
- **界面上个别字符显示不出来**（例如特殊符号、性格修正这类带色的标注）：属于游戏与这条运行路径的显示差异，换字体不一定有用，社区里也把它列为已知现象，别在这上面反复折腾。

界面和字体都顺了之后，接下来影响体验的就是按键布局与画面，见 [虚拟按键手柄与画面设置.md](虚拟按键手柄与画面设置.md)；游戏起不来的问题仍然看 [游戏打不开与报错排查.md](游戏打不开与报错排查.md)。
