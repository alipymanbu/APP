# 把电脑上的游戏导入 JoiPlay 怎么弄

> 本篇讲一个 PC 游戏从电脑到手机、再到 JoiPlay 游戏列表里的完整过程：放哪个目录、怎么传、怎么解压、入口文件选哪个。

导入这件事本身不难，坑都在细节上：游戏放在受系统保护的目录里会导致存不上档，压缩包没解压完会导致加载失败，入口文件选错则直接提示缺插件。按下面的顺序走，这几类问题都能绕开。

## 一、先决定游戏放在哪

新建一个自己的目录，比如手机存储根目录下的 `JoiPlayGames`，之后所有游戏都往里放。有三条要求：

- **别放在 `Android` 目录下**。从安卓 11 起这个目录对普通应用限制很严，游戏文件放在里面容易出现读不到、存不上；
- **别放在 `Download` 目录下**。部分机型对这个目录也有额外限制，同样会影响存档；
- **路径里尽量只用英文和数字**。游戏自己的目录名、上层目录名都算，中文和空格在某些游戏里会触发加载错误，层级也别套得太深。

一个干净的例子是：`内部存储/JoiPlayGames/PokemonEssentials/`。如果你的手机插了存储卡，游戏放在**内部存储**比放在存储卡上更稳 —— 有些机型不支持把游戏存在外置卡上，表现是能玩但存不上档。

## 二、把游戏从电脑搬到手机

三种方式，按你的条件挑一种：

| 方式 | 怎么做 | 适合 |
| --- | --- | --- |
| 数据线（MTP） | 手机连电脑，在手机上把 USB 用途选成「文件传输」，电脑上就会出现手机盘符，直接把游戏文件夹拖进 `JoiPlayGames` | 一次性搬很多个大游戏 |
| ADB 推送 | 手机开发者选项里打开 USB 调试，电脑装好 ADB 后执行命令（见下） | 习惯命令行、要反复搬同一批目录 |
| 云盘或聊天工具中转 | 电脑上传、手机下载，再解压 | 手机上直接下载的游戏包，或者不在同一台电脑旁 |

ADB 推送的命令长这样，第一条把整个游戏目录推过去，第二条推单个压缩包：

```bash
adb push "D:\games\PokemonEssentials" /sdcard/JoiPlayGames/PokemonEssentials
adb push "D:\games\game.zip" /sdcard/JoiPlayGames/
```

用 ADB 的好处是顺带能装 APK（`adb install 插件.apk`），插件和游戏一起搬完，不用来回切数据线模式。

传完之后核对一下文件数量 —— 传输中断在数据线和云盘中转里都出现过，尤其是一个游戏几百兆的时候。传坏的包后面会以「加载失败 / 文件找不到」的形式报出来，见 [游戏打不开与报错排查.md](游戏打不开与报错排查.md)。

## 三、解压

手机端用一个解压工具（ZArchiver、RAR 之类）打开压缩包，选「解压到当前目录」。几个注意点：

1. **不要直接在压缩包里运行文件**。有些手机文件管理器能点进去看压缩包内容，但游戏必须解压成普通文件夹才能用；
2. **分卷压缩包要全部下载齐再解压**。名字带 `part1`、`part2` 的那种，缺一个卷会解压失败或者解出半截文件；解压时只要选第一个卷，工具会自己往下接；
3. **解压出来的目录层级要对**。有的发布包会多套一层，比如解成 `JoiPlayGames/PokemonEssentials/PokemonEssentials/`，进去看到的第一个目录里如果没有入口文件，就往里再进一层；
4. **解压完再删压缩包**，能省不少空间，但删之前最好先启动一次游戏确认能进。

## 四、找到该选哪个入口文件

加游戏那一步要你指定一个文件，选错了游戏就进不去。按引擎对号入座：

| 引擎 | 入口文件 |
| --- | --- |
| RPG Maker XP / VX / VX Ace | 游戏目录里的 `Game.exe` |
| RPG Maker MV / MZ | 游戏目录下的 `www/index.html` |
| Ren'Py | 与游戏同名的那一个 `.exe` |
| TyranoBuilder、Construct、HTML5 | `index.html` |

不确定游戏是什么引擎，就看目录里有什么：出现 `renpy` 目录是 Ren'Py，出现 `www` 目录是 RPG Maker MV/MZ，出现 `Game.ini` 和 `RGSS` 开头的 DLL 是老 RPG Maker。完整的判断表在 [插件怎么装与哪个引擎配哪个.md](插件怎么装与哪个引擎配哪个.md) 第三节。

## 五、加进游戏列表

1. 打开 JoiPlay，点右上角的 `+`，选「添加游戏」（界面可能是英文的 Add Game，按位置找）；
2. 在可执行文件那一栏点「选择」（Choose），一层层进到游戏目录，选中上一节表里对应的那个文件，确认；
3. 接下来会让你填游戏名、版本号、图标 —— **三个都可以不填**，直接下一步。名字填了只是列表里好看，版本号不填不影响玩；
4. 完成后游戏会出现在列表里，点图标启动。

想让列表整齐一点，同一款游戏的目录名、列表里的游戏名保持一致，之后找存档、搬游戏的时候不容易认错。

## 六、第一次启动会遇到的两件事

- **提示缺插件**：启动时弹出类似 `You need RPG Maker Plugin` 的提示，说明这个引擎的插件还没装，按 [插件怎么装与哪个引擎配哪个.md](插件怎么装与哪个引擎配哪个.md) 装上再启动；
- **提示需要运行包**：RPG Maker XP / VX / VX Ace 的游戏常见，游戏里缺共享素材时要补一个运行包（RTP），处理办法见 [RTP运行库缺失怎么补.md](RTP运行库缺失怎么补.md)。

两件都不提示、但屏幕一直黑着，或者进去就报脚本错误，那属于排查范围，看 [游戏打不开与报错排查.md](游戏打不开与报错排查.md)。

## 七、有些游戏搬进来也没用

这个工具不是 Windows 模拟器，它只按引擎适配。所以下面这几类游戏不用折腾：

- 引擎不在官方支持列表里的（比如用 Unity、Unreal 做的）；
- 游戏脚本里用了 Windows 专有接口，或用了 Node.js 专有功能（报错里出现 `require is not defined` 就是这一类）；
- 加密方式特殊的 RPG Maker 游戏，素材包是加了壳的 `.rgssad` / `.rgss2a` / `.rgss3a`。
