## 一、按提示原文查

| 你看到的提示 | 大概是什么 | 怎么做 |
| --- | --- | --- |
| 解析包错误 | 安装包下载不完整或被改动 | 重新下载并校验 MD5，见 [下载与安装教程.md](下载与安装教程.md) 第四节 |
| 已被阻止安装 / 被拦截 | 没给下载它的应用开「安装未知应用」 | 开权限后重装，路径见 [下载与安装教程.md](下载与安装教程.md) 第五节 |
| 与已有应用冲突 | 机器上已有同包名 `com.vivo.game` 的另一份 | vivo / iQOO 手机自带的就是它，先确认自带那份能不能用；不能用就卸载旧的再装 |
| 安装失败（反复） | 空间不足、安装位置受限、缓存异常 | 见本文第二节 |
| 发现高危病毒 | 系统安全检测拦了安装 | 先确认包来源可靠（比对过 MD5），再在设置 → 安全 → 更多安全设置 → 应用安装里放行；该项名称各系统版本不同 |
| 安装按钮是灰的 | 应用没通过当前系统的上架校验 | 换官方渠道或换一个版本再试 |
| 应用无响应 / 闪退 | 缓存、权限或系统版本问题 | 见本文第三节 |
| 账号不存在 | 改绑过手机号或邮箱，却还在用旧的登录 | 用当前绑定的手机号或邮箱登录，见 [账号登录与实名认证.md](账号登录与实名认证.md) 第四节 |
| 登录后游戏数据没了 | 登错账号或区服 | 先核对账号与区服，再在游戏登录界面点「切换账号」选其他游戏 ID |
| 账号突然登不上、提示被停用 | 该账号申请过未成年充值退款 | 官方口径是这类账号会被封停，见 [未成年充值退款怎么申请.md](未成年充值退款怎么申请.md) 第四节 |
| 交易来的角色找不回 | 角色已在游戏交易中售出 | 官方口径是交易成功的角色不支持找回，见 [渠道服和官服有什么区别.md](渠道服和官服有什么区别.md) 第五节 |
| 礼券没到账 | 没按活动规则参与，或还没发放 | 见 [礼包V钻与积分怎么用.md](礼包V钻与积分怎么用.md) 第六节 |

## 二、装了但一直提示安装失败

官方给的排查顺序是：

1. **看存储空间**：空间不足就先卸载不常用的应用、清理垃圾文件，再装。
2. **换安装位置**：部分游戏只支持装在系统空间，把「首选安装位置」改成系统空间后重新下载安装。
3. **重启手机后重下**：回游戏中心重新下载安装一次。
4. **恢复出厂**：前三条都无效时，备份重要数据后恢复出厂设置（清除所有数据并格式化），再重新下载安装。这一步会清空手机数据，动手前务必确认备份完整。

官方客服的安装排查里还有三条，常被忽略：

- **存储权限被关**：设置 → 应用与权限 → 应用管理 → 游戏中心 → 权限 → 存储，先禁止再重新允许，然后重装。
- **开了多用户模式**：设置 → 系统管理 → 多用户，如果开着，取消它，或切到当初安装时所在的那个用户再试。
- **下载记录有残留**：游戏中心 → 我的 → 我的下载，把那条下载记录和对应安装包一起删掉，重新下载。

## 三、打开就闪退，或用着用着无响应

按顺序试，多数在第 3 步之前就好了：

1. **重启应用**：设置 → 应用与权限（或更多设置）→ 应用管理 → 游戏中心 → 强制停止，再从后台清掉重开。
2. **升级系统与应用**：设置 → 系统升级里检查系统版本；应用商店里把游戏中心升到最新版。
3. **清内存与存储**：用 i 管家做一次一键优化，再用空间清理释放存储。官方建议保持剩余空间在 20% 以上。
4. **检查权限**：长按桌面图标 → 应用信息 → 权限，把权限都允许后再打开。
5. **清除数据**：设置 → 应用管理 → 游戏中心 → 存储 → 清除数据。**这会清掉登录状态、收藏和下载记录**，动手前确认没有正在下载的任务。
6. **卸载重装**：桌面长按图标卸载，再重新安装。如果闪退是从某次版本更新后开始的，官方给小贴士是先用旧版本、同时关掉应用商店的「WLAN 下自动更新」，等新版本修复后再打开自动更新。

换到另一台同安卓版本的设备上同样闪退，基本可以判断是该应用在这个系统版本上没适配好，这种情况只能等新版本推送，或向应用方反馈。

## 四、下载不动、下到一半停住

- **先看网络**：换一个网络再试。公共 WiFi 和信号弱的移动网络都容易出这个问题。
- **再怀疑缓存**：清游戏中心的缓存后重试（清缓存的具体路径见 [下载游戏与安装管理.md](下载游戏与安装管理.md) 第三节）。
- **最后删记录重下**：把那条下载记录和安装包一起删掉，重新下载。
- 同一时段身边同款机型也一样卡着，官方口径是可能赶上服务端异常，换个时间段再试，或直接联系人工客服。

补充一条：**暂停和删除不是一回事**。暂停可以接着下，删除等于把已下的大小清空，下次从头来。

## 五、需要人工客服时

官方给了两个统一入口：

- **在线客服**：游戏中心里点任意一款游戏 → 进入详情页 → 下滑点「咨询客服」。积分相关的咨询也可以走「我 → 设置 → 帮助与反馈」里的客服图标。
- **热线**：vivo 互联网服务热线 `4006299688`。

报问题前先准备好这几项，能少几个来回：手机型号与系统版本、游戏中心版本号（「我 → 设置」里可看）、出问题时的提示原文，以及大致的发生时间。
