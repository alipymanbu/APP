## 一、先确认你是不是真的需要装

vivo 和 iQOO 手机出厂就带这个应用，桌面或应用列表里找一下，名字可能是「游戏中心」。已经有的直接打开用，不用再装一遍 —— 重复装会提示「与已有应用冲突」。

需要自己装的通常是两种情况：

- 用的是小米、华为、荣耀、OPPO、一加、三星等别家安卓手机，想玩 vivo 渠道的游戏；
- vivo 手机上误删过、或做过「卸载更新」，想把独立安装的那份装回来。

下表是网盘里那份安装包的实际信息。网上搜到的「最新版」往往已经是另一个版本号，装之前以这张表为准，装完也能拿它复核。

| 项目 | 值 |
| --- | --- |
| 应用名 | vivo游戏中心 |
| 包名 | `com.vivo.game` |
| 版本 | 7.2.15.1 |
| 安装包大小 | 110.82M |
| 安装包 MD5 | `0a48b5e7d5021e458bedcdfeb16e4811` |
| 形态 | 安卓应用（APK） |
| 官网 | [game.vivo.com.cn](https://game.vivo.com.cn/) |
| 界面语言 | 简体中文 |

三点提醒：

- 这是安卓包，**iPhone 和 iPad 装不了**，苹果设备上也没有 vivo 渠道的游戏可玩。
- 官方页面没有列出最低安卓版本。安装时系统若直接提示「不兼容」「无法安装」，就是这台机器装不上，换设备比反复重试有用。
- 110.82M 只算应用本身。游戏中心里的游戏是另外下载的，大型网游几个 G 很常见，空间要按「应用 + 打算玩的游戏」一起留。

## 三、从网盘把安装包取到手机

1. 在手机浏览器或夸克 App 里打开 [vivo游戏中心 安装文件资源（夸克网盘）](https://pan.quark.cn/s/a3aeb50d0c7c)。
2. 先点「保存到我的网盘」，再下载。直接下也能用，但转存之后原分享链接失效了也不影响你。
3. 等下完，记住它存在哪 —— 多数浏览器放在「下载」或 `Download` 目录。
4. 文件名以网盘里实际显示的为准，一般形如 `vivo游戏中心_v7.2.15.1.apk`。

打开链接提示失效或要提取码，说明这条分享已不是当前状态，换最新那条再试。

## 四、装之前花半分钟校验一下

安装包从网络传到手机，中途出错的话，装的时候会报「解析包错误」。先校验一次，能省掉后面一堆莫名其妙的排查。

把 APK 拷到电脑上，在文件所在目录执行：

```powershell
certutil -hashfile "vivo游戏中心_v7.2.15.1.apk" MD5
```

输出的十六进制串去掉空格后，应与第二节表里的 `0a48b5e7d5021e458bedcdfeb16e4811` 完全一致（大小写不敏感）。手机上用带 MD5 校验功能的文件管理器也能做。对不上就重新下一次，别将就着装。

## 五、先去系统里放行「未知来源」

网盘里的包不是从应用商店装的，安卓默认会拦一次。要给负责下载它的那个应用（浏览器或夸克）开安装权限，各品牌路径不同：

| 品牌 | 大致路径 |
| --- | --- |
| vivo / iQOO | 设置 → 应用与权限 → 权限管理 → 权限 → 安装未知应用 |
| 小米 / 红米 | 设置 → 应用设置 → 应用管理 → 权限管理 → 安装未知应用 |
| 华为 / 荣耀 | 设置 → 安全 → 更多安全设置 → 安装外部来源应用 |
| OPPO / 一加 / realme | 设置 → 安全 → 安装外部来源应用 |
| 三星 | 设置 → 生物识别和安全 → 安装未知应用 |
| 原生安卓 | 设置 → 应用 → 特殊应用权限 → 安装未知应用 |

记不住路径，就在设置顶部搜索框里搜「未知应用」或「外部来源」，基本都跳到同一页。找到负责下载的那个应用，把开关打开，弹窗里选「仍要安装」。

## 六、安装与第一次打开

1. 从通知栏点刚下完的文件，或打开文件管理器找到那个 `.apk` 点它。
2. 安装界面点「安装」，等进度走完，桌面出现图标。
3. 首次启动会依次弹权限申请。真正影响功能的几项如下：

| 权限 | 不给会怎样 |
| --- | --- |
| 存储 / 照片和视频 | 游戏包下不下来，缓存也写不进去 |
| 网络 | 打开后拉不到内容，游戏列表是空的 |
| 安装其他应用 | 游戏下完后点安装没反应，得手动去文件管理器装那个包 |
| 通知 | 只影响下载完成提醒，不影响使用 |

具体弹哪几项、叫什么名字，以你手机上实际弹出的为准。

4. 启动后如果直接要求登录，属正常 —— 下载记录、礼包、签到这些动作都挂在账号上，见 [账号登录与实名认证.md](账号登录与实名认证.md)。
5. 非 vivo 手机上打开后，界面和入口会有差异，部分系统级功能（游戏空间、悬浮窗一类）可能没有，见 [其他品牌手机能不能用.md](其他品牌手机能不能用.md)。

## 七、装不上或者装完打不开

按这个顺序自查，比反复重装有效：

- 提示「解析包错误」→ 回第四节重新校验 MD5，文件多半没下完整。
- 提示「已被阻止安装」「被拦截」→ 第五节的未知来源权限没开，或者开给了另一个应用。
- 提示「与已有应用冲突」→ 手机上已有同包名（`com.vivo.game`）的另一份。vivo/iQOO 手机自带的就是它，先确认自带那份能不能用，能用就别再装第二份；不能用则先卸载旧的再装。
- 提示空间不足 → 先清出不小于安装包大小再加余量的空间。官方给的办法里还有一条：把「首选安装位置」改成系统空间再下。
- 装好后点图标闪一下退回桌面 → 先确认系统版本是否过旧；仍不行，到 [常见问题与排查.md](常见问题与排查.md) 第三节按「闪退」往下走。
