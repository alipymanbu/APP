## 一、先对一遍：你要装的是哪一版

网上能搜到的多半是官方最新版，而网盘里放的是固定的一版，两者版本号经常对不上。装之前先看这张表，它就是这份文档对应的安装包：

| 项目 | 值 |
| --- | --- |
| 应用名 | Vocal Pitch Monitor |
| 开发者 | TadaoYamaoka |
| 版本 | v1.5.5 |
| 包名 | com.tadaoyamaoka.vocalpitchmonitor |
| 安装包大小 | 5.54M |
| MD5 | 041C24BF091019DDB3D645C7A69A6D34 |

版本号、包名、安装包大小以这张表为准。官方之后如果发过更新的版本，那是另一份包，不影响这里写的事实。

## 二、对准系统要求

| 项目 | 要求 |
| --- | --- |
| 系统版本 | Android 7.0 及以上 |
| 麦克风 | 必须。应用的全部功能都建立在麦克风输入上 |
| 屏幕方向 | 竖屏、横屏都支持 |
| 网络 | 取安装文件时需要；日常使用不需要 |

系统门槛取自官方应用商店页面，会随版本变化，**以官方页面上当时显示的要求为准**。官方安卓版页面：[Google Play 上的 Vocal Pitch Monitor](https://play.google.com/store/apps/details?id=com.tadaoyamaoka.vocalpitchmonitor)。

## 三、从网盘把安装包取到手机上

整个过程在手机端操作最省事，也可以在电脑上先转存再回到手机下载：

1. 打开 [Vocal Pitch Monitor 安装文件资源（夸克网盘）](https://pan.quark.cn/s/709eba58e3bf)，把里面的文件夹保存到自己的网盘；
2. 在手机上的夸克网盘里找到刚转存的那一项，点下载，等它落到手机本地；
3. 记一下下载完成时提示的保存位置，装的时候要回到那里找 `.apk` 文件。

第 3 步常被忽略：安卓各家的下载目录不一样，装的时候在文件管理里翻错地方，会误以为没下载成功。

## 四、安装步骤

1. 用手机自带的文件管理打开刚才的下载目录，找到 `.apk` 文件，点它；
2. 第一次装这类来源的安装包，系统会提示「不允许从此来源安装应用」，按提示进到设置里，把对应来源的开关打开（不同品牌的入口名字不一样，通常在「设置 → 安全」或「设置 → 应用管理」下），再回来点一次安装；
3. 等待安装完成，桌面上会出现 Vocal Pitch Monitor 的图标。

安装过程中如果提示「解析包出错」「应用未安装」，先核对第一节那张表里的大小和 MD5——大概率是文件没下载完整，回到网盘重新下一遍更省时间，具体排查见 [常见问题与排查.md](常见问题与排查.md)。

## 五、首次启动要放行的两件事

打开应用什么曲线都没有，八成是权限没给。第一次启动时系统会弹出请求，逐条放行：

| 权限 | 用途 | 不给会怎样 |
| --- | --- | --- |
| 麦克风（录音音频） | 取声音做实时音高显示 | 完全不出曲线，这是应用的核心权限 |
| 存储 / 文件 | 录音保存、读取已有录音文件 | 录音能看不能存，保存与载入功能不可用 |

如果第一次点成了拒绝，之后不会再弹窗，要自己去「设置 → 应用 → Vocal Pitch Monitor → 权限」里重新打开。各品牌安卓的菜单层级略有差异，找不到就用设置里的搜索框搜应用名。

## 六、装完怎么确认装对了

三个核对点，都来自第一节那张表：

- **应用信息里的版本号**：进「设置 → 应用 → Vocal Pitch Monitor」，看版本是不是 `v1.5.5`；
- **包名**：少数机型和应用市场会显示包名，应为 `com.tadaoyamaoka.vocalpitchmonitor`；
- **最直接的验证**：打开应用对着麦克风哼一个长音，屏幕上应该立刻画出一条随声音起伏的线。曲线动起来，说明安装、权限、麦克风这条链路都通了。

曲线出来了但看不懂，接着看 [实时音高图怎么看.md](实时音高图怎么看.md)。

## 七、安卓版、iOS 版与同名软件

- 官方同时发布了 **iOS 版**。iOS 版是付费应用，界面与部分设置项和安卓版不完全一样，本文里的步骤针对安卓安装包。
- 想要不带广告的版本，可以看官方的付费版（应用名里带 Pro），它需要单独获取，不是拿本文这份包去换。免费版与付费版的差别以官方商店页面上的说明为准。
- 网上能搜到**同名的电脑端软件**，那不是这个应用。本应用是手机端应用，官方发布渠道就是 Google Play 与 App Store，这两个页面上的开发者名都是 TadaoYamaoka——对不上就不要装。
