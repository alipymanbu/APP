# 大富翁Go 好友怎么加与合作活动

> 大富翁Go（MONOPOLY GO!）里好友不是可选项：换贴纸、社区宝箱、合作类活动都要靠好友列表。本篇讲三种加好友方式各自怎么操作、邀请链接有什么隐私注意点、加了好友之后能一起玩什么，以及加不上人时先查哪里。

## 一、好友入口在哪

主界面**右下角的好友图标**（两只握手的图案）。点开之后上面是已有好友列表，下面是几种添加方式的按钮。找不到按钮时先看右下角，再往菜单里翻一层。

## 二、三种加好友方式

| 方式 | 怎么用 | 适合什么场景 |
| --- | --- | --- |
| 通讯录 | 授权通讯录权限 → 输入手机号验证 → 列表里已经在玩的人可以逐个添加 | 身边熟人一圈都在玩时最省事；不想交手机号就别用这条 |
| Facebook | 先把游戏连上 Facebook → 在你 Facebook 好友里已经玩这款游戏的人会出现在建议列表 | 想一次性把熟人加完，且不介意和 Facebook 账号关联 |
| 邀请链接 | 点「邀请」生成一条专属链接 → 用任意聊天软件发给对方 → 对方通过链接安装并进入游戏后自动成为好友 | 对方还没装游戏；这是最常用的一条路 |

有的版本还能在同一菜单里按用户名或好友码找人，入口就在上面这几个按钮旁边，以你游戏内看到的为准。

## 三、邀请链接的隐私注意点

- **点开链接就等于加了你。**所以别把链接发到公开群、论坛、动态评论区 —— 发出去谁点谁进你的好友列表。
- 只想给特定的人，就单独私聊发。
- 邀请奖励不是「点一下就到账」：得等对方把游戏装好、走完注册并绑定，才算数（具体条件以游戏内邀请页的说明为准）。
- 加了陌生人之后如果觉得不合适，可以在对方资料页屏蔽，屏蔽只影响之后的互动，已经发生的交换不会回退。

## 四、加了好友之后能一起做什么

| 玩法 | 需要什么 | 你能得到什么 |
| --- | --- | --- |
| 贴纸交换 | 互为好友 | 补齐相册，见 [贴纸相册与交换怎么玩.md](贴纸相册与交换怎么玩.md) |
| 社区宝箱 | 好友一起攒进度 | 开箱时参与的人都有奖励；你帮好友开自己也拿一份 |
| 合作类活动 | 和好友推进同一条进度条 | 活动里程碑里的贴纸包与掷骰次数 |
| 伙伴 / 竞速类活动 | 组队完成 | 活动专属奖励 |
| 好友互赠 | 每天的互赠次数 | 互送掷骰次数等资源，按玩家的普遍反馈，赠送用的是活动额度而不是从自己余额里扣，具体以游戏内提示为准 |
| 拆迁与银行抢劫 | 不需要好友 | 好友也会出现在你的对手池里，看到自己人被抢不用惊讶 |

## 五、加不上、列表是空的时先查这几处

| 现象 | 可能原因 | 怎么处理 |
| --- | --- | --- |
| 通讯录里一个可加的人都没有 | 对方没授权通讯录，或确实没人在玩 | 改用 Facebook 或邀请链接 |
| Facebook 方式看不到建议 | 游戏没连上 Facebook | 先在设置里连上 Facebook，再回好友菜单刷新 |
| 点了邀请链接没加上 | 对方没走完安装与注册流程 | 让对方重新点一次链接，并把新手引导走完 |
| 邀请成功了但奖励没到 | 奖励发放有延迟，或对方没满足全部条件 | 隔一段时间再看；仍未到就找游戏内客服 |
| 好友列表整片空白 | 网络或服务端问题 | 见 [卡加载与闪退怎么排查.md](卡加载与闪退怎么排查.md) |

## 六、每天花两分钟做的事

1. 把当天的好友互赠发一遍，能发多少发多少 —— 次数每天重置，攒着不用就没了。
2. 看一眼社区宝箱是不是满了，满了就约在线的朋友一起开。
3. 有合作类活动时，组队名额优先留给每天都会上线的人，否则进度条容易卡在大半。
4. 相册里有重复贴纸，先问一圈谁缺，再决定当天的交换次数怎么分配。
5. 好友多起来之后，把长期不上线的挪出优先名单，把每天的互动次数留给还活跃的人。
