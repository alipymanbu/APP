# 大富翁Go 卡加载与闪退怎么排查

## 一、先分清：是你这边的问题，还是服务器的问题

出现下面任意一条，多半是服务端那边：

- 两台设备（手机加平板）登同一个账号都进不去；
- Wi-Fi 和移动数据换着来都进不去；
- 官方账号下或社区里有一堆人在同时说进不去。

确认服务端状态的官方渠道：

- 官方 X（Twitter）：[https://twitter.com/MonopolyGo](https://twitter.com/MonopolyGo)
- 官方 Facebook 主页：[https://www.facebook.com/MonopolyGO](https://www.facebook.com/MonopolyGO)
- 官方 Discord 服务器：[https://discord.gg/officialmonopolygo](https://discord.gg/officialmonopolygo)
- 官网：[https://www.monopolygo.com/](https://www.monopolygo.com/)

确认是服务器的问题就只能等，反复重装、反复清数据只会白折腾，还有把进度弄丢的风险。

## 二、本地方向按顺序排查

1. **彻底关掉再开**：从最近任务里把游戏划掉（不是按返回键退出），再重新打开。这一步能解决相当一部分「卡在一半」。
2. **换网络试一次**：Wi-Fi 与移动数据互换；必要时切一次飞行模式再切回来，强制重连。
3. **看存储空间**：手机存储快满时，游戏写不进临时文件就会卡。先腾出几百 MB 以上再试。
4. **清缓存（安卓）**：设置 → 应用 → 找到游戏 → 存储 → 清除缓存。**认准「清除缓存」，不要点「清除数据」** —— 清除数据会把本地的访客进度一起清掉。
5. **重启手机**。
6. **重装**：只在确认账号已经绑定的前提下做。重装后登录同一账号，进度会回来，做法见 [账号绑定与换手机找回进度.md](账号绑定与换手机找回进度.md)。
7. **看系统时间与版本**：系统时间明显不准，或者游戏版本落后服务端太多，都可能连不上；按提示更新游戏。

## 三、按现象对照

| 现象 | 常见原因 | 怎么处理 |
| --- | --- | --- |
| 一直停在加载画面 | 网络不稳、缓存损坏、服务端在维护 | 先按第二节 1~4 步走，再去看官方渠道有没有公告 |
| 提示「很抱歉，发生了一个错误，请重启游戏」 | 多为与服务端通信异常 | 重启游戏；成片出现时等一会儿再进 |
| 领奖励时闪退 | 客户端已知问题，奖励通常已经到账 | 重启游戏，去奖励列表核对一遍，不要重复点击 |
| 开社区宝箱时闪退 | 同上 | 重启后重新打开宝箱界面查看结果 |
| 合作类活动的进度和别人不同步 | 网络延迟，两边进度没对齐 | 双方都换到稳定网络多等一会儿，进度会追上 |
| 金色暴走期间的交换显示「已过期」 | 客户端状态没同步上来 | 退出游戏重进再看；仍然不对就找客服处理 |
| 装完打不开、黑屏 | 安装或资源不完整 | 见 [下载与安装教程.md](下载与安装教程.md) |
| 进去后骰子、贴纸数量看着不对 | 界面显示没刷新 | 彻底关掉重开一次；仍不对就记录数量与时间点找客服 |

## 四、什么时候该找客服，怎么找

从**游戏内**的帮助与客服入口提交，这是唯一被官方认可的通道。提交时把这些一起给上，处理会快很多：

- **玩家 ID**（游戏内个人资料里可以看到）
- 出问题的大致时间点
- 你当时的操作：在哪个界面、点了什么
- 截图或录屏
- 账号是绑在 Facebook 还是邮箱上

**不要去找自称「官方客服」的第三方账号。**官方不会在社交平台上私信向你索要账号信息或验证码。

## 五、减少复发的几个习惯

- 保持游戏更新到当前版本，落后太多的版本迟早连不上。
- 至少留出 1GB 以上的空闲存储。
- 别在网络切换的瞬间操作 —— 从 Wi-Fi 走到室外切到移动数据那几秒最容易出问题。
- 游戏长期挂在后台的话，隔几天彻底关一次，把内存和缓存放掉。
- 下线前把现金用掉、盾牌补满，这样即使回来发现被抢过，损失也在可接受范围。
