## 一、网盘里这一份安装包是哪个版本

线上手游的服务端一直在更新，网上能搜到的通常是「当前最新版」，和你手里这一份常常不是同一个版本。下面这组数值对应的是网盘里那份文件，装之前先记一下：

| 项目 | 值 |
| --- | --- |
| 版本号 | 1.74.2 |
| 包名 | `com.scopely.monopolygo.kbinstaller` |
| 安装包大小 | 145.45M |
| MD5 | `85c8eb8d0ac84f09da251651cf66b41c` |

装完之后游戏内可能提示更新，按提示走就行 —— 更新只会把版本号往上推，上面这组数值仍然是「你下载的那一份」的标识。

## 二、动手之前先确认三件事

1. **存储空间**：安装包本身 145.45M，首次进入还要下载一批游戏资源，建议至少留出 1GB 空闲。
2. **网络**：这款游戏必须联网才能玩，没有离线模式；装和进都用 Wi-Fi 更稳。
3. **系统版本**：机型太旧可能装不上或进去就卡住，最低支持的系统版本以官方商店页面当时显示的为准。

## 三、安装步骤

1. 用手机浏览器打开[大富翁Go 安装文件资源（夸克网盘）](https://pan.quark.cn/s/04fe546ccb84)，**先转存到自己网盘，再从自己网盘下载** —— 以后换手机重装直接去自己网盘取，不用再翻分享链接。
2. 等下载完成，在通知栏或文件管理器里点开这个 `.apk` 文件。
3. 系统提示「出于安全考虑，不允许从此来源安装」时，进设置允许当前这个应用（浏览器或文件管理器）安装未知应用，再返回继续。不同品牌手机的入口不一样，在设置里搜「安装未知应用」最快。
4. 等安装完成，桌面出现游戏图标。
5. 第一次点开图标，游戏会下载资源包。这一步屏幕上会有进度，别在过程中反复切后台或锁屏，等它走完。

## 四、进去之后第一件事：先绑账号

第一次进游戏会让你选登录方式。**先按 [账号绑定与换手机找回进度.md](账号绑定与换手机找回进度.md) 里的做法把账号绑上，再去玩。**不绑账号就装、装完不满意又卸载，进度很可能找不回来。

## 五、装不上或进不去时按现象对照

| 现象 | 常见原因 | 怎么处理 |
| --- | --- | --- |
| 提示「解析包错误」「应用未安装」 | 下载中断，文件不完整 | 重新下载；下完先用文件管理器看一眼大小，应接近 145.45M |
| 提示签名冲突、无法覆盖安装 | 手机里已装过同一款游戏的其他来源版本 | 先卸载旧版本再装；卸载前确认账号已经绑好 |
| 找不到「允许安装未知应用」的开关 | 系统把权限藏起来了 | 设置里搜「安装未知应用」「特殊权限」；部分品牌还要先关掉「纯净模式」或类似防护 |
| 装完点开黑屏、闪退 | 资源没下完，或机型与系统版本不匹配 | 先清缓存重进；仍不行看 [卡加载与闪退怎么排查.md](卡加载与闪退怎么排查.md) |
| 进去提示必须更新 | 服务端版本已经推进 | 按游戏内提示更新；更新后版本号高于 1.74.2 是正常的 |

## 六、几个容易踩的点

- **下载没结束就点安装**：断包安装最典型的报错就是「解析包错误」，重下比找原因快。
- **把安装包留在浏览器临时目录里**：清缓存或换机后就没了，转存到网盘更保险。
- **装完就删安装包**：万一更新失败需要重装，本地留一份能省很多事。
- **一台设备装两个来源的同一款游戏**：签名不一致，第二份会被系统直接拒绝安装。
