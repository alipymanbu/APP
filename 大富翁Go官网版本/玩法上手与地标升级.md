# 大富翁Go 玩法上手与地标升级

> 大富翁Go（MONOPOLY GO!）的推进逻辑很直白：掷骰子让棋子在棋盘上走，落到地标就买下或升级，净资产涨上去才解锁下一个棋盘。本篇讲清一次操作会发生什么、地标和盾牌怎么用、拆迁与银行抢劫怎么结算，以及新手前几天按什么顺序玩不浪费骰子。

## 一、一次操作只做一件事：掷骰子

点主界面下方那颗 `GO` 按钮，棋子按点数在棋盘上往前走。点数随机，落在哪一格决定接下来发生什么：

| 落到的格子 | 会发生什么 |
| --- | --- |
| 地标格（物业） | 可以花现金买下，或把已有的地标升一级 |
| 收益格 | 直接拿一笔游戏币 |
| 机会卡 | 抽一张卡，随机加钱、扣钱或让你再移动 |
| 铁路 | 在对手的棋盘上会触发拆迁或银行抢劫的小游戏 |
| 监狱 | 进去之后要掷出对子或等一段时间才能出来 |
| 税收格 | 按规则扣掉一部分现金 |

棋盘上每块地标都能反复升级；一个棋盘的地标全部升满后，就转到下一个主题棋盘。主题棋盘会持续增加，场景一路换下去。

## 二、净资产是唯一的总进度条

**净资产 = 你名下所有地标的价值总和。**它决定三件事：

1. 能不能解锁下一个棋盘；
2. 每达成一个新的净资产档位，会发一批奖励（里面包含掷骰次数）；
3. 拆迁与银行抢劫能拿走多少，也和你的净资产挂钩。

所以「把钱堆在手里」是效率最低的玩法：现金不变成地标，净资产不涨，收益上限就卡在原地。**能升级就升级。**

## 三、倍率：一掷多用，也一掷多耗

`GO` 按钮旁边有一个倍率按钮。它的作用是**一次消耗多颗骰子，那一格的全部收益按同样倍数放大**：

- x1：一次花 1 颗骰子，收益原样；
- 更高倍率：一次花更多骰子，现金收益、活动计分、拆迁与抢劫的金额都按倍数放大。

可选档位随进度解锁，具体上限看游戏内那个按钮当时显示的数字。新手最容易犯的两种错：一直挂 x1 慢得像爬；或者一直挂高倍率，几分钟把骰子烧光。

可操作的做法是**先在棋盘上数格子**：离最近的高价值格（地标、铁路）还有几步，就在那一步之前把倍率调上去，其余时候压低。骰子本身怎么来、怎么回，见 [掷骰次数怎么获得与恢复.md](掷骰次数怎么获得与恢复.md)。

## 四、拆迁与银行抢劫：和其他玩家互动的两个小游戏

在别人的棋盘上落到特定格子（铁路一类）时会触发这两个小游戏：

| 小游戏 | 你要做什么 | 收益怎么算 |
| --- | --- | --- |
| 拆迁（Shut Down） | 从附近玩家列表里挑一个目标，攻击对方地标 | 按小游戏里的骰子结果，再乘上你当时的倍率 |
| 银行抢劫（Bank Heist） | 翻牌，翻出三个相同图案决定抢劫规模 | 规模越高拿得越多，也有翻出「失败」的时候 |

**盾牌是唯一的防御手段。**被拆迁或被抢劫时，如果目标棋盘上有盾牌，会先消耗一个盾牌，现金不受损失。盾牌不能直接买，来自社区宝箱、快速胜利与活动奖励，能同时持有的数量有上限（有的版本是 3 个，以游戏内显示为准）。

准备下线之前，把盾牌补满、把现金尽量花在地标上，是比较省心的习惯。触发格子与结算规则会随版本调整，以游戏内弹出的说明为准。

## 五、活动与锦标赛：真正拉开差距的地方

游戏里长期并行着几种玩法：

- **锦标赛**：按你在棋盘上落到的计分格累计分数，和其他玩家比排名，名次越靠前奖励越好；
- **限时活动**：有进度条式的主线活动，也有需要和好友一起推进的合作类活动；
- **限时小玩法**：掉落类、抓取类之类的小游戏，各有自己的代币与奖励；
- **每日任务**：快速胜利那类固定日常，量不大但很稳。

奖励里最值钱的通常是**贴纸包**和**掷骰次数**，两者分别在另外两篇里展开：[贴纸相册与交换怎么玩.md](贴纸相册与交换怎么玩.md)、[掷骰次数怎么获得与恢复.md](掷骰次数怎么获得与恢复.md)。

这几层活动是同时跑的，骰子却只有一份。**哪些格子能同时推进两条进度条、什么时段该集中投**，单独写在 [活动和锦标赛怎么挑着做.md](活动和锦标赛怎么挑着做.md)。

## 六、新手前几天的顺序建议

1. **第一天**：跟着新手引导走完，把账号绑好，先熟悉格子和倍率按钮的位置。
2. **每天都做的三件事**：领每日登录奖励 → 做完快速胜利 → 收商店的免费礼物。花不了几分钟，但这是骰子最稳的来源。
3. **骰子攒着冲活动**：把骰子集中用在有主线活动、且里程碑奖励好的时段，而不是每天平均撒掉。
4. **钱不隔夜**：下线前把现金换成地标升级，既涨净资产，也少给对手留可抢的钱。
5. **尽早加好友**：好友越多，能换的贴纸越多、能参加的合作活动越多，见 [好友怎么加与合作活动.md](好友怎么加与合作活动.md)。
