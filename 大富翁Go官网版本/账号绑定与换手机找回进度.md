# 大富翁Go 账号绑定与换手机找回进度

> 大富翁Go（MONOPOLY GO!）的进度保存在线上账号里，不绑账号就等于把进度押在这一台设备上。本篇讲访客账号和绑定账号的差别、怎么绑 Facebook 或 Scopely 账号、换手机怎么把进度搬过去，以及登录后变成新号时怎么退回原账号。

## 一、访客账号和绑定账号差在哪

| 对比项 | 访客（不绑账号） | 已绑定账号 |
| --- | --- | --- |
| 进度存在哪 | 这一台设备上 | 服务器上，跟着账号走 |
| 换手机 | 带不走 | 登录同一账号即可恢复 |
| 卸载重装 | 很可能从头开始 | 正常恢复 |
| 能不能加好友 | 可以 | 可以 |
| 主要风险 | 设备丢了、坏了、恢复出厂，进度就没了 | 只要记得住登录方式就没问题 |

结论很直接：**装好之后第一件事就是绑账号**，别等攒了一堆地标和贴纸再绑。

## 二、绑 Facebook

1. 进游戏 → 打开个人资料或设置 → 找账号相关的项。
2. 选 Facebook，按提示授权。
3. 回到主界面确认账号状态已经是「已连接」。

**绑之前先确认手机上登的是你自己的 Facebook 账号**；绑错了账号，进度会跟着那个账号走，后面要退回原账号就麻烦了。

## 三、绑 Scopely 账号（邮箱）

Scopely 是这款游戏的发行方，它有一套自己的账号体系，多数游戏都能用邮箱登录，也是不依赖 Facebook 的另一条备选路径。

- 新版登录流程已经改成**无密码**：填邮箱 → 收一封验证码邮件 → 用验证码登录，不再要求你设密码。
- 入口和具体文案以游戏内当时显示的界面为准。
- 收不到验证码时，先看垃圾邮件与推广分类，再核对邮箱是否拼写正确，然后过一分钟再点一次重发。

## 四、换手机怎么把进度搬过去

1. **在旧手机上先确认已经绑定**（Facebook 或 Scopely 邮箱，至少有一个）。
2. 新手机按 [下载与安装教程.md](下载与安装教程.md) 装好。
3. 新机第一次打开会走新手引导，**把引导走完** —— 账号登录的入口就在引导之后，跳不过去。
4. 进设置 → 账号，用旧机上绑定的那个方式登录。
5. 登录成功后，地标、现金、贴纸、净资产都会回来。

一条容易踩的坑：如果新机上**先用访客身份玩了一段**再去登录旧账号，登录之后屏幕上会变成旧账号的内容，那几天的访客进度**没法合并进来**。所以新机装好就登录，**先登录再玩**。

## 五、登录后变成新号、进度不见了

官方帮助里的说法是：进度一般没有被删，最常见的原因是你登进了另一个账号，或者根本没登录。按这个顺序处理：

1. 检查当前登录状态：设置 → 账号，看登的是不是你以为的那个号。
2. 退出到登录界面，用**原账号**重新登录。
3. Facebook 方式的话，确认手机上登的也是原来那个 Facebook 账号。
4. 以上都不行，就找游戏内客服。**报两个用户名最有效**：原来的用户名，和现在屏幕上显示的用户名 —— 官方就是靠这两个定位你的账号。

## 六、官方明确说过做不到的事

- **账号不能合并**：两个账号的进度、现金、道具不能互相转移，只能挑一个继续玩。
- **道具不能跨账号转移**：贴纸、金币这类东西不能从 A 账号搬到 B 账号。
- **同一账号可以多设备登录**：绑好之后手机和平板登同一个账号，进度是同步的，但别同时在同一台设备上开两个账号玩。
- **注销要主动申请**：游戏内帮助入口进去提交，注销之后原账号的数据不再可访问，做之前想清楚。

## 七、给账号加一道保险

- **记下玩家 ID**：游戏内个人资料里能看到，找客服时报这个定位最快。
- **记住当初用的是哪种登录方式**（Facebook 还是邮箱），并保证那个账号本身还能正常登录 —— 邮箱被停用、Facebook 账号登不上，都会连带游戏进不去。
- **账号信息只填在游戏内的官方登录界面**，不要交给任何第三方页面或自称客服的人。
