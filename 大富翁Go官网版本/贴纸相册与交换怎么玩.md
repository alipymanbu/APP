## 一、相册长什么样

- 一个**相册**分成若干**套装**，每套固定 9 张贴纸。
- 贴纸按稀有度分 1 到 5 星，越高的越难开出来。
- 另有一类是**金色贴纸**，通常 4 到 5 星，规则和普通贴纸不一样（见第四节）。
- 相册是**按赛季走**的：当前赛季结束后会换新相册，旧的套数不会再计入进度。
- 相册功能要账号等级升到 15 级左右才开放，新手前几天看不到入口是正常的。

## 二、贴纸包从哪来

| 来源 | 大概出什么 |
| --- | --- |
| 每日登录奖励 | 小包为主 |
| 快速胜利的周进度条 | 一周做满给一包品质较高的 |
| 商店免费礼物（每 8 小时） | 小包为主，偶尔带更好的 |
| 活动与锦标赛的里程碑 | 中高品质包，是高品质包的主要来源 |
| 锦标赛排名靠前 | 高品质包 |
| 社区宝箱 | 不定，和好友一起攒出来的 |
| 完成套装 / 完成相册 | 掷骰次数与其他奖励 |
| 星值保险库 | 固定搭配的包，见第五节 |
| 商店里的付费同捆包 | 直接用真实货币购买 |

**中高品质包几乎都绑在活动进度上**，所以开包效率的高低取决于你怎么安排活动顺序，这部分见 [活动和锦标赛怎么挑着做.md](活动和锦标赛怎么挑着做.md)。

## 三、日常交换怎么操作

1. 打开相册，找到右上角标着份数的贴纸 —— 有重复的才能送。
2. 点开这张贴纸，选「发送给好友」。
3. 从好友列表里勾选要送的人，发出。
4. 对方在通知里确认后，贴纸到账；你这边扣掉一张重复。

几条规则要知道：

- **只能送重复的**：每种贴纸自己至少得留一张，剩下一张才能送。
- **每天有次数上限**（常见是 5 次），当天用完就得等第二天，不累积。
- **双方必须是游戏内好友**，所以交换的前置条件是先加好友，做法见 [好友怎么加与合作活动.md](好友怎么加与合作活动.md)。
- 一般只能一对一换；想用多张普通贴纸换一张稀有贴纸，要和对方分两次走流程。

## 四、金色贴纸：平时换不了，只在限定窗口能换

金色贴纸不参与日常交换，官方会不定期开一个限时窗口（Golden Blitz）集中放开：

- 每次窗口**只放开两张指定的金色贴纸**可以交换，不在名单里的照样不能换。
- 窗口时长按小时计（常见是 24 小时上下，以游戏内公告为准）。
- 窗口内的金色交换**单独计次**，不占用你每天的普通交换次数。
- 能不能换上，取决于你手里有没有**这两张之一的重复**。名单由社区投票选出，官方会在 Discord 与 Facebook 上提前公布，想换就提前盯着。
- 窗口结束后，交易请求里没被确认的会显示为已过期；遇到这种情况退出游戏重进一次再看，仍然不对就找客服。

## 五、星值与保险库

- **重复贴纸可以折成星值**，星越高，能开的保险库档位越高。
- 保险库里装的是掷骰次数加高品质贴纸包，是「重复贴纸换资源」的主要出口。
- 门槛按档位递增（常见分蓝库、紫库两档），**每 24 小时只能开一个库**。
- 档位与内容会随版本调整，开之前看一眼游戏内那个界面的说明。
- 保险库只能给你更多开包机会，**开出什么仍然是随机的**，不保证拿到你缺的那一张。

## 六、自选贴纸和「开包加成」别搞混

- **自选贴纸（Wild Sticker）**：拿到之后可以直接指定兑换相册里缺的那一张，**金色贴纸也能兑**。它一般在合作类活动、竞速类活动一类的奖励里出。要注意它是**拿到就得立刻用**的，留着不用可能错过窗口，所以缺哪张最好提前想好。
- **开包加成（Sticker Boom）**：只影响这段时间里开包能拿到的贴纸数量，**它并不等于金色贴纸可以随便换**。金色贴纸能不能交易，只看金色暴走那个窗口，见第四节。
- 两者的区别记住一句话就够了：**开包加成改的是「开包」，金色暴走改的是「交换」**。

## 七、找不到人换贴纸怎么办

- **优先现实里的亲友**：交换需要对上具体某一张，陌生人互相匹配效率很低。
- 官方 Facebook 有贴纸交换群，官方 Discord 也有交换频道，游戏内公告会给出入口，适合找愿意一对一互补的玩家。
- 防骗要点，越简单越有效：
  - 贴纸只能走游戏内的赠送流程，**别为了换贴纸把账号、密码、验证码给任何人**；官方不会私信问你要这些。
  - 不接受「先给东西再给贴纸」「先给贴纸再给东西」这类场外交易，场外交易出问题没有任何保障。
  - 对方催得越急，越要慢下来核对对方昵称再确认。

## 八、每天的收集节奏

1. 上线先开商店免费礼物和当日贴纸包，把能拿的包拿掉。
2. 看一眼相册里缺哪几张，把重复的记下来。
3. 有重复就先问一圈好友谁缺 —— 每天的次数当天用完就没了。
4. 有金色窗口开放时，先确认自己有没有名单上那两张的重复，有的话当天就把交易发出去。
5. 相册临近赛季结束时，先把能开的保险库开掉，别压着星值等新赛季。
