## 一、注册一个账号

1. 打开应用，先过入口选择那一层（节点 / 线路），进到登录页。
2. 登录页上找「注册」或「没有账号，去注册」的入口。
3. 按页面要求填写注册信息、设置密码，完成验证。
4. 页面也常提供第三方账号快捷登录（比如用某个社交账号一键登录）。用哪种方式取决于你看到的登录页提供了什么 —— 不同版本开放的入口不完全一样，以你屏幕上的选项为准。
5. 注册成功后会自动进入个人中心或首页，这时再去广场挑角色，一般就不会再被拦住了。

想先看看好不好用，也可以先用游客 / 免登录状态进广场试聊，但游客状态下角色收藏、聊天记录保存这类功能通常受限，想长期用还是建议注册。

## 二、登录不上的常见原因

| 现象 | 先检查什么 |
| --- | --- |
| 收不到验证码 | 号码是否填错、是否被短信拦截、稍等 60 秒再点重发 |
| 提示密码错误 | 大小写、输入法是否带空格；确认后走「忘记密码」 |
| 第三方登录点了没反应 | 对应社交 App 是否已登录、是否被系统限制后台唤起 |
| 一直转圈进不去 | 回上一层的入口选择换一个线路，或换网络环境（见排查篇） |

「忘记密码」的入口一般在登录页文字链上，按提示完成身份验证后即可重设。

## 三、换手机或重装之后

账号下的角色库、聊天记录这类数据是跟着账号走的，不在手机本地。所以换设备的正确做法是：

1. 在新设备上装好同一份应用。
2. 用原来的账号登录，而不是重新注册。
3. 登录后进「我的角色 / 我的对话」确认收藏与历史对话是否回来了。

只重装不换号（卸载后重装）也一样，用原账号登录即可，不需要提前备份手机本地文件。只有一件事要留意：**同一账号不要在多台设备上同时长时间挂着同一段对话**，多端来回切容易让人设前后对不上。

## 四、注销与账号安全

- **注销账号**：在个人中心或「设置 → 账号管理」里找注销入口。注销后角色卡、对话记录等数据会被清除且无法恢复，操作前想清楚；怎么先把自己要留的对话导出留档，见 [聊天记录与隐私设置.md](聊天记录与隐私设置.md)。
- **密码独立**：别把这里的密码设成和邮箱、支付类应用相同的密码。
- **别在第三方站点输账号**：只有应用内的登录页才是官方登录入口。任何要求你在网页上输入这个应用账号密码的页面，都不要填。

## 五、关于邀请与奖励

平台侧有邀请好友的活动，形式上一般是生成你的专属邀请链接、好友通过链接注册后双方获得体验奖励。具体的奖励内容与规则会变动，本文不写死数字 —— 以应用内的活动页面或官方渠道当时的说明为准。
