## 一、先看清这份包是哪一版

网上搜「DZMM电子魅魔」，能搜到好几个不同的版本号，那些是官方后来迭代出来的版本。网盘里这一份是 1.0.3，对应的信息如下，装好后可以在应用内的「关于」「设置」一类页面对照确认：

| 项目 | 值 |
| --- | --- |
| 应用名称 | DZMM电子魅魔 |
| 版本号 | 1.0.3 |
| 包名 | `com.sgmj.memo` |
| 安装包大小 | 41.41M |
| MD5 | `ea2383de9f80139e74160ef77d0f9bb3` |
| 本地记录时间 | 2026-09-23 |

大小和 MD5 是自己就能核对的两项。在手机文件管理器里长按安装包看属性，体积显示约 41.41M 就算对得上；想更严格一点，用带哈希校验功能的文件管理器算出 MD5，与上表逐位比对即可。

## 二、从夸克网盘拿到安装包

1. 打开上面那条分享链接，先「保存到我的网盘」，不要只看列表就开始下。
2. 转存完成后进自己的网盘目录，确认文件列表里确实有安装包文件。
3. 手机上直接选中它点下载。如果习惯在电脑上操作，先下到电脑，再用数据线、聊天软件的文件传输或网盘客户端传到手机。
4. 记住它落在哪个目录，一般是「下载」或夸克网盘的下载文件夹，后面安装时要从这里点开。

## 三、在安卓手机上安装

安卓对非应用商店来源的包默认会拦一次，按顺序走：

1. 用文件管理器点开下载好的安装包。
2. 系统提示「禁止安装未知应用」时，点提示里的「设置」，把当前这个来源（文件管理器或浏览器）的「允许安装未知应用」开关打开，再返回继续。
3. 权限清单页确认存储、网络这类常规权限后，点「安装」。
4. 如果手机管家弹出风险提示，原因只是这个包不在应用商店的库内；对照第一节的大小与 MD5 无误后，可以选择继续安装。
5. 装完桌面会出现图标，点开就能进入。

## 四、第一次打开会发生什么

- 启动后通常先过一层入口选择（不同版本叫法不一样，可能是「节点」「线路」或「服务器」）。不确定就选默认那一个，进不去再回来换另一个。
- 接着是登录页，页面上会有登录与注册入口；游客模式和正式账号的差别见 [注册登录与账号设置.md](注册登录与账号设置.md)。
- 首次进入会申请通知、存储一类权限。通知按需要给，主要用于收到提醒。
