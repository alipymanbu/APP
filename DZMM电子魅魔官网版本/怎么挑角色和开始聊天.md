## 一、进广场挑一个角色

广场（有的版本叫「社区」或「探索」）是浏览别人分享的角色卡的地方，也是新手最快能聊起来的位置：

1. 底部导航切到广场页。
2. 页面上方通常有分类或标签，先按题材粗筛一遍 —— 悬疑、古风、科幻、日常陪伴这类分类能帮你快速缩小范围。
3. 想找具体的角色，用页面顶部的搜索框输入关键词，比如角色名或题材词。
4. 点进角色详情页，先看简介、标签和开场白，判断合不合口味。
5. 觉得合适就点「开始对话」或「使用」；也可以先「收藏」，之后在「我的角色」里再聊。

## 二、把角色收进自己的库

- 详情页上的收藏 / 添加按钮会把角色放进「我的角色」列表，之后不用每次回广场找。
- 收藏的角色如果原作者后来改了设定，你这边看到的内容可能跟着变；想固定住某一版，做法是把它导出成自己的角色卡，见 [角色卡怎么创建与导入.md](角色卡怎么创建与导入.md)。

## 三、聊天界面上的几个按钮

进到对话页之后，能频繁用到的操作是这些：

| 操作 | 位置 / 说明 |
| --- | --- |
| 发送消息 | 底部输入框，输入后点发送或回车 |
| 查看 / 重新生成回复 | 消息旁或左下角通常有个「重新生成」类图标，对不满意的回复可以让它重来 |
| 对话样式与气泡效果 | 对话框下方的设置按钮里，可以调气泡样式这类显示项 |
| 切换模型 | 对话页顶部或设置里，切换后回复风格会变，历史记录保留，详见 [模型切换与音色设置.md](模型切换与音色设置.md) |
| 查看历史对话 | 「消息」或「我的对话」页，可以接着上次的进度继续 |
| 重置剧情 / 改已发内容 | 剧情跑偏时用对话内的重置剧情；长按自己的消息通常可以修改或重发 |
| 我的设定 | 右上角菜单里，填你自己在剧情里的身份（名字、与角色的关系），之后角色会照这个称呼你 |

## 四、同时跟多个角色聊

应用支持并行开多个对话线程，也就是不同角色各聊各的、互不打断。用法上就一条经验：**每个角色的对话单独一条线，不要把两个角色的剧情写进同一个窗口**，否则模型的上下文容易串，人设也容易崩。想切换剧情线，就在同一角色下新建一条对话，而不是在旧对话里硬拐弯。

这是「各聊各的」那种并行。如果你要的是**几个角色待在同一个场景里互相回应**，那是另一种玩法，见 [群聊派对怎么用.md](群聊派对怎么用.md)。

## 五、聊不顺的时候

- 角色一直不接话或跑题：先看是不是卡在网络（见 [常见问题与排查.md](常见问题与排查.md)），再考虑换一个模型试。
- 人设前后不一致：多数是上下文变长之后的正常现象，处理办法是重申关键设定，或新建一条对话重开。
- 想要一个广场里没有的角色：自己建一张，见 [角色卡怎么创建与导入.md](角色卡怎么创建与导入.md)。
