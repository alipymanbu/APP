## 一、角色卡里到底装着什么

角色卡是这个应用的核心概念，它把一个虚拟角色的身份、性格和开场方式打包在一起。一张卡通常包含这几项：

| 字段 | 作用 | 写不好会怎样 |
| --- | --- | --- |
| 角色名称 | 对话页与列表里的称呼 | 只影响显示，无所谓 |
| 类别 / 标签 | 决定别人能不能搜到你 | 标签太冷门，等于没人找得到 |
| 头像 / 背景图 | 视觉部分 | 留空也能用，只是列表里不好认 |
| 详细人设 | 背景故事、性格、价值观、说话习惯 | 写得空，回复就飘 |
| 开场白 | 对话开始时角色说的第一句 | 决定整段对话的基调 |

## 二、创建一个自己的角色

不同版本入口名称略有差别，路径基本是「加号 / 创作 → 创建角色」：

1. 在首页或聊天页点右上角或底部的加号，选「创建角色」。
2. 填角色名称、类别，按需要加自定义标签。
3. 上传头像和背景图。
4. 写人设，这是最花时间的一步，写法和要点见下一节。
5. 填写开场白。
6. 保存。如果版本带审核流程，公开到社区前需要提交审核；不公开则只在自己账号里用。

免费账号能建的角色卡数量有限（第三方资料里出现过「免费 5 张、会员 50 张」这类说法，配额会调整，以应用内显示为准），建之前想清楚哪几张值得留着。

## 三、人设怎么写才不崩

- **用一致的视角写**：要么全用第三人称描述，要么全用第一人称自述，别混。
- **核心特质别互相打架**：写「高冷」又写「话痨」，模型会挑一个执行，结果每次聊天性格都不一样。
- **给具体反应，不要给形容词堆砌**：「被夸奖时会先否认再小声承认」比「很可爱」有用得多。
- **划清边界**：可以写明角色不会聊的话题，减少跑偏。
- **开场白定调**：第一句是第三人称旁白还是角色对你说的话，会影响整段对话的叙述方式，要和你想要的玩法一致。

背景类的设定（地名、组织、历史事件）不建议全往角色卡里塞 —— 角色卡越臃肿，越容易把人设本身冲淡。这类内容拆成世界书更合适，做法见 [世界书怎么配置.md](世界书怎么配置.md)。

## 四、导入外部的角色卡

应用支持导入外部角色卡，常见两种格式：

- **PNG 角色卡**：外表是一张角色立绘，人设数据藏在图片的元数据块里，所以它既是图片也是配置文件。
- **JSON 角色卡**：纯文本，没有人设图，导入后会配一个默认头像。

导入路径一般是角色管理页或「+」菜单里的「导入」，选中文件即可，系统会自动读取设定。

### 导入失败先看这两点

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 提示没有角色数据 / 解析失败 | 图片被社交软件压过，元数据被剥掉了 | 让对方用「文件」方式发原图，或从角色卡分享站点用下载按钮取原始文件 |
| 要求输入密码 | 这张卡被作者加密了 | 找作者要解密密码，输错会提示解密失败 |
| 导入后设定错位 / 乱码 | 卡本身字段不完整 | 换一张卡，或把 JSON 用文本编辑器打开核对字段 |

## 五、导出与分享自己的卡

想把自己建的卡给别人用，去角色管理页：

1. 进「角色 / 我的角色」，点开目标角色。
2. 找「导出角色卡」或「分享」按钮，部分版本在右上角菜单里。
3. 选导出方式：保存为图片（会存进相册）或生成分享链接（复制后发给别人）。
4. 对方拿到链接或图片后，按第四节的方式导入即可。

导入到别人设备上的卡，设定以导出那一刻为准，之后你在本地的修改一般不会同步过去。

搞定角色之后，下一步通常是把模型和音色调到顺手，见 [模型切换与音色设置.md](模型切换与音色设置.md)。
