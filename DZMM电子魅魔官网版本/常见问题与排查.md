## 一、安装类

| 现象 | 先查什么 | 再做 |
| --- | --- | --- |
| 提示「解析包出错」 | 安装包是不是完整的 41.41M | 回网盘重新下载，别用被中断过的包 |
| 提示「禁止安装未知应用」 | 是系统拦截，不是包有问题 | 在提示里点设置，给当前来源打开「允许安装未知应用」 |
| 手机管家报风险 | 这个包不在应用商店库内 | 核对版本、大小、MD5 无误后继续安装 |
| 提示系统版本过低 | 设备系统太旧 | 换一台较新的安卓设备，或更新系统 |
| 安装按钮点了没反应 | 存储空间不足 | 清出至少几百兆空间再试 |

## 二、登录类

| 现象 | 先查什么 | 再做 |
| --- | --- | --- |
| 收不到验证码 | 号码填错、被短信拦截 | 等 60 秒重发；换一次网络再试 |
| 密码错误 | 大小写、输入法空格 | 走「忘记密码」重设 |
| 点了登录一直转圈 | 当前线路不通 | 回入口选择换一个节点，或切 Wi-Fi / 流量 |
| 第三方登录没反应 | 对应社交 App 未登录或后台被限制 | 先打开那个 App 登录，再回来重试 |

## 三、使用类

| 现象 | 先查什么 | 再做 |
| --- | --- | --- |
| 发消息后一直不回复 | 网络是否正常，换节点能不能通 | 换网络 / 换线路；仍不行就退出重进应用 |
| 回复很敷衍、特别短 | 是不是把回复字数限制调小了 | 在个人中心把字数上限调大 |
| 角色答非所问、人设崩 | 对话是不是太长了 | 重申关键设定，或新建一条对话重开 |
| 角色把之前的事记混了 | 记忆条目里存了错的内容 | 去角色设置里查看并删除对应记忆条目 |
| 界面卡顿、滑动掉帧 | 后台程序太多、机身发热 | 清后台、降画质类显示特效 |
| 打开就闪退 | 系统版本或权限异常 | 清应用缓存后重开；仍闪退就卸载重装（记录在云端，不会丢） |
| 耗电明显变快 | 长时间挂在前台语音或绘画 | 用完直接退出，而不是一直留在后台 |

## 四、语音与创作类

| 现象 | 先查什么 | 再做 |
| --- | --- | --- |
| 开了语音没声音 | 系统静音、媒体音量为 0 | 调媒体音量，确认没连错蓝牙设备 |
| 音色列表点不动 | 该音色是否已下载 / 需要网络加载 | 换网络重试，或换一个音色 |
| 绘画生成失败 | 提示词是否为空、是否超长 | 精简提示词后重试；等待时间长属于正常 |
| 自定义模型报错 | 密钥是否填错、余额是否用完 | 核对密钥与模型名，回你接入的那个服务商查额度 |

## 五、账号类

| 现象 | 处理 |
| --- | --- |
| 换了手机，收藏和记录没了 | 大概率是重新注册了新账号，退出后用原账号登录 |
| 想彻底删掉数据 | 在「设置 → 账号管理」注销账号，操作不可逆，先导出需要的对话 |
| 想换绑手机号 / 改密码 | 在个人中心的账号设置里操作，按页面提示验证 |

## 六、还解决不了怎么办

先把问题归到上面哪一类，再确认一件事：**你装的版本是不是 1.0.3**（判断方法见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)）。不同版本的界面与入口差别不小，排查前先对一下版本，能省掉很多来回。版本确认无误、上面几类都试过仍不行，就去应用内的帮助 / 反馈入口提交问题，并在描述里带上版本号和机型，方便定位。
