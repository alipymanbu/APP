## 一、世界书解决什么问题

角色卡写的是「角色是谁」，世界书写的是「世界长什么样」。它把地名、组织、门派、历史事件这类设定拆成一条条的条目，每条挂几个触发词 —— **对话里出现了对应词，这条设定才会被带上**。

好处是设定可以写得很厚，却不占每次对话的开销：不提就用不上。

## 二、什么时候该用它

- 你的故事有大背景（国家、门派、公司、势力关系），塞进角色卡里会把人设撑爆。
- 多个角色共用同一套背景，不想在每个角色卡里重复抄一遍。
- 有专有名词，希望角色每次都按统一设定解释，而不是自由发挥。

## 三、配置步骤

入口名称随版本略有差异，一般在 AI 仓库或创作页里，流程是：

1. 新建一个世界书，起个容易认的名字（比如按故事名）。
2. 在里面新建条目，每条包含两部分：**触发词**（关键词）和**内容**（这条设定本身）。
3. 触发词可以填多个同义词，命中任意一个就生效。比如「青云门」可以同时写「青云」「青云宗」。
4. 把世界书绑定到具体角色，或设成所有角色共用。
5. 回到对话里验证：说一句包含触发词的话，看角色的回应里有没有用上这条设定。

## 四、写条目的四条规则

| 规则 | 说明 |
| --- | --- |
| 触发词要具体 | 写「青云门」而不是「门」这种到处都会出现的字，否则每轮都被触发 |
| 一条只讲一件事 | 「青云门的位置」和「青云门的掌门」分两条，改起来不影响彼此 |
| 内容写成事实 | 写「青云门在三年前灭门」，不写「青云门很神秘」，后者对模型没有约束力 |
| 不要全设成常驻 | 常驻条目等于每次都带，多了就把对话本身挤掉了 |

## 五、不触发怎么查

| 检查项 | 说明 |
| --- | --- |
| 有没有写触发词 | 漏填触发词的条目永远不会被带进来 |
| 条目是否启用 | 新建后忘了开启、或保存失败的情况都有 |
| 有没有绑定到当前角色 | 世界书建在账号里，但没挂到正在聊的角色上就不会生效 |
| 触发词是不是太泛 | 太泛会一直触发，太生僻则永远不触发，取中间值 |
| 内容是不是太长 | 单条过长会把上下文占满，导致后续内容被挤掉，精简后重试 |

如果试过以上几项仍不生效，结合 [常见问题与排查.md](常见问题与排查.md) 里的记忆类条目一起排查 —— 世界书不生效和「角色忘了设定」在现象上很像，但前者是配置问题，后者是上下文长度问题。
