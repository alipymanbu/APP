## 一、装不上

**提示「已阻止安装」或安全提醒**
Android 8 及以上对安装来源是按应用逐个控制的。到设置 → 应用 → 找到你用来打开安装包的那个文件管理器 → 安装未知应用 → 允许，再回到文件管理器重新点开 APK。

**提示「解析包时出现问题」**
先怀疑文件不完整：安装包在下载或传输过程中被截断了。删掉本地这份，从 [Root Explorer 安装文件资源（夸克网盘）](https://pan.quark.cn/s/37d883b91bc1) 重新下载一份再装。同时确认下载下来的确实是 `.apk` 结尾的文件，而不是被浏览器改成了压缩包或跳转页。

**提示「应用未安装」或与已有版本冲突**
手机上已经存在一个包名相同的版本。先到设置里把旧的卸载（如果系统不让卸，说明它是预装进系统目录的，要用文件管理器删掉系统目录里的那份），再装新的。

**装完在桌面找不到图标**
去应用完整列表里找，或者用系统设置里的搜索搜「Root Explorer」。部分启动器会把新应用收进二级菜单。

## 二、用不了

**看不到 `/data`、`/system` 里的内容，列表是空的**
先按 [没root能用哪些功能.md](没root能用哪些功能.md) 第三节的三条办法确认到底有没有 root。有 root 但仍空白，去授权管理工具里找 Root Explorer 的条目，把授权改成允许，再重启一次应用。

**提示 su 程序版本过旧，或授权工具没有响应**
授权工具（Magisk、SuperSU 一类）本身太旧，或者它给 Root Explorer 的授权记录是坏的。先在授权工具里删掉 Root Explorer 那条记录让它重新申请一次；授权工具本身版本过旧则建议更新。

**应用一启动就闪退**
先清一次应用数据再打开，排除历史配置损坏；清完依旧闪退，基本是这一版与本机系统不兼容。2.16 是较早的版本，在很新的系统上出现闪退并不意外——普通文件操作改用系统自带文件管理器也能完成，需要 root 的功能则要另找工具。

## 三、写不进

**挂载读写失败，或复制到系统目录报权限错误**

按顺序确认三件事：

1. 授权工具里确认已经放行（不是只点过一次弹窗，而是记录里状态为允许）。
2. 目标分区确实处于可写状态——看路径栏右侧的 `r/w`，切换之后再操作一次。
3. 上面两条都成立仍然失败，就是系统层面禁止写入。Android 10 及以上的机型常见这种情况，属于设计限制而非操作错误，详见 [系统目录读写与权限修改.md](系统目录读写与权限修改.md) 第五节。

**在 `/sdcard` 里也写不了（Android 11 及以上）**
系统对文件管理器的存储权限收紧了。到设置 → 应用 → Root Explorer → 权限 → 文件与媒体，选择「允许管理所有文件」；`Android/data`、`Android/obb` 还要在应用内按提示单独授权，系统更新或清数据之后需要重新授权。

## 四、操作失败

**删除或移动失败**
两类常见原因：文件正被某个应用占用（先关掉相关应用，或重启手机再试）；目标分区剩余空间不足（移动是「先写后删」，空间要够装下整份）。复制同理。

**粘贴后看不到结果**
先确认你粘贴的位置和刚才复制的来源是不是同一个目录，再看是不是粘到了另一张存储卡（外置卡）上。大文件复制过程中退出应用可能被中断，回目标目录比对一下文件大小是否与源文件一致。

**中文文件名乱码、缩略图不显示**
属显示层问题，不影响文件本身。文件名乱码多与压缩包内的编码有关，换工具解压；缩略图不显示通常是该目录文件太多，或这个格式不被识别。

## 五、安全提醒（比上面任何一条都重要）

修改系统目录里的任何东西之前，先把原件复制一份到用户存储。上面那些「操作失败」都能重试，唯独系统文件被改坏之后，手机可能连开机都困难——那一步只能靠恢复模式或刷机解决。
