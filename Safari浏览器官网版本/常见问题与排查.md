# 常见问题与排查

> 这一篇按「你看到的现象」组织：闪退、页面打不开、下载的文件不见了、历史记录怎么清、安装被拦下、广告还在弹。每一步都标了会不会清掉你的收藏，按顺序做，不用一步到位。

排查前先记住一条原则：**先做不会丢数据的操作，能不动「清除数据」就不动。** 下面每一节都会标出这一步的代价。

## 一、打开就闪退

按代价从低到高做：

1. **完全关掉再开**。打开最近任务列表，把 Safari浏览器 那一张卡片划掉，重新点图标进入。
2. **重启手机**。闪退有一半是系统资源或残留进程的问题，重启能解掉。
3. **清缓存**（不丢收藏、不丢历史）。路径：`设置 → 应用 → 应用管理 → Safari浏览器 → 存储`，点**清除缓存**。清完再打开。
4. **确认安装包是完整的**。回到文件管理器核对那份 APK 的体积是不是 3.77 MB 左右，不是就删掉重取一份。
5. **卸载重装**（会丢收藏和设置）。这一步之前，先把自己要留的网址抄出来。

如果五步都做过、换了几次安装包还是闪退，多半是这个版本和你这台机器的系统版本合不来，换回手机自带浏览器更省事。

## 二、网页打不开或一直空白

先分清是**所有网站都打不开**还是**只有某一个网站打不开**，两者的处理路子完全不同。

**只有一个网站打不开：**

- 换一个浏览器打开同一个网址。别的浏览器能开，说明是这个网站对这款浏览器的兼容问题，没有太好的办法，只能换浏览器看；
- 你输入的地址是否完整（少了 `www.`、多了空格都会开不了）；
- 这个网站本身可能正在维护，隔一会儿再试。

**所有网站都打不开：**

1. 先在别的应用里确认网络是通的（比如刷一下短视频）；
2. 在 WiFi 和移动数据之间切换一次 —— 很多「打不开」其实是某一个网络本身有问题；
3. 连的是需要认证的公共 WiFi（酒店、机场），先在系统的浏览器里完成登录页；
4. 手机系统的**日期和时间**是否准确。时间偏差太大时，带证书的网站会直接拒绝连接，表现就是一直空白；
5. 回到 `设置 → 应用 → Safari浏览器 → 存储`，**清除缓存**；仍然不行再考虑清除数据（见下一节）。

## 三、下载的文件找不到

浏览器下载的文件默认落在手机的「下载」目录里，但不同版本和不同系统上位置会变，按下面顺序找：

1. **先看保存路径**。到浏览器的设置里找「下载」相关项，页面上通常会写明当前的保存目录，部分版本还可以在这里改成你顺手的位置。
2. **用文件管理器搜文件名**。打开系统自带的文件管理器，进「内部存储」，在搜索框里输入文件名的一部分。这是最快的办法，不用猜目录。
3. **注意安卓 11 之后的限制**。如果你的系统是安卓 11 或更高，应用自己的目录（`Android/data/...`）普通文件管理器可能打不开。想看这类目录，用系统自带的文件管理器，或者把手机连到电脑上查看。
4. **确认下载真的完成了**。回到浏览器的下载列表看状态，没下完的话自然找不到文件。

把下载目录固定成一个你熟悉的位置（比如内部存储根目录下的「Download」），以后就不用每次找了。

## 四、想清掉历史记录和缓存

「清缓存」和「清除数据」是两件事，效果差很远，别点错：

| 操作 | 会清掉什么 | 会留下什么 |
| --- | --- | --- |
| 清除缓存 | 网页临时文件、缩略图等 | 历史记录、收藏、登录状态 |
| 清除数据 | 应用里的全部本地数据 | 什么都不留，等于刚装上 |

路径都在 `设置 → 应用 → 应用管理 → Safari浏览器 → 存储`：

- 只想让浏览器跑得利索一点、腾点空间 → 清**缓存**；
- 想彻底清空浏览痕迹 → 清**数据**，但收藏也会一起没，操作前先备份网址。

如果只是想「这次别留记录」，不用清来清去，直接用无痕浏览就行 —— 见 [无痕浏览与全屏浏览怎么用.md](无痕浏览与全屏浏览怎么用.md)。

## 五、安装时被系统或安全软件拦下

这类提示分三种，处理方式不同：

- **「禁止安装未知应用」**：这是系统对非商店来源的正常拦截。按 [下载与安装教程.md](下载与安装教程.md) 第三节把当前来源的权限打开即可。
- **手机管家 / 安全中心报「风险应用」**：这类软件对不在自家商店上架的 APK 一律提示风险。你可以选择继续安装，但要清楚这意味着安装包没有经过商店审核 —— 对网银、支付这类用途，建议改用自带浏览器。
- **提示「应用未安装」**：手机里已经有签名不同的同包名版本（`com.apple.safari`）。先卸载旧的再装。

## 六、广告和弹窗还在弹

这款浏览器带拦截规则，但拦截主要针对网页内的弹窗和横幅，做不到把一切广告都清掉：

- **拦截开关是否打开**：到浏览器设置里找与广告拦截、弹窗拦截相关的开关，确认是开着的；
- **有些广告来自网站自身**：比如视频站点的前贴片，属于网页内容的一部分，工具通常拦不住；
- **遇到诱导下载、跳转页**：不要点页面上的「立即安装」「点击继续」这类按钮，直接返回或关闭标签页。

## 七、都试过还是不行

按这个顺序收尾：

1. 卸载后重新取一份安装包再装一次（确认体积是 3.77 MB）；
2. 换一台手机试同一个安装包，用来区分「是包的问题」还是「是我这台机器的问题」；
3. 记录清楚你遇到的现象 —— 什么操作、什么提示、什么型号的手机、系统版本多少。带着这些信息再去找解决办法，比只说「打不开」有效得多。
