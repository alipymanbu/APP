## 一、装之前先对一下版本

网盘里那份安装包，和你在网上搜到的「最新版」不一定是同一版 —— 网上能搜到的通常是各下载站自己更新的，而这里发出去的固定是下面这一版。文档里凡是出现版本号、包名、体积，都以它为准：

| 项目 | 值 |
| --- | --- |
| 版本 | 2.0.1 |
| 包名 | `com.apple.safari` |
| 安装包体积 | 3.77 MB（3,951,457 字节） |
| MD5 | `10c152cc9816393939d70075495af940` |

装完想确认拿到的是不是这一版，看两处就够：

1. 系统「设置 → 应用 → 应用管理 → Safari浏览器」，点进详情页能看到版本号；
2. 用文件管理器长按那个 APK 文件，看它的体积是不是 3.77 MB 左右。

体积只有 3.77 MB 是这款软件的常态，别因为「安装包怎么这么小」就以为下载没完成；反过来，如果你下回来的文件有几十 MB，那多半不是同一份东西。

## 二、把安装包取到手机上

安装包在 [Safari浏览器 安装文件资源（夸克网盘）](https://pan.quark.cn/s/172da872b73e) 里，用手机或电脑打开都能转存。取包和传包有两种常见走法，选顺手的：

- **手机直接下**：在手机上打开网盘页面，转存后从网盘 App 里下载。下载完成后在网盘 App 的「传输」列表里点开文件，系统会直接问你要不要安装。
- **电脑下了再传**：电脑下载后，用数据线、微信文件传输助手、网盘同步或局域网工具把 APK 传到手机。传到手机后，用系统自带的文件管理器找到它，点一下即可发起安装。

传输过程中最容易出问题的地方是**文件名后缀被改掉**。有些传输工具会把 `.apk` 变成 `.apk.1` 或直接去掉后缀，这类文件点开不会触发安装。看到这种情况，用文件管理器把后缀改回 `.apk` 再点。

## 三、安装：绕不过的「未知来源」

这款软件不在手机自带应用商店里，所以第一次装一定会遇到系统的安全提示，这是正常流程，不是安装包出错：

1. 点击 APK，系统弹出「禁止安装未知应用」类的提示，选择**设置**；
2. 在跳转过去的页面里，把**当前这个来源**（文件管理器或网盘 App）的「允许安装未知应用」打开；
3. 返回，重新点一次 APK；
4. 安装界面会列出它要的权限，确认后点**安装**。

各家系统（小米、OPPO、vivo、华为、荣耀等）的入口名字不一样，但都在「设置 → 应用 → 特殊应用权限 / 安装未知应用」这一带，找不到就在设置里搜「未知应用」。

## 四、首次打开会要的权限

装上之后第一次运行，一般会碰到两类授权，处理方式不一样：

| 提示 | 该不该给 | 说明 |
| --- | --- | --- |
| 存储 / 文件和媒体 | 建议给 | 不给的话下载文件、保存网页截图这类操作会失败 |
| 通知 | 看需要 | 与浏览网页无关，不想收推送可以直接拒绝 |

如果当时手滑点了「拒绝」，之后不是没救：到「设置 → 应用 → Safari浏览器 → 权限」里重新打开即可，不需要重装。

还要注意一点：安卓 11 以后，应用只能看到自己目录下的文件。如果你在浏览器里下载了东西，却在文件管理器的根目录里找不到，这是系统规则造成的，不是下载失败 —— 具体去哪找，见 [常见问题与排查.md](常见问题与排查.md)。

## 五、装不上，或者装完打不开

按现象对号入座：

- **提示「解析包错误」**：APK 没下完整（传输中断）。删掉重下，核对上面表格里的体积和 MD5。
- **提示「应用未安装」**：手机上已经装过一个签名不同的同包名版本。先卸载旧的 `com.apple.safari`，再装这一版。卸载前记得先导出你要留的书签。
- **提示「与系统不兼容」**：你的安卓版本低于这款软件的要求。这款软件在部分下载站被标注为「安卓 5.2 以上」，但安卓 5.x 系统实际只到 5.1，这个标注本身就不严谨，只能当参考 —— 真实门槛以你手机上的安装提示为准。
- **装上了但一点就闪退**：先在「设置 → 应用 → Safari浏览器 → 存储」里清一次缓存再打开；仍然闪退就卸载重装。这一步的完整排查顺序写在 [常见问题与排查.md](常见问题与排查.md)。

## 六、换版本与彻底卸载

这款软件目前没有应用内自动更新，装新版就是**下载新的 APK 覆盖安装**。覆盖安装的前提是两次安装包的签名一致，正常情况下不会丢书签和设置；如果系统报「应用未安装」，说明签名对不上，只能先卸载再装，这时书签会一起清掉。

想彻底卸载干净，除常规卸载外再看一眼这两处：

- 「设置 → 应用 → Safari浏览器 → 存储」里是否还留着数据（常规卸载后系统会一并清除）；
- 用文件管理器检查内部存储目录下是否残留它创建的下载文件夹，需要就手动删。
