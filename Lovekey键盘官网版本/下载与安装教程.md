Lovekey键盘 是苏州猜猜看科技有限公司做的一款安卓手机输入法，重点不在「打字快不快」，而在把聊天回复做进了键盘里：复制对方发来的话，点一下键盘上的入口，就能拿到几条可以直接发出去的候选回复。本篇只处理安装和首次启用这一段——装完能正常打字、能调出悬浮球，就算过关。

## 一、先弄清网盘里这份包是哪一版

网上搜到的版本信息多半是发布时的最新版，网盘里这份是整理文档时核对过的那一版，两者未必是同一个版本号。下面这些值以网盘里那份包为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | Lovekey键盘 |
| 版本号 | 1.7.6 |
| 包名 | `com.fd.lovekeyboard` |
| 安装包体积 | 63.07 MB |
| MD5 | `880bc296cfbf36d761932bacaa492951` |

官方应用商店在架的版本比这一版新（截至 2026-09 已到 1.8.x～1.9.x，具体以你看到时的商店页面为准）。所以别拿商店页的版本号来核对本地这个包——对不上是正常的，不是包坏了。

安装包本体就在头部那条夸克网盘分享里，转存到自己网盘后下载即可。想顺手验一下包完不完整，可以在电脑上用校验工具算一遍 MD5，和上表一致再装；手机端下的包不方便校验，那就只看体积是否接近 63.07 MB。

## 二、装之前要核对的几件事

**第一，确认是同一个应用。** 应用市场里叫「恋爱键盘」「高情商键盘」「聊天话术键盘」的应用有一大堆，图标和名字都长得很像，但包名各不相同。系统认的是包名，这套文档对应的那个是 `com.fd.lovekeyboard`。装错了的表现是：设置里能启用的输入法列表里，出现的名字跟你以为的那个对不上。

**第二，别拿第三方下载站的最低系统版本来判断。** 官网（`https://www.lovekeyboard.com/`）只在用户协议里写明有 iOS 与 Android 两个版本，没有公开最低安卓版本；各下载站抄来抄去的数字从 3.6 到 8.0 都有，彼此矛盾，当不了依据。想知道这台手机能不能装，最省事的办法就是直接装：安卓在设备不兼容时会拒绝安装，直接提示「应用未安装」或「与你的设备不兼容」，不会给你装上半残的一版。

**第三，确认这个包是从哪来的。** 官方用户协议写明：软件可以从 Lovekey 的网站或获得授权的第三方获取；如果是从**未经授权的第三方**拿到与本软件同名的安装程序，官方无法保证它能正常使用，对由此造成的损失也不负责。所以拿到包之后，除了核对包名 `com.fd.lovekeyboard`，也顺手认一下来源。至于用起来之后哪些内容会被处理、哪些东西不要往里放，单独写在 [输入的内容会被怎么处理.md](输入的内容会被怎么处理.md)。

## 三、安装步骤

1. **转存并下载**：从 [Lovekey键盘 安装文件资源（夸克网盘）](https://pan.quark.cn/s/38ddbae94286) 把安装包转存到自己的网盘，再下载到手机。
2. **把包送到手机上**：手机端直接下载最省事；在电脑上下载的，用数据线或任意传输工具拷进手机存储。
3. **允许安装未知来源应用**：在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给用来打开安装包的那个应用（文件管理器或浏览器）打开开关。国产定制系统通常把这项收在「安全」或「隐私」分类下面。
4. **点击安装包完成安装**：系统若提示「应用未经过安全检测」或「来自未知来源」，选择继续安装即可，非商店渠道的安装包都会走这一步。
5. **手机里已有更高版本要先卸载**：安卓不允许用更低版本的包覆盖更高版本，会直接报「应用未安装」。想换成网盘里这一版，得先卸载手机里的新版，应用内的设置和登录状态会一起清掉。
6. **装完先别急着点开打字**：Lovekey键盘 是个输入法，装上只是把程序放进了手机，还得走完下面第四节的三步，系统才会真正用它来打字。

## 四、从「装上」到「能用」的三步

这三步缺一步都会出现「明明装了却用不了」：

| 步骤 | 在哪做 | 不做会怎样 |
| --- | --- | --- |
| 点「启用键盘」 | 打开 Lovekey键盘 应用，首页会有启用入口，点了会跳到系统设置 | 系统输入法列表里根本看不到它 |
| 选为当前输入法 | 系统「设置」里的输入法与键盘相关项 | 打字时跳出来的还是原来的键盘 |
| 开悬浮球并给悬浮窗权限 | 应用内的悬浮球开关 + 系统里的悬浮窗权限 | 打字能用，但快速调用那套入口出不来 |

第 2 步各家手机的菜单叫法不一样，找不到就按这个顺序试：

1. 打开系统「设置」，在顶部的搜索框里直接搜「输入法」或「键盘」，绝大多数机型能直接跳到目标页；
2. 手工找的话，通常在「语言和输入法」「系统和更新」「更多设置」「系统管理」这几类目录下，页面里的名字可能是「当前输入法」「默认键盘」「虚拟键盘」「屏幕键盘」；
3. 进到列表后先**勾选** Lovekey键盘（这一步是授权它作为输入法），再把它**设为默认**——只勾不设，打字时仍然不会用它。

第 3 步的悬浮窗权限同理：它不在应用自己的设置里，要去系统的应用权限页面，找到 Lovekey键盘，打开「显示在其他应用上层」或「悬浮窗」这一项。悬浮球的具体用法和权限给法，写在 [一键帮回复怎么用.md](一键帮回复怎么用.md)。

## 五、装完做一次最小验证

按顺序试一遍，四条都过说明安装这一关通了：

1. 打开任意一个聊天输入框（短信、微信都行），看底部弹出来的是不是 Lovekey键盘 的样子，而不是原来的键盘；
2. 在键盘上找切换键，长按或点一下，看能不能切回原来的输入法——能切回才说明它只是「多了一个可选项」，没有把系统键盘顶掉；
3. 点屏幕上的悬浮球，看能不能弹出调用面板；
4. 复制一段对方发来的话，点键盘上的回复入口，看有没有返回候选内容。第 4 条不通多半是账号或网络的问题，不是安装问题，对照 [常见问题与排查.md](常见问题与排查.md) 查。

## 六、以后出了新版本怎么升级

网盘那份分享是长期有效的：更新版本时替换的是分享里的安装包文件，**分享链接本身不变**，升级不用再去找新地址。

1. 回到本文头部那条分享，看里面的包是不是比 1.7.6 更新；
2. 直接下载新包点安装。包名相同、版本号更高时，安卓允许覆盖安装，**原来的设置和登录状态会保留**；
3. 覆盖安装报「应用未安装」，一般是新包的签名和手机里那份对不上，或者版本号反而更低——这种情况只能先卸载再装，代价是设置要重配一遍。

有一点要自己留意：它不是从手机自带应用商店装的，商店不会替这类来源的包检查更新。想保持新版，得隔一段时间回分享里看一眼；或者直接用官方应用商店渠道安装，让它自己更新——但那样装到的就是商店当前在架的新版，跟你手上这份 1.7.6 不是同一版。同一台手机上不要同时装本文这份和别的渠道的同包名安装包，签名不一致同样会报「应用未安装」。
