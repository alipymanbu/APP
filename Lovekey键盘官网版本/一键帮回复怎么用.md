# Lovekey键盘 一键帮回复怎么用

> 本篇讲这个键盘最核心的一个动作：把对方发来的话送进键盘、拿到几条候选回复、挑一条上屏发出去，以及用之前必须先具备的三个前提。

「一键帮回复」是 Lovekey键盘 区别于普通输入法的地方：你不用自己想怎么接话，把对方那条消息复制下来，键盘读这段内容，给出几条可以直接发出去的候选回复。本篇按一次真实聊天的顺序把这几步拆开讲，并说清它在什么情况下给不出结果。

## 一、四个前提，缺一个按钮点了也没反应

这四项都具备，回复才会出来；少任何一项，表现都是「点了没动静」或者「一直转圈」：

| 前提 | 为什么需要 | 怎么确认 |
| --- | --- | --- |
| 已设为默认输入法 | 键盘没被系统启用，聊天界面里调出来的就不是它 | 见 [下载与安装教程.md](下载与安装教程.md) 第四节 |
| 已登录账号 | 候选回复要连服务器取，没账号就没有结果 | 打开 Lovekey键盘 应用，看是否停在登录页 |
| 手机能联网 | 同上，地铁里信号断掉时最容易遇到 | 用移动数据或 Wi-Fi 各试一次 |
| 允许读剪贴板 | 你复制的对方那句话，是从剪贴板里读的 | 首次点回复入口时会弹权限提示，选允许 |

其中最容易忽略的是剪贴板这一项：有些系统会在应用首次读取剪贴板时弹一个提示条，如果你顺手点了「不允许」，之后就会一直读不到内容，表现是候选区空着。

## 二、一次完整操作，分四步

1. **复制对方那条消息**：在聊天界面长按对方发来的消息，选「复制」。屏幕上通常会出现一个「已复制」的提示条，看到了再往下走。
2. **调出 Lovekey键盘**：在聊天输入框位置切换到 Lovekey键盘；如果它已经在用了，直接进入第 3 步。
3. **点回复入口**：点键盘上的「一键帮回复」入口，键盘会读走剪贴板里那句话，然后给出若干条候选回复。这一步需要一点时间，等候选出来，不要连点。
4. **挑一条上屏**：点一下某条候选，它会填进聊天输入框。**这时候还没有发出去**——你可以先改两个词、换个称呼，确认顺口了再自己点发送。

最后那一下必须由你点，这一点要清楚：它给的是建议，不会替你发消息。

## 三、候选不合口味，改的是「人设」和「亲密度」

同一个对方、同一句话，候选内容会随两个设置变化：

- **人设**决定口气是热情还是克制、是正经还是开玩笑；
- **亲密度**决定分寸，也就是能不能用亲昵的称呼、能不能开玩笑。

觉得候选太油、太生硬、或者太客气，不要反复点刷新，先去调这两个设置——调法见 [聊天人设与亲密度怎么设置.md](聊天人设与亲密度怎么设置.md)。换聊天对象时（比如从同事换到对象），顺手把亲密度调一下，同一套回复用在两种关系上通常会不合适。

## 四、候选出不来时的对照表

按现象查，多数问题在前两行：

| 现象 | 常见原因 | 怎么办 |
| --- | --- | --- |
| 点了完全没反应 | 剪贴板是空的，或复制动作没成功 | 回聊天界面重新长按复制一次，看到「已复制」提示再回键盘 |
| 一直转圈后失败 | 网络断开、或登录态掉了 | 切到 Wi-Fi 再试；仍不行就打开应用重新登录 |
| 候选内容与你复制的那句无关 | 剪贴板里还是上一次复制的内容 | 系统会在切到别的应用后清空剪贴板，复制后尽快进键盘 |
| 候选里出现不认识的人名或称呼 | 对方那句话本身带指代不清的说法（「他」「那个事」） | 把上下文补进输入框再生成，或直接手动改 |
| 只有一两条、内容很敷衍 | 当前亲密度档位或人设不搭 | 换一个人设或调高/调低亲密度再试 |
| 同一句每次都给出差不多的东西 | 正常现象，生成结果本身会有重复 | 换人设或改动一下复制进去的那句话 |

## 五、把它当草稿用，比当「代笔」用更顺手

用得比较舒服的方式是：**让键盘出草稿，你来收尾**。

- 上屏后先把语气词改成你平时说话的习惯，一句话里别塞两件事；
- 涉及时间、地点、金额这类信息，一律自己核对一遍再发——候选是按对方的原话生成的，你手机里的行程它并不知道；
- 一次对话里别连续用同一套句式，连着几条都像模板，对方是看得出来的；
- **别把整段聊天记录随手往里送**。粘进去的每一句都会被拿去处理，里面夹着手机号、住址、证件照片这类内容时就先删掉——哪些内容不适合上传、给了哪些权限，写在 [输入的内容会被怎么处理.md](输入的内容会被怎么处理.md)。

需要说明的是，这套回复是按你复制进去的那段文字生成的。对方只发了「在吗」两个字时，能拿到的也就是针对这两个字的回复，不会知道你前面聊了什么——这种情况建议先自己接一两句，把话题铺开再用。
