# Lovekey键盘 常见问题与排查

> 本篇按现象查问题：键盘弹不出来、悬浮球不见、回复生成不了、装不上或要重装、卸载后还有残留，每条都给先查什么、再做什么。

Lovekey键盘 这类应用的问题，绝大多数不是「软件坏了」，而是卡在两处：系统没真正承认它是当前输入法，或者回复需要的联网与登录条件没满足。本篇把常见现象分五类整理，遇到问题先定位在哪一类，再往下查。

## 一、键盘装了也能启用，聊天时却弹不出来

按这个顺序查，多数问题在第一条：

| 先查什么 | 具体表现 | 怎么处理 |
| --- | --- | --- |
| 是否只是「勾选」了、没「设为默认」 | 输入法列表里能看到 Lovekey键盘，但打字时出来的是原来那个键盘 | 回系统输入法设置，把默认输入法改成 Lovekey键盘 |
| 当前应用的键盘切换 | 在别的应用里正常，只在某一个应用里不弹 | 在该应用的输入框里点键盘切换键，或长按输入框选输入法 |
| 系统是否限制它后台运行 | 用一阵子后突然不弹了，重启又好了 | 在系统「应用 → Lovekey键盘 → 电池/后台管理」里取消限制 |
| 是否需要重启一次 | 刚装完还没重启过 | 重启手机再试 |
| 是否被系统停用了 | 输入法列表里它变灰或消失 | 重新在列表里启用一次；仍不行就卸载重装 |

还有一种是看起来像但不一样的：**弹出的键盘样子是 Lovekey键盘，但皮肤/主题不对**——那不是弹不出来的问题，看 [主题与键盘外观怎么设置.md](主题与键盘外观怎么设置.md)。

## 二、悬浮球不出现，或者点了没反应

悬浮球要同时满足两个条件，缺一个都不显示：

1. **应用内的悬浮球开关打开了**——这个开关在 Lovekey键盘 自己的设置里；
2. **系统给了悬浮窗权限**——在「设置 → 应用 → Lovekey键盘 → 权限」里找「显示在其他应用上层」或「悬浮窗」。

两个都开了还是不见，再看这三种情况：

- **权限被系统自动收回了**。部分安卓版本对长期不用的权限会自动收回，尤其是不常开的悬浮窗权限。表现是「昨天还在、今天没了」，重新授予一次即可。
- **悬浮球被拖到了屏幕边缘之外**。贴边到极限位置时容易被手势区吃掉，试着在屏幕中间偏下一点的位置重新找它，或者重启后再看。
- **和系统的手势/悬浮球冲突**。手机自带手势球、悬浮导航这类功能会抢占同一片区域，先把系统那一个关掉再试。

## 三、回复生成不出来

这一类的现象和原因对应得很紧，照着对：

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 点下去毫无反应，候选区空的 | 剪贴板里没有内容——复制动作没成功，或系统在你切换应用时清空了 | 回聊天界面重新长按复制，看到「已复制」提示再回键盘点 |
| 一直转圈最后失败 | 网络不通，或登录态失效 | 换 Wi-Fi 试一次；仍失败就打开 Lovekey键盘 应用重新登录 |
| 候选内容和你刚复制的那句无关 | 剪贴板里留的是上一次复制的内容 | 复制后立刻切回键盘，中间不要经过别的应用 |
| 提示需要开通会员才能继续 | 非会员状态下能用的范围用完了，或该内容属于会员项 | 见 [注册登录与会员订阅.md](注册登录与会员订阅.md) 第二节 |
| 首次使用就问「是否允许读取剪贴板」，点了不允许 | 之后一直读不到你复制的句子 | 去系统权限里把剪贴板/剪贴板相关的访问放开，或卸载重装后重新授权 |

判断「是网络问题还是账号问题」有个简单办法：打开 Lovekey键盘 应用本身，看它自己的页面能不能正常加载。应用页面也转圈，是网络问题；应用页面正常、只有键盘里的回复出不来，多是登录态掉了。

## 四、装不上、或者要重新装

| 提示 | 原因 | 处理 |
| --- | --- | --- |
| 「应用未安装」 | 手机里已有更高版本，或签名与已装的那份不一致 | 先卸载手机里的旧版，再装 |
| 「解析包出错」「安装包损坏」 | 下载过程中被截断，或存的不是完整的 APK | 重新下载一份，下载完核对体积是否接近 63.07 MB（本文对应的那一版信息见 [下载与安装教程.md](下载与安装教程.md) 第一节） |
| 装完点开就闪退 | 系统安全策略拦截，或该版本与当前系统不匹配 | 在系统的「应用管理」里给它放行后重试；仍闪退说明这个版本与你的系统不合，换应用商店在架的新版本装 |

需要重新装一份时，安装文件资源仍在文首那条分享里，[Lovekey键盘 安装文件资源（夸克网盘）](https://pan.quark.cn/s/38ddbae94286) 转存后下载即可；链接是长期有效的，里面有更新版本时替换的是文件本身，链接不变。

重装前先想清楚一件事：**卸载会把应用内的设置（人设、亲密度、皮肤、登录状态）一起清掉**，重装后要重新走一遍 [下载与安装教程.md](下载与安装教程.md) 第四节的启用三步。只是想解决「某个设置不对」，别用卸载重装这一招。

## 五、彻底卸载，不留残项

只从桌面把图标删掉不算卸干净，输入法类应用通常还留着几处引用，会表现为「卸载后输入法列表里还挂着一个用不了的名字」。按顺序清：

1. 在系统「设置 → 应用 → Lovekey键盘」里选卸载；
2. 回输入法设置页，看列表里是否还残留 Lovekey 相关的项，有就删掉或停用；
3. 检查权限页里还挂着它名字的悬浮窗、通知、剪贴板这类授权项，一并收回；
4. 如果换用别的输入法，顺手把默认输入法改成那一个，避免打字时弹出「找不到输入法」。

清完之后再装回同一版本，就是一次干净的重装。

## 六、升级之后设置变了

用新版本覆盖安装时，安卓会保留应用数据，人设、亲密度这些设置一般还在；但**跨版本升级后设置项的名称、位置、默认值有可能变化**，看起来像「设置丢了」，其实是这一版换了叫法或分了新分类。逐项回应用里对一遍即可，不必重装。

只有一种情况会真的丢设置：新包和手机里那份签名对不上、被迫先卸载再装（见第四节第一条）。这种就要老老实实重配一遍。
