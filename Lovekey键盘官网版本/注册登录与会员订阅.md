Lovekey键盘 要登录才能用它的回复功能，另外还有一个叫「L+」的付费会员。本篇把账号与付费这两件事说清楚：怎么登录、哪些情况会遇到会员限制、以及订阅怎么查、怎么停。

## 一、怎么登录

按官方用户协议与隐私协议的说明，登录方式有两类：

| 方式 | 说明 |
| --- | --- |
| 手机号 | 用手机号创建账号，这是官方列出的主要方式 |
| 第三方账号 | 微信、Apple ID、Google 这类账号授权登录，官方列出的可选方式 |

首次登录通常还要补一个账号名称。这几种方式创建的账号是分开的：用手机号登录过、之后又换成微信登录，在应用看来可能是两个账号，会员和设置不一定互通。**一开始用哪种方式，后面就一直用那种**，换手机时也照原样登。

**为什么非得登录**：生成回复这一步要连服务器取结果，服务器得知道是谁在请求，所以账号是功能的前提而不是可选项。这也是为什么会出现「键盘能打字、点了回复却一直转圈」——往往不是键盘坏了，是登录态掉了。

## 二、L+ 会员是按什么周期订阅的

官方把它叫 **L+ 会员**，说法是「您可以按年或者按月成为 L+ 会员，在成为会员期间，您可以自由使用 Lovekey 的所有功能」。从这句话能推出的两件事：

1. **它是一个按期订阅的会员**，不是买断；在架的档位有连续包月、连续包季这类（具体档位与价格在应用内的购买页展示，会随活动调整，**以你打开购买页时显示的为准**）；
2. **有一部分内容在非会员状态下是受限的**，官方用「成为会员期间可以自由使用所有功能」来描述会员状态。至于具体哪些功能免费、哪些要会员、免费额度有多少，官方没有列出固定清单，以应用内当期说明为准。

会员权益以官方《Lovekey L+会员协议》为准，该协议发布在官网（`https://www.lovekeyboard.com/agreement/member.html`），里面写明会员名称与权益内容都可能在后续调整，调整前已开通的不受影响。

## 三、自动续费怎么关

订阅类服务的关键点在这里：**取消续费的入口不在 Lovekey键盘 里面，而在你当初完成支付的那个渠道里**。所以第一步是回想自己是在哪付的钱：

- **在苹果设备上开通的**：进手机的「设置」，点最上面的 Apple ID，找「订阅」，在列表里找到这项订阅并关闭自动续费。官方在订阅说明里给的也是这个路径：设置 → iTunes Store 与 App Store → Apple ID → 查看 Apple ID → 订阅。
- **在安卓上开通的**：走的是应用内购买，取消要去完成支付的那个渠道。支付宝或微信这类支付工具里一般都有「自动续费 / 免密支付」的管理入口，逐一翻一下，找到与 Lovekey键盘 相关的这一项关掉。
- **已经扣了的能不能退**：订阅费由收款渠道结算，官方和渠道的退款规则各不相同，只能在对应渠道里按它的流程申请，应用内一般没有退款入口。

关掉自动续费之后，本期的会员时长一般还会保留到该周期结束，之后不再扣费——**要在到期前处理**，扣费通常发生在到期前的一小段时间内，等到扣完再关就晚了。

## 四、只在官方渠道开通

网上能搜到代充、低价激活码、第三方店铺开的「长期会员」这类东西。后果很具体：账号权益是绑在账号上的，来源不明的兑换码可能根本进不了你的账号，进了也可能被上游回收，出问题时代充方和官方都不会替你处理。会员就在应用内的购买页开，别绕路。

另外，账号本身有找回与安全相关的流程，官方把处理规则写在用户协议和隐私协议里（`https://www.lovekeyboard.com/agreement/user.html`、`https://www.lovekeyboard.com/agreement/privacy.html`）；账号出问题时，先看应用内有没有反馈入口，官网页面底部也留了官方联系邮箱，以页面上显示的为准。

## 五、和账号有关的几个常见疑问

- **换手机后会员还在吗**：会员资格挂在登录的账号上，正常情况登录同一个账号即可，遇到没跟过来的情况走应用内反馈；
- **卸载重装会丢会员吗**：账号不变就不影响；但**重新安装后一定要用原来的方式登录**，用另一种方式登进去等于换了个账号，会看起来像「会员没了」；
- **不登录能一直打字吗**：键盘本身的输入能力不依赖登录，但生成回复、人设这些功能都需要账号，实际使用体验会大打折扣；
- **免费额度用完了怎么办**：先确认是额度用完了还是登录掉了，这两者的提示不一样。分不清时对照 [常见问题与排查.md](常见问题与排查.md) 里「三、回复生成不出来」那一节逐项查。
