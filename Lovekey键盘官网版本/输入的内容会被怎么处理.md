# Lovekey键盘 输入的内容会被怎么处理

> 本篇只讲一件事：用这个键盘时，你交出去的是什么内容、哪些东西不要往里放、给了哪几个权限，以及你在官方协议下有哪些可主张的权利。

Lovekey键盘 要把你复制的那句话变成候选回复，就必须先把内容交到服务器上处理，所以「什么内容会被处理」不是可以忽略的细节。本篇按官方《Lovekey隐私协议》与《Lovekey用户协议》里写明的内容，把它拆成可判断的几条，方便你在动手复制之前先想一秒。

## 一、官方写明会处理的信息

按官方隐私协议的分类，用这个应用时会涉及的信息大致是四类：

| 类别 | 具体是什么 | 什么时候产生 |
| --- | --- | --- |
| 账号信息 | 手机号，或微信 / Apple ID / Google 授权后拿到的昵称、头像等公开信息 | 注册、登录时 |
| 账号名称 | 你自己设置的名字 | 可选，不设也行 |
| 使用信息 | 点击、收藏、搜索、查询、浏览这类操作记录 | 使用过程中 |
| 你主动提交的内容 | 你复制、上传、导入的那部分聊天内容 | 用回复、识别、导入这类功能时 |

官方的表述是「仅会处理您使用产品或服务所需的个人信息」，并且写明注册登录与支付属于基本功能所必需——也就是账号信息这一项，拒绝提供就用不了对应功能，这不是可以关掉的选项。

## 二、聊天记录与截图：这类内容最容易越界

官方在协议里专门提醒过一件事：**你上传的聊天记录或截图里，可能包含对方的头像、昵称、联系方式、聊天内容等个人信息**，上传前要确保自己已经拿到对方的合法授权。

同时官方明确点名了几类**不要上传**的信息：

- 身份证件；
- 银行卡信息；
- 账号密码；
- 精确位置；
- 健康信息。

理由很直白——这些信息跟「生成一条回复」这个需求毫无关系，放进去只是白白扩大信息的暴露面。

给你一个动手前的判据：

| 准备复制/上传的内容 | 怎么处理 |
| --- | --- |
| 就是对方一两句话 | 正常用，这是这个功能的设计场景 |
| 整段聊天记录，里面夹着手机号、住址 | 先把这些字段删掉再送进去 |
| 对方的身份证照片、银行卡截图 | 不要上传 |
| 你自己的账号密码、验证码 | 不要输入、不要上传，任何工具都不该要这个 |

## 三、这三个权限各自意味着什么

装上之后你至少要给它三项授权，每一项都对应一个具体动作，可以自己决定要不要给、用不用时收回来：

| 权限 | 用途 | 想收紧的话 |
| --- | --- | --- |
| 读取剪贴板 | 你把对方那句话复制下来，它从剪贴板里取走 | 不用这个功能时，在系统权限里收回来即可，不影响打字 |
| 悬浮窗（显示在其他应用上层） | 让悬浮球能停在别人家应用界面上 | 平时关掉、要用时再开 |
| 联网 | 生成回复、加载人设这类内容都要走网络 | 关掉就只剩基础打字，等于不用这些功能 |

权限名目在不同系统版本里叫法不一样，以你自己手机上显示的名称为准。

## 四、你在官方协议下的几项权利

官方隐私协议里写明，除了法律法规另有规定的情况，你对自己的个人信息享有**知情权和决定权**，可以限制或拒绝对方处理你的信息，也可以要求对方解释处理规则。落到能做的动作上：

1. **想知道处理了什么**，看官方隐私协议——它按功能把「收集什么、为什么收集」逐条列了出来；
2. **不想让某类信息被处理**，对应功能不用即可（比如不复制含敏感内容的文字）；
3. **协议会变**。官方写明会根据法律变化、经营情况、软件升级等原因修订协议，**更新后的条款公布即生效**，你可以在软件里查看当前版本；不同意改动内容时，官方给的选择是停止使用。

关于未成年人，官方在用户协议里的写法是：若您是 18 周岁以下的未成年人，建议由监护人仔细阅读协议并在同意的前提下使用本产品、或向它提供信息。

## 五、两条和获取渠道有关的提醒

1. **从官方渠道或官方授权渠道获取安装包**。官方用户协议写明，你可以从 Lovekey 的网站或获得授权的第三方获取；同时写明，如果你是从未经授权的第三方拿到与本软件同名的安装程序，官方无法保证它能正常使用，对因此造成的损失也不负责。想在电脑上跑安卓版时，用模拟器或带安卓运行环境的桌面应用安装的是同一份包，这条同样适用；
2. **苹果设备上还有一层规则**。官方隐私协议里写明，苹果用户还要同时适用 Apple 的标准 EULA（`https://www.apple.com/legal/internet-services/itunes/dev/stdeula/`），订阅与退款也走 Apple 那一套流程，相关部分见 [注册登录与会员订阅.md](注册登录与会员订阅.md)。

这两条和前面几节的关系是：渠道决定了你装上的是不是这一份、账号能不能正常登；权限与上传习惯决定了内容交出去了多少。两边都留意一下，用起来就没那么多顾虑。
