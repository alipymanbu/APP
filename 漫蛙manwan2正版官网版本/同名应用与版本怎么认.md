用「漫蛙」这个名字的应用和站点不止一个：光看名字，你分不出搜索结果里哪一条是你要的那份。本篇给出两件可操作的判断依据 —— 包名与哈希 —— 以及一套辨认那些自称「官网」的页面的标准。

## 一、名字的变体有多少

同一个应用在网上的写法至少有这些：

| 写法 | 常见于哪里 |
| --- | --- |
| 漫蛙2 / 漫蛙漫画 | 各类软件页的标题 |
| 漫蛙manwa2 / 漫蛙2manwa2 | 下载站的收录名 |
| 漫蛙manwan2正版 | 网盘目录名、部分软件页 |
| manwa2 | 只留英文的简写 |

注意 `manwa2` 与 `manwan2` 只差一个字母，两个都在被使用。**名字里多一个 n 或少一个 n，不代表是不同版本，也不代表是不同应用** —— 这是搜索时最容易踩的坑：按一个写法搜不到，换个写法就出来了。

## 二、为什么网上的版本号不能当判断依据

这是本篇最该记住的一条。把公开软件页里同一名字下的数据摊开看，会得到这样一张表：

| 公开页写的版本 | 公开页写的体积 | 公开页写的厂商 |
| --- | --- | --- |
| 1.10 | 20 MB | 一家信息科技公司 |
| 2.90 | 95.47 MB | 一家机械公司 |
| 3.1.7 | 29.27 MB | 未标注 |
| 5.47 | 196.30 MB | 同上那家机械公司 |

同一个名字，版本从 1.x 排到 5.x，体积差了近十倍，标注的厂商彼此无关。这说明这些页面收录的**不是同一个安装包** —— 有的是不同渠道的包，有的是名字相近的另一个应用，有的则只是抄来凑页面的。

结论：**「版本号对得上」这件事在这类应用上没有证明力**。真正能认人的只有两项：包名和 MD5。

## 三、按包名认人

包名是安卓给应用的唯一身份证，装完之后在「设置 → 应用 → 应用管理」里找到这个应用就能看到，也可以用一个能读安装包信息的工具直接读 APK。

| 包名 | 说明 |
| --- | --- |
| `com.jumang.mwtwo` | 网盘里这份，本文的核对基准 |
| `com.manwamh.hyy` | 另一个用了「漫蛙」名头的包，与上面不是同一个 |
| `cn.lsrmw.dnjgbyliu` | 又一份同名的包，同样对不上 |

后面两个包名来自公开软件页的收录信息，把它们的版本、体积、厂商列进上表，就能看出与本文这份毫无关系。也就是说：**你在别处下到的「漫蛙」，很可能根本不是这一个包。**

## 四、怎么看待那些自称「官网」的页面

用这个名字能搜出一批自称官网的站点，它们的共同特征比它们的名字更好认：

- **介绍文字高度雷同**：同一套「海量资源库 / 高清流畅 / 智能追更与离线下载」的说法，排版都很像，换域名不换文案；
- **挂着无法核实的数据**：写着「10 万+ 资源」「500 万+ 活跃用户」「4.9 分」这类数字，却不给可核对的包名与哈希；
- **下载按钮指向站内跳转**：点下去先在站内绕一圈，最后给的包名和页面上写的对不上；
- **域名本身会换**：不少页面自己就在讲「域名常变、建议收藏防走失地址」。

这四条里任意一条都足以把它当**推广页**看待、而不是当事实来源。判断优先级也简单：**能给出包名 + MD5 的说明可信度更高；只给宣传语和下载按钮的，一律只当作广告。**

所以本篇给的建议很直接：**需要安装文件就用本文头部那份**，别在搜索结果里随手点一个「免费下载」。

## 五、同一台手机上装了两个「漫蛙」会怎样

包名不同，安卓不会拦着你 —— 两个可以共存，桌面图标和显示名可能几乎一样，点开时很容易点错，而且书架和阅读记录各是各的，互不相通。

处理办法：装完在应用信息里确认一次包名是不是 `com.jumang.mwtwo`，不是就把随后装上的那个多余的删掉。辨认自己点的到底是哪一个，看应用信息页的包名最快，别靠图标。

## 六、遇到新版本要不要先卸载

分两种情况：

| 情况 | 做法 |
| --- | --- |
| 新旧两个包**包名相同** | 直接安装覆盖即可，不必先卸载（签名不同会失败，那时才需要先卸载） |
| 新旧两个包**包名不同** | 卸载其中一个之前先确认它是不是你要留下的那个，两个是独立应用 |

换版本本身不影响书架内容的前提是同一个包名、同一个账号。若不确定自己手里是哪一个包，回到 [打不开与加载失败怎么排查.md](打不开与加载失败怎么排查.md) 的卸载重装一节，那里写了卸载前要先做的准备。
