看漫画真正需要管理的是「我在追哪几部、各自看到第几话」。漫蛙manwan2正版把这件事拆成了两个入口：书架要你手动加，最近阅读自动记。本篇讲清两者的分工，以及换手机时怎么不让追了半年的列表白费。

## 一、书架和最近阅读有什么区别

| | 书架 | 最近阅读 |
| --- | --- | --- |
| 怎么产生的 | 你在详情页手动加入 | 自动记录，打开过的就在里面 |
| 会记进度吗 | 会，跟着作品一起记 | 会，记录到具体章节 |
| 会不会自己变多 | 不会 | 会，看过的都留下 |
| 适合做什么 | 长期追更的清单 | 临时找回刚看的那一部 |

一句话分开用：**常追的放书架，翻过的交给最近阅读**。只想找回上一部看到一半的作品，去最近阅读比在书架里翻更快。

## 二、把作品加进书架

在作品详情页找「加入书架 / 收藏」之类的按钮（不同版本用词不完全一样）。加完之后，书架里一般能按最近阅读或更新时间排序 —— 排序方式换个版本可能挪了位置，以你实际看到的界面为准。

书架里点开作品，会直接跳到你上次看到的那一话，不用再翻章节列表。

## 三、连载怎么盯更新

盯更新靠应用的更新提醒，而提醒要能到你手机上，得先过系统这一关：

1. 第一次打开时如果弹通知权限，选允许；
2. 之前拒绝过的，去「设置 → 应用 → 应用管理 → 找到本应用 → 通知」里重新打开；
3. 部分手机还有省电策略会掐掉后台提醒，把本应用加入「不受限制 / 允许后台活动」的白名单更稳。

提醒的开关细节各版本不同，但链条是一样的：**收藏了作品 + 系统允许通知 = 新章节能提醒到你**。少任何一环都不会有弹窗，这不是应用坏了。

## 四、登录与不登录，差在哪

| | 不登录 | 登录 |
| --- | --- | --- |
| 书架与进度存在哪 | 只在本机 | 跟着账号走 |
| 换手机 / 重装后 | 全部丢失 | 登录同一账号后回来 |
| 离线缓存 | 能正常用 | 能正常用 |

需要说明的是，公开软件页在「要不要注册」这件事上口径并不一致：有的写「免注册直接进」，有的写要用手机号收验证码注册。**以你装的那一版界面上实际有没有登录入口为准** —— 打开「我的」页面看一眼就知道。如果那里有登录 / 注册入口，建议登录一次，理由见上表第二行：不登录的话，换手机或重装之后书架就找不回来了。

## 五、换手机怎么把书架带走

前提只有一个：**在旧手机上登录过**。没登录过的，只能在新手机上重新一部部加回来。

步骤：

1. 旧手机确认登录状态没掉（「我的」页里能看到账号）；
2. 新手机装**同一个包名**的版本 —— `com.jumang.mwtwo`，装错成同名的另一个包，进度读不出来，怎么分辨见 [同名应用与版本怎么认.md](同名应用与版本怎么认.md)；安装文件就是本文头部那一份；
3. 用同一个账号登录；
4. 打开书架核对条数，再随便点开一部确认进度落在原来的话数上。

## 六、书架数据会被哪些操作清掉

- **卸载应用**：本机书架和进度一起没了，登录过的可以靠重新登录找回；
- **系统设置里「清除数据」**：同上，等同重装；
- **系统设置里「清除缓存」**：一般不影响登录状态与书架，只清临时文件（会把已缓存的章节也清掉，见 [离线缓存与下载管理.md](离线缓存与下载管理.md)）。

清缓存和清数据只差一个字，影响完全不同。动手前先确认自己点的是哪一个，具体对照表在 [打不开与加载失败怎么排查.md](打不开与加载失败怎么排查.md) 的第五节。
