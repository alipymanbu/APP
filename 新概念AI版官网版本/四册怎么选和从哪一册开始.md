## 一、四册分别是什么难度

应用里的课程是按《新概念英语》教材的册别组织的。教材本身的编排是难度逐册上升，选错了册，学起来就是「每句话都查词」或者「太简单坐不住」两种极端。

| 册别 | 教材编排的大致侧重 | 适合谁 |
| --- | --- | --- |
| 第一册 | 从日常对话与基础语法入手，句子短、生词少 | 零基础，或基础明显薄弱、语法没成体系的人 |
| 第二册 | 以短篇故事为主，靠故事反复巩固语法与句子结构 | 能读懂简单句、但写不出完整句的人 |
| 第三册 | 长篇文章与更复杂的语法，练逻辑表达 | 语法框架已有，需要扩阅读量与句式的人 |
| 第四册 | 选文偏人文与科技，篇幅长、长难句多 | 已能较顺畅阅读，想接近原版材料的人 |

这是一份粗定位，具体到某一课的难度以你打开后看到的课文为准。教材版本的差异（比如是否用新版）也会影响个别课文的取舍。

## 二、选册的判断标准

不要按「学了几年英语」选，按**实际体验**选：

- **听课文录音，能听懂大半、但自己复述不出来** → 这一册就是你的起点。
- **听录音基本听不出在说什么** → 往下一册，不要硬扛。硬扛的成本是每天花在查词上的时间远超练习时间。
- **听一遍就能复述，练习也几乎全对** → 往上一册。太简单的内容，做题的快感撑不过一周。

对多数自学者来说，第二册是比第一册更常见的实际起点——第一册的内容对成年人来说进度偏慢。

## 三、在应用里怎么进对应的册

应用把四册内容都放在里面，你可以直接进需要的那一册，不必从第一册第一课顺次解锁。每个 lesson（课）的固定构成是：

1. **课文**：配原创插画，用来先把这一课讲什么看明白；
2. **详解**：从单词、语法、句型、口语几个角度拆这一课，做法见[课文详解和随堂练习怎么用.md](课文详解和随堂练习怎么用.md)；
3. **随堂练习**：学完即练，检验这一课有没有听进去；
4. **真题**：每个 lesson 配历年真题，见[真题训练和错题复习怎么做.md](真题训练和错题复习怎么做.md)。

**学到一半想换册**：各册的内容是分开进的，换册不难；但换册后原有的错题本、复习计划怎么衔接，以你应用内实际看到的情况为准——换之前先想清楚，别在同一个位置来回跳。

## 四、语速调节：从慢速磨到原速

官方说明里列了「语速调节」这项功能，听力与跟读环节都可以用。它的实际用法是：

- **第一遍用慢速**：先把每个词听清楚，尤其是连读和弱读的位置。
- **对着课文跟一遍**：慢速跟读，确认自己能跟上，再回原速。
- **回原速再来一遍**：考试和真实对话都是原速，慢速只是过渡工具，不要一直停在慢速。
- **同一句反复听**：配合「单句循环」，把听不清的那一句单独拎出来重复，具体操作见[AI纠音和口语跟读怎么练.md](AI纠音和口语跟读怎么练.md)。

语速档位具体有哪些、能不能记住上次的设置，以你应用内显示为准。

## 五、给自学者的节奏建议

一课的标准流程是「看插画课文 → 过详解 → 做随堂练习 → 做真题 → 错题进复习」。**不要跳掉随堂练习直接做真题**：随堂练习是即时检验，真题是拉长时间跨度的检验，两者测的不是一回事。

每天固定一课或半课，比周末突击五课有效——这一点和错题复习的推送逻辑有关，见[真题训练和错题复习怎么做.md](真题训练和错题复习怎么做.md)。

## 六、想对着纸质课本学，课文对不上怎么办

不少人手里本来就有一本纸质《新概念英语》，想一边看书一边用应用。这时常见的问题是：**某一篇课文在应用里翻不到，或者课号和书上的对不上**。

原因通常不是应用漏了内容，而是**版次不同**——《新概念英语》有多个版次，不同版次之间调整过课文的取舍。按公开流传的版本对照整理，差异的分布大致是这样：

| 册别 | 不同版次之间的课文差异 |
| --- | --- |
| 第一册 | 绝大多数课文相同，个别单词与专有名词有改动 |
| 第二册 | 只有少数几课被替换 |
| 第三册 | 少数几课被替换 |
| 第四册 | 差异最大，多个版次之间课文的增删都比较明显 |

这份对照来自公开流传的整理资料，**不是教材出版方发布的说明**，具体到某一课，以你手上那本书和应用里实际打开的课文为准。

对不上的时候，别按课号硬找，用这两个索引更快：

1. **按课文标题找**。课号会随版次变，课文标题一般不变；
2. **按课文首句找**。同一篇课文即使换了版次，开头那句通常还是原句，顺着第一课往后翻，比对首句最快。

还有一种「对不上」是正常的：**你手上的是配套教辅，不是教材本身**。教辅的编排跟着它自己配套的那一版走，本来就不必和应用一一对应，直接按应用里的课序学即可。
