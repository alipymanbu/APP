## 一、动手前先定两件事

- **目标游戏**：首次启动时的「配置路径」就是在定这个。主界面顶部那张灰色卡片点一下就能启动游戏，右上角菜单能设置启动游戏时顺带执行什么操作。
- **操作模式**：没有授权成功，下面的保存全是白做。四种模式的条件和授权步骤见 [操作模式怎么选.md](操作模式怎么选.md)。

## 二、每次保存前都要确认的一件事

**保存的时候，目标游戏不能在后台运行。** 这是官方教程里反复强调的一条，也是最常见的「保存成功但不生效」的原因。

判断标准不是「看起来退出了」，而是最近任务列表里没有它。要彻底一点，保存前先把游戏划掉。

## 三、快速开始：适合不想细调的人

主界面「快速开始」区域是一键式的，把几个常用选项选好，点「保存并启动游戏」或「仅保存」即可。里面那几个选项的含义：

| 选项 | 含义 | 注意 |
| --- | --- | --- |
| 保存模式 | 决定写哪一类配置文件 | **一般手机选 UC，平板选 EC**；两者的取舍见 [UC模式和EC模式有什么区别.md](UC模式和EC模式有什么区别.md) |
| 分辨率 | 游戏内渲染像素点的密度 | 调高画面更清晰，但游戏内按钮会变小；部分平板/折叠屏因机型锁分辨率，直接改可能不生效 |
| 特效 | 命中特效等效果的档位 | 官方自己标注为「玄学代码，作用可能不明显」 |
| 大屏适配 | 修正修改分辨率后出现的画面放大/缩小 | 平板、折叠屏上更常用 |

其余选项就是游戏里本来就有的那些画面档位，按自己设备性能挑。

## 四、要细调就进编辑器

「快速开始」之外，「功能」页里是更细的几个工具，分工不一样，别搞混：

| 工具 | 管什么 |
| --- | --- |
| UC 可视化 | 以图形界面调画质相关参数，不用看代码 |
| UC 逐行解析 | 把代码逐行翻译出来，想知道每一项到底改了什么时用 |
| UC 编辑器 | 直接编辑 UC 文件内容 |
| US 编辑器 | 调音质，以及水面反射效果的开关 |
| EC 编辑器 | 画质与音质一起改 |
| 代码库 | 官方云端收录的现成方案，可直接取用 |
| 收藏夹 | 配置的导入 / 导出 / 上传 / 下载，换机或备份时用 |

注意 UC 和 EC 是两套东西：**用了 UC 就不要再留着 EC 的配置**，两套同时存在会互相冲突，表现就是改了没反应。两种模式各自能干什么、什么时候必须换，见 [UC模式和EC模式有什么区别.md](UC模式和EC模式有什么区别.md)。

## 五、怎么判断已经改成功

这是最容易被误判的一步。判断依据不是「游戏里出现了新档位」：

- 进入游戏的画面设置，看选项上有**没有「当前」这两个字**。
- 「当前」落在哪一项，游戏实际用的就是哪一项。
- **如果你要的档位上没有「当前」，说明它落在被隐藏的档位上——这恰恰是改成功了。**
- 游戏里原本就不显示的选项，修改后照样不会显示，这是正常的。

**成功之后不要再去动游戏内的画面设置**，改一下就可能被打回默认。直接进对局看效果。

## 六、帧率能不能上去，由三层决定

LT画质助手 只是把配置里的帧率值写进去，实际能不能跑到，取决于下面三层，缺一层就上不去：

1. **屏幕本身**：屏幕刷新率只有 60Hz 的设备，帧率最多到 60。
2. **系统设置**：屏幕是 120Hz，但系统里没开高刷新率，或者给这个游戏单独限了刷新率，最终仍会卡在那个值。
3. **系统锁帧**：少数机型在系统层面锁住刷新率，即使前两项都对，实际刷新率也上不去。这种情况需要按自己机型的办法处理，官方 FAQ 里的建议是去各平台搜自己的设备型号。

再往上还有 144 / 165 帧这类更高档位，官方更新日志里标注了同一个前提：**需设备硬件支持，否则无效**。屏幕本身跑不到那个刷新率，改上去也不会有变化。各档位与设备的关系，见 [支持哪些游戏和设备.md](支持哪些游戏和设备.md)。

所以「别人同款包能上 120 帧，我这台上不去」不等于软件没用，先按上面三层对一遍。

## 七、每次进游戏都要改？用画质锁定

游戏自己有还原机制，改完的配置可能下一次启动就被还原。软件里有「画质锁定」功能对付这个。

用法有个顺序要求：

1. 先改好画质；
2. 再开启锁定；
3. 之后要再改，**先解锁 → 再修改 → 再重新锁定**。

锁定不等于稳定帧率，它只管配置不被还原。

## 八、几个顺手的功能

- **修复文件**：第一次改某款游戏之前，建议先跑一次。注意修复 SAV 会让游戏部分设置恢复默认，**先备份灵敏度等设置**；修复完成后要启动一次游戏才算数。
- **小白衣**：清理游戏下载下来的服饰资源包。
- **MIUI 性能模式**：在小米设备上调用系统隐藏的性能模式。
- **悬浮准星**：游戏内叠加一个准星，样式可在软件内调整。
