# LT画质助手 UC模式和EC模式有什么区别

> 保存画质时要在 UC 和 EC 之间选一个，选错会碰到「分辨率改不动」，或者音质被锁死在某个档位。本篇讲这两种模式各自能干什么、什么时候必须换、换完之后要注意什么，以及它和 SAV 那套是什么关系。

## 一、两种模式的实际差别

| 对比项 | UC 模式 | EC 模式 |
| --- | --- | --- |
| 改分辨率 | 部分设备改不动 | 能改 |
| 游戏音质 | 可以调 | 锁定为「高」，调不了 |
| 画面放大 / 缩小 | 少见 | 机型本身锁分辨率时容易出现 |
| 适合的设备 | 一般手机 | 平板、折叠屏 |

一句话记法：**UC 保音质、EC 保分辨率**，两者不能同时拿到。这句是从官方 FAQ 的说明里推出来的——官方原文是「UC 模式下部分设备无法修改分辨率，此时需要使用 EC 模式；EC 模式下游戏音质锁定为高无法修改」。

## 二、怎么决定用哪个

1. **先按设备定**：官方给的口径是「一般手机选 UC，平板选 EC」。
2. **改不动分辨率就换**：在 UC 下改分辨率没反应，切到 EC 再改一次。
3. **出现画面异常就换回去**：切到 EC 后如果画面被放大或缩小，那是机型锁分辨率时会出现的现象，不是软件坏了。可以试「大屏适配」修一次，修不好就切回 UC。

这三步走完基本就定了，不需要反复来回切。

## 三、两套配置不能同时留着

UC 和 EC 写的是不同的配置文件，同时存在会互相覆盖，表现就是「保存成功但游戏里没动静」。

正确的做法是：**用哪一套，就只留哪一套**。从 UC 切到 EC、或者从 EC 切回 UC 之后，重新保存一次，让软件把旧那套盖掉。

改完还是没反应，按 [常见问题与排查.md](常见问题与排查.md) 第一节的顺序往下查。

## 四、还有第三种：SAV

除了 UC 和 EC，软件里还有一套 SAV。三者不是同一层的东西：

- **UC / EC**：走「保存模式」，主要用于和平精英这类以 UC/EC 为主的游戏。
- **SAV**：在和平精英里，如果游戏内选不到你想要的帧率档位，就进 **SAV 可视化** 改帧率；保存成功后启动游戏**不要再去动画面设置**。
- **PUBGM 这类游戏主要走 SAV**，而不是 UC/EC——这是官方修改教程里明确写着的差别。

也就是说，看到一篇教程说「用 UC 改」，但你的游戏是 PUBGM，那条路可能本来就不适用。

## 五、切换之后要确认的事

换保存模式不会顺带帮你检查别的东西，改完自己核这三项：

| 项目 | 怎么确认 |
| --- | --- |
| 旧配置已清掉 | 确认另一套（EC 或 UC）没有残留，否则会互相覆盖 |
| 有没有生效 | 看游戏画面设置里「当前」两个字落在哪一项，方法见 [画质与帧率怎么调.md](画质与帧率怎么调.md) 第五节 |
| 音质是否被锁 | EC 模式下音质固定在高档，想要可调的音质就得回到 UC |

需要重改时，记得先关闭「画质锁定」再动，改完再锁上。
