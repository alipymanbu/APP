## 一、保存失败，或者提示保存成功但游戏没变化

按下面顺序查，大部分问题在前两步就能定位：

| 检查点 | 具体怎么确认 |
| --- | --- |
| 游戏在后台运行 | 在最近任务列表里划掉游戏，再保存一次。这是最常见的原因 |
| 授权没给到 | 存储 / Android/data 目录权限是否已授；换过操作模式的话要重新授权 |
| 目标路径选错 | 游戏装了多个版本（不同渠道、不同服务器）时，路径选错就写不进正确的位置 |
| UC 与 EC 冲突 | 想用 UC 生效，就不能留着 EC 的配置；两套并存会互相覆盖，差别见 [UC模式和EC模式有什么区别.md](UC模式和EC模式有什么区别.md) |
| 文件被游戏还原 | 每次启动都被还原的，用「画质锁定」；锁定要先解锁再改再锁 |

上面都排完了还是不生效，先用软件内的「**修复文件**」功能跑一遍再重改。注意修复 SAV 会让游戏部分设置恢复默认，**先把灵敏度这类设置备份下来**；修复完成后必须启动一次游戏才生效。

## 二、改了之后游戏里看不到对应的画质档位

这通常是正常的，不代表失败。判断依据是选项上有没有「当前」两个字，而不是有没有出现新档位：

- 你要的档位没有「当前」→ 说明它落在被隐藏的档位上，**这就是改成功了**。
- 游戏里原本就不显示的选项，修改后照样不会显示。
- 成功之后**不要再去动游戏内的画面设置**，动了就可能失效。

## 三、这次改完有效，下次进游戏又变回去了

游戏客户端会把自己认为「不该存在」的配置还原掉。解决办法是「画质锁定」：

1. 先把画质改好；
2. 再开启锁定；
3. 以后要再改，顺序是**先解锁 → 修改 → 再锁定**。

锁定只解决「配置被还原」，不等于帧率变稳。

## 四、帧率上不去

先按 [支持哪些游戏和设备.md](支持哪些游戏和设备.md) 第二节的三层前提对一遍（屏幕刷新率、系统高刷开关、应用级限帧）。三层都满足还是上不去，再看这两条：

- **不要用无限帧率**：部分设备改成无限帧率后反而被锁帧，改回 90 / 120 就正常了。
- **改成 120 后反而掉到低帧**：把游戏切到后台，用软件改好帧率再切回游戏；返回后**不要进设置页**，进去会失效。

## 五、修改后游戏画面被放大或缩小

部分机型改分辨率后会出现这个现象，EC 模式下更容易碰到（原因见 [UC模式和EC模式有什么区别.md](UC模式和EC模式有什么区别.md)）。三种处理方式，从省事到麻烦依次试：

1. 把游戏切到后台，再切回来；
2. 用「大屏适配 / 大屏修复」选项；
3. 换一种保存模式（UC ↔ EC）后重改。

## 六、闪退、卡住、连不上

| 现象 | 处理 |
| --- | --- |
| 打开就闪退 | 确认系统版本是否过低；换 `File` 模式再试 |
| 提示「当前设备似乎不支持此模式」 | 不是装坏了，换一种操作模式 |
| Shell / Root 模式提示「无法连接」 | **完全关闭** LT画质助手（最近任务里划掉），进 Shizuku 或 Root 管理器重新授权，再重开 |
| 授权界面点不了「使用此文件夹」 | 换 File 模式；提示「为保护您的隐私，请选择其他文件夹」说明设备不支持该模式 |
| 重启后 Shell 模式失效 | Shizuku 的服务重启后要重新启动，这是它的工作方式 |

## 七、想把游戏改回原来的样子

软件里有两个可用入口，官方的更新日志里都出现过：

- **还原画质**：把改过的画质配置退回原状；
- **修复文件**：针对相关配置文件做修复，也是「保存一直不生效」时的兜底手段。

两个都不需要先把 LT画质助手 卸载掉。跑完同样要启动一次游戏才生效。

卸载 LT画质助手 只是移除这个应用本身，不要把它当成「恢复游戏设置」的动作——要恢复就先还原或修复，再卸载。

## 八、账号风险：官方明确提示过

这一点官方在自己的用户协议里就写明了：**使用本应用可能带来包括但不限于账号封禁等风险，该等风险由用户自行承担**。同时官方也说明，实际效果取决于设备性能与系统版本，不保证在你的设备上可用。

所以要不要在某些游戏上长期用、用多大改动，是你自己的取舍。涉及竞技类账号时，先用小号或先只改画质、不动帧率，风险更容易控制。

## 九、关于高级版

软件内有一部分功能标注了**需要开通高级版**才能使用，其余功能可直接用。官方用户协议写明付费服务按公布的资费标准收取，并对退款有明确限制——官方的修改教程里也写了「不支持退款」。官方的更新日志里还提到过，软件后来加入了用户系统、**高级版权限跟随账号**。

因此开通之前，先确认两件事：

1. 你要用的那个功能确实需要高级版，而不是免费功能没找到入口；
2. 你的设备能不能跑得动对应游戏的修改，先用免费功能试一次，确认能生效再考虑付费。
