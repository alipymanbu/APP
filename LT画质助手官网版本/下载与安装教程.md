## 一、装之前先对一遍版本和要求

下面这张表是网盘里那一份包的实际情况。网上搜到的「最新版」常常已经是另一个版本号，装之前以这张表为准，装完在手机的应用信息页也能对得上。

| 项目 | 值 |
| --- | --- |
| 应用名 | LT画质助手 |
| 包名 | `com.lengtong.tool` |
| 版本 | 5.3.0 |
| 安装包大小 | 9.60M |
| 安装包 MD5 | `c666beb09e66e5d16a27b026e4244d57` |
| 平台 | 安卓手机应用（APK） |
| 系统门槛 | 安卓手机；Android 11 及以上首次使用会多一步文件夹授权，具体门槛以官方页面和实际安装提示为准 |

三条判断：

- 这是一个安卓手机应用。想在电脑上用它，得先装安卓模拟器，再把包装进模拟器里；模拟器的 Android/data 目录结构和真机不同，能不能用要自己试。
- 它改的是手机上已经装好的游戏文件，所以**手机上得先有目标游戏**，空着手机装它没有意义。
- 名字里的 `LT` 是官方写法，两个大写字母。下载站里的小写写法指的是同一个应用，怎么核对见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。

## 二、从网盘把安装包取到手机

1. 打开 [LT画质助手 安装文件资源（夸克网盘）](https://pan.quark.cn/s/65e49719762a)。
2. 先点「保存到我的网盘」，再下载。直接下载也能用，但转存到自己的网盘之后，原分享链接以后失效了也不影响你。
3. 等文件下载完，记下它在手机里的位置，多数浏览器会放在「下载」或「Download」目录。
4. 文件名通常形如 `LT画质助手_v5.3.0.apk`，以网盘里实际显示的名字为准。

如果打开链接提示失效或需要提取码，说明这条分享已经不是当前状态，换最新的一条再试。

## 三、动手装之前校验一下包

安装包从网络传到手机，中间出过错的话，装的时候会报「解析包错误」。花半分钟校验一次，能省掉后面一堆莫名其妙的排查。

用电脑校验最省事，把 APK 拷到电脑上，在文件所在目录执行：

```powershell
certutil -hashfile "LT画质助手_v5.3.0.apk" MD5
```

输出的十六进制串去掉空格后，应该和第一节表里的 `c666beb09e66e5d16a27b026e4244d57` 完全一致（大小写不敏感）。手机上也可以用带 MD5 校验功能的文件管理器做同样的事。

对不上就重新下载一次，别将就着装。

## 四、先去系统里放行「未知来源」

网盘里的包不是从应用商店装的，安卓默认会拦一次。要先给下载它的那个应用（浏览器或夸克）开安装权限，各品牌路径不一样：

| 品牌 | 大致路径 |
| --- | --- |
| 小米 / 红米 | 设置 → 应用设置 → 应用管理 → 权限管理 → 安装未知应用 |
| 华为 / 荣耀 | 设置 → 安全 → 更多安全设置 → 安装外部来源应用 |
| OPPO / 一加 / realme | 设置 → 安全 → 安装外部来源应用 |
| vivo / iQOO | 设置 → 安全 → 更多安全设置 → 安装未知应用 |
| 三星 | 设置 → 生物识别和安全 → 安装未知应用 |
| 原生安卓 | 设置 → 应用 → 特殊应用权限 → 安装未知应用 |

路径记不住没关系，在设置顶部的搜索框里直接搜「未知应用」或「外部来源」，基本都能跳到同一页。找到负责下载的那个应用，把开关打开。

## 五、安装与第一次打开

1. 从通知栏点刚下载完的文件，或者打开文件管理器找到那个 `.apk` 点它。
2. 弹出安装界面点「安装」，等进度走完，桌面出现图标。
3. 第一次启动会**自动进入「配置路径」界面**，让你选这次要改哪个游戏。选错了不要紧，之后在主界面顶部那张灰色卡片处还能重新切换目标应用。
4. 选完回到主界面时，**Android 11 及以上的机型会弹出一个授权框**：点「确定」跳到系统界面，再点底部的「使用此文件夹」。这一步是给应用读写游戏文件所在目录的权限，跳过它后面保存必然失败。
5. 首次启动还会申请几项权限，真正影响功能的是这两项：

| 权限 | 不给会怎样 |
| --- | --- |
| 存储 / 文件（含 Android/data 目录访问） | 读不到游戏文件，保存一律失败 |
| 通知 | 只影响状态提醒，不影响改画质 |

6. 启动后如果提示「当前设备似乎不支持此模式」，不是装坏了，是这一种操作模式在这台设备上走不通，换一种模式即可，见 [操作模式怎么选.md](操作模式怎么选.md)。

## 六、装不上或者装完打不开

按这个顺序自查，比反复重装有效：

- 提示「解析包错误」「应用未安装」→ 回到第三节重新校验 MD5，文件多半没下完整。
- 提示「已被阻止安装」→ 第四节的未知来源权限没开，或开了但给错了应用（要给浏览器/网盘，不是给 LT画质助手）。
- 装完点图标没反应、闪一下退回桌面 → 先确认手机系统版本是否过低；仍不行按 [常见问题与排查.md](常见问题与排查.md) 第六节排查。
- 装到一半提示空间不足 → 先清出不小于安装包大小的空间再试。
- 装好、也能打开，但选不了目标游戏 → 说明目标游戏没装在这台手机上，或装在了分身/多开空间里，先切回主空间再试。
