# LT画质助手 操作模式怎么选

> LT画质助手 要改的是游戏目录下的配置文件，能不能改成功，第一步取决于「操作模式」选对没有。本篇把 File、DocumentFile、Shell、Root 四种模式要什么条件、怎么授权、选哪种，一次说清。

## 一、四种模式各自要什么条件

| 模式 | 额外要准备什么 | 授权在哪做 | 什么时候用它 |
| --- | --- | --- | --- |
| File | 无 | 软件内提示操作 | 先试这个，能过就不折腾 |
| DocumentFile | 无（但要多授一次 Android/data 目录权限） | 系统文件夹选择界面，点「使用此文件夹」 | File 模式走不通时 |
| Shell | 装 Shizuku 并启动它的服务 | Shizuku 里给 LT画质助手 授权 | 不想 Root，又需要比前两种更高的权限 |
| Root | 手机已经 Root，且有 Root 管理器 | Root 管理器里给 LT画质助手 授权 | 手机本来就是 Root 状态 |

判断顺序很直接：**先 File → 不行换 DocumentFile → 再不行才考虑 Shell 或 Root**。前两种不需要手机做任何额外准备，能覆盖大部分机型；后两种要动系统层面的东西，装之前先想清楚值不值。

## 二、在哪儿切换模式

首次使用时会走一遍「操作模式向导」，跟着选就行。之后要改，在软件内设置里能找到同一个向导。

每次换模式，授权要重新给一遍——之前那次授权是给上一个模式的，新模式下不通用。

## 三、DocumentFile 模式的授权动作，只有一步

这个模式的坑全在授权界面：

1. 软件主动弹出提示时点「授予」，跳到系统界面。
2. **直接点底部的「使用此文件夹」，不要退出去选别的目录，也不要新建文件夹。**
3. 再点「允许」。

两种情况说明这台设备用不了这个模式，别在这一步反复试：

- 提示「无法使用此文件夹」；
- 点了「使用此文件夹」后，系统弹「为保护您的隐私，请选择其他文件夹」。

出现这两种提示就换 File 模式，或者往下走 Shell 模式。

## 四、Shell 模式：先让 Shizuku 跑起来

Shell 模式本身不复杂，复杂的是它依赖 Shizuku 这个外部工具，而 Shizuku 需要在每次重启后重新启动服务。

1. 装 Shizuku。官方给了两个来源：一个在 `lengtongls.lanzoup.com`，另一个在 GitHub 的 [`RikkaApps/Shizuku`](https://github.com/RikkaApps/Shizuku/releases) 发布页。用哪个都行，认版本和发布方，别从陌生站下。
2. 按 Shizuku 自己的说明把服务启动起来。Android 11 及以上一般通过「无线调试」里的配对流程启动，具体步骤以 Shizuku 应用内的引导为准。
3. 回到 LT画质助手，按软件内提示完成授权。
4. 如果提示「无法连接」：**完全关闭 LT画质助手**（不是切后台，是在最近任务里划掉），再进 Shizuku 重新给它授权，然后重开 LT画质助手。

重启手机之后 Shizuku 的服务会停，Shell 模式会失效，需要重新启动一次 Shizuku。这是 Shizuku 的工作方式，不是 LT画质助手 的问题。

## 五、Root 模式

手机已经 Root 的话，选 Root 模式，按软件内提示在 Root 管理器里给一次授权即可。同样地，如果提示「无法连接」，先完全关闭 LT画质助手，再进 Root 管理器重新授权。

Root 模式给到的权限最高，但它需要你对 Root 本身已经熟悉；没有 Root 的手机不要为了这个应用去折腾 Root。

## 六、选完模式之后要确认的事

改完模式别急着去调画质，先确认两件事：

1. **授权真的给上了**：回到软件里，能正常读到目标游戏的信息、能列出游戏目录下的文件，才算通过。
2. **目标游戏路径选对了**：同一款游戏可能有多个版本（不同渠道、不同服务器），路径选错会出现「保存成功但游戏没变化」，排查方法见 [常见问题与排查.md](常见问题与排查.md) 第一节。

这两项都确认了，再按 [画质与帧率怎么调.md](画质与帧率怎么调.md) 开始改。
