这份清单按「现象 → 先查什么 → 怎么处理」组织。绝大多数问题出在书源和本地文件上，而不是软件本身，所以先按现象定位，不要急着重装。

## 一、装完打开什么都没有

这是第一次打开最常见的状态：在线内容由书源决定，书架里还没有东西。如果你的版本已经预置了书源、直接就能搜到书，这一步可以跳过。

- 想在线看：按 [书源怎么导入和管理.md](书源怎么导入和管理.md) 导入书源，再回书架搜索。
- 想读手里的书：按 [本地TXT与EPUB怎么导入.md](本地TXT与EPUB怎么导入.md) 添加本地。

## 二、搜索没结果 / 某本书打不开

| 先查 | 判断 | 处理 |
| --- | --- | --- |
| 书源是否启用 | 书源被禁用了，搜索不会走它 | 书源管理里重新启用 |
| 书源是否失效 | 校验后进了「失效」分组 | 禁用或删除失效源，补一份新合集 |
| 只是某本书不行 | 其它书正常，说明是这个源跟不上 | 阅读界面 → 换源，换一个能出正文的源 |

站点改版就会让书源失效，这是常态。定期在书源管理里跑一次「校验所选」，比事后逐本排查快得多。另外，书源地址要你自己从可信的社区渠道取，本文只讲怎么导、怎么管，不提供具体地址。

## 三、正文缺字漏字、内容缺失或排版错乱

这一类基本都是**替换净化规则误杀**，不是源的问题。

1. 先关闭替换净化，然后刷新本章，看是否恢复正常。
2. 恢复正常 → 说明是净化规则把正文一起替换掉了，去规则里改关键词或减小替换范围。
3. 关闭后仍然异常 → 点开菜单里的「源链接」看原文，原文也缺就是源本身的问题，换个源即可。

同一现象若只出现在某一本书上，几乎可以确定是规则误杀，不必怀疑软件。逐条定位到具体是哪条规则的步骤，见 [替换净化怎么用.md](替换净化怎么用.md)。

## 四、漫画源显示乱码或打不开

漫画源与小说源不是同一种东西，**不同阅读器的源也不通用**。把别处拿来的漫画源导进 阅读app，规则对不上就会乱码或空白。确认你导入的是当前版本可用的漫画源，再重新导入。

## 五、旧版书源导进来用不了

2.0 时代的书源规则与现在的版本不兼容，导入后可能搜得到、打开是空。建议导入后筛一遍，失效的直接禁用，优先用为当前版本适配的新源。

## 六、本地 TXT 相关问题

| 现象 | 处理 |
| --- | --- |
| 打开是乱码 | 阅读设置里手动切换字符编码（UTF-8 / GBK）后重新加载 |
| 目录只有一章或为空 | 换「txt目录正则」规则后重新扫描目录 |
| 提示 `LoadTocError` | 先确认编码，再换目录正则 |
| 正文被当成章节标题 | 换更严格的目录正则，或换一个排版规整的文件版本 |

详细步骤见 [本地TXT与EPUB怎么导入.md](本地TXT与EPUB怎么导入.md)。

## 七、朗读没声音

- 用的是在线引擎但当前没网 → 换系统语音，或恢复网络。
- 手机里没有可用的语音引擎 → 先到系统「文字转语音」设置里装一个。
- 音色列表是空的 → 朗读设置界面右上角 `⋮` → `导入默认规则`。
- 读到一半停 → 把应用加入电池「不优化」名单，并打开「朗读时息屏」。

## 八、更新或换机之后数据不见了

数据跟着包名走。装了**不同包名**的版本，旧数据不会自动带过去，看起来就像「更新后全没了」。

- 以后换版本前，先在「我的」→「备份与恢复」里做一次备份。
- 已经换了：回到旧版本导出书源，再在新版本里导入，步骤见 [备份与换手机迁移.md](备份与换手机迁移.md)。
- 从很老的版本迁过来：在「备份与恢复」里选 `导入旧版本数据`，直接吃旧版本导出的备份，比逐条重建省事。

## 九、校验说书源失效了，是不是就不能用了

不是。校验只是当场测一次，站点临时限流、当下网络不通都会判「失效」，它只能当参考。以「打开后能不能取到正文」为准，别一看校验失败就把源全删了。同类的两个误判（发现页书很少、只带发现的源读不了正文）记在 [书源怎么导入和管理.md](书源怎么导入和管理.md) 第六节。

## 十、几个容易误判的小情况

- **书架右上角的数字**：代表这本书有更新的章节数，不是收藏数。
- **菜单里点左边没反应**：左侧区域默认是上一页，改成上一章后行为会变，见 [阅读界面与翻页设置.md](阅读界面与翻页设置.md)。
- **权限被回收**：系统清理后可能回收文件夹授权，表现为导入或扫描失败，重新执行一次「添加本地」授权即可。

## 十一、装不上、装完闪退

| 提示 / 现象 | 处理 |
| --- | --- |
| 「解析软件包时出现问题」 | 先按 [下载与安装教程.md](下载与安装教程.md) 里的包名与 MD5 核对安装包有没有下全；文件没问题就是系统版本过旧，换较新的安卓机型装 |
| 「不允许安装未知来源应用」 | 在系统设置里给当前这个文件管理器（或浏览器）打开「安装未知应用」权限，再装一次 |
| 被「安全检测 / 纯净模式」拦住 | 选「继续安装 / 仍要安装」，必要时临时关掉纯净模式，装完再打开 |
| 装完点图标闪退 | 设置 → 应用 → 阅读app → 权限，把「文件和媒体」打开；仍然闪退就重新下一遍安装包 |

安装失败基本绕不开两个原因：安装包没下全，或者系统太旧。先把安装包核对一遍，再考虑换设备或换版本，别反复重装碰运气。
