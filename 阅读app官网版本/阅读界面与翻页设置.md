# 阅读界面与翻页设置

> 本篇讲 阅读app 阅读界面怎么唤出设置面板，字号、字体、背景、翻页方式、夜间与墨水屏模式各在哪里调，以及自定义字体和主题怎么装。

阅读app 的字号、背景与翻页设置不放在主页，而是跟着「阅读界面」走：打开一本书后点一下屏幕中间，底部会弹出阅读菜单，字号、字体、背景、翻页、朗读、目录、进度全在这一层。本篇把这几个入口逐个讲清，并说明自定义字体和现成主题怎么装。

## 一、唤出菜单与三个区域

点屏幕中间后，界面分成三块：

| 区域 | 默认动作 | 备注 |
| --- | --- | --- |
| 左侧 | 上一页 | 可在设置里改成翻到上一章 |
| 中间 | 唤出 / 收起菜单 | 想看正文时再点一下收起 |
| 右侧 | 下一页 | 同上 |

菜单栏里从左到右一般是：目录、阅读设置、朗读、换源、进度。长按某本书的封面或正文还能直接调出快捷操作。

## 二、字号与排版

在「阅读设置」里逐项调：

| 项目 | 可调范围 | 什么时候要动它 |
| --- | --- | --- |
| 字号 | 连续可调 | 屏幕小或视力吃紧时加大 |
| 字体 | 系统字体 / 自定义字体 | 见下面的「装自定义字体」 |
| 行距 | 连续可调 | 行距太小读起来挤，1.5 倍左右多数人舒服 |
| 段距 | 连续可调 | 段落之间留白，网络小说排版乱时更明显 |
| 加粗 | 开 / 关 | 墨水屏上开加粗，笔画更实 |
| 简繁转换 | 简体 / 繁体 / 关闭 | 看港台版或繁体源时用 |

调完不用保存，直接返回就生效，且**对所有书生效**，不必一本本设。

## 三、翻页方式怎么选

「阅读设置」里的翻页动画决定手势和动画效果：

| 模式 | 手感 | 适合 |
| --- | --- | --- |
| 覆盖 | 新页盖住旧页 | 折中，默认值通常就是它 |
| 仿真 | 模仿纸质书翻页 | 想要书感、不在意动画开销 |
| 滑动 | 横向平移 | 习惯左右滑的人 |
| 滚动 | 上下连续滚动 | 追更、看长篇，不用反复翻页 |
| 无动画 | 直接切换 | 老机型、追求省电 |

滚动模式下还可以设置「一次滚一屏」还是连续滚，以及是否显示滚动条。

## 四、背景、夜间与墨水屏

- **背景**：可选纯色、自定义图片，也可以直接套一份主题（背景图 + 字体 + 颜色打包在一起）。
- **夜间模式**：跟随系统，或在阅读设置里手动切。切过去之后背景、字体颜色、菜单都会一起变。
- **墨水屏模式**：针对墨水屏设备，减少动画和渐变，翻页用整屏刷新，避免残影。
- **状态栏**：可以设置阅读时是否显示时间、电量、本章进度。

> 主题不只是换个底色。别人做好的主题包里含背景图和配色，导入一次就能在「主题列表」里随时切换，比自己调快得多。

## 五、装自定义字体

1. 把 `.TTF` / `.OTF` 字体文件放进 `Read/字体/` 文件夹（该文件夹需先通过「添加本地」授权，见 [本地TXT与EPUB怎么导入.md](本地TXT与EPUB怎么导入.md)）。
2. 阅读设置 → 字体 → 选择你放进去的字体。列表里没出现时，退出设置重进一次。

字体文件越大，首次加载越慢；中文字体动辄十几 MB，建议只留常用的两三个。

## 六、导入一份现成的排版 / 主题

- **主题**：复制一整套主题参数后，进「我的」→「主题设置」→「主题列表」→「剪切板导入」，再点新主题切换。
- **排版配置**：把排版 `.zip` 放进 `Read/排版配置/`，在排版设置里导入，一次性套用字号、行距、段距的组合。

这两类配置都是「别人调好的参数」，导入后仍可以继续微调，不满意切回默认即可。

排版定了之后，接下来常调的就是朗读和翻页手感，见 [朗读听书怎么设置.md](朗读听书怎么设置.md)。
