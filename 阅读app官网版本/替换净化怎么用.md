# 替换净化怎么用

> 本篇讲 阅读app 的替换净化规则是什么、一条规则的五行长什么样、怎么导入和新建，以及正文被误删时怎么定位到具体那条规则。

替换净化是 阅读app 里一个「改字」的功能：按规则把正文中出现的内容替换掉或直接删掉。用它去广告尾巴、统一错别字、屏蔽某些词都行；反过来，规则写得太宽也会把正文一起删掉，所以它既是排错工具，也是很多「正文缺字」问题的源头。

## 一、它能解决什么

| 场景 | 规则怎么写 |
| --- | --- |
| 每章末尾都跟着一段广告 | 把广告里固定出现的那串文字填进「被替换内容」，「替换为」留空 |
| 同一个词在不同源上写法不一 | 把错误写法填进「被替换内容」，正确写法填「替换为」 |
| 某些词每次出现都影响阅读 | 同上，留空即删除 |

要注意它改的是**显示出来的正文**，不改原文；关掉规则后原文立刻恢复。

## 二、入口与三种来源

进「我的」→「替换净化」，规则列表就在这里。加规则的三种方式和书源很像：

1. **网络导入**：右上角 `⋮` → `网络导入` → 粘贴规则地址 → 确定。适合一次拿一整套通用规则。
2. **本地导入**：规则文件先传进手机，再走 `本地导入` 选中它。
3. **手动新建**：点右上角 `+` 逐条填。只想处理自己常遇到的那几个词时用这种最省事。

导入进来的规则是**逐条勾选生效**的，不是导入就全开。别人给的合集动辄几十上百条，建议先只勾需要的那几条。

## 三、一条规则的五行长什么样

手动新建时按顺序填五行，含义是固定的：

| 行序 | 填什么 | 说明 |
| --- | --- | --- |
| 第一行 | 替换规则名称 | 自己看得懂就行 |
| 第二行 | 分组 | 可留空，用来归类 |
| 第三行 | 替换规则 | 需要被替换掉的内容 |
| 第四行 | 替换为 | 想替换成的内容；**留空表示删除**第三行那段 |
| 第五行 | 替换范围 | 填书名或源名，只对这一本 / 这一个源生效；留空则对所有书籍和源生效 |

第五行是最容易被忽略、也最该用的一行：把范围收窄到某一本书或某一个源，就基本不会波及别处。

## 四、正文被误删怎么定位到规则

出现「正文缺字漏字、内容缺失」时，按下面的顺序缩小范围：

1. 先把替换净化整体关掉，刷新本章。恢复正常，就说明确实是规则误杀。
2. 再按分组或按条逐批勾回来，复现问题的那一批里就有问题规则。
3. 找到后单独取消勾选它，或者把第三行的关键字写得更具体、把第五行的范围限定到具体书名 / 源名。

整套流程在 [常见问题与排查.md](常见问题与排查.md) 里也列了一份速查版本，两边可以配合着看。

## 五、什么时候不要用它

- 只是想换掉一本书的来源：用「换源」，不是替换净化。
- 正文本身就缺章少段：那是书源的问题，规则再怎么写也补不回来，按 [书源怎么导入和管理.md](书源怎么导入和管理.md) 换源。
- 本地 TXT 打开是乱码：那是文件编码问题，属于 [本地TXT与EPUB怎么导入.md](本地TXT与EPUB怎么导入.md) 的范围，不是替换净化能处理的。
