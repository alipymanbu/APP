# 朗读听书怎么设置

> 本篇讲 阅读app 的朗读功能怎么打开、在线朗读引擎和系统语音引擎有什么区别、默认规则怎么补，以及朗读没声音、断句怪、后台会停这几类问题怎么处理。

阅读app 的朗读适合通勤、做家务时听书，也适合眼睛累的时候换成听的。它的设置入口不在主页：点屏幕中间唤出阅读菜单后，要**长按**朗读按钮才会进设置。本篇讲引擎怎么选、默认规则怎么补，以及没声音、断句怪、后台会停怎么处理。

## 一、打开朗读并进设置

1. 打开一本书，**点屏幕中间**唤出阅读菜单。
2. 底部找到 `朗读` 按钮。
3. **长按** `朗读`（短按是直接开始读）→ 进入朗读设置界面。

进去以后能选朗读引擎、语速、音调、定时，以及切到系统语音。

## 二、两类朗读引擎怎么选

| 类型 | 声音来源 | 联网 | 特点 |
| --- | --- | --- | --- |
| 在线朗读引擎 | 第三方在线合成接口 | 必须联网 | 音色多、自然度高；断网就不出声 |
| 系统语音引擎（TTS） | 手机本地安装的语音包 | 可离线 | 稳定、省流量；音色取决于装了哪个语音包 |

阅读app 内置了一批在线朗读引擎，长按进设置就能看到。**如果列表里只有一两条、没有可选音色**，进设置界面右上角 `⋮` → `导入默认规则`，把默认引擎列表补回来。

用系统语音时，先去手机的「设置 → 无障碍 / 文字转语音」确认已有一个可用的语音引擎（例如系统自带语音或第三方 TTS 应用），否则朗读会静默无声。

## 三、几个值得调的参数

| 参数 | 建议 |
| --- | --- |
| 语速 | 从默认值起步，一次加一档，加太快会吞字 |
| 音调 | 听久了刺耳就压低一档 |
| 定时关闭 | 睡前听设定 30 / 60 分钟，到点自动停 |
| 朗读时息屏 | 打开后锁屏继续读，省电 |
| 逐句 / 逐段 | 断句不自然时切换朗读粒度试试 |

朗读开始后，通知栏会出现控制条，可以暂停、上下句、切章，不必回到阅读界面。

## 四、朗读没声音或中断的排查

| 现象 | 排查方向 | 处理 |
| --- | --- | --- |
| 点了朗读完全没声 | 用的是在线引擎但没网，或系统没有 TTS 引擎 | 换成系统语音；或先在系统里装一个语音引擎 |
| 读两句就停 | 系统省电策略把后台杀了 | 在电池设置里给阅读app「允许后台活动 / 不优化」 |
| 锁屏后停 | 息屏朗读没开 | 朗读设置里打开「朗读时息屏」 |
| 断句很怪、念错字 | 朗读粒度和文本本身的问题 | 改粒度；正文有错别字时先用替换净化处理 |
| 音色列表是空的 | 默认规则没导入 | 设置界面右上角 `⋮` → `导入默认规则` |

朗读走的是正文文本，所以**正文本身有没有取全，决定了朗读能不能读完一整章**。如果同一本书朗读到一半反复停、或者念出来缺段，问题多半在书源正文，先按 [书源怎么导入和管理.md](书源怎么导入和管理.md) 换一个源再试。

听书时不方便看屏幕，字号、字体这类排版设置基本用不上；等回到屏幕上再按 [阅读界面与翻页设置.md](阅读界面与翻页设置.md) 调即可。
