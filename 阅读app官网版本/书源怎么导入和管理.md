阅读app 是「书源驱动」的阅读器：能搜到哪些书，取决于你导入了哪些书源。所以第一次装好后如果书架是空的、搜索没结果，基本就是还没配书源。这篇按「导入 → 管理 → 失效处理」三步讲。

## 一、书源是什么

书源是一份规则文件，里面写好了「去哪里搜、怎么取目录、怎么取正文」。阅读app 按这份规则把网页内容取回来，重新排版后显示在阅读界面上。

- 文件后缀通常是 `.json`，也有 `.txt`。
- 一个书源对应一个站点；日常导入的是**合集**，一次几十到上千条。
- 书源不是软件自带的，由第三方维护分享，所以同一本书在不同源上的排版、完整度、更新速度都不一样。

## 二、三种导入方式

### 网络导入（最常用）

1. 进底部导航的「我的」→「书源管理」。
2. 点右上角 `⋮` → `网络导入`。
3. 把书源地址粘进输入框（一般形如 `https://某个域名/xxx.json`），点确定。
4. 加载出书源列表后，勾选需要的，或直接全选，再点确定。

地址打不开、一直转圈或提示读取失败，都是在这一步就报出来，不会写进书源列表。

### 本地导入

1. 先把书源文件传进手机（发到自己微信 / QQ、或用数据线拷进 `Read` 文件夹都可以）。
2. 「我的」→「书源管理」→ `⋮` → `本地导入`。
3. 在系统文件选择器里找到那个文件并选中它。
4. 勾选书源后点确定。

导入失败时先看后缀：官方文档提到过 `.json` 在部分机型上导不进去，把后缀改成 `.txt` 再试一次即可。

### 二维码导入

在书源分享页截图或长按识别二维码，选 `⋮` → `二维码导入` 扫码添加。适合从别人的分享页直接拿一份整理好的源。

## 三、导入之后怎么管理

书源管理页的批量操作集中在两个菜单里：右上角 `⋮` 是导入类操作，右下角的菜单是**对选中的书源**做操作。

| 操作 | 作用 |
| --- | --- |
| 启用所选 / 禁用所选 | 暂时不用的源留着但关掉，搜索时就不会走它 |
| 添加分组 / 移除分组 | 把源按题材或来源分组，列表长了才好找 |
| 置顶所选 | 质量好的源排在前面 |
| 导出所选 / 分享选中源 | 导出成文件换机带走，或生成链接/二维码给朋友 |
| 校验所选 | 批量测一遍还能不能用 |

列表里书源名右侧的标记代表它有没有「发现」：

- 绿点：有发现，且已启用。
- 红点：有发现，但没启用。
- 没有标记：这个源没有发现页，只能搜索。

## 四、书源失效了怎么办

站点改版、换域名、加验证，都会让书源失效，这是常态，不是软件坏了。

1. 进「书源管理」，全选 → 右下角菜单 → `校验所选`。
2. 校验失败的源会被归到 `失效` 分组，进这个分组可以批量禁用或删除。
3. 要补新源，用「网络导入」重新导入一份更新的合集；只想补单个站点的源，单独导入那条即可。
4. 只是**某一本书**看不了、其它书正常：在阅读界面点屏幕中间唤出菜单，用「换源」从其它书源里挑一个能出正文的即可，不用动书源列表。

一组源能用多久没有保证，以你导入当天的可用性为准；定期重跑一次校验，比留着几百条失效源更省事。
