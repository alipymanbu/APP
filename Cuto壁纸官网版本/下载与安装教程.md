## 一、先说清这一份是哪个版本

Cuto壁纸 是一款手机壁纸应用，走的是「编辑人工挑选、每天一张」的路子，图片绝大多数来自免费无版权图库 Unsplash，App 内没有广告。安装本身不复杂，真正容易卡住的只有两处：包从哪儿来、自动换壁纸要的后台权限怎么给对。

动手前先对照下表，确认手上这一份是对的：

| 项目 | 这一份的情况 |
| --- | --- |
| 应用名 | Cuto壁纸 |
| 开发者 | 深圳市平常罐子网络科技有限公司 |
| 包名 | `com.sspai.cuto.android` |
| 版本号 | v3.0.3 |
| 安装包大小 | 7.30 MB |
| 安装包 MD5 | `7248D42F2C6D3AE84F522500893D3C6B` |
| 适用设备 | 安卓手机、安卓平板 |
| 是否需要联网 | 浏览、下载、自动换壁纸都要网络；换本地导入的图片不需要 |

**版本号别拿搜索结果里的来对。** 应用商店和第三方下载页显示的，通常是官方当前最新版，与这一份未必是同一个。想确认装得对不对，只看两项：包名是不是 `com.sspai.cuto.android`，版本号是不是 v3.0.3。

**最低系统版本不写死。** 各家第三方页面标注的互相矛盾（从 Android 4.0 到 8.0 都有人写），都不是官方口径。最省事的判断办法是打开[应用宝上的 Cuto壁纸 页面](https://sj.qq.com/appdetail/com.sspai.cuto.android)，按钮能点「安装」就说明你的系统版本够用；真装不上时系统会自己拦下来，不会装到一半坏掉。

## 二、从网盘把安装包取到手机

安装包通过夸克网盘分享。相比在搜索结果里随手点一个「立即下载」，从网盘转存再下载的好处是链接固定，文件不会被中途替换成别的东西。

1. 在手机上打开 [Cuto壁纸 安装文件资源（夸克网盘）](https://pan.quark.cn/s/c5631fd4b5a8)。手机浏览器和夸克 App 都能打开，**建议用夸克 App**，浏览器下大文件容易被切后台打断。
2. 点「保存到我的网盘」，把文件转存到自己账号下。转存之后，后续下载就不再依赖原分享链接还挂着。
3. 回自己的网盘找到这个文件，点下载，等它落到手机存储里。
4. 下完核对两件事：文件名结尾是 `.apk`；大小在 7.30 MB 左右。差得多的多半没下完，删掉重来。

更习惯在电脑上操作的话：电脑端网盘下好，用数据线拷到手机 `Download` 目录，效果一样；之后从手机「文件管理」里点它安装。

手上有校验工具可以顺手算一遍 MD5，和上表的 `7248D42F2C6D3AE84F522500893D3C6B` 比一比：一致说明传输没出错，不一致就重下一遍。不查也不影响安装，这只是多一层保险。

## 三、安装：系统会拦一次，放行即可

这一份是手动安装的，不是从应用商店点的「安装」，所以点安装包时系统会拦一下，提示「不允许安装来自此来源的应用」之类。这是安卓对非商店来源应用的常规限制，不代表文件有问题。

1. 打开「文件管理」，进 `Download`（下载）目录，找到刚下好的 apk，点它。
2. 出现拦截提示时，点提示里的「设置」，打开**允许安装此来源的应用**开关。
   - 部分机型要去「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，找到刚才用来打开文件的那个 App（文件管理或浏览器），单独放行。
3. 回安装界面点「安装」，等进度条走完。
4. 出现「打开 / 完成」时先点「完成」。首次启动前把权限一次理顺，比进去之后反复弹窗省事。

## 四、首次打开要给的权限

| 权限 | 用途 | 建议 |
| --- | --- | --- |
| 通知 | 换壁纸后的提示，点进去能看到刚换上的是哪张 | 建议给。不给的话「更换通知」这个用法直接没有，自动换壁纸本身照常 |
| 存储 / 照片与媒体 | 读你导入的本地图片、把壁纸存到相册 | 建议给。不导入本地图、不保存图片的话可以不给 |
| 网络 | 拉取壁纸列表与图片 | 必给，而且要在系统里允许它联网 |

**联网权限单独提一句**：部分国产系统默认会把新装应用的移动数据、WLAN 关掉，这时 Cuto壁纸 打开是空白的。去「应用信息 → 联网控制」里把 WLAN 和数据都勾上。

## 五、装完先做三步自检

1. **能打开、有内容**：点图标进主界面，能看到一批壁纸缩略图。空白的话先回上一节检查联网权限。
2. **能设成壁纸**：随便点开一张，按界面提示设为壁纸，回桌面看换没换。
3. **能记下这一张**：点「收藏」，退出再进来，看它还在不在收藏里。

三步都过，基础使用就通了。要让手机自己定时换壁纸，还差一步后台保活，做法见 [自动换壁纸怎么设置.md](自动换壁纸怎么设置.md)；设好了却到点没换，见 [自动换壁纸不生效怎么排查.md](自动换壁纸不生效怎么排查.md)。

## 六、升级与卸载要注意的

- **升级**：新版本会换一个安装包文件名，直接装新包覆盖即可，一般不用先卸载。**先卸载再装反而会把本地收藏和设置一起清掉**——安卓默认连应用私有目录一起删。
- **卸载**：卸载会清掉本地收藏与已导入的本地图片列表。要留着，先在 App 里登录账号把收藏同步上去，再卸载。
- **安装包删了**：任何时候都能回文首那条 Cuto壁纸 安装文件资源的链接重新取一份；已经转存过的不受原分享链接影响。
