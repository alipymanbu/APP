# Cuto壁纸 手机后台保活怎么设置

> 自动换壁纸要能用，前提是系统不把 Cuto壁纸 清掉。这里是各品牌手机上要动的那几个开关。

国产定制系统对后台应用管得比较严，默认设置下 Cuto壁纸 很难一直待着，于是「到了点没换壁纸」这种事几乎必然发生。下面按品牌列出官方给出的设置路径——路径名字各家不一样，但要做的事其实是同一批。本篇对应的是网盘里那份 v3.0.3（包名 `com.sspai.cuto.android`）。

## 一、要放行的其实是这四件事

先在概念上分清，再去对应机型找入口，会快很多：

| 要放行的事 | 各家常见的叫法 |
| --- | --- |
| 让它能自己醒过来 | 自启动、后台自动启动、允许自动启动 |
| 让它能在后台待着 | 省电策略、电池优化、后台高耗电、耗电管理 |
| 让它能连上网 | 联网控制、网络管理、流量使用情况 |
| 让它别被顺手清掉 | 多任务卡片加锁、清理白名单 |

四个里少一个，自动换壁纸都可能停，而且不会报错——只会在几天后被发现壁纸一直没变。

## 二、小米：官方给的三步

1. 长按桌面上的 Cuto壁纸 图标，选「应用信息」。
2. 打开「自启动」。
3. 在「联网控制」里勾上 WLAN 和数据；把「省电策略」改成「无限制」。

## 三、vivo：官方给的四步

vivo 这一套里有一项别的品牌不太一样，容易被漏掉：**「修改壁纸」也是一个要单独放行的权限**。

1. 「设置 → 电池 → 后台高耗电」，在列表里找到 Cuto壁纸，改成**允许后台高耗电**。
2. 「设置 → 隐私 → 权限管理 → 权限 → 自启动」，选「全部」，找到 Cuto壁纸并打开。
3. 退回上一级「权限」页面，选**修改壁纸**，把 Cuto壁纸 设为允许。
4. 再退回上一级，选**网络管理**，允许 Cuto壁纸 使用移动数据和 WLAN。

第 3 步跟自动换壁纸直接相关：这项没放行，App 能在后台跑、也取得到图，但换不了壁纸，现象和「没运行」很像。

## 四、三星与其他品牌

官方文档同样为三星等品牌准备了单独的操作说明，入口位置与上面两家类似：都在「应用信息」或「设置 → 应用管理」附近，逐项找上面那张表里的四件事即可。找不到对应名字时的通用找法：

- 在系统设置里直接搜**「自启动」**和**「电池优化」**，多数系统会把对应入口搜出来；
- 在「应用管理 → Cuto壁纸」这个页面里上下翻一遍，权限、联网、电池、通知通常都在这一页集中。

## 五、华为手机：官方给的通用检查清单

华为官方支持页面并不针对某个应用，而是一份「应用无法后台运行」的通用排查表，逐条对一遍即可：

| 设置项 | 怎么改 |
| --- | --- |
| 锁定后台应用 | 打开 Cuto壁纸 后进多任务界面，下拉它的卡片加锁 |
| 允许后台运行 | 搜「应用启动管理」，关掉 Cuto壁纸 的自动管理，在弹框里勾选允许后台活动 |
| 电池优化 | 搜「电池优化」，把 Cuto壁纸 设为**不允许**（即不优化这个应用） |
| 省电模式 | 「设置 → 电池」里关掉省电模式 / 低电量模式 |
| 休眠时保持网络 | 「设置 → 电池 → 更多电池设置」里开启休眠时始终保持网络连接 |
| 开发者选项 | 若曾开启过开发者选项，确认里面的**「不保留活动」是关闭**的，后台进程限制为「标准限制」 |

华为官方还提了两点值得留意：**后台应用开太多**会导致运行内存不足，久未使用的应用被系统关掉；**第三方管家类清理软件**可能会强制清理后台，如果装过这类工具，先把它卸载再观察一轮。

## 六、设完自己验一遍

改完设置别就放下，花几分钟确认它真的会跑：

1. 把自动换壁纸的间隔设成一个几分钟的小值（做法见 [自动换壁纸怎么设置.md](自动换壁纸怎么设置.md)），同时打开更换通知。
2. 熄屏放着，到点后亮屏看一眼锁屏或桌面。
3. 换了 → 四件事都到位了，把间隔改回你想要的频率。
4. 没换 → 按 [自动换壁纸不生效怎么排查.md](自动换壁纸不生效怎么排查.md) 逐条排，重点复查「省电策略」和 vivo 那台机器上的「修改壁纸」权限。
