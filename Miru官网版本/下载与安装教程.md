Miru 是开源的多平台媒体应用，本体不带任何内容，装完得自己加扩展源才有东西可看。本篇只解决一件事：把网盘里这份包装进设备，并确认自己装的是哪一版。

## 一、先弄清网盘里这份包是哪一版

网上搜到的版本号通常是当时的最新发布版，而网盘里这份是整理文档时核对过的版本，两者未必是同一个。本文出现的版本号、包名、体积都以下表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | Miru |
| 版本号 | 1.8.1 |
| 包名 | `miru.miaomint` |
| 安装包体积 | 17.54 MB |
| MD5 | `F81A3F5A733BA30DD9BE789EFB54A068` |
| 开发方 | Miru Project，开源项目，许可证 AGPL-3.0 |

安装包本体在头部那条「Miru 安装文件资源（夸克网盘）」里，转存到自己网盘后下载即可。

两件事先说明白：

- **版本号怎么读**。官方按 `v1.8.x` 这样的版本号逐个发布，发布页在代码仓库的 Releases 页（[github.com/miru-project/miru-app](https://github.com/miru-project/miru-app)）。当前最新是哪个数字，以该页当时显示为准。
- **同名软件不止一个**。搜索引擎里叫「Miru」的产品有好几款，认包名 `miru.miaomint` 最稳，区分方法见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。

## 二、装之前要核对的两件事

**第一，设备类型。** 这是安卓应用，官方发布页同时提供 Windows 版安装包，**没有 iOS 版** —— iPhone 与 iPad 装不了。苹果设备上只能用网页版，而网页版能做的事情是受限的（官方自己也建议优先用客户端）。

**第二，CPU 架构。** 官方发布页把安卓包按 CPU 架构分开发布：`app-arm64-v8a-release.apk`、`app-armeabi-v7a-release.apk`、`app-x86_64-release.apk` 三个。近几年出的手机绝大多数对应 **arm64-v8a**；网盘里给的是一个安装包，装上时若提示「应用与设备不兼容 / 无法解析」，先怀疑是不是架构对不上，可以到官方发布页对照一下自己的机型。

## 三、安卓安装步骤

1. **转存并下载**：从 [Miru 安装文件资源（夸克网盘）](https://pan.quark.cn/s/006b0400e496) 把 APK 转存到自己网盘，再下载到手机；
2. **允许安装未知来源应用**：在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给用来打开安装包的那个应用（文件管理器或浏览器）打开开关；
3. **签名冲突就先卸载**：手机里若已有同包名但签名不同的版本，安装会直接失败，先把旧的那个卸掉再装；
4. **装完先别急着搜索**：搜索为空是正常的，接下来要做的事见第五节。

## 四、Windows 安装

官方发布页给 Windows 两个包：`miru-setup-<版本>.exe`（安装版）与 `Miru-<版本>-windows.zip`（免安装压缩包）。两个都能用，装不上或启动异常时可以互相换着试。

Windows 端的界面逻辑、设置项与手机端基本一一对应，中文怎么切见 [中文界面与语言设置.md](中文界面与语言设置.md)。

## 五、第一次打开先做两步

打开后界面是**英文的**，首页也是空的 —— 这两点都不是装坏了：

1. **改中文**：进设置把 Language 选成中文，位置与步骤见 [中文界面与语言设置.md](中文界面与语言设置.md)；
2. **装扩展**：Miru 本体不带内容，要先到扩展页从官方仓库装几个源，装法见 [扩展怎么安装与管理.md](扩展怎么安装与管理.md)。

这两步做完才算能正常用。

## 六、装完做一次最小验证

装好扩展后，回首页搜一个常见的片名或漫画名：能搜出结果、点开能正常播放或翻页，就说明安装、语言、扩展三件事都通了。

搜不到结果、点开报错、或者一直转圈，按 [常见问题与排查.md](常见问题与排查.md) 往下排。
