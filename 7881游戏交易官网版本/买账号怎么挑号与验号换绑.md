买号的坑集中在两个地方：一是下单前没看清买的是哪类商品，二是验号与换绑这两个环节里做了不该做的事。这篇按你实际会走的顺序讲，每节末尾都给出一个能立刻执行的判据。

## 一、先分清你买的是哪一类

平台上的商品不是一个品种，不同类型走的流程完全不同：

| 商品类型 | 交付方式 | 是否需要客服介入 |
| --- | --- | --- |
| 游戏账号 | 客服协助验号 → 改密解绑 → 换绑给你 | 需要，全程在客服引导下进行 |
| 游戏币 / 金币 | 你在游戏内与卖家（或收货商）当面/邮件交付 | 视商品而定，挂单商品多为双方自行交付 |
| 装备、道具 | 一般按游戏内约定方式交付 | 同上 |
| CDK、激活码、礼包类 | 下单后系统自动发码，即「自动发货」类商品 | 不需要 |

账号类商品是唯一有「验号 + 换绑」两段式交接的，也是翻车最多的。后面几节主要围绕它展开；如果买的是自动发货类，下单后在订单里直接取码即可。

## 二、在客户端里把目标商品筛出来

客户端首页给了几个直达频道：买账号、账号估值、游戏币、精品账号；顶部的搜索框支持按游戏名或商品编号搜索。进「我要买」之后可以先在手游 / 端游之间切，再按道具类型、区服、角色等条件往下筛（具体筛选项按不同游戏会有差别，以你所在游戏的页面为准）。

按下面这个顺序筛，效率最高：

1. 先锁定**区服**。跨服的账号对你没用，这一步放在价格之前；
2. 再看**保障标识**（下一节详述），它决定了出事之后有没有兜底；
3. 最后看价格与商品描述细节。

搜不到你要的游戏、或者客户端版本明显落后时，重装一份确定版本的包最省事，从这里取：[7881游戏交易 安装文件资源（夸克网盘）](https://pan.quark.cn/s/837aaaf74c4f)。

## 三、下单前要看的两类标识

商品列表和详情页上会出现两类保障标识，它们不是装饰，直接决定你能拿到什么：

| 标识 | 保什么 | 谁出钱 |
| --- | --- | --- |
| 找回包赔 | 账号被卖家恶意找回时，凭凭证申请赔付，平台全额赔付 | 服务随商品附带，账号不转手时长期有效 |
| 安心购 | 商品被找回、被运营商收回、被官方封号等情况，优先找回或全额退款 | 买家另付服务费，按商品类型与游戏不同计费 |

两者的保障范围、期限、举证要求和终止条件都不一样，挑号前先看 [找回包赔与安心购怎么用.md](找回包赔与安心购怎么用.md)，再决定要不要为安心购多付那笔服务费。

## 四、从下单到拿货：官方流程的九步

官方给出的账号交易流程是固定的九步，其中第 3、5、6 步需要你配合：

| 步骤 | 谁在做 | 你要做什么 |
| --- | --- | --- |
| 1 发布账号商品 | 卖家（需先签署账号转让协议，审核通过后上架） | 无 |
| 2 审核账号安全信息 | 客服（核实是否存在找回记录） | 无 |
| 3 截图验号 | 买家 / 客服 | 见下一节 |
| 4 确认购买 | 买家 | 想清楚再点，点了之后不能单方面取消 |
| 5 卖家资料审核 | 卖家与客服 | 普通订单要本人信息；终身包赔与安心购订单还要父母及亲属相关信息，卖家不配合就走不动 |
| 6 账号资料换绑 | 卖家、客服、买家 | 提供接收验证码的手机 / 邮箱，配合改密 |
| 7 交易完成 | 客服把账号发给你，你确认 | 收到后 **30 分钟内**确认 |
| 8 签署服务协议 | 卖家与买家 | 协议约定账号永不找回 |
| 9 卖家资金到账 | 平台打款给卖家 | 无 |

第 6 步的等待时间按账号区服不同：QQ 区没有审核时间，直接换绑；微信区在换绑操作后 72 小时才换绑成功。这 72 小时里页面会一直显示在换绑中，属于正常流程，不是卡住了。

## 五、验号环节的边界

只有王者荣耀支持用营地自助验号，其他游戏暂时由客服人员上号截图确认。验号期间有三条硬性限制，踩了后果自负：

- **不要进游戏做任何操作**，特别是不要使用账号内的道具、货币；
- **不要充值**，任何金额的充值都会把换绑流程搞复杂，甚至导致换绑失败；
- 验号全程以客服引导的方式为准（扫码上号 / 提供账号密码上号 / 平台截图三选一，按客服指定）。

换绑完成前，如果因为你的上号操作给卖家账号造成损失，赔偿责任在你这边；平台只做协商，金额由双方自行确定。

还有一条容易被忽略：**商品标题与截图不作为最终商品结果**，游戏内的时限道具、日常消耗品、流通货币、皮肤英雄数量都可能已经变化，一律以验号结果为准。所以你提号之后要自己再复验一遍——官方给的窗口是提号后 30 分钟内，结算前不反馈就视为接受，包括描述不符等问题。

## 六、确认交易之后的边界

- **确认验号无误就等于确认交易**，进入换绑阶段后不再接受单方面取消；
- 如果因为个人原因一定要取消，需支付号价金额 **5% 的违约金**，由守约方收取；
- 换绑交接验证码、进入审核之后（包含游戏换绑审核期、挂 P 设备、新注册 QQ 15 天换绑等待期等情况），同样不接受单方面取消，只能双方协商，平台不判定责任；
- 如果确实是游戏厂商原因导致首次换绑失败，双方配合平台引导仍无法完成交付的，按平台方案无责取消订单；
- 交易期间如果证实账号有黑号记录，可以取消交易，各方都不承担责任。

## 七、拿到账号后立刻做的三件事

1. **改密码**：换成只有你知道的密码，别沿用卖家给的那一串；
2. **换成自己的绑定**：把手机、邮箱、密保换成你能控制的，这一步不做，后面的保障都容易失效；
3. **记住二次实名的延迟**：腾讯系游戏的人脸认证与「可二次更改」这类状态，因异地等原因可能有 30 天左右的延迟展示，签收后 30 天内没有任何反馈，之后再出问题平台不承担担保责任。

## 八、买家侧的订单处理中心

交易中的订单都在「订单处理中心」里跟进，各区块的用途如下：

| 区块 | 用途 |
| --- | --- |
| 订单状态区 | 切「进行中 / 已完成 / 已取消」 |
| 订单列表区 | 你近期的订单记录 |
| 对话角色区 | 默认与卖家联系；要找客服要点「联系订单客服」，右侧跑马灯是安全警示 |
| 发货流水区 | 看发货与处理进度 |
| 操作区 | 收到货点「确认收货」；少收或没收到点「未收到货」并联系客服 |

聊天与沟通都留在平台内。平台本身不会以任何名义让你私下交易，对方一旦提出加微信、走站外，或者引导你提供联系方式、脱离平台付款，直接上报客服——这是判定的关键动作，也是你自己唯一的举证机会。

出问题先翻 [常见问题与排查.md](常见问题与排查.md)，涉及赔付申请的看 [找回包赔与安心购怎么用.md](找回包赔与安心购怎么用.md)。
