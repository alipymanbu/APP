# 7881游戏交易 游戏币与道具交易怎么做

> 本篇讲非账号类商品（游戏币、装备、道具、点卡、CDK）的两条出货路径怎么选、交付时怎么留证，以及自动发货类商品怎么发货。

游戏币、装备、道具这类商品和账号最大的区别是：**交付在游戏内完成，平台只保证资金与规则，不替你发货**。所以决定你能不能顺利收钱的，是交付方式和发货凭证。先把两条路径分清，再往下看细节。

## 一、挂单卖和出货给收货商，先选一条

| 维度 | 挂单卖 | 出货给收货商 |
| --- | --- | --- |
| 入口 | 「我要卖」→ 选游戏、类型、区服 → 填写发布 | 收货网入口，见下一节 |
| 交易对手 | 由买家下单，等单来 | 你先挑收货商，价格由对方挂出 |
| 价格 | 你自己定 | 按收货商的收货价 |
| 成交速度 | 取决于行情与曝光 | 对方在线就快，适合走量 |
| 提现手续费 | 售得资金提现按收费标准收取 | 出货订单累积的出货额度可享优惠提现额度，DNF 与魔兽怀旧服出货额度免提现手续费 |

判断标准很简单：**单件、想卖高价 → 挂单；批量、想快速回款 → 出货**。提现手续费那一条是出货侧的实际优势，走量的话差距会拉开。

发布类操作在手机客户端与 PC 端都能做；而自动发货、批量发布这两项，官方帮助里给出的操作路径都在 PC 端。手机端主要用来跟单、看消息、收推送，装一份客户端即可：[7881游戏交易 安装文件资源（夸克网盘）](https://pan.quark.cn/s/837aaaf74c4f)。

## 二、出货给收货商：三个入口

官方给出的出货入口有三个，任选其一：

1. **首页 → 收货网**：进去后按游戏与类型搜索，列表就是各家收货需求；
2. **商品列表页**：先选好区服（不选区服时收货网入口不显示），选中对应商品并填写你要出货的数量；
3. **商品发布页**：页面右侧就是收货网入口，同样选商品、填数量。

前两个入口都带「查看更多」，点进去能跳到收货网列表页看更多收货商家。选定商家后进入填单页，按提示把信息填完点「立即出货」，订单就生成了。

选择商家时务必核对**区服与阵营**，这一步填错，货物会交付给错误的对象，损失由自己承担。

## 三、订单处理中心：出货侧怎么操作

出货订单都在订单处理中心跟进，页面分四块：左侧订单列表（已完结的订单保留 3 天）、中间聊天模块（可与收货商、客服沟通）、右上订单详情、右下操作区。

按顺序做这几件事：

1. 长时间没有收货商联系你收货，可以直接申请撤单，并要求收货商赔付；
2. 收货商确认收货角色后，角色信息会出现在聊天框与订单详情里，**由你主动在游戏内联系对方交易**；
3. 交易完成后联系收货商完成订单；如果你实际出货数量少于订单数量，要确认「部分完成」，不要直接点完成全部；
4. 若实际数量多于订单数量，多出来的部分平台不负责。

第 2 步里有一句是原话、也是最重要的一句：**切记不要接受任何发起的交易**。你主动发起交易，对方才知道货是从哪来的；由对方发起、你被动确认，容易被钓鱼或掉包。

## 四、发货凭证怎么留

纠纷判定以你的**发货凭证**为准。口径如下：

- 交付全程录屏或录视频，画面里要能看到游戏角色名、交易时间、物品与数量；
- 邮件 / 拍卖行等交付方式，同时保留邮件记录或交易流水截图；
- 凭证与订单能对上：订单里的收货角色、数量，与视频里出现的一致；
- 一次出货对应一次录制，别用旧视频顶替。

数量不足时按第三节所说点「部分完成」，剩下的数量另开订单或与收货商协商，这样凭证与订单金额才对得上。

## 五、自动发货：CDK、激活码、礼包怎么发

自抽号、激活码、礼包类商品可以挂成自动发货，买家下单后系统直接发码，你不需要盯着。设置流程在 PC 端：

1. 登录 PC 端 → 我要卖 → 选类目 → 选择「自动交易」（这一类目不需要额外的准入服务）；
2. 在商品库存处粘贴 CDK 库存：**每换行一件，单次最多 5000 字**，库存数量按换行实时计算；
3. 发布成功后，该商品在列表里会带「自动发货」标记；
4. 后续补货、删码走「个人中心 → 我是卖家 → 我的商品管理 → 选择 CDK 商品 → 库存管理」，支持批量新增、批量删除和单条编辑。

库存与订单状态的对应关系是固定的，知道这个就不会疑神疑鬼：

| 订单结果 | 库存变化 |
| --- | --- |
| 订单成功 | 库存自动减少，对应码标记为已售出 |
| 订单部分完成 | 同上，库存自动减少 |
| 订单取消 | 默认把库存标记为已退回；买家已提取的 CDK 会被标记为可出售 |

粘贴库存这一步最容易出错：多一个空行就多发一件，粘贴前先把表格里的空行清掉，粘完核对一次系统算出的库存数量再发布。

## 六、这类商品有没有保障

游戏币、装备、道具类商品同样可以带保障标识，但保障与费用和账号类不同：

- **安心购**：这类商品的服务期限与账号类不一样，费率按游戏不同在订单金额的 1% 至 5.5% 区间内收取，具体见 [找回包赔与安心购怎么用.md](找回包赔与安心购怎么用.md)；
- **找回包赔**：只针对「账号被找回」这一种情况，非账号类商品不适用。

也就是说，卖游戏币和道具时不用关心包赔；买家如果为订单买了安心购，理赔时要拿出的举证里包含商品名称、数量与交易角色名，这些都要与交易时一致——你按订单如实交付，这部分自然对得上。

订单、交付、提现过程中卡住，先查 [常见问题与排查.md](常见问题与排查.md)；卖的是账号而不是币和道具，回 [卖账号怎么发布与收款提现.md](卖账号怎么发布与收款提现.md) 看对应流程。
