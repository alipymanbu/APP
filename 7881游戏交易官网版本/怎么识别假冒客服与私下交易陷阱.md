这个平台的骗局几乎都指向同一个动作：把你从平台里拉出去。交易规则、担保、凭证全都在站内生效，一旦对方让你加微信、走站外付款、或者在游戏里私下交接，你已经不在任何保障范围内了。下面这些判据不用记全，记住第一条就够用。

## 一、官方客服不会做的几件事

官方协议里逐条写明了工作人员的行为边界，这几条反过来就是最好的识骗判据：

| 官方声明 | 对应的骗局说法 |
| --- | --- |
| 工作人员不会在游戏里向你索取任何游戏账号或平台账号信息 | 游戏里有人自称客服、找你要账号密码 |
| 不会以任何名义让你私下交易 | 让你加微信 / QQ 私下转账、私发装备 |
| 不会在游戏里索取平台账号信息、不会要求变更角色名、交易地点或删除角色 | 让你把货物交给「另一个角色」 |
| 交易成功后不会在游戏里再向你取回任何物品 | 交易完成后又来找你要「验证一下」 |
| 官方 400 电话没有外拨功能 | 接到自称该号码的来电，一律按诈骗处理 |

再补一条平台的硬规则：**你也不能主动联系对方私下交易**，双方都踩线的结果是账号被永久封停，钱货都追不回来。

## 二、官方列出的高频骗局类型

平台的「交易安全警示」分类下有一份持续更新的名单，这些名字本身就值得记一遍：

- **假冒客服「缴纳保证金」诈骗**：对方以「订单异常、需要缴纳保证金才能放款」为由要钱，或声称「钱被平台冻结了，先转一笔解冻」；
- **钓鱼网站**：搜索「7881」时出现的仿冒站点、仿冒登录页，输入账号密码即被窃取；
- **私下交易付款不发货**：绕开平台付款，付款后对方不发东西；
- **卖家恶意假发货**：卖家用假凭证或未实际交付来蒙过订单；
- **刷单 / 兼职诈骗、套路骗、网购退款诈骗、假冒国家机关诈骗**：这几类是通用的电诈套路换了个马甲，凡是要求先付钱、先充值、先提供验证码的，都按诈骗处理。

共同特征只有一个：**钱或货的流向偏离订单**。订单是唯一的账，任何要求你离开订单去操作的，都可以直接终止对话。

## 三、代练类订单的特殊风险

代练不是「买个东西」这么简单——你要把账号交给别人操作一段时间，风险敞口完全不同：

- 官方在买家须知里明确提示：**代练过程中账号可能因游戏官方检测、违规操作等原因被封停或处罚**，下单即视为已知晓该风险；
- 因卖家违规操作导致账号损失的，买方向卖家索赔，平台提供必要协助；
- 卖家一侧的义务是：仅在买家授权范围内操作，不得违规使用买家个人信息，不得以买家名义从事与代练无关的行为，违规造成损失需全额赔偿。

另外，官方对代练与交易中的作弊、恶意、欺诈行为列了明确的处理口径：

| 类别 | 典型行为 |
| --- | --- |
| 作弊类 | 使用外挂、演员刷分、卡分、伪造截图 |
| 恶意行为 | 毁号、恶意撤销订单、虚假提交完成 |
| 欺诈类 | 盗号、冒充号主骗钱、登录 QQ / 微信诈骗 |

这几类一经发现，平台的处置是封停账号、冻结资金、协助买家维权，情节严重的移交司法机关。

## 四、发现异常时的三步动作

1. **停手**：不要再付款、不要再交付物品、不要把验证码给对方。已经进入游戏交易流程的，直接中断；
2. **留证**：把聊天记录、对方账号 ID、订单号、转账凭证截图保存下来。游戏内的交付过程本来就该录屏，这一步在防骗里同样有用；
3. **走站内上报**：在订单处理中心点「联系订单客服」上报，不要去找搜索结果里的「客服电话」。

如果钱已经转出去了、且落在平台主体名下的情形，帮助中心的「交易安全警示」分类里有专门一条讲怎么处理，按它给的官方渠道走，别信任何主动联系你的「内部渠道」。退款、冻结、解冻这类涉及资金的动作，只认你在站内操作的记录。

交易本身怎么走、凭证怎么留，见 [买账号怎么挑号与验号换绑.md](买账号怎么挑号与验号换绑.md) 与 [卖账号怎么发布与收款提现.md](卖账号怎么发布与收款提现.md)；纠纷已经发生、要按流程举证的，看 [交易纠纷怎么举证与判定.md](交易纠纷怎么举证与判定.md)；其他报错与官方渠道汇总在 [常见问题与排查.md](常见问题与排查.md)。
