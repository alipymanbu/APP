卖号的收益能不能顺利落袋，卡点通常不在「有没有买家」，而在资料齐不齐、配合快不快、提现条件符不符合。下面按你实际的操作顺序排，每一步都给出可执行的判据。

## 一、开卖前必须过的三关

| 关卡 | 具体要求 | 不满足会怎样 |
| --- | --- | --- |
| 实名认证 | 账号完成实名，见 [注册登录与实名认证.md](注册登录与实名认证.md) | 发布、提现、商家服务全部走不通 |
| 年龄 | 未满 18 周岁不得参与平台任何交易 | 无法开卖 |
| 账号转让协议 | 发布账号类商品前需先签署账号转让协议 | 商品不上架，审核不通过 |

另外提前想好一件事：**普通订单只要本人相关信息，而终身包赔与安心购订单还需要父母及亲属相关信息**。这两类订单卖得更快，但资料环节更细，家里人不一定能随时配合——发布时就按你要走的订单类型把资料准备好。

## 二、发布商品的路径

1. 登录后进「我要卖」，先在手游 / 端游之间选一类；
2. 选游戏：可以用首字母筛选，也可以直接用搜索框找；
3. 选商品类型与所在区服——区服这一步别凭记忆填，要对准游戏内实际区服；
4. 依次填写商品信息、账号信息、扩展信息，点「完成并发布」；
5. 发布成功后想改、想下架，去「我是卖家 → 已发布的商品」里管理。

**批量发布**是另一条路：需要先在「个人中心 → 商家服务」里找到「商品批量发布」提交申请，申请前必须完成实名认证，审核通过后再进批量发布页面使用。只有零星几个号的卖家，用不上这条。

## 三、商品信息怎么写才少退回

发布之后要走审核，账号安全信息由客服核实（这一步买家看不到，但决定商品能否上架）。想少一次退回，把下面几条对着填：

- **区服写到最小可交易单位**。大区写错等于商品发错区，交易阶段才发现就只能取消；
- **数量与内容按游戏内实际写**。时限道具、日常消耗品、流通货币、皮肤英雄数量都处在变化中，平台也明确说明商品标题与截图不作为最终商品结果，以买家验号结果为准；
- **不要用标题做承诺**。写「必出」「永久包换」这类话，既不进担保范围，还容易在纠纷里被当成争议点；
- **图要能看清关键信息**。买家主要靠截图判断值不值得问，段位、区服、皮肤与道具数量这些关键项拍不清楚，商品就很难被点开；

## 四、订单来了之后的配合动作

买家下单后，平台会通过短信与客户端推送通知你。从这一刻开始的节奏是固定的：

| 阶段 | 你要做什么 | 时间要求 |
| --- | --- | --- |
| 验号 | 协助买家扫码上号，或按客服指定提供账号密码 / 截图 | 尽快，别拖 |
| 卖家资料审核 | 按订单类型提交本人信息（包赔 / 安心购订单还需父母及亲属信息） | 以客服提示为准 |
| 换绑 | 用客服要求的方式把账号绑定换成买家的手机 / 邮箱 | QQ 区直接换绑；微信区换绑后 72 小时生效 |
| 收款 | 买家确认后，平台打款到你的平台账户 | 包赔订单立即到账，安心购订单 2 小时，普通订单 24 小时 |

客户端收不到订单提醒是最容易吃亏的一环：买家的 30 分钟确认、客服的换绑通知都是靠推送走的。收不到就自己定时进「订单中心」看，或者先把客户端更新到当前版本，安装包见 [7881游戏交易 安装文件资源（夸克网盘）](https://pan.quark.cn/s/837aaaf74c4f)。

界面一直在「进行中」不动，先判断是哪种等待：微信区 72 小时换绑审核、游戏换绑审核期、新注册 QQ 的 15 天换绑等待期，这些都是规则内的等待，不是异常。

## 五、走到取消那一步要付多少

- 买家确认交易后，双方都不接受单方面取消；
- 如果确实是个人原因要取消，需支付号价金额 **5% 的违约金**，由守约方收取；
- 卖家拒不支付违约金的，该账号与用户会在多平台被拉黑下架；
- 换绑审核进行中要求撤单的，要等过户结果出来才能按实际情况处理；
- 因游戏厂商原因首次换绑失败、双方配合后仍无法交付的，按平台方案无责取消。

违约金这件事只影响一种情况：你已经确认交易又在半路反悔。发布前想清楚价格与预期，比事后谈取消划算。

## 六、提现规则：时间、限额、到账

余额提现是卖家最关心的环节，规则集中在下面这张表：

| 项目 | 规则 |
| --- | --- |
| 提现入口 | 个人中心 / 「我的」里的余额，选支付宝、微信或银行卡 |
| 提现时段 | 每天 00:10 至 23:30，其余时间提交可能出现延时 |
| 单笔上限 | 50000 元 |
| 到账时间 | 参考收款账户右侧的到账时间提醒，正常为 5 分钟至 2 小时；银行维护等突发情况会另行公告 |
| 不可提现的资金 | 充值金额不能用于提现 |
| 手续费 | 优惠提现额度只来自在 7881 收货网出货；售得、充值等方式获得的资金提现时按收费标准收取。DNF 与魔兽怀旧服两款游戏的出货订单累积出货额度免提现手续费 |
| 月末时段 | 每月最后一天是银行对账期，当天 21:00 至次日 08:00 的提现会在次月 1 日 00:10 起陆续到账 |

这张表里最需要提前知道的是两个点：**在 00:10 至 23:30 之外提交的提现不会当夜到账**；**卖号所得与收货网出货所得在手续费上是两套待遇**。做大规模出货的卖家，把出货额度用足能省一笔。

具体的费率标准官方以页面图表形式给出并会调整，这里不写死数字，以帮助中心「提现收费标准」与银行收费标准页面当时显示的为准。

## 七、提现失败怎么处理

| 现象 | 处理 |
| --- | --- |
| 提现失败 | 先核对提现账户信息（姓名、账号）是否与实名信息一致，改对后重新提交 |
| 提现到支付宝失败 | 官方给出的办法是改用该支付宝账号注册邮箱重试 |
| 银行卡丢了 | 先在账户里删除这张丢失的卡信息，再添加新的提现账户 |
| 一直没到账 | 对照第六节的时段与月末规则；都不符合再找客服 |

有一条是红线：**平台禁止任何形式的套现**。被系统检测到套现的，会暂停提现并加收 3% 交易手续费，金额较大的会报案处理。正常买卖不需要碰这条线。

交易环节的其他报错、客服联系方式和防骗要点，统一看 [常见问题与排查.md](常见问题与排查.md)；只卖游戏币、装备道具、点卡这类非账号商品的，接着看 [游戏币与道具交易怎么做.md](游戏币与道具交易怎么做.md)。
