## 一、登录入口在哪

打开应用后，**首页右上角那张头像是登录入口**。点它会弹出一个菜单，里面有**登录、关注、历史记录、设置、关于、退出登录**几项。没登录时头部显示的是默认灰头像，菜单里的「关注」和「历史记录」点了会提示「用户未登录」；登录之后这里会显示你的头像、昵称和会员等级（LV 几），并带上经验进度条。

头像是默认的灰头像时，就说明当前没有登录态。

## 二、用哪种方式登录

BiliYou 里能走到四条登录路径，但它们的维护状态差别很大，选之前先看清楚：

| 登录方式 | 怎么进 | 现在的状态 |
| --- | --- | --- |
| **网页登录** | 头像菜单 → 登录 | 默认走的就是它，官方长期维护 |
| **扫码登录** | 网页登录页右上角「二维码登录」按钮 | 1.1.3 加入，可用 |
| 密码登录 | 需先进隐藏的测试页 | 自 1.0.8 起官方已不再维护 |
| 短信登录 | 需先进隐藏的测试页 | 自 1.0.8 起官方已不再维护 |

**建议直接用网页登录。** 点「登录」后打开的是一个内嵌的浏览页，里面就是 B 站自己的 H5 登录页，你在那里填手机号、验证码或账号密码，流程和网页版一致；官方更新日志里写过，这条路「现在登录没有任何问题了」，1.1.3 还专门修过平板因 UA 不同而进不了登录页的问题。登录成功后页面会自动跳回首页，并弹一条「网页登录成功」。

**扫码登录**不用另外找入口：就在上面那个网页登录页的右上角，有个「二维码登录」按钮。点进去用手机上的 B 站 App 扫一下即可，适合不想在键盘上敲账号密码的场景。扫完之后如果界面没自动跳转，点页面右上角的「手动检查登录状态」就能确认结果。

密码登录和短信登录这两页虽然还留在代码里，但官方在 1.0.8 的更新说明里写明**已不再维护**，入口也挪到了长按搜索框才会出现的测试页里。它们能不能用取决于 B 站的接口有没有变，不建议把它当成常规登录方式。

## 三、登录前后差在哪

先用一张表把差别说清楚，再决定要不要登录：

| 内容 | 未登录 | 已登录 |
| --- | --- | --- |
| 首页推荐、热门、搜索、播放 | 可用 | 可用 |
| 番剧搜索与播放 | 可用 | 可用 |
| 观看历史记录 | 无 | 有 |
| 动态（关注的 UP 主更新） | 无 | 有 |
| 关注列表 | 无 | 有 |
| 评论、点赞、投币 | 不可用 | 可用 |

简单说：只想「随便刷刷视频」，不登录完全够用；想把使用痕迹留下来、要看自己关注的人，就必须登录。

## 四、退出登录与数据归属

退出入口在头像菜单里：点头像 → 「退出登录」→ 确认。

有三点需要提前知道：

- **退出登录不会删掉你在这个应用里的界面设置**（主题、字体缩放、弹幕参数这些和账号无关），但历史记录、动态这类内容会立刻看不到。
- **登录状态存在应用自己的本地数据里**，清除应用数据或卸载重装之后需要重新登录。BiliYou 没有做云端同步，也就没有「换手机自动带过去」这回事。
- **登录凭证就是你的 B 站账号身份。** 第三方客户端登录时用的仍是你自己的账号，所以别在别人的设备上登录；公共设备上用完之后，记得退出并清除应用数据。

## 五、登录不上去时的顺序

按下面顺序试，基本能定位到是环境问题还是账号问题：

1. **先换网络**：流量与 Wi-Fi 互换一次，再重进登录页。第三方客户端登录失败里，网络与接口状态占很大比例。
2. **网页登录页打不开或一直是空白页** → 见[常见问题与排查.md](常见问题与排查.md)的「登录相关」一节。
3. **提示需要人机验证或短信验证** → 这是 B 站账号侧的风控，按页面提示完成验证再回来重试，不需要在 BiliYou 里做额外设置。
4. **扫码一直显示未扫码** → 确认手机上的 B 站 App 已经登录、并且扫的是 BiliYou 展示的那张二维码；扫完停几秒，再点右上角「手动检查登录状态」。
5. **所有方式都失败** → 检查手机时间是否准确（系统时间偏差会导致请求校验失败），再重启一次应用。
