## 一、这是什么，装之前先确认两件事

KiliKili 是给智能手表用的第三方 B 站客户端：在表盘上浏览推荐视频、搜索、看关注 UP 主的更新，也能直接播放。它不替代手机版 B 站，界面是按手表的小屏幕做的。

装之前确认两件事：

| 检查项 | 这份包的要求 | 在哪儿看 |
| --- | --- | --- |
| 系统版本 | Android 5.0（API 21）及以上 | 手表「设置 → 关于 → 系统版本」 |
| CPU 架构 | 只含 32 位 ARM（armeabi-v7a） | 见下文第二节 |

系统版本这一条来自项目在代码仓库里的构建配置；这份安装包本身只打包了 32 位 ARM 的原生库，能执行 32 位应用的手表可以装，纯 64 位、已不再兼容 32 位应用的设备会被系统直接拒绝，安装时报「与您的设备不兼容」这类提示。

## 三、把安装包送进手表的三条路

三条路都能用，按你手边的条件挑一条即可。

### 3.1 手表自己下载安装

前提是手表能连 Wi-Fi，并且装了能打开网盘的浏览器或文件管理器。

1. 在手表上打开 **KiliKili 安装文件资源（夸克网盘）**：[https://pan.quark.cn/s/7d45f9523be3](https://pan.quark.cn/s/7d45f9523be3)；
2. 转存到自己网盘后下载，或者直接下载这一份包；
3. 下载完成后用文件管理器点这个 `.apk` 安装。

手表上操作的两个注意点：表盘上不一定能看全下载进度，等系统通知栏出现「下载完成」再动手；安装按钮通常在列表最底部，记得滑到底。

### 3.2 用手机配套应用推送到手表

部分手表厂商的配套手机应用提供「安装应用到手表」这类入口，把 APK 先传到手机再推过去即可。这条路依赖厂商应用的功能，不是每块表都有，找不到入口就换 3.3 或 3.1。

### 3.3 用 ADB 安装（最稳，适合反复重装）

先在手表上打开调试：设置 → 关于 → 连点「版本号」进入开发者选项 → 打开「USB 调试」与「通过 Wi-Fi 调试」，手表会给出 IP 与端口。

```bash
adb connect 192.168.1.23:5555     # 换成你手表提示的 IP 与端口
adb install -r "KiliKili_v0.3.2.apk"
```

`-r` 表示覆盖安装、保留已有数据，装第二次会用到。装完可以 `adb disconnect` 断开。

## 四、安装时容易被挡的两个地方

- **未知来源权限**：手表上要允许「安装未知应用」，并且授权对象是**你用来点安装的那个应用**（文件管理器或浏览器）。没开的时候点安装要么没反应，要么弹「已阻止安装」。用 ADB 装的话，还要在开发者选项里打开「通过 USB 安装」这类开关。
- **剩余空间**：包本身不到 19 MB，加上安装后的运行数据，建议手表剩余空间留 100 MB 以上，避免装到一半失败。

## 五、第一次打开会看到什么

1. 启动后先出现登录页，这一步可以跳过 —— 不登录也能浏览推荐和搜索，跟账号绑定的内容要登录后才出现，具体见 [登录与账号同步.md](登录与账号同步.md)；
2. 确认手表已经连上网络：没网时界面会一直停在加载状态，那不是卡死；
3. 首页给的是推荐／热门列表，向下滑动浏览；部分支持旋转表冠的机型，转动表冠也能滚动列表。

安装过程报错、或者装好之后打不开，分别对照 [手表上装不上怎么排查.md](手表上装不上怎么排查.md) 与 [常见问题与排查.md](常见问题与排查.md)。
