# 快对AI 错题本整理与打印

> 错题本的价值不在「收集」，在「复习时能筛出来、能打印出来」。这篇讲怎么拍进去、去手写和归类怎么做、导出打印怎么走、以及换设备前必须先做的动作。

错题本要解决的是「抄错题太费时间」。你对着一道错题拍一张，应用会**去掉上面的手写笔迹、还原出空白题目**，然后按科目归类存好；复习的时候按科目、章节或错误类型筛出来，可以导出成 PDF 或者直接连打印机。整条链路里最值钱的是「去手写」这一步 —— 它省掉的是重抄题干的那二十分钟。

## 一、把题收进去

1. 打开错题本入口，点拍照；
2. 对着**作业本、练习册、试卷上的错题**拍，画面里把整道题（含题干）拍全；
3. 应用自动去掉手写笔迹、保留印刷题干，生成一张干净的题目存档；
4. 确认存档没问题后保存，它会按科目自动归类。

**拍摄注意**：光线均匀、纸面平整这两条和别处一样；另外**别把相邻的题一起拍进去**，一次一道题，还原后的图片才干净。铅笔痕迹、用修正带涂改过的区域是最容易去不干净的地方，遇到就重新拍一张更清晰的。

## 二、整理：让复习时能筛出来

存进去只是第一步，真正决定好不好用的是分类。可用的维度通常包括：

| 维度 | 用途 |
| --- | --- |
| 科目 | 复习时按学科整批调出来 |
| 章节 / 知识点 | 定位到具体薄弱环节，比按科目细一层 |
| 错误类型 | 区分「不会做」和「算错」，两类复习方式完全不同 |
| 自定义标签 | 比如「期中前」「考前必看」，按你自己的节奏分组 |

**加标签这件事建议当场做**，不要攒着 —— 一周后回来看那张图，很难想起当时为什么错。一个够用的做法是：拍进去的时候顺手标一个错误类型（概念不清 / 计算失误 / 审题漏条件），复习时按这一项筛，效果比按科目筛明显。

另外，**错题本里的题是可以在应用内重做的**，做完对照原来的正确答案，比自己另找本子重做省事。

## 三、导出、打印、分享

复习场景里最需要的是「拿出来」。错题本的导出有三个去处：

- **导出成 PDF**：文件落在手机本地，可以自己打印、也可以存档；分科目导出，不要一次导全部（几百道题的 PDF 打开很慢，打印也不好分页）；
- **直接打印**：部分机型支持一键连接打印机，能不能连、连什么型号以手机和打印机自身的能力为准；更通用的办法是导出 PDF 之后用系统的打印服务；
- **分享给微信 / QQ**：适合把错题发给同学、家长，或者换设备时自己转存过去。

导出的 PDF **不要只留在应用里**。换设备、清缓存、卸载重装都可能让它消失，把重要的那几份导到本地或发一份到自己的微信收藏，是最省事的备份方式。

## 四、换设备前必须先做的一件事

错题本、收藏、检查记录都挂在**账号**上。所以：

1. 换手机之前，先确认当前是登录状态，且错题本能正常打开（能看到之前存的题）；
2. 新机上**用同一套登录方式**登录 —— 原来用手机号，就继续用手机号；原来用微信，就继续用微信。**手机号和微信在系统里是两套账号**，混着登会出现「东西全没了」的错觉，实际是把另一套空账号登进来了；
3. 登录后如果短时间内看不到历史内容，先别急着重装，等它同步或手动下拉刷新一次。

## 五、占用空间与清理

错题是一张张图片，**攒到几百道题之后占用会明显起来**，在存储紧张的手机上会出现「应用变卡、拍照变慢」的现象。处理顺序：

1. **先导出再清理**：确定重要的几份 PDF 已经存到本地；
2. 清理应用的**缓存**（不删数据），这一步在手机的「设置 → 应用 → 快对AI → 存储」里；缓存清掉不会丢错题；
3. 真的空间不够，再回应用内按月筛，把已经掌握的老错题逐条删掉 —— 这比直接清数据安全。

## 六、家长用错题本的正确姿势

给家长一个简单的用法：**别把错题本当成「惩罚清单」**。它的实际用法是每周花十分钟，按错误类型筛一遍，同一类型连续出现三次的那一栏，才是需要花时间补的地方；只出现一次的，看过解析就够了。

配合作业检查用效果最好：批改完直接把错的题拍进去，归档和批改就在同一段操作里完成，见 [作业检查怎么用.md](作业检查怎么用.md)。如果错题本里的图识别得不好、想先把题干弄成干净的文字或 PDF，可以用扫描那条路自己重做一份，见 [拍照翻译与文件扫描.md](拍照翻译与文件扫描.md)。
