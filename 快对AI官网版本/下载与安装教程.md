## 一、装之前先记住这三个标识

不管你从哪个渠道拿到安装包，认这三个值就够判断是不是同一款应用：

| 项目 | 值 |
| --- | --- |
| 应用名 | 快对AI |
| 包名 | `com.kuaiduizuoye.scan` |
| 本包版本 | 6.95.0 |
| 本包体积 | 46.64M |
| 本包 MD5 | `b203ab7d4e5be2aa16ac247583c98623` |

**包名是唯一不会随改名、换渠道而变的东西**。商店页面、安装器信息、手机设置里的应用信息，都能看到包名；只要对得上 `com.kuaiduizuoye.scan`，就是同一款应用，哪怕它的图标和名字显示成「快对作业」。

版本号和体积是**这份包的**值。应用商店里展示的往往是更新的版本、也常见体积写得更小或更大（渠道统计口径不同），两者不一致不代表装错了 —— 判断依据始终是包名和 MD5。

## 二、系统要求：别只看商店页那一行

官方各商店页面标注的系统要求并不完全一致：较新的页面写 **Android 6.0 以上**，一些历史版本页写的是 Android 5.0 以上。这个差异来自页面更新节奏，不作为承诺。

实际结论按下面的口径处理：

- 手机系统在 **Android 8.0 及以上**：基本可以直接装、直接用；
- 手机系统在 **Android 6.0 ~ 7.x**：能装上，但拍照识别、AI 问答这类需要联网推理的功能在老机型上更容易卡；
- 手机系统 **低于 Android 6.0**：不建议再折腾，直接换设备。

系统要求这类信息会变，装之前以官方应用商店当前页面的标注为准。

## 四、安装步骤

安卓安装非商店来源的 APK，系统会拦一道，这是正常的，不是包有问题。

1. 把 APK 传到手机（微信/QQ 发给自己、数据线拷贝、网盘 App 直接下载都行）；
2. 用手机的「文件管理」找到这个 APK，点它；
3. 系统提示「不允许安装未知应用」时，点提示里的设置入口，给**文件管理**或**当前这个安装器**打开「允许安装未知应用」权限 —— 注意要开的是发起安装的那个应用，不是浏览器；
4. 回到安装界面，点「安装」；
5. 安装完成后**先别急着打开**，回到权限设置把那个「允许安装未知应用」的开关关掉。

安装时系统列出的权限里，几个是功能必需的，看到不用惊讶：

| 权限 | 用途 |
| --- | --- |
| 相机 | 拍照搜题、作业检查、拍照翻译 |
| 存储 / 相册 | 读取要识别的图片、保存解析图片与导出的 PDF |
| 麦克风 | 语音搜题 |
| 位置 | 按你所在地区匹配教材版本 |
| 通知 | 预约类提醒与服务消息 |

## 五、第一次打开要做的三件事

1. **登录**。快对AI 的错题本、收藏、检查记录都挂在账号上，不登录换设备就丢。注册入口支持手机号，也支持微信、QQ 这类快捷方式（以 App 内实际给出的入口为准）。**登录方式一旦选定就固定下来** —— 手机号和微信在系统里是两套账号，用哪个登录，数据就在哪套下面。
2. **给摄像头权限**。第一次点拍照会弹权限申请，直接允许；误点了「禁止」也不会卡死，去手机的「设置 → 应用 → 快对AI → 权限」里补回来即可。
3. **用一本手边的练习册试一次扫码**。对着练习册封底的条形码扫一下，能出整本解析就说明这台设备、这个网络、这个版本都正常，后面的功能不用逐个试。

## 六、装不上时的排查顺序

按下面的顺序走，三步之内基本能定位：

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 提示「解析包时出现问题」 | 包没下完就中断了 | 看文件大小是不是 46.64M，MD5 是不是 `b203ab7d4e5be2aa16ac247583c98623`，对不上就重下 |
| 提示「应用未安装」/「与已有应用签名冲突」 | 手机上已有一个签名不同的同名版本 | 先在设置里卸载旧的那个，再装 |
| 提示「您的设备不兼容」 | 系统版本低于应用要求 | 换 Android 8.0 以上的设备 |
| 装完点开就退回桌面 | 多为系统版本偏低，或安装包来自二次打包的网站 | 先按上文 MD5 核对，确认无误后换设备试 |
| 装上了但没有图标 / 商店提示要更新 | 商店侧识别到同包名的另一份 | 二选一，别同时留两份 |

最后一条值得多说一句：**不要在多个来源各下一份重复安装**。同包名不同签名的两份包互相覆盖时，最坏的结果是账号数据读不出来。认准一处来源，就一直用它。

## 七、换手机、重装、升级怎么处理

- **换手机**：新机上先用同一账号登录，再去安装。顺序反过来（先装先逛、后登录）也不会丢东西，但错题本里的图片要等登录后才会同步过来。
- **重装**：卸载前确认账号已登录且错题本已同步。重装后如果发现结论不对，先看是不是登录了另一套账号。
- **升级**：商店渠道会自动更新；网盘渠道的包不会自动升级，需要自己下新版本覆盖安装 —— 覆盖安装不会清掉账号数据，但如果新旧包签名不同，系统会要求先卸载，这种情况**先备份/确认错题本已同步再卸载**。
