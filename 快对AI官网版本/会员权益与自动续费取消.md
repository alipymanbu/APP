# 快对AI 会员权益与自动续费取消

快对AI 本身免费下载，主要功能（扫码查教辅、作业检查、错题本）不需要会员就能用；官方页面列出的会员权益是**视频解题、VIP 问答、保存图片**这类偏「进一步」的能力。真正容易出问题的地方不在买，而在**买了之后忘了关自动续费**，所以这篇把取消的路径一条条写清楚。

## 一、哪些算会员权益

按官方页面说明，会员权益包含这几类：

| 权益 | 说明 |
| --- | --- |
| 视频解题 | 难题的讲解视频 |
| VIP 问答 | 提问类功能的额度与优先 |
| 保存图片 | 导出、保存相关内容 |

**基础的教辅解析、拍照搜题、作业检查、错题本不受会员影响**，这些是它的基础免费能力。也就是说，如果你只是想给家长查作业对错、扫练习册答案，不开会员也够用；需要视频解析、或者需要把内容导出保存时，才需要考虑。

具体某项功能当前是否收费、免费额度是多少，会随版本调整，**以 App 内当前显示为准**。

## 二、订阅周期有哪几种

官方页面列出的周期是：**1 个月、3 个月、12 个月**，以及对应的**连续包月 / 连续包季 / 连续包年**。

两者的区别是：

- 买单期（1 个月 / 3 个月 / 12 个月）：到期就停，不会自动扣下一笔；
- 连续包月 / 包季 / 包年：到期自动从绑定的支付账户扣下一期费用，**这就是需要关注自动续费的那一类**。

开通页面上，连续包月的价格通常比单月低，代价就是默认进入自动续费。决定之前看清页面上标的是哪一种。

## 三、取消自动续费：四条路

按你当初付款的方式选一条。**任意一条成功即可**，不需要每条都做。

### 1. 应用内取消

路径是：打开快对AI → **我的** → 点**会员卡片**进会员中心 → 点立即续费进商品页 → 滑到页面底部 → **自动续费管理** → 选中对应项目 → **取消自动续费**。

这条路径上最容易找不到的是「自动续费管理」—— 它藏在**商品购买页的最底部**，不在会员中心的显眼位置。

### 2. 微信支付用户

「我」→「服务」→「钱包」→「支付设置」→「自动续费」→ 找到快对相关项目 → **关闭扣费服务**。

### 3. 支付宝用户

「我的」→「设置」→「支付设置」→「免密支付/自动扣款」→ 找到快对相关项目 → **关闭服务**。

### 4. 苹果支付用户（iOS 端）

手机的「设置」→「Apple ID、iCloud、媒体与购买项目」→「订阅」→ 找到快对项目 → **取消订阅**。

**在苹果端订阅的，一定要走这条路**：在应用内点取消往往不生效，因为扣费主体是 Apple。反过来，在安卓端订阅的，也去不了 Apple 的订阅页 —— 这是两条独立的扣费通道。

## 四、两个关键时间点

官方规则里有两个时间点，决定了你还有没有机会避免被扣：

| 时间点 | 含义 |
| --- | --- |
| 当前周期结束前 **5 日** | 官方会通过站内信或推送发送一次自动续费提醒 |
| 当前周期结束前 **24 小时** | 各家商店页面里提到的「在此时间点以前完成取消」的口径 |

**最稳的做法是开通完当场就去关一次**。熟悉一遍路径，也比事后找入口省事。

## 五、已经被扣了怎么办

官方协议里有一句明确的话：**当期连通包费用完成扣费之后，无法退款**。所以「这期刚被扣、能不能退」这类请求，按协议是不同意的，成功率不高。

能走的流程是：

1. 先在**上面四条路里关掉自动续费**，别让下一期继续扣 —— 这一步优先级最高；
2. 再打开快对AI → **我的** → **客服中心** → **我要退款**，按页面给的流程走，或在「我的订单」里对具体订单发起申诉；
3. 如果不认可处理结果，属于消费争议，可以走常规的消费维权渠道。

**顺带提醒一个常见误解**：卸载应用**不会**停止自动续费。扣费是在支付渠道侧完成的，应用删了照扣。必须先取消自动续费，再考虑卸不卸。

## 六、开通之前先弄清楚的三件事

- **先用免费能力，再决定要不要买**：扫码、作业检查、错题本这三条免费就能跑，用一周再判断视频解析和问答额度对你有没有用；
- **别在两套账号上各买一次**：手机号和微信是两套账号，会员权益跟着购买时那套走，换另一套登录会「看不出是会员」，遇到这种情况的排查见 [常见问题与排查.md](常见问题与排查.md)；
- **学生用的设备，家长要留心开通页**：开通页面默认偏向连续包月，孩子自己点开很容易选错，可以在支付渠道里直接关掉免密扣款；
- **多台设备共用一个账号，不用重复买**：会员跟着账号走，手机、平板、电脑上（走应用宝电脑版的这一台也同理）登录同一套账号即可。**但苹果内购与安卓内购是两条独立通道**，在 iPhone 上买的那份，登到安卓上不一定生效，跨系统使用前先确认清楚。
