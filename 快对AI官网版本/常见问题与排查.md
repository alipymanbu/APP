## 二、识别不准、答案对不上

这是反馈最多、也最容易归错因的一类。先分清是**识别错**还是**题库没有**：

- **识别的字和题面不一样** → 是图片问题。重新拍：光线均匀、纸面放平、只框住这一道题；有公式和图形的，一定要让公式和题干在同一张图里。
- **识别对了但搜不到** → 是题库问题。换 AI 解题那条路（见 [AI解题和追问怎么用.md](AI解题和追问怎么用.md)），它会现场推，不依赖题库里有没有这道题。
- **答案是错的** → 优先怀疑**教材版本对不上**。同一道题在不同版本、不同年份的教辅里，答案可能不同；确认书封面上的版本名再作判断。
- **同一道题反复识错** → 别再重试同一张图。改成手动输入题干，把关键数字和条件打进去，比反复拍更快出结果。

**AI 相关的输出（AI 解题、AI 写作、翻译）官方都不作正确性承诺**，用之前自己核一遍，尤其是要把结果交出去或抄下来的场合。

### 拍照自查清单：重拍之前先过一遍这几条

同一张图重试不会变好，但下面任意一条没做到，都会让识别结果明显变差：

| 检查项 | 具体做法 |
| --- | --- |
| 距离 | 镜头离纸面 **15~25 厘米**，题目占画面 **2/3 以上**；太近会对不上焦，太远字太小 |
| 光线 | 走窗边或用「主灯 + 台灯」两处光源，**别用闪光灯直射**（纸面反光那一块会变成空白） |
| 角度 | 手机与纸面平行、从正上方拍；开手机的**网格线**辅助对正，斜拍会让文字透视变形 |
| 稳定 | 手肘抵住桌面，按下快门前**先点一下屏幕对焦**，等对焦框稳定再拍 |
| 镜头 | 用眼镜布擦一下镜头。镜头上的指纹和油污会造成整体发虚，这一条最容易被忽略 |
| 纸张 | 抚平褶皱、挪开压住题目的手指和文具；书页弯曲时宁可分两次拍 |

这六条同时满足还识错，基本可以排除拍摄问题，转去手动输入题干。

## 三、扫码扫不出整本书

按可能性排：书没在库里 → 版本对不上 → 条形码本身不清楚。

1. 换入口再试一次：输入条形码数字、按书名搜、拍封面搜，四个入口的命中范围不完全一样；
2. 书名搜**别输全名**，输能定位到这套书的关键词；
3. 四个入口都搜不到，基本就是没收录，改用作业检查或 AI 解题处理单道题。

还有一个容易当成故障的现象：**扫到了但内容很少**。这通常是这本书只收录了部分页码（主练习部分有，附页和测验卷没有），不是加载失败。详细说明见 [扫码查教辅和整本解析.md](扫码查教辅和整本解析.md)。

## 四、悬浮窗搜题打不开

悬浮窗不出现，几乎都是手机系统那一侧的权限被拦了：

1. 确认在「我的 → 悬浮窗搜题」里开关是打开的；
2. 去手机的 `设置 → 应用 → 快对AI → 权限`，找 **「显示在其他应用的上层」**（有的机型叫「悬浮窗」「后台弹出界面」）并允许；
3. 有些机型的省电策略会在后台把这类权限清掉，把快对AI 加进「允许后台运行 / 不受省电限制」的名单里；
4. 全部给完之后，**退回应用点一次「立即开始」**，悬浮窗才会被挂起来。

## 五、越用越卡、占空间

错题本是一张张图片，攒到几百道之后占用会明显上升，表现是拍照变慢、切页变卡。处理顺序：

1. 先把需要的错题导出成 PDF 存到本地（见 [错题本整理与打印.md](错题本整理与打印.md)）；
2. 去手机 `设置 → 应用 → 快对AI → 存储` **清缓存**（不选「清除数据」，清数据会把本地内容一起删掉）；
3. 空间仍紧张，再回应用内按时间筛，逐条删掉已经掌握的老错题。

## 六、账号相关：数据没了、会员不生效、换绑

这三个现象是同一个根：**手机号和微信是两套独立账号**。

- **换手机后错题本空了**：先看是不是登了另一套账号。换回原来那套登录方式，内容就回来了；两套都想用的，趁早固定一套。
- **买了会员还是受限**：回想买的时候用的是哪种登录方式，用那一种登进去。换回后仍没有权益，再找客服。
- **想换绑手机号**：应用里目前没有换绑入口，多个第三方教程也反馈过「不支持换绑」。确实要换，走客服确认是否还有别的处理方式；
- **想注销账号**：走「我的 → 客服中心」，以 App 内的流程为准。注销前先把错题本和收藏导出，注销后无法找回。

## 七、装不上、想固定用某一版

先核对包的完整性，再判断设备兼容性：

1. 看文件大小是不是 **46.64M**、MD5 是不是 `b203ab7d4e5be2aa16ac247583c98623`，对不上就重新下；
2. 提示「解析包时出现问题」= 包没下完；提示「与已有应用签名冲突」= 手机上已有一个同名不同签名的版本，先卸载旧的；
3. 提示「设备不兼容」或点开就退回桌面 = 系统版本不够，建议在 **Android 8.0 及以上**的设备上使用。

想自己固定用一个版本、不让商店自动升级，就从 **快对AI 安装文件资源（夸克网盘）** 取包：[https://pan.quark.cn/s/6d2fc2a54487](https://pan.quark.cn/s/6d2fc2a54487)。网盘里那份是 **6.95.0**，包名 `com.kuaiduizuoye.scan`；更完整的环境要求与安装步骤见 [下载与安装教程.md](下载与安装教程.md)。

## 八、这些情况不用修，是设计如此

碰到下面几种，别当成故障反复重装：

- **首页有推荐内容和活动位**：新版首页本来就不只一个搜索框；只想去广告式地查答案，用旧版本更安静，见 [快对作业改名后有什么变化.md](快对作业改名后有什么变化.md)；
- **视频解题要会员**：这是会员权益，不是功能坏了，见 [会员权益与自动续费取消.md](会员权益与自动续费取消.md)；
- **一部分题目没有视频讲解**：视频只覆盖重点题和易错题，题目有文字解析不等于该有视频；
- **没网时扫码/收藏能用、翻译和 AI 不能用**：这几类功能对网络的依赖程度不同。
