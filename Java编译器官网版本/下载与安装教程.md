Java编译器 是面向安卓手机的一个轻量代码编辑器加编译器，主要给刚开始学 Java 的人用：装完就能在手机上敲一段代码、点一下运行、当场看结果，不需要自己配 JDK，也不需要连电脑。开发方是唐山旗鱼科技有限公司。本篇只做一件事——把网盘里这份包装进手机并正常打开。

## 一、先弄清网盘里这份包是哪一版

网上搜到的版本号通常是商店里的最新版，网盘里这份是制作文档时核对过的版本，两者未必是同一个。本文涉及版本号、包名、体积的地方都以下表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | Java编译器 |
| 版本号 | 10.4.1 |
| 包名 | `coding.yu.javacompiler.new` |
| 安装包体积 | 24.65 MB |
| MD5 | `9687f58126cc7f930e5292d30b24bd9e` |
| 开发方 | 唐山旗鱼科技有限公司 |

安装包本体放在页首那个网盘入口里，转存到自己网盘后再下载到本机。

关于版本号：这一版写作 `10.4.1`，是三段数字的形式。从公开记录看，开发方是按小版本逐位往上走（出现过 10.3.0、10.3.1、10.4.1 这样的序列），官方没有公布过版本号的命名规则；眼下哪个数字最新，以商店页面上当时显示的为准，别拿第三方下载站的标注当准。

## 二、装之前要核对的两件事

**第一，认包名，别装成同名应用。** 各商店里叫「Java编译器」的应用不止一个，光看名字很容易装错。本文这份的包名是 `coding.yu.javacompiler.new`，开发方是唐山旗鱼科技有限公司；装完可以在「设置 → 应用 → 应用管理」里点进该应用，核对这两项是否与上表一致。包名不同的属于另一个应用，**不能互相覆盖安装**，界面与功能也不一样，识别方法见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。

**第二，系统版本与剩余空间。** 官方商店页面没有标注明确的安卓版本下限，以商店页面当时显示的要求为准。包体 24.65 MB，装完还会再占一部分空间，编译运行也要有地方临时存放，装之前留出几百 MB 余量比较稳妥。如果手机系统很旧，先在文件管理器里点一下安装包看看能不能正常解析——报错怎么处理见 [常见问题与排查.md](常见问题与排查.md)。

想顺手校验下载的包有没有传坏，可以在电脑上用系统自带命令算一遍 MD5，结果应当与上表逐位一致：

```cmd
certutil -hashfile Java编译器_v10.4.1.apk MD5
```

（文件名随版本变化，以网盘里当时显示的文件名为准。）

## 三、安装步骤

1. **转存并下载**：从 [Java编译器 安装文件资源（夸克网盘）](https://pan.quark.cn/s/0ce54a208e4e) 把安装包转存到自己的网盘，再下载；手机端直接下载最省事，在电脑上下载就用数据线或传输工具拷进手机存储。
2. **允许安装未知来源应用**：在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给用来打开安装包的那个应用（文件管理器或浏览器）打开开关。国产定制系统这项常收在「安全」或「隐私」分类下。
3. **点击安装包完成安装**：系统提示「应用未经过安全检测」或「来自未知来源」属侧载安装的常规提示，选择继续安装即可。
4. **回装低版本要先卸载**：安卓不允许用更低版本的安装包覆盖更高版本，会直接报「应用未安装」。手机上如果已经装了比 10.4.1 更高的版本，先卸载旧版再装。
5. **装完先别急着乱点**：先按下一节把权限过一遍，再进编辑器写第一段代码。

## 四、第一次打开要看的几处

1. **存储权限**：商店详情页标明的权限里包含「读取文件与文档」「写入文件与文档」，用途是把你写的代码保存到手机上。首次保存、或从文件管理器打开代码文件时，系统会问一次，同意即可；拒绝也能敲代码，但存不进手机存储。
2. **与保存代码无关的申请**：短信、通讯录、定位、无障碍这类权限与写代码没有关系，直接拒绝，不影响使用。
3. **界面形态**：目前这一版打开后直接就是代码编辑界面，不需要注册或登录，也没有启动引导页。
4. **输入法要先配一遍**：手机键盘上 `{}`、`;`、`()` 这些符号不像电脑键盘那样一格一个，得先切到符号面板里找。更要紧的是把输入法的**自动纠错和自动大写关掉**——它们会把 `String` 悄悄改成 `string`，代码报错还看不出来。具体开关与符号输入技巧见 [手机上敲代码的输入法怎么配.md](手机上敲代码的输入法怎么配.md)。

如果点运行之后长时间没反应，或者安装时提示「解析包错误」「应用未安装」，转 [常见问题与排查.md](常见问题与排查.md)。
