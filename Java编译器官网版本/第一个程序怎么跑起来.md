# Java编译器 第一个程序怎么跑起来

这篇给的是最短路径：新建文件 → 敲一段 Hello World → 点运行 → 看到输出。只要这一步通了，后面的变量、循环、数组都是在同一个流程里换代码而已。

## 一、跑通一段 Hello World

1. 打开 Java编译器，进入代码编辑界面；
2. 新建一个代码文件，命名为 `Hello.java`；
3. 把下面这段敲进编辑区：

```java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, Java");
    }
}
```

4. 点右上角的运行按钮，等它编译完成；
5. 结果区会显示 `Hello, Java`。看到这一行，说明编辑、编译、运行这条链是通的。

首次运行时系统可能再要一次存储权限（用于保存代码文件），同意即可。

## 二、三处最容易卡住的地方

| 卡点 | 具体表现 | 怎么做 |
| --- | --- | --- |
| 文件名与类名不一致 | 报错里出现 `class Hello is public, should be declared in a file named Hello.java` | 文件名去掉后缀后必须和 `public class` 后面那个名字**逐字一致**，包含大小写。这是 Java 语言本身的规矩，不是这个软件额外加的 |
| 少了 `main` 方法 | 提示找不到主方法、或运行后没有任何输出 | 入口方法固定写成 `public static void main(String[] args)`，四个词缺一不可；大小写错了同样不认 |
| 输入法打成了中文标点 | 报错指向某一行，但那一行怎么看都没问题 | 中文全角的分号 `；`、括号 `（）`、引号 `“”` 和英文半角长得像但不是一回事。把输入法切回英文，重新敲这一行的标点 |

这三条里，第三条在手机上尤其高发——手机输入法默认中文，符号面板第一层常常就是全角符号。

## 三、运行结果在哪看

- **正常输出**：`System.out.println(...)` 打印的内容会出现在代码区下方或运行结果区域，按顺序往下排；
- **报错信息**：编译不过时，结果区给的是错误提示（开发方在更新说明里写到过报错信息支持复制），可以长按复制出来；
- **报错怎么读**：每一行错误通常带有行号与错误类型，先看最上面那一条——后面的错误常常是第一条引起的连锁反应。具体读法与常见错误对照见 [编译报错与代码联想怎么处理.md](编译报错与代码联想怎么处理.md)。

## 四、改一改再跑一次

跑通 Hello World 之后，建议立刻做一次"改一处、跑一次"的小练习，把循环熟悉一下：

```java
public class Hello {
    public static void main(String[] args) {
        for (int i = 1; i <= 5; i++) {
            System.out.println("第 " + i + " 次运行");
        }
    }
}
```

点运行后会依次输出五行。写代码时留意两件事：

- 每改一次都直接点运行，不用先"保存"再"运行"——自动保存是常态，具体存在哪见 [项目与代码文件怎么管理.md](项目与代码文件怎么管理.md)；
- 联想提示不出现、字体太小看不清，都是编辑器设置问题，不是装坏了，见 [主题字体与编辑器设置.md](主题字体与编辑器设置.md)。

## 五、跑通之后往哪走

在手机上写 Java，写法和电脑上一致，差别只在输入与阅读体验：手机屏幕小，一次别写太长的方法；长行会自动折行，容易看错括号配对，括号成对的习惯比在电脑上更重要。

代码文件的管理、从文件管理器导入现成的 `.java` 文件、以及需要引用第三方库时怎么办，都在 [项目与代码文件怎么管理.md](项目与代码文件怎么管理.md) 里。这一步如果点运行没反应或者一直停在编译中，先看 [常见问题与排查.md](常见问题与排查.md)。
