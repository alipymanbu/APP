手机上写代码，看得清比功能多更要紧。这个软件的编辑器设置里，值得花时间调的其实是四样：字号、代码字体、主题、注释高亮。这篇逐项说清它们各自解决什么问题。

## 一、设置里通常有这几项

| 设置项 | 作用 | 建议 |
| --- | --- | --- |
| 代码字体 | 决定字母与符号的字形，等宽字体能让缩进对齐、括号配对更容易看 | 优先选等宽字体；最新一版的更新说明里提到过新增代码字体 |
| 字号 | 一屏显示多少行 | 竖屏 12~14 号左右比较稳，再大就会频繁左右滑动 |
| 主题 | 编辑区配色方案，公开介绍里提到过内置多款主题 | 白天室外用浅色、夜间或长时间看用深色 |
| 注释高亮 | 把 `//`、`/* */` 的注释与代码区分开 | 保持开启，注释成片后能一眼看出哪段是代码 |
| 撤销 | 撤回上一步误操作 | 更新说明里提到过支持撤销；删错代码时先试撤销，不要急着关掉文件 |

**入口名称与位置会随版本微调，以你手机上那一版实际显示的为准。** 找不到某一项时，先在编辑界面右上角或侧边菜单里找"设置"。

## 二、字号：手机上的可读性底线

- **别贴着极限调大**。字号调得太大，一行代码会折成两三行，括号配对反而更难认；
- **折行是手机上的主要干扰源**。宁可字号小一号，也要让一行的 `if (...) {` 尽量留在同一行；
- **看不太清时优先换字体而不是猛加字号**：等宽字体的数字与括号更规整，同样字号下辨识度更高。

## 三、字体：为什么要选等宽

Java 代码里 `l`（小写 L）、`1`（数字一）、`I`（大写 i）容易混，`0` 和 `O` 也一样。等宽字体在这些字符上通常有明显区别，非等宽字体则常常分不出来——把变量名里的 `l` 看成 `1` 是新手最常见的低级错误之一。

如果换字体后出现**某些字符显示成方框或问号**，说明这个字体缺字形，换回默认字体或换一个覆盖更全的即可，不是软件坏了。

## 四、主题与注释高亮

- **深色主题的实际好处是省电与护眼**：OLED 屏幕上深色底像素基本不发光，长时间看代码比浅色底舒服；
- **浅色主题的优势在户外**：阳光下浅底深字的可读性通常更好；
- **注释高亮建议一直开着**。学 Java 时经常需要在代码旁边写"这行在干什么"，注释和代码颜色区分开了，回头读自己写的代码会轻松很多。这也是近期版本更新里明确提到加进去的一项。

主题只影响显示，不影响代码本身，随便换、随时换，不会有副作用。

## 五、撤销与误操作

写代码时最常见的两种误操作是**误删一整段**和**粘贴覆盖了原来的内容**。处理顺序：

1. 先按撤销，一步不够就多按几次；
2. 撤销不到时，别继续在同一个文件里乱改——先复制现有内容留底，再动手；
3. 真要救不回来，看 [项目与代码文件怎么管理.md](项目与代码文件怎么管理.md) 里备份那一节，从之前的拷贝里找回。

关掉文件、退出软件不会导致代码丢失（自动保存是常态），但**撤销记录通常不跨会话保留**，重启后撤不回上一次会话里的操作。

## 六、设置调完还是不对劲

- **改了字体或主题没变化**：确认当前打开的是代码文件、不是在文件列表页；设置一般对之后打开的编辑区生效；
- **联想不出、或输入时卡顿**：先按 [编译报错与代码联想怎么处理.md](编译报错与代码联想怎么处理.md) 里那一节排查，再考虑重装；
- **设置被重置**：清数据或重装会带走设置，属正常现象，代码文件不受影响（只要没删）。

编辑体验调顺之后，回到 [第一个程序怎么跑起来.md](第一个程序怎么跑起来.md) 把最小的运行闭环跑一遍，确认改动之后点运行一切照旧。
