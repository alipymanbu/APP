在手机上写代码，最容易被忽略的不是语法，而是"文件到底在哪"。这篇把文件的位置、命名、导入与备份一次说清，避免出现"换了手机代码全没了"这类问题。

## 一、代码存在手机里，不存云端

这个软件没有账号体系，代码只写在手机本地存储里，自动保存是常态——不需要像在电脑上那样记得按保存。由此带来两个直接结论：

- **换手机、双清、卸载重装，代码不会跟着回来**。要留住就自己把 `.java` 文件拷出去（见第五节）；
- **手机上删掉文件就是真删了**，没有云端回收站可以找回。

具体落在哪个目录，可以在应用内的文件/项目列表里长按或点开文件属性查看路径；也可以在系统「设置 → 应用 → 应用管理 → Java编译器 → 存储」里看它占用的空间与目录。**不同版本给的入口名称可能略有差异，以你手机上那一版实际显示的为准。**

## 二、文件与文件夹怎么组织

写练习时，一个文件装一个类最省事。文件攒多了之后，用文件夹按主题分：

| 做法 | 建议 |
| --- | --- |
| 文件名 | 建议只用英文、数字和下划线。原因很实际：文件名去掉后缀后要与 `public class` 的类名逐字一致，两边都用英文时核对起来最不容易出错 |
| 一个文件一个 `public` 类 | Java 规定一个文件里只能有一个与文件名同名的 `public` 类。练习阶段别把它们塞进同一个文件 |
| 目录分类 | 按学习主题建目录（如 `basic`、`oop`、`algo`），比全堆在根目录好找得多 |
| 临时试验 | 单独丢一个 `tmp` 目录，随手改坏了直接删，不影响正式练习文件 |

关于"能不能用中文命名"：Java 语言本身用的是 Unicode 字符集，标识符允许非拉丁字母，所以**中文类名、中文文件名在语法上是合法的**，`public class 测试` 这样的写法能通过编译。但仍建议用英文，原因是实际使用中的麻烦都在语法之外：文件名与类名必须逐字一致，含中文时多一分核对成本；文件在手机、电脑、聊天软件之间来回传时，非 ASCII 文件名更容易出现乱码或被改名。**如果只是想给练习加备注，写在代码注释里比写在文件名里更合适。**

重命名和删除都在应用内的文件列表里操作。**重命名时记得同步改类名**，否则重新运行会报「类名与文件名不一致」。

## 三、打开手机里已有的代码文件

官方说明里写明了支持"直接从文件管理器中打开代码文件"，这条对下面几种场景最管用：

1. 电脑上写好的 `.java` 传进手机，用**系统文件管理器**点开它，选择用 Java编译器 打开；
2. 从聊天软件、网盘下载的示例代码，同样在文件管理器里点开；
3. 代码文件在 SD 卡或下载目录里，不想手动搬运，就直接从文件管理器打开。

打开后能不能直接编译，取决于文件自身：类名与文件名不一致、缺少 `main` 方法、依赖了没有引入的第三方库，都会报错。前两种情况的处理见 [编译报错与代码联想怎么处理.md](编译报错与代码联想怎么处理.md)。

有些版本的软件内也提供导入本地文件夹的入口（公开介绍里提到过"可以导入本地文件夹"）。如果你的版本里有这一项，把练习代码集中放在一个文件夹里再整体导入，比逐个打开省事。

## 四、需要第三方库的时候

公开的软件介绍提到这一版可以添加 `jar` 格式的 lib 文件作为依赖。本套文档没有逐项验证当前版本里这个入口的具体位置，需要用到第三方库时：

1. 先在应用的**项目设置或文件菜单**里找 lib、jar、依赖相关的选项；
2. 把库文件放进项目对应的 lib 目录，再回到代码里 `import`；
3. 如果怎么也找不到入口，就用不依赖外部库的写法实现同样功能——手机上写练习代码，绝大多数场景不需要引入 jar。

引用外部库时若报"找不到类/包"，先确认库是否真的被加进项目，而不是先怀疑代码——判断顺序见 [编译报错与代码联想怎么处理.md](编译报错与代码联想怎么处理.md)。

## 五、备份与换机

代码只在本地，备份必须自己动手。三条路径里下面这两条最省事：

1. **手机本地留副本**：用系统文件管理器把代码目录整包复制到另一处（如 `Download`），换机时再传回去；
2. **拷到电脑或网盘**：把整包目录压缩后通过数据线、聊天软件或网盘传到电脑；文件多、要重复备份的也可以用 adb 命令直接拉取。

三条路径的详细步骤、命令写法，以及备份后"必须验证能打开"这一步，都在 [手机上的代码怎么备份到电脑.md](手机上的代码怎么备份到电脑.md) 里。

练习文件丢了重写更快，不必备份；已经攒成项目、或者准备换手机/刷机/恢复出厂设置之前，则一定要先备份一次——这三件事做完，本地代码就找不回来了。文件删了、路径找不到了、导入后打不开，先在 [常见问题与排查.md](常见问题与排查.md) 里对现象，再决定要不要重装。
