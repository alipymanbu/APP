# Java编译器 手机上的代码怎么备份到电脑

> 代码只存在手机本地，卸载与换机都会一起带走。这篇给三条可操作的备份路径，以及备份时最容易漏掉的一步。
> **相关文档**：[项目与代码文件怎么管理.md](项目与代码文件怎么管理.md) · [常见问题与排查.md](常见问题与排查.md)

练习代码丢了不可惜，但如果已经攒了几十个文件、或者里面有正在做的项目，就该把它当成需要定期备份的东西——因为**这份软件没有账号也没有云同步，代码删了、卸载了、换手机了，都不会自己回来**。

## 一、要备份的其实只有源文件

| 内容 | 要不要备份 | 说明 |
| --- | --- | --- |
| `.java` 源文件 | **要** | 唯一不可再生的东西，代码全在这里 |
| 应用本身 | 不必 | 安装包在网盘里随时能再取一份（见 [下载与安装教程.md](下载与安装教程.md)） |
| 编辑器设置（主题、字体） | 不必 | 重装后按 [主题字体与编辑器设置.md](主题字体与编辑器设置.md) 重调一遍，几分钟的事 |

所以备份的目标很明确：**把 `.java` 文件整包拷出来**。

## 二、方法一：文件管理器直接拷（推荐）

不用电脑也能做，最通用：

1. 打开系统文件管理器，找到存放代码的那个目录（怎么找见 [项目与代码文件怎么管理.md](项目与代码文件怎么管理.md)）；
2. 长按目录 → 全选 → 复制，粘到手机另一处（例如 `Download`）作为本地副本；
3. 再用聊天软件、网盘或数据线，把这份副本传到电脑；
4. 到电脑上打开几个文件确认内容完整、不是 0 字节。

**小提示**：这一步顺手多做一个动作——把备份按日期命名（如 `java-练习-2026-09`），以后不用猜哪份是新的。

## 三、方法二：用 adb 拉到电脑

电脑上装了 Android 平台的调试工具（adb）时，可以用一条命令把目录拉到本地，适合文件多、要重复备份的场景。手机需在"开发者选项"里打开 USB 调试，再用数据线连上电脑：

```bash
adb devices
adb pull /sdcard/你的代码目录 ./java-backup
```

第一条确认设备已被识别，第二条把整个目录拉到当前目录下的 `java-backup` 里。两点注意：

- **能拉到什么取决于该目录的位置**。能通过文件管理器看到的目录，adb 也能读到；看不到的私有目录需要额外权限，普通使用不必碰；
- **不要反向覆盖**。`adb push` 是往手机写，备份场景一般用不到，写错方向可能覆盖手机上的新代码。

## 四、方法三：借道网盘或聊天工具

把代码目录压缩成一个 zip，上传到自己的网盘或发给自己，换设备时再下载。优点是零成本、跨设备方便；缺点是要手动做，容易忘。练习阶段够用，长期维护的项目还是前两种更靠谱。

## 五、备份完必须做的一步

**验证能打开。** 备份最容易出的问题是"文件传过去了但打不开"：传输中断、编码损坏、压缩包没传完，都会出现这种情况。所以备份完至少做一次：

1. 在电脑上打开其中一个 `.java`，确认中文注释没有变成乱码；
2. 再挑一个文件传回手机，用"从文件管理器打开"的方式打开，能正常显示再算备份成功；
3. 恢复时**不要直接覆盖**手机上的同名文件，先比对两边内容再决定留哪一份。

## 六、多久做一次

- **随手练习**：不用管，丢了重写更快；
- **有在推进的项目**：每完成一个能跑通的版本就备份一次，比自己估"大概快写完了"可靠；
- **换手机、刷机、恢复出厂设置之前**：必须先备份，这几件事做完代码就找不回来了。

代码找不到、备份文件打不开、恢复后报错，先在 [常见问题与排查.md](常见问题与排查.md) 里对现象；如果是文件本身丢了且事先没备份，本地没有回收站，只能重写。
