# Java编译器 同名应用与官方渠道怎么认

> 应用商店里叫「Java编译器」的不止一个，名字、图标都容易看混。这篇给三个可核对的锚点，帮你确认手上装的是哪一个。

「Java编译器」是个通用名词，不是某个产品的专有名称——任何能在手机上编译 Java 的工具，商店描述里都可能这么写。所以光凭搜索关键词装应用，很容易装到另一个功能相近、但完全无关的软件上。

## 一、用这三项核对身份

不管从哪个渠道拿到安装包，装完都可以在「设置 → 应用 → 应用管理」里点进该应用，核对下面三项：

| 核对项 | 本套文档对应的值 | 为什么看这项 |
| --- | --- | --- |
| 开发方 | 唐山旗鱼科技有限公司 | 同名的应用往往分属不同公司，这项最能一眼分开 |
| 包名 | `coding.yu.javacompiler.new` | 包名是应用在系统里的唯一标识，改不了、也没法伪装成一致的 |
| 版本号 | 10.4.1 | 与本文档所写的这一版对应；版本可以升级，包名不会变 |

三项里**包名最可靠**：名字可以起得一样、图标可以抄，包名不同就是两个互不相干的应用，**不能互相覆盖安装**，也装不出同一个软件。

## 二、几个常被当成"同一个"的工具

下面这几个都能在手机上跑 Java，但都是别的产品，与本套文档对应的 Java编译器 没有关系：

| 名称 | 包名 | 它是什么 |
| --- | --- | --- |
| Jvdroid | `ru.iiec.jvdroid` | 面向教学的安卓 Java IDE，自带 OpenJDK 11 离线编译，支持 Maven 工程 |
| AIDE | `com.aide.ui` | 安卓上的集成开发环境，主要用来在手机上写并打包安卓应用 |
| Termux | `com.termux` | 安卓上的终端模拟器，装完还要自己执行命令安装 JDK 才能编译 Java |

这三者与本文这份 Java编译器 的差别不在"好不好用"，而在**门槛与用途**：Jvdroid 与 AIDE 提供完整的工程体系，Termux 需要敲命令行；本文这份的定位是装完就能敲几行代码、点运行看结果，没有工程配置那一步。

## 三、同一个开发方还有别的产品

唐山旗鱼科技有限公司还出过一个名字很像的产品 **Python编译器**（包名 `coding.yu.pythoncompiler.new`），界面形态与本文这份接近，只是跑的是 Python。两者的包名都以 `coding.yu.` 开头、但后半段不同，属两个独立应用，不能互装。

**核对时的实用技巧**：看到 `coding.yu.` 开头的包名，说明这一系是同一个开发方的产品；但只有 `coding.yu.javacompiler.new` 才是本文档对应的那一个。

## 四、官方渠道与手上这份的关系

要确认官方的最新版本、说明与更新记录，认**应用商店里该应用的详情页**（应用宝、小米应用商店等主流商店都能搜到这个包名对应的条目）与**开发者主体**这两处。第三方下载站转载的版本号、体积经常对不上，别拿它当标准。

需要说清的一点：**本套文档配的安装包与官方最新版未必是同一版**。网盘里这份是制作文档时核对过的版本（上表里的 10.4.1），官方可能已经发布了更新的版本。想确认自己装的是哪一版，用第一节那个表逐项对一遍即可。

如果你装的这一版界面上很多描述对不上，先回 [下载与安装教程.md](下载与安装教程.md) 确认包名；装不上、打开闪退、两个同名图标分不清，到 [常见问题与排查.md](常见问题与排查.md) 按现象对表。
