这份清单按"你看到什么现象"来查。第一步永远是分清两件事：**是代码编译报错，还是软件本身不工作**。前者去 [编译报错与代码联想怎么处理.md](编译报错与代码联想怎么处理.md)，后者看这里。

## 一、安装与打开

| 现象 | 常见原因 | 怎么处理 |
| --- | --- | --- |
| 提示「解析包错误」 | 安装包没下完整，或下载过程中被截断 | 重新下载一次；电脑上下载的可以在电脑上算 MD5 与文档里给的值比对（见 [下载与安装教程.md](下载与安装教程.md)） |
| 提示「应用未安装」 | 手机里已有同包名但版本更高的应用，安卓不允许降级覆盖 | 先卸载旧版再装；若两个版本签名不同，同样会失败，也只能先卸载 |
| 点击安装包没反应 | 缺"安装未知应用"权限，系统直接拦下且不提示 | 去「设置 → 应用 → 特殊应用权限 → 安装未知应用」给文件管理器或浏览器打开开关 |
| 装完桌面找不到图标 | 被系统归到应用抽屉里，或装了但被安全软件隐藏 | 在系统「设置 → 应用 → 应用管理」里搜应用名；能搜到就说明装上了 |
| 打开就闪退 | 系统版本过低，或安装包与当前系统不兼容 | 若系统很旧，换新一点的安卓设备试；仍不行则换网盘里更新的一份包 |

## 二、运行相关

| 现象 | 常见原因 | 怎么处理 |
| --- | --- | --- |
| 点运行完全没反应 | 编辑器里内容为空、或文件保存失败；也可能是上一次编译还没结束 | 确认编辑区里有完整代码（含 `main` 方法），退到文件列表再重新打开一次，再点运行 |
| 一直停在编译中 | 代码体量过大，或手机可用内存紧张 | 关掉后台其它应用再试；练习阶段把代码拆成小文件，别在一个文件里堆几千行 |
| 运行结果区没有任何内容 | 程序执行了但没有打印任何东西 | 程序只有产生输出才有结果可看，加一句 `System.out.println(...)` 再运行一次 |
| 改了代码，结果还是旧的 | 编译针对的是当前这一份内容，改完没重新点运行 | 每次改完都重新点一次运行 |
| 输出里中文显示异常 | 与编码有关，不同版本表现不一致 | 先在代码里用英文输出验证编译链是否正常；确认只是编码显示问题后，改用英文提示信息更稳 |
| 明明语法没错却报错 | 上一节说的高发原因：全角标点、文件名与类名不一致 | 按 [编译报错与代码联想怎么处理.md](编译报错与代码联想怎么处理.md) 的对照表逐条核对 |
| 用了 `Scanner` 的程序一点运行就停住 | 运行环境没有控制台输入通道，程序卡在等输入上 | 判断方法与三种绕法见 [键盘输入的程序为什么卡住.md](键盘输入的程序为什么卡住.md) |
| 代码看着完全正确，却报"找不到符号""缺分号" | 输入法的自动纠错、自动大写或全角标点，把你敲的内容悄悄改了 | 关掉输入法的自动纠错与自动大写，见 [手机上敲代码的输入法怎么配.md](手机上敲代码的输入法怎么配.md) |

## 三、文件与保存

| 现象 | 常见原因 | 怎么处理 |
| --- | --- | --- |
| 代码保存不了 | 没给存储权限 | 在「设置 → 应用 → 应用管理 → Java编译器 → 权限」里把文件读写权限打开 |
| 重进软件代码不见了 | 编辑的是没保存的临时内容；或文件被删、被移动到别处 | 先在文件列表里找找有没有同名文件；找不回就说明当时没落到存储里，重要代码要自己往外拷一份（见 [项目与代码文件怎么管理.md](项目与代码文件怎么管理.md)） |
| 从文件管理器打开的 `.java` 打不开 | 文件本身不完整，或类名与文件名不一致导致编辑器无法按 Java 处理 | 先把文件复制到手机内部存储再打开；核对类名与文件名是否一致 |
| 换手机后代码全没了 | 代码只存在本地存储，没有账号同步 | 只能从自己做的备份里恢复；换机前先拷出来，做法见 [手机上的代码怎么备份到电脑.md](手机上的代码怎么备份到电脑.md) |
| 文件删了想找回 | 本地删除没有回收站 | 无法在应用内找回，只能从自己做的备份里恢复 |

## 四、权限与网络

- **必须要的**：文件读写（保存与打开代码）。不给这一项，写代码可以，但存不进手机存储。
- **与写代码无关的**：短信、通讯录、定位、无障碍这类申请，直接拒绝，不影响编译与运行。
- **要不要联网**：编译在手机的本地环境里完成，写代码本身不依赖账号也不需要登录。断网时能否完整使用，以你手机上那一版实际表现为准。
- **后台被杀**：部分国产系统会在锁屏后清理后台。如果切出去再回来发现内容变了，先确认是否被系统清理，做法是在电池设置里把 Java编译器 设为"允许后台运行"。

## 五、还是不行怎么处理

按顺序做这三件事：

1. **换一份包重装**：先卸载，再从 [Java编译器 安装文件资源（夸克网盘）](https://pan.quark.cn/s/0ce54a208e4e) 取一份重新安装（代码文件提前拷出来）；
2. **确认装的不是同名应用**：核对包名与开发方，见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)；
3. **分清新旧版本**：网盘里这份是制作文档时核对过的 10.4.1，官方可能已有更新的版本，若你的问题在新版里已修，换新版即可。

重装之前记得备份代码——本地存储里的代码不会跟着账号回来。
