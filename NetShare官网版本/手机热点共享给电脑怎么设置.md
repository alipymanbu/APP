# NetShare 手机热点共享给电脑怎么设置

> 从手机开启共享到电脑真正能上网的完整步骤，Windows、macOS、Linux 三条路径分别怎么写。

把手机的网络给电脑用，NetShare 比系统热点多一步：电脑连上热点之后还要指定一次代理或导入一次连接配置。这一步不做，热点是连得上的，但浏览器打不开任何网页。本文按「手机怎么开 → 电脑怎么连 → 电脑怎么配」的顺序写，三条路径按你自己的系统选一条走。

## 一、为什么连上热点还要多配一步

系统自带热点是把流量直接路由给接入设备；NetShare 在不 root 的前提下做不到这一点，它是在手机上跑一个本地代理，让接入设备的流量先交给这个代理再出去。官方在常见问答里也是这个说法：因为安卓系统的限制，不 root 就无法直接转发流量，所以要用代理的方式绕过去。

由此带来两个你在操作上会碰到的结果：

- **电脑必须手工指定代理**（或者导入它提供的一条 VPN 连接），不能指望连上 Wi-Fi 就自动通网；
- **代理地址和端口要以手机应用界面上显示的值为准**。常见值是 `192.168.49.1` 加端口 `8282`，但不同版本、不同机型下可能不同，不要凭记忆填。

先确认手机那侧已经装好并开启了共享（见 [下载与安装教程.md](下载与安装教程.md)），再往下走。

## 二、第一步：在手机上开启共享

1. 打开 NetShare，把共享开关打开（Windows 侧那套配置也依赖这一步，顺序不能反）；
2. 记下界面上显示的三样东西：**热点名称（SSID）**、**密码**、**代理地址与端口**；
3. 保持这个界面能随时切回来——后面电脑上要照着填的正是这几个值。

如果热点名称旁边还显示了一个类似 `192.168.49.1` 的地址，那是接入设备的网关，也是代理地址；要分享已有 Wi-Fi 而不是移动数据时，先在手机上连上那个 Wi-Fi 再开共享，见 [WiFi中继与信号扩展怎么用.md](WiFi中继与信号扩展怎么用.md)。

## 三、第二步：让电脑连上这个热点

Windows 任务栏、macOS 菜单栏的 Wi-Fi、Linux 的桌面网络菜单里，找到手机上显示的那个热点名称，输入密码连接。

连接之后有个现象要先说明：**电脑会显示「已连接，但无法访问 Internet」或出现黄色感叹号**。这是正常的——此时电脑还差最后一步配置，见下一节。不要把它当成故障去反复断连重连。

## 四、第三步：按系统把网络配通

### 4.1 Windows

官方给的是一条自动配置命令，它会新增一条名为 NetShare 的 VPN 连接，用起来最完整（浏览器以外的程序也走这条线）。

1. 手机保持共享状态、电脑保持连着热点；
2. 按 `Win + R`，输入 `cmd` 后回车，打开命令提示符；
3. 把下面这行粘进去回车，脚本会自动新增连接：

```
curl http://192.168.49.1:8181/wbt -o w.bat & start w.bat
```

4. 系统会弹出一个批处理窗口执行配置，按提示走完；
5. 配好之后点任务栏的网络图标，进 VPN 列表，选中名为 **NetShare** 的连接并点连接。

配置命令里的地址取自手机界面；如果你看到的代理地址不是 `192.168.49.1`，把命令里的这一段替换成手机实际显示的值。Windows 10 1803 及以后自带 `curl`，提示找不到命令说明系统太旧，用下面的备选方案。

**备选方案：只用 HTTP 代理。** 适合只想让浏览器上网的场景：

1. 打开「控制面板 → 网络和 Internet → Internet 选项」；
2. 切到「连接」选项卡，点右下角的「局域网(LAN)设置」；
3. 勾选「为 LAN 使用代理服务器」；
4. 地址填手机界面显示的代理地址（常见为 `192.168.49.1`），端口填 `8282` 或手机显示的值；
5. 确定保存，回到浏览器刷一次页面。

这个方案有个已知短板：只认系统代理的程序才能上网，聊天软件、游戏、部分下载工具会没网，处理办法见 [代理设置后上不了网怎么排查.md](代理设置后上不了网怎么排查.md)。

### 4.2 macOS

同样先让 Mac 连上热点，再选一种方式：

**方式一：一条命令装好配置。** 打开「终端」（`Command + 空格` 搜索 Terminal），粘贴下面这行回车：

```
bash <(curl -s http://192.168.49.1:8181/msh)
```

过程中如果要求输入密码，输的是你登录这台 Mac 的开机密码（终端里输入时不显示字符，正常现象）。

**方式二：手工配置自动代理。** 适合不想在终端里跑命令的情况：

1. 打开「系统设置 → 网络」，选中 Wi-Fi，点已连接的 NetShare 网络右侧的「详细信息」；
2. 在弹出窗口左侧选「代理」；
3. 打开「自动代理配置」的开关；
4. 在 URL 一栏填入 `http://192.168.49.1:8282`（以手机界面显示的值替换）；
5. 点「好」，再点「应用」保存。

### 4.3 Linux

先连上热点，再按桌面环境选一条：

**GNOME（Ubuntu、Fedora、Pop!_OS 等）**：「设置 → 网络 → 网络代理 → 手动」，打开 HTTP 代理，主机填 `192.168.49.1`、端口填 `8282`，有 HTTPS 一栏的话填同样的值，保存。

**KDE Plasma**：「系统设置 → 网络 → 代理 → 手动配置」，HTTP 与 HTTPS 都填 `192.168.49.1` 与 `8282`，应用。

**只在终端里用**：给当前会话临时导出代理变量，关掉终端就失效：

```
export http_proxy=http://192.168.49.1:8282
export https_proxy=http://192.168.49.1:8282
export HTTP_PROXY=http://192.168.49.1:8282
export HTTPS_PROXY=http://192.168.49.1:8282
```

用 `echo $http_proxy` 可以确认变量是否生效。

Linux 上最常见的落差是「浏览器能开、终端里 `curl` 或 `apt` 不行」——这些程序默认不读桌面代理设置，用上面那组环境变量即可；再有一部分程序连环境变量也不认，得去它自己的配置里单独填代理。

## 五、配完的验证与速查

| 现象 | 说明 |
| --- | --- |
| 浏览器能打开网页 | 链路通了，可以正常用 |
| 提示「已连接，无法访问 Internet」 | 电脑侧代理没配或配错，回到第四节 |
| 浏览器能开、某个软件不行 | 该软件不读系统代理，见 [代理设置后上不了网怎么排查.md](代理设置后上不了网怎么排查.md) |
| 一开始好用，几分钟后断 | 多数是手机的电池优化掐了 NetShare，按排查篇处理 |

## 六、用完记得收尾

1. **在电脑上把代理关掉或改回「自动检测」**。手工填的代理是留在系统设置里的，回到家里或公司的正常 Wi-Fi 后如果不撤销，会出现「连上了却没网」的情况，很容易被误判成网络故障。
2. **在手机上关闭共享开关**。共享一直开着会持续耗电，手机也会明显发热。
3. 用 Windows 自动配置方式的，VPN 列表里那条 NetShare 连接可以留着不动，下次连热点时直接用。

换到另一台设备上网时，重复第二到第四节的步骤即可；接入端不是电脑而是手机、平板，看 [给另一台手机和平板共享网络.md](给另一台手机和平板共享网络.md)。
