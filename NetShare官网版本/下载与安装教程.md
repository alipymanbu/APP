NetShare 是一款把手机的网络共享给其他设备的安卓应用，在 Google Play 上的名称是「NetShare - no-root-tethering」，全程不需要 root 权限。它和系统自带热点最大的不同是：接入端连上热点后还要再配一次代理、或者装一次它的客户端，才能真正上网。本篇只解决一件事——把网盘里这份包装到「出网的那台手机」上，并把首次打开要放行的项目配齐。

## 一、先弄清网盘里这份包是哪一版

网上能搜到的是官方当时的最新版，网盘里这份是制作文档时逐项核对过的那一版，两者未必是同一个版本号。本文出现的版本号、包名、体积一律以下表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | NetShare |
| 商店显示名 | NetShare - no-root-tethering |
| 版本号 | 272 |
| 包名 | `kha.prog.mikrotik` |
| 安装包体积 | 0.96 MB（1,005,673 字节） |
| MD5 | `604727DB7FA22BEC8C8511B01847308D` |
| 核对日期 | 2026-09-24 |

**关于版本号**：这个应用的版本号是纯数字往上递增的，没有 `1.5.2` 那样的三段式，所以看到「272」不要当成 2.7.2 去理解。想知道官方当前是什么版本，以应用商店页面当时显示的为准。

**关于体积**：安装包不到 1 MB，是同类工具里少见的轻量，装到手机上几乎不占空间；装完后的实际占用会比它略大一点，属正常现象。

## 二、这份包要装在哪一台设备上

NetShare 分「出网的一侧」和「接入的一侧」，两边的安装需求不一样，先对一下再动手：

| 设备角色 | 是否要装 NetShare | 说明 |
| --- | --- | --- |
| 出网的那台安卓手机 | 必须装 | 由它建立热点、把网络转发给别的设备 |
| Windows / macOS / Linux 电脑 | 不用装 | 连上热点后跑一条配置命令，或手工填代理 |
| 另一台安卓手机 / 平板 / Chromebook | 建议装 | 装了以后点 CONNECT 直接接入，比手工填代理省事 |
| iPhone / iPad | 不用装 | 在 Wi-Fi 设置里手工填代理即可 |

这个应用只有安卓版，装不到 iPhone 上，也没有可以装在电脑上的服务端。拿错设备装了半天发现根本无法共享，通常就是没分清这两侧。

## 三、安装步骤

1. **转存并下载**：从 [NetShare 安装文件资源（夸克网盘）](https://pan.quark.cn/s/d284414b61a5) 把 APK 转存到自己的网盘再下载；直接用出网的那台手机下载最省事。
2. **允许安装未知来源应用**：在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给用来打开这个安装包的应用（文件管理器或浏览器）放行。部分定制系统把这项收在「安全」或「隐私」分类下。
3. **点击 APK 完成安装**：系统提示「应用未经过安全检测」时选择继续，这是第三方渠道安装包的常规提示。
4. **别和别的渠道版本混装**：同一个包名 `kha.prog.mikrotik` 在不同分发渠道的签名可能不同，安卓不允许签名不同的同名应用互相覆盖。遇到「应用未安装」，先卸载手机里已有的那个再装；卸载会一并清掉它的设置。
5. **回装低版本同样要先卸载**：安装包版本号低于手机里已装的那一版时，安卓会直接拒绝安装。

## 四、首次打开要放行的项目

| 项目 | 在哪放行 | 不放行会怎样 |
| --- | --- | --- |
| VPN 连接请求 | 开启共享时（或接入端点 CONNECT 时）系统弹窗，选「允许」 | 热点连得上，但接入端打不开任何网页 |
| 电池优化 / 后台限制 | 「设置 → 应用 → NetShare → 电池」改成「不受限制」，部分机型还要在手机管家里放行后台运行 | 共享跑几分钟就自己断，屏幕一关就断 |
| 通知 | 按系统弹窗允许 | 看不到当前共享状态，不好判断它是否还在工作 |
| 存储 / 文件访问 | 按系统弹窗允许 | 一般不影响共享，只在保存配置类操作时用到 |

各品牌机型的设置路径和措辞差别不小，认准「电池」「后台」「VPN」这几个关键词去找即可。电脑那侧不需要在这里配任何权限，它的设置在电脑上完成，见 [手机热点共享给电脑怎么设置.md](手机热点共享给电脑怎么设置.md)。

## 五、装完做一次最小验证

先用一台设备把链路走通，再考虑多设备：

1. 打开 NetShare 的共享开关，记下界面上显示的热点名称、密码，以及代理地址与端口；
2. 拿一台电脑（或另一台手机）连上这个热点；
3. 按 [手机热点共享给电脑怎么设置.md](手机热点共享给电脑怎么设置.md) 或 [给另一台手机和平板共享网络.md](给另一台手机和平板共享网络.md) 把接入端配好；
4. 在接入端打开浏览器访问任意网站，能打开就说明通了。

热点连得上但网页打不开，先别怀疑版本装错，直接看 [代理设置后上不了网怎么排查.md](代理设置后上不了网怎么排查.md)；如果连热点列表里都找不到它，看 [支持哪些系统和设备.md](支持哪些系统和设备.md) 里的设备支持情况。

## 六、想从官方渠道核对与更新

网盘里这份是本文核对过的那一版。想确认官方是否已有更新，或者想对照官方说明，可以走这两个入口：

| 渠道 | 地址 |
| --- | --- |
| 官方站点 | [netshare.app](https://netshare.app/) |
| Google Play | [商店页面](https://play.google.com/store/apps/details?id=kha.prog.mikrotik) |

商店里的版本通常比网盘里这份新。换版本时先卸载再装，不要直接覆盖；换版本之后热点名称、代理端口这类参数可能发生变化，一律以应用界面实际显示的为准。
