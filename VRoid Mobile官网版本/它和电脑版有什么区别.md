# VRoid Mobile 和电脑版有什么区别

> 本篇把「VRoid Mobile」和「VRoid Studio」这两个容易混的名字讲开：各自是什么、实际能力差在哪、能不能互相流转。

VRoid Mobile 是手机上的角色制作与拍照应用，VRoid Studio 是电脑（和 iPad）上的 3D 角色制作软件，两者同属 pixiv 的 VRoid 项目、共用同一个账号体系，但**是两个独立的软件，功能不能互相替代**。如果你搜到的介绍一会儿说「手机上捏人拍照」、一会儿又说「压感笔刷画贴图」，那多半是把两边的资料混在一起了。

## 一、一句话分清

| | VRoid Mobile | VRoid Studio |
| --- | --- | --- |
| 形态 | 手机应用 | 桌面软件（另有 iPad 版） |
| 跑在哪 | Android、iOS | Windows、macOS、iPad |
| 主要用途 | 拼角色、换装、拍照（含 AR） | 精细做 3D 角色模型 |
| 账号 | 需要 VRoid Hub（即 pixiv）账号 | 可选关联 VRoid Hub 账号 |
| 版本号 | 1.x（如 1.16.3） | 2.x（如 2.14.0） |

**两边的版本号各走各的**，不存在「手机版 1.16.3 对应电脑版某个版本」这种对应关系。看到别人写「VRoid 最新版 2.x」，说的是电脑版。

## 二、为什么这两个名字总是被写混

三个原因叠在一起：

1. 产品名都以「VRoid」开头，中文语境里常被简写成「VRoid」，单独看分不出是哪一个；
2. 官方早期在手机版上用的名字是日文「VRoidモバイル」，英文站写 VRoid Mobile，中文页面翻法不统一；
3. 有些第三方介绍页把手机版直接写成「VRoid Studio 手机版」，于是「手机版」这个说法被沿用开来。

**辨认靠包名最稳**：手机版的 Android 包名是 `net.pixiv.vroid.android`，电脑版没有 Android 包。你手上这份安装包就是这个包名，所以它属于**手机版**。

## 三、实际能力差在哪

这是最需要分清的一节——几个常被张冠李戴的功能：

| 能力 | VRoid Mobile | VRoid Studio |
| --- | --- | --- |
| 脸部调整 | 从预设里挑五官部件，再用滑块调位置、角度、大小 | 预设 + 逐参数调整，另有表情编辑器 |
| 画贴图（绘制头发、衣服纹理） | 没有贴图绘制功能 | 有笔刷工具，支持数位板压感 |
| 换装 | 应用内「Avatar Wear」一键穿脱 | 服装编辑器 + XWear 换装体系 |
| 自建服装 | 只能用在应用内已有的单品里挑 | 可以从模板改，也能从零做 |
| AR 拍照 | 有（AR 相机） | 没有 |
| 多人同框 | 有（单人拍摄可摆 10 个角色，同一影棚最多 4 人一起） | 没有 |
| 导出 VRM | 可以（经由 VRoid Hub） | 可以直接导出 VRM |

所以「能用压感笔直接画贴图」「能精细到面部肌肉」这类说法，说的是**电脑版**，手机版做不到——手机版的设计前提是「不用从零建模」，只能选部件加滑块。理解这一点，很多「为什么我找不到某功能」的困惑就没了。

## 四、能不能互相流转

可以，但要经过 VRoid Hub 中转，而且**是单向变方便、反向受限**：

| 方向 | 怎么做 | 限制 |
| --- | --- | --- |
| 手机版 → 别处 | 把角色上传到 VRoid Hub，再从 Hub 下载 VRM 文件 | 模型要由 1.14.4 及以后的版本上传；别人做的模型、含不允许下载单品的模型不能下载 |
| 电脑版 → 手机版 | 把模型传到 VRoid Hub，在手机版里调回来拍照 | 调回来的角色**不能在手机版里编辑**；VRM 1.0 格式和有年龄限制的模型不会出现在手机版里 |
| 手机版 → 手机版 | 换手机时用 Hub 中转 | 手机版没有直接把模型数据从旧机搬到新机的功能；币和付费单品可以转移，模型数据不行 |

细节见 [导出VRM与在别的软件里用.md](导出VRM与在别的软件里用.md)。

## 五、付费情况

两边的收费方式不一样，混着记容易误会：

| | VRoid Mobile | VRoid Studio |
| --- | --- | --- |
| 软件本身 | 免费下载 | 免费下载 |
| 应用内购买 | 有：服装里的付费单品要用 VRoid 币买 | 没有这一项 |
| 广告 | 官方商店页未标注含广告 | 官方 2026 年 4 月公告：PC 版与 iPad 版将引入广告横幅，并提供隐藏选项（以官方公告为准） |

手机版的付费主要发生在「买衣服」上，不买付费单品也能正常做角色和拍照。

## 六、按你的设备对照

- 只用手机会做角色、拍照片、发社交平台 → 手机版这一套就够，装好即用；
- 要在电脑上细调贴图、做给 VRChat 用的模型 → 需要电脑版 VRoid Studio；手机版做的角色可以经 VRoid Hub 导出成 VRM 文件，拿到支持 VRM 的软件里用；
- 想拿 Hub 上的角色来拍照 → 手机版可以直接把 Hub 上的角色调进影棚（有年龄限制和 VRM 1.0 格式的除外）。

两条下载与安装的说明是分开的：手机版见 [下载与安装教程.md](下载与安装教程.md)；电脑版请以官方主页 [vroid.com/studio](https://vroid.com/studio) 的版本与要求为准。
