# VRoid Mobile 常见问题与排查

> 本篇按「症状 → 原因 → 处理」整理手机版最常遇到的几类问题，解法大多来自官方帮助页。

手机版功能不复杂，但有几类问题的表现很像「软件坏了」，实际都是权限、设备能力或者账号状态导致的。下面按症状分组，对照着查比反复重装快得多。

## 一、装不上、进不去

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| 安装时报「解析包错误」「应用未安装」 | 安装包传输损坏，或手机空间不够 | 先按 [下载与安装教程.md](下载与安装教程.md) 里的 MD5 核对文件；文件没问题就清出 300 MB 以上空间重试 |
| 提示不允许安装未知来源应用 | 系统默认关掉了侧载 | 给**发起安装的那个应用**（一般是文件管理器）开「安装未知应用」权限，不是系统全局开关 |
| 装好了，点图标没反应或闪退 | 机型过老、内存不足 | 官方明确写了「满足系统版本也不保证能跑」；先清理后台与存储，仍不行说明机型确实不支持 |

## 二、登录

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| 提示登录失败（Failed to log in 一类） | 默认浏览器处理不了登录跳转 | **把系统默认浏览器换成 Chrome 再试**——这是官方给的原话解法；同时把系统和浏览器都升到最新版 |
| 换过账号，进去还是旧角色的数据 | 登录态没切换干净 | 官方有专门的「切换账号」条目，按它走一遍；顺手确认浏览器里也退了旧账号 |

## 三、拍照与相册

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| 提示保存成功，相册里没有 | iOS 的照片权限被设成了「选择照片…」或「不允许」 | 进「设置 → VRoid → 照片」改成**「所有照片」** |
| 每存一张照片都弹一次权限窗 | 同上 | 同上 |
| 第一次保存时不知道该选哪个 | 权限弹窗选项的含义 | 直接选「允许访问所有照片」，选「选择照片…」会出现上面两种毛病 |
| 找不到 AR 拍摄入口 | 设备不支持 ARCore / ARKit | 入口只对支持的设备显示，不是开关；机型支持列表见官方 ARCore 支持页；官方也提示过，老机型即使在列表里也可能用不了 |
| 想拍视频但找不到录像按钮 | 应用没有录像功能 | 用系统录屏：iOS 在「设置 → 控制中心 → 自定控制」里加上「屏幕录制」，Android 用任意录屏应用 |

## 四、币与付费

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| 只买了一件单品，币被扣了两次 | 官方说明是购买时处理时间不足导致的内部问题 | 官方会核实后退还 VRoid 币。通过[官方咨询表单](https://www.pixiv.net/support.php?mode=inquiry&type=1&service=vroid-mobile)提交，要带上三样：**购买日期、所购单品的截图、登录手机版用的 VRoid Hub 账号邮箱** |
| 分不清哪些衣服要花钱 | 免费单品与付费单品混在同一个列表里 | 按钮是 **Collect** 的是 0 币免费单品，**Purchase** 才需要币 |

## 五、角色显示不出来

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| VRoid Hub 上明明有，手机版列表里就是没有 | 模型有年龄限制（R-15 / R-18），或是 VRM 1.0 格式 | 这两类模型手机版不读取，换一个没有这两个限制的模型来拍 |
| 调回来的角色表情不动、姿势僵着 | 表情动画是为手机版里做的模型优化的 | 官方说明：外部软件做的模型、以及部分电脑版做的模型，表情可能出不来；不是操作问题，目前没有用户侧的解 |
| 想改调回来的角色却找不到编辑入口 | 通过 Hub 调进来的角色不能在手机版里编辑 | 回做它的那台设备改；或者在一开始就用手机版新建角色 |

## 六、功能找不到，先排除这几种误会

| 你以为有的功能 | 实际情况 |
| --- | --- |
| 用笔刷画头发、画衣服贴图 | 手机版**没有**贴图绘制；有笔刷和压感的是电脑版 VRoid Studio |
| 精细到单个面部肌肉的调整 | 手机版是在预设部件上拉滑块调位置与比例，做不到改笔画 |
| 用下载来的 XWear 服装文件给角色换上 | XWear 是电脑版的服装格式；手机版用应用内的 Avatar Wear 列表 |
| 和朋友一起进影棚后临时换个角色 | Shoot Together 模式下不能换角色，要离开影棚、回角色制作页选好再进 |

对着 [它和电脑版有什么区别.md](它和电脑版有什么区别.md) 里的能力对照表核一遍，基本能判断某个功能到底属于哪一边。

## 七、数据会不会丢

| 场景 | 结果 |
| --- | --- |
| 卸载应用 / 重装 | **角色数据一起清除，重装也恢复不了**；币和已购付费单品不受影响 |
| 换手机 | 模型数据没有直接迁移的办法；先把角色上传到 VRoid Hub，在新设备上登录同一账号调回来用（但不能再编辑） |
| 币和付费单品 | 可以转移到新设备 |

结论很简单：**任何清理动作之前，先把要留的角色传到 VRoid Hub**。上传步骤见 [怎么捏出自己的3D角色.md](怎么捏出自己的3D角色.md)。

---

上面这些之外的问题，官方帮助站按功能分了类（角色制作、拍摄、使用条件、注册注销、故障），遇到报错时先按报错原文在那里对一遍，比在论坛里猜要快。
