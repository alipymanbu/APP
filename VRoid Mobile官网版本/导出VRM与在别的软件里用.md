# VRoid Mobile 导出VRM与在别的软件里用

> 本篇讲手机版做的角色怎么变成 VRM 文件拿给别的软件用、哪些情况导不出来、模型的使用条件，以及换设备时数据怎么处理。

VRM 是 3D 角色的一种通用文件格式，VTuber 直播软件、VRChat 这类虚拟社交平台都能直接读它。手机版做的角色**不能直接从手机里导出文件**，要经过 VRoid Hub 中转：先把角色传上 Hub，再从 Hub 下载 VRM。本篇把这条链路和它的限制讲清楚。

## 一、导出流程

两步，顺序不能颠倒：

1. **在手机版里把角色上传到 VRoid Hub**——入口在首页右下角的图标，传到浏览器里选「保存并公开」或「私下保存」（步骤见 [怎么捏出自己的3D角色.md](怎么捏出自己的3D角色.md)）；
2. **到 VRoid Hub 上打开自己的模型页，下载 VRM 文件**。

下载下来的 VRM 就是一个普通文件，放进支持 VRM 的软件里就能用。

## 二、哪几种情况下载不了

在掏钱买衣服、或者花时间捏角色之前，先看这一节能省事：

| 情况 | 结果 |
| --- | --- |
| 模型是**别人**做的 | 不能下载 |
| 模型里含有**不允许下载的单品** | 整个模型都不能下载 |
| 模型是由 **1.14.4 之前**的版本上传到 Hub 的 | 不能下载 |

第三条的意思是：这个下载能力是 1.14.4 版本才加的，官方把适用范围限定为「经由 1.14.4 及以后版本上传到 VRoid Hub 的模型」。你手上这份 1.16.3 高于这个版本，新传的角色不受影响。

第二条和买衣服直接相关——有些服装单品本身就带「不允许下载」的条件，穿了它的模型整体就导不出来。挑单品时留意这道限制。

「别人做的模型不能下载」这条，实际是对方在 Hub 上把「他人使用」设成了不允许；对方也可以随时改。另外，对方的可见性设置还会影响你能不能在自己的列表里看到这个角色，两种限制的区别见 [角色上传后谁能看到怎么设.md](角色上传后谁能看到怎么设.md)。

## 三、反过来：Hub 上的角色在手机版里看不到

从 VRoid Hub 往手机版调角色时，有两类模型**不会出现**在列表里：

| 类型 | 说明 |
| --- | --- |
| 有年龄限制的模型 | 标记为 R-15 或 R-18 的角色 |
| VRM 1.0 格式的模型 | 手机版不读取这个版本的格式 |

也就是说，你在 Hub 上收藏了一个角色，回到手机版却找不到它——先按这两条对一下。这两条限制同时作用于「调回来拍照」和「在影棚里摆放」。

## 四、调回来的模型有两件事做不到

- **不能编辑。** 通过 Hub 调进手机版的角色，只能在影棚里用，改不了五官和衣服。要改必须回到做它的那台设备。
- **表情动作可能不正常。** 官方说明里写过：手机版的表情动画是**专门为手机版里做的模型**优化的，外部软件做的模型、以及一部分电脑版做的模型，表情可能调用不出来或者姿势僵硬。

第二点在拿别人的模型拍照时特别常见，不是你的操作问题。

## 五、模型本身的使用条件

官方帮助页把「用 pixiv 持有权利的预设做出来的模型数据」的使用条件列成了下面这张表：

| 用途 | 是否允许 |
| --- | --- |
| 作为头像使用 | 允许 |
| 暴力类表现 | 允许 |
| 性表现 | 允许 |
| 企业商业用途 | 允许 |
| 个人商业用途 | 允许 |
| 个人营利性活动（赠送活动等） | 允许 |
| 改编 | 允许（**付费单品与贴图除外**） |
| 再分发 | **不允许** |
| 署名 | 不需要 |

三条需要单独记住的：

- **再分发是明确不允许的**，改过的不行，原样转发也不行。模型数据与贴图都不行。
- **也不能把这类数据以「允许下载」的条件上传到 VRoid Hub**。如果设成只有自己能访问，那么上传到 VRoid Hub、或者 VRChat 这类虚拟社交平台是可以的。
- **付费单品不能改编**，这条和上一条是两回事，别混。

这套条件只覆盖 pixiv 持有权利的部分。如果你的模型里用了别人的作品、或者用了非 pixiv 持有权利的内容，那部分要按对应的条款处理，不在上表范围内。

## 六、换设备的时候

| 东西 | 怎么处理 |
| --- | --- |
| 角色模型数据 | 手机上**没有**直接搬到新设备的办法；先把角色传到 VRoid Hub，在新设备上登录同一账号调回来用（但不能编辑） |
| VRoid 币与已购买的付费单品 | 可以转移，跟着账号走 |
| 拍好的照片 | 在手机相册里，按你自己的备份习惯处理 |

所以换手机前的最优顺序是「先上传角色、再换设备」。反过来做——先把应用卸了——角色数据就一起没了，官方明确写过这一点。

---

角色能导出之后，它的用法就打开了：给直播软件当形象、或者放进 VRChat 这类平台里。如果这个过程中出现「角色不显示」「表情不动」这类情况，先看 [常见问题与排查.md](常见问题与排查.md)。
