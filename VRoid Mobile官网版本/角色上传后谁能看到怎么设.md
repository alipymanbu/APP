# VRoid Mobile 角色上传后谁能看到怎么设

> 本篇讲角色传上 VRoid Hub 之后还能改哪些设置：谁能看到、别人能不能用、要不要设年龄限制，以及 2026 年 5 月那次会自动改设置的更新。

在手机版里点上传时，你只做了一个选择（公开或私下）。角色到了 VRoid Hub 之后，还有很多项可以随时改——而这几项直接决定「别人搜不搜得到」「别人能不能拿去用」「导出 VRM 会不会受影响」。如果你上传后就没再管过，这一篇值得对一遍。

## 一、上传时选的那一项，决定的只是底色

手机版上传时只能二选一：

| 上传时选的 | 含义 |
| --- | --- |
| Save and publish（保存并公开） | 角色出现在 VRoid Hub 上，别人可以看到 |
| Save privately（私下保存） | 只有自己能看到、自己能用 |

这只是「底色」。更细的可见范围、能不能被别人使用，都要到 Hub 上去设。

## 二、Hub 上能设的东西

登录 VRoid Hub 后打开自己角色的设置，能动的项大致是这些：

| 设置项 | 作用 | 什么时候用得上 |
| --- | --- | --- |
| 可见性（公开范围） | 全体公开 / 非公开 / 仅关注者可见 | 不想被搜到，或只想给关注你的人看 |
| 显示方式 | 3D 预览（所有人）/ 3D 预览（仅登录用户）/ 静止画 | 不想让未登录的访客转着看模型 |
| 浏览限制 | 可标为 R-15 或 R-18 | 角色内容需要设年龄门槛 |
| 他人使用 | 允许或不允许别人使用你的模型 | 只想自己用就设成不允许 |
| 标签 | 供 Hub 上搜索用 | 想被别人搜到 |
| 动作 | 给角色选一个页面里的待机动作 | 让模型页看起来更完整 |
| 缩略图 / 全身图 | 模型页上显示的图片 | 上传时没拍好，之后补 |

表格里的「仅关注者可见」和「仅登录用户可见的 3D 预览」这两档是 2026 年 5 月 20 日那次更新加进来的，见下面第四节。

## 三、改设置走哪条路

路径是固定的：

1. 登录 VRoid Hub（`https://hub.vroid.com/`）；
2. 进「Your characters」；
3. 选要改的角色；
4. 进「Edit model data」→「Edit browsing settings」，在那一页改可见性与显示设置。

改完不用重新上传角色，手机版那边也不需要做任何同步动作。

## 四、2026 年 5 月那次更新改了什么

官方在 2026 年 5 月 20 日发过一则更新说明，这次更新**自动改了一部分模型的设置**。如果你在那之前传过角色，最好去确认一下：

| 变化 | 具体内容 |
| --- | --- |
| 新增「仅关注者可见」 | 设为这一档后，模型不出现在搜索结果里，对没关注你的人等同于私下，也不再出现在模型列表页 |
| 新增「仅登录用户可见的 3D 预览」 | 未登录的人打开模型页只能看到静止画，不能转动预览 |
| 自动变更 | 原本是「3D 预览（公开）」、且使用条件为「允许第三方使用（下载）：不允许」的模型，被统一改成了「3D 预览（仅登录用户可见）」 |

第三条是重点：**被自动改过的模型，任何人都可以手动改回公开，包括你自己**。所以碰到「我的模型怎么突然不能转了」这类情况，先去那个设置页看一眼。已经开启下载功能的模型、以及本来就是静止画显示的模型，不受这次变更影响。

## 五、手机上不能往 Hub 传 VRM 文件

这一条容易和「用手机版上传角色」混淆，分开看：

| 要传的东西 | 能不能用手机 |
| --- | --- |
| 手机版里捏的角色（应用内上传） | 可以，走应用里的上传入口 |
| 电脑上做好的 VRM 文件（从 Hub 网页上传） | **不行**，官方说明要改用电脑 |

## 六、Hub 本身是什么

VRoid Hub 是 pixiv 提供的 3D 角色托管平台，用 pixiv 账号就能免费用，界面支持日语和英语。角色传上去之后会生成一个独立页面，别人可以在上面看到、点赞、留言，作者允许的话还能下载模型数据。

它同时也是手机版和电脑版之间的中转站：手机版做的角色想给别的软件用，要经过它导出 VRM（见 [导出VRM与在别的软件里用.md](导出VRM与在别的软件里用.md)）。

---

Hub 的设置里，对手机版用户影响最直接的是两项：**可见性**（决定别人搜不搜得到你的角色）和**他人使用**（决定别人能不能把你的角色调进他的影棚拍照）。这两项设完，手机版这边不用再做任何操作。
