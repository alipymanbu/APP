# VRoid Mobile 怎么捏出自己的3D角色

> 本篇讲手机版里从零做出一个角色的流程：脸、发型、体形分别怎么调，以及做完之后怎么存到 VRoid Hub。

手机版做角色的方式不是「从空白模型开始捏」，而是**从一堆现成的部件里挑，再用滑块改成你想要的样子**。要动的地方归成四块：脸、发型、体形、服装。前两块决定像不像，第三块决定比例，第四块另见换装那一篇。全程不需要任何建模基础。

## 一、调整的基本套路

每一块的玩法都一样，记住这个循环就行：

1. 进对应分类，从列表里点一个部件（选脸型、选发型、选眼睛等）；
2. 看画面中间的角色实时变成你选的样子；
3. 用滑块微调——位置、角度、大小、颜色这类；
4. 不满意就回列表换一个，循环到顺眼为止。

改动是实时预览的，不用「生成」也不用保存中间态，直接在你看到的结果上继续调就行。

## 二、脸

脸部是部件最多的部分，按五官拆开各有各的列表：

| 可调的部分 | 怎么调 |
| --- | --- |
| 脸型 / 轮廓 | 选基础脸，再用滑块改轮廓细节 |
| 眼睛 | 选形状与颜色；位置（上下、左右）、宽度、高度、眼角角度可用滑块调 |
| 眉毛 | 选形状与颜色；角度、上下位置、间距可用滑块调 |
| 鼻子 | 用滑块调位置、大小 |
| 嘴巴 | 用滑块调位置、宽度 |
| 耳朵 | 用滑块调大小 |

要注意的是**滑块能调出的是比例和位置，不是「改笔画」**。想把眼睛换成完全不同的画风，靠的是回列表里换一个眼睛预设，而不是把滑块拉到底。手机版没有贴图绘制功能，画眼睛细节这件事在电脑版才有——两者区别见 [它和电脑版有什么区别.md](它和电脑版有什么区别.md)。

## 三、发型

发型分三层，可以分开选：

| 层 | 说明 |
| --- | --- |
| 整套发型 | 从预设里挑一个整体造型，颜色单独选 |
| 刘海（Bangs） | 单独换前面的头发 |
| 后发（Back） | 单独换后面的头发 |

「刘海」和「后发」能拆开选是 1.15.0 版加入的，同一个版本还加入了**肤色调整**。所以你可以在一个喜欢的整体发型上，只换掉前面的刘海，或者把后发换成另一种长度——不必为了改一个地方放弃整个造型。

## 四、体形

体形用滑块调，能动的包括身高、头的大小、四肢长度这类比例项。**男体和女体可调的项目不完全一样**，有些参数只在其中一边出现，选性别时就已经决定了后面能调什么。

体形改动的效果是整体性的：调身高会连带改变整个人物在画面里的取景大小，所以在拍摄前把它调准，比拍的时候再靠镜头凑更省事。

## 五、做完之后：把角色存到 VRoid Hub

**这一步别跳过。** 角色只存在手机本地时，能用的场景很有限；上传到 VRoid Hub 之后才能：

- 在同一个影棚里放多个自己的角色（互不相同的角色需要各自在 Hub 上有记录）；
- 在没有这个角色的设备上把它调回来；
- 下载成 VRM 文件给别的软件用。

上传入口在首页右下角的图标。点了之后会跳到浏览器，页面底部选**「保存并公开」或「私下保存」**：

| 选项 | 含义 |
| --- | --- |
| 保存并公开 | 角色出现在 VRoid Hub 上，别人可以看到、按条件使用 |
| 私下保存 | 只有自己能看、自己能用 |

上传完回到应用里刷新一下，角色就在列表里了。已经用它拍过多人合影的角色，实际上是**已经注册到 Hub 上了**，不用再走一遍上传。

## 六、两条会影响操作顺序的限制

- **从 VRoid Hub 调回来的角色不能在手机版里编辑。** 也就是说，改角色只能在「这台手机上自己做的那个」上改；一旦是通过 Hub 调回来的，就只能拿来拍照，要改就得回到当初做它的那台设备。
- **删掉应用 = 删掉里面所有角色数据。** 官方说明里明确写过：卸载应用会连模型数据一起清除，重装也找不回来。换手机或者清理空间之前，先把要留的角色传到 VRoid Hub。
