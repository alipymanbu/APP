VRoid Mobile 是 pixiv 在手机端做的一款 3D 角色应用：从现成的脸、头发、身体部件里挑着拼出一个人物，给他换衣服，再用 AR 相机或应用内的虚拟影棚拍照。它面向的是完全没接触过 3D 建模的人，不需要会画画，也不需要会用桌面建模软件。本篇把「装哪一个、装在什么设备上、第一次打开要准备什么」讲清楚。

## 一、先确认你要装的是哪一个

「VRoid」这个名字下挂着好几个东西，装错了会很费解，所以先对一遍：

| 名字 | 是什么 | 跑在哪 |
| --- | --- | --- |
| VRoid Mobile | 手机端的角色制作与拍照应用 | Android / iOS |
| VRoid Studio | 桌面端的 3D 角色制作软件 | Windows / macOS / iPad |
| VRoid Hub | 3D 角色托管平台 | 网页 |

本篇讲的是 **VRoid Mobile**，也就是手机上那个。它在 Android 上的包名是 `net.pixiv.vroid.android`——名字容易被别处写串，**认包名最稳**。两者的详细区别、以及能不能互相流转，见 [它和电脑版有什么区别.md](它和电脑版有什么区别.md)。

## 二、这份安装包的信息

| 项目 | 值 |
| --- | --- |
| 版本 | 1.16.3 |
| 应用包名 | `net.pixiv.vroid.android` |
| 安装包大小 | 98.32 MB |
| MD5 | `29774CA4813F96B6ED1FD704FB6F0582` |
| 开发者 | pixiv Inc. |

官方商店页的记录里，1.16.3 之后还出过 1.16.4（以商店页当时显示为准）。你手上这份是 1.16.3，两个版本的更新说明都写得很简短（类似「小幅改进」「修复」），官方没有公布功能差异。

下载完可以先核对 MD5：在电脑上用校验工具算一遍，和上表一致再传到手机。包体近 100 MB，传输过程出问题会表现为安装时的「解析包错误」，先核对再排查能省不少事。

## 三、系统要求

官方帮助页写的要求是：

| 平台 | 要求 |
| --- | --- |
| Android | 6.0 及以上，且支持 OpenGL ES 3.0 或更高 |
| iOS | 11 及以上 |
| AR 拍摄 | 设备需支持 ARCore（Android）或 ARKit（iOS） |

三点容易被忽略：

- **AR 拍摄是「有就有、没有就没有」**：设备不支持时，界面上不会出现 AR 入口，这不是设置里能打开的开关。
- 官方明确写了「满足系统版本也不保证能跑」：年代久远的机型、内存紧张的机型都可能出问题。
- 3D 渲染和拍照都比较吃性能，机身发热属于常见现象。

## 四、安装步骤

安装包从 [VRoid Mobile 安装文件资源（夸克网盘）](https://pan.quark.cn/s/9b8305f0f364) 取，Android 上装这份包走的是标准的侧载流程：

1. 把 APK 文件传到手机（数据线、网盘、聊天工具互传都行）；
2. 在文件管理器里点这个 APK；
3. 系统提示「不允许安装未知来源应用」时，进设置，把**你正在用来发起安装的那个应用**（通常是文件管理器）的「安装未知应用」权限打开——授权对象是发起安装的应用，不是系统全局开关；
4. 返回后继续安装，装完桌面上会出现图标。

第一次打开会比之后慢，属于正常现象。

安装过程中报「解析包错误」或「应用未安装」时，先回「二、这份安装包的信息」核对 MD5；文件没问题再检查手机剩余空间，预留 300 MB 以上比较稳妥。

## 五、第一次打开要准备的三件事

### 账号

**必须先有账号才能用。** 应用里的角色数据挂在 VRoid Hub 账号下，而这个账号就是 pixiv 账号，没有的话需要先注册一个。

登录环节有一个很具体的坑：如果提示「Failed to log in」之类的登录失败，**把系统默认浏览器换成 Chrome，再试一次**。这条解法来自官方帮助页——登录要跳转浏览器完成，部分浏览器处理不了这个跳转。系统与浏览器都更新到最新版也一并照做。

### 权限

| 权限 | 什么时候要 | 不给会怎样 |
| --- | --- | --- |
| 相机 | 用 AR 拍摄时 | AR 模式无法取景 |
| 照片 / 存储 | 保存拍好的照片时 | 点了保存，相册里却没有 |

iOS 上第一次保存照片，弹窗里**要选「允许访问所有照片」**。如果之前误选了「选择照片…」或「不允许」，得去「设置 → VRoid → 照片」改回「所有照片」，否则会出现「提示保存成功、相册里却没有」，或者每存一张就弹一次窗。

### 界面语言

官方商店页标注的对应语言是**日语和英语**，没有简体中文；界面语言跟随系统设置，中文系统下一般显示英文界面。

也就是说菜单名和按钮名都是英文或日文。后面几篇提到具体操作时给的都是界面上的英文叫法，方便你照着找。

---

装好之后的第一步永远是做角色——没有角色，换装和拍照的入口都是空的，这一步的操作见 [怎么捏出自己的3D角色.md](怎么捏出自己的3D角色.md)。如果卡在登录、权限或者报错上，[常见问题与排查.md](常见问题与排查.md) 按「症状 → 原因 → 处理」列了官方给出的解法。
