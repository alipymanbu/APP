# VRoid Mobile 拍照合影与AR相机怎么用

> 本篇讲手机版的两种拍摄方式、影棚里的多人玩法、相机模式的操作，以及拍出来的照片能用到什么程度。

拍角色是手机版的主要用法。它有两种拍摄模式：一种把角色放进现实场景（AR 相机），一种在应用自带的 3D 影棚里拍（虚拟相机）。两条路进去的方式不同，能玩的玩法也不同——想和朋友一起拍只能用虚拟影棚，想让角色站在自己家地板上只能用 AR。

## 一、AR 相机与虚拟相机的区别

| | AR 相机 | 虚拟相机（3D 影棚） |
| --- | --- | --- |
| 背景 | 手机摄像头拍到的真实场景 | 应用内提供的 3D 空间 |
| 多角色同框 | 不支持 | 支持，单人模式最多 10 个 |
| 和朋友一起 | 不支持 | 支持，最多 4 人同一个影棚 |
| 设备要求 | 需要 ARCore（Android）或 ARKit（iOS） | 无额外要求 |

## 二、虚拟影棚怎么进

角色做好之后，进影棚的路径是固定的：

1. 点屏幕**右下角的相机按钮**；
2. 出现拍摄点选择页，选一个你喜欢的影棚；
3. 选 **Shoot Alone**（一个人拍）或 **Shoot Together**（一起拍）；
4. 第一次进会弹教程，点「次へ（Next）」继续。

应用里的 3D 空间主要是这三个：

| 影棚 | 什么来头 |
| --- | --- |
| OZ | 电影《夏日大作战》里那个虚拟空间的重现版本 |
| Hanafuda Stage | 花札主题的舞台 |
| Penthouse | 顶层公寓场景 |

## 三、Shoot Alone：一屏放多个角色

这是「自己拍自己」的模式，能在同一个影棚里摆多个角色：

- **最多 10 个**你做的角色同时出现在画面里；
- 从**屏幕右上角的图标**打开角色列表，切到 VRoid Hub 标签页挑角色；
- 选中要摆的角色后，它会先出现在画面中央：**发蓝光表示位置有效，发红光表示位置无效**，滑动屏幕把位置挪到有效区，颜色会由红变蓝；
- 想换当前正在操作的角色，点画面里那个角色本人就行；也可以点**左上角显示的数字**；同一个入口还能删掉选中的角色；
- 第 3 个、第 4 个角色重复同样的步骤。

一个前提：**想用自己在手机版里做的角色，得先把它上传到 VRoid Hub**。之前一起合拍过的角色算已经注册过，不用再传。

AR 拍摄**不支持**这样的多角色摆放——摆多个角色只在 3D 影棚模式里有。

## 四、Shoot Together：和朋友进同一个影棚

选 Shoot Together 进影棚后，界面上会多出三样东西：

| 界面元素 | 作用 |
| --- | --- |
| 显示人数 | 当前这个影棚里有几个人 |
| 创建 / 分享邀请链接 | 生成链接发给别人，对方点进来就在同一个影棚 |
| 聊天 | 影棚内用文字聊 |

**同一个影棚最多 4 个人**。影棚内的角色可以互相看到，也可以用文字沟通。

一条容易踩的规则：**Shoot Together 模式下不能换角色**。官方给的处理方式是——离开影棚，回到角色制作页选好要用的角色，再重新进来。所以在约人合拍之前，先把想用的角色切好。

## 五、相机模式里能调什么

在影棚里进入相机模式后：

- **改变视角**：在屏幕任意处上下左右滑动，或**用两根手指滑动**，改变朝向与方向；
- **横屏也能用**，横过来照样拍。

界面上的按钮按功能分成这几类：

| 按钮 | 作用 |
| --- | --- |
| 退出 | 离开相机模式 |
| 拍摄尺寸 / 滤镜 | 选画幅和滤镜，点开后有多个可选 |
| 移动 | 让角色上下左右移动、转向；腾空后用于调整升降 |
| 表情姿势 | 让角色摆姿势、做动作 |
| 拍摄按钮 | 按下拍照 |
| 跳跃 | 站在地面时跳起，腾空时继续上升 |

点开这一项可以选拍摄尺寸和多种滤镜。官方早期的发布说明里给到的数字是一键滤镜 17 种、可调参数 11 项（含明暗、对比度、景深、颗粒等）；具体以你当前版本界面上的选项为准。

按钮里的「表情姿势」是让角色做预设好的动作，**不是**把你的表情映射到角色身上。想让角色跟着你的脸一起转头、做表情，那是 VRoid Hub 网页上的**面部追踪**功能，要用电脑浏览器打开 Hub、用电脑摄像头来驱动；官方在 2025 年 2 月 27 日的功能说明里明确写了**手机端不支持**这一功能。所以在手机版里找「表情跟随」是找不到的。

## 六、想拍视频：得用系统录屏

**应用本身没有录像功能。** 官方给的替代办法是录屏：

| 平台 | 怎么做 |
| --- | --- |
| iOS | 先到「设置 → 控制中心 → 自定控制」里加上「屏幕录制」，之后从控制中心点录制按钮开始录 |
| Android | 用任意一款录屏应用录屏幕 |

这也意味着录下来的画面会带上应用界面上的按钮，介意的话拍摄前先把界面收起来（或录完自己裁）。

## 七、AR 入口不见了

AR 入口**只对支持的设备显示**，不支持的设备上这个图标根本不出现——不是设置里能打开的开关，也不是版本问题。判断依据是设备有没有 ARCore（Android）或 ARKit（iOS）。官方还提醒：即使某台设备在支持列表里，如果机型很老，也可能用不了 AR 拍摄。

排查步骤见 [常见问题与排查.md](常见问题与排查.md)。

## 八、照片能不能商用

官方对这件事的口径是**先看照片里有什么**：

- **AR 拍摄要特别留意**。照片里如果拍进了第三方的商标、logo 之类的东西，你拿去做商业用途可能侵犯第三方的权利。用之前自己核一遍画面内容。
- **影棚场景有额外限制**。OZ、Hanafuda Stage、Penthouse 这些 3D 空间主要是给人拍照片、在里面交流用的：把角色在这些场景里的视频发出去是可以的，但**不能把照片或视频印成周边卖给别人**，也不要把角色做成付费内容提供出去。

模型本身的使用条件（能不能商用、能不能改、能不能再分发）是另一套规则，见 [导出VRM与在别的软件里用.md](导出VRM与在别的软件里用.md)。
