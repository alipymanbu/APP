# VRoid Mobile 换装与服装怎么获取

> 本篇讲手机版里的服装体系：衣服分几类、怎么一键换上、免费与付费怎么区分、付费单品的限制，以及换手机时衣服会不会丢。

手机版给角色穿的衣服在应用里叫 **Avatar Wear**，是官方为 3D 角色单独准备的一批服装单品。它的用法和现实里换衣服很像：按部位分件，点一下穿上去，点另一件就替换掉。衣服不是「买断一套造型」，而是**一件一件攒**。

## 一、衣服怎么分类

按穿着部位分件，主要几类是：

| 分类 | 对应什么 |
| --- | --- |
| 上衣（Tops） | 衬衫、外套这类上身单品 |
| 下装（Bottoms） | 裤子、裙子 |
| 连衣裙（Dress） | 上下连成一件的款式 |
| 袜子（Socks） | 长短袜 |
| 鞋（Shoes） | 各类鞋 |

分类的意义在于：你可以在已选的整体搭配上，只换掉其中一件。比如保留连衣裙，只把鞋换掉；或者保留上衣，换下装。

## 二、怎么把衣服换上去

在角色制作页找到服装分类，流程是「分类 → 单品 → 点一下」：

1. 进对应分类，列表里是这个分类下的所有单品；
2. 点你想穿的那一件，角色身上立刻换成它；
3. 想脱掉就走同一路径再选一次，或者换别的单品顶替。

换装是**一键生效**的，没有「试穿 → 确认」这一步。这也意味着点错了不要紧，再点回来就行。

## 三、免费单品与付费单品

列表里同时混着免费和付费的单品，**靠价格区分，不靠位置**：

| 情况 | 界面表现 | 你要做什么 |
| --- | --- | --- |
| 免费单品（0 币） | 按钮是 **Collect** | 点一下直接收下 |
| 付费单品 | 按钮是 **Purchase**，显示所需币数 | 先有足够的 VRoid 币才能买 |

官方在 1.14.4 版的更新说明里专门写过这个改动：价格为 0 币的单品，按钮从「Purchase」改成了「Collect」。所以看到 Collect，说明这件不用花钱。

VRoid 币是**应用内购买**的形式获得的，也就是要花钱充值。手机版的付费主要就花在买衣服上——不买付费单品，做角色、换装、拍照这些功能都不受影响。

## 四、付费单品有两条硬限制

这是在花钱之前就该知道的两条：

- **付费单品不能改动。** 官方的模型授权条款里，可改编一栏写的是「允许（付费单品与贴图除外）」——也就是免费单品你可以改，付费单品不能。
- **不能再分发。** 授权条款里再分发一栏是「不允许」，这条对免费和付费单品都适用，改过的也不行。也就是说，衣服和贴图不能转给别人，也不能上传到 VRoid Hub 时把下载权限开成允许。

另外，官方还写明：如果模型里含有**不允许下载的单品**，这个模型就整体不能从 VRoid Hub 下载成 VRM 文件。买衣服时留意一下单品的下载限制，会直接影响你后面能不能把角色导出到别的软件里用（见 [导出VRM与在别的软件里用.md](导出VRM与在别的软件里用.md)）。

## 五、换手机、重装应用时衣服会不会丢

分开看两样东西：

| 东西 | 会不会跟着走 |
| --- | --- |
| VRoid 币和已购买的付费单品 | **会**——官方说明里明确写了币和付费单品可以转移到新设备 |
| 角色模型数据（你捏的那个角色本身） | **不会**——官方说目前没有把模型数据直接从旧设备搬去新设备的办法 |

所以换机时的顺序建议是：**先在旧手机上把要留的角色上传到 VRoid Hub**（步骤见 [怎么捏出自己的3D角色.md](怎么捏出自己的3D角色.md)），再在新手机上登录同一个账号把它们调回来。这样衣服和币会自动跟账号走，角色也还在，只是调回来的角色不能再编辑。

同样道理，**卸载应用会连角色数据一起删掉**，重装也恢复不了；币和付费单品不受影响。清理手机空间之前留意这点。

## 六、别把手机版的衣服和电脑版的搞混

电脑版 VRoid Studio 的换装走的是另一套体系，服装是 **XWear 格式的文件**，从 BOOTH 之类的渠道获取、在电脑上导入。手机版用的是应用内的 Avatar Wear 列表。

两套服装不是同一批资源，名字也长得不一样。如果你看到「下载 XWear 给角色换上」的教程却找不到对应入口，那说的是电脑版——两者的功能对照见 [它和电脑版有什么区别.md](它和电脑版有什么区别.md)。
