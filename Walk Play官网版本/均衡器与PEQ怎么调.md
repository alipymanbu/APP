均衡器是 Walk Play 的主功能：它改的不是手机播放器的音效，而是耳机/小尾巴里那颗音频芯片的参数，所以改完换哪个 App 放歌都生效。这篇按「先看懂参数 → 用预设起步 → 单段微调 → 收尾压电平」的顺序走，最后交代滤波器。

## 一、E、Q、Gain 分别是三个什么数

PEQ 页面上每个频段一般有三栏，含义固定：

| 参数 | 管什么 | 调大往哪边走 |
| --- | --- | --- |
| **E**（频率 / Frequency） | 你打算动的是哪一段声音，比如 100 Hz 是低频，3 kHz 是人声 | 数值越大，动的越是偏高音的部分 |
| **Gain**（增益） | 这一段要抬高还是压低，单位是 dB | 正数是抬高、负数是压低；一次改动别超过几个 dB |
| **Q**（品质因数） | 这条改动「铺」得多宽 | Q 越大，影响的频带越窄、越像只动一个点；Q 越小，影响的范围越宽 |

三者是一组：**先决定动哪一段（E），再决定抬还是压、多少（Gain），最后决定这一刀切得宽还是窄（Q）**。新手最常犯的错是只盯 Gain，把一大段频率一起抬起来，结果是低音糊、人声闷。

## 二、从预设起步，不要从零调

官方提供了按音乐风格做好的预设，界面上能看到「摇滚」「人声」「流行」这一类名字。正确用法是：

1. 先选一个**方向最接近你口味**的预设，听一段熟悉的歌；
2. 整体方向对了，再在此基础上做小改动；
3. 整体方向就不对，换个预设再来，而不是硬把当前这个调回来。

从零开始拖动滑块，很容易越调越糊，因为你没有参照物。

## 三、一次只改一段，改完听半分钟

一条来自调音实践的规则：**一次只改一个频段，听 30~60 秒，再决定下一步**。人耳对声音有适应期，短时间内堆叠好几个改动，等你回头听已经分不清是哪一刀起的作用了。

按「你听到的问题」去找要动的频段，比记频点更实用：

| 你听到的问题 | 先试哪里 | 怎么动 |
| --- | --- | --- |
| 声音太亮、齿音刺耳 | 6~9 kHz 一带 | 小幅往下压，别一次压狠 |
| 人声发闷、像被盖住 | 1~3 kHz 一带 | 小幅抬高 |
| 低音没有量感、发干 | 60~120 Hz 一带 | 小幅抬高 |
| 低音嗡嗡的、发浑 | 150~250 Hz 一带 | 小幅往下压 |
| 整体听久了累 | 高频段 + 略微压一点低频 | 先做减法，再做加法 |

每个应用到的频段、能动的频段数量，取决于你设备的芯片，页面上实际给出几段就调几段。

## 四、抬了好几个频段，就要把总电平压下来

同时抬高多个频段时，信号叠起来会超过程度上限，听感是破音、失真。处理办法很简单：

- 页面上如果有 **Preamp / 输出电平** 这一类总控，在做提升之前先把它**往下压一点**；
- 压多少，按你抬的总量估：抬了三段各 2 dB，就先压 3~5 dB 起步，再听。
- 一旦听出破音，**先降总电平、再减各段的提升量**，不要反过来。

声音失真的其他原因（源文件、音量、连接）见[常见问题与排查.md](常见问题与排查.md)。

## 五、数字滤波器怎么选

一部分小尾巴的芯片会提供几种数字滤波器模式，界面里能看到类似下面这些缩写。它们改的是瞬态和边缘的处理方式，属于「最后撒的一点调味」，**建议在均衡器调好之后再动**。不同设备提供的模式不一样，以你页面上实际显示为准：

| 模式 | 听感倾向 | 大致适合 |
| --- | --- | --- |
| FAST-LL（快速 / 低延迟） | 瞬态干净、感觉更直接 | 打游戏、听节奏强的曲子 |
| FAST-PC（快速 / 相位补偿） | 快，但声像位置会略有变化 | 想保留力度、又在意定位 |
| SLOW-LL（慢速 / 低延迟） | 高频柔和、边缘不刺 | 久听、容易累的耳机 |
| SLOW-PC（慢速 / 相位补偿） | 更松弛、偏监听感 | 长时间听、听人声 |
| NOS（非过采样） | 更暖、更软 | 老录音、偏暖的耳机 |

用法上有两条经验：

- **一次只挑一个模式，先用一天**。边调 EQ 边换滤波器，等于两个变量同时动，永远调不稳。
- 换滤波器不会改善「频响不平衡」这种问题，那是均衡器的活；滤波器改的是质感。

## 六、调好了别忘保存

这里有个容易漏的地方：**在页面上改完参数并不等于已经生效**。Walk Play 的保存分「写进设备」和「存到云端」两回事，分别什么时候用、怎么找回，见[方案保存与云端同步.md](方案保存与云端同步.md)。
