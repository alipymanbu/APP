# Shazam 识别歌曲的几种方式

## 一、最常见的一种：打开应用，按那个大按钮

识别这件事本身只有一个动作，难点在于"当时手上是什么状态"——所以在讲各种入口之前，先把最常规的那一种说清楚：打开 Shazam，屏幕中间就是一个大按钮，把手机对着声音按下去，界面进入聆听状态，几秒后出结果。

操作上只有两个要点：

1. **手机靠近音源**。音箱、电视、别人手机的外放口都行。隔得太远，或者被周围的说话声压住，成功率会明显下降。
2. **按下去之后让它听完**。中途再按一下是中止当前这次识别，切走或锁屏也可能让这一次白听。

识别到的歌会自动进音乐库，不用你手动保存。找历史记录的做法见 [识别历史与账号同步.md](识别历史与账号同步.md)。

## 二、不用先打开应用就能按的三个入口

识别经常发生在"你正拿着手机干别的"的时候，所以下面这三个入口值得先配好。

**长按桌面上的 Shazam 图标**：弹出的菜单里有"Shazam Now"（立即识别），点它直接开始听，跳过进应用这一步。这是配置成本最低的一个入口，什么都不用设，装完就有。

**快速设置面板里的 Shazam 开关**：加到系统下拉的快捷开关里之后，从任何界面下拉就能按。两种加进去的办法：

- 进 Shazam，点应用界面底部的"将 Shazam 添加到您的快速设置中"，跟着屏幕指引走完；
- 或者从屏幕右上角下拉出快速设置，点铅笔（编辑）图标，在"可用按钮"里找到 Shazam（或"Shazam 自动识别"），拖到面板上，再点完成。

**桌面小组件**：长按主屏幕空白处 → 小组件 → 在列表里滚到或搜到 Shazam → 挑一个尺寸 → 添加，然后把它摆到顺手的位置。加好之后在主屏幕上按一下就能识别，省掉"打开应用"这一步。

需要注意：**小组件和快速设置的具体操作步骤，不同安卓设备、不同安卓版本并不一样**。上面写的是通用走法，找不到对应选项时，看一下系统自己的帮助说明。

## 三、手表上识别

戴 Wear OS 智能手表时，也可以在手表上直接识别曲目，不用掏手机。适合的场景很具体：在店里、车里听到一段旋律，手机在包里或者口袋里，抬手按一下就够了（前提是手表上装了 Shazam 对应的组件）。

识别结果会回到手机端的音乐库里，和用手机识别出来的记录放在一起。

## 四、在电脑网页里识别

在电脑浏览器里装上 Shazam 的浏览器扩展之后，可以识别**当前这个网页正在播放的**声音。注意它认的是网页流出来的音频，不是你周围环境里的声音——在电脑上看剧、听播客时想查一段配乐，用它比"对着音箱按手机"方便得多。

这是另一套使用场景，和手机端装不装、装哪一版没有关系。想确认扩展的安装入口和当前支持情况，看 [www.shazam.com](https://www.shazam.com) 上的说明即可。

## 五、该用哪一个：场景对照表

| 你当时的情况 | 用哪个入口 |
| --- | --- |
| 专门坐下来听一首不认识的歌 | 打开应用，按主按钮 |
| 手上正拿着手机刷别的 | 长按桌面图标选"Shazam Now"，或下拉快速设置按一下 |
| 不想每次都打开应用 | 桌面小组件 |
| 听到的是手机自己放出来的声音（哪怕插着耳机） | 弹出式 Shazam 或自动识别，见 [自动识别与浮窗通知设置.md](自动识别与浮窗通知设置.md) |
| 一集剧、一场演出里有好几首歌要认 | 自动识别（连续模式），见 [自动识别与浮窗通知设置.md](自动识别与浮窗通知设置.md) |
| 在电脑上看网页视频 | 浏览器扩展 |
| 手机在包里，只有手表在手上 | 手表上识别 |

这张表里没有出现的"认不出来"这一类情况，不在本篇范围，按 [识别不出来怎么排查.md](识别不出来怎么排查.md) 处理。

## 六、入口配好了，还剩两件事要确认

**第一件是麦克风权限。** 上面所有入口都建立在同一个前提上：应用能收到声音。权限被关掉之后，按哪个入口都没反应，而且界面未必会提示你原因。检查位置在"设置 → 应用 → Shazam → 权限 → 麦克风"。

**第二件是"听到的是谁的声音"。** 手机麦克风听的是**环境音**——音箱、电视、别人手机外放。手机自己放出来的声音（短视频、直播、播客、音乐 App，含耳机场景）走不到麦克风里，得换成弹出式或自动识别。这是两套不同的取音方式，不分优劣，只看场合。
