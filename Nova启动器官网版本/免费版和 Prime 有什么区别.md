# Nova启动器 免费版和 Prime 有什么区别

> 本篇对照免费版与 Nova Prime 的功能边界、购买方式与购买后换机怎么处理，帮你判断哪些功能确实用得上。

装完 Nova启动器 就能用，但设置里总有一些选项点进去用不了——那属于 Nova Prime。网盘里这份是主程序，装上就相当于免费版；Prime 是走官方渠道购买后启用的一组进阶功能。本篇只做功能对照与渠道说明，怎么买、多少钱以官方页面当时显示的为准。

## 一、两边的关系先搞清楚

- **主程序是基础**：桌面、抽屉、图标、搜索、备份这些核心能力都在主程序里，不买任何东西也能正常用。
- **Prime 是一组权限**：官方在应用商店里把它做成了一个单独的购买项（有的渠道是一个只负责开通的配套应用）。买了之后要能生效，主程序必须还在手机上，两个都在才有效果。
- **同一台手机上装了两份来源不同的主程序会打架**：包名一样但签名不同，会出现「应用未安装」。想换回官方渠道的包，先备份，再卸载重装。

## 二、功能对照表

| 功能 | 免费版 | Prime |
| --- | --- | --- |
| 桌面与抽屉的网格、边距、图标大小 | 有 | 有 |
| 图标包、图标形状、标签颜色 | 有 | 有 |
| 文件夹的创建与外观 | 有 | 有 |
| 备份与恢复 | 有 | 有 |
| 搜索（含算式、单位换算等即时结果） | 有 | 有 |
| 桌面手势（滑动、捏合、双击） | 无 | 有 |
| 图标与文件夹上的滑动动作 | 无 | 有 |
| 通知角标（数字、动态、小圆点） | 无 | 有 |
| 抽屉分组（标签页与文件夹） | 无 | 有 |
| 隐藏应用 | 无 | 有 |
| 更多滚动效果 | 部分 | 全部 |

这张表的用法很直接：**先看第二列里有哪几项是你真的会天天用的**。多数人的高频项其实只有一个——要么是手势，要么是角标，要么是隐藏应用。只为其中一项付费值不值，由你自己判断。

两个容易误会的地方：

- **「免费版有广告」是误会**。官方明确说过，任何版本的 Nova 都不带广告；如果你在桌面上看到广告，来源是别的应用，不是桌面本身。
- **用不了 ≠ 装错了**。设置里某项灰着或点进去提示需要购买，属于权限边界，不是安装包有问题。

## 三、购买渠道与形态

- **渠道**：官方渠道是应用商店内购。**没有 Google Play 服务**的设备买不了，这一点要在动手前先确认，别在桌面上折腾半天再去解决支付条件。
- **形态**：官方给出的口径是提供两种——**按年订阅**和**一次性买断**。价格和具体档位会调整，以官方页面当时显示的为准；同一个功能在不同时期可能只有其中一种可选。
- **配套应用**：官方 FAQ 里说明，若设备没有 Google Play 服务，可以联系官方支持申请由官方发放的直接授权，前提仍是先在官方商店完成购买。这条路径要走官方支持渠道，别从别处找。

## 四、买完之后：换机、退款与转账户

- **换机**：一次性购买是绑定在购买账号上的，换到新手机后用同一个账号登录，可以重新装上，功能不用再买一次。
- **退款**：官方 FAQ 给出的口径是需要提供购买凭证，且购买时间在 30 天以内的可以申请；超过这个时间官方不受理。通过应用商店购买的话，商店本身也有退款窗口，先看商店的规则更快。
- **转到另一个账号**：可以转，但官方要求购买满一年、并提供原始购买凭证与目标账号邮箱，走官方支持处理。一年内不给转，这是硬规定，不用反复问。
- **重新安装后没生效**：先在配套应用或商店的购买记录里点一次「恢复购买」，再重启一次桌面。确认账号是当初购买的那一个。

## 五、不买的话，日常会缺什么

按使用场景而不是按功能列表来看更清楚：

| 你的用法 | 不买会缺什么 | 有没有替代办法 |
| --- | --- | --- |
| 只想把桌面排整齐、换个图标包 | 基本不缺 | 免费部分够用 |
| 想在图标上显示未读数 | 缺角标 | 用系统自带的角标设置，效果随系统而定 |
| 想靠手势少点几次 | 缺手势 | 依赖系统自带的手势与快捷方式 |
| 应用太多、抽屉太乱 | 缺抽屉分组与隐藏应用 | 手动建桌面文件夹顶着用 |
| 想双击锁屏 | 缺手势 | 用手机电源键，或找系统自带的锁屏快捷方式 |

决定要买之前，建议先把免费部分调到自己满意，确认这套桌面确实会长期用下去，再考虑付费项——配置本身随时可以备份带走，见 [备份与换机恢复.md](备份与换机恢复.md)。
