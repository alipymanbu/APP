# Nova启动器 常见问题与排查

> 本篇集中处理换桌面后最常撞到的几类毛病：默认桌面被抢回去、返回桌面动画卡顿、图标与文件夹不见了、桌面变卡或闪退。

换第三方桌面之后遇到的问题，大致分三类：权限被系统收回、系统对第三方桌面支持不好、桌面进程被系统清掉。真正属于应用本身故障的很少。本篇按「症状 → 先查什么 → 怎么处理」整理成可照着走的清单，每一步都能单独验证。

## 一、按 Home 键回到的是系统桌面

说明默认桌面没设住，或者被系统改回去了。按顺序做：

1. 到系统设置的搜索框里搜「默认」，打开「主屏幕应用」，确认选的是 Nova启动器；
2. 回桌面按一次 Home 键验证。如果又变回去，检查系统里是否有「省电模式」「智能省电」这类开关把它一并改了；
3. **系统大版本升级后需要重设一次**，这很常见——升级会把默认应用重置为系统自带桌面；
4. 有些机型在「设置 → 应用 → 默认应用」之外，还有一处「桌面」的独立开关，两处都要指向 Nova。

装完之后的完整设置步骤见 [下载与安装教程.md](下载与安装教程.md)。

## 二、返回桌面的动画卡一顿，图标慢半拍

这是第三方桌面最典型的抱怨，**根子不在 Nova**：从屏幕底部上滑返回桌面这段动画，做在系统自带桌面里，用第三方桌面时系统要把画面「交接」过去，中间那一小段就是看起来的卡顿。

能做的几件事：

| 做法 | 位置 | 说明 |
| --- | --- | --- |
| 把桌面动画速度改回默认档 | Nova 设置里样式或动画相关的分类下 | 调成极快的档位时，和系统动画节奏对不上，反而更显得掉帧 |
| 屏幕刷新率设为「高」 | 系统 → 显示 → 屏幕刷新率 | 设为「智能 / 标准」时分场景降帧，动画更容易被看出掉帧 |
| 解除桌面的省电限制 | 系统 → 应用 → Nova启动器 → 电池 | 被系统降频后动画会明显发涩 |
| 减少实时内容 | 桌面本身 | 多个实时小组件加动态壁纸，是动画掉帧的常见来源 |

**系统手势动画与第三方桌面配合不好，是系统层面的限制**，官方也把这一点说成「不取决于桌面，取决于系统与设备厂商」。所以换了几个桌面都一样卡时，别再折腾桌面设置，把上面三项调完即可。

## 三、桌面上的图标或文件夹不见了

| 现象 | 先查这里 | 处理 |
| --- | --- | --- |
| 单个应用图标不见了 | 应用是否被隐藏 | 到抽屉设置的隐藏列表里放开，详见 [应用抽屉与 Nova Now 怎么用.md](应用抽屉与 Nova Now 怎么用.md) |
| 整个文件夹不见了 | 是否把文件夹里的最后一个图标拖走了 | 文件夹里只剩一个图标时会自动解散，重新拖一个图标叠上去即可 |
| 一整页桌面不见了 | 桌面页是否被删或被合并 | 到主屏设置里看页数与页面顺序 |
| 恢复备份后大量图标空白 | 新机上缺应用或图标包 | 先装回应用，再在样式里重新选中图标包 |
| 图标位置自己变乱了 | 系统更新或桌面进程重载 | 从备份恢复一次布局，见 [备份与换机恢复.md](备份与换机恢复.md) |

## 四、桌面变卡、应用列表加载慢

按这个顺序排，前三项解决八成情况：

1. **省电与后台**：系统 → 应用 → Nova启动器 → 电池设为「无限制」，并允许自启动；在最近任务里给桌面加锁，防止一键清理扫掉它。桌面被杀掉再拉起时，抽屉与图标要重新加载，那几秒的等待就是这么来的。
2. **存储空间**：可用空间低于一成时，系统整体读写变慢，桌面加载图标最先受影响。
3. **实时内容体积**：逐个移除动态壁纸与实时小组件测一次，能立刻定位到是哪一个拖的。
4. **重启一次**：先重启桌面进程（设置里或强制停止后重新进桌面），不行再重启手机。
5. **检查是不是别的东西在抢资源**：后台常驻的清理类、加速类应用会和系统自身的进程管理打架，这是新旧手机都常见的一类干扰。

## 五、桌面停止运行 / 反复闪退

- **系统刚更新完就闪退**：先重启手机，再进桌面看是否恢复；仍不行就清一次桌面的缓存（系统 → 应用 → Nova启动器 → 存储 → 清除缓存，注意别点「清除数据」，那会删掉配置）。
- **装完某个小组件之后开始闪退**：把那个小组件先移除。小组件损坏会连带桌面一起崩，这是排查里最容易漏的一条。
- **清缓存无效**：从备份恢复一次配置；再无效就备份好之后卸载重装。
- **重装前必须做的事**：导出备份。卸载会一并删掉桌面布局、手势与配色，没有备份就只能从头再配一遍。

## 六、系统更新后每个屏幕都出现一个 Nova 的悬浮图标

这是新系统把无障碍快捷方式摆到了屏幕上，不是 Nova 出了问题。处理办法：到系统「无障碍」设置里找到 Nova，**只关掉它的快捷方式开关，不要关掉整项服务**——把服务关掉的话，锁屏手势一类的功能会一起失效，官方专门提示过这一点。

## 七、这两件事别指望桌面解决

- **最近任务（多任务界面）异常**：不显示内容、滑动不顺、不能长按固定应用，这些都属于系统自带桌面的能力范围，第三方桌面在系统接口上拿不到这块，换哪个桌面都一样，只能等系统更新或找设备厂商。
- **屏幕底部导航方式**：三大金刚键还是全面屏手势，由系统设置决定，桌面改不了。

## 八、排查到最后还是不行

1. **先备份**，保证无论怎么折腾都能退回现在这个状态；
2. 到 Nova 设置里的「联系支持」入口提一次反馈——从这个入口提交会带上设备与版本信息，比在外面发帖有效；
3. 想重装就按 [下载与安装教程.md](下载与安装教程.md) 的卸载与重装一节走，装的是网盘里那份包时，注意核对版本与 MD5；
4. **不要用来源不明的包去替换**。包名相同但签名不同的两个包互相装不上，混装只会把配置搞丢。
