Nova启动器（官方英文名 Nova Launcher，包名 `com.teslacoilsw.launcher`）是一个替换手机自带桌面的启动器。它的安装只是第一步——不把它设成「默认桌面」，按返回主屏键还是会回到系统自带桌面。本篇按「核对安装包 → 安装 → 设为默认桌面」三步讲，适合第一次换第三方桌面的安卓手机与平板用户。

## 一、先核对网盘里这份包

网上搜到的通常是官方当前最新版，和网盘里这份往往不是同一个版本号。本篇出现的版本、包名、体积一律以下表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | Nova启动器（官方英文名 Nova Launcher） |
| 版本号 | 889008.8.9 |
| 包名 | `com.teslacoilsw.launcher` |
| 安装包体积 | 35.40 MB |
| MD5 | `31854ae74b1b71e1e93f87b368da1010` |
| 核对时间 | 2026-09-23 |

安装包本体在 [Nova启动器 安装文件资源（夸克网盘）](https://pan.quark.cn/s/28f1d9bf463e) 里，转存到自己的网盘再下载到手机。

几点要分清：

- **官方渠道在哪**：官网是 [novalauncher.com](https://novalauncher.com/)，常见问题页是 [novalauncher.com/faq](https://novalauncher.com/faq)。想确认自己手上这份是不是同一款，看包名 `com.teslacoilsw.launcher` 最快——名字里带 Nova 的桌面应用不止一个，包名不会重名。
- **版本会对不上**：官方发布流现在已经走到 8.9 一档，网盘里这份是更早的那一代；两边的设置项名称与菜单位置会有出入，新功能也只出现在更新的版本里。具体哪天是哪一版，以官方发布页当时显示的为准。
- **MD5 怎么用**：下载完用文件管理器看文件详情，或用任意校验工具算一次 MD5，与上表一致说明传输没损坏；体积明显小于 35.40 MB 就是没下完，直接重下。
- **系统要求**：官方应用页标注的最低系统是 Android 8.0 / 8.1 及以上（不同渠道的写法略有差异，以官方页面当时显示的为准）。比这更老的系统只能用历史版本，装了新版也起不来。

## 二、装之前先确认两件事

1. **原来用的是什么桌面**。如果你手机上原本就是 Nova（旧版），先在旧版里做一次备份再动手，否则覆盖安装出问题就只能从头重排桌面，步骤见 [备份与换机恢复.md](备份与换机恢复.md)。
2. **桌面上的小组件要有心理准备**。换桌面后，原来摆在系统桌面上的小组件需要重新往 Nova 的桌面上放一遍；部分厂商自带的小组件（比如天气、日历的定制款）在第三方桌面上可能显示不出来。这属于系统限制，不是安装出错。

## 三、安装步骤

1. 把安装包下载到手机。在电脑上下载的话，用数据线或任意传输工具拷进手机存储都可以。
2. **允许安装未知来源应用**：在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给用来打开安装包的那个应用（文件管理器或浏览器）打开开关。国产定制系统常把这一项收在「安全」「隐私」「更多安全设置」下面，路径不一就搜「未知应用」。
3. **点开 APK 完成安装**：系统提示「应用未经过安全检测」时选继续安装，这是第三方渠道安装包的常规提示。
4. 安装完成先别急着按 Home 键——按下去只会回到系统桌面，下一步要把默认桌面改过来。

安装被拦下时，不同提示对应的情况不一样，按这张表对：

| 系统提示 | 原因 | 处理 |
| --- | --- | --- |
| 解析包错误 / 解析包时出现问题 | 下载不完整或文件损坏 | 重新下载，下完核对体积是不是 35.40 MB、MD5 是否与上表一致 |
| 应用未安装 | 手机上已装了同包名但签名不同的版本（例如别的渠道拿的包） | 先在旧 Nova 里备份，再卸载旧版重装 |
| 已阻止安装 / 安全提示 | 未知来源开关没打开 | 回到第 2 步，给打开安装包的那个应用开权限 |
| 提示与系统不兼容 | 系统版本低于这份包的最低要求 | 换一份适配自己系统的旧版本，或放弃安装 |

## 四、设为默认桌面

装完第一次打开 Nova，会先走一段引导（选择从零开始、沿用当前桌面布局，或者恢复一份备份），引导里也会顺带问你要不要把 Nova 设成默认桌面。如果当时点掉了，用下面任意一条路补上：

- **按下 Home 键触发选择框**：系统会弹出「使用以下方式完成操作」，选 Nova启动器，再点「始终」。这是最省事的一条路。
- **在系统设置里改**：打开系统设置，在最上面的搜索框里搜「默认」，找到「主屏幕应用」（有的系统叫「桌面」「Home 应用」），切到 Nova启动器。各家定制系统的层级不一样，用搜索框比一层层翻快得多。
- **在 Nova 里改**：打开 Nova 设置，顶部如果有一条提示「尚未设为默认」的横幅，点它就能直接跳到系统那个选择框。

改完按一次 Home 键验证：能回到你刚配好的 Nova 桌面，而不是原来的桌面，才算成功。

## 五、装完顺手做的三件事

- **确认无障碍服务只关快捷方式、不关服务**：Nova 用到无障碍服务来实现部分锁屏与角标功能。有些系统更新后会在每个屏幕上挂一个 Nova 的悬浮图标，处理办法是到系统「无障碍」里关掉 Nova 那一项的**快捷方式**开关，别把整项服务关掉，否则锁屏手势之类的功能会一起失效。
- **做一次备份**：桌面还没怎么调，也建议先备份一遍，后面的调整就有了退路，见 [备份与换机恢复.md](备份与换机恢复.md)。
- **看一眼角标权限**：想让桌面图标显示未读数量，需要额外授予「通知使用权」，没授的话角标不会出现，判断顺序见 [通知角标不显示怎么办.md](通知角标不显示怎么办.md)。

## 六、卸载与重新安装

- **卸载**：在「设置 → 应用」里找到 Nova启动器点卸载。卸载会一并删掉桌面布局、图标设置与手势配置，**动手前先导出一次备份**。
- **重装**：包名相同、签名相同就能直接覆盖安装，不需要先卸载，覆盖安装不会清掉已有设置。如果提示「应用未安装」，说明两份包不是同一把密钥签的，这时只能先备份、再卸载、后安装。
- **卸载后回不去系统桌面**：如果卸载前把默认桌面设成了 Nova，卸载后系统会自动切回自带桌面，不需要额外处理。
