Nova启动器 最常被用到的就是桌面布局这一块：一屏能放几个图标、图标多大、图标下面的文字什么颜色、托盘放几页，这些都能改。本篇按「进设置 → 改网格 → 改图标 → 改托盘与文件夹 → 改滚动与壁纸」的顺序讲，对着网盘里那份 889008.8.9 的界面走一遍大约十分钟。

## 一、先把设置入口认一遍

进 Nova 设置的两条路：

- **长按桌面空白处** → 弹出菜单 → 点「设置」；
- **从应用抽屉里**打开「Nova 设置」这个独立图标（装完 Nova 后它会一并出现在抽屉里）。

设置页的入口按主题平铺排列，常用的是这几处：主屏、应用抽屉、文件夹、托盘（Dock）、样式，手势与备份各占一处。**不同版本的名称与位置会略有差异**，下面提到的路径按「大类 → 具体项」的层级找，别死记位置。

## 二、主屏网格：决定一屏放几个图标

路径：Nova 设置 → 主屏 → 网格。

| 项目 | 作用 | 调法上的注意点 |
| --- | --- | --- |
| 行数 / 列数 | 一屏横向、纵向各放几个格子 | 列数调大，图标变小、间距变窄；6×5 以上在小屏手机上会显得拥挤 |
| 图标大小 | 图标在本屏的显示尺寸 | 它和网格是两个独立参数：网格决定「格子多大」，它决定「图标占格子多大」 |
| 宽度 / 高度边距 | 网格四周留白 | 想让桌面显得更满就减小边距，但要注意别让图标顶到屏幕边缘，手势导航机型会不好按 |
| 标签显示 | 图标下面那行文字 | 在这里可以整体关掉标签，或单独调颜色与字号 |

**图标位置对不齐，用 Subgrid（子网格定位）**：Nova 允许把图标或小组件停在两个格子之间的位置，也就是「半格」。摆放时按住图标不要马上松手，拖动到目标位置附近会吸附到半格上。这项能力是它和其他桌面差别最大的地方——想让几个图标严格居中、或者给小组件留出一条缝，靠它比反复微调网格省事。

**小组件叠着放**：如果摆小组件时总被其他元素挤开，在 Nova 设置 → 主屏 → 高级里打开「放置时允许重叠」，摆好之后再手动把层级排一下即可。

## 三、图标下面的文字（标签）

路径：Nova 设置 → 样式 → 主屏 → 文本。同一个入口下另有一处「应用抽屉 → 文本」，管的是抽屉里的标签，两处要分别调。

- **看不见标签了**：多半是主屏的「标签」开关被关掉，或标签颜色被调成了与壁纸近似的色。回这两个地方确认。
- **文字压住图标**：调小标签字号，或者把「标签行数」限制为 1 行、超出部分省略。壁纸颜色花的时候，可以给标签加一层文字阴影，比换颜色更有效。
- **只改一个应用的图标或名字**：长按桌面上那个图标 → 编辑 → 在里面单独换图标、改名称。这只影响这一个图标，不动全局设置。

## 四、托盘（Dock）：页数、背景与搜索栏

路径：Nova 设置 → 托盘。

- **多页托盘**：把托盘页数调到 2 页以上，托盘就能左右滑动。常用的做法是第 1 页放通讯类应用、第 2 页放工具类，切换时不用回桌面翻页。
- **托盘里放小组件**：托盘不只是放图标，也可以放 1×1 的小组件（比如一个迷你播放器控件），摆放方式和在桌面上放小组件一样。
- **托盘背景**：可以关掉背景做全透明，也可以留一条半透明的底边。加了背景之后，桌面滚动时托盘边界更清楚。
- **搜索栏位置**：搜索栏可以放在桌面上、也可以塞进托盘里（托盘图标的上方或下方），不想用就整体隐藏。

## 五、文件夹：外观与展开方式

- **新建**：把一个图标拖到另一个图标上松手，就形成一个文件夹；也可以把抽屉里的文件夹直接拖到桌面上。拖不动就去 Nova 设置 → 主屏 → 高级里检查「放置时允许重叠」的状态。
- **外观**：文件夹的背景样式、预览样式（网格预览还是小图标预览）都在 Nova 设置 → 文件夹里改。文件夹图标本身也能替换成任意一个应用图标，让它在桌面上看起来像一个普通应用。
- **放进文件夹里的应用不见了**：先确认它是不是被隐藏了——隐藏的应用在文件夹里同样不显示，判定方法见 [应用抽屉与 Nova Now 怎么用.md](应用抽屉与 Nova Now 怎么用.md)。

## 六、滚动效果与壁纸

路径：Nova 设置 → 主屏 → 滚动。

- **循环滚动**：打开后从最后一屏再往后翻会回到第一屏，桌面页多的时候省一次回翻。
- **滚动效果**：桌面切页与抽屉翻页各有一套效果可选，其中一部分只在购买过 Prime 之后可选，见 [免费版和 Prime 有什么区别.md](免费版和 Prime 有什么区别.md)。
- **壁纸要不要跟着滚**：关掉壁纸滚动，页面切换时壁纸是静止的，视觉上更稳；开着更有纵深。同一张壁纸想同时用于桌面和锁屏，需要系统在 Android 7.0 以上才支持分别设置。
- 想在某屏左边挂一个信息流页面（比如系统自带的资讯页），需要额外装官方提供的同伴应用，并且**必须在 Nova 设置 → 主屏 → 滚动里关掉无限滚动**，两者会冲突。

## 七、改乱了的回退办法

- **回到改动前**：用 Nova 设置里的备份与恢复，把之前导出的那份布局还原回来，具体步骤见 [备份与换机恢复.md](备份与换机恢复.md)。养成「大改之前先备份一次」的习惯，比事后重排省事得多。
- **只想还原某一处**：桌面布局的改动是分类保存的，网格、图标、托盘的设置互不影响，改坏了哪一类就只把那一类调回去，不必整份恢复。
- **恢复后图标变空白**：说明当时用的应用或图标包已经不在手机上了，把缺的应用补装回来，图标会自动接上，详见 [常见问题与排查.md](常见问题与排查.md)。
