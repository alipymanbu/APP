# Nova启动器 应用抽屉与 Nova Now 怎么用

应用抽屉是装完 Nova 之后每天都要用的地方：手机上所有应用都列在这里，桌面上只放常用的那几个。本篇讲抽屉怎么打开、怎么排、怎么把不想看的应用藏掉，以及 8.x 版本里主屏左侧那个 Nova Now 页面能拿来做什么。未特别说明的路径都以 Nova 设置里的分类为准，名称随版本略有差异。

## 一、抽屉怎么打开，抽屉按钮丢了怎么找回来

抽屉的默认打开方式是从桌面**向上滑**。如果滑不出来，或者你想在桌面上放一个抽屉按钮，两条路都行：

1. **加一个抽屉图标**：长按桌面空白处 → 进入小组件列表 → 找到 Nova 的操作（Nova Actions）→ 选「应用抽屉」，就会往桌面上放一个抽屉入口，再把它拖进托盘即可。
2. **改成点图标打开**：Nova 设置 → 应用抽屉 → 打开应用抽屉 → 选「图标」，托盘上会出现抽屉按钮。

顺带一个高频问题：**上滑打开了搜索而不是抽屉**。这两件事由同一个上滑动作触发，取决于你在 Nova 设置 → 手势与输入里把上滑分给了谁。两者的分工与改法见 [手势和快捷操作怎么设置.md](手势和快捷操作怎么设置.md)。

## 二、抽屉怎么排、怎么滚

路径：Nova 设置 → 应用抽屉。

| 项目 | 可选值 | 什么时候选它 |
| --- | --- | --- |
| 滚动方式 | 垂直连续滚动 / 水平分页 | 应用多、按字母找，选垂直；想保持和桌面一致的翻页手感，选水平 |
| 样式 | 常规网格 / 卡片式 / 列表式等 | 深色壁纸下卡片式层次更清楚；列表式一屏能看到更多名字 |
| 图标大小与标签 | 独立于桌面的一套参数 | 只影响抽屉，不会连带改桌面 |
| 搜索栏 | 显示 / 隐藏、放在顶部或底部 | 单手操作时放底部更好按 |

**抽屉里的顺序不用调，也调不了**：应用与文件夹在抽屉里按名称字母排序，Nova 没有提供手动排序的开关。想让常用的排前面，做法是分组（第四节）或直接放到桌面上，而不是改排序。

## 三、隐藏应用：藏起来，但不是卸载

路径：Nova 设置 → 应用抽屉 → 隐藏应用。也可以直接在抽屉里**长按某个应用图标，点那个眼睛形状的按钮**，一步藏掉。

这里有个容易被误解的地方，先看清楚再动手：

- 隐藏的应用**只是从抽屉里消失**，它仍然在手机上、仍然会出现在主屏（如果你摆在桌面上）和搜索结果里。
- 所以它是**整理工具，不是隐私工具**。想彻底不让别人看到某个应用，第三方桌面做不到这件事，需要用系统自带的应用锁或隐私空间。

想放回来，回同一个入口把勾去掉即可。这一项同样属于购买 Prime 之后才能用的功能，没买过的话在抽屉设置里看不到隐藏应用这个入口。

## 四、抽屉分组：给抽屉加标签页或文件夹

路径：Nova 设置 → 应用抽屉 → 抽屉组。可以新建标签页，也可以在标签里建文件夹给应用归类。

- 适合的场景：应用装到上百个以后，把「社交」「工具」「游戏」分成三页，比在一个长列表里滑到底快得多。
- 这一项属于进阶功能，没购买过 Prime 时打不开，判断方法见 [免费版和 Prime 有什么区别.md](免费版和 Prime 有什么区别.md)。
- 分好组之后可以和手势配合：给上滑手势分一个「打开抽屉的某个标签页」，一次到位。

## 五、智能文件夹：让 Nova 自己分类

路径：Nova 设置 → 应用抽屉 → 智能文件夹。打开后，Nova 会按应用类型自动归类出几个可浏览的分类（比如通讯、影音、工具），把它们放进抽屉的文件夹或标签页里。

它的定位是**降低整理成本**，不是替代你手动分组：

- 自动分类的判断依据是应用自身的类别信息，个别应用会归到你不认可的那一类，需要手动拖到正确位置；
- 分类结果不是把所有应用都塞进去，因此抽屉里仍会有一批应用留在外面，这是预期行为；
- 如果你已经有自己的分组习惯，可以不开这一项，两者并不冲突。

## 六、搜索：比翻抽屉快

在抽屉顶部（或底部，看你把搜索栏放哪了）点一下搜索框，就能按应用名找应用。搜索相关几点：

- **不只是搜应用**：输入算式、单位换算一类的内容，结果会直接显示在搜索框下方（官方把它叫 Micro Results），点一下就能复制或跳转。
- **搜索历史**：搜索框里的历史记录可以关掉。介意留痕的话，去搜索设置里关掉历史记录开关。
- **搜不到某个应用**：先到系统「设置 → 应用」里确认它没有被停用——被停用的应用在任何桌面下都调不出来；如果你手工隐藏过它，抽屉里看不到，但搜索结果里仍然会出现，别把这两件事弄混。

## 七、Nova Now：主屏左边的那个页面

把主屏往左划到底，会看到 Nova Now 这一页。它分成上下两块：

- **上面**是搜索与应用推荐，推荐依据是你近期和长期的使用频率，用得越久越准；
- **下面**是卡片区，卡片按最近使用排序，可以在卡片上长按把里面的快捷方式固定住，也可以把不看的卡片关掉。

卡片本身是可以自定义的：

| 你想要的 | 做法 |
| --- | --- |
| 固定一张常看的卡片 | 在 Nova Now 里长按卡片，用菜单里的固定选项 |
| 只让某张卡片在特定场景出现 | 给卡片加条件，例如连上某个蓝牙耳机时才把运动相关的那组卡片抬上来 |
| 关掉不看的卡片 | 卡片自带的关闭入口，关掉后不再出现在这一页 |
| 天气、日历这类信息 | 卡片区里有对应的卡片可以直接用 |

两个实际会遇到的情况先说清楚：**8.x 的卡片功能还在迭代**，你手上这份包里的卡片种类和按钮位置可能和下个版本不一样，以实际界面为准；另外，Nova Now 占的是主屏左侧那个位置，原本挂在那里的系统资讯页需要多划一次才能进去，想把这个位置让回去，到主屏相关设置里找 Nova Now 的开关（以你当前版本的界面为准）。
