# Nova启动器 通知角标不显示怎么办

> 本篇讲桌面图标上的未读角标为什么不出现：先区分角标类型，再逐项检查通知使用权与系统开关。

换了 Nova启动器 之后，很多人第一反应是「怎么图标上面不显示未读数了」。角标不出现几乎都是权限或类型选择的问题，很少是应用坏了。本篇按「先选类型 → 再给权限 → 再看系统层限制」的顺序排查，多数情况在前两步就能解决。

## 一、先确认角标类型

路径：Nova 设置 → 通知角标。这一页决定角标长什么样，可选的大致是三类：

| 类型 | 长什么样 | 适合谁 |
| --- | --- | --- |
| 数字角标 | 图标角上显示未读条数 | 要一眼看出「有几条没看」 |
| 动态角标 | 角标样式随通知变化，可自定义 | 想和整套桌面配色统一 |
| 小圆点 | 只显示一个点，不带数字 | 只要知道「有新的」，不需要具体条数 |

两个先决条件：

- **一次只能用一种**。官方明确说过，不同应用分别用不同角标类型这件事做不到，所以你选了数字角标，所有应用就都是数字角标。
- **这一块属于购买 Prime 之后才能改的进阶设置**。如果 Nova 设置里根本找不到「通知角标」入口，先看 [免费版和 Prime 有什么区别.md](免费版和 Prime 有什么区别.md)，不是应用装坏了。

## 二、再给「通知使用权」

角标的原理是读取系统通知，所以必须拿到通知使用权，这是最常见的漏项：

1. 打开 Nova 设置 → 通知角标，如果页面底部或顶部有一条权限提示，点它；
2. 系统会跳到「通知使用权 / 通知访问」列表，找到 Nova 那一项，把开关打开；
3. 有的系统会弹一次确认框，提示「该应用将能读取所有通知」，点允许。

授权之后**先发一条消息给自己测试**（比如给自己发条短信、或者用另一台设备发条微信），桌面图标上应该立刻出现角标。不测试就判断，容易把「本来就没有未读」当成故障。

## 三、系统层还有三道闸

Android 自己也会管角标，Nova 授了权、系统没放行一样不显示。按下面这张表逐项对（路径名各家不同，用系统设置里的搜索框搜关键词最快）：

| 检查点 | 位置（各家叫法） | 要设成什么 |
| --- | --- | --- |
| 应用通知开关 | 设置 → 通知 → 找到具体应用 | 「允许通知」打开，否则没有角标可读 |
| 桌面角标总开关 | 设置 → 通知 → 角标 / 通知圆点 | 打开；关掉的话所有桌面都不显示角标，与用哪个桌面无关 |
| 省电限制 | 设置 → 应用 → Nova启动器 → 电池 | 设为「无限制 / 不优化」，被系统清掉后角标会停更 |
| 专注模式 / 勿扰 | 设置 → 声音与振动 → 勿扰 | 部分机型在勿扰状态下会一并压掉角标 |
| 自启动 | 设置 → 应用 → 自启动 / 后台启动 | 允许，保证桌面进程能收到通知变化 |

## 四、只有个别应用不显示角标

如果只是某几个应用没角标，问题通常不在 Nova：

- 到 Nova 设置 → 通知角标 → 逐应用列表里，确认那个应用没有被单独关掉；
- 到系统「设置 → 通知」里看那个应用的通知开关与分类开关，有些应用会把「消息提醒」之外的通知类型关得很干净，结果只有点没有数字；
- 少数应用自己不发标准通知（例如只在自己内部显示红点），任何第三方桌面都读不到它的未读数，这属于应用侧的限制。

## 五、角标不更新的几种表现与对应的原因

| 表现 | 常见原因 | 处理 |
| --- | --- | --- |
| 刚装完一直没有 | 通知使用权没授 | 回到第二节重新授权 |
| 数字一直停在旧值，清掉通知也不消 | 桌面进程被杀，通知监听断了 | 解除省电限制后重启手机 |
| 昨天有今天没有 | 系统更新后权限被回收 | 重新检查通知使用权与系统角标开关 |
| 锁屏一会儿回来角标就没了 | 后台被系统清理 | 允许自启动 + 锁定后台任务，见 [常见问题与排查.md](常见问题与排查.md) |
| 只在抽屉里有、桌面上没有 | 桌面那个图标是快捷方式或小组件 | 把应用图标重新拖一份到桌面 |

排查时**每改一项就发一条测试通知验证一次**，比一次性改五处、最后不知道是哪一项生效要省事得多。
