# Nova启动器 后台被杀怎么办

> 本篇讲桌面进程被系统清理后出现的「每次回桌面都要等一会儿」：怎么判断是被清理了，以及各家系统要开哪几个开关。

桌面被系统清掉之后的表现很好认：切到别的应用待一会儿再按 Home 键，桌面先是白屏或旧壁纸，然后图标一个个蹦出来，抽屉要重新加载。这不是 Nova 崩了，是它被系统的省电机制从后台清掉了，重新进桌面要重建一遍。本篇给一套判断方法，再把主流定制系统要动的开关列清楚。

## 一、先确认是不是后台被杀

1. 打开几个其他应用，让桌面离开前台一两分钟；
2. 按 Home 键回桌面，同时盯着图标出现的时间；
3. **正常情况**：桌面立刻就在，图标不需要重新出现；
4. **被清理了**：会先看到空白或纯壁纸，然后图标陆续刷出，抽屉第一次打开也要顿一下。

抽屉每次打开都重新加载、角标停更、桌面时不时回到默认样式，也都是同一个原因的外在表现。

## 二、每一家都要做的三件事

各家系统的菜单名字不一样，但要做的事就这三件，先都做掉：

1. **电池设为不限制**：系统 → 应用 → 找到 Nova启动器 → 电池 / 耗电管理 → 选「无限制」「不优化」或「允许后台活动」；
2. **允许自启动**：在手机管家 / 安全中心 / 安全与隐私里找到「自启动管理」，把 Nova启动器 打开；
3. **在最近任务里锁定**：进入最近任务界面，把 Nova 的那张卡片下拉或长按，出现锁形标志；被锁定的应用不会被「一键清理」扫掉。

## 三、各家系统的具体位置

下面是实测常用的路径，同一品牌的不同系统版本会有出入，找不到就用系统设置里的搜索框搜关键词。

| 系统 | 自启动 | 电池 / 后台 | 最近任务锁定 |
| --- | --- | --- | --- |
| 小米（MIUI / 澎湃 OS） | 手机管家 → 应用管理 → 权限 → 自启动管理；新版本在 设置 → 应用 → Nova启动器 → 应用权限 → 后台自启动 | 设置 → 应用 → Nova启动器 → 电池 → 选「无限制」 | 最近任务里把卡片下拉到出现锁形标志 |
| 华为 / 荣耀 | 手机管家 → 启动管理 → 找到 Nova启动器 → 改为「手动管理」，把自启动、关联启动、后台活动三项都勾上 | 设置 → 电池 → 应用启动管理 / 电池优化 → 把 Nova启动器 设为「不允许优化」 | 最近任务里下拉卡片，出现锁形标志 |
| OPPO / 一加（ColorOS） | 手机管家 → 权限隐私 → 自启动管理 | 设置 → 电池 → 耗电保护 → 找到 Nova启动器 → 关掉「后台冻结」与「检测到异常时自动优化」 | 最近任务里下拉或长按卡片锁定 |
| vivo（OriginOS / Funtouch） | i管家 → 应用管理 → 自启动管理 | i管家 → 电池管理 → 后台高耗电 → 允许 Nova启动器 | 最近任务里下拉卡片锁定 |
| 三星（One UI） | 智能管理器 → 自动运行应用程序 → 打开 Nova启动器 | 智能管理器 → 电池 → 未监视的应用程序 → 把 Nova启动器 加进去 | 最近任务 → 右上角更多 → 锁定应用程序 |

## 四、两个最容易被忽略的坑

- **「如果应用未使用则暂停应用活动」**：新版安卓在一些系统上默认开启。它会在应用一段时间不用之后**自动撤销已经授予的权限**。对桌面来说，这会让通知使用权（角标要用）在某天突然失效，表现就是「昨天还有角标，今天全没了」。位置大致在 系统 → 应用 → Nova启动器 → 权限 或应用信息页的底部的「暂停应用活动」开关，关掉它。
- **开发者选项里的「后台进程限制」**：如果你或某个工具曾把后台进程上限调成了「最多 1 个 / 2 个」，桌面会被优先牺牲。把它改回「标准限制」。

另外，装过清理类、加速类应用的话，先把它们卸载或关掉自动清理，它们和系统的进程管理会互相打架，这类问题在新旧手机上都很常见。

## 五、做完之后怎么验证

1. 在最近任务里点一次「一键清理」，然后按 Home 键：**桌面应当立刻出现**，图标不需要重新加载；
2. 发一条消息，看图标角标是否立刻出现（角标一并验证了通知监听没被清掉，相关设置见 [通知角标不显示怎么办.md](通知角标不显示怎么办.md)）；
3. 放一晚上第二天再按 Home 键回桌面，看是否还是秒回。夜间休眠是最容易复现的场景，过了这一关才算真的稳。

依旧会被清理时，按 [常见问题与排查.md](常见问题与排查.md) 里的顺序往下排查，重点看是否装了两个互相冲突的清理工具。
