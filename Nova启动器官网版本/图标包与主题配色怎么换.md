# Nova启动器 图标包与主题配色怎么换

> 本篇讲外观这一层怎么改：套图标包、统一图标形状、用壁纸取色或自选配色、在深浅色主题间切换，以及改完不生效时怎么处理。

图标包和配色是换桌面最直观的收益：装一个图标包，整桌图标一次统一；打开壁纸取色，文件夹、托盘、抽屉的底色会跟着壁纸走。本篇按「图标 → 形状 → 配色 → 深浅色」四层讲，最后给一份改完不生效的对照表。路径都以 Nova 设置 → 样式（外观）里的分类为准，名称随版本略有差异。

## 一、套图标包：主流做法

1. **先装图标包**。图标包本身是独立应用，从应用商店里搜「icon pack」或具体名字装好；
2. **再让 Nova 用它**：Nova 设置 → 样式 → 图标主题 → 在列表里选中刚装的那个图标包；
3. 选中后桌面图标会立刻替换，不需要重启。**如果没变化**，看第六节的对照表。

几点实际经验：

- **多数图标包覆盖不到全部应用**。新装的应用、国内应用、小众应用时常缺失，缺的那些会退回原始图标，看起来像「有的换了有的没换」，这是正常现象，不是图标包坏了。
- **换图标包前记一下当前用的是哪个**。图标包的风格差异很大，想换回去时如果忘了原来那个的名字，得一个个试。
- **图标包和桌面主题是两回事**。图标包换的是图标，桌面本身的配色、文件夹样式不受它影响，需要另外调。

## 二、只想换掉一个图标

不想整套换的时候，针对单个图标改更省事：

- 长按桌面上的图标 → 编辑 → 换图标 → 从图标包里挑一个，或者直接选自己相册里的图片；
- 这个改动只对当前这个图标生效，全局的图标包设置不受影响；
- 想撤销，回同一个入口换成「系统默认」或重新选回原图标即可。

## 三、让整套图标看起来统一

不装图标包也能统一观感，靠的是这几项：

| 项目 | 效果 | 适合的场景 |
| --- | --- | --- |
| 图标形状 | 把所有图标裁成同一种外形（圆形、方形、圆角等） | 图标风格杂乱、又没有合适的图标包 |
| 图标大小 | 统一缩放，不改图标本身 | 换了大屏手机后图标显得偏小 |
| 标签颜色与大小 | 统一桌面与抽屉的文字样式 | 壁纸颜色花，文字看不清 |

形状和大小这两项在样式设置里，桌面和抽屉各有一套，改桌面那套不会连带改抽屉。

## 四、配色：跟着壁纸走，还是自己定

Nova 的配色有两种来源，效果差别明显：

- **跟随系统取色（Material You 一类）**：颜色从壁纸里提取，换壁纸后整套界面的色调会跟着变，风格最统一，也不用自己配色；
- **自己选强调色**：在颜色选择器里指定一个色值，整套界面固定用它，换个壁纸也不变，适合有明确配色偏好的人。

配色影响的元素包括：文件夹背景、托盘背景、抽屉背景、页面指示器、标签文字颜色等。**小组件也能单独指定颜色**：长按桌面上支持取色的小组件 → 选自定义颜色 → 取消「由 Nova 管理」这一项之后，就能从预置颜色里挑一个，或者进高级模式自己调。这样即使壁纸换了，那个小组件的颜色仍然保持你定的那一个。

一个顺序上的建议：**先定壁纸，再调配色**。反过来做的话，换壁纸时整套配色的观感会变，前面调的等于白调。

## 五、深浅色主题

路径：Nova 设置 → 深色主题（有的版本叫夜间模式）。

| 模式 | 行为 | 什么时候用 |
| --- | --- | --- |
| 跟随系统 | 系统进深色，桌面跟着进 | 大多数人的选择，和系统其他应用保持一致 |
| 按日出日落 | 到点自动切换 | 不想手动切、又不想完全跟着系统 |
| 常开 / 常关 | 固定一种 | 常开适合夜间长期使用；常关适合喜欢亮色界面 |

深色主题影响的是桌面与抽屉的底色、文件夹背景、菜单这些界面元素，**不会改变图标包本身**——浅色图标包配上深色界面显得突兀的话，还是得换一个适配深色的图标包。

## 六、改完不生效的对照表

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 换了图标包但桌面没变 | 图标包应用没真正装上，或 Nova 里选中没保存 | 先确认图标包应用在抽屉里能看到，再回图标主题处重选一次 |
| 部分图标还是原样 | 图标包里没有覆盖到这些应用 | 给这几个图标单独手改（第二节），或换一个收录更全的图标包 |
| 图标变糊、边缘有锯齿 | 图标包给的是低分辨率图，或图标包本身适配的是旧安卓版本 | 换图标包；不要靠放大图标尺寸解决，只会更糊 |
| 换壁纸后配色没跟着变 | 取色结果没有重新应用 | 回配色设置里重新触发一次取色，或重新选一次壁纸 |
| 改完过一阵自己变回去了 | 桌面进程被杀后重新加载，图标包要重新挂上 | 按 [后台被杀怎么办.md](后台被杀怎么办.md) 解除省电限制并允许自启动 |
| 桌面正常、抽屉没变化 | 样式里桌面与抽屉是两套设置 | 到抽屉那一套里再改一次 |

改到满意之后**导出一次备份**：图标包名字、配色、形状这些都会一并存进去，换机时不用重新凭记忆配一遍，见 [备份与换机恢复.md](备份与换机恢复.md)。
