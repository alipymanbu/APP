桌面这东西调好了很值钱：网格、图标、手势、配色一层层叠起来，重来一遍就是半小时。Nova启动器 自带备份与恢复，把配置导出成一个文件，换手机或者调坏了都能退回上一个状态。本篇讲清楚备份里到底存了什么、怎么存才不丢、恢复时哪几步必须补做。

## 一、备份在哪里做

路径：Nova 设置 → 备份与导入（有的版本叫「备份与恢复」），里面有「备份」和「恢复」两个入口。做备份时可以选存到哪：

| 存法 | 适合的情况 |
| --- | --- |
| 存到 Nova 的默认目录 | 随手备一份，本机用 |
| 手动选一个位置 | 想自己归档，比如按日期分文件夹 |
| 直接分享出去 | 传到云盘、聊天工具或邮箱，这一步才是真正防丢的关键 |

**只存在手机内部存储的备份，风险最大**：手机丢了、换机了、恢复出厂了，备份跟着一起没。建议每次做完都顺手分享一份到自己的云盘。

关于备份文件本身，有三件事值得先知道：

- **长什么样**：导出的备份文件以 `.novabackup` 结尾（多个来源一致，实际以你导出后在文件管理器里看到的文件名为准）。它本质是一个压缩包，只有 Nova 自己读得懂，别用手改里面的内容，改了大概率恢复失败。
- **存在哪**：选「存到默认目录」时，文件落在手机存储里 Nova 自己的目录下；换机时如果只拷了照片视频，这个文件很容易被漏掉。这也是更推荐「分享到云盘」的原因。
- **多存几份不冲突**：不同的配置可以各存一份（比如一套极简桌面、一套信息量大的桌面），恢复时按文件选，不是只能留一份。

## 二、备份里存了什么，没存什么

| 内容 | 会不会进备份 |
| --- | --- |
| 桌面布局：图标位置、文件夹、桌面页与网格 | 会 |
| 外观：图标包选择、图标形状与大小、配色、深浅色主题 | 会 |
| 交互：手势绑定、托盘的页数与背景、抽屉设置 | 会 |
| 应用本身 | 不会 |
| 图标包、小组件这些第三方应用 | 不会（只记了名字，应用不在就显示不出来） |
| 壁纸文件 | 不会 |
| 小组件里的数据（比如待办事项目） | 不会 |

把这张表记牢，恢复后的预期就不会错：**备份搬的是「怎么摆」，不是「摆的是什么」**。

## 三、换机怎么搬

1. **在新手机上先装好 Nova启动器**。安装包在 [Nova启动器 安装文件资源（夸克网盘）](https://pan.quark.cn/s/28f1d9bf463e) 里，装完后按 [下载与安装教程.md](下载与安装教程.md) 把它设为默认桌面。
2. **把备份文件弄到新手机上**。原来存在云盘里的，直接在新机上下载即可；只存在旧手机里的，用传输工具拷过去。
3. **在新机的 Nova 里执行恢复**：Nova 设置 → 备份与导入 → 恢复 → 选中那个备份文件。
4. **补装缺的应用与图标包**。旧机上装过的图标包、被布局引用到的应用，新机上没有的话，那一处会留空。装回来之后图标通常会自动接上，不用逐个重设。
5. **重新摆一遍小组件**。小组件不随备份走，这一步省不掉。
6. **检查兜底项**：桌面是否已设为默认、通知使用权是否重新授予（角标需要）、手势有没有因为系统差异失效。前两项的做法分别在 [下载与安装教程.md](下载与安装教程.md) 与 [通知角标不显示怎么办.md](通知角标不显示怎么办.md)。

## 四、版本之间有一条硬边界

**Nova 7 的备份和 Nova 8 的备份不要混用**。官方给的说法很直接：Nova 7 的备份只在 Nova 7 上用，Nova 8 的备份只在 Nova 8 上用，两个版本之间改动较大，混用容易把配置搞乱。

所以从旧版升上来之前，先在旧版里导出一份备份留底（万一要退回去）；升级之后再导出一份新版备份。你手上这份包是 8.x 一档，旧版本导出的备份不要直接往上恢复。

## 五、从别的桌面搬家

Nova 支持从多数主流桌面导入布局，包括手机自带的那个桌面。做法是在 Nova 的设置里找导入相关的入口，选中要导入的桌面来源即可。

用之前先把两件事说清楚：

- **前提是应用还在**：导入的是布局与位置，旧桌面上用到的应用必须还装在手机上，否则导入后同样是空位；
- **导入是单向的**：导入完成后改动的是 Nova 自己的布局，不会反过来影响系统桌面。所以想留退路，就在导入前先把 Nova 当前的布局备份一次。

## 六、恢复之后不对劲怎么办

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 图标位置对了，但图标是空白的 | 对应应用或图标包没装 | 补装应用后刷新一次桌面；图标包在样式里重新选中一次 |
| 桌面多出几个空位 | 备份里有该应用，新机上没有 | 装回该应用，或者直接删掉空位 |
| 恢复完比原来还乱 | 备份本身就是在半成品状态下做的 | 换一份更早的备份来恢复；做备份前尽量先把桌面调到位 |
| 恢复入口点了没反应 | 备份文件不在手机当前能访问的位置 | 把文件放到手机存储里再用恢复功能选它 |
| 恢复后手势、角标都不对了 | 新机系统与旧机不同，权限与手势边界要重设 | 按 [手势和快捷操作怎么设置.md](手势和快捷操作怎么设置.md) 与 [通知角标不显示怎么办.md](通知角标不显示怎么办.md) 各过一遍 |

**最要紧的一条**：只有导出过备份，卸载重装才是一条退路。没备份就卸载，等于把调好的桌面直接丢掉。
