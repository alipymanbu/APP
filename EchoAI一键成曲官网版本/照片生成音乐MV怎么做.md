## 一、这一步做的是什么

给一首已经生成的歌配上画面：你上传若干张照片，应用按歌曲节奏切换画面、让字幕对齐唱词，最后合成一段能直接分享的 MV。它的定位是「把现成的照片用起来」，不是剪片子——想精细调度每一帧，手机端的这类工具都做不到，那该用桌面剪辑软件。

MV 建立在一首已经成型的歌上，所以顺序是先有歌再配画面：还没生成歌就先看 [一句话写歌怎么做.md](一句话写歌怎么做.md)。

## 二、照片怎么挑

这一步决定成片上限，比后面调参重要得多：

| 要素 | 建议 | 原因 |
| --- | --- | --- |
| 张数 | 十几张到几十张之间 | 太少画面重复得明显，太多单张停留不足一秒、看不清 |
| 清晰度 | 用手机原图，别用聊天工具压过的 | 压缩过的图在成片里会更糊 |
| 主体 | 有人物的照片优先 | 空景照片容易被卡切成不成形的局部 |
| 光线 | 同一组照片的光线尽量接近 | 明暗来回跳，成片会显得乱 |
| 画面方向 | 统一方向（都竖或都横） | 混着传进去，切换时会碰到留黑边或裁切 |
| 内容 | 避开证件、工牌、门牌号这类信息 | 一旦分享出去就收不回来 |

挑图时按「这首歌的情绪线」排一遍顺序，比随机丢进去效果好：开头放场景照，副歌段落放人物特写。

## 三、生成与预览

1. 在作品里找到那首歌，进 MV 相关入口；
2. 按提示选中照片，确认顺序；
3. 提交生成，等它合成完。合成要处理画面与音频对齐，耗时随照片张数与负载变化，**以应用内进度提示为准**；
4. 先完整看一遍再决定要不要存。

## 四、画面与字幕不对怎么调

| 现象 | 通常的成因 | 怎么处理 |
| --- | --- | --- |
| 照片切换和鼓点对不上 | 用的是慢歌，节奏点本身稀疏 | 回 [大师模式怎么调细节.md](大师模式怎么调细节.md) 把 BPM 提一点再重新生成歌 |
| 某张照片被裁掉了脸 | 该图主体偏在画面边缘 | 换一张，或把这张挪到不重要的段落 |
| 字幕和唱词差半拍 | 唱词本身有拖音或换气 | 改歌词断句后重新生成；这属于常见的对齐误差，不一定是操作问题 |
| 画面来回闪 | 同类照片太密、明暗跳变 | 把风格接近的图打散，重新排顺序 |
| 整段灰暗 | 原图曝光不足 | 换图，应用内的处理通常提不亮这种图 |

判断「该改歌还是该改图」的方法很简单：**问题的节奏在音频上，就改歌；问题出在画面主体上，就改图**。来回改错方向是最费时间的一种折腾。

## 五、照片里有别人的时候

MV 里出现他人形象，属于使用他人肖像，先做完这件事再分享：

- **照片里有家人、朋友、同事**：先问一句，对方同意再往外发。发在自己可见范围内和公开发布，是两回事；
- **照片里有不认识的陌生人**：不要把这类照片用在对外的 MV 里；
- **不要上传明显是他人摄影作品的照片**（比如杂志图、他人拍摄的成品照片），那涉及照片本身的著作权。

生成完成、准备往外发之前，建议把作品与发布相关的规则过一遍，见 [AI音乐作品的版权与发布注意.md](AI音乐作品的版权与发布注意.md)。合成一直失败、或者上传照片后没反应，按 [常见问题与排查.md](常见问题与排查.md) 第三节处理。
