包名 `com.anjiu.buff` 是判断「装的是不是同一个客户端」最稳的一项依据：应用商店的商品详情页会标出包名，装机时对一眼就能避开装错。MD5 用来确认下载是否完整——在电脑上可以执行 `certutil -hashfile 文件名 MD5` 核对，手机上多数文件管理器在文件详情里也能看到。

## 三、装之前先过三道门槛

**第一，账号门槛。** 领券、充值、角色交易都要求先登录；充值那一步还要选中你在**某一款游戏里的账号与区服**，账号选错就会充到别处。所以先把要用哪个手机号注册定下来，再动手装，能省一次来回。

**第二，年龄与资费门槛。** 应用商店页面标注的适用年龄是「年满十六周岁以上」，资费说明为「游戏内充值购买」。也就是说：装这个客户端本身不收费，但你要在它里面买折扣充值和福利，才需要花钱。

**第三，机器门槛。** 官方站没有单独列出最低安卓版本，常见的应用信息页标注为安卓 5.2 以上，实际以你手机安装时的兼容性提示为准。安装包 40.05 MB，装完占用的空间更大；另外你还会在这里下载游戏本体、存优惠券截图与订单凭证，机身至少预留几百兆比较从容。

## 四、安装步骤

1. **转存并下载**：打开 [游戏fan 安装文件资源（夸克网盘）](https://pan.quark.cn/s/c5e4a338a8b4)，把 APK 转存到自己的网盘再下载；在手机上直接下载最省事，在电脑上下载的还要再传一次。
2. **允许安装未知来源应用**：在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给打开安装包的那个应用（文件管理器或浏览器）打开开关；国产定制系统的这项开关一般收在「安全」或「隐私」下面。
3. **点 APK 完成安装**：系统若提示「应用未经过安全检测」或「来源未知」，选择继续安装即可，这是第三方渠道安装包的常规提示。
4. **留意版本高低**：安卓不允许用更低版本的包覆盖更高版本。手机里已有更高版本时，先卸载旧版再装，卸载会一并清掉本地已登录的会话。
5. **装完先别急着充钱**：先把下一节的权限过一遍，再登录进「我的」看一眼账号状态，比装完就直奔充值页要稳。

## 五、首次打开要关注的权限

安装与首次启动时通常会要这几项，用途都和你要做的事直接相关：

| 权限 / 设置 | 不给会怎样 |
| --- | --- |
| 存储 / 文件与媒体 | 应用内下载的游戏安装包存不下，截图与订单凭证也不好保存 |
| 安装未知应用（部分系统单独列出） | 应用内下载完的游戏点不动「安装」，只能自己去文件管理器里找包 |
| 通知 | 预约游戏上线的提醒、活动与福利消息只在应用内提示，锁屏时看不到 |
| 位置、通讯录、相机等与平台功能无关的项 | 与找游戏、充值、领券的正常流程没有关系，可以拒绝 |

各机型和系统版本的弹窗顺序、叫法会有差异，以你手机上实际出现的为准。支付那一步通常会跳到微信或支付宝的页面，相关提示来自对应渠道而不是这个应用本身。

## 六、装完做一次最小验证

1. 打开应用，能看到游戏推荐列表与搜索入口（一般在首页或「找游戏」页）；
2. 搜索一款你知道名字的游戏，能刷出结果，说明网络与列表链路正常；
3. 进「我的」看登录状态，顺手确认账号与安全入口的位置，为后面换绑、注销做准备；
4. 点开任意一款游戏的详情页，能看到优惠券 / 礼包与充值入口，说明详情页这条链路已经通了。

登录不上、装完打不开、充值时拉不起支付这类情况，统一看 [常见问题与排查.md](常见问题与排查.md)。装好之后想先找一款游戏试手，接着看 [找游戏与预约开服.md](找游戏与预约开服.md)。
