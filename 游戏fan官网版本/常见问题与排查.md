平台上遇到的「问题」，多数不是故障，而是规则内的等待、账号信息没对上，或者权限没给。下面按你卡住的位置分节，每节先给判据、再给动作。找不到对应现象时，直接跳到最后一节找客服。

## 一、装不上、打开闪退、启动没反应

| 现象 | 先判断 | 再处理 |
| --- | --- | --- |
| 提示「应用未安装」 | 手机里是不是已有更高版本 | 安卓不允许低版本覆盖高版本，先卸载旧版再装 |
| 提示「来源未知」「未经安全检测」 | 是不是第三方渠道的包 | 这是常规提示，在「安装未知应用」里放行后继续装 |
| 装完打开就闪退 | 系统版本是否过低 | 官方站未列出最低安卓版本，常见应用信息页标注安卓 5.2 以上，低于这条线容易出现启动异常 |
| 启动后一直停在启动页 | 网络是否通 | 换 Wi-Fi / 流量重试；仍不行再考虑重装 |

客户端明显异常、或你觉得装的那份包不放心时，最省事的做法是重装一份确定版本的包，从这里取：[游戏fan 安装文件资源（夸克网盘）](https://pan.quark.cn/s/c5e4a338a8b4)，版本核对与安装细节见 [下载与安装教程.md](下载与安装教程.md)。

## 二、充值付了钱、游戏里没到账

**第一原则：不要重复下单。** 按顺序走：

1. **退出游戏进程重新登录**，先看游戏里的邮件、背包、商城订单有没有这笔；
2. 回平台看订单状态，显示「处理中」的先等一会儿，渠道侧短暂延迟是常见情况；
3. 确认平台订单已完成、游戏里仍没有，把**订单号 + 支付成功截图 + 充值时间 + 游戏与角色**凑齐，找客服核对；
4. 客服处理期间不要为同一笔再充一次，多笔异常订单会让核对变慢。

充值步骤本身与账户选择容易出错的地方，见 [充值折扣怎么用.md](充值折扣怎么用.md)；如果钱其实到了、只是充到了别的账号或区服，那属于另一类问题，按 [充错账号或区服怎么办.md](充错账号或区服怎么办.md) 处理。

## 三、折扣没生效，实付金额对不上

这类情况九成出在「选的不是你以为的那条通道」，逐项对照：

| 现象 | 常见原因 |
| --- | --- |
| 实付就是原价 | 充值通道选错了，或该游戏没有可用的折扣档位 |
| 券没抵扣 | 券与这款游戏 / 这个档位不匹配，或券已过期 |
| 想用首充价但按续充算了 | 该账号在这个游戏里已经充过，首充资格已经用掉 |
| 券和活动不能一起用 | 当期活动的可用范围与券的适用范围不一致 |

页面上的活动规则写得比任何攻略都准，**以当次结算页显示的实付金额为准**；拿不准就先小额试一次，确认折扣确实生效再继续。券的领取与适用范围见 [优惠券与礼包怎么领.md](优惠券与礼包怎么领.md)。

## 四、支付拉不起来、提示限额

- **点充值没反应或跳不到支付页**：先退出应用重新进，再试一次；仍不行换一种支付方式；
- **提示达到商户限额**：这是支付渠道侧的限制，不是账号出问题——可以降低单笔金额分几次付，或换一种支付方式；
- **付了款但页面没返回**：不要立刻再付一次，先回平台看订单状态，确认没生成订单再重试。

单笔上限与可用支付方式由渠道侧决定，页面上会提示当时的可用选项，以实际提示为准。

## 五、券和礼包领不了、领了没作用

| 现象 | 判据 | 处理 |
| --- | --- | --- |
| 领券按钮点不动 | 是否登录、是否已领过 | 先登录；同一张券通常只能领一次（个别券有每日额度） |
| 领了券但没有券包 | 券一般是绑在具体游戏下的 | 回到那款游戏的详情页查看，而不是在通用券包里找 |
| 礼包领了在游戏里用不了 | 礼包是游戏内兑换，不是平台内抵扣 | 按礼包的兑换说明回到对应游戏里使用，注意有效期 |
| 签到 / 任务奖励没到账 | 是否达到领取条件 | 回签到与任务页面看条件说明；领取类异常优先找客服并附截图 |

礼包与券的区别、各类福利的入口分布，见 [优惠券与礼包怎么领.md](优惠券与礼包怎么领.md)。

## 六、登录不上、收不到验证码

| 现象 | 先判断 | 再处理 |
| --- | --- | --- |
| 收不到短信验证码 | 手机是否有拦截 / 信号 | 等一会儿重发；检查拦截记录；换网络再试 |
| 换手机后收不到通知 | 手机号是否已换绑 | 趁旧号还能收短信时完成换绑，入口在账号与安全里 |
| 忘记密码 | 绑定的手机号是否还在用 | 走登录页的找回流程；登录密码与支付密码是两套，别混 |
| 提示账号异常 | 是否有过异常登录或违规行为 | 先改密码，再按客服指引处理，不要反复尝试登录 |

换绑、注销的完整条件与顺序见 [账号注册登录与换绑注销.md](账号注册登录与换绑注销.md)。

## 七、角色交易卡住

先看订单状态是哪一档，再对号处理：

- **卡在审核**：挂牌信息与实际不符会被退回，按提示修正后重新提交；
- **卡在交接**：买家尚未完成接收，按页面指引推进，不要重复下单；
- **提现没到账**：先核对提现账户信息是否与实名的本人一致，再看提现金额是否超出可提范围；
- **想取消已经下的单**：以平台页面写明的取消口径为准，自己单方面取消通常不被接受。

卖家侧与买家侧的分工、以及哪些操作应当立刻停手，见 [角色交易怎么做.md](角色交易怎么做.md)。

## 八、官方渠道与客服怎么找

| 需要什么 | 去哪里 |
| --- | --- |
| 官方站点与下载页 | [bd.buff.vip](https://bd.buff.vip/)，页面上标注了当时的版本号与更新时间 |
| 订单、充值、券的问题 | 优先用应用内的客服入口，订单类问题附上订单号最快 |
| 站点公示的联系电话 | `4006099210`（以官方站页面当时公示的号码为准） |
| 账号、实名、提现问题 | 走应用内客服，涉及资金的申诉要准备实名与订单凭证 |

联系客服前把三样东西准备好：**账号（注册手机号）、订单号、问题截图**。缺订单号的话，客服要先帮你定位是哪一笔，处理会明显变慢。另外，任何主动私聊你并索要验证码、密码的「客服」都不是官方人员，遇到直接停止对话并向平台反馈。
