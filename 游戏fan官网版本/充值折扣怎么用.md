# 游戏fan 充值折扣怎么用

> 一次折扣充值要按什么顺序做、在哪一步最容易出错，以及付完款之后怎么确认这笔钱确实进了你的游戏账号。

游戏fan 的主要用途就是在平台内给手游充值，按平台侧的宣传口径，折扣「平均每笔 4 折、最低 2 折」。这篇不讲平台怎么谈来的折扣，只讲你实际要做的那几件事：进哪个入口、选什么、什么时候该停手核对。

## 一、动手之前先把三件事定下来

充值这条链路上有三个变量，任何一个选错都比多花几块钱麻烦：

| 要定的事 | 定错的后果 |
| --- | --- |
| 哪款游戏 | 券与折扣是按游戏给的，游戏选错这单就白做 |
| 充到哪个账号、哪个区服 | 钱进了别人的号，找回要走客服，周期很长 |
| 用哪张券 / 哪个档位 | 券与档位不匹配时抵扣不会生效，等于原价充了 |

**先把券领了再进来充**：券的领取位置在游戏详情页，见 [优惠券与礼包怎么领.md](优惠券与礼包怎么领.md)。顺序反过来的话，多数券在付款后已经用不上。

## 二、一次折扣充值的完整步骤

进入路径会随版本微调，但步骤节点是固定的：

1. **找到游戏**：从「找游戏」页或搜索进入你要充值的游戏详情页；
2. **进充值入口**：在详情页点充值相关的按钮，进入这单的充值页；
3. **选充值通道**：同一款游戏可能列出多个充值来源，选到对应平台的那一条（页面上会标明折扣信息）；
4. **选游戏账号与区服**：把要充值的账号填上或选上，这一步填错后面全错；
5. **选金额与支付方式**：选档位或输入金额，下单前再看一眼页面上的实付金额；
6. **完成支付**：按提示跳转到微信 / 支付宝等渠道付款，付完回到平台看订单状态。

各步骤的按钮名称在不同版本里有差别，**以你页面上实际显示的文字为准**。准备充大额之前，先用一笔小额把整条链路验通再谈别的。

## 三、账号与区服这一步，慢一点

这是最容易出问题的一步，值得单独说：

- **账号要填你游戏里真实的账号标识**，不是平台账号。两种账号是分开的两套，把平台注册手机号填进去是不会到账的；
- **区服要选到最小单位**。同一个游戏开多个服是常态，只写游戏名不够；
- **确认角色名**。多数情况下充值前能看到角色信息，看到的角色名与你预期不一致就停下来重选；
- **别在聊天里把你的游戏账号密码发给任何人**。正常充值流程不需要对方登录你的游戏账号，谁要谁可疑。

付款前的最后一眼就是为这一步留的：页面上的账号、区服、角色名、实付金额四项都对，再输支付密码。

## 四、首充和续充

同一个游戏里，「第一次充」和「之后接着充」通常是两套价格：

- **首充**：面向该账号在该游戏的第一笔充值，优惠力度一般更大；
- **续充**：之后重复充值时用的档位，折扣比例与首充可能不同；
- **月卡 / 战令类**：属于周期性消费，也会出现在充值档位里，买之前先确认是不是你要的那个周期。

同一账号是否已算作「已充过」，以页面显示的档位与价格为准。**别人告诉你「换个号还能再享首充」这类说法不要跟**——平台判定的是账号，不是设备。

## 五、平台币是什么，什么时候用得上

平台里除了按游戏直接充，还有一种先充平台币、再用平台币消费的方式。它的用处主要是：

- 遇到游戏内有**指定单笔金额**要求、而支付渠道单次付不了那么大额时，可以先把金额充成平台币，再在游戏内一次付清；
- 部分活动的抵扣是按平台币结算的。

平台币的适用范围、能不能退回、有效期如何，各版本与各活动不完全一致，**以平台币页面上的说明为准**。不确定就先小额试一次，别一次充大额囤着。

## 六、到账要多久，没到账怎么办

平台侧的说法是 APP 内充值秒到账。实际遇到没到账，按这个顺序处理，**不要重复下单**：

1. **先完全退出游戏进程，重新登录**，看邮件、背包或商城订单里有没有这笔；
2. 隔几分钟再回平台看订单状态，有的订单在渠道侧会短暂处于处理中；
3. 仍然没有，就带着订单号与支付截图找客服处理——不要在同一笔没解决前反复充值，多笔异常订单只会让核对更慢。

完整的现象对照与处理步骤见 [常见问题与排查.md](常见问题与排查.md) 的「充值没到账」一节。

## 七、每一笔都留一份凭证

平台内的充值记录会保留，但**你自己留一份更保险**：付款成功的截图、订单号、充值时间、金额、充值的游戏与角色，这几项凑齐，出问题时无论找客服还是找支付渠道，都用得上。大额充值建议拆成几笔小额，一笔出异常不至于影响全部。

另外，充值的账号如果之后要换绑手机号或注销，先确认余额与未完成的订单已经处理干净，再走账号流程，见 [账号注册登录与换绑注销.md](账号注册登录与换绑注销.md)。
