# 会员和免费听歌怎么算

## 一、收费分三层，先分清你卡在哪一层

| 层次 | 内容 | 是否要花钱 |
| --- | --- | --- |
| 本地音乐 | 手机存储里自己的文件 | 不花钱，不联网也能放 |
| 常规在线曲库 | 无需会员即可在线播放的歌曲 | 不花钱，会消耗流量 |
| 会员曲库 / 付费歌曲 | 需要开通音乐会员，或单独购买专辑、单曲 | 要花钱 |

同一首歌在不同时间可能落在不同层里：版权到期下架、新专辑首发期单独售卖，都会让「昨天还能听、今天要会员」。碰到这种情况先确认是不是曲库变动，不必先怀疑是应用坏了。

## 二、会员的下载份额：按月的量，不是无限

vivo 官方的会员页面里写明：**豪华会员每月享有一定数量的付费歌曲下载份额**，页面上会显示「本月已下载 N 首 / 还剩余 N 首」。

由此可以肯定两点：

- 会员下载付费歌曲是按月计量、会自动扣减的；
- 不是「开了会员就能把曲库整库搬下来」，超额之后需要另想办法。

因此在开启「边听边下载」这类自动下载功能前先想一下：自动下载会消耗月度份额，关掉它更稳妥。

## 三、下载下来的文件存在哪，为什么别的播放器打不开

想确认某首歌到底存到了手机的什么位置，官方给的查法是：进入 vivo音乐 →「我的」→「下载」→ 点歌曲右侧的「...」→「曲目信息」→「位置」。这里显示的路径就是你实际存放的地方，不必去猜应用把文件放在哪个目录。

关于付费歌曲的下载文件，官方有一条明确说明：**这类文件是 `vms` 加密格式，只能在会员生效期间通过本应用离线播放**，会员到期后无法在本地使用，也不能给第三方播放器播放。由此可以解释日常会碰到的三个现象：

| 现象 | 原因 |
| --- | --- |
| 文件管理里看到 `.vms` 结尾的文件，点开没反应 | 加密文件，本来就打不开 |
| 把下载文件拷到别的播放器或别的手机，播不了 | 同一个加密格式，换个环境一样读不出来 |
| 会员到期后，之前下载的歌点不开了 | 加密文件的使用与会员状态绑定 |

这条限制针对的是付费歌曲的下载文件；你自己拷进手机的本地音乐（MP3、FLAC 等）不受影响，做法见 [本地音乐导入与扫描.md](本地音乐导入与扫描.md)。

## 四、不想开会员：用应用内的免费模式换来一段时长

官方社区公布的玩法是这样：

1. 打开 vivo音乐，点页面中间或右上角的菜单按钮，打开侧边栏；
2. 选择「免费模式」；
3. 点「获取免费时长」，看完一小段广告；
4. 领取成功后即可播放会员歌曲，弹窗里会提示这次免费听的剩余时间。

它适合「偶尔想听一两首会员歌」的场景：用广告换几十分钟的时长。如果你的听歌量是每天通勤两小时，每次都去攒时长并不划算，直接开会员更省事。

## 五、vivo / iQOO 新机用户先查一件事

vivo 官方的新机权益礼包里出现过「音乐 VIP 月卡」，领取入口在 vivo 官网 App 的会员频道，且有**购机时间限制**（需在购机后规定天数内）和**活动期限**。手上是新机的，先去看一眼能不能领，再决定要不要买——这类权益通常下载量有限、过期不补。

## 六、价格与活动：别拿老帖当依据

会员价格属于会变的营销信息，第三方站点上抄来的「XX 元/月」往往滞后好几年。判断依据只有两个：

- 应用内会员购买页显示的价格与权益；
- vivo 官方页面（官网 / 应用商店里的会员说明）当下的展示。

开通页面上的自动续费开关常常是默认勾选的，不需要就自己关掉。取消要去你当初的支付渠道里操作，路径如下（通用路径，2026-09 核对）：

- **微信支付**：微信 →「我」→「服务」→「钱包」→ 右上角「支付设置」→「扣费服务」→ 找到对应项目 →「关闭扣费服务」；
- **支付宝**：支付宝 →「我的」→ 右上角「设置」→「支付设置」→「免密支付/自动扣款」→ 找到对应项目 →「关闭服务」。

取消的是下一期的自动扣款，当期已支付的周期通常照常生效。如果已经发生了不愿续费的扣款，先联系对应平台的客服说明情况，再走支付渠道的申诉入口，比单纯卸载应用有效——卸载并不会让扣费停下来。

## 七、会员到期后，之前下载的歌还能不能听

不能。官方明确说明这类下载文件只能在会员生效期间通过本应用离线播放，会员到期后无法本地使用，也不能用于第三方播放器（文件格式与原因见本文第三节）。

所以「先开一个月，把想听的全下下来」这条路走不通。真正需要长期留存的音乐，自己保存一份通用格式的文件（MP3、FLAC），本地文件播放不受会员状态影响——这也是不少人把它同时当本地播放器用的原因。
