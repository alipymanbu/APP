# 本地音乐导入与扫描

> 手机里攒了一堆自己下载的歌，怎么让 vivo音乐 认出来？这篇讲文件放哪、支持哪些格式、扫描设置里的三个门槛，以及认出来之后能做什么。

## 一、文件怎么进手机最省事

| 方式 | 做法 | 适合场景 |
| --- | --- | --- |
| 数据线直连 | 用数据线连电脑，把音乐文件夹复制到「手机存储」下 | 一次要搬很多文件，或整张专辑带封面 |
| 换机工具 | 用官方的换机 / 互传工具从旧手机搬过来 | 刚换机，老手机里已有整套音乐库 |
| 网盘下载 | 在网盘 App 里把歌曲下载到手机 | 零散补几首，文件先在云上 |
| 从电脑传 | 电脑端工具推送后，在手机文件管理里确认文件落到了存储里 | 不方便插线时 |

放的位置有一条原则：**放在机身存储里**，不要放在 SD 卡上。官方客服在排查扫描问题时明确提到，SD 卡不稳定或读不出来会导致扫描失败；真要用卡，也建议先把歌曲复制到机身存储的文件夹里。

## 二、它会自己扫，你也可以自己按

官方手册的说法是：不需要手动一首首添加，手机会自动扫描存储设备里的歌曲并加入列表。所以正常流程就是——文件放进去，打开应用等它扫完。

想立刻看到刚放进去的歌，手动触发一次：进入「本地」→ 点右上角的「+」→「扫描歌曲」。

## 三、支持哪些格式

官方客服给出的支持格式是：

```
MP3、AAC、WAV、WMA、MIDI、AMR、APE、FLAC、OGG、M4A
```

机型规格页里写的播放器支持范围略有出入（少了 M4A），所以遇到个别格式打不开时，先用 MP3 转一份验证是格式问题还是文件问题。另外官方手册在部分机型上提到，播放器会屏蔽 amr、awb、midi(mid) 这类格式，这些文件可以从文件管理里直接打开播放——也就是说能播，只是不进应用内的歌曲列表。

**第三方音乐软件下载的文件要单独考虑**：这类文件常带版权加密，官方客服的口径是其它播放器无法扫描添加，只能用下载它的那个软件播放。这类歌扫不到，不是设置问题。

## 四、扫描设置里的三个门槛

进「本地」→ 右上角「+」→「扫描歌曲」→ 右上角设置图标，里面有三项会直接影响「扫得到 / 扫不到」：

| 设置项 | 默认效果 | 什么时候要调 |
| --- | --- | --- |
| 不扫描的文件夹 | 被勾选的文件夹里的音乐不会被扫描 | 你确定歌在那个文件夹却没显示，先来这里取消勾选 |
| 不扫描 60 秒以下音频 | 铃声、提示音、试听片段一类的短文件会被过滤 | 想听短音频、有声片段时关掉它 |
| 不扫描 100KB 以下的音频 | 体积过小的文件被过滤 | 老式低码率小文件、语音备忘会被误伤，需要时关掉 |

改完设置记得再点一次扫描，改设置不会自动重扫。

## 五、扫进来之后能做什么

在「本地」的歌曲列表里，点歌曲右侧的操作，常用的是这几项：

- **加入歌单**：把本地歌曲并进自建歌单（歌单相关操作见 [歌单与换机同步.md](歌单与换机同步.md)）；
- **设为铃声**：直接把本地音乐设成来电铃声，不用再找第三方工具转；
- **分享**：把文件或歌曲信息分享出去；
- **删除**：多选后删除，或从列表右侧菜单删除；注意这是删除文件本身，删错了要重新拷一份进来。

## 六、本地音乐和在线曲库是两套东西

需要分清楚：本地歌曲是手机存储里的文件，不联网也能放，不占会员；在线曲库是另一回事，按会员与版权规则来。两者在同一个界面里并列显示，但来源、能否离线、是否收费完全不同——把本地音乐当成「自己的硬盘」，把在线曲库当成「听歌服务」，就不会在「为什么这首不用会员、那首要会员」上困惑了。
