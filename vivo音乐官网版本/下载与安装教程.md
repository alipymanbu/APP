## 一、先把版本对上，再动手

vivo音乐 原名 i音乐，是 vivo / iQOO 手机自带的音乐播放器，安卓手机可以直接安装。这份安装包的核对信息如下，其中的版本号、包名与体积以本地资源为准：

| 项目 | 内容 |
| --- | --- |
| 应用名称 | vivo音乐（原 i音乐） |
| 版本号 | 10.6.44.0 |
| 包名 | com.android.bbkmusic |
| 安装包大小 | 71.02 MB |
| MD5 | `a2490394be75fdff60ded82f62d387e9` |
| 适用平台 | Android |

网上官方页面显示的版本号通常更新（比如商店里已经是更高的版本），这是因为资源包停留在整理当时那一版。真伪核对不看版本号高低，看**包名**：包名一致、能装上，就是同一款应用。

**包名一致带来一个限制**：同一台手机上，同包名的应用只能存在一份。所以

- 如果你之前装过 i音乐 或从应用商店升级过，请先卸载旧的，再装这份；否则会提示「应用未安装」或安装后被系统判定为同一个应用而覆盖更新；
- 如果你只想升级到新版，不需要卸载，直接覆盖安装即可（数据通常保留，但涉及账号信息时建议先登录确认一遍）。

## 二、下载与转存

[vivo音乐 安装文件资源（夸克网盘）](https://pan.quark.cn/s/db59c15a03a8)

打开分享页后按这个顺序做：

1. 先点「保存到我的网盘」，把文件夹转存到自己账号下。分享链接可能变动，转存过就随时取得到；
2. 在网盘 App 里进入转存后的 `vivo音乐` 文件夹，下载其中的 apk 文件到手机；
3. 下载完成后用文件管理定位到这个 apk（网盘下载任务里通常有「打开方式」入口，能直接跳到安装界面）。

用手机流量下载前先想一下：安装包 71 MB 左右，不算大，但如果同时开着无损音质的在线试听，流量消耗会明显加快。

## 三、安装步骤

1. **开安装权限**：进入 `设置 > 应用 > 特殊应用权限 > 安装未知应用`，把你用来打开 apk 的那个应用（文件管理、网盘客户端等）的开关打开；
2. **点 apk 安装**：在文件管理里点开下载好的 apk，按提示确认；
3. **遇到系统拦截**：部分机型会提示「已阻止安装」，这通常是应用商店的安全扫描或纯净模式在拦，按提示选择「继续安装」或临时关闭纯净模式即可；
4. **安装完成**：桌面出现图标（新版显示为 vivo音乐），点开即可，无需注册也能先听本地音乐。

## 四、首次打开要给的权限

| 权限 | 用来做什么 | 不给会怎样 |
| --- | --- | --- |
| 存储 / 音乐和音频 | 扫描手机里的本地歌曲 | 本地歌曲列表空白，扫不到自己的文件 |
| 通知 | 在通知栏显示播放控件、显示下载进度 | 锁屏和下拉栏里没有播放控制 |
| 电话（部分机型会要） | 来电时暂停播放等系统联动 | 部分机型可能出现异常提示 |

如果你发现某个功能点了没反应，官方的通用处理口径是把该应用的权限给全，再重新打开试试（见 [常见问题与排查.md](常见问题与排查.md)）。

## 五、装到非 vivo 手机上会少什么

官方使用手册是按 vivo / iQOO 机型写的，装在别的品牌手机上能用，但下面这几项要提前有预期：

- **HiFi**：需要机型本身带 HiFi 硬件，官方支持页给的第一步就是「先确认手机是否支持 HiFi」，不支持就没有这个开关；
- **深空音效里的耳机适配**：针对 vivo 各款耳机调过，换用其它品牌耳机时这项参考价值有限；
- **系统级联动**：状态栏音乐控件、锁屏播放、原子随身听一类功能依赖 vivo 的系统，其它系统上以实际表现为准。

具体设置路径见 [音质与音效怎么设置.md](音质与音效怎么设置.md)。

## 六、确认装好了、装对了

1. 打开应用，进「我的」→「本地」：能看到本机歌曲，说明存储权限正常；
2. 在设置里查看版本号，应为 10.6.44.0；
3. 进入 `设置 > 应用 > 应用管理` 找到 vivo音乐，确认包名是 `com.android.bbkmusic`。
