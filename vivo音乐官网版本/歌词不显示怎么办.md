# 歌词不显示怎么办

> 歌词分三种：播放页歌词、桌面歌词、锁屏歌词，各自的开关位置和失败原因都不一样。这篇按这三种情况分别给出检查顺序，本地歌曲缺歌词怎么补也一并写清。

## 一、先确认你要的是哪一种歌词

| 你要的效果 | 开关在哪 | 最容易卡在哪 |
| --- | --- | --- |
| 播放页里跟着滚动的歌词 | 通常不用设置，点一下封面 / 词图区域就能显示 | 在线歌曲自动匹配；本地歌曲需要手动搜索或自备歌词文件 |
| 桌面上悬浮的歌词 | 设置里的「桌面歌词」开关 | 部分机型还要在通知栏里再点一次，或需要悬浮窗权限 |
| 锁屏上显示的歌词 | 与机型、系统版本和锁屏样式相关 | 系统版本不够、或当前主题的锁屏样式不支持 |

三种歌词彼此独立：桌面歌词开了不等于锁屏有，锁屏显示了播放页也可能一直停在封面。

## 二、播放页里没有歌词

在线歌曲和本地歌曲走的不是同一条路，分开处理：

1. **在线歌曲**：播放器会自动匹配歌词。先把网络确认一遍——歌词数据要联网取，网络不通时播放页就只有封面。
2. **本地歌曲**：需要在播放界面点一下词图（封面）区域，调出手动搜索歌词的入口，用歌名加歌手搜。
3. **搜不到就自己补一份**：在电脑上准备一份与歌曲**同名同目录**的 lrc 歌词文件，例如 `童年.mp3` 配 `童年.lrc`，两个文件放在手机存储里的同一个文件夹，再播放这首本地歌曲，就能自动加载。

第 2、3 条来自公开问答里反复出现的做法（不是官方手册里的条目），关键是**文件名与所在目录都要对上**：名字差一个字，或者歌曲在一个文件夹、歌词在另一个文件夹，都不会加载。

## 三、桌面歌词调不出来

入口在设置里的「桌面歌词」开关（部分版本在左上角的「≡」→ 设置里）。打开后仍不显示的，按顺序查下面两项（来自用户反馈，非官方口径）：

1. **通知栏里的二次开关**：播放音乐后下拉通知栏，看有没有一个歌词按钮，那里需要再点一次才真正显示到桌面；
2. **系统权限**：到 `设置 > 应用 > 应用管理 > vivo音乐 > 权限` 里检查「显示悬浮窗」（部分系统叫「悬浮窗」或「后台弹出界面」）与「锁屏通知」是否被关掉了。

桌面歌词不显示时，系统层面多半是在拦悬浮窗，而不是应用内的开关没开。

## 四、锁屏歌词不显示

官方客服的口径是：**OriginOS / iQOO UI / Funtouch 4.0 及以上系统的机型支持锁屏显示歌词**。据此先排除两件事：

- **系统版本**是否达到要求；
- **锁屏样式或主题**是否支持：锁屏歌词与主题强相关，换一个主题、或换回默认锁屏样式再试，是官方给出的处理方向。

## 五、歌词在滚，但跟唱对不上

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 整段固定提前或延后几秒 | 本地 lrc 的时间轴与这份音频不是同一个版本 | 换一份与音频配套的 lrc，或改用内嵌歌词的音频文件 |
| 歌词内容和歌名对不上 | 在线匹配到了同名歌曲的另一个版本（现场版、翻唱版） | 用歌名加歌手重新搜一次，在搜索结果里换一条 |
| 只有某一首没有歌词 | 该歌曲没有可用的歌词数据 | 用本地 lrc 兜底，或接受这首不显示歌词 |

时间轴对不上是本地文件问题，换文件就能解决；内容对不上是匹配问题，换搜索结果才能解决。两类原因别混着改，否则会来回折腾。
