模拟器出问题，原因集中在几处：存储权限、游戏文件本身、图形驱动、机身材质与散热。这篇按现象分节，每节只给能动手的步骤，不解释原理。**遇到问题直接跳到对应那一节，不要从头重装。**

## 一、装不上、装上打不开

| 现象 | 先做什么 |
| --- | --- |
| 提示「应用未安装」 | 手机里已装了版本号更高的同包名应用，先把旧的卸掉再装 |
| 提示与设备不兼容 | 系统版本低于 Android 7.0，这份包装不上 |
| 装完打开就退到桌面 | 先卸载再重装一次，覆盖安装留下的旧数据是常见诱因 |
| 安装界面反复弹安全提示 | 第三方渠道安装包的常规提示，按提示继续即可 |

版本号、包名、体积该核对哪些，见 [下载与安装教程.md](下载与安装教程.md) 第一节的表格。

## 二、应用能进，但列表里没有游戏

最常见的一类，按顺序查四条：

1. **目录选对了吗**：选到了自建目录的上一级、或者直接选了存储根目录，都会扫不出东西；
2. **格式对吗**：只认 `.nds` 与 `.zip`、`.7z` 压缩包，`.rar` 与拆开的文件块不会被列出；
3. **文件真的在本地吗**：网盘客户端的在线占位文件读不到，看文件属性里的占用空间是不是实际大小；
4. **存储权限给全了吗**：进应用权限页确认存储是允许状态，不是「仅在使用时允许」。

**放在 `Android/data` 下面的游戏也扫不到**——Android 11 之后不少系统把这块区域对新装应用隔离，把文件挪到自己新建的目录里再试。完整的目录建议见 [游戏文件放哪与怎么导入.md](游戏文件放哪与怎么导入.md)。

## 三、选游戏目录时反复提示、进不去

1. 换一个**自己新建的普通目录**（例如存储根目录下的 `nds`），不要选 `Android/data`、系统目录或存储根目录本身；
2. 在弹出的系统文件选择器里，**选中目录后要点确认授权**，中途退出会白选一次；
3. 用了外置 SD 卡的话，确认卡挂载正常、没被拔过；
4. 都不行就换一个位置新建目录再选，能定位到是「目录有问题」还是「选目录这个动作被系统挡了」。

## 四、进游戏黑屏、只有声音、闪退

**黑屏或只有声音**，按这个顺序试：

1. **先等半分钟**。部分游戏首次加载会比较久，急着杀进程反而打断初始化；
2. 换一次渲染器，换完重启应用；
3. 把内部分辨率降一档再进，个别游戏在特定档位下必然黑屏；
4. 以上都无效就记下是哪一款游戏——这类通常与设置无关，不用在上面耗时间。

**闪退**分两种：

- **一进游戏就退**：多半是个别游戏的兼容性问题，换渲染器试一次；不行就记下游戏名；
- **进什么游戏都退**：先把版本更新到 2.0.0 及以上，早期版本在部分图形芯片上有偶发崩溃，已在后续版本修掉。仍然闪退再考虑清除应用数据——**这一步会一并清掉应用私有目录里的存档**，动手前先看 [存档与进度怎么备份迁移.md](存档与进度怎么备份迁移.md)。

## 五、提示缺少 BIOS 或固件文件

这类提示出现在你**主动打开了「使用自定义 BIOS」**、或者启动主机固件菜单之后，不是默认状态下会遇到的。应用会把缺哪个文件名直接列出来，按 [BIOS与固件怎么准备.md](BIOS与固件怎么准备.md) 补齐，或者干脆把这一项关回去——普通的 DS 游戏不需要它。

## 六、两块屏显示不对，或者只剩一块

这不是驱动问题，是布局参数的问题：把布局编辑器里的两块屏重新摆一次，确认没有互相遮挡、也没有被拖到屏幕外。折叠屏与自带双屏设备上的档位不一样，改法见 [双屏布局与横竖屏怎么设置.md](双屏布局与横竖屏怎么设置.md)。

## 七、手柄连上了但按键没反应

按「先系统、后应用」查最省时间，完整的排查表在 [手柄与触屏按键怎么设置.md](手柄与触屏按键怎么设置.md) 第六节。最常被忽略的三条：

| 现象 | 多半是什么原因 |
| --- | --- |
| 所有键都没反应 | 系统里的蓝牙配对残留，删掉记录重配一次 |
| 只有个别键不灵 | 映射表里那几项是空的，重进映射页指定一次 |
| 有线能用、无线不行 | 问题在蓝牙链路，不在应用 |

## 八、卡顿、掉帧，玩一会儿才卡

不要一上来就重装，按 [画面与性能怎么调.md](画面与性能怎么调.md) 的顺序走一遍，优先动这三项：

1. 打开帧率显示，先确认「是不是真的在掉帧」，有些游戏本来就是 30 帧的节奏；
2. 把内部分辨率降到 1x 试一次，这是单项收益最大的一步；
3. 换渲染器再试一次，换完重启应用。

**玩十几二十分钟之后才开始卡的，是机身过热降频**，不属于设置问题，注意散热、别边充边玩即可。另外，32 位处理器的设备没有即时编译可用，性能上限本身就低，这类机器的卡顿不是调出来的。

## 九、画面花屏、贴图错位、整块变黑

归因通常很单一：**当前渲染器与你的图形驱动不匹配**。

1. 把渲染器换到另一个选项，用同一款游戏对比；
2. 换完重启一次应用，有的机型不重启不生效；
3. 只有个别游戏出问题的，多半是该游戏自身的兼容性问题，换渲染器能缓解就保持现状。

## 十、存档不见了、进度对不上

先分清丢的是游戏内存档还是即时存档，再看存档目录选的是哪一种：换过存档位置、或者用第三方前端启动没扫描过的游戏，都会让存档落在别的地方。完整说明见 [存档与进度怎么备份迁移.md](存档与进度怎么备份迁移.md)。

## 十一、金手指勾了却没效果

先确认码对应的游戏版本是否匹配（地区版本不同，地址不一样），再检查分组有没有勾上、是不是需要按键触发的码。逐条排查见 [金手指怎么导入与使用.md](金手指怎么导入与使用.md) 第五节。

## 十二、怎么确认自己装的是哪一版

进应用的设置或关于页面看版本号，与 [下载与安装教程.md](下载与安装教程.md) 第一节表格里的 `2.0.0PS` 对一下。对不上说明是另一份包，本文涉及的选项名称与位置可能与你看到的不完全一致。

怀疑安装包不完整、或者想换一份干净的：从 [melonDS模拟器 安装文件资源（夸克网盘）](https://pan.quark.cn/s/a323a8650901) 重新转存下载，装之前先卸载旧版，并按 [存档与进度怎么备份迁移.md](存档与进度怎么备份迁移.md) 备份一次存档。

## 十三、要不要换成别的 melonDS 安卓版

除网盘里这一条线之外，还流传着几个改版：有的在它的基础上加强了 Vulkan 与成就相关的东西，有的直接是每日构建分支。它们和本文这份的选项名称、功能范围并不完全一样，属于「选哪条路」的问题，本篇不替你下结论。要对照着用，**注意换版本等于可能换存档兼容性**，动手前先按 [存档与进度怎么备份迁移.md](存档与进度怎么备份迁移.md) 备份。

## 十四、界面是英文的，怎么改成中文

这份包在 2.0.0 起提供了简体中文翻译，界面语言**跟随系统语言**：系统设为简体中文，打开应用就是中文，不需要在应用里找开关。

如果系统是英文、只想让这一个应用显示中文：

1. Android 13 及以上，进「设置 → 应用 → melonDS → 语言」，单独指定为简体中文；
2. 部分机型的系统设置里没有这一项，那就只能把系统语言改成简体中文；
3. 在应用内翻不到「语言」选项是正常的，这类应用一般不做应用内的语言开关。

## 十五、能不能联机玩

只有 Wi-Fi 联网这一条有支持，**需要两台机器凑在一起的本地无线玩法这条安卓版做不了**（作者列为缺失功能）。两类联机的区别、以及 Wi-Fi 联网在哪儿发起，见 [能不能联机与Wi-Fi怎么用.md](能不能联机与Wi-Fi怎么用.md)。
