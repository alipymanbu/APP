# melonDS模拟器 金手指怎么导入与使用

金手指就是往游戏内存里写固定值的一组指令，模拟器负责在你勾选之后把它们应用上去。它本身不带任何代码，所以「有金手指可用」的前提是你手上有一份码表，或者自己知道那串码。这篇只讲怎么把它用上，不讨论码从哪来。

## 一、两条路，先分清

| 方式 | 适合 | 说明 |
| --- | --- | --- |
| 导入数据库 | 想一次拿到大量游戏的金手指 | 数据库是一个 XML 文件，里面按游戏分好条目，导入后按游戏自动列出 |
| 手动添加 | 只有某一款游戏的几行码 | 直接把码贴进去，适合针对性使用 |

**先导入数据库再手动补充**是最省事的组合：绝大部分游戏能在数据库里直接找到，找不到的再自己贴一条。

## 二、导入一份数据库

1. 打开应用，进**设置**，找到金手指那一项；
2. 打开「启用金手指」开关；
3. 点「导入金手指」，在弹出的文件选择里挑那个 XML 文件；
4. 等它导入完。条目多的数据库会慢一些，**导入期间不要退出应用**；
5. 导入完成后回到主页即可。

数据库文件放在哪都行，应用会记住导入的结果，不需要每次重导。更新数据库后重新导入一次即可。

## 三、进游戏之后在哪勾选

金手指不是在主界面里开的，而是在**游戏运行中**：

1. 启动一款游戏；
2. 唤出模拟器的暂停或菜单，进入金手指页面；
3. 页面上会列出属于这款游戏的条目，展开需要的那一组，把对应项勾上；
4. 勾选后即时生效，多数不需要重开游戏。

如果这一页是空的，说明数据库里没有匹配到这款游戏，或者前面导入那一步没成功，按下一节查。

## 四、自己写一条

1. 同样先打开「启用金手指」；
2. 新建一个分组（方便归类），在分组里新建一条金手指，把码粘进去；
3. 名称随便起，能认出来是哪一条就行；
4. 回游戏里按上一节的方式勾选。

**分组是必须先建的**：没有分组时新建的条目无处可放，页面看起来像「加不上」。

## 五、选了却没效果，按顺序查

1. **这条码对应的游戏版本对不对**。金手指多数是按游戏的某个地区版本写的，日版、美版、汉化版的地址不一样，版本对不上，勾了也不会生效，这是最常见的一种；
2. **分组有没有勾上**，只勾了组里的条目、没勾分组本身，有的界面下不会生效；
3. **是不是需要按键触发的码**。有些金手指要求你在游戏里按住某组按键才起效，勾上之后还得按键；
4. **数据库有没有真的导入成功**。列表能显示出这款游戏的条目，就说明导入是好的；
5. **同一条码同时只留一份**。重复添加相同码有时会互相干扰，删到只剩一条再看。

## 六、和成就类功能的关系

如果你在用成就类功能，要知道**开了金手指之后，成就系统通常会判定这次游玩不算数**——具体规则以那个功能自己的说明为准，这里不替它下结论。想两样都要的话，用完成就之后再开金手指，或者分开两个存档来玩。

## 七、影响范围

金手指只作用于**你当前玩的这一份游戏内存**。出错、想撤销，把勾选全部取消、或者重开游戏就恢复原状；不会写进游戏文件，也不会影响别的游戏。
