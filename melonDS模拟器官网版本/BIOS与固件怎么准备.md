# melonDS模拟器 BIOS与固件怎么准备

> 这篇说清一件容易被教程搞混的事：什么时候可以不提供 BIOS 就玩，什么时候必须自备，以及文件放哪里。

搜「melonDS 要不要 BIOS」，会看到两种完全相反的说法。分歧的来源很简单：**不同的使用场景要求不同**。这篇按场景分开说，看完你就能判断自己属于哪一种。

## 一、默认设置下，玩 DS 游戏不需要你提供 BIOS

应用里有一项「使用自定义 BIOS」，**默认是关着的**。这一项关着时：

- 启动 DS 游戏**不会**先去检查 BIOS 目录；
- 模拟器用内置的回退方案来顶替 BIOS，内存里临时生成一份固件；
- 也就是说，**只玩普通 DS 游戏，什么都不准备就能开始**。

这是很多人「直接装完就玩上了」的原因，也是他们坚持说「不需要 BIOS」的原因。

## 二、什么情况下必须自己准备

以下场景会用到真实的 BIOS 与固件文件：

- **要进 DSi 模式、玩 DSiWare**；
- **要启动主机固件菜单**（而不是直接进游戏）——这个动作本身就会把「使用自定义 BIOS」打开；
- **游戏要用到摄像头、麦克风、Wi-Fi 一类的功能**；
- **某款游戏用回退方案跑不正常**，需要换真实固件再试。

这时「使用自定义 BIOS」必须打开，并且对应目录里得有文件，缺了会被应用拦下并给出提示。

## 三、需要哪些文件

按名字准备，比按用途记更省事。应用读的是文件名，不是文件内容：

```text
DS 目录（给 DS 模式用）
├── bios7.bin
├── bios9.bin
└── firmware.bin

DSi 目录（给 DSi 模式用）
├── bios7.bin
├── bios9.bin
└── firmware.bin
```

**两个目录下的文件名是一样的**，靠文件大小与放入的目录来区分是 DS 版还是 DSi 版。DS 模式和 DSi 模式是分开检查的，**只玩 DSi 的话两个目录都要配齐**，只配一个会在启动时被提示。

## 四、在哪里指定

1. 打开应用，进**设置**，找到固件或 BIOS 相关的项；
2. 打开「使用自定义 BIOS」；
3. 分别指定「DS 目录」与「DSi 目录」两个路径；
4. 回到主页启动游戏，让它检查一次。

目录没配、或者被系统拒绝访问时，**应用会把需要的文件名直接列在屏幕上**，照着补文件最快，不用去猜。文件放在手机存储或 SD 卡上的普通目录里即可，不需要放到应用私有目录。

## 五、文件从哪来

这几份文件属于主机自己带的数据，**没有可以公开下载的正规渠道**。正当的做法是从你自己拥有的那台 DS / DSi 上把数据导出来，导出的方法在相关的自制软件社区里有成套说明，这里不提供任何下载地址，也不建议用别人给的文件——来源不明的固件文件既可能对不上，也可能夹带别的东西。

## 六、打开自定义 BIOS 之后常见的提示

| 提示 | 含义 | 处理 |
| --- | --- | --- |
| 提示缺少某个 `.bin` 文件 | 目录里文件名不对或没放进去 | 按屏幕列出的文件名补齐，注意大小写 |
| 提示目录不可用 | 选到了应用没有读权限的位置 | 换一个普通目录重新选一次 |
| 只提 DSi 相关的文件缺失 | DSi 目录没配齐 | 把 DS 与 DSi 两个目录一起配好 |
| 以前能玩、打开这项之后反而进不去 | 文件版本与模式不匹配 | 把这项关回去，普通 DS 游戏照旧能玩 |

**不确定要不要开这一项时，就别开**：普通的 DS 游戏用默认的回退方案完全够用，只有确有用到第二节里那些功能时才需要动它。
