模拟器本身是空的，列表里有没有游戏完全取决于你把文件放在了哪、以及文件是不是它认的格式。这篇按「格式 → 目录 → 导入 → 排错」的顺序讲，装好之后先把这几步走完，后面就很少再回来翻。

## 一、认哪些格式

| 扩展名 | 说明 |
| --- | --- |
| `.nds` | NDS 卡带镜像，最直接的一种 |
| `.zip` / `.7z` | 压缩包，应用能直接读取包内的游戏文件，不必先解压 |

不在这个范围内的不会出现在列表里：`.rar` 压缩包、被拆开的文件块、其他主机的镜像都不认。压缩包虽然能直接读，但**一个压缩包里只放一款游戏**最省事，多合一压缩包在列表里只算一项，挑游戏时反而麻烦。

还有一条容易踩的：**DSiWare 这类小体量下载版游戏，通常要求解压之后再放**，以压缩包形式放进去不一定能被识别。普通卡带镜像可以压缩包直接读，两类游戏的待遇不同。DSiWare 还需要单独准备固件文件，见 [BIOS与固件怎么准备.md](BIOS与固件怎么准备.md)。

## 二、目录建在哪一层

推荐这样一个结构：

```text
存储根目录/
└── nds/                   ← 自己新建，专门放 NDS 游戏
    ├── GameA.nds
    └── GameB.zip
```

三条要注意的：

- **不要把存储根目录直接当游戏目录**。应用会扫描所选目录下的内容，根目录文件杂、层级深，扫描慢且容易混进无关文件。
- **不要放在 `Android/data` 下面**。Android 11 之后，不少系统把这个区域对新装应用限制得很严，放这里的游戏经常扫不到。
- **内部存储和外置 SD 卡都行**，但外置卡的挂载路径在重启或换卡后可能变化，游戏多的话建议统一放一处。

## 三、第一次导入

1. 打开应用，在提示里选中上面那个 `nds` 目录。注意选的是**装着游戏文件的那一层**，不是它外面一层。
2. 等应用扫描完，主页列表里就会出现游戏。
3. 列表默认显示文件名。想让条目更整齐，可以在设置里调整显示方式，不做这一步不影响玩。

## 四、加了新游戏却没出现

应用在列表里记的是「扫描过的 ROM」，新拷进来的文件不一定会自动冒出来。按顺序处理：

1. 回设置里**重新选一次游戏目录**，让它重扫；
2. 确认文件下载完了：网盘客户端的「在线占位」文件在本机没有实际内容，应用读不到，看一下文件属性里的占用空间是不是和体积对得上；
3. 确认扩展名是 `.nds`、`.zip` 或 `.7z`，`.rar` 要先解压；
4. 确认没放进 `Android/data` 那类受限目录；
5. 都排除了还是不行，把这款文件单独放到新建的空目录里再选一次，能定位到是「目录整体有问题」还是「这一个文件有问题」。

## 五、用第三方前端启动

这条模拟器可以被第三方前端（各类游戏启动器、桌面前端）调起来，参数是固定的：

- 包名：`me.magnum.melonds`
- 活动名：`me.magnum.melonds.ui.emulator.EmulatorActivity`
- 传入方式：优先传指向 ROM 的 URI 并授予读权限；也兼容旧的 `uri` 与 `PATH` 字符串参数

有一个坑要提前知道：**如果这款 ROM 之前没在模拟器里扫描过，它无法把存档写到你指定的位置**，会退到应用私有目录 `Android/data/me.magnum.melonds/files/saves`。所以习惯用前端启动的话，最好先在模拟器里把游戏目录完整扫一遍，存档位置才符合预期，相关设置见 [存档与进度怎么备份迁移.md](存档与进度怎么备份迁移.md)。

## 六、游戏名和图标怎么变好看

列表上的名字默认来自文件名，图标是统一占位图。应用扫描时会读取 ROM 头部的信息，把文件名改得规范一些（去掉来源后缀、补上地区或版本标记），列表读起来会清爽不少；这一步纯属个人习惯，与能不能玩无关。
