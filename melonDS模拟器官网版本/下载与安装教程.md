melonDS模拟器 是安卓上用来玩任天堂 NDS 与 DSi 游戏的开源模拟器。它自己不附带任何游戏，装完还要你准备游戏文件才能玩起来。本篇只处理从拿到安装包到第一次打开这一段，游戏文件怎么放见 [游戏文件放哪与怎么导入.md](游戏文件放哪与怎么导入.md)。

## 一、先弄清网盘里这份包是哪一版

搜「melonDS 安卓」能翻出好几个下载入口，各处的版本号还对不上。网盘里这份是本文核对过的那一份，全文涉及的版本号、包名、体积一律以下表为准：

| 项目 | 值 |
| --- | --- |
| 官方核心名 | melonDS |
| 本文安装包版本号 | 2.0.0PS |
| 包名 | `me.magnum.melonds` |
| 安装包体积 | 20.02 MB |
| MD5 | `9D2779650E42F16017D11A35D395EDDF` |
| 系统要求 | Android 7.0（API 24）及以上 |

**版本号末尾的 `PS` 不是笔误**：这条安卓版按发布渠道打出两套包，Google Play 商店渠道的后缀是 `PS`，GitHub 发布页渠道的后缀是 `GH`。两套的包名与主版本号相同，差别主要在签名与更新检查的途径，具体功能以发布页当时的说明为准。

**体积与 MD5 可以直接和网盘里的文件对一下**：Windows 上用 `certutil -hashfile 文件名 MD5`，手机上的文件管理器多数也带校验功能。对不上说明拿到的是另一份包，或者下载过程出了岔子。

## 二、能不能装在你的手机上

两条先看：

- **系统版本**：这份包的最低要求是 Android 7.0。低于这个版本装不上，安装器会直接拒绝。
- **处理器位数**：64 位设备（arm64-v8a）是理想状态；32 位设备也能装，但这条安卓版在 32 位上没有即时编译（JIT）可用，帧率会明显不够，多数游戏跑不满速。

真正决定「某款游戏能不能流畅跑」的是芯片里的图形部分与驱动，同一个版本在不同机型上差别可以很大，这一点在 [画面与性能怎么调.md](画面与性能怎么调.md) 里有更具体的说明。装之前没法只看参数得出结论，装完拿一款游戏实测一分钟是最快的判断方式。

## 三、安装步骤

1. **转存并下载**：从 [melonDS模拟器 安装文件资源（夸克网盘）](https://pan.quark.cn/s/a323a8650901) 把安装包转存到自己的网盘，再下载到手机或电脑。手机端直接下载最省事。
2. **让系统允许安装**：在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给打开这个安装包的应用（文件管理器或浏览器）打开开关。国产系统多把这项收在「安全」或「隐私」分类下面。
3. **点击安装包完成安装**：提示「应用未经过安全检测」是第三方渠道安装包的常规提示，按提示继续即可。
4. **升级可以覆盖安装**：同包名的较高版本能直接覆盖，设置与存档默认保留。但如果已装的版本号比新包更高，系统会直接报「应用未安装」，这时要先卸载旧版。
5. **装完先别急着进游戏**：第一次打开需要先指定游戏目录，见下一节。

## 四、第一次打开：先指定游戏目录

这条模拟器的流程是「先告诉它游戏放在哪个文件夹，再从那个文件夹里挑游戏」，和一部分模拟器「进应用再看列表」不同：

1. 第一次打开会提示你选择一个 ROM 目录，也就是存放游戏文件的文件夹。选你自己新建的、确实放着游戏文件的那一层，不要选存储根目录。
2. 选定后应用会扫描这个目录，把识别到的游戏列出来。
3. 列表里点一款游戏即可开始。

选目录这一步卡住的人最多，原因通常出在选错层级或文件格式不被识别，两种情况在 [游戏文件放哪与怎么导入.md](游戏文件放哪与怎么导入.md) 里分别有说明。

## 五、装完做一次最小验证

1. 打开应用能正常进入，没有停在权限或目录提示上；
2. 选好游戏目录后，列表里能出现游戏名；
3. 随便进一款游戏，等画面出来，就说明安装这一步已经走通。

如果第 2 步列表是空的，问题在目录或文件，不在安装本身，不要反复重装，按 [游戏文件放哪与怎么导入.md](游戏文件放哪与怎么导入.md) 排查即可。

## 六、这个模拟器是什么来路

分清两层，后面遇到问题时才知道该去哪儿看说明：

| 层面 | 是什么 | 谁在维护 |
| --- | --- | --- |
| melonDS 核心 | 模拟 NDS / DSi 硬件的开源程序，GPL-3.0 许可 | 原作者 Arisotura 与社区，主页 `melonds.kuribo64.net` |
| 安卓版外壳 | 把核心搬到安卓上的应用，网盘里这份就是它 | Rafael V. Caetano 单独维护，源码与发布记录在 `github.com/rafaelvcaetano/melonDS-android` |

**安卓版不是 melonDS 团队官方发布的**，属社区移植。由此带来两件事：一是它的功能更新跟着安卓版自己的节奏走，不一定与桌面版同步；二是遇到问题到桌面版那边问没有用，得看安卓版自己的发布页。这条安卓版目前公布的缺口是本地多人联机、DSi SD 卡、自定义按键皮肤、更多显示滤镜这四项，在它的项目说明里列在「缺失功能」下。
