# Preply 使用指南

Preply 是一个找真人老师上一对一网课的平台：官网口径是覆盖 90 多种语言，中国区商店里的中文名则写着「学习50+种语言」。这份指南写给想用它的中文用户 —— 先讲清它是什么、怎么开始，再讲订阅与退费这些最容易踩坑的地方。

---

## 一、它是什么，适合谁

Preply 不是一个自学 App，而是一个**导师市场**：你自己挑老师、买课时、用内置教室上一对一视频课。规模上，它的导师数量在十万量级，语言覆盖 90 多种（官方口径）。

和几个常被拿来比较的平台相比，差别主要在收费方式和灵活度上：

| 平台 | 怎么收费 | 特点 |
| --- | --- | --- |
| Preply | **订阅制**，每 28 天自动续费 | 绑定一位导师、内置教室、有系统的学习页 |
| italki | 按课时单买 | 更灵活、通常更便宜，取消线因老师而异 |
| Cambly | 订阅 | 只教英语，能随时开课，适合练口语 |

**在动手之前，有三件事必须先知道**：

| 要知道的事 | 具体是什么 |
| --- | --- |
| 是订阅制，不是按次买 | 每 28 天自动续费，一个周期最低 4 节课，每份订阅只对应一位导师 |
| 退订只能在网页端 | App 里能约课、上课、发消息，但按官方帮助中心的说明，**取消订阅和取消订单要在浏览器里操作** |
| 支付有地域限制 | 官方支持列表里有中国银联，但同一条说明里也写明「因地域限制可能无法使用」；支付宝、微信支付不在官方列表里 |

所以它适合这样的人：**能接受按月自动扣款、并且想跟着固定一位老师长期学**。如果你只想先买几节课试试、或者担心自动续费，按课时计费的平台会更省心。另外，老师教什么语言、和老师本人会不会说中文是两回事：如果你完全不会英语，选师时要专门看老师「我会讲」里有没有中文。

## 二、下载与安装

网盘里这份安装包的信息是：版本 `6.61.0`，包名 `com.preply`，体积约 70.04 MB，MD5 为 `478BE1FB52736F5CE588C33F020AF64A`。下载入口：https://pan.quark.cn/s/ab5e7c6ff6aa

拿到文件后可以自己算一次 MD5 比对确认没下错（不少文件管理器自带校验功能）。**网上商店里的版本一直在更新，与网盘里这份不一定是同一版**，本文的版本信息以网盘这份为准。

装到安卓设备上：

1. 从上面这个链接把 APK 转存到自己网盘，再下载到手机；
2. 在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给打开安装包的那个应用打开开关；
3. 点击 APK 完成安装，提示「未经过安全检测」时选择继续安装即可。

系统版本方面**说法不太一致**：有的资料标 Android 10 以上，也有标 9 以上的，官方没有给出明确的最低版本。**建议 Android 10 及以上再装**，低版本设备可能装不上或上课时闪退。

本文这份是安卓安装包；用 iPhone 的话，到 App Store 下载同一款应用就行，账号与订阅是通用的。

## 三、注册与订阅

### 注册

支持邮箱注册，也可以用 Google、Facebook、Apple 账号登录。**只是浏览导师、看价格，不需要绑卡**；但下单时必须提供有效的支付方式，而且订阅生效后已绑的卡是不能删除的。

### 从试课到订阅

正常的路径是：**筛选导师 → 付费试课 → 满意后订阅 → 开始上课**。

**价格没有统一价目表**：每位老师的课时单价由老师自己定，写在他/她的主页上；试课与订阅都按这个单价乘课时数计算，具体金额以结算页为准。

要留意的几点：

- **首节试课是付费的**（25 分钟或 50 分钟，预订时扣费），不是免费体验；长期有折扣码活动，具体以官网当时为准；
- 如果对试课的老师不满意，官方给的机会是**再换两位老师试课**（换师试课不额外收费，细则以帮助中心为准）；
- **一份订阅只对应一位导师**；想同时跟两位老师学的，等于再开一份订阅，课时可以在老师之间转移。

### 订阅规则（这部分最容易踩坑）

| 规则 | 具体说明 |
| --- | --- |
| 周期 | 每 28 天自动续费一次 |
| 课时量 | 每个周期最低 4 节课 |
| 暂停 | 每个周期可以暂停一次，最多延后 20 天 |
| 取消 | 随时可取消，没有违约金，但**要在续费日之前 1 天**操作（提前整 24 小时更保险） |
| 未用的课时 | 到期会作废；官方不同页面口径不完全一致，以帮助中心与客服答复为准 |
| 退款 | **不是取消订阅就自动退款**：要在扣款后 28 天内提出，且该周期没有已消耗的课时，并且需要主动联系客服申请；款项退回原支付渠道，官方说明最长 30 天 |

### 付款方式

官方支持的渠道包括 Visa、Mastercard、Amex、JCB、中国银联、Maestro 等，以及 Google Pay、Apple Pay，以美元/欧元/英镑结算。

**中国用户最常遇到的问题是卡被拒。** 官方在付款方式说明里明确写了「因地域限制，JCB、中国银联、Maestro 等可能无法使用」；**支付宝、微信支付没有出现在官方列表里**。卡被拒时，多半是发卡行的跨境或外币风控，需要联系银行确认；实在不行就换一张卡。

## 四、上课：约课、改期、换老师

- **提前 12 小时是条硬线**。在开课前 12 小时以上取消，课时退回；不足 12 小时取消，课时不退，而且要付给老师。**不足 12 小时才动手改期，通常也按同样口径处理**（以帮助中心的取消与改期规则为准）—— 所以临时有事要尽早改期，别拖到最后一刻；
- **时区要在设置里确认**。平台按你设的时区显示上课时间，时区错了会直接错过课；
- **课堂是视频 + 白板 + 文件 + 聊天的合集**（Preply Classroom），上课前几分钟进去试一下摄像头和麦克风，能省掉开课时的忙乱；
- **课后有学习页**：课时记录、进度与词汇闪卡、每日练习都在那里；
- **换老师**：可以转移课时，也可以额外加第二位导师（相当于再加一份订阅）。

## 五、常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 没用几节课就被扣了一整期 | 忘了取消自动续费。取消要在**到期前 1 天**做，而且要去网页端；已经被扣的，尽快联系客服说明情况 —— 是否符合退款条件、能退多少，由客服按当期课时使用情况判定 |
| 付款时卡被拒 | 官方已说明部分卡种因地域限制不可用，先联系发卡行确认没开跨境风控，再换一张卡 |
| App 里找不到退订入口 | 退订、取消订单只能在网页端做，App 内不提供 |
| 约不到合适的时间 | 换一位在该时段有空档的导师，或提前几天约 |
| 临时有事 | 12 小时以上改期，课时不会损失 |
| 客服回复慢 | 客服以欧美时段为主，周末可能要等一两天（第三方反馈，非官方说明） |

界面不用担心看不懂：**Preply 的网站与帮助中心有中文版，App 也支持简体中文界面**。使用中如果遇到应用本身的问题（装不上、闪退），安装包始终从 https://pan.quark.cn/s/ab5e7c6ff6aa 取用即可。
