## 一、先分清是哪一种「不刷新」

四种现象对应四条不同的处理路线，先对号，别一上来就重装应用（重装会清掉本机便签）。

| 你看到的现象 | 大概率属于 | 先做什么 |
| --- | --- | --- |
| 部件空白，一点内容都没有 | 部件没绑到便签，或桌面重载后没恢复 | 打开应用确认便签还在，再移除并重新添加部件 |
| 部件显示旧的文字，你在应用里改了没变 | 应用的刷新被系统限制 | 看第二节的后台与省电设置 |
| 只有某一个部件不刷新，其他正常 | 那个部件的绑定或尺寸问题 | 单独移除那一个再重加 |
| 有便签边框，但里面没有文字 | 字体回退或部件尺寸太小 | 先拉大部件，再看 [手写涂鸦与便签外观怎么设.md](手写涂鸦与便签外观怎么设.md) 里的字体限制说明 |

四条都排除了还不行，再走第五节的「缓存与桌面重载」。

## 二、最常见的原因：系统把应用的后台限制住了

桌面小部件的刷新要靠应用在后台活着。安卓的省电机制会把不常打开的应用冻结，部件就会停在旧内容上。这条在国产定制系统上尤其常见，各家开关的名字不一样，改的是同一个东西 —— **让应用可以在后台运行**。

| 系统 | 大致路径 |
| --- | --- |
| 原生 Android / Pixel | 设置 → 应用 → Sticky Notes + Widget → 电池 → 选「不受限制」 |
| 小米 / Redmi（MIUI、HyperOS） | 设置 → 应用设置 → 应用管理 → 找到本应用 → 省电策略 → 选「无限制」 |
| 华为 / 荣耀 | 设置 → 应用 → 应用启动管理 → 找到本应用 → 关闭「自动管理」，手动打开允许后台活动 |
| OPPO / 一加 / realme（ColorOS） | 设置 → 电池 → 应用耗电管理 → 找到本应用 → 允许后台运行 |
| vivo / iQOO（OriginOS） | 设置 → 电池 → 后台高耗电 → 允许本应用 |
| 三星（One UI） | 设置 → 电池 → 后台使用限制 → 确认本应用不在「已休眠的应用」里 |

改完**先重启一次手机**，再观察部件是否恢复刷新。另外，系统的全局「省电模式 / 超级省电」开着时，上面这些设置可能被覆盖 —— 先关掉全局省电模式看一次，确认是不是它导致的。

不建议为了保住部件刷新就把手机的省电机制整体关掉，续航的代价通常比这点便利大。按单个应用放开就够。

## 三、重启手机后部件变空白

重启会让桌面把上面的部件重新加载一遍，加载顺序和时机由桌面应用决定，出现短暂空白是正常的。处理顺序：

1. 等十几秒到半分钟，别急着动手；
2. 仍空白 → 把该部件移除，按 [桌面小部件怎么添加与调整.md](桌面小部件怎么添加与调整.md) 重新添加并绑定便签；
3. 每次都这样 → 说明这台机型的桌面对第三方部件的恢复做得不理想，回到第二节放开后台限制。

## 四、移除重加的标准动作

这个动作在排查里要反复用，注意别做错 —— **移除部件不会删掉便签本身**，敢做：

1. 长按桌面上的部件，拖到顶部的「移除」松手；
2. 长按桌面空白处 → 选择「小部件」；
3. 重新选一个样式拖到桌面；
4. 按提示选择这条部件要显示哪条便签（或哪个文件夹）。

重加之后如果内容是对的，说明问题出在桌面侧的部件实例上，不在便签数据；如果重加还是空白，问题在应用被限制或被系统卸载，继续往下查。

## 五、系统更新、桌面更新之后的缓存不一致

手机系统或桌面（启动器）更新之后，桌面缓存的旧部件信息可能和新系统对不上，表现就是部件画不出来。

- **清桌面的缓存**：设置 → 应用 → 显示系统应用 → 找到你正在用的桌面（启动器）→ 存储 → 「清除缓存」。**注意只清缓存，不要点「清除数据」** —— 那会把桌面布局、图标位置一起重置。
- **清本应用的缓存**同理：设置 → 应用 → Sticky Notes + Widget → 存储 → 清除缓存。同样别点「清除数据」，那会删掉便签。
- 清完重启一次手机再看。

如果失效恰好发生在系统大版本更新之后、且上面几步都无效，可以再等一个系统小版本更新 —— 部件类问题常常是在系统侧被修掉的。

## 六、桌面空间和存储空间

两个容易被忽略的硬限制：

- **桌面页放不下**。新页没有空位、或当前页格子被图标占满时，部件是加不上去的。先挪出空间或新建一页。
- **内部存储接近写满**。存储空间不足时桌面的绘制会出现异常，部件首当其冲。清出一些空间后再试。

## 七、查到最后仍不稳定怎么办

按上面走完还是时不时失效，说明这台机型对第三方小部件的限制比较严。与其反复折腾，不如降低依赖：

- 桌面只留 1~2 条最常用的便签部件，数量少、出问题也容易定位；
- 其余便签通过应用内的列表与文件夹查看，见 [文件夹分组搜索与回收站.md](文件夹分组搜索与回收站.md)；
- 别把「不会丢的重要信息」只留在桌面上 —— 桌面只是显示层，内容以应用内为准，重要内容按 [备份恢复与换机迁移.md](备份恢复与换机迁移.md) 定期导出。
