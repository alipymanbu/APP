# Sticky Notes + Widget 便签加密与隐私设置

加密码解决的是「别人翻你手机」这一类场景，但它有明确的边界：桌面小部件上已经显示出来的内容不在它的保护范围内。本篇讲密码加在哪一层、忘记密码会怎样、数据实际存在哪里，以及备份文件为什么不受它保护。

## 一、加密保护的是「打开便签」这一步

官方功能列表里给出的能力是**用密码保护便签和文件夹**。它的作用范围要说清楚：

- 加过密码的便签、文件夹，别人拿到你的手机、点开这个应用时，打不开；
- 它**不加密桌面小部件**。已经放到桌面上的便签内容是按小部件显示出来的，密码拦不住「桌面上已经显示的那几行字」。

所以真正私密的内容，处理方式是：**加密码 + 不要放到桌面小部件上**。想上桌面的内容，就按「会被人看到」来写。

## 二、怎么加密码

密码是加在便签或文件夹上的，也就是说**按对象来的，不是全局一个开关**：

1. 在便签或文件夹的设置里选择锁定 / 密码保护；
2. 第一次用会让你设一个密码；
3. 之后打开被锁的对象需要输入密码。

文件夹锁上之后，里面的便签随之受保护，所以更省事的做法是**按用途分好文件夹再整体上锁**，而不是一条条锁 —— 分组方法见 [文件夹分组搜索与回收站.md](文件夹分组搜索与回收站.md)。

## 三、忘记密码会怎样

这一点务必当成前提来对待：**这是一道本机锁，忘记之后没有「找回密码」的常规途径**（没有邮箱验证、没有密保问题这类找回链路是这类本地便签应用的通行做法）。可以做的只有两种处理：

- 如果之前导出过未加密状态下的备份文件，并且你确定备份里的内容就是你要的，可以靠恢复备份把内容拿回来 —— 但密码设置本身也会随之回到备份时的状态，方法见 [备份恢复与换机迁移.md](备份恢复与换机迁移.md)；
- 没有任何备份，就只能接受这部分内容拿不回来。

因此：

- **密码要用你长期记得住的那一个**，别为了「更安全」设一个随手编的；
- 锁之前，先确认内容真的需要锁 —— 锁了之后自己忘掉，代价比不锁更高。

## 四、数据存在哪

这个应用**默认把便签存在手机本地**（这也是它能离线用的原因）。商店页面把它描述为「数据保存在本地、提供备份与恢复」，并声明不收集你的数据 —— 页面口径会随版本更新调整，以官方当时显示为准。

对应到使用上：

- **不联网也能记便签**，桌面小部件照常显示；
- **卸载应用会删掉本机便签**，卸载前先备份；
- 应用申请网络权限是为了在线备份 / 同步这类需要联网的功能，不用这些功能时离线记录不受影响。安装时系统列出的权限项，按你自己的接受程度决定是否继续装。

## 五、除了加密码，还能做什么

按「手机被别人拿到」这个场景，独立的几道防线是：

| 场景 | 有效做法 |
| --- | --- |
| 别人拿到已通过锁屏的手机，翻这个应用 | 加密码锁文件夹；私密内容不上桌面小部件 |
| 别人拿到仍处于锁屏状态的手机 | 用系统锁屏密码 / 生物识别拦住，比应用内密码更早一步 |
| 手机借给他人临时用 | 私密文件夹加锁；桌面只留不敏感的内容 |
| 手机丢失 | 提前开系统查找设备 / 远程锁定；私密内容不要依赖单一应用内的加密 |
| 二手转卖或维修 | 先备份 → 退出应用并清除数据 → 再交出去 |

## 六、最容易被忽略的一处：备份文件不受密码保护

锁定和备份是两件互相独立的事。你把便签锁上，再导出备份，导出的那份文件**通常不带锁**；拿到它的人，可以在别处把内容恢复出来。

所以放备份文件的地方要自己把关：放在自己的网盘私有目录、自己的邮箱、自己的电脑上，别丢进公共分享或群里。做法见 [备份恢复与换机迁移.md](备份恢复与换机迁移.md)。

如果设完密码之后打不开、提示密码错误，先换一种输入法、并确认没有多敲空格或把全角字符按成半角，再试一次；无论如何**不要卸载重装** —— 卸载会直接清掉本机数据，比忘记密码的损失更大。
