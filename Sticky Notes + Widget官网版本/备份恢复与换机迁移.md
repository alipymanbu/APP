> 便签默认存在手机本机。本篇讲怎么做本地备份、怎么恢复、换手机时怎么把便签带过去。

## 一、先记住一条：便签不会自己跟着你走

这个应用的数据默认保存在手机本地。卸载应用、恢复出厂设置、换手机，本机数据都会丢 —— 除非你事先做过备份。官方功能列表里的对应能力是**本地备份与恢复**，也就是说「备份动作要你自己做」。

因此有两个时间点必须备份：

- **升级应用之前**。官方在 5.0.9 的更新说明里明确提醒过，那次更新可能导致已有便签被永久删除且无法恢复，并建议升级前先保存重要数据。升不升级自己定，但备份要先做。
- **换手机、恢复出厂、大扫除式整理之前**。

## 二、本地备份怎么做

在便签列表的应用设置里找备份相关入口，流程是标准的「导出到手机存储」：

1. 打开应用设置，找到备份 / 导出项；
2. 指定导出位置（应用自行选择或由你选一个文件夹）；
3. 等提示完成，然后**把导出的备份文件复制到手机之外的地方** —— 存进网盘、发到自己的邮箱、拷到电脑都行。

第 3 步是很多人漏掉的一步：备份文件留在手机里，手机丢了或恢复出厂，备份跟着一起没了，等于没备。

备份文件与便签内容一样属于你的私人数据，别放进公共分享。

## 三、恢复怎么做

恢复是在**新装的应用**里做的，顺序别弄反：

1. 先装好同一款应用（安装包见 [下载与安装教程.md](下载与安装教程.md)），**先不要急着新建一堆便签**；
2. 进应用设置，选恢复 / 导入，指向之前导出的备份文件；
3. 等恢复完成，检查便签条数、文件夹结构、手写内容是否都在；
4. 确认没问题之后，再开始正常使用。

两个提醒：

- **恢复通常不会与现有内容合并得很聪明**。如果新机上已经手动记了内容，恢复之后可能出现重复条目，恢复前先决定以哪一份为准。
- **跨版本恢复不保证兼容**。网盘里这份是 4.3.4，如果你是在商店里的新版上做备份、再恢复到旧版，或者反过来，都可能失败。换版本时尽量用同一个版本做备份和恢复。

## 四、换手机的完整顺序

按这个顺序走，出问题的概率最低：

1. **旧手机**：先把便签整理一遍（该删的删、该归档的归档，见 [文件夹分组搜索与回收站.md](文件夹分组搜索与回收站.md)）；
2. **旧手机**：做本地备份，并把备份文件传到手机之外；
3. **旧手机**：确认新手机上能正确恢复之后，再卸载或清空；
4. **新手机**：装同一款应用（版本尽量与旧机一致）；
5. **新手机**：恢复备份，逐项核对便签、文件夹、手写内容；
6. 核对无误后，重新往桌面添加小部件，见 [桌面小部件怎么添加与调整.md](桌面小部件怎么添加与调整.md)。

**不要先卸载旧手机上的应用**。旧手机上的那份是最后的原样数据，新机恢复验证通过之前，它是你的退路。

## 五、在线同步是另一回事

较新版本里还有**在线同步 / 云备份**这一项，商店页面把它写成面向订阅用户的能力。需要注意：

- 它和「本地备份文件」不是同一条路。本地备份是一份你可以自己拿走的文件；在线同步更接近「同一个账号下的多设备共享」，依赖官方服务与账号。
- 网盘里这份 4.3.4 是 2022 年的版本，官方商店现在对 6.x 的描述与它差别很大（6.x 改成了订阅制、并加了在线同步等能力）。**别拿商店新版的介绍来对照你装的老版**，功能项对不上很正常。
- 无论有没有在线同步，**本地导出的备份文件都值得留一份** —— 在线服务会随版本和商务策略变化，自己手里的文件不会。

## 六、备份文件放在哪、要不要演练

存放原则是「至少两处，且都不在同一台手机上」。按成本从低到高：

| 位置 | 说明 |
| --- | --- |
| 自己的网盘私有目录 | 最省事，换手机时能直接在新机上下回来 |
| 发给自己的一封邮件 | 附件留档，不容易被误删；别发到群里或公共分享 |
| 电脑本地 | 断网也能取回，适合放最重要的那一份 |

判断存得够不够到位的标准只有一条：**能不能在不碰旧手机的前提下，从另一个地方把这份备份重新取出来**。取不出来，就等于没备份。

另外建议做一次「备份演练」—— 刚装好、还没开始记东西的时候，直接恢复一次备份，核对便签条数、文件夹结构、手写内容是否都对得上，确认无误再正式用。趁手里没有多少数据时验证，成本最低；等记了几百条才发现恢复不成功，代价就大了。

## 七、备份该多久做一次

没有通用答案，按「丢一次会有多麻烦」来定：

| 便签里放的东西 | 建议频率 |
| --- | --- |
| 临时提醒、用完就删 | 不必定期备份，升级前做一次即可 |
| 工作待办、常用清单 | 每月一次，或在每次大批整理前 |
| 账号信息、长期资料、手写图 | 每次改动后立刻导出，并同时存到手机之外 |

最后一条容易被忽略：**给便签加了密码不会保护备份文件**。备份导出后是一份独立的文件，如果你把它放在别人能碰到的地方，加密设置拦不住它。相关设置见 [便签加密与隐私设置.md](便签加密与隐私设置.md)。
