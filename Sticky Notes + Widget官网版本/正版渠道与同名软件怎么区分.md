# Sticky Notes + Widget 正版渠道与同名软件怎么区分

> 搜「Sticky Notes」会搜出一堆同名软件，其中还包括微软的便笺。本篇讲怎么确认你装的到底是哪一个。

「Sticky Notes」这个名字下面有好几款不同的应用，还有微软的便笺；这款应用自己后来也改过名。本篇给一个不依赖记忆的判断方法 —— 看包名，再把它和同名软件、以及同一开发者的另外两个包区分开。

## 一、最可靠的一招：看包名

应用名字可以重名、可以改，「包名」几乎不会变。在手机上确认的方式：

1. 打开系统「设置」→「应用」（部分机型叫「应用管理」）；
2. 找到这款便签应用，点进「应用信息」；
3. 拉到最下面，看版本号与包名。

本篇讲的是这一款：

| 项目 | 值 |
| --- | --- |
| 包名 | `com.symcoding.widget.stickynotes` |
| 开发者 | SYM Coding |
| 网盘里的版本 | 4.3.4 |
| 安装包体积 | 6.26 MB |

包名对得上，就说明是同一个应用；对不上，就是另一款同名软件，界面和功能都跟本篇讲的没关系。

## 二、这个名字改过

这一款应用**改过名**，所以你在商店里看到的名字可能和标题不一样：

- 早期到 5.x 那一代，商店里的名字是 **Sticky Notes + Widget**；
- 6.x 之后改成了 **WeeNote Notes and Widget**，官方页面与介绍文案也跟着换了。

判断依据仍然是包名 —— 改名前后的包名没有变，因此**桌面上的图标名字、商店里的商品名可能不一致，但它们是同一个应用**。网盘里这份 4.3.4 属于改名前的那一代，装好后显示的也是当时的名字。

## 三、和微软的便笺怎么分

搜「Sticky Notes」时排在前面的常常是**微软 Windows 自带的便笺**。两者的区别：

| | 这一款（SYM Coding） | 微软便笺 |
| --- | --- | --- |
| 跑在哪 | 安卓手机，主打桌面小部件 | Windows 自带；手机上要经 OneNote / 微软账号那条线 |
| 账号 | 不登录也能用 | 跨设备同步依赖微软账号 |
| 装法 | 装一个安装包即可 | Windows 上随系统或从微软商店；手机上是另一套 |
| 怎么认 | 包名 `com.symcoding.widget.stickynotes` | 包名不是这个 |

如果你要的是「手机上放一张便签在桌面」，找的是这一款；如果你要的是「Windows 桌面上那张黄色便签跨设备同步」，那是微软那条线，本篇的安装包对你没用。

## 四、商店里还有几款同名应用

应用商店里以「Sticky Notes」「Sticky Notes Widget」为名的应用有好几款，出自不同开发者。它们和这一款**没有关系**，界面、数据、备份格式都不通用。区分方法还是第二节那一条：看包名和开发者，别只看图标和名字。

## 五、同一个开发者下面有三个包，别装错

| 包 | 是什么 | 要不要装 |
| --- | --- | --- |
| 主应用（Sticky Notes + Widget / 现名 WeeNote） | 便签本体，提供桌面小部件 | 要，本篇讲的就是它 |
| Pro 版 | 同一开发者的另一个包，官方描述里写明是「无广告版本」 | 可选。它与免费版是**两个独立的应用**，两者的便签数据不互通 |
| 主题包（Sticky Notes Theme Stickers） | 给主应用加背景和便签夹样式的小应用 | 可选。官方说明写明它**不是独立应用、必须配合主应用安装**，作用只是给主应用补样式 |

**不要把 Pro 版当升级包直接装上去**：它不会继承免费版里的便签。想换之前先备份。

**某项功能提示要购买 / 授权时**，不要靠反复卸载重装去「试一试」—— 重装既不会恢复购买状态，还会把本机便签一起清掉。顺序应该是：先按 [备份恢复与换机迁移.md](备份恢复与换机迁移.md) 导出备份，再去应用内找「恢复已购项目」这类入口（官方在 5.0.9 的更新说明里就有一条是修复「恢复已购项目」）。而你装的那一版里到底有没有这类付费入口、它和 Pro 版是什么关系，以应用内实际显示为准。

**要不要花钱、有没有广告**：官方给 Pro 版写的卖点是「无广告版本」，从这句话反推，免费版里是带广告位的（这是从官方描述反推，不是官方原话）；商店里现在这一代还改成了先试用、后购买的模式。你装的那一版怎么收费、广告以什么形式出现，打开应用用一次就知道了。

## 六、官方渠道在哪

官方的开发者站点是 [stickynotesbysymcoding.blogspot.com](https://stickynotesbysymcoding.blogspot.com/)，上面按平台（iOS、Android、macOS、Windows 桌面）分别放说明；应用商店页面上也挂着同一个站点与隐私政策页。想确认某个版本、某条功能说明是不是官方的，从这两个入口核对，比看第三方下载站可靠。

第三方下载站上流传的**改造过的安装包不要装**：这类包可能被改动过，也可能带着你没同意的东西，而且它和官方版本的备份互不兼容 —— 出问题时既没人负责，也没法用官方版本恢复你的便签。要装就用本篇开头给出的那份安装文件资源，或者官方商店里那一条。

## 七、顺手对一下版本号

商店页面现在介绍的是 6.x 那一代（订阅制、系统要求提到 Android 11 及以上），而网盘里这份是 2022 年发布的 4.3.4。**两者的功能项和界面并不一样**，别拿商店的介绍来对照手上的老版本，看到「这个功能我没有」很正常。

几类需要留意归属的功能：官方在 6.x 那一代的介绍里提到过**便签定时提醒、在线同步与备份、订阅制**这些能力，而 4.3.4 是 2022 年的版本，**这几项它有没有、以什么形式提供，官方没有单独留档**，本篇也无法核实 —— 打开应用自己看一眼最准：找得到入口就是有，找不到就是这一版没有。

想确认自己装的是哪一版：系统设置 → 应用 → 这款便签应用 → 看版本号是否为 4.3.4。版本升级的注意事项见 [备份恢复与换机迁移.md](备份恢复与换机迁移.md)，安装步骤见 [下载与安装教程.md](下载与安装教程.md)。
