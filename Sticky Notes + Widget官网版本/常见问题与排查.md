# Sticky Notes + Widget 常见问题与排查

装不上、小部件不出现、内容不刷新、忘记密码 —— 这些是这类便签应用最常见的几类毛病。本篇按现象列出排查顺序，并标出哪些动作会连带清掉本机便签，免得为了排查反而丢了数据。

## 一、装不上：解析包错误或提示不兼容

按这个顺序查：

1. **安装包是否完整**。重新下载一次，再对一下 [下载与安装教程.md](下载与安装教程.md) 里给出的 MD5。下到一半的包最容易报「解析包时出现问题」。
2. **系统版本**。5.x 那一代官方标的是 Android 7.0 及以上，现在的 6.x 已提到 Android 11 及以上（以官方页面当时显示为准）。系统过低时提示不兼容，属于正常现象，不是包坏了。
3. **允许安装未知来源应用**。Android 8 及以上是按应用逐个授权的：文件管理器、浏览器、网盘客户端各自都要单独允许一次。
4. **同包名冲突**。手机里已经装过同一个包名（`com.symcoding.widget.stickynotes`）的版本时，系统会要求替换。想装这一份就先卸载旧版 —— 注意卸载会清掉旧版里的便签，先备份。

## 二、小部件列表里找不到这个应用

装好了，但长按桌面 → 小部件里没有它。可以依次试：

- **重启手机后重开一次小部件列表**。新装应用的小部件有时要等桌面刷新一次才会出现在列表里；
- **确认装的应用还在**。被安全软件或系统清理功能卸载后，桌面上残留的小部件是失效状态；
- **确认装的是主应用而不是主题包**。官方另有一个主题包应用，它不提供小部件、必须配合主应用使用，装错了解不了问题；
- **部分系统对第三方小部件有限制**。如果系统本身限制桌面小部件数量或禁止某个应用的小部件，需要在该系统的桌面设置里放开。

## 三、小部件加上去了，却是空白 / 点不开

先分清两种情况：

| 现象 | 怎么处理 |
| --- | --- |
| 小部件空着但应用里能看到那条便签 | 小部件可能绑定了错误的便签，长按小部件重新选择要显示的便签 |
| 应用里那条便签也不见了 | 多半是被删掉了，去回收站找，见 [文件夹分组搜索与回收站.md](文件夹分组搜索与回收站.md) |
| 小部件一放上去就空白，应用里本来就没内容 | 先建一条便签，再把小部件绑到它上面 |

排查时**不要先把应用卸载重装**：卸载会连本机便签一起清掉，而问题很可能只是小部件绑定关系错了。

## 四、改了便签，桌面上的小部件没变

先确认「改的是不是桌面上那一条」，这一步能解决大部分误会：

1. 切到应用里确认改动已经保存（退出编辑状态）；
2. 核对桌面上那个小部件绑定的确实是这条便签 —— 多条便签长得像时经常认错；
3. 回桌面等几秒，或把桌面划到别的页再划回来。

三步都没用，或者小部件是过一段时间后「自己不刷新了」，那不属于「改了没变」这一类，按 [桌面小部件不刷新怎么解决.md](桌面小部件不刷新怎么解决.md) 对号处理。

## 五、字显示不全 / 划不动

小部件的显示区域是固定的，内容超了就要靠**小部件内滚动**看后面的部分。如果滑不动：

- 先把小部件拉大一点再试，太小的小部件有时收不到滑动；
- 检查是不是被桌面的翻页手势抢走了 —— 在小部件正中间上下滑，而不是从屏幕边缘起手；
- 仍然不行，说明这条内容对这个尺寸来说太长，要么删减，要么换更大的小部件样式。

## 六、小部件里的字体和我设置的不一样

**这是官方自己标注过的限制**：桌面小部件里文字较长时，会回退成默认字体显示。也就是说你在便签里选的特殊字体，在短文本的小部件上能体现，长文本的小部件上看不到。

能做的只有：把要强调字体的内容写短，或者接受小部件用默认字体、只让应用内页面保持你选的字体。这不是设置没保存。

## 七、忘记密码打不开便签

这类本地锁没有常规的找回途径。有未加密的旧备份时，可以靠恢复备份拿回内容（备份会把密码设置一起带回当时的状态）；没有备份就没有别的办法。具体见 [便签加密与隐私设置.md](便签加密与隐私设置.md)。输入法把全角字符当半角、或多按了一个空格，也会表现为「密码错误」，先换一种输入方式试一次再下结论。

## 八、升级之后便签不见了

官方在 5.0.9 的更新说明里提醒过，那次更新可能导致已有便签被永久删除且无法恢复，并建议升级前先保存重要数据。遇到升级后内容缺失：

- 先在应用里确认不是被移进了回收站或换到了别的文件夹；
- 有升级前的备份就恢复它，见 [备份恢复与换机迁移.md](备份恢复与换机迁移.md)；
- 没有备份，只能接受这部分内容丢失 —— 这也是为什么升级前要先备份。

## 九、桌面变卡、耗电变多

桌面上的小部件是持续刷新的，**小部件数量直接决定代价**。几件可以立刻做的事：

- 把桌面小部件数减到真正需要的那几条，其余便签留在应用列表里；
- 每条小部件只保留当前要看的便签，不用的移掉（移掉小部件不会删便签）；
- 长文本便签少放小部件，避免频繁滚动渲染。

如果只是某一台手机上明显异常，先在系统设置里看是哪个应用在耗电，再决定要不要调整。小部件被系统限制后反复失效的排查，见 [桌面小部件不刷新怎么解决.md](桌面小部件不刷新怎么解决.md)。

## 十、卸载之前一定要知道的事

**卸载应用会连同本机便签数据一起删除**，回收站里的内容也在其中。要卸载、要换机、要恢复出厂，顺序都是：先备份并确认备份文件已经存到手机之外，再动手。见 [备份恢复与换机迁移.md](备份恢复与换机迁移.md)。

其余使用问题（分组、外观、加密码）分别见 [文件夹分组搜索与回收站.md](文件夹分组搜索与回收站.md)、[手写涂鸦与便签外观怎么设.md](手写涂鸦与便签外观怎么设.md)、[便签加密与隐私设置.md](便签加密与隐私设置.md)。
