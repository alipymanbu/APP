## 一、安装包是哪一份

网盘里放的是安卓版安装包，安装前先核对一下这几项，确认下到的是同一个文件：

| 项目 | 值 |
| --- | --- |
| 应用名 | Sticky Notes + Widget |
| 版本 | 4.3.4 |
| 包名 | `com.symcoding.widget.stickynotes` |
| 安装包体积 | 6.26 MB |
| MD5 | `5A3B0F601CEBF7F8964CEA35C46DA5F9` |

版本号这一栏要特别注意：网上能搜到的官方最新版已经是 6.x，和网盘里这份 4.3.4 不是同一个版本。应用商店里的介绍、截图、功能清单都是按最新版写的，装完之后如果发现某个功能名字对不上，先看是不是版本差异，而不是包有问题。安装包在这里转存后下载：**Sticky Notes + Widget 安装文件资源（夸克网盘）** —— [https://pan.quark.cn/s/7b9ef7719888](https://pan.quark.cn/s/7b9ef7719888)。

## 二、装到手机上

1. 在手机上打开网盘里的分享链接，把安装包转存到自己的网盘，再下载到手机本地（夸克的分享页通常要求先转存再下载，直接点下载有时会失败）。
2. 打开手机的「文件管理」，找到刚下好的 `.apk` 文件点击安装。
3. 系统会弹出「是否允许安装未知来源的应用」，允许当前这个文件管理器或浏览器安装应用即可。这一步在 Android 8 及以上是逐应用授权的，装完可以关回去。
4. 如果手机装了安全类软件，它可能提示「该应用未经验证」，选择继续安装。

安装过程中不需要注册账号，也不需要登录，装完点「打开」就能进主界面。

## 三、第一次打开会看到什么

打开后是一个便签列表页，此时桌面上什么都没有 —— 这是最容易让人以为「装错了」的地方。Sticky Notes + Widget 的便签要**你自己手动放到桌面**才会出现，加小部件的步骤见 [桌面小部件怎么添加与调整.md](桌面小部件怎么添加与调整.md)。

首次进入建议先做两件事：

- 新建一条测试便签，随便写点字，确认打字和保存正常；
- 把这条便签放到桌面，确认小部件能正常显示，再正式记东西。

先验证再使用，比先记一堆然后发现桌面显示不出来要省事。

## 四、系统要求

官方商店对不同代的版本标的门槛不一样：5.x 那一代标的是 Android 7.0 及以上，现在的 6.x 已经提到 Android 11 及以上（以官方页面当时显示为准）。**4.3.4 这一版的最低系统版本官方没有单独公布**，所以这里不给具体数字，只给参考：它发布得比 5.x 更早，门槛不会比上面那个更高。你手机实际能不能装，以安装时的系统提示为准 —— 如果提示「应用与你的手机不兼容」或解析安装包出错，多半是系统版本低于该包要求，或安装包在下载过程中损坏（可以用第一节的 MD5 对一下）。

## 五、装完之后的几个注意点

- **别急着装完就升级**：商店里的新版和网盘里这份差别很大，升上去之后界面与功能都会变。官方在 5.0.9 的更新说明里明确提醒过，那次更新可能导致已有便签被永久删除、无法恢复，并建议升级前先保存重要数据。要不要升级自己决定，升之前先按 [备份恢复与换机迁移.md](备份恢复与换机迁移.md) 做一次备份。
- **换手机时先备份再迁移**：便签默认存在本机，直接换机不会跟着走，迁移方法见 [备份恢复与换机迁移.md](备份恢复与换机迁移.md)。
- **同一个包名只能装一个**：如果手机里已经装过同包名的版本（比如从商店装的），装这一份时会提示替换或冲突，先卸载旧的再装，或者干脆继续用旧的那份。
- 卸载应用会连带清掉本机的便签数据，卸载前务必先备份。

## 六、和「微软便笺」不是同一个软件

搜「Sticky Notes」很容易搜到微软 Windows 自带的便笺，那是另一套完全不同的东西，和本篇讲的这个应用没有关系。判断方法、以及这个应用改名后的官方名称，见 [正版渠道与同名软件怎么区分.md](正版渠道与同名软件怎么区分.md)。

安装完加小部件时如果桌面列表里找不到它，按 [常见问题与排查.md](常见问题与排查.md) 里的顺序排查。
