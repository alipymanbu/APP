Microsoft Authenticator（中文常写作「微软身份验证器」）是微软出的手机两步验证应用，把各网站的 6 位动态口令和微软账号的登录批准集中放在一部手机上。本篇只解决第一步：把网盘里这份 6.2503.1892 装好，并弄清装完要做什么。

## 一、先核对网盘里这份包是哪一版

网上搜到的多是官方当前最新版，和网盘里这份常常不是同一个版本号。本篇出现的版本、包名、体积一律以下表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | Microsoft Authenticator |
| 版本号 | 6.2503.1892 |
| 包名 | `com.azure.authenticator` |
| 安装包体积 | 101.94 MB |
| MD5 | `AB7A5020FDD95E3EC6B10CECB261BF34` |
| 开发者 | Microsoft Corporation |
| 收费情况 | 免费，无内购解锁项 |
| 形态 | 手机应用，只有 Android 与 iOS 版，没有电脑版 |
| 核对时间 | 2026-09-23 |

安装包本体在 [Microsoft Authenticator 安装文件资源（夸克网盘）](https://pan.quark.cn/s/e2bb2384bd23) 里，转存到自己的网盘再下载到手机。

几点要分清：

- **认版本看包名**：手机里如果同时有别的验证器，最容易混的是「Google Authenticator」——两者图标和名字都带 Authenticator，但包名完全不同。想确认手上这份是微软的，看包名 `com.azure.authenticator` 最快。
- **版本会往前走**：6.2503.1892 之后官方还会继续发新版，具体哪天是哪一版以官方发布页当时显示的为准。本文按 6.2503.1892 写，个别菜单位置在新版里可能不同。
- **体积对不上就是没下完**：101.94 MB 上下才对；明显偏小说明传输中断，重新下一遍更省事。
- **MD5 怎么用**：下载完用文件管理器看文件详情，或找任意校验工具算一次 MD5，与上表一致说明文件没损坏。

## 二、官方渠道在哪，国内怎么装

| 渠道 | 说明 |
| --- | --- |
| [官网产品页](https://www.microsoft.com/authenticator) | 官方的介绍与下载入口，两个平台的商店链接都在这里 |
| [官方支持页](https://support.microsoft.com/zh-cn/authenticator) | 账号添加、备份恢复、故障排查的官方说明都在这套页面下 |
| Google Play 商店 | 官方主推的安卓渠道 |
| Apple App Store | iOS 渠道 |
| 联想 / OPPO / 三星应用商店 | 官方为**中国用户**单独列出的安卓渠道 |

中国用户这一条要单独看：官方在其《在中国下载 Microsoft Authenticator》一文中明确写了两件事 —— **Google Play 商店在中国不可用**，所以国内安卓机只能从联想、OPPO、三星这三家应用商店装；同时**中国区只提供有限的身份验证方式**，具体哪些能用见 [常见问题与排查.md](常见问题与排查.md)。同页还有一句免责：官方会尽量让各商店版本保持最新，但不对其他网站上的版本负责。

拿不到上述商店、或商店版本偏低时，网盘里这份安装包是另一条路，装法见下一节。

## 三、安装步骤

1. 把安装包下载到手机。在电脑上下载的话，用数据线或任意传输工具拷进手机存储都可以。
2. **允许安装未知来源应用**：在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给用来打开安装包的那个应用（文件管理器或浏览器）打开开关。国产定制系统常把这一项收在「安全」「隐私」「更多安全设置」下面。
3. **点开 APK 完成安装**：系统提示「应用未经过安全检测」时选继续安装，这是从商店以外装包的常规提示。
4. **装完先别急着扫码**：这个应用不需要登录就能用，但要先加一个账号进去才会有码，见 [添加账户与绑定验证码.md](添加账户与绑定验证码.md)。

安装被拦下时，不同提示对应的情况不一样，按这张表对：

| 系统提示 | 原因 | 处理 |
| --- | --- | --- |
| 解析包错误 | 下载不完整或文件损坏 | 重新下载，下完核对体积是不是 101.94 MB、MD5 是否与上表一致 |
| 应用未安装 | 手机上已有同包名但签名不同的版本 | 先卸载旧版再装。**卸载前先确认旧版里的账号能从别处恢复**，否则码会一起丢 |
| 已阻止安装 / 安全提示 | 未知来源开关没打开 | 回到第 2 步，给打开安装包的那个应用开权限 |
| 装完图标找不到 | 被系统收进了「工具箱」或抽屉页 | 在桌面下拉搜索里输 Authenticator 找 |

**关于系统版本**：官方商店页会标注当版的最低系统要求，这个门槛会随版本推进抬高。2025 年下半年起，Android 8.0 的机器在商店里已经显示为不兼容（来自 Microsoft 问答区的用户反馈），更老的系统更不用试。装之前先看商店页当时写的门槛，别照抄网上几年前的说法。

## 四、第一次打开要做什么

首次启动是几屏说明页，进度很浅，但有两件事别漏：

1. **把应用锁打开**。设置里有应用锁开关，打开后每次进入都要用设备 PIN 或指纹/面容验证一次，批准登录通知时同样会要求。这一步建议在加账号之前就做掉。
2. **顺手看一眼通知开关**。设置 → 通知设置，确认「显示通知」是开的。微软账号的登录批准靠推送，这项关了就只剩手动输码这条路，排查步骤见 [批准登录通知没反应怎么排查.md](批准登录通知没反应怎么排查.md)。

## 五、装完做一次最小验证

1. 挑一个已经在用的账号（主邮箱最合适），按 [添加账户与绑定验证码.md](添加账户与绑定验证码.md) 把账号加进来；
2. 退出登录再登一次，用 Microsoft Authenticator 当前显示的 6 位码完整走一遍登录；
3. 登录通过后，**立刻去开云备份** —— 安卓端的备份是免费开的，别等丢手机那天才想起来，路径见 [换手机与备份恢复.md](换手机与备份恢复.md)。

三项都过了，说明这份包装得没问题。第 2 步出现「你未输入预期的验证码」，先看 [验证码不对怎么办.md](验证码不对怎么办.md)。
