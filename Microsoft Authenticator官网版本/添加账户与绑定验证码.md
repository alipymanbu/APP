# Microsoft Authenticator 添加账户与绑定验证码

Microsoft Authenticator 能装的不止微软账号：个人 Microsoft 账号、工作或学校账号，以及 Amazon、Facebook、Instagram、Google 这类第三方账号都能放进来。本篇按账号类型拆开写，并补上「扫码扫不上」时的手动录入口径。

## 一、先决定让它干什么

官方把用法分成三种，加账号之前先想清楚要哪一种，后面的设置入口不一样：

| 用法 | 登录时你要做的 | 适合谁 | 在哪开 |
| --- | --- | --- | --- |
| 验证登录的一种方式 | 忘了密码时用它验证身份 | 想留条后路、但平时仍用密码 | [account.microsoft.com/security](https://account.microsoft.com/security) |
| 每次登录的方式（两步验证） | 除密码外再输一次 6 位码或点批准 | 大多数人的默认选择 | 同上，找「两步验证」区 |
| 唯一的登录方式（无密码） | 只在手机上点一下批准 | 不想再输密码 | 同上，找「无密码帐户」区 |

三种可以叠加，但顺序建议是「先开验证登录 → 确认码能对上 → 再升级成两步验证或无密码」。一上来就设成唯一方式，万一这台手机出问题，账号会很难进，具体见 [无密码登录与通行密钥.md](无密码登录与通行密钥.md)。

## 二、添加个人 Microsoft 账号

以「每次登录的方式」为例，全程在两个地方之间来回：电脑上的账号安全页、手机上的 Authenticator。

1. 电脑浏览器打开 [account.microsoft.com/security](https://account.microsoft.com/security)，登录要加的那个账号；
2. 选「管理我的登录方式」，再选「添加新的登录或验证方式」；
3. 选「使用应用」。这个页面上还有一个「设置其他 Authenticator 应用」的入口，选它再点「下一步」，才会显示出二维码；
4. 手机上打开 Authenticator，点右上角的加号；
5. 选「个人帐户」，再点「扫描 QR 码」，对着电脑屏幕扫；
6. 扫完按提示在当前设备上批准一次，整个流程才算闭环。

**扫不上的情况**：官方给了兜底入口 —— 在电脑那一侧点「我无法扫描 PC 上的条形码」，然后选「在移动设备上手动输入代码」，屏幕上会显示一组密钥和账号名，照着在手机里填。手动录入时最容易错的是密钥里的字符（`0` 与 `O`、`1` 与 `I`），一位错整个码就全废。

## 三、添加工作或学校账号

这条路走的是安全信息页，和上面的账号安全页不是同一个入口：

1. 浏览器打开 [mysignins.microsoft.com/security-info](https://mysignins.microsoft.com/security-info)，登录组织给的账号；
2. 选「添加登录方法」，下拉里选「Microsoft Authenticator」，点「添加」；
3. 手机上如果已经装了 Authenticator，选「下一步」就能看到二维码；
4. 手机上点加号 →「添加账户」→「工作或学校帐户」，扫码；
5. 按组织要求再验证一次。

两个会卡住的地方：

- **看不到「安全信息」页**：官方给的绕法是去「其他安全验证」，勾上 Authenticator 应用旁边的复选框，再点「配置」，二维码就会出来。
- **能不能点批准，不由你定**：工作或学校账号的一键批准开关在 IT 管理员手里，他关掉之后你只能手动输 6 位码。这不是应用坏了。

## 四、添加第三方账号（Amazon、Facebook、Google 等）

第三方账号没有推送批准，只有 6 位动态码，所以流程是「在对方的账号里开启两步验证 → 把二维码给 Authenticator 扫」。

1. 在目标网站/应用的账号设置里找到两步验证（有的叫双重验证、双因素认证）并开启；
2. 它一般会给你两条路：装它自家的应用，或用「其他验证器应用」。**选后者**，页面会显示二维码；
3. 打开 Authenticator → 加号 →「其他帐户」；
4. 用手机相机扫这个二维码（在 Authenticator 里扫和用系统相机扫都可以）；
5. 该网站通常会让你立刻回填一个当前显示的 6 位码来确认绑定成功。

**第三方账号没有手动输入密钥怎么找**：二维码页面下面常有一行「无法扫描？手动输入密钥」，点开就有那串密钥。如果对方只给二维码、不给密钥，那就只能用相机扫，扫不了只能换设备或截图后再扫。

## 五、加进来之后：改名与查找

账号多了以后，列表里会堆成一片，两件事值得花一分钟做：

- **改名**：长按或点开账号可以编辑名称。官方专门提示过 —— 新加的账号如果和已有账号同名，可以改掉新加的那个名字再继续。同类账号（三个 Google、两个公司邮箱）建议在名字里带上用途，比如「工作邮箱-财务」。
- **按名搜索**：账号列表上方有搜索框，按名字过滤比上下滚快得多。

## 六、加账号时常见的几种卡法

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 「QR 扫描不起作用」 | 版本过旧，官方明确要求用最新版才能添加账号 | 更新到当前最新版再试；商店装不上的机型可参考 [下载与安装教程.md](下载与安装教程.md) |
| 「你尝试添加的帐户暂时无效」 | 对方的服务侧状态不对，或这组凭据已失效 | 回对方网站重启一次两步验证，重新生成二维码 |
| 「抱歉，仅部分设置已成功完成」 | 绑定只做了一半 | 回安全信息页看这条方法在不在；不在就删掉重加一次 |
| 添加后码马上能用，但对方网站不认 | 手机时间漂了 | 见 [验证码不对怎么办.md](验证码不对怎么办.md) |
| 加完账号列表里是灰色的 | 账号需要进一步验证 | 点开这个账号，按提示补登录或补验证 |

加完账号后如果一直收不到登录批准，先看 [批准登录通知没反应怎么排查.md](批准登录通知没反应怎么排查.md)，别急着删账号重来。
