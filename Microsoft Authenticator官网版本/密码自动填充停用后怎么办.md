# Microsoft Authenticator 密码自动填充停用后怎么办

> 2025 年下半年起，自动填充已经在 Authenticator 里停掉，保存的密码和地址转去了 Edge，付款信息被删除。本篇给时间线和替代做法。

如果你以前用 Authenticator 顺手存过网页密码，打开应用却发现这部分入口没了 —— 这不是版本装错，是官方主动下线了这个功能。本篇把时间线、数据去向和替代路径一次说清，省得以为自己的密码丢了。

## 一、停用时间线

按官方支持页写的节点：

| 时间 | 变化 |
| --- | --- |
| 2025 年 5 月 | 应用内弹出通知，告知这次变更 |
| 2025 年 6 月 | 停止在 Authenticator 里**添加或导入**新密码 |
| 2025 年 7 月 | Authenticator 的**自动填充功能停止工作** |
| 2025 年 8 月中旬 | 已保存的个人信息**在 Authenticator 里不再可访问** |

注意节奏是先「不能再加新的」，再「不能再自动填」，最后「看不到已存的」。所以在那几个月里出现「填不上去了」是符合预期的，不用担心是自己操作坏的。

## 二、密码和地址去哪了

**它们没有丢，是转到了 Microsoft Edge。**

- 密码和地址会安全地同步到你的 Microsoft 帐户，在 Edge 里跨设备可用；
- 官方明确说明：**生成的密码历史记录没有保留**；
- 也就是说，只要在 Edge 里登录同一个 Microsoft 帐户，就能看到、管理原来的那些密码。

**付款信息是另一回事：被删了。**

- 出于安全原因，存在 Authenticator 里的付款信息已被删除，无法再访问；
- 官方解释付款信息本来就只存在创建它的那台设备上、不参与同步；
- 2025 年 7 月之后，设备上存的付款信息会被清掉；**需要手动重建**。

对绝大多数人来说，需要重建的就是购物网站里存的那几张卡，逐个网站重记一次即可。

## 三、想让 Edge 接着自动填充

在手机上把 Edge 设成自动填充提供程序：

1. 在手机上装 Microsoft Edge；
2. 打开 Edge，用同一个 Microsoft 帐户登录；
3. 进手机「设置 → 通用（或常规）」；
4. 找「自动填充与密码」；
5. 在「自动填充来源」一栏里选 **Edge**。

设置完成后，密码与地址由 Edge 提供自动填充。工作或学校账号另有一步：

- 如果给工作或学校账号设过**通行密钥**，要在设备设置的「自动填充 → 其他服务」里**打开 Authenticator 的开关**，否则通行密钥会一起被禁用。这一点和 [无密码登录与通行密钥.md](无密码登录与通行密钥.md) 里那条提醒是同一个原因。

## 四、想改用别的密码管理器

不想继续用 Edge 的，官方给的路径是「先把密码从 Edge 导出成 CSV，再导入别的管理器」：

1. 在偏好使用的管理器里把它设为系统默认的自动填充提供程序（在手机设置的自动填充项里改）；
2. 在 Edge 里导出保存的密码，得到一份 CSV 文件（导出方法见 Microsoft 支持页）；
3. 把这份 CSV 导入新的密码管理器。

**安全提示**：导出的 CSV 是**明文密码表**，里面有账号和密码原文。导入完成后立刻删掉这份文件，别让它躺在下载目录或聊天记录里。

## 五、还有哪些东西没受影响

这一节是为了避免误判「整个应用都被砍了」：

| 功能 | 现状 |
| --- | --- |
| 6 位一次性验证码 | 照常用 |
| 微软账号的登录批准通知 | 照常用 |
| 第三方账号（Google、Facebook、Amazon 等）的验证码 | 照常用 |
| 通行密钥（Entra 密钥） | **继续支持** |
| 密码与地址的自动填充 | 已停用，转 Edge |
| 付款信息 | 已删除，需手动重建 |
| 生成的密码历史 | 未保留 |

所以这个应用的核心用途 —— 出验证码和批准登录 —— 完全没变，只是不再兼任密码管理器。验证码相关的用法仍按 [添加账户与绑定验证码.md](添加账户与绑定验证码.md) 走。

## 六、两条要留意的边界

- **导入旧密码这件事没有回头路**：官方在 2025 年 6 月就停掉了「添加或导入新密码」，所以别指望把 Edge 里的密码再导回 Authenticator，方向只能是往外导。
- **时间点会继续变**：这批变更涉及 Edge 与系统自动填充设置，各平台入口名称可能调整，具体以官方支持页当时显示的为准。若以后备份方式也有调整（例如 2027 年 1 月起备份改用 Google One），一并参考 [换手机与备份恢复.md](换手机与备份恢复.md)。
