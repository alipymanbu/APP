# Microsoft Authenticator 怎么删除账号与注销

> 只删一个账号、清空全部、还是只想关掉某种登录方式 —— 三种需求的路径不同，而且删本地账号并不等于解除服务器上的注册。

不再用这个应用、或者要把某台设备彻底从验证体系里摘掉时，删东西的顺序有讲究：删了账号就用不了设备验证登录，清数据没有撤销，而删掉手机上的账号也不代表服务器那边解除了注册。本篇按三种实际需求分开写。

## 一、只删一个账号

1. 打开 Authenticator，点开要删的那个账号；
2. 点「设置」；
3. 点「删除帐户」。

官方在这条后面补了一句要紧的：**删除账号后，你将无法使用设备验证登录**。也就是说这个账号在这台手机上从此不再产生验证码、也不再接收批准请求。以后想加回来，得回账号的安全信息页重新绑定一次，见 [添加账户与绑定验证码.md](添加账户与绑定验证码.md)。

## 二、清空全部账号（等同于注销）

官方给的做法就是清应用数据：

- **Android**：系统「设置」→「应用」→ Authenticator →「存储」或「存储和缓存」→「清除数据」→ 确定；
- **iOS**：系统「设置」→「通用」→「存储」→ 在应用列表里选 Authenticator →「卸载应用程序」。

两步后面官方都加了同一句提醒：**没有撤销。所有账号都会被删除，并且你将无法使用设备验证登录。**

**注意别点错**：安卓上「清除缓存」和「清除数据」是两回事。缓存随便清，删的是临时数据；数据一清，账号全没。

## 三、全清之前先想清楚两件事

1. **要不要先留一份备份**：清完想恢复，只能靠云备份的还原入口，而那个入口要求设备上**先没有任何账号**才会出现 —— 具体见 [换手机与备份恢复.md](换手机与备份恢复.md)。从没开过备份的话，清掉就等于永久失去；
2. **这些账号还有没有别的登录路径**：至少确认备用邮箱、手机号或另一台设备里有一条可用，再动手。把它当作动手前的最后一道检查。

## 四、删本地账号不等于解除服务器上的注册

这一点最容易被忽略：**删掉手机上的账号，服务器那边仍可能认为这台设备可以批准登录**，推送还会继续往这里发 —— 这也是很多人换了手机之后「通知一直跑到旧手机」的根因。

要把这台设备真正摘掉，得在服务器侧操作：

- **个人 Microsoft 账号**：到 [account.microsoft.com/security](https://account.microsoft.com/security) 的两步验证区域，关闭旧设备的验证；
- **工作或学校账号**：到 [myapps.microsoft.com](https://myapps.microsoft.com) 或所在组织的公司门户做同样操作。

两端的完整步骤见 [批准登录通知没反应怎么排查.md](批准登录通知没反应怎么排查.md)。

## 五、只关掉「无密码登录」，不删账号

只是不想再用「手机上点一下批准」这套，不用删账号：

1. 打开 [account.microsoft.com/security](https://account.microsoft.com/security)，登录账号；
2. 选「管理我的登录方式」；
3. 找到「无密码帐户」区域，把该功能关掉。

关掉之后密码方式仍照常用，验证器里的账号也不受影响。**工作或学校账号的这个开关在组织手里**，个人改不动就找 IT。这条功能本身怎么用见 [无密码登录与通行密钥.md](无密码登录与通行密钥.md)。

## 六、连云备份一起清掉

想连备份也一并删除：Authenticator →「设置」→「备份」→ 关掉「云备份」开关 → 确定。之后要重新开始备份，再打开开关，选「继续」或「更改账户」登录一次即可。

## 七、清完还想用：当作新装机走一遍

按「装包 → 加账号 → 开应用锁 → 开云备份」这个顺序来，前两步见 [下载与安装教程.md](下载与安装教程.md) 与 [添加账户与绑定验证码.md](添加账户与绑定验证码.md)。

有一个坑要提醒：清数据之后重新打开应用，开屏页会有一个「**从备份还原**」入口 —— **如果你并不想恢复旧数据，别点它**，选了它会用备份里的账号覆盖当前空白状态。
