前面几篇各自讲透了安装、绑定、通知、验证码、换机这几件事，这一篇收的是零散但高频的问题：联网要求、平台限制、应用锁、权限、中国区可用范围，以及几条错误消息该怎么读。

## 一、它到底要不要联网

| 用途 | 联网 |
| --- | --- |
| 显示 6 位动态验证码 | 不需要。不联网、没插卡也能出码 |
| 接收并回复登录批准 | 需要。设备和服务器之间的请求要走网络 |

官方还提到一句实际感受：应用关掉就停止运行，所以也不占后台电。**所以出门在外没信号时，码照样能用，只是收不到点批准那种请求。**

## 二、为什么没有电脑版

官方在其常见问题里明确说明：Microsoft Authenticator **不提供 Windows 或 Mac 版本**，桌面端只有网页版的管理入口。想在小屏幕上管理账号，还是得用手机。

这也带来一个实际约束：**手机是这套验证的载体，换了手机、手机坏了都会影响登录**。所以备用验证方式和备份方法值得提前配好，见 [换手机与备份恢复.md](换手机与备份恢复.md)。

## 三、应用锁怎么开

应用锁是这个应用里最值得开的一个开关：

1. 打开 Authenticator，进「设置」；
2. 找到「应用锁」并打开；
3. 按系统提示确认用设备 PIN 或生物识别。

打开之后的行为是：

- 每次进入应用都要验证一次；
- **批准登录通知时也会要求验证** —— 这正是它防「别人拿你手机点批准」的关键作用。

如果在设备上设过锁屏密码，应用锁一般会直接跟着用那套凭据。**用了工作配置文件的话**，官方提示过：常规安全的生物识别不一定延续到工作配置文件里，需要在工作配置文件里单独登记一次生物识别，否则会只让输 PIN。

## 四、通知和账号类型

不是所有账号都能收登录批准：

- **Microsoft 个人账号**：可以；
- **工作或学校账号**：可以，但开关在组织手里，可能被关掉；
- **第三方账号（Google、Facebook 等）**：**没有**批准通知，只有 6 位码；
- **中国区的账号**：没有推送批准，只有验证码方式（见第六节）。

收不到通知时按 [批准登录通知没反应怎么排查.md](批准登录通知没反应怎么排查.md) 的顺序查，先确认账号类型本身支不支持推送。**反过来**，如果收到的是你根本没发起的批准请求，一律点拒绝、不要批准，处理顺序见 [收到不是自己发起的登录请求怎么办.md](收到不是自己发起的登录请求怎么办.md)。

## 五、手表和位置权限

- **智能手表**：Apple Watch 和 Android 穿戴设备**目前不能直接跑这个应用的安全功能**，但可以把手机上的通知镜像到手表上，等于多一个提醒入口，批准仍要在手机上做。
- **为什么它要位置权限**：这不是应用自己要的 —— 当组织配置了「按所在地限制资源访问」的策略时，会要求你每隔一小时共享一次位置，用来确认你仍在允许的国家/地区内。**没有这类策略的账号不会遇到这个提示**（iOS 侧官方建议给「始终允许」，免得每小时手工确认一次）。

## 六、中国区能用到哪些功能

官方《在中国下载 Microsoft Authenticator》页面给的对照如下（Android 与 iOS 大体一致）：

| 功能 | 在中国是否支持 |
| --- | --- |
| 用推送通知做多重身份验证 | 不支持 |
| 用一次性密码做多重身份验证 | 支持（验证码有效期 30 秒） |
| 通行密钥 | 不支持（不适用于由世纪互联运营的 Microsoft Azure） |
| 其他功能 | 支持 |

两点补充：

1. 中国区装安卓版**不能走 Google Play**（官方说该商店在中国不可用），只能从联想、OPPO、三星的应用商店装，详见 [下载与安装教程.md](下载与安装教程.md)；
2. 官方说明：想给工作或学校账号用验证码方式，需要 IT 管理员在「身份验证方法」里启用 Microsoft Authenticator。

这些支持范围会随官方政策调整，**以官方页面当时显示的为准**。

## 七、几条错误消息怎么读

| 消息 | 含义 | 怎么处理 |
| --- | --- | --- |
| 你的设备已越狱 / 已被 root | 账号策略不允许在不安全设备上使用 | 换一台未改动的设备；这是策略限制，绕过不是正当做法 |
| 启用推送通知以接收警报 / 请确保在设置中启用了推送通知 | 推送权限没给到位 | 核对系统通知权限与应用内通知设置两项 |
| Google Play 服务当前在此设备上不可用 | 设备缺 Google 服务框架 | 改用验证码方式；国内渠道装的机器常遇到这一条 |
| 你尝试添加的帐户暂时无效 | 对方服务侧的状态或这组凭据已失效 | 回对方网站重新生成一次绑定 |
| 抱歉，仅部分设置已成功完成 | 绑定做了一半 | 到安全信息页确认方法是否已加上，没有就删掉重加 |
| 此时无法完成登录 | 一次性失败，原因面较宽 | 先按网络、时间、版本这三项自查 |
| 登录被拒绝 | 请求被拒或已失效 | 重新发起一次登录；若非本人发起的请求，改密码，顺序见 [收到不是自己发起的登录请求怎么办.md](收到不是自己发起的登录请求怎么办.md) |

## 八、两条版本相关的硬规则

1. **添加账号必须用最新版**：官方明确写了这一点 —— 版本旧了连扫码都可能失败。
2. **官方不支持超过一年的版本**：设置里有「应用更新」开关，建议保持打开；商店里能更新就更新。

装不上的机型、或商店拿不到包的情况，仍可参考 [下载与安装教程.md](下载与安装教程.md) 里的网盘安装文件资源。已经存过密码、发现自动填充用不了的，直接看 [密码自动填充停用后怎么办.md](密码自动填充停用后怎么办.md)。
