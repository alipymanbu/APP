# Microsoft Authenticator 收到不是自己发起的登录请求怎么办

> 手机上突然弹出你没发起的登录批准，说明有人正拿着你的用户名撞密码。本篇讲清哪些请求必须一律拒绝、怎么查这次尝试有没有成功、以及误点了批准之后的补救顺序。

连着收到几条批准请求、而你根本没在登录，这不是应用抽风，是有人拿到了你的用户名在试。好消息是：**这套机制的作用正是把这类尝试挡在门外**，只要你不动手，对方进不来。本篇按「先挡、再查、后加固、最后补救」的顺序写。

## 一、先分清三类不请自来的东西

| 现象 | 官方给出的常见原因 | 你要做什么 |
| --- | --- | --- |
| 没发起过的批准请求 | 有人在用你的正确用户名配错误密码尝试登录；或别人把邮箱/手机号输错到了你的账号上；或你**之前**那次请求延迟送达 | 一律拒绝 |
| 没请求过的验证码 | 同上三种 | 不要回应 |
| 账号页面提示异常活动 | 系统已识别出可疑登录 | 按页面提示处理，见第三节 |

第三类里的「延迟送达」值得留意一下：如果你几分钟前确实登录过某处、只是提示晚到了，那属于正常现象，不是被攻击。分不清时就看第三节的活动记录，那里能直接看出到底有没有人真的在试。

## 二、守住一条：不请自来的，一律拒绝

官方口径很明确：**对任何不是自己发起的登录请求，一律选拒绝；对没请求过的验证码，不要回应**。只要你不给出正确响应，攻击者就是进不去账号的 —— 这套保护的设计前提正是「你不动手」。

所以最要紧的一条是：**别出于好奇或手滑点批准**。同时也要清楚，反复出现提示本身不等于账号已经被攻破，别被吓到去乱改设置。

## 三、查这一次有没有成功

拒绝之后，去活动记录里确认一下有没有漏网的：

1. **个人账号**：打开 [account.microsoft.com/security](https://account.microsoft.com/security)，选「查看活动」，能看到最近约 30 天的登录记录，含设备、应用与地点；
2. **工作或学校账号**：登录「我的账户」，看「最近活动」；
3. **逐条筛选陌生项**：重点看不认识的地点、设备型号、浏览器或应用；
4. **按页面分区处理**：
   - 记录出现在「异常活动」下 → 展开它，选「这不是我」；
   - 记录出现在「最近活动」下但明显不是你 → 展开它，选「保护你的帐户」；
   这两个按钮都会把你带进后续的加固流程。
5. **位置不准是正常的**：移动网络、代理、企业出口都会让定位显示成别的城市甚至别的国家。别只看位置就下结论，要把设备、浏览器、应用三项合起来判断。

## 四、不管有没有成功，先把账号加固一遍

1. **改密码**：换成一个只在这个站用、别处不复用的强密码，并且**从一台你认为干净的设备上改**；
2. **检查安全信息**：电话号码、备用邮箱、登录方式逐条核对，**不认识的直接删掉**；
3. **补齐第二条独立的验证路径**：验证器 + 备用邮箱（或手机号），别让一部手机成为唯一入口，理由与做法见 [批准登录通知没反应怎么排查.md](批准登录通知没反应怎么排查.md)；
4. **可以顺手改成无密码登录**：不再用可被猜的密码，见 [无密码登录与通行密钥.md](无密码登录与通行密钥.md)。

## 五、误点了「批准」或者把码给出去过

这几种情况按顺序做，别跳步：

1. **立刻改密码**，从干净设备上改；
2. **检查转发规则和邮箱规则**：被入侵的账号常被塞进自动转发或隐藏规则，发现陌生的就删掉；
3. **确认安全信息有没有被替换**：如果页面上出现「你的安全信息更改仍在挂起」或「你暂时无法访问此站点」，说明原有的安全信息被清掉换过。这时账号会进入**为期 30 天的受限状态**：敏感操作被挡住，但大多数服务照常可用，OneDrive 个人保管库这类会被拦；
4. **撤销旧的验证设备注册**：手机上删账号不等于服务器那边解除，具体两端的操作见 [批准登录通知没反应怎么排查.md](批准登录通知没反应怎么排查.md)。

## 六、账号被锁住时怎么解

1. 先去 [account.microsoft.com](https://account.microsoft.com/) 试登录，多数锁定在登录流程里就能解开；
2. **如果登录时看不到「让我们证明你是人类」这个选项**，说明账号是因为可疑活动或违反使用条款被锁的 —— 按页面里以 `aka.ms` 开头的链接提交恢复申请，官方会通过邮件联系你；
3. **只提交一次**：官方明确说明重复提交会拖慢处理速度；
4. **被临时拦住验证时**：先换一个已经配好的验证方式，再换网络（数据与 Wi-Fi 互换）试；如果怀疑是临时封锁，**至少等 24 小时再试**，之后仍不行就等到 48 小时、再不行等一周。关键是**这段等待期不要再反复登录或重置密码**，反复尝试会让冷却重新计时。

## 七、想少被骚扰一点

- **Outlook 手机端的批准入口可以单独关掉**：Outlook → 设置 → 账户 → 选中该账户 → 账户 → 登录请求 → 关掉「允许登录请求」。**注意这只去掉一条批准路径，不会阻止别人继续尝试登录**；
- **提示不会一直响**：对方在多次被拒后通常会放弃。期间把「拒绝」当常态处理，隔几天回活动页确认一次没有成功登录；
- **确认过没有陌生登录，就不必为此换账号**。被撞用户名是很常见的事，不等于账号已经不安全。

## 八、什么时候该找人工

- **个人账号**：用微软的登录助手，它会按你的实际情况给出下一步；
- **工作或学校账号**：找组织的 IT 支持，带上活动页的截图和时间点，比口述快得多；
- **怀疑已经被成功入侵**：按官方「被入侵或泄露的账号」恢复指引走，恢复后重点复核邮箱转发规则与安全信息两处。

拒绝请求这件事本身你已经做对了，剩下的就是把这四步做齐：**改密码、核安全信息、补第二条验证路径、解除旧设备注册**。
