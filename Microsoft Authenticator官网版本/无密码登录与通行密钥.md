# Microsoft Authenticator 无密码登录与通行密钥

> 手机上点一下批准就登录（无密码）和通行密钥不是一回事：分别怎么开、对安卓版本有什么要求、哪些组织会禁用、失败时先查什么。

微软账号有两套「不用输密码」的登录方式，很多人在设置页里看到两个选项却分不清。简单说：**点批准**是把手机当作确认按钮，**通行密钥**是把手机当作一把钥匙。两者要求、入口、适用范围都不一样，本篇分开讲。

## 一、先分清这两件事

| 对比项 | 手机批准登录（无密码帐户） | 通行密钥（Passkey） |
| --- | --- | --- |
| 登录时你要做的 | 手机上点一下批准 | 用指纹/面容/PIN 验证后直接登录 |
| 账号密钥存在哪 | 服务器侧，手机只是确认端 | 手机本地（或同步的凭据存储） |
| 主要用在 | Microsoft 账号本身的登录 | 微软账号，也覆盖组织资源与原生应用 |
| 谁决定能不能用 | 个人账号自助开；工作或学校账号由组织决定 | 同上，且受账号策略约束 |
| 安卓门槛 | 无特别版本要求 | **Android 14 及以上**才能用通行密钥登录 |
| 需要联网 | 要 | 要 |

## 二、开「手机批准登录」

1. 浏览器打开 [account.microsoft.com/security](https://account.microsoft.com/security)，登录账号；
2. 选「管理我的登录方式」；
3. 往下找到「**无密码帐户**」区域，选择打开该功能；
4. 按提示验证身份，然后在手机上批准发过来的那一次请求。

开完之后，登录这个账号时只要在手机上点批准就够了。**风险也要一起看**：手机丢了、或者手机不在身边，这条唯一路径就断了。所以开之前确认备用邮箱和手机号是最新的，并给应用开上应用锁。

工作或学校账号想用同一套体验，取决于组织策略，管理员没开就没有这个选项。

## 三、开通行密钥

通行密钥对安卓版本有硬要求，先确认设备够不够格：

- **注册和登录都要 Android 14 或更高**；
- 官方还补了一句：**如果设备是 Android 14、但没法把 Authenticator 设为通行密钥提供程序，建议升到 Android 15**；
- 通行密钥登录还要求 **Google Play 服务 21 或更高版本**（因为需要用户验证）。

版本够了以后，两条路都能注册：

**路线一：从 Authenticator 应用内注册（官方推荐）**

1. 在 Authenticator 里登录这个账号（还没有就按 [添加账户与绑定验证码.md](添加账户与绑定验证码.md) 先加进来）；
2. 点开账号，选「创建密钥」（Create a passkey，有的版本译作「创建通行密钥」）；
3. 完成一次多重身份验证；
4. 必要时先给应用设屏幕锁；
5. 按提示把 **Authenticator 设为通行密钥提供程序**；
6. 注册完成后回到账号页，能看到 Passkey 已经作为登录方法加上去了。

**路线二：从安全信息页注册**

1. 浏览器登录 [mysignins.microsoft.com/security-info](https://mysignins.microsoft.com/security-info)；
2. 选「添加登录方法」，在列表里选「Passkey in Microsoft Authenticator」；
3. 按提示打开 Authenticator 创建密钥，其余同上。

## 四、把 Microsoft Authenticator 设成通行密钥提供程序（安卓）

这一步是安卓上最容易卡住的地方，因为入口名称各家 ROM 不一样：

1. 在设备设置里**直接搜索「Passkey」或「通行密钥」**，不同厂商的路径不一致，搜比翻菜单快；
2. 找到「密码和帐户」这类入口，在「其他提供程序」一节里**勾上 Authenticator**；
3. 回到 Authenticator，点「完成」确认；
4. 之后在账号里能看到通行密钥已添加。

**关键提醒**：如果给工作或学校账号设过密钥，要保证这个开关**一直**是开着的。**把 Authenticator 从通行密钥提供程序里关掉，等于把那些密钥一起停掉**，原有的登录方式也会跟着失效。

## 五、用通行密钥登录

- **同一个设备上、浏览器里登录**：打开要访问的站点（例如 [office.com](https://www.office.com/)），输入用户名；如果上次是用通行密钥登的，会直接提示你验证。没有提示就选「其他登录方式」，再选「面容、指纹、PIN 或安全密钥」。
- **不输用户名直接登**：登录页上选「登录选项」，再选上面那一项。**设备上存了多个通行密钥时会让你先挑一个**。
- **跨设备登录**：在另一台设备（例如 Windows 11 23H2 及以上的电脑）上发起，选「iPhone、iPad 或 Android 设备」，屏幕上出现二维码后用**系统相机**扫。官方特别说明：**Authenticator 应用内的相机不支持扫 WebAuthn 二维码**，必须用系统相机。这一步要求两台设备都开蓝牙并有网络。

## 六、通行密钥用不了时

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 提示设备不支持，建议升级系统 | 系统版本不够 | 升到 Android 15 再试；Android 14 属于「可能启不起来」的那一档 |
| 设置里找不到「其他提供程序」 | 各厂商 ROM 入口不同 | 在设置里搜 Passkey；仍找不到就查设备厂商说明 |
| 只有 PIN 输入，没有指纹/面容 | 用了工作配置文件，且没在工作配置文件里登记生物识别 | 在工作配置文件里单独添加一次生物识别 |
| 注册好了但登录时看不到选项 | 账号策略没放开，或提供程序开关被关掉 | 先确认开关是开的；工作或学校账号要问管理员 |
| 提示需要蓝牙才能跨设备 | 跨设备登录本身要求蓝牙+网络 | 两台设备都打开蓝牙，组织禁蓝牙时需管理员放行 |

## 七、中国区用户的限制

官方《在中国下载 Microsoft Authenticator》页面里写明：**通行密钥不适用于由世纪互联运营的 Microsoft Azure**。也就是说，账号若挂在世纪互联运营的那套服务上，通行密钥这条路走不通，只能用验证码方式。中国区还开放了哪些功能，整理在 [常见问题与排查.md](常见问题与排查.md) 里。

通行密钥的可用范围官方会持续调整，具体以官方 Entra 文档与支持页当时显示的为准。
