分贝测试仪把手机变成一个随手可用的噪音参考表：读数够不够用，取决于你测的是哪一段、怎么测。这篇讲清手机麦克风的能力边界、读数偏差从哪来，以及怎么操作能让数值更接近真实情况，帮你在「看个大概」和「要个准数」之间选对做法。

## 一、先弄清这台手机能测到哪一段

用手机测分贝，能用的区间是中间那一段，两头都不太行：

| 区间 | 情况 |
| --- | --- |
| 约 25 dB 以下 | 手机本身的底噪就有这么高，测出来的是它自己，不是环境 |
| 约 30 ~ 90 dB | 相对可用的区间，日常家居、办公室、马路噪音都在这一段 |
| 约 95 ~ 110 dB 以上 | 多数手机麦克风会过载削顶，读数停在某个值上不再往上涨，实际可能更高 |

所以遇到两个典型现象别急着怀疑应用坏了：一是安静到极致的房间怎么测都是二十几，那是手机的噪声下限；二是站在电锯、演唱会音箱跟前，读数卡在 100 出头不动，那是麦克风顶到上限了，不是在报「噪音只有这么大」。

顺带记住分贝的刻度不是线性的：**声强翻一倍大约只加 3 dB，而人耳听起来「响一倍」大约要加 10 dB**。所以你看到从 60 涨到 63 时，声音的强度其实已经翻了一番。

## 二、为什么同一间屋子两台手机读数不一样

这是最常被当成「应用不准」的情况，其实来源在硬件和系统，不在算法：

1. **麦克风灵敏度有离散**。手机麦克风出厂规格本身就有个几 dB 的容差，加上外壳开孔、装配差异，两台机器差上几 dB 很平常，没校准的情况下差到十几 dB 也不稀奇。
2. **麦克风位置不同**。多数手机的麦克风在机身底部或背面，有的还有多个（顶部、背面各一个）。同样平放在桌上，底部麦克风朝上还是朝下，读数就不一样。
3. **系统的音频处理不同**。为了通话清晰，手机音频链路会做降噪和自动增益，不同厂商、不同机型的力度不同，这会改变「声音大小」到「数字大小」之间的对应关系。

结论是：**跨手机比绝对数值没有意义，同一台手机做前后对比才有意义**。想在装修前后、换隔音窗前后看变化，就用同一台手机、同样的位置和拿法各测一次，比较的是这个差值。

## 三、怎么测更接近真实值

按对结果影响从大到小排：

1. **别挡住麦克风**。先找一下麦克风开孔在哪（通常在底部或背面），测的时候手指、手机壳、手掌都别盖上去；带厚壳的机型可以摘壳再测。
2. **让麦克风朝向声源**，手机离身体一臂左右，别贴着胸口或大腿——身体的遮挡和反射会改变你测到的声音。
3. **看平均，别盯瞬时值**。数字一直在跳是正常的，人耳听到的也是波动；要一个代表值，就让测量持续 30 秒到 1 分钟，看这段时间的整体水平和最高值，而不是取某一秒的读数。
4. **固定测量高度和距离**。噪音随距离衰减，今天举在耳边测、明天放在桌上测，两次结果没有可比性；要对比就固定同一个点位、同一个高度。
5. **避开风和气流**。空调出风口、开着的车窗旁，气流打在麦克风上会直接顶高读数，这不是噪音。
6. **不要边充电边长时间测**。充电时的电流声和机身的电磁干扰都可能被麦克风收进去。

如果应用里有校准或补偿数值一类的设置项，可以做一次并排校准：拿一台可靠的参考表放在旁边，在稳定声源（开着的风扇、空调风道这类）下各测一段，把差值填进去。没有参考设备的话，就把重点放在相对比较上，不要指望绝对数值精确。

## 四、这些情况下读数不能当真

- **合规或法律用途**。正式的噪音投诉鉴定、职业接触评估要求用通过认证的声级计（IEC 61672 一类的 Class 1 / Class 2 设备），手机应用无论怎么校准都达不到这个门槛。手机读数可以用来自查和初步排摸，不能拿去当正式检测结论，具体怎么留材料见 [测噪音怎么留证据.md](测噪音怎么留证据.md)。
- **超过约 100 dB 的强声源**。如上节所述，这一段普遍会低报，读数只说明「非常吵」，不能说明具体多少。
- **极低频、极安静的场景**。手机麦克风对低频响应有限，安静到接近手机底噪时读数也失去意义。
- **和专业表口径不同时不作数**。专业声级计常按 A 计权（贴近人耳听感，写作 dBA）出数，如果两边用的计权方式不同，数值本来就不该一样，对比前先确认口径一致。

## 五、常见场景的分贝参考

下面这些数值是常见的公开参考，用来给读数对个量级，不同来源略有出入：

| 大致分贝 | 对应场景 |
| --- | --- |
| 10 ~ 20 | 呼吸声、树叶沙沙声 |
| 30 | 耳语、夜间安静的卧室 |
| 40 | 安静的图书馆 |
| 50 | 安静的办公室 |
| 60 | 正常交谈 |
| 70 | 繁忙的道路交通、吸尘器 |
| 80 | 繁忙街道、闹钟 |
| 90 | 工厂机器运转、地铁进站 |
| 100 | 近距离的电锯、吹风机 |
| 110 | 音乐会现场、汽车喇叭 |
| 120 | 近距离的飞机起飞 |

关于听力保护，常被引用的参考线是**连续 85 dB 上下、持续 8 小时**属于需要留意的暴露水平，各地标准不同，以当地规定为准。用手机测出来长期高过这个量级的环境，值得认真对待：换到安静位置、缩短停留时间、必要时用上耳塞。

读数长时间卡在某个值不动、或者一直是 0，属于设备与权限层面的问题，处理办法见 [常见问题与排查.md](常见问题与排查.md)。
