分贝测试仪是安卓上一款用手机麦克风测环境噪音的应用，开发方是武汉速诺科技有限公司，主要用来快速判断家里、办公室、工地旁边这类环境吵不吵。本篇只解决一件事：把网盘里这份包装进手机，并把第一次打开要用到的权限配齐。

## 一、先确认网盘里这份包是哪一版

这份安装包的获取入口就是本文开头给出的那一条夸克网盘资源，转存到自己的网盘后再下载。

版本号方面：这个应用在官方渠道的版本号形如 `1.3.x`，末位随每次修订递增，官方后续发布的版本号可能已经高于 v1.3.0，具体以官方渠道当时显示的为准，这里不预判。想知道官方最新版和更新说明，可以看它在腾讯应用宝上的发布页 [sj.qq.com/appdetail/com.novv.dbmeter](https://sj.qq.com/appdetail/com.novv.dbmeter)。

MD5 是干什么用的：下载完成后可以核对一下文件的 MD5 值，与上表一致说明文件完整、没有传坏。对不上就重新下一次，别拿一个可能残缺的包装上去试。

系统要求方面：官方公开页面没有给出确切的最低安卓版本号，所以最终以两点为准——安装时系统有没有提示「不兼容」，以及装完能不能正常打开。这个应用完全依赖手机的麦克风硬件，没有可用麦克风的设备装上也测不出东西。

## 二、装之前要核对的两件事

**第一，认准包名，别装成同名应用。** 应用市场里叫「分贝测试仪」「分贝仪」「噪音分贝仪」的应用有很多，界面相似、包名各不相同。本文这份的包名是 `com.novv.dbmeter`；包名不同就是另一个应用，两者在系统里各自独立，**不能互相覆盖安装**，也不会共用数据。如果你之前装过另一条包名线的同类应用，先想清楚要留哪一个。

**第二，留出安装空间。** 安装包本身 29.43 MB，装完占用会比这大一些。历史记录与保存的内容也会占地方，长期用下来建议保证手机有一两百 MB 的余量。

## 三、安装步骤

1. **转存并下载**：从 [分贝测试仪 安装文件资源（夸克网盘）](https://pan.quark.cn/s/5f5941f63498) 把 APK 转存到自己的网盘，再下载到手机或电脑。
2. **把包送到手机上**：手机端直接下载最省事；在电脑上下载的话，用数据线或任意传输工具拷进手机存储即可。
3. **允许安装未知来源应用**：在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给用来打开安装包的那个应用（文件管理器或浏览器）打开开关。国产定制系统里这项开关常收在「安全」或「隐私」分类下。
4. **点击 APK 完成安装**：系统若提示「应用未经过安全检测」，选继续安装即可，这是第三方渠道安装包的常规提示。
5. **回装低版本要先卸载**：安卓不允许用更低版本的安装包覆盖更高版本，会直接报「应用未安装」。如果手机里已装的版本比 v1.3.0 高，先卸载旧版再装。
6. **装完先别急着打开**：把下一节的权限过一遍。麦克风没给到，打开后就是一个怎么都不动的读数。

## 四、第一次打开要给的权限

第一次启动通常按顺序弹几项授权，逐项对照处理：

| 权限 | 用来做什么 | 不给会怎样 |
| --- | --- | --- |
| 麦克风 | 采集环境声音，是这个应用的命门 | 读数一直是 0 或纹丝不动，等于用不了 |
| 位置信息 | 给测量记录标上测量地点 | 记录里看不到地点，测量本身一般照常 |
| 存储 / 文件 | 保存历史记录、留存测量内容 | 历史记录可能存不下来 |
| 通知 | 前台服务类的运行提示 | 影响很小，可按需给 |

附带一个 Android 上的注意点：麦克风权限选「仅在使用时允许」就够用；但如果系统的应用详情页里有「禁止后台使用麦克风」这类开关，长时间连续测量时会被系统掐断，需要放开。位置权限的隐私取舍见 [历史记录与测量地点怎么看.md](历史记录与测量地点怎么看.md)。

## 五、装完做一次最小验证

1. 打开应用，按上一节把麦克风权限给全；
2. 看主界面读数有没有随环境声音变化：安静房间里通常落在三十多到四十多分贝，对着手机说句话，数值会立刻往上跳；
3. 换到更吵的地方（开着的风扇、窗外的马路）再测一次，数值应该明显更高；
4. 保存一条记录，退回列表能找回，说明存储与记录这条链路是通的。

读数一直不动或一直是 0，先看 [常见问题与排查.md](常见问题与排查.md)；数值跟另一台手机差很多属于手机麦克风的正常离散，原因和应对办法在 [测出来的分贝准不准.md](测出来的分贝准不准.md) 里。
