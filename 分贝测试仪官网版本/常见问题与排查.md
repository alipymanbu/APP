# 分贝测试仪 常见问题与排查

分贝测试仪装好之后真正会卡住人的，基本就是权限、麦克风和系统后台限制这几处。这篇按「你看到什么现象」分节，每节只给能动手的步骤，遇到问题直接跳到对应那一节。

## 一、装不上、提示「应用未安装」

| 现象 | 处理 |
| --- | --- |
| 提示「应用未安装」 | 手机里已装了版本号更高的同一个包，或装了另一条包名线的同类应用；先卸载再装 |
| 提示「与你的设备不兼容」 | 系统版本偏低，或安装包没下载完整；重新从 [分贝测试仪 安装文件资源（夸克网盘）](https://pan.quark.cn/s/5f5941f63498) 下一次 |
| 安装界面反复弹安全提示 | 第三方渠道安装包的常规提示，按提示继续即可 |
| 装完打开就闪退 | 卸载后重装一次，覆盖安装遗留的旧数据是常见诱因 |
| 想确认装的是不是同一个应用 | 在系统应用信息里看包名是不是 `com.novv.dbmeter` |

## 二、打开后读数一直是 0 或纹丝不动

按可能性从高到低排：

1. **麦克风权限没给到**。进「设置 → 应用 → 分贝测试仪 → 权限」，把麦克风设为「允许」。这一项没给，应用永远读不到声音。
2. **麦克风被别的应用占着**。通话、录音、语音助手、视频会议这类正在使用麦克风的应用会让它测不到，先把它们关掉。
3. **麦克风开孔被挡住**。手机壳、手指、支架压住麦克风孔，读数就会非常低甚至不变；换个握法或摘掉壳再试。
4. **系统里有「禁止后台使用麦克风」一类的开关**。连续测量时被系统掐断，表现就是数值突然停住，把这个限制放开。
5. **确实太安静**。手机本身有底噪，安静到接近底噪时读数会贴在二十几不动，换个有点声音的环境就能验证。

## 三、读数卡在某个值上，再吵也不涨

这不是故障，是手机麦克风顶到上限了。多数手机麦克风在很吵的环境里会过载，读数停在 100 上下不再变化，而实际声压可能更高。

处理办法只有一个：离声源远一点，退到读数还能随距离变化的范围内再测。要测电锯、演唱会音箱这种强声源的真实数值，只能靠专业声级计，手机测不了。详细解释见 [测出来的分贝准不准.md](测出来的分贝准不准.md)。

## 四、数值忽高忽低，或者和别人的手机差很多

- **数字一直在跳是正常的**。环境噪声本来就在波动，用一段时间内的整体水平和最高值来判断，别纠结某一秒的数字。
- **两台手机读数不一样也正常**。麦克风灵敏度、开孔位置、系统的音频处理都不同，没校准的情况下差上几 dB 到十几 dB 很常见。**同一台手机做前后对比**才有意义。
- **想减小误差**，按 [测出来的分贝准不准.md](测出来的分贝准不准.md) 里「怎么测更接近真实值」那一节的顺序调。

## 五、测量记录里不显示地点

1. 确认手机系统的定位总开关是打开的；
2. 确认给了应用位置权限（设置 → 应用 → 分贝测试仪 → 权限）；
3. 在室内、地下车库这类遮挡严重的地方首次定位会比较慢，稍等一会儿再看；
4. 不想开定位也没关系，测量本身不受影响，只是记录里地点一栏是空的。权限与隐私取舍见 [历史记录与测量地点怎么看.md](历史记录与测量地点怎么看.md)。

## 六、之前的测量记录不见了

按顺序排查：

1. 确认是不是切到了别的时间段或列表页；
2. 回想有没有在系统里对应用做过「清除数据」，那一步会连记录一起清掉；
3. 是不是刚升级、重装或换了手机——记录默认存在本地，不跟着迁移。

要长期保留的记录，早点截图或导出归档；详细说明见 [历史记录与测量地点怎么看.md](历史记录与测量地点怎么看.md)。

## 七、锁屏或切到别的应用就停止测量

这是系统的后台限制在起作用，不是应用自己停了：

1. 进「设置 → 应用 → 分贝测试仪」，找到电池相关的选项；
2. 把省电策略改成「不受限制」，或把它加进后台运行白名单；
3. 部分机型的手机管家里还有一层「后台运行管理」，同样要放行；
4. 别用第三方清理工具冻结它的后台进程，被冻结后表现就是数值不再更新。

## 八、长时间测量时耗电快、机身发热

麦克风持续工作加屏幕常亮，是这类应用耗电的主要来源：

- 测量期间把屏幕亮度调低，或者设置更短的自动锁屏时间，测完及时退出；
- 别边充电边长时间测，充电本身也发热，还会给读数引入干扰；
- 只是想知道「大概多少」的话，测够三十秒到一分钟就够了，不需要一直开着。
