# 分贝测试仪 装修隔音前后怎么对比着测

> 想验证换窗户、贴吸音棉、加隔音门到底有没有效果，只测一次说明不了问题；这篇给一套固定条件、前后各测一遍的做法。

改造前后差了多少分贝，是这类应用最实在的用法之一。难点不在测，而在**让两次测量只差在你要比较的那一项上**：声源、测点、时段、手机、时长都要前后一致。这篇给一套照着做就能比的流程。

## 一、只有条件一致，差值才有意义

同一间屋子、同一个声音，换个位置测出来能差好几 dB，所以前后对比的第一条原则是：**除了你要验证的那个改动，其他条件全都不动**。

| 要固定的项 | 具体怎么做 |
| --- | --- |
| 测量设备 | 前后都用同一台手机、同一个应用，中途不换机 |
| 测点位置 | 记住离墙多少厘米、离地多少厘米，前后站同一个点 |
| 手机姿态 | 前后都放在台面或小支架上，别一次手持、一次放桌面 |
| 测量时段 | 选同类的时段，比如前后都在晚间 21 点到 22 点 |
| 环境状态 | 门窗开闭、空调与风扇开关，前后保持一致 |
| 测量时长 | 每次同样测够 30 秒到 1 分钟 |

## 二、动手之前先测一组基线

改造前先测两组数，后面才有得比：

1. **背景噪声（基线）**：关掉你要比较的那个声源，安静状态下测 1 分钟，记下平均值。
2. **目标声源**：用同一个声源、同一个位置再测一遍。

背景噪声这一项容易被忽略，但它决定了后面的数字算不算数：**背景至少要比你要测的声音低 6 dB，最好低 10 dB 以上**。达不到说明环境本身太吵，你测到的主要是环境在说话，而不是那个声源。

## 三、声源要能复现

测隔音最麻烦的地方是「外面马路的车声」这类环境音没法复现。可行的替代办法是自造一个稳定声源：

- 用另一台手机或蓝牙音箱，固定在离被测墙面约 1 米的位置，播放稳定的噪声或音乐，音量前后调成同一个刻度；
- 把播放设备的位置、音量刻度、播放内容记下来——这三项不固定，后面就没得比；
- 没有音箱时退而求其次：固定高度、固定位置做同一个动作（比如同一个柜门在同一位置开关），也比随手制造各种声音强。

## 四、距离的影响要先心里有数

声音随距离衰减，不知道这个量级，很容易把「站远了」当成「隔音生效了」：

| 离声源的距离 | 相对 1 米处的读数变化 |
| --- | --- |
| 1 米 | 基准（0） |
| 2 米 | 约 -6 dB |
| 4 米 | 约 -12 dB |
| 8 米 | 约 -18 dB |

这是自由场里的近似规律，室内有墙面反射，实测会打折扣，但趋势摆在那儿：**前后两次只要测点挪了，差值就不可信**。

反过来，室内反射也意味着同一房间挪半米，读数就可能差上 3 到 6 dB。要严谨一点，就在房间里选 3 个相隔一米左右的点各测一遍取平均，而不是只测一个点。

## 五、手机别拿在手上

手持测量会把手掌与衣物的摩擦振动一起收进去，这部分对读数的影响不小。做法很简单：

- 把手机放在一块软布（超细纤维布、棉 T 恤都行）上，再放到桌面上，高度贴近你平时听声音的位置；
- 或者用小支架夹住手机，让麦克风朝向声源；
- **放好之后不要再碰它**，直到这一次测量结束。

## 六、每次测三遍、取平均

单次读数代表不了什么，更不能拿「改造前某一次的最低值」去比「改造后某一次的最高值」。规矩是：

1. 每个测点测 3 次，每次 30 秒到 1 分钟；
2. 记下每次的平均值与最高值；
3. 三次取平均，作为这个测点的代表值；
4. 改造前后各做一遍，比较代表值之间的差值。

稳态噪声（风扇、空调、持续车流）测 30 秒以上够用；起伏大的噪声（间断的装修声、偶发车流）要拉长到十几分钟才有代表性。

## 七、把条件一起记下来

只记数字，过一个月你自己也想不起当时门窗是开还是关。建议照这个格式记，和记录截图放在一起：

```text
日期：2026-08-03     时段：21:10 - 21:40
测点：主卧，离窗 1 米、离地 1.2 米
设备：同一台手机 + 分贝测试仪
环境：窗户关闭、空调关闭
背景噪声：约 38 dB（测 1 分钟的平均值）
目标声源：客厅音响，同一音量刻度
测点读数：3 次平均 56 dB，最高 61 dB
备注：改造前
```

改造后再照这张表填一遍，两张并排，差值一目了然。

改造完发现读数变化很小，先别急着下结论说改造没用——先核对两边的测点、时段、环境状态是不是真的完全一致；差值反常得离谱时，按 [测出来的分贝准不准.md](测出来的分贝准不准.md) 排查是不是测量本身出了问题。要把这套数据整理成能拿给别人看的材料，做法见 [测噪音怎么留证据.md](测噪音怎么留证据.md)。
