## 二、装之前要核对的两件事

**第一，别和名字相似的另一个应用装混。** 市面上还有一个叫「创游世界」的应用，名字只差一个字，但两者是不同产品、包名也不同。判断依据不是名字，而是**包名** —— 本文这份是 `cn.xiguacity.shell`。

**第二，先准备好能收短信的手机号。** 这个应用要注册登录后才能发布作品，而注册需要手机号做实名核验（详见 [注册登录与账号设置.md](注册登录与账号设置.md)）。没准备好手机号，装上也只能以游客身份浏览。

## 三、安装步骤

1. **转存并下载**：从 [共创世界 安装文件资源（夸克网盘）](https://pan.quark.cn/s/abb2bf2e303f) 把 APK 转存到自己网盘，再下载到手机；
2. **允许安装未知来源应用**：在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给用来打开安装包的那个应用（文件管理器或浏览器）打开开关。国产定制系统的这项开关通常收在「安全」或「隐私」下面；
3. **点击 APK 完成安装**：系统若提示「应用未经过安全检测」，选择继续安装即可，这是第三方渠道安装包的常规提示；
4. **回装低版本要先卸载**：安卓不允许用更低版本的安装包覆盖更高版本，会直接报「应用未安装」。如果手机里已装的版本比 2.2.0 高，先卸载再装，本地数据会一并清掉。

## 四、第一次打开要走的流程

打开后按顺序做这几步，走到「能看到首页的作品流」就算通了：

| 步骤 | 说明 |
| --- | --- |
| 同意用户协议与隐私政策 | 首次启动会弹出，不点同意进不去 |
| 选择登录方式 | 手机号注册，或使用第三方账号登录 |
| 以游客身份先看看 | 不登录也能浏览作品，但发布、评论等操作需要登录 |
| 检查网络 | 首页内容来自线上，网络不通时会一直转圈而不是报错 |

各步骤的细节与常见卡点写在 [注册登录与账号设置.md](注册登录与账号设置.md) 里，本篇不重复。

## 五、装完做一次最小验证

1. 应用能正常打开，不会刚进去就退回桌面；
2. 登录后首页能刷出作品列表；
3. 点开任意一个作品能看到预览，说明网络与账号状态都正常。

装完打不开、或者装到一半报错，按 [常见问题与排查.md](常见问题与排查.md) 里对应的现象逐条排除。安装包与后续版本更新，统一从 [共创世界 安装文件资源（夸克网盘）](https://pan.quark.cn/s/abb2bf2e303f) 取用。
