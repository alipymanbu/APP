## 一、现象速查

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 收不到注册验证码 | 短信被拦截、网络异常、重试次数过多 | 见第二节 |
| 登录后提示账号异常 | 频繁重试触发风控，或第三方账号状态异常 | 换手机号登录方式，或稍后再试 |
| 创作时卡顿、闪退 | 客户端版本较旧；老机型性能吃紧 | 见第三节 |
| 发布后自己搜不到作品 | 仍在审核中，或审核未通过 | 见第四节 |
| 作品加载慢、打不开 | 大体积作品首次加载要下载资源，网络差时明显 | 换 Wi-Fi 或换个时段再试 |
| 忘记密码、手机号已换 | 自助找回依赖原手机号 | 走客服渠道处理 |
| 安装包点不开、安装失败 | 安装包没下完，或系统版本偏低 | 重新下载；核对 MD5 |
| 界面上找不到某功能 | 手机端与桌面端功能位置与完整度不同 | 换网页版/桌面端对照 |

## 二、收不到验证码的排查顺序

按这个顺序走，别一上来就反复点「重新发送」—— 短时间连点很容易被判定为异常请求，反而更收不到：

1. **先等一会儿**。验证码短信有延迟，等待期间不要重复提交；
2. **看拦截**。手机管家的垃圾短信、运营商的拦截记录里经常能找到它；
3. **换网络**。从 Wi-Fi 切到移动数据再试一次，或反过来；
4. **确认号码**。核对输错的位数与区号，尤其是双卡设备选错了卡；
5. 都不行就**隔一段时间再试**，等风控冷却过去。

## 三、创作时卡顿与闪退

这一类问题在客户端更新日志里被明确提到过 —— 较新的版本修的就是「部分机型创作时卡顿和闪退」。

处理顺序：

1. **先把客户端升级到较新的版本**（本文这份是 2.2.0，更新包从 [共创世界 安装文件资源（夸克网盘）](https://pan.quark.cn/s/abb2bf2e303f) 或官方渠道取用）；
2. **清一次后台**再进创作界面，老机型同时开着多个应用时最容易崩；
3. **降低作品复杂度**：素材越多、角色越多，内存压力越大；
4. **换设备**：如果只在某一台老设备上崩，换到桌面端做同一个作品通常就没有问题。

注意：**闪退前没保存的改动会丢**。养成改动几步就保存一次的习惯，比事后找原因划算。

## 四、发布之后看不到作品

按这个顺序判断：

- **还在审核中** → 等一段时间刷新看看，审核不是即时的；
- **审核未通过** → 按平台的提示修改内容后重新提交，反复提交同一份内容没有意义；
- **没登录错账号** → 确认发布用的账号和现在查看用的是同一个；
- **作品仅在本地** → 确认你真的走完了发布流程，而不是只保存了草稿。

## 五、装不上、打不开

- **核对安装包是否完整**：拿本文的 MD5 `2106FF158260A7175AAC8B1E1B4DB461` 与本地文件比对，不一致就重新下载；
- **卡在安装过程**：先卸载设备里已有的同名应用，安卓不允许签名不同的两份包共存；
- **装上就退回桌面**：多为系统版本偏低，参考 [下载与安装教程.md](下载与安装教程.md) 第一节的系统要求说明。

安装包与后续版本更新，统一从 [共创世界 安装文件资源（夸克网盘）](https://pan.quark.cn/s/abb2bf2e303f) 取用。
