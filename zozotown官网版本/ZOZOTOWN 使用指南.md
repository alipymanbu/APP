# ZOZOTOWN 使用指南

ZOZOTOWN 是日本规模最大的时尚电商之一，由株式会社 ZOZO（现属 LINEヤフー 集团）运营，站点在 `zozo.jp`。这份指南写给想用它的中文用户：先说清楚它适不适合你，再讲怎么把网盘里那份包装上、怎么注册、怎么下单、东西怎么到手。

---

## 一、它是什么，适合谁

ZOZOTOWN 不是某个品牌自己的商城，而是一个**把上千个日本品牌放进同一个货架**的平台。它在日本的定位就是「横向逛、横向比」——同一件外套，你能在这里同时看到多个品牌、多种价位的替代品。

商品规模在百万件级、品牌数以千计。用户以日本国内为主，活跃会员中女性占多数。第三方做的日本时尚电商使用率调查里，它常年排在前列，与亚马逊、优衣库这类名字并列。

**在动手下载之前，有三件事必须先知道**，它们决定了它到底适不适合你：

| 要知道的事 | 具体是什么 |
| --- | --- |
| 只有日文界面 | 官方没有中文或英文界面，搜索也要用日文关键词 |
| 官方不支持海外使用 | 官方帮助页明确写明，App 不支持面向日本国外以及平板设备使用 |
| 不直邮 | 没有官方海外直邮，也没有官方跨境转运合作，海外用户实际走的是转运或代购 |

先把一条边界说清楚：**官方口径是面向日本国内使用的**，海外用户走转运，属于「超出官方支持范围」的自行安排 —— 本篇只把现实路径和风险讲明白，不涉及任何伪造身份或规避官方限制的做法。

所以它适合这样的人：**愿意接受全日文界面、并且已经有（或准备找）日本收货地址与转运渠道**，同时接受账号与订单风险自负。如果你只想点几下就送到家门口，它会更费劲。

## 二、下载与安装

网盘里这份安装包的信息是：版本 `7.39.11`，包名 `jp.zozo.android.town`，体积约 113.45 MB，MD5 为 `7BACA9561C7973F81122A01AE41F90F6`。下载入口：https://pan.quark.cn/s/19170e599918

想确认自己没下错，可以自己算一次 MD5 再逐位比对：不少文件管理器自带校验或属性查看功能，也可以装个哈希校验类小工具。**网上搜到的版本通常是官方最新版，与网盘里这份不一定是同一版**，本文的版本信息以网盘这份为准。

装到安卓设备上的步骤：

1. 从上面这个链接把 APK 转存到自己网盘，再下载到手机；
2. 在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给打开安装包的那个应用打开开关；
3. 点击 APK 完成安装，系统提示「未经过安全检测」时选择继续安装即可。

几点提醒：

- **体积偏大（113 MB），建议在 Wi-Fi 下下载**；
- **系统版本建议 Android 9 及以上**：ZOZO 官方给出的手机端浏览环境建议是 Android 9 及更高版本 + Chrome；App 本身没有公开写明最低版本，**Android 8 及更早的设备可能装不上或无法正常使用**，建议 9 及以上再尝试；
- 装上之后**不要指望界面是中文的**，前面已经说过，但它确实会让第一次使用的门槛高不少。

## 三、注册与下单

### 注册

注册免费，需要这几样：**一个邮箱**（它同时也是你的 ZOZO ID，一个邮箱只能注册一个账号）、密码、性别、生日，以及**日本邮编**。官方没有强制要求日本手机号，但**收货地址必须是日本的**（日本邮编 + 收件人姓名；用转运仓时，转运商一般要求姓名写成片假名，注册转运账号时会给你建议写法），这也是海外用户需要转运仓库的原因。

不注册也能用一部分：可以游客身份浏览，甚至可以走到下单（预约商品、积分与部分支付方式只在登录后可用）。但**收货地址仍然必须是日本地址**，这一点不因是否注册而改变。

### 找东西

搜索**只认日文**，这是中文用户最常卡住的地方。可行的办法是先用中文找到商品，再从中日电商或品牌官网拿到它的日文名，回 ZOZOTOWN 里搜。平台上比较有特色的两项：

- **尺码比较与「マルチサイズ」**：填身高体重后，它会给出更适合你的尺码建议，这在网购衣服时比看 S/M/L 靠谱；
- **收藏与降价提醒**：把商品收进收藏，降价或补货时会有通知。

### 付款

支付方式主要这几种，都只能用**日本境内的支付环境**：

| 方式 | 说明 |
| --- | --- |
| 信用卡 / ZOZOCARD | 最常见的路径，首次绑卡要在结算流程里添加 |
| PayPay | 日本本地支付工具，用余额支付 |
| 便利店支付 | 生成单号后去便利店付款，手续费约 330 日元 |
| 货到付款 | 手续费约 330 日元 |
| 后付款（ツケ払い） | 最长可延后约两个月，有额度上限，手续费约 330 日元 |

注意两点：**海外发行的信用卡能否使用没有明确结论**，公开反馈里被拒的情况不少，实际以结算页为准；另外 **LINE Pay 已于 2025 年 4 月 30 日在日本停止服务**，老教程里提到的这个选项现在用不了。上面这些手续费与可用方式，也都**以结算页当时显示为准**。

## 四、东西怎么到手

**ZOZOTOWN 不直邮海外。** 官方曾有过海外站点（ZOZOTOWN.com 等），但都在 2014 年前后关停了，目前没有官方跨境渠道，官方也没有与转运服务商合作。

中文用户的实际路径是**转运或代购**：

1. 在转运商那里注册，拿到属于你的**日本仓库地址**；
2. 在 ZOZOTOWN 下单时，把收货地址填成这个仓库地址 —— 用转运仓时，**务必把转运商给你的入库码填进「地址 2」**，不填会无法入库；
3. 包裹到达仓库后，在转运商后台选择国际运输方式（EMS、海运等）并支付国际运费。

这条链路还有两个容易忽略的坑。

**一是费用不止商品价**：国际运费按重量计算，包裹入境还可能产生关税或清关费用，这部分由收件人承担 —— 下单前先把这笔预算算进去。

**二是退换货**。ZOZOTOWN 侧允许到货后 7 天内申请退货（起算时点以它的退货规则页为准），但一旦经由转运，包裹已经在境外，多数转运商不承担退回与退款，实操上很难完成。尺码和款式拿不准时，宁可先少买一件试试。

## 五、常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 提示该邮箱已注册 | 一个邮箱只能对应一个 ZOZO ID，换邮箱注册，或用原账号找回 |
| 找不到想买的东西 | 搜索只支持日文，换成日文关键词再试 |
| 结算时卡在付款 | 首次绑卡要在结算流程里完成；海外发卡可能被拒 |
| 包裹迟迟不入库 | 检查转运仓库地址是否填对，以及**入库码是否填在「地址 2」** |
| 想退货但东西已在海外 | 转运场景下退货实操困难，下单前先确认尺码与款式 |
| 界面看不懂 | 没有中文界面，只能借助翻译工具；这也是使用它的主要成本 |

使用中如果遇到应用本身的问题（闪退、安装失败等），安装包始终从 https://pan.quark.cn/s/19170e599918 重新取用即可。
