# 树懒Acc 开启加速与游戏库怎么用

## 一、主界面上就三块东西

打开应用后，你只需要认识这三块：

| 位置 | 是什么 | 你要不要管它 |
| --- | --- | --- |
| 剩余服务时间 | 你还有多少天可用 | 要管：为 0 时加速不生效，见 [会员时长与续费怎么买.md](会员时长与续费怎么买.md) |
| 开启加速开关 | 加速的总开关 | 要管：玩之前点一下 |
| 核心操作区下方的功能入口 | 续费、支持的游戏、邀请好友等 | 按需进：找游戏、填邀请码、买时长都从这里走 |

官方对界面的描述是「所有额外负担都留给了技术架构和后台程序」，也就是不需要你手动选线路、调参数 —— 找不到这类设置项是正常的，不是功能藏起来了。

## 二、开启加速：一次点击

1. 确认剩余服务时间不为 0。
2. 点一下「开启加速」按钮，按钮变成开启态。
3. 之后直接切到你玩的游戏即可。

官方说明里提到一个关键点：**这一次开启对接下来玩的任意游戏都生效**，程序会自动识别当前游戏正在使用的网络链路并选取线路，不需要每换一个游戏就重开一遍。所以正常的用法是「进游戏前开着，玩完关掉」，而不是每个游戏都点一次。

## 三、第一次开启可能弹的授权提示

有些机型在第一次点「开启加速」时，系统会再弹一次与网络连接有关的授权（类似「**连接请求**」的对话框，带一个应用名）。这是安卓系统对「由应用接管网络流量」这一类行为的统一询问，属于正常提示，同意即可。

如果当时点了拒绝，或者后来手滑关掉了：到「设置 → 网络与互联网 → VPN」（部分机型在「连接 → 更多连接设置」里）能看到这个条目，把它启用或重新授权。**不授权的话，加速开关像是开着，实际并没有生效** —— 这是「我明明开了加速却还是卡」最常见的一个原因。

## 四、游戏库怎么找游戏

1. 从主界面下方的功能入口进「支持的游戏」。
2. 列表里翻，或者在搜索框里直接搜游戏名。
3. 找到目标游戏后，按页面上的按钮安装或更新。

官方文案里提到支持的游戏在千款量级，并强调新游跟进 —— 官网首页写的是「1000+ 款游戏已支持，随时跟进外服新游戏发布」，应用商店的说明里则写「数百款新老海外手游，开服就支持」。**两个数字口径不同，以你在应用内实际能搜到多少为准**，不必拿某个具体数字去较真。

游戏库里能做的不只是加速：借助加速通道下载游戏内数据也是它的用法之一，这对动辄几个 G 的海外手游很实用 —— 官方首页的说法是「10 分钟下好游戏内数据」，这个时间取决于你的宽带与游戏服务器，当作量级参考即可。

## 五、找不到想玩的游戏怎么办

官方在应用商店的说明里给了明确路径：**「新游支持、功能改进、独创想法等任何意见均可联系我们（联系方式在app内帮助与反馈处）」**。也就是说，搜索里没有的游戏，可以直接通过应用内的「帮助与反馈」提支持需求，不需要在论坛里发帖等人转达。

同一个入口还承接另外三类问题：某个游戏能搜到但装不上、加速效果不理想、游戏更新后加速失效。提的时候把游戏名、手机型号、出现时间写清楚，能省一轮来回。

## 六、加速能解决什么、不能解决什么

写清楚边界，免得白折腾：

| 情况 | 加速有没有用 |
| --- | --- |
| 游戏延迟高、频繁掉线、卡在加载 | 是它的用途范围 |
| 游戏内数据下载慢 | 是它的用途范围 |
| 手机本身卡顿、发热、掉帧 | 无关。加速只动网络，不改设备性能 |
| 游戏账号被封、无法登录（非网络原因） | 无关，要找游戏官方 |
| 根本没装那款游戏 | 先在游戏库里找，找不到就按上一节提需求 |

还有一条边界是官方自己划的：应用商店的说明里写明，这个工具「**仅支持加速境内、境外法律法规允许访问的游戏内容**」。也就是说，某款游戏的内容本身能不能用，不取决于加速做得好不好。

## 七、开完之后如果不对劲

- 剩余时间显示为 0 —— 先看 [会员时长与续费怎么买.md](会员时长与续费怎么买.md)。
- 开了加速还是卡、中途掉线、游戏库里点安装没反应 —— 逐条对照 [常见问题与排查.md](常见问题与排查.md)。
- 应用本身打不开、初始化失败 —— 那不是加速的问题，看 [初始化失败与闪退怎么排查.md](初始化失败与闪退怎么排查.md)。
- 只有某一款游戏加速不了、或者它从「支持的游戏」里消失了 —— 看 [某个游戏突然不能加速了怎么办.md](某个游戏突然不能加速了怎么办.md)。
