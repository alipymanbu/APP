# 树懒Acc 某个游戏突然不能加速了怎么办

> 之前一直在加速的游戏，某天开始加速没效果，或者干脆从「支持的游戏」里消失了。本篇讲怎么先分清是你这边的问题还是这款游戏的问题，以及为什么「某款游戏的加速会被下掉」这件事官方早就写在协议里。

## 一、先按「范围」判方向

| 现象 | 大概率原因 | 直接跳转 |
| --- | --- | --- |
| 所有游戏都加速不了 | 你这边的问题：时长到期、连接授权被拒、本地网络异常 | 第二节 |
| 只有这一款游戏不行，其他正常 | 这款游戏的加速可能已被下线 | 第三节 |
| 游戏库里搜不到这款游戏了 | 同上；也可能是游戏改名了 | 第三节 |
| 应用本身就打不开 | 环境或账号问题，与加速无关 | 看 [初始化失败与闪退怎么排查.md](初始化失败与闪退怎么排查.md) |

## 二、所有游戏都不行：三条自查

1. **剩余服务时间是不是 0。** 为 0 时开关看着是开的，实际不生效 —— 补时长见 [会员时长与续费怎么买.md](会员时长与续费怎么买.md)。
2. **第一次开启加速时那次系统连接授权有没有被拒。** 拒过就等于没接管流量，重新授权的路径在 [开启加速与游戏库怎么用.md](开启加速与游戏库怎么用.md) 第三节。
3. **换一个网络再试。** 从 Wi-Fi 切到蜂窝数据；家里路由器长期没断电的话重启一次；同时把正在下载、看视频这类占带宽的任务停掉。只有某一个 Wi-Fi 下不行，问题在那一侧。

## 三、只有这一款游戏不行：这可能是正常下线，不是故障

官方用户协议里有一条与这个现象直接对应的说明（转述原意）：**因为树懒采用 IP 共用技术，而被加速游戏的服务商对共用 IP 的限制策略并不确定；如果游戏服务商限制其公共 IP，导致官方无法再提供可用的公共 IP，官方可以关闭对应游戏的加速服务，并且不承担由此带来的损失。**

把这段话翻译成现象就是：

- 加速是按游戏逐个维护的，**某一款游戏的可用性取决于上游游戏服务商对公共 IP 的态度**，这个态度会变；
- 一旦变了，官方会**主动把这款游戏的加速关掉**，而不是留着让你反复失败；
- 所以这种情况**再重装、再换网络、再续时长都不会恢复** —— 不属于你能修好的故障。

另外两种常见情况也要排除：**游戏改名或换了登录方式**（库里搜旧名字搜不到，试试新名字），以及**游戏停服**。

### 判断顺序

1. 在「支持的游戏」里用游戏的全名、简称各搜一次，看是不是改名导致的搜不到。
2. 在同一个网络下试另一款游戏：能正常加速，说明是这款游戏单独的问题；也不能，回到第二节。
3. 两步都确认之后，按下一节提反馈。

## 四、提反馈时把这些写全

通过应用内「帮助与反馈」提交（这是官方在应用商店说明里指定的入口，游戏支持类需求也从这里提）：

| 要写的内容 | 例子 |
| --- | --- |
| 游戏全名与区服 | 游戏名 + 日服 / 国际服 / 台服 |
| 手机型号与系统版本 | 例如某型号 + 安卓 14 |
| 树懒Acc 版本号 | 在「设置 → 应用 → 应用信息」里看，见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md) 第二节 |
| 具体现象 | 「列表里搜不到了」/「开关是开的但延迟没变化」/「进游戏提示网络异常」 |
| 出现时间与频率 | 从哪天开始、每次都这样还是偶发 |

写得越具体，越容易判断是「下线了」还是「还在维护、需要修」。

## 五、这几件事别做

- **别为了「恢复加速」去装来路不明的包。** 某款游戏的加速有没有，取决于官方后台，不取决于你装的是哪一版包。
- **别反复卸载重装。** 对「单款游戏被下线」这种情况，重装不会改变任何东西，反而要重新登录。
- **别拿第三方页面上的「已支持游戏列表」当准。** 那些页面更新不及时，以应用内搜到没搜到为准。
