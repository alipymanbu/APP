## 一、先确认这一版是什么

树懒Acc 是杭州溪云网络科技有限公司做的一款手机端网络加速工具，官方给自己的定位是「外服手游加速器」：打开它点一次「开启加速」，让手机连游戏服务器的网络走它优化过的线路，用来减少玩海外手游时的延迟、掉线，以及加快游戏内数据的下载。公开渠道里能拿到的是手机版。

| 项目 | 这一版的情况 |
| --- | --- |
| 适用设备 | 安卓手机 / 安卓平板（另有 iOS 版） |
| 系统要求 | 官方公告写明不支持低于安卓 5.0 的系统 |
| 包名 | com.wesloth.slothacc |
| 版本号 | 2.9.5 |
| 安装包大小 | 3.63 MB |
| 安装包 MD5 | c8b4ef765e855a7b796eb0eb347f69fd |
| 开发者 | 杭州溪云网络科技有限公司 |
| 是否必须联网 | 是。注册登录、开启加速、看游戏库都要联网 |

三点先说明：

1. **第三方下载页常标「需要安卓系统 5.2 以上」，这个版本号不用较真** —— 安卓对外的公开版本号是 5.0、5.1，之后直接跳到 6.0，并没有 5.2。按「安卓 5 系及以上」理解即可，真正能不能装以你手机点下去之后的提示为准。
2. **网上搜到的版本通常比这一版新。** 判断「我装的对不对」看包名和版本号能不能对上，不要拿某篇介绍里写的版本号来比；核对方法见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。
3. **手机系统越新，旧安装包越容易装不上或者装上后闪退。** 这一版是 2.9.5，如果你的手机是近两年的新系统，安装时提示「应用与你的手机不兼容」，先别急着认定包坏了 —— 是系统把这一版拦下来了，解决办法与取舍见 [初始化失败与闪退怎么排查.md](初始化失败与闪退怎么排查.md)。

## 二、能从哪里拿到安装包

| 渠道 | 形态 | 说明 |
| --- | --- | --- |
| 官网 [shulanapp.com](https://shulanapp.com) | 安卓版 + App Store | 官方下载入口，版本最新 |
| 国内安卓应用商店（如应用宝） | 安卓版 | 商店详情页可查开发者、版本号与权限清单 |
| App Store | iOS 版 | 搜「树懒Acc」，开发者是杭州溪云网络科技有限公司 |
| 夸克网盘分享（见本篇开头） | 安卓版 | 转存后取包，适合商店里已经没有这一版、或者想留一份离线备份的情况 |

安装包落在本地之后，**先核对包名与版本号再装**：包名对得上 `com.wesloth.slothacc`，才说明手上这份是官方那个应用。第三方下载站的包不一定与页面标称的版本一致，页面上写着「高速下载」「安全下载」的按钮还常常是先让你装一个下载器，再拿到的包里是什么就不好说了。

## 三、把安装包取到手机

1. 在手机上打开 [树懒Acc 安装文件资源（夸克网盘）](https://pan.quark.cn/s/1f17a8cacf14)。用手机浏览器或夸克 App 都行，**建议在夸克 App 里打开**，浏览器下大文件容易被打断。
2. 点「保存到我的网盘」，先转存到自己账号下。转存之后就不再依赖原分享的状态了。
3. 进入自己的网盘找到这个文件，点下载，等它落到手机的「下载」目录。
4. 下载完核对两件事：文件名以 `.apk` 结尾；大小在 3.63 MB 左右。差得多的多半没下完整，删掉重下，别续传。

习惯在电脑上操作的：先在电脑端网盘把这个文件下载下来，再用数据线（USB）拷到手机的 `Download` 目录，之后在手机上从「文件管理」里点它安装，效果一样。

## 四、安装时放行一次「未知来源」

这个应用如果不在你手机自带的应用商店里，安装时系统会拦一下，这是默认行为，不代表文件有问题。

1. 打开「文件管理」，进入 `Download`（下载）目录，找到刚下好的安装包，点它。
2. 系统弹出「为了安全，你的手机不允许安装来自此来源的应用」这类提示时，点提示里的「设置」，打开**允许安装此来源的应用**开关。
   - 有的机型要自己去「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，找到你刚才用来打开文件的那个 App（文件管理或浏览器），逐个放行。
3. 回到安装界面点「安装」，等进度条走完，出现「打开 / 完成」。
4. 先点「完成」，不要马上点「打开」—— 首次启动前把权限一次给对，省得进去之后反复弹窗。

安装完成后，桌面或应用列表里会出现树懒Acc 的图标。

## 五、首次打开会要的权限

注册登录、开启加速、游戏库这三件事分别要用到不同的权限，按系统提示给就行：

| 权限 | 用途 | 建议 |
| --- | --- | --- |
| 网络与 WLAN 状态 | 注册登录、开启加速、加载游戏库 | 必须给 |
| 通知 | 运营公告、时长提醒 | 想要提醒就给，不想被打扰可以拒绝 |
| 存储 / 文件与媒体 | 缓存、下载游戏内数据 | 建议给，拒了相关功能可能报错 |
| 后台运行 / 电池优化白名单 | 加速在后台保持生效 | 建议放行，否则切到游戏后加速可能掉 |
| 电话状态 / 设备信息 | 安卓常见的版本适配写法 | 给不给都不影响加速本身 |

该版本完整的权限清单可以在应用商店的详情页查到（应用宝一类商店有「应用权限」入口）。**拒绝某项权限之后功能报错，先回到权限页把它补上，比反复重装省事。** 另外，第一次点「开启加速」时可能还会再弹一次系统级的连接授权，那一条见 [开启加速与游戏库怎么用.md](开启加速与游戏库怎么用.md) 第三节。

## 六、iOS 版怎么装

iOS 版走 App Store，和安卓版的包不是同一个，别拿安卓的安装包往 iPhone 上装。

1. 在 App Store 搜索「树懒Acc」，认开发者 `Hangzhou Xiyun Technology Co.,Ltd.`（即杭州溪云网络科技有限公司）。
2. 官网 [shulanapp.com](https://shulanapp.com) 上的 App Store 入口也是同一个页面。
3. 官网另有一页说明：**除中国区之外，日本、港澳台、韩国、美国、欧洲、澳洲等地区的 App Store 也能下载**，但需要登录对应地区的 Apple ID。是否要这么做，取决于你手上已有的 Apple ID 在哪个区。
4. iOS 版按 App Store 的规则更新与扣款，界面位置与安卓版不完全一样，本篇下面提到的设置路径都以安卓为准。

两端账号能否共用同一份时长、同一份积分，以你在应用内登录之后实际看到的数据为准；拿不准就先用安卓端登录看一眼剩余天数，再在 iOS 端登录对照。

## 七、装完先做三步自检

别急着开游戏，先花一分钟确认这三件事：

1. **能打开、不闪退**：图标点进去能进主界面，能看到「开启加速」按钮和剩余服务时间。反复闪退看 [初始化失败与闪退怎么排查.md](初始化失败与闪退怎么排查.md) 第二节。
2. **能走到注册 / 登录那一步**：首次打开会先让你同意用户协议与隐私政策，之后进「我的」能看到注册 / 登录入口。能正常注册或登录，说明账号这一环通了，详细流程见 [注册登录与账号设置.md](注册登录与账号设置.md)。
3. **点开关有反应**：点一次「开启加速」，按钮状态变成开启态（同时系统可能弹一次连接授权，同意即可）。

三步都过，就可以按 [开启加速与游戏库怎么用.md](开启加速与游戏库怎么用.md) 里的顺序去搜游戏、开加速了。

## 八、升级与卸载

- **升级**：新版本会换一个安装包文件名，直接覆盖安装即可。**不要先卸载** —— 卸载会清掉应用本地数据，登录状态也要重来一遍。
- **卸载**：换机或重装前，确认自己已经注册并登录过账号；剩余时长、积分、邀请奖励都挂在账号上，重装后登录同一账号才能看到。
- **安装包丢了**：回到本篇开头那条网盘链接重新取一次即可，已经转存过的版本不受原分享状态影响，取包与安装步骤同上。
- **系统升级之后打不开了**：先用覆盖安装试一次；还是不行，多半是这一版与新系统不兼容，改到应用商店装最新版更省事。官方用户协议里也写明：新版本发布后旧版本可能无法使用，所以长期不更新是有风险的。
