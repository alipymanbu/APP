# 树懒Acc 初始化失败与闪退怎么排查

> 「初始化失败」「一进去就闪退」是树懒Acc 反馈里最集中的一类问题。官方自己给过三类原因，本篇把它们拆成可逐条对照的排查顺序，从最可能的那一条开始。

## 一、按这三类逐条对

官方公告《树懒acc初始化失败，闪退问题》给出的原因只有三类，第三方软件站转述的也是同样三条。**先按顺序对一遍，不要一上来就卸载重装。**

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 打开就闪退、初始化失败 | 设备环境不支持 | 见下表，逐项排除 |
| 初始化失败，其他应用正常 | 手机系统时间不对 | 开「日期与时间」的自动设置 |
| 之前能用，突然不行了 | 账号判定异常（恶意注册、账号多人共用） | 见本节第三类 |

### 第一类：设备环境不支持

官方明确列出的五种情况：**不支持模拟器运行、不支持低于安卓 5.0 的系统、不支持低于 iOS 9.0 的系统、不支持 Root 过的设备、不支持越狱过的设备。**

| 你的情况 | 结论与做法 |
| --- | --- |
| 在电脑模拟器里装 | 不能用。换真机；为什么这条路走不通、替代做法见 [电脑上能不能用.md](电脑上能不能用.md) |
| 手机系统低于安卓 5.0 | 装不上或用不了，只能换设备 |
| iPhone 系统低于 iOS 9.0 | 同上 |
| 手机 Root 过 | 需要取消 Root（多数情况下要刷回官方系统），这是很多人忽略的一条 |
| iPhone 越狱过 | 同上 |
| 手机没 Root，系统也够新 | 看第二类 |

### 第二类：系统时间不对

这一条最容易被忽略，也最好修：

1. 打开「设置 → 系统 → 日期与时间」（各机型路径略有差异）。
2. 打开「自动设置时间」/「使用网络提供的时间」。
3. 回到树懒Acc，**完全退出后重新打开**（不是只切到后台）。

如果手机时间比实际时间差得比较多，应用与服务端的校验就对不上，表现就是初始化过不去。手动改过时间来玩游戏、或用过某些改系统时间的工具，回到这里改回自动即可。

### 第三类：账号被判异常

官方公告的原话是「为了防止恶意用户滥用影响其他用户，有采用系统性的防御措施，请不要恶意注册、滥用或者将账号分享给多人使用」。落到具体行为上就是三件事：

1. **短时间内反复注册新账号**（比如为了多领免费时长）；
2. **把账号借给别人、和多人共用**；
3. **拿别人的账号登录**。

这几条在官方用户协议里也都写了后果：可以暂停或终止服务、注销账号并回收权益。如果你做过上面任何一件事，正确的处理不是反复重装，而是**用回自己正常注册的那一个账号**；确实被封了，只能通过应用内的「帮助与反馈」找官方申诉，申诉入口与联系方式见 [注册登录与账号设置.md](注册登录与账号设置.md) 第五节。

## 二、闪退的另外几种情况

上面三类之外的闪退，按下面顺序试：

1. **装完第一次打开就闪退**：先确认安装包是不是完整下载的（大小 3.63 MB 左右、以 `.apk` 结尾），续传下坏过一半的包最容易出现这种情况 —— 删掉重新下。
2. **系统升级后开始闪退**：多半是这一版与你的新系统不兼容。先用覆盖安装试一次；不行就换成应用商店里的最新版。官方用户协议里写明新版本发布后旧版本可能无法使用，长期停在旧版风险是存在的。
3. **用到一半闪退**：先看是不是刚点了「开启加速」就崩 —— 那种情况优先查第三节的授权问题（在 [开启加速与游戏库怎么用.md](开启加速与游戏库怎么用.md)）；如果崩在注册登录过程中，先确认网络通不通。
4. **清完缓存/数据之后才出问题**：清除应用数据会一并清掉本地登录状态，重新登录即可，账号里的时长不会丢。

## 三、都排查过还是不行

按这个顺序找官方：

1. **应用内「帮助与反馈」** —— 官方在应用商店的说明里指定的联系方式，渠道、账号、环境类问题都从这里提。
2. **官网 [shulanapp.com](https://shulanapp.com)** 上的合作邮箱 `support@wesloth.com` 与官方微博入口。

提问题时把这几项一次说清，能少一轮来回：手机型号与系统版本、是否 Root / 越狱、是否在模拟器里、树懒Acc 的版本号、报错原文或截图、出问题的时间点。

## 四、有几个动作不要做

- **不要反复卸载重装**：卸载会清掉本地登录状态，而对第一类（环境不支持）与第三类（账号异常）问题，重装根本解决不了。
- **不要为了「换个环境试试」去装来路不明的包**：换包只会多一个变量，核对方法见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。
- **不要清理其他应用的数据**、也不要随手关掉系统服务来「腾环境」，那会把别的东西弄坏。
