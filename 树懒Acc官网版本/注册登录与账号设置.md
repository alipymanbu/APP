## 一、账号是干什么用的

树懒Acc 的加速时长、积分、邀请奖励，都是记在账号上的，不是记在手机上。这意味着两件事：

- **换手机、卸载重装之后，登录同一个账号就能把时长和积分找回来**；
- 反过来，**没登录就用（游客状态）的那部分数据，换设备拿不回来**。

所以拿到应用后第一件事不是急着开加速，而是先把账号登录上。

## 二、注册与登录怎么走

1. 打开应用，先进「我的」界面。
2. 找到「注册 / 登录」入口，点进去。
3. 按提示填注册信息（官方协议里提到会用到手机号这类真实身份信息），提交后点「注册」。
4. 注册成功后一般会自动登录，回到主界面就能看到剩余服务时间。

入口的文字与位置各版本调整过，以你手机上显示的为准。如果打开后找不到注册入口，先确认自己点的是「我的」而不是「设置」——这两个界面的距离很近。

## 三、官方用户协议里，和你直接相关的几条

下面几条摘自官方用户协议（转述原意，具体表述以协议原文为准），它们会实实在在影响你用起来顺不顺：

| 协议内容 | 对你的影响 |
| --- | --- |
| 可以先不注册、以游客身份使用；但基于账号安全与法律法规要求，官方随时可能停止未实名账号的服务 | 打算长期用就直接注册，别等被拦下来 |
| 账号只能自己使用，**不得赠与、借用、租用、转让或售卖** | 帮朋友「代练式」共用账号属于违约，不是省事 |
| 若官方发现或合理认为使用者不是账号初始注册人，可暂停或终止服务并注销账号 | 共用账号的两个人可能同时用不了 |
| 注册后长期未登录（协议写的是连续超过六个月未登录）可能被收回账号 | 极少用的账号偶尔登一次 |
| 频繁注册、批量注册、恶意注册会被注销账号并回收相关权益 | 别为了多领免费时长短时间内反复注册 |

另外要提醒的是：官方公告在解释「初始化失败」时，把「恶意注册或其它违反平台规定的情况」列为三类原因之一 —— 对应的排查顺序见 [初始化失败与闪退怎么排查.md](初始化失败与闪退怎么排查.md) 第一节第三类。

## 四、换手机、重装、装错版本之后

| 场景 | 该怎么做 |
| --- | --- |
| 换手机 | 新机上装好应用，登录**原来那个账号**，剩余时长与积分会回到界面上 |
| 卸载重装 | 同上，重装前确认自己登录过账号 |
| 之前一直用游客状态 | 数据无法迁移，只能从现在开始注册使用 |
| 从非官方渠道装的包 | 先看是否登录过账号，再换回官方包重装，核对方法见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md) |
| 安卓换 iOS（或反向） | 两端界面与购买渠道不同，登录后各自显示什么以应用内为准 |

换机之后如果发现时长不见了，先确认登录的是不是原来那个账号，再对照 [常见问题与排查.md](常见问题与排查.md) 里账号与时长那一节。

## 五、忘记密码、以及怎么找官方

- **忘记密码**：走登录页的找回 / 申诉入口。官方协议里说明，找回时系统核对的是申诉资料与后台记录是否一致，它并不能判断申诉的人是不是账号真正的主人 —— 所以**注册时填的信息尽量填真实、能记住的**，这直接决定你能不能找回。
- **找官方**：应用内的「帮助与反馈」是最直接的一条路，也是官方自己在应用商店说明里给出的联系方式 —— **账号、时长、扣款这类问题走这里**。官网 [shulanapp.com](https://shulanapp.com) 上另留有邮箱 `support@wesloth.com`（官网页面上标注的用途是合作事宜）与官方微博入口，公告类信息看微博。别在第三方论坛里找「客服」。
- 论坛、评论区里出现的「代查账号」「帮你补时长」一律不要信。

## 六、账号安全的几个习惯

1. **一个账号只自己用。** 多人共用一个账号不但违反协议，还容易触发风控，表现就是应用打不开或者初始化失败。
2. **别在图省事的时候反复注册小号**去领免费时长，官方协议里写明这类行为会被注销。
3. **密码不与其他账号复用。** 找回流程只核对资料一致性，账号一旦被别人申诉走，很难证明是你本人的。
4. **换机前先确认能登录。** 卸载是不可逆的，本地数据会跟着一起没，账号里没有的数据就真没了。
