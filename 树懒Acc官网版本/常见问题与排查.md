## 一、加速相关的

**开了加速还是延迟高、卡顿**

1. 先看剩余服务时间是不是 0 —— 为 0 时开关看着是开的，实际不生效。这种情况直接看 [会员时长与续费怎么买.md](会员时长与续费怎么买.md)。
2. 再看第一次开启时那次系统连接授权有没有被拒；拒过就相当于没接管流量。重新授权的路径在 [开启加速与游戏库怎么用.md](开启加速与游戏库怎么用.md) 第三节。
3. 换个网络对比一下：从 Wi-Fi 切到蜂窝数据再试。家里 Wi-Fi 长期没断电的话重启一次路由器；同时把正在下载、看视频这类占带宽的任务停掉。如果只有某一个 Wi-Fi 下卡，问题在那一侧的网络，不在应用。
4. 确认玩的是加速生效的那个游戏进程 —— 加速是按游戏识别的，开着加速去玩客户端里的小游戏、或者用浏览器看视频，不等于有加速效果。
5. 如果上面都排除了，而且**只有某一款游戏**不行、别的游戏正常，那多半不是你能修好的，看 [某个游戏突然不能加速了怎么办.md](某个游戏突然不能加速了怎么办.md)。

**玩到一半掉线**

- 先在掉线后立刻看一眼加速开关是否还在开启态。切到后台被系统清理掉是常见原因，处理办法见下一节。
- 如果是「小概率断线」，官方更新日志里出现过「小概率断线问题的修复」，说明这类问题历来是随版本修的 —— 停在旧版会一直遇到，覆盖安装新版更直接。

**切到游戏之后加速就断了**

- 这是后台被杀。到「设置 → 应用 → 树懒Acc → 耗电管理 / 电池」里把它设为**允许后台活动**，并加入电池优化白名单；部分机型还要在最近任务里给它「加锁」。
- 省电模式开着时，系统会更激进地清理后台，玩游戏时先关掉省电模式。

## 二、游戏库相关的

**搜不到想玩的游戏**

官方在应用商店说明里给的路径是：新游支持、功能改进这类需求都可以通过**应用内「帮助与反馈」**联系。把游戏全名、区服写清楚提上去即可，不用在论坛里等别人转达。

另有一种情况是**之前能搜到、现在搜不到了**，那和「从来没有过」不是一回事，判断方法见 [某个游戏突然不能加速了怎么办.md](某个游戏突然不能加速了怎么办.md)。

**点安装没反应、游戏内数据下载很慢**

1. 先在开启加速的状态下重试一次 —— 借助加速通道下载本来就是它的用法之一。
2. 检查手机剩余存储空间，空间不足时安装动作会直接失败而不报明确原因。
3. 游戏本体在不在应用商店上架、是否要靠对应地区的账号购买，这是游戏那边的事，跟加速无关。

**支持的到底是几百款还是上千款**

官网首页写「1000+ 款游戏已支持」，应用商店的说明写「数百款新老海外手游」。**两个口径不同，以你在应用内能搜到多少为准**；数量本身是持续变的，不必拿某个数字对照。

## 三、账号与时长相关的

**换了手机，剩余时长不见了**

- 九成是登录了另一个账号。先退出登录，再用原来那个账号登一次；时长、积分、邀请奖励都挂在账号上。
- 如果原本一直用游客状态，那是拿不回来的 —— 游客数据不跨设备，以后记得先注册。
- 详情见 [注册登录与账号设置.md](注册登录与账号设置.md) 第四节。

**填了邀请码但没看到时长到账**

- 官方口径是「填写完毕后您和邀请您的人会同时获得免费使用时间」，但没有写死到账时间。等几分钟、重开一次应用再看。
- 确认这确实是你第一次填：**每个人只能填一次别人的邀请码**，填过之后入口会消失、也无法更换，见 [邀请码与免费时长怎么拿.md](邀请码与免费时长怎么拿.md)。

**时长走得比预期快**

- 计费是按天倒计时，不是按「实际开启加速的小时数」计 —— 官方对外的说法是「购买服务天数」，没有提暂停机制。买长周期前先按这个前提算一遍；依据见 [会员时长与续费怎么买.md](会员时长与续费怎么买.md)。

## 四、环境与设备相关的

**能在电脑模拟器上跑吗**

不能。官方明确列出不支持模拟器运行，同类限制还有 Root 设备、越狱设备、低于安卓 5.0 / iOS 9.0 的系统。完整清单和逐条处理见 [初始化失败与闪退怎么排查.md](初始化失败与闪退怎么排查.md) 第一节。

**那电脑上还有别的办法吗**

没有官方的电脑版可用，装模拟器这条路官方已经堵上。想投屏到电脑上看、或者用电脑给手机传安装包，这两件事不受影响，具体说明和「电脑版下载」页面的识别方法见 [电脑上能不能用.md](电脑上能不能用.md)。

**能不能一边用别的应用一边加速**

加速接管的是网络链路，不限制你同时开别的应用。真正会打断它的是系统把应用清掉（见第一节第三条），不是同时开了几个应用。

## 五、想重装或者换机，重新取一份安装包

换手机、手机系统升级后打不开、原包被误删，都可以从同一个地方重新取：在手机上打开 [树懒Acc 安装文件资源（夸克网盘）](https://pan.quark.cn/s/1f17a8cacf14)，转存之后下载，再按 [下载与安装教程.md](下载与安装教程.md) 第四节安装。重新装之前别忘了先确认账号能登录，时长是跟着账号走的。

## 六、怎么找官方

| 渠道 | 适合问什么 |
| --- | --- |
| 应用内「帮助与反馈」 | 游戏支持需求、功能问题、账号异常申诉（官方在应用商店说明里指定的入口） |
| 官网 [shulanapp.com](https://shulanapp.com) 上的合作邮箱 `support@wesloth.com` | 合作与一般咨询 |
| 官网上的官方微博入口 | 公告类信息 |

提问时把手机型号、系统版本、应用版本号、报错原文或截图一次给全。**评论区、论坛里的「客服」和「代充」「代补时长」都不是官方渠道**，涉及账号和付款的事只走上面这三个入口。
