FNF夜间协议 是《Friday Night Funkin'》的一首单曲模组，曲目原名 Nocturnal Protocol，题材取自《Myths of Tubbyland》，对手是「守护者」与腐化后的天线宝宝角色。本篇只做两件事：帮你核对网盘里这份包到底是哪一版，以及把它顺利装进你的安卓设备。

## 一、先核对网盘里这份包是哪一版

各下载站标的版本号是他们自己的登记，和网盘里这份常常对不上。本文出现的版本、包名、体积一律以下表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | FNF夜间协议 |
| 版本标识 | `txh` |
| 包名 | `com.shadowmario.psychengine` |
| 安装包体积 | 131.13 MB |
| MD5 | `B1AB60E8C84723C201CAF6EC2A5141DD` |
| 形态 | 安卓 APK |
| 本文核对时间 | 2026-09-23 |

几点容易混的地方：

- **版本标识写的是 `txh`**，不是常见的 `1.x.x` 形式。这是打包这一版的人自己的标记方式，不影响安装，也不代表新旧，按上表认包即可。
- **判断是不是同一个包，看包名 + MD5**，不要看名字旁边的版本数字。网上搜到的是曲目的最新重制版，和网盘里这份并非同一版，版本标识不同是正常的。
- **包名 `com.shadowmario.psychengine` 是公用的**。这套手机端打包走的是社区引擎 Psych Engine 的包名，所以**很多别的 FNF 模组打包版的包名和它一模一样**。装之前先想一下：手机里如果已经装了另一个同包名的 FNF 模组，装这份会把它覆盖掉，两个不能共存。

## 二、安卓上安装

1. **先转存再下载**。打开 [FNF夜间协议 安装文件资源（夸克网盘）](https://pan.quark.cn/s/00397303c3a3)，先把 APK 转存到你自己的网盘，再从网盘里下载到手机。转存别省：分享链接失效后，只有转过存的那份还在。
2. **允许安装未知来源应用**。在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，允许你准备用来打开安装包的那个应用（文件管理器、浏览器或网盘客户端），再点 APK 安装。
3. **看到「应用未安装」先卸载旧版**。手机里若已有同包名但签名不同的版本，覆盖安装会直接失败，先卸掉那个再装。
4. **给足存储空间**。安装包本身 131.13 MB，装完还要占一份应用体积，再留一点给运行时的缓存，别把空间卡在临界值上。
5. **安装包别只留在本地**。转存过的那份留在你自己的网盘里，才是长期可用的备份；只存手机本地的话，误删或换机就得重新去找。

## 三、为什么它不需要你另外装引擎

《Friday Night Funkin'》的模组分两种玩法，网盘里这份属于**打包好的那一种**：

| 玩法 | 你需要做的 | 适合谁 |
| --- | --- | --- |
| 自己装引擎 + 放模组 | 先装 Psych Engine 客户端，再把模组文件夹放进应用的 `mods` 目录 | 手上已经有一堆模组、想随时切换的人 |
| 直接用打包好的安装包 | 装一个 APK，打开就是这首曲子 | 只想玩这一个模组、不想折腾文件目录的人 |

网盘里这份是后者：曲目已经打包进手机端安装包，**装上打开就能玩，不用自己准备引擎，也不用去 `Android/data` 这类目录里搬文件**。想在手机上看 `Android/data` 里的内容，在 Android 11 之后还得靠支持访问隐藏目录的文件管理器或电脑，那条路对只想玩一首曲子的人来说没必要走。

## 四、第一次打开先做三件事

1. **确认能进主菜单**。能出现主菜单就说明引擎跑起来了；停在黑屏、或者一闪就退，见 [打不开闪退和卡顿怎么排查.md](打不开闪退和卡顿怎么排查.md)。
2. **先在 Freeplay 里把音量与谱面看一眼**。进曲目选择界面，确认这首 Nocturnal Protocol 在里面、且能正常加载。曲目加载不出来通常是包不完整，重下一次安装包即可。
3. **顺手把键位和下落方向调成你习惯的**。手机横屏握持时四个方向键的位置未必顺手，改键位、谱面下移这些都在设置里，位置见 [按键判定与游戏设置怎么调.md](按键判定与游戏设置怎么调.md)。

## 五、装完做一次最小验证

进 Freeplay 选 Nocturnal Protocol，随便打一小段，看三件事：

- **有声音、音符在动** → 包和音频都正常，装成了；
- **有画面但按了没反应** → 是触控或键位设置问题，见 [按键判定与游戏设置怎么调.md](按键判定与游戏设置怎么调.md)；
- **装完打不开、或者进去就闪退** → 见 [打不开闪退和卡顿怎么排查.md](打不开闪退和卡顿怎么排查.md)。
