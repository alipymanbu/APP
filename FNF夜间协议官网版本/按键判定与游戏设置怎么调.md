网盘里这一版跑在社区引擎 Psych Engine 上，所以它的菜单结构和设置项就是这套引擎的那一套。本篇按「先看懂判定、再动手调」的顺序来：先弄清音符怎么算命中，再逐个说改键位、延迟、谱面方向、帧率这几个选项管什么。

## 一、一局是怎么打的

屏幕上有四条轨道，对应左、下、上、右四个方向。音符从一侧往判定区移动，落到判定区内时按下对应方向就算命中。对手（这里是「守护者」）也在同一首曲子里按自己的谱面出招，血条是双方共用的：你命中就回一点，漏掉就往对手那边偏。

| 界面上你会看到 | 它代表什么 |
| --- | --- |
| 四条轨道与下落音符 | 你要按的方向与时机 |
| 中间的判定等级 | 这一下按得准不准（越往前越好，最差是 Miss） |
| Combo 数字 | 连续命中数，断一次归零 |
| Accuracy | 整曲准确率，和连击不同，断连不影响已得的准确率 |
| Miss 数 | 漏掉或按错的累计次数 |
| 血条 | 空到对手一侧即本局失败 |

## 二、手机上怎么按

- **四个方向键就在屏幕下方**，点按即可，按早了或按错了都会掉准确率。
- **横屏握持**是常规姿势：两只手各管两个方向键，屏幕中间留给看谱面。
- **别用指甲或戴厚手套按**，触控面板对这类接触点识别不稳，会表现为「明明按了却判 Miss」。
- **音游手感的一半在延迟**。如果你觉得「我明明踩在点上却判早/判晚」，那多半不是手的问题，去调第三节的偏移。

## 三、最值得调的四个设置

设置入口在**主菜单的选项（Options）里**，分「控制」和「偏好」两栏：

| 设置 | 在哪 | 调它解决什么 |
| --- | --- | --- |
| 键位（Controls） | 控制栏 | 手机横屏时四个方向键的位置/大小不顺手 |
| 延迟与偏移（Delay / Combo Offset） | 控制栏 | 音画不同步导致「踩不准」 |
| 谱面方向（Downscroll / Middlescroll） | 偏好栏 | 习惯音符从上往下落，或想让谱面居中 |
| 帧率与画质（Framerate / Low Quality / Anti-Aliasing） | 偏好栏 | 掉帧、发热、闪退 |

逐个说：

1. **改键位**：进 Controls，把四个方向各自点一遍，再按下你想用的位置。改完**一定要退出去打一小段验证**，键位设错的表现是「按了完全没反应」，容易误以为是游戏坏了。
2. **调延迟**：选项里有一项管按键与音频的对齐（不同版本叫 Delay 或 Offset）。判早判晚就小幅加减，**一次只改几个数值，改完打同一段**对比，别一口气拉到底。
3. **换谱面方向**：偏好里打开 Downscroll 后音符从上往下落，适合习惯下落式音游的人；Middlescroll 会让谱面靠中间。这两个纯粹看个人习惯，不影响判定。
4. **压帧率与画质**：偏好里能设帧率上限，也能开低画质、关抗锯齿。中低端机卡顿优先动这里，详见 [打不开闪退和卡顿怎么排查.md](打不开闪退和卡顿怎么排查.md)。

同一栏里还有几个和画面对应的开关：音符溅射（Note Splashes）关掉能省一点性能；**闪烁光效（Flashing Lights）建议先关掉再打**，这首曲子本身气氛偏暗、有突然的光效，对光敏感的人先关为妙。有的版本里还有 Ghost Tapping 这类选项（提前轻按不算失误），按错频率高的话可以打开找手感。

## 四、选歌界面还能改两件事

在 Freeplay（自由选曲）里选中曲目后，调设置的位置还能改两项：

- **Scroll Speed（下落速度）**：音符移动的快慢。看着太挤就调慢，觉得太拖就调快，它对判定宽容度没有影响，只影响你读谱的难度。
- **Damage（受伤量）**：一次失误掉多少血。

这两个值是**临时调、当场生效**的，适合先在这儿试出舒服的数，再决定要不要固化成习惯。

## 五、打不过去时先别怀疑自己

这首曲子是一整首单曲、没有分段，失误一多就容易一路崩。按这个顺序排查：

1. **先确认不是设备问题** —— 掉帧会让判定整体偏，见 [打不开闪退和卡顿怎么排查.md](打不开闪退和卡顿怎么排查.md)；
2. **再确认不是延迟问题** —— 重调第三节里的偏移；
3. **最后才是难度** —— 降 Scroll Speed、熟悉谱面段落。

想了解这首曲子的段落结构和两个结局怎么看，接 [曲目背景与两个结局怎么看.md](曲目背景与两个结局怎么看.md)。
