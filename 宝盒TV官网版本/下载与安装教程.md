宝盒TV 是装在大屏上看影视的应用，界面按遥控器操作设计，片单与分类都来自应用里配置好的资源接口。本篇只做一件事：把网盘里那份包完整、正确地装到你的设备上并打开它。

下面这张表是当前网盘里那份包的实际信息。装之前在电脑上对一次，装完在设备上还能再对一次，两次都对得上才算装对了东西。

| 应用名 | 宝盒TV |
| 包名 | `com.CatBox` |
| 版本 | 5.2.6 |
| 安装包大小 | 54.35M |
| 安装包 MD5 | `d6712201b2be3b4601bf6129ba1a0fe6` |

三条判断：

- **认包名最稳**：网上叫「宝盒TV」的东西不止一个，图标和名字都靠不住，包名 `com.CatBox` 才唯一。同名应用的区分见 [同名应用与版本怎么认.md](同名应用与版本怎么认.md)。
- **留出足够空间**：安装包本身 54.35M，装完占用更大，设备上留 100M 以上的空闲空间比较稳妥。
- **最低系统版本没法照搬**：各处下载页对它的写法不一致（有写安卓 4.4 的，也有写更低的），这份包的记录里没有这一项。老设备（安卓 5 以下）能不能跑起来，以实机安装结果为准。

## 二、从网盘把安装包取到本地

1. 打开 [宝盒TV 安装文件资源（夸克网盘）](https://pan.quark.cn/s/ee8810ef35dc)。
2. 先点「保存到我的网盘」，再下载。转存一次之后，即使原来那条分享以后失效，你手上这份也还在。
3. **建议在电脑上取包**：后面拷 U 盘正好顺手，电视端的浏览器下载既慢又难找文件位置。
4. 文件名一般是 `宝盒TV_v5.2.6.apk` 这种形式，以网盘里实际显示的名字为准。

## 三、动手装之前先校验一次

安装包在网络传输中出错，装的时候会报「解析包错误」。花半分钟对一次 MD5，能省掉后面一串没头绪的排查。

把 APK 拷到电脑上，在它所在目录执行：

```powershell
certutil -hashfile "宝盒TV_v5.2.6.apk" MD5
```

输出的十六进制串去掉空格后，应该和第一节表里的 `d6712201b2be3b4601bf6129ba1a0fe6` 完全一致（大小写不敏感）。对不上就重新下载一次，别将就着装。

## 四、装到电视盒子 / 智能电视（U 盘法）

大屏设备上最稳的一条路，不需要在电视上登录任何账号：

1. 把上一步校验过的 `.apk` 复制到 U 盘根目录。**文件名建议改短**（例如 `bhtv.apk`），有些电视的文件管理器对长中文名显示不全，改短能少一个变量。
2. 拔下 U 盘，插到电视或盒子侧面或背面的 USB 口。
3. 在设备上打开自带的「文件管理」（有的叫「媒体中心」「外接存储」「U 盘」），切到外接存储那一栏。
4. 找到那个 `.apk` 文件，点它开始安装。
5. 中途若弹出「禁止安装未知来源应用」，先按第五节放行，再回来重装一次。

装完在设备的「应用」列表里能找到它。桌面图标没有自动出现的话，从应用列表里直接打开，或者把设备断电重启一次，图标通常会补到桌面上。

## 五、先去系统里放行「未知来源」

网盘里的包不是从应用商店装的，安卓默认会拦一次。要给**你用来安装的那个应用**（文件管理器或浏览器）开安装权限：

| 设备 | 大致路径 |
| --- | --- |
| 小米电视 / 小米盒子 | 设置 → 账号与安全 → 允许安装未知来源的应用 |
| 当贝、天猫魔盒一类安卓盒子 | 设置 → 安全 → 未知来源 |
| 华为智慧屏 | 设置 → 安全 → 更多安全设置 → 安装外部来源应用 |
| 索尼等原生安卓电视 | 设置 → 应用 → 安全和限制 → 未知来源 |
| 手机 / 平板 | 设置 → 应用 → 特殊应用权限 → 安装未知应用 |

各家的叫法与层级都不一样，记不住就在设置的搜索框里搜「未知来源」或「外部来源」，基本都能跳到同一页。**放行的是安装动作的来源，不是应用本身**：用文件管理器装就放行文件管理器，用浏览器下载安装就放行浏览器。

## 六、装到手机或平板

1. 把 `.apk` 传到手机上，在文件管理器里点它安装，走完进度条即可。
2. 部分手机还要额外关掉「纯净模式」，或允许该来源安装应用，弹窗会直接把你导过去。
3. 界面是按横屏大屏设计的，装在手机上操作方式以实机表现为准；拿到遥控器体验的设备上，操作方式见 [遥控器操作与界面导航.md](遥控器操作与界面导航.md)。

## 七、装不上、装完打不开

按这个顺序排查，比反复重装有效：

- **提示「解析包错误」「应用未安装」** → 回到第三节重新校验 MD5，文件多半没下完整。
- **提示「已被阻止安装」** → 第五节那项权限没开，或者开给了别的应用。
- **装了但应用列表里找不到** → 部分电视桌面不自动添加快捷方式，去「设置 → 应用 → 全部应用」里找；找不到说明其实没装上。
- **点图标闪一下就退回桌面** → 多为设备系统版本偏低或设备内存不足，换一台设备试装是最快的判断方法。
- **提示空间不足** → 先清出不小于安装包两倍的空间再装。
- **装完打开了但里面是空白** → 这不是安装问题，按 [加载不出内容与播放卡顿怎么排查.md](加载不出内容与播放卡顿怎么排查.md) 排查。
