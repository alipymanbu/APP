片单和分类来自应用里配置好的资源接口，所以**同一个片名下面往往挂着好几条来源**。这一层带来的最大好处是：卡顿、黑屏、只有声音没画面，多半换一条就解决，不用清缓存也不用重装。

## 一、换线路：第一优先的动作

播放页呼出控件层后，找「线路」「换源」「播放源」这一类选项（不同版本叫法不同，认它旁边是不是列着一串并列的条目即可）。

什么时候该换：

| 现象 | 处理 |
| --- | --- |
| 缓冲圈转了十几秒不动 | 换下一条 |
| 能播但模糊，另一条同集是高清 | 换 |
| 某一集点开是黑的，同剧其他集正常 | 只换这一集 |
| 有声音没画面 | 换（多半是这条源编码与应用不匹配） |
| 换了之后从片头重来 | 手动把进度拖回去，换线路不一定继承进度 |

两点经验：

- **别连着点好几条**。每条线路都要建立一次连接，连点会让前一次连接还没断开就开始下一次，反而更容易卡。选中一条，等它出画面。
- **换线路治不了「整个应用的片单都打不开」**。那种情况是配置层面或网络层面的问题，按 [加载不出内容与播放卡顿怎么排查.md](加载不出内容与播放卡顿怎么排查.md) 排查，换线路是白费力气。

## 二、清晰度：跟着来源走，不是越高越好

清晰度档位（标清 / 高清 / 超清之类）是**这一条线路自己提供的**，所以：

- 一条线路只提供标清，档位列表里就不会有高清这一项，想要更高的清晰度只能换到别的线路；
- 大屏上看，低清晰度的噪点很显眼。电视接的是家里宽带，网络条件通常比手机好，能选高就选高一档；
- 转圈多、出画慢的时候，**降一档清晰度往往立刻见效**，这比换线路更快。

## 三、画面比例：被拉伸或出现黑边时用

画面比例（有的写「屏幕比例」「缩放」）解决三种观感问题：

| 现象 | 调法 |
| --- | --- |
| 人物被横向拉扁 | 从「全屏 / 拉伸」切回「原始 / 自适应」 |
| 上下或左右有明显黑边 | 切到「全屏」，代价是可能裁掉一点边缘 |
| 字幕被切掉一半 | 用「自适应」并留意有没有字幕位置的选项 |

老片和新片的画幅本来就不一样，出现黑边不一定是设置错了。**先看画面里的人物有没有变形** —— 变形才是设置问题，黑边通常不是。

## 四、倍速、字幕、音轨

| 项目 | 说明 |
| --- | --- |
| 倍速 | 追剧赶进度用。开到 1.5 倍以上，字幕和嘴型会比 1 倍速更容易对不齐，这是常见的观感差异 |
| 字幕 | 能不能显示取决于这条来源本身带不带字幕文件。列表里有「字幕」项但点开是空的，就是来源没带 |
| 音轨 | 多语言片子才会有多项，选了之后要等一两秒切换，没反应再选一次 |
| 定时关闭 | 睡前看的话用得上，按剩余时长或到点时间设，大多数版本都会保留上次的选择 |

## 五、播放内核要不要换

这部分先看你的设置里有没有。**如果你的版本里没有「播放内核」「解码方式」这类选项，直接跳过本节** —— 默认那一套就是给你这台设备用的。

有这一项时，可选项通常包括系统自带的播放器内核、软解硬解之类。简单的判断方法：

1. 先保持默认不动，正常看着就别改；
2. 出现「画面正常但一直掉帧」「颜色明显发灰发绿」「有声音没画面」这三种情况之一，才换一次内核试试；
3. 换完仍然一样，说明问题不在内核，回到第一节换线路，或者去查网络与设备性能。

软解与硬解的取舍不用记原理：**老设备上发热、掉帧明显时优先试硬解；硬解下画面花屏就切回软解**。改完记得退出播放页重新进一次，在同一部片子里切内核经常不生效。

## 六、想让画面稳定的几条固定习惯

- 播放前把设备的省电模式关掉，它会压解码性能，表现为画质正常但持续掉帧；
- 大屏用网线比 WiFi 稳，盒子有网口就插网线，这是最省事的一次性投入；
- 别在后台同时挂着别的下载，尤其是电视盒子上还开着其他应用的时候；
- 长时间连续看，设备会积热降频，卡顿从这里来的话，让它歇几分钟比任何设置都管用。
