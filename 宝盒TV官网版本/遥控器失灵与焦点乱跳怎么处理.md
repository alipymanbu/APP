# 宝盒TV 遥控器失灵与焦点乱跳怎么处理

> 遥控器按键没用、焦点乱跳、按键控制了别的设备 —— 这三种现象的成因完全不同。本篇按症状分类，给出从电池到 HDMI-CEC 的排查顺序。

大屏上的操作全靠遥控器，所以「遥控器不好使」和「应用不好用」在体感上是一件事。先把症状对上，能省掉很多没用功 —— 比如焦点乱跳是设备侧的信号问题，换应用、重装应用都不会有任何变化。

## 一、按症状先分类

| 症状 | 最可能的原因 | 看第几节 |
| --- | --- | --- |
| 完全没反应，按什么都不亮 | 电池、触点、遥控器本身 | 第二节 |
| 只有电源键有用，方向键全没用 | 蓝牙配对断了（红外部分还活着） | 第三节 |
| 要凑到设备跟前按才有反应 | 红外被挡、或蓝牙信号弱 | 第四节 |
| 反应慢、按一下跳两格、焦点乱跑 | 按键抖动、信号干扰、配对状态异常 | 第五节 |
| 按音量却切了输入源、开了音响时遥控失灵 | HDMI-CEC 冲突 | 第六节 |
| 遥控器正常，但应用里焦点卡住不动 | 应用内部的弹窗或界面状态 | 第七节 |

## 二、电池与触点：先做这两步

这两步最不起眼，但它俩解决掉的问题比后面所有设置加起来还多：

1. **换两节新电池**，别用抽屉里放了一半的。装之前看一眼正负极方向。
2. **擦一下电池仓里的金属触点**。触点上有锈蚀、油污或变形，就会出现「看着有电、按着没反应」。
3. 顺手检查按键有没有卡死或没回弹 —— 卡住一个键会持续发信号，表现出来就是遥控器整体抽风。

遥控器背面如果有一个小孔（复位孔），用牙签按一下可以复位，这是最省事的一招。

## 三、蓝牙遥控器：删掉旧配对再重连

现在的遥控器大多是「蓝牙负责方向键 + 红外负责开关机」的混合式，所以会出现「只有电源键管用」这种典型现象：红外那条路还通，蓝牙那条已经断了。

重新配对的做法大同小异：

1. 用鼠标或手机遥控类的应用救急进设置（设备支持外接鼠标的话，插上就能出现光标），进「遥控器与配件」或「蓝牙遥控器」那一页；
2. **先把列表里已经配过的遥控器记录全部删掉**。有用户反馈过这种情况：反复换电池都没用，最后发现是配对列表被占满了，清空之后一配就好 —— 这条属于社区经验，不一定适用于你的设备，但动手成本很低，值得先试；
3. 再按住遥控器上的组合键进入配对模式（常见是「主页键 + 返回键」或「主页键 + 菜单键」长按数秒，直到指示灯闪烁），在设备的配对页面里选中它，等它显示已连接。

**注意别在配对列表里同时留着两台同型号遥控器**，否则会出现「按一下不知道谁在响应」的乱跳。

## 四、红外部分：遮挡与验证

红外遥控必须对着设备的接收窗，没有蓝牙那种绕障能力：

- 确认设备红外接收窗（一般在机身正面或电源指示灯附近）前面没有摆件、防尘布、音箱挡住；
- **用手机相机验证遥控器还在不在发红外**：打开手机相机对着遥控器前端的发射头，按任意键，屏幕上能看到一个紫色的光点在闪，说明遥控器在发射，问题在接收端；看不到，说明是遥控器本身的问题；
- 换一个角度按（斜着按、抬高一点）有时立刻就通，说明接收窗位置偏。

## 五、按键抖动与信号干扰

「按一下跳两格」「焦点自己往下跑」多属这一类：

- **按键接触不良**：老化遥控器常见。试一次慢按、按实了再松手，看是否只有快按时才跳 —— 是的话就是按键问题；
- **蓝牙信号干扰**：设备周围挤着路由器、无线键鼠接收器、USB 3.0 硬盘时，蓝牙遥控会变迟钝。把蓝牙接收环境清一清，或者把设备挪开半米试试；
- **配对状态其实是半连接**：表现是走两步停一下、过一会儿又好了。办法还是回到第三节，删掉记录重新配一次。

## 六、HDMI-CEC：按键控制了别的设备

这一类最容易被误判成「遥控器坏了」。典型的三个症状：

- 按遥控器上的音量键，动的却是音响或功放；
- 一开音响，电视遥控就没反应了；
- 输入源自己乱跳，或者设备自己开机。

原因是 HDMI-CEC 让接在 HDMI 上的几台设备互相能指挥对方，设备一多就会「抢控制权」。排查办法是**临时关掉 CEC 再试**：

| 品牌/设备 | CEC 在菜单里的别名 |
| --- | --- |
| 索尼 | BRAVIA Sync |
| 三星 | Anynet+ |
| LG | SimpLink |
| 松下 | VIERA Link / EZ-Sync |
| 飞利浦 | EasyLink |
| 夏普 / 东芝 | Aquos Link / Regza Link |
| 多数盒子与电视 | 直接写 HDMI CEC |

先在电视或音响上关一次试；仍然乱，再把这台盒子的 CEC 也关掉。确认是它引起的问题之后怎么做取舍（要不要一直关着）取决于你家里有几台设备，本篇不替你决定。**菜单名称随品牌和固件版本变化，找不到就先在设置里搜 CEC。**

## 七、遥控器正常，但焦点卡住

如果只有某个应用里卡，遥控器在别处一切正常，那就不是遥控器的问题，而是应用界面的状态问题：

1. **先按返回键**。焦点被一个弹窗或提示框吃住时，方向键只在弹窗内部生效，先把当前这一层退掉；
2. 退到最外层（首页）再重新往里走一次，多半就恢复了；
3. 还不行就退出应用重进 —— 这比在设置里改任何选项都有效；
4. 应用界面本身比较卡的时候，遥控会看起来「按了没反应」，其实是在排队。等两秒再按，别连按。

判断方法很简单：**同一个遥控器在设备主界面上好不好使**。主界面顺、进应用就卡，问题在应用或设备性能，与遥控器无关，按 [播放线路与画面怎么调.md](播放线路与画面怎么调.md) 第六节里关于设备温度与降频那几条看。

## 八、什么时候该换遥控器了

三条硬指标，满足任意一条就没必要再修：

- **手机相机看不到红外光点**，且换新电池无效 —— 发射头坏了；
- 拆开看按键膜片明显破损、或者一按下去弹不回来；
- 设备里能搜到其它遥控器、配得上、也能用，只有这一只配不上 —— 这只的蓝牙模块坏了。

买替换遥控器时注意两点：**红外遥控要选支持你这台设备品牌/型号的**（或买带学习功能的通用遥控）；**蓝牙遥控要选明确写着支持安卓电视的**，普通蓝牙遥控器不一定能被电视系统识别。
