这类大屏应用的操作逻辑都一样：**全靠「焦点」**。遥控器的方向键移动的是一个高亮的方框（焦点），焦点停在哪儿，按确认键就是对哪儿操作。明白了这一点，下面的操作都不用背。

## 一、遥控器按键对应什么

| 按键 | 在这个应用里的作用 |
| --- | --- |
| 上 / 下 / 左 / 右 | 移动焦点。首页是上下换行、左右换列 |
| 确定 / OK | 执行当前焦点：进分类、开始播放、确认选项 |
| 返回 | 退回上一层。在首页连按会退出应用 |
| 菜单键（有的遥控器有） | 部分界面里呼出附加选项，没有这个键也不影响主要功能 |
| 音量、电源 | 由设备本身处理，与应用无关 |

不同遥控器的键位名称不一（有的把确定键印成「OK」、有的印成一个圈），对着上表理解功能即可。

## 二、首页怎么走

首页的构成通常是「上方一排分类 / 下方一块内容墙」：

1. 应用打开后焦点默认落在某个推荐位上。**先按返回键确认一下自己现在在第几层**——如果一按就退出应用，说明刚才已经在家最外层。
2. 用左右键在分类之间切换（电影 / 剧集 / 综艺 / 动漫这类），上下键在同一行里翻。
3. 焦点停在某个封面时，一般会显示片名或简介；按确定键进入。

**焦点卡住不动**：先按两次返回，退到首页再重试。焦点被弹窗吃住了（比如弹出的提示框）时，方向键只在弹窗内部生效，先把弹窗关掉。

## 三、播放页那一层控件

播放页的控件是**隐藏**的，多数版本按一下确定键或方向键才呼出来，几秒不操作又自动隐藏。呼出来的那一层通常按这几个顺序排列：

```
进度条  ←  播放 / 暂停  →  清晰度、线路、倍速、画面比例、字幕、音轨
```

用左右键在控件之间移动，焦点停在某项上按确定键展开它的选项列表。呼不出来、或者呼出来一下就消失，是遥控器按键抖动导致的，稳住手指再按一次即可。

各项具体怎么选，见 [播放线路与画面怎么调.md](播放线路与画面怎么调.md)。

## 四、片名怎么输入

搜索要靠屏幕上的软键盘，一个字一个字点，这是大屏上最累的一步。三条经验：

- **片名尽量输短**：输两三个关键字就够，剩下的靠结果列表辨认，别把整部片名敲完。
- **先按确定键选中输入框**，焦点变成光标之后再开始点字母；焦点还在外面时点字母是不生效的。
- **首字母往往更快**：多数聚合搜索对拼音首字母是认的，输「liuliang」和输「ll」都能出结果的范围要自己试一次。搜出来的东西怎么用，见 [搜索收藏与观看记录.md](搜索收藏与观看记录.md)。

如果遥控器上有语音键，部分设备能直接用语音代替打字，能不能用取决于你的设备与遥控器，不是应用本身提供的。

## 五、设置入口在哪

公开的使用说明里，这类应用的设置入口都在**首页的一个角落**，进去之后能看到分组的配置项，其中一项是资源接口地址（有的写作「点播」「配置」「接口」），另一项是播放相关选项。

几点提醒：

- **改配置前先记住原来的值**。填错之后片单会变空，而你还得靠原值改回来；稳妥做法是先用手机拍一张屏幕。
- **改完要回首页让它重新加载**，停在设置页不会自动生效。
- 接口地址由内容提供方给出。**用之前先确认这个来源是你有权使用的**，本文不提供任何地址。
- 输入地址用软键盘效率很低，如果同一份配置要在多台设备上填，不如把配置方式固定成一种，少改少错。

## 六、找不到功能入口时的顺序

大屏应用的界面改版比手机应用频繁，同一项功能在新旧版本里可能挪了位置。按这个顺序找：

1. 首页左上角 / 右上角 / 底部一排的图标，逐个个停一下看提示文字；
2. 播放页呼出控件层，看有没有第二排选项；
3. 进首页的设置，看有没有「其他」「高级」这类分组；
4. 都找不到，说明这个版本里确实没有这项功能，不必再翻。

遇到界面里的文字与上面描述对不上，以你设备上实际显示的为准 —— 界面文案随版本变，操作逻辑（焦点 + 确定键）不变。
