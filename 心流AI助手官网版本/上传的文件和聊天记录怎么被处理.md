你会往这个应用里放进论文、财报、会议记录、公众号文章 —— 所以「这些东西会被怎么处理」不是可选项，是决定你敢不敢上传的前提。官方《隐私政策》与《用户服务协议》都公开在官网上，本篇把与读者动作相关的部分挑出来讲清。

## 一、哪些内容会被记录

按官方《隐私政策》，与你直接相关的是这几类（下表内容取自官网公开的隐私政策文件，更新日期 2024-12-06、生效日期 2024-12-13，以官方页面当时显示为准）：

| 记录的内容 | 用在什么地方 |
| --- | --- |
| 手机号与短信验证码 | 注册与登录，手机号就是账号 |
| 你输入的文本、图片与论文资料 | 提供对话与检索增强服务 |
| 对话记录（含生成的回答） | 让你随时查看与管理历史 |
| 智能体的名称、开场语与操作记录 | 唤起并运行你配置的智能体 |
| 日志、设备与网络信息、位置、Cookie | 服务稳定与安全防护 |

其中「日志与设备信息」这一类包含设备标识、操作系统、浏览器类型、文件目录等条目，属于这类应用的常规做法；它和你上传的文件内容是两回事。

## 二、你上传的文件会被怎么用

这是最需要说清的一点：**你导入的文件不是只在本地解析。**

- 上传与导入后，解析、检索、生成都在服务端完成 —— 这也是为什么断网之后知识库问不出内容；
- 官方写明：**在经过加密处理且不识别特定个人的前提下，会把所收集的数据用于机器学习、算法模型训练或其他数据分析**；
- 也写明：原则上不向其他组织和个人提供或共享你的个人信息，法定情形与另行取得同意的除外；若要把信息用于政策未载明的用途，会事先取得同意。

**由此得到的操作结论很简单：** 涉密材料、未公开的内部文件、他人的隐私信息，不要上传。这不是产品功能问题，而是你上传之前该做的判断。官方协议里也写了一条对等要求：你输入的内容若涉及第三方信息，需先取得对方合法授权。

## 三、它申请的权限分别对应什么

第一次使用时会陆续弹出权限请求，官方隐私政策里逐条对应了用途：

| 权限 | 用来做什么 |
| --- | --- |
| 麦克风（录音） | 语音输入、电话模式 |
| 电话状态 | 一键登录 |
| 通知 | 接收推送 |
| 读取外置存储 | 上传与阅读本地文件 |
| 写入外置存储 | 语音输入的临时文件、应用内下载更新包 |
| 摄像头 | 拍摄、扫描二维码、视频模式 |
| 蓝牙 | 语音或电话模式下连接蓝牙设备 |

**可以只给需要的：** 官方明确写了，拒绝附加权限不影响基本功能；例如不授权读取本地存储，仍可以通过「添加网页 URL」的方式把内容放进知识库。

## 四、把回答分享出去时注意什么

应用支持把回答分享到微信、朋友圈，或者生成图片、链接再发出去。分享是**一次性对外公开的动作**，两件事值得先确认：

1. 分享出去的内容里有没有夹带你自己的文件原文、内部数据；
2. 生成图片分享时，图片上会带上回答内容，截图前先看一眼有没有不该外传的部分。

## 五、你自己能做哪些管理动作

| 想做的事 | 入口 |
| --- | --- |
| 查阅、更正、复制自己的信息 | 客户端内「设置 — 我要反馈」，或直接在对话页查看 |
| 删除部分内容 | 在对应页面内删除；整账号删除走「设置 — 注销账号」 |
| 撤回已给的权限 | 系统设置里逐项关闭 |
| 联系官方 | 邮箱 `service@iflow.cn`（协议里公布的沟通渠道） |

两点提醒：**注销账号等于删除该账号下的全部信息，操作前把要留的笔记与文件导出**；另外官方写明，删除后由于法律与安全技术限制，**备份系统中的数据可能无法立即清除**，会先限制进一步处理直到可以清除或匿名化。

## 六、账号被限制的可能情形

协议里列了几种会触发警告、限制功能、暂停使用甚至封禁的行为，与你日常使用相关的两类是：

- 利用它编造、传播虚假信息；
- 上传侵权内容（未经授权使用他人的论文、图片、资料）。

「上传自己的或已获授权的内容」既是合规要求，也是账号能长期用下去的前提。
