把一批资料丢进去，让它产出成品，是这个产品效率最高的用法。可产出的成果有六类：报告、PPT、思维导图、AI 播客、测验、定时简报。本篇讲每类适合什么场景、导出时要注意什么。

## 一、生成前必须先做的事

**先把资料收进知识库并等解析完成。** 生成动作读的是库里选中的来源，不是整个互联网。跳过这一步，得到的会是一份通用的泛泛之作，跟你的资料没关系。

| 准备动作 | 为什么 |
| --- | --- |
| 资料解析完成 | 没解析完就生成，成品的引用会缺章节 |
| 选定来源范围 | 生成用的是「选中的来源」，选错范围等于用错材料 |
| 想清成品给谁看 | 同一个资料，给领导汇报和给同事同步，结构完全不同，写进要求里 |

## 二、六种成果各适合什么

| 成果 | 适合的场景 | 说明 |
| --- | --- | --- |
| 总结报告 | 读完一批资料要留一份书面结论 | 内容跟随来源，会标出处 |
| PPT | 汇报、分享、课堂 | 可选择商务或卡通风格，支持下载成本地可编辑的 `.pptx` |
| 思维导图 | 理清结构、梳理思路 | 较新版本提供多种导图模式，具体样式以 App 内显示为准 |
| AI 播客 | 通勤、运动时听 | 双人对谈形式，把文字内容转成可听的音频，支持锁屏与通知栏播放控制 |
| 测验 | 检验自己记住了多少 | 适合考前或读书后自测 |
| 定时简报 | 固定周期收到整理好的摘要 | 较新版本提供了统一的简报管理入口，集中查看与整理 |

你手上这份 1.17.0 与官方最新版存在版本差，界面上可能少几个入口；哪些功能从哪个版本开始提供，见 [下载与安装教程.md](下载与安装教程.md) 第五节。

## 三、生成步骤与耗时预期

1. 进知识库，勾选这次要用的来源；
2. 选择产出类型（报告 / PPT / 导图 / 播客 / 测验 / 简报）；
3. 在要求里写清用途、篇幅、风格；
4. 发起生成后**耐心等**，不要反复点。长资料生成 PPT 与播客需要时间，反复重发只会同时排几个任务，更慢；
5. 生成完成后先通读一遍再导出 —— 尤其是数字、人名、单位，这些是最容易出错的地方。

## 四、导出与保存

| 要留的形式 | 怎么做 |
| --- | --- |
| PPT 继续改 | 下载为 `.pptx`，在本机 PowerPoint / WPS 里调整版式与配色 |
| 报告留档 | 先从生成结果里导出或复制成文本，再存到账号笔记里；纯文本比截图更好改 |
| 播客在路上听 | 直接在 App 内播放，支持锁屏与通知栏控制；要留档的先确认导出入口是否提供，以页面显示为准 |
| 导图留存 | 导出或截图，导图类的排版导出后容易走形，截图更稳 |
| 只要分享给某个人看 | 回答类内容支持分享到微信、朋友圈，也可以生成图片或链接再发出去；分享是一次性对外公开的动作，发之前确认里面没夹带不该外传的资料 |

**一条实用建议：** 生成出来的成品先别急着导出。把它当作初稿，花几分钟把引用出处和数字核一遍，比导出后自己回头改要省事得多。

## 五、效果不理想的处理顺序

1. **内容跟资料无关** → 检查来源范围是不是没选中，或资料没解析完；
2. **结构不对** → 别重新生成，先在要求里补一句结构（例如「按问题—原因—对策三段」）；
3. **篇幅不对** → 明确写「控制在 10 页以内」这类硬指标，比说「简短点」有用；
4. **风格不搭** → PPT 换一种模板风格再生成；
5. **生成失败** → 看状态提示，按 [常见问题与排查.md](常见问题与排查.md) 处理。

需要一份完整成品的场景（例如课程作业里的文献综述），可以把论文精读出的笔记和报告串起来用，读与写的分工见 [论文检索与精读怎么用.md](论文检索与精读怎么用.md)。
