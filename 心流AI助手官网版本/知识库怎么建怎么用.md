知识库是心流AI助手区别于普通聊天工具的地方：你把资料收进来，它基于这些资料回答，并在句末标出出处。本篇讲从建库到提问的完整动作，以及几个容易白忙一场的坑。

## 一、知识库能收什么

| 来源 | 具体形式 |
| --- | --- |
| 本地文件 | PDF、Word、PPT、Excel、TXT、EPUB |
| 网页链接 | 普通网页、公众号文章链接 |
| 纯文本 | 直接把一段文字粘进去 |
| 图片 | 拍照或选图，让内容以图片形式入库 |

较新版本放宽了单个文件的大小限制，能收更大的文件；你手上这份是 1.17.0，具体大小上限以 App 内提示为准。

**导入就是上传。** 文件、链接、图片都是交到服务端做解析与检索的，这也是断网之后问不出内容的原因。所以涉密材料、未公开的内部文件、他人的隐私信息不要放进来 —— 数据会被怎么处理，见 [上传的文件和聊天记录怎么被处理.md](上传的文件和聊天记录怎么被处理.md)。

**首次导入会请求存储权限**：不给读取本地存储的权限，也可以改用「添加网页 URL」把内容放进库，功能不受影响。

## 二、建库与导入

1. 打开「知识库」入口，新建一个知识库，**给一个能认出来的名字**（例如「行业研报」而不是「知识库1」）—— 后面提问要按库选择来源，名字含糊自己会找错；
2. 进库后选导入方式，把文件、链接或图片加进来；
3. 等解析完成。解析期间不要反复退出重进，长文档需要时间；
4. 解析完成后，先问一个你确定文中一定有的细节，答得上来再开始正式提问。

**为什么要先试一次：** 如果导入的是整页都是图片的扫描件（没有文字层），解析出来的可能只有零星内容。用一句试探就能提前发现这种文件，免得后面拿它生成报告时才发现内容不全。

## 三、基于自己的资料提问

- 提问前先确认当前选中的**来源范围**：是某一个知识库，还是全部；
- 回答里的编号脚注就是出处，点一下可以回到原文那一处；
- 如果回答看上去不像来自你的资料，先检查来源范围是不是选错了 —— 这是最常见的误判。

**提问写法上，一次把三件事说清最省事：** 你要的结论是什么、给谁看、要多长。例如「按这份财报，列出毛利率下滑的三个原因，每条一句话，给部门周会用」。分三次追问拼出来的结果，通常不如一次说清。

## 四、跨文档对比的正确姿势

同一主题的多份资料，放进**同一个知识库**再提问，效果比分别丢进多个库要好：

| 你要做的事 | 怎么组织 |
| --- | --- |
| 对比几份方案的差异 | 全部放进一个库，问「这几份在预算口径上的差别是什么」 |
| 查某份资料里的某一处细节 | 可以只选那一份作为来源，减少干扰 |
| 按同一批资料反复产出 | 固定用同一个库，别每次重新导入，省上传与解析时间 |

具体到论文文献的检索与精读，单独写在 [论文检索与精读怎么用.md](论文检索与精读怎么用.md) 里。

## 五、库里的资料能产出什么

资料收好之后，可以基于选中的来源生成总结报告、PPT、思维导图、AI 播客、测验、定时简报等成果，各自的操作与导出方式见 [报告PPT播客怎么生成与导出.md](报告PPT播客怎么生成与导出.md)。

## 六、几个容易白忙的坑

- **重复导入同一份文件**：库内会出现多份内容相似的材料，提问时结果被稀释。导入前先按文件名核对一遍库里已有的资料；
- **导入后立刻提问长文档**：解析没完成时，回答里可能引用不到后面的章节。等解析状态显示完成再问；
- **把整个库拿去问具体到某一页的细节**：来源范围越小，回答越容易被资料本身约束住；问细节时只勾选相关的那一份；
- **删库前先导出**：删除知识库是不可逆的，库里那批资料随之下线 —— 需要保留的成品先在账号里另存或导出到本地。

导入失败、解析一直不结束、或者回答问题引用不到资料，按 [常见问题与排查.md](常见问题与排查.md) 里对应现象处理。
