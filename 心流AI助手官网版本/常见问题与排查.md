先在下表找到你遇到的那一行，再按后面的分节处理。这个产品里的多数「故障」其实是两种原因：**版本较旧看不到入口**，或者**资料还没解析完就急着提问**。

## 一、现象速查

| 现象 | 常见原因 | 去看哪一节 |
| --- | --- | --- |
| 装不上、装完打不开 | 安装包不完整、同名应用冲突、系统版本偏低 | 第二节 |
| 卡在登录页、验证码收不到 | 短信拦截、索取过频被限流、网络异常 | 第二节 |
| 某些功能找不到入口 | 手上这份是较旧版本 | 第三节 |
| 搜不到想要的资料 | 问题太宽泛、没触发联网检索 | 第四节 |
| 上传文件失败、解析没反应 | 文件格式不支持、体积过大、扫描件无文字层 | 第五节 |
| 报告/PPT/播客生成失败或很慢 | 来源没选中、资料没解析完、同时排了多个任务 | 第六节 |
| 引用点不开、出处对不上 | 来源标记对应的页面不可达 | 第四节 |
| 买了会员还是受限 | 登错账号、版本较旧 | 第七节 |
| 回答明显不准 | 问题写法太宽泛、来源质量参差 | 第四节 |

## 二、装不上、登录不了

**装不上：**

1. 先核对安装包完整性 —— 本地算一遍 MD5，与 [下载与安装教程.md](下载与安装教程.md) 第一节表里的值比对，对不上就重新下载；
2. 手机里若已有同名但签名不同的版本，先卸载再装；
3. 提示「未知来源」被拦，去系统设置里给安装动作授权；
4. 都排除了仍失败，多为系统版本偏低，换设备或换较新版本试。

**登录不了：**

- 验证码收不到：检查短信拦截；同一号码短时间内反复索取会被限流，隔几分钟再试；Wi-Fi 与移动数据互换一次；
- 一直转圈：换网络重试，确认系统时间准确（时间偏差会影响验证）；
- 提示账号异常：不要反复重试，按第八节的官方反馈渠道提出；
- 换过手机号：先用旧号登录再改绑定，旧号已停用只能走官方反馈。

## 三、功能入口找不到

先看版本。你手上这份是 1.17.0，而知识库 2.0、暗黑模式、App 内会员入口、思维导图模式、记忆系统等是 1.19 之后才陆续加入的 —— 入口缺失通常属于版本差异，不是故障。判断方法与各版本差异见 [下载与安装教程.md](下载与安装教程.md) 第五节。

## 四、搜不到、引用对不上

1. **问题收窄**：把「XX 行业怎么样」改成「XX 行业 2025 年的出货量是多少，来源要权威的」。宽泛问题容易得到通用答案；
2. **确认走了联网**：需要最新信息时，把「查一下最新」写进问题里，别让它按常识答；
3. **看来源再采信**：回答里的来源标记点开核对，来源是内容农场还是官方渠道，直接影响可信度；
4. **引用点不开**：原页面可能已下线或被限流，换一个来源重新问同一件事；
5. **回答内容像通用模板**：往往是因为提问里没有你的具体场景，补上用途、对象、篇幅再问一次。

## 五、上传与解析

| 现象 | 处理 |
| --- | --- |
| 提示格式不支持 | 只收 PDF、Word、PPT、Excel、TXT、EPUB 这类常见格式，先把资料转成其中一种 |
| 提示文件过大 | 较新版本支持更大的文件；旧版本先拆分文件或转成更小的格式 |
| 解析一直不结束 | 别反复退出重进；长文档需要时间，超时过长先移除再重新导入 |
| 导入成功但问不出内容 | 多半是扫描件没有文字层，换一份带文字层的版本，或对关键页单独处理 |
| 网页链接导入失败 | 该页面可能要求登录或有反抓取限制，改写内容为纯文本后再导入 |

导入后先做一次试探性提问，确认内容真的进去了，再拿它生成成品，理由见 [知识库怎么建怎么用.md](知识库怎么建怎么用.md) 第二节。

## 六、生成类任务

1. **先生成再排查**：报告、PPT、播客生成需要时间，反复点只会同时排多个任务，更慢；
2. **内容跟资料无关**：检查来源范围是不是没选中，以及资料是否解析完成；
3. **一直不出结果**：退出当前生成、清理排队任务、换网络后重发一次；
4. **额度被扣但没结果**：先看额度是否退回，没退回就带时间与任务类型按第八节的渠道反馈，详见 [会员与额度怎么算.md](会员与额度怎么算.md) 第五节；
5. **导出后版式走形**：PPT 下载为 `.pptx` 后在本机调整更稳；导图类建议截图留档，具体做法见 [报告PPT播客怎么生成与导出.md](报告PPT播客怎么生成与导出.md) 第四节。

## 七、会员不生效

按这个顺序查，别直接当成系统故障：

1. **看登录的是哪个账号** —— 权益只跟购买时那个账号走；
2. **看 App 版本** —— 旧版本可能连会员页都打不开；
3. **看系统订阅列表** —— 确认订单存在、没被误退；
4. 三条都对仍不生效，带订单截图按第八节的渠道反馈。

取消续费的入口在系统应用商店账户的订阅管理里，卸载 App 或退出登录都不会终止扣款，这一步容易漏，详见 [会员与额度怎么算.md](会员与额度怎么算.md) 第三节。

## 八、找官方反馈前先准备好三样

上面几节都排查过仍没解决的，走官方反馈渠道：客户端内「设置 — 我要反馈」，或邮箱 `service@iflow.cn`（官方协议里公布的沟通渠道）。

一次就能说清的反馈，通常包含这三样，比反复追问效率高得多：

| 准备什么 | 怎么取 |
| --- | --- |
| 现象发生的具体时间 | 精确到分钟，便于对方定位日志 |
| 截图或录屏 | 出错时的界面截图，比文字描述更准 |
| 版本号与包名 | 版本在「设置 — 关于」一类的页面里；包名是 `cn.iflow.ai` |

涉及订单与额度的，把订单截图一并附上；涉及具体回答不准的，把那段对话截图附上。

## 九、什么时候该换设备或重装

出现下面两种情况，再考虑重装或换设备，否则多是网络与账号层面的问题：

- 同一网络下其他应用正常，只有它连不上，且重启设备后依旧；
- 安装包 MD5 核对不上，或安装过程反复失败。

重装前先把要留的笔记、知识库内容确认已经同步到账号，安装包始终从 [心流AI助手 安装文件资源（夸克网盘）](https://pan.quark.cn/s/2cef8d3ae484) 取用，认包名 `cn.iflow.ai`。
