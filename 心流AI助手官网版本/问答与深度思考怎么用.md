打开心流AI助手，底部输入框就是主要入口。它的回答默认会联网检索并附来源，也可以在提问时切换成更慢但更深的多轮思考。本篇讲这两种模式分别什么时候用，以及怎么把答案一次问到位。

## 一、一次提问，两步动作

1. 在输入框写下你的问题；
2. 发出后等它检索并作答，回答里的来源标记可以点开核对。

**提问写法上，把三件事一次说清最省事：** 你想要什么结论、给谁看、要多长。含糊的问题会得到四平八稳的答案，写清场景的提问才能拿到能直接用的结果：

| 写法 | 结果 |
| --- | --- |
| 「讲讲 XX」 | 一段通用介绍，你多半还要再改 |
| 「给刚接手项目的同事讲清 XX 的关键节点，200 字以内，列成三条」 | 基本可以直接发出去 |

## 二、问完之后还能做什么

回答出来只是第一步，接下来的四个动作比重新提问有用：

| 动作 | 用在哪 |
| --- | --- |
| 追问 | 答案方向对了但不够细，接着问细节，不用重复前面的背景 |
| 重新生成 | 对整体结构不满意，想换个思路再来一版 |
| 看延申话题 | 不知道下一步该问什么时，从它给的延伸方向里挑 |
| 存进笔记或知识库 | 这条问答以后还要用，先存起来，避免再问一遍 |

把回答直接存进知识库，是它比较特别的一个动作：存进去之后，这条内容就变成了你自己的资料，之后可以和其他文件一起被引用、被生成报告，做法见 [知识库怎么建怎么用.md](知识库怎么建怎么用.md)。

## 三、什么时候该切到深度思考

同一个输入框下，通常可以选普通问答或更深的思考模式（不同版本里叫法不完全一样，有的叫慢推理，有的叫深度思考）。选择依据是问题的复杂度，不是你的心情：

| 你的问题 | 用哪个 |
| --- | --- |
| 查一个事实、找一份资料、翻译一段话 | 普通问答，快 |
| 需要权衡取舍、要给出理由链、要比较几种方案 | 深度思考，慢但更完整 |
| 学术问题、需要读文献再回答 | 学术/论文模式，见 [论文检索与精读怎么用.md](论文检索与精读怎么用.md) |

**注意一件事：** 深度思考会多花时间，也会多消耗额度。宽泛的问题用深度思考，得到的往往只是一段更长的宽泛回答 —— 先把问题收窄，再决定要不要上深度模式。

## 四、回答里有图片和多轮推理

联网检索得到的答案里可能夹带网上的图片，图文对照读起来更直观；复杂问题它会分多步推理再给结论。这两种情况都属于正常输出，不等于你的问题没被理解。

## 五、记忆与偏好

较新版本加入了记忆能力，会记住你的使用偏好，后续交流里不用每次重述背景。以下几点需要知道：

- 记忆只作用在你自己账号下；
- 换到另一套账号，之前记住的偏好不会跟着走；
- 如果发现它总按某个旧习惯回答，先去记忆相关入口检查一下里面存了什么 —— 多数「它怎么老是这么答」的问题，答案在这里。

## 六、几个容易误判的现象

- **回答里有你不认同的说法**：先点开来源看原文，再决定是它引用错了，还是你记错了；
- **回答明显不是最新信息**：确认这次有没有联网检索；有时问题写得像常识题，它就不去搜了，把「查一下最新」写进问题里；
- **同一个问题两次答案不一样**：生成带有随机性，属于正常；要稳定复现，把要求写得更具体（格式、长度、必须包含的点）；
- **答到一半停下**：网络中断或额度耗尽都可能，先看状态提示，再按 [常见问题与排查.md](常见问题与排查.md) 处理。
