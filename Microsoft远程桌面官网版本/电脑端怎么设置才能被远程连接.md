# Microsoft远程桌面 电脑端怎么设置才能被远程连接

> 手机端连不上，原因大多在被控电脑那一侧。本篇按顺序过一遍：系统版本、开关、用户权限、防火墙与端口、地址、待机设置。

手机上的 Microsoft远程桌面 只是个遥控器，真正决定连不连得上的是被控那台 Windows 电脑。这台电脑要同时满足六个条件：系统版本够、远程桌面开着、你的账户有权限、防火墙放行、地址可达、并且它醒着。下面按这六条逐个过，每一条都给出在电脑上的具体位置。

## 一、确认系统版本支持被远程

| 被控电脑的版本 | 能不能被远程连接 |
| --- | --- |
| Windows 11 / 10 专业版、企业版 | 可以 |
| Windows Server 2016 及以后 | 可以 |
| Windows 11 / 10 家庭版 | 不可以，设置里根本没有「远程桌面」这一项 |

微软的原话是：可使用远程桌面连接到 Windows 的专业版和企业版 SKU，无法连接到运行家庭版的计算机。查法：在被控电脑上进「设置 → 系统 → 关于」，看「Windows 规格」里的「版本」。是家庭版只能先升级到专业版，或改用别的远程方式，客户端这边没有绕过的办法。

## 二、打开远程桌面并记下电脑名

1. 在被控电脑上进「设置 → 系统 → 远程桌面」，把开关打开，弹确认框时选确认；
2. 同一页面下方「如何连接到此电脑」里记下**电脑名称**，形如 `DESKTOP-8K3L1M`。这个名字待会儿要填进手机的 PC 名称里；
3. 该页的「高级设置」里有一项「要求计算机使用网络级别身份验证进行连接」（NLA）。保持勾选更安全；但官方也提醒：如果要从家庭网络外部远程连接到该网络上的电脑，不要选这一项。取舍与现象见 [连不上或报错怎么排查.md](连不上或报错怎么排查.md)。

开机后电脑要保持在开机状态，远程连接不要求有人坐在电脑前，但要求它没睡、没关机、连着网。

## 三、谁有权限连进来

- **Administrators 组成员默认就有权限。** 其他账户要在同一页面的「可以选择远程访问此电脑的用户」里手动加进去。
- **远程用的账户必须有密码。** 官方策略是：使用空密码的本地账户只允许在本地控制台登录，远程登录会被拒。如果你的电脑平时不设密码，这一步必须先补上。
- **本机正在使用时会被断开。** 客户端版 Windows 同时只维持一个交互会话：你从手机登进去时，本机上原来的登录会断开回到锁屏（连的时候会提示「有另一个用户已登录，若继续，他将被断开」），两边不能各玩各的。
- **第二个人也连不进来。** 这条限制跟账户无关——换另一个账户从第二台设备连，结果同样是前一个会话被顶掉，不是新开一个。默认允许多个并发会话的是 Windows Server（默认 2 个管理会话），客户端版 Windows 想做到多人同时在线，官方路径只有部署远程桌面服务（RDS）这一条，且需要相应的许可。
- **顺序上的一点影响**：你从手机连进去、用完直接关屏走人，电脑上可能留下一个「已断开」的会话占着位置。下次本机的人想登录时，Windows 会让他选择把那个会话顶掉，属于正常现象。

## 四、防火墙与端口

开启远程桌面的同时，Windows 防火墙会自动创建放行「远程桌面」的入站规则（专用与公用两个网络配置文件各一条）。下面两种情况需要你自己动手：

- 曾经手工清理或禁用过防火墙规则；
- 改过远程桌面的默认端口——官方规则是按默认端口建的，改端口后规则不再匹配，要自己补一条对应端口的入站规则。

默认端口是 TCP 3389。在被控电脑上执行：

```powershell
netstat -ano | findstr :3389
```

出现 `LISTENING` 说明本机正在监听。没有输出的话，要么远程桌面没真正开启，要么端口被改过——这时用 `findstr` 换成你改后的端口再查一次。

## 五、地址怎么给（同网 / 跨网）

| 场景 | 手机里 PC 名称填什么 | 还要做什么 |
| --- | --- | --- |
| 手机与被控电脑连同一个 Wi-Fi | 电脑名，或局域网 IPv4（形如 `192.168.1.23`） | 无 |
| 手机在外面，要连家里电脑 | 家里的公网地址加端口 | 路由器端口转发或 VPN，见下一条 |
| 连公司内网电脑 | 管理员给的内网电脑名 | 另需远程桌面网关，见 [远程资源订阅与网关怎么设置.md](远程资源订阅与网关怎么设置.md) |

查被控电脑的局域网地址：进「设置 → 网络和 Internet → 属性」看 IPv4 地址，或命令行执行：

```powershell
ipconfig
```

看重用的那张网卡那一行。注意：**电脑换 Wi-Fi、重启路由器后这个地址会变**，手机里存的旧地址会失效，报错多为「找不到电脑」。家里固定不动的机器，可以在路由器里给它绑定一个固定 IP。

跨网访问的提醒：不要为了图省事把 3389 直接映射到公网，这是被扫描最多的端口之一。优先用 VPN 进内网，再走远程桌面；确实要端口转发时，远程账户一定要有强密码。

## 六、让它别睡

被控电脑睡着时，远程连接就会失败，而且提示往往是「找不到电脑」，很容易被误判成网络问题。

- 进「设置 → 系统 → 电源和电池 → 屏幕和睡眠」，把「接通电源时」的睡眠改为「从不」，屏幕熄灭时间可以按需保留；
- 笔记本还要单独确认「合上盖子时的操作」不是睡眠；
- 如果电脑是开着、也没睡，但空闲一段时间后就连不上，可以检查无线网卡的省电选项，临时关掉再试。

## 七、一条最小自检链

按顺序确认，任何一条不成立就先修它，不要跳跃：

1. 电脑开着、连着网；
2. 「设置 → 系统 → 远程桌面」开关是打开的；
3. 你要用的账户有密码，且在可远程访问的用户列表里；
4. 防火墙里「远程桌面」规则没被禁用；
5. `netstat` 里能看到 3389 处于 `LISTENING`；
6. 手机与被控电脑在同一个网络里，填的地址是当前有效的那一个。

六条都成立还是连不上，转 [连不上或报错怎么排查.md](连不上或报错怎么排查.md)，那里按错误码给分层排查顺序。
