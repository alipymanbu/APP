Microsoft远程桌面是微软的安卓远程桌面客户端，装手机里，用来连一台已经开启「远程桌面」的 Windows 电脑。网盘里这份属于 8.x 版本线，包名 `com.microsoft.rdc.android`，已经不是应用商店里在维护的那个新版客户端。本篇只管三件事：认版本、装进手机、确认连得上的前提都在。

## 一、网盘里这份包是哪一版

网上搜到的多半是新一代客户端（包名以 `androidx` 结尾）或 Windows 应用，界面和版本号跟这份都不一样。以下数值以你手里这个安装包为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | Microsoft远程桌面（安卓客户端，8.x 版本线） |
| 版本号 | v8.1.82.445 |
| 包名 | `com.microsoft.rdc.android` |
| 安装包体积 | 18.22M |
| MD5 | `791D3F1C3CA07BAD2AA8FD4AF6B6D953` |
| 运行平台 | 安卓手机 / 平板（Chrome OS 上装 Google Play 版同样可用） |

下载完整包后，用任意 MD5 校验工具对一下上表里的值，对不上多半是文件没下全，删掉重下。

关于这条版本线：官方更新日志里 8.x 的记录停在 2020 年 5 月的 8.1.80（内容是更换客户端图标、并为「把连接和设置迁移到新客户端」做准备），之后微软的安卓客户端主线转到了包名以 `androidx` 结尾的新客户端，再往后统一到 Windows 应用。所以你手里这份是一个已经停止演进的版本：能用，但不会再有新功能。三代客户端的对应关系见 [和Windows应用有什么区别.md](和Windows应用有什么区别.md)。

关于手机的安卓版本：官方给出新旧最低版本要求的区间是在后面那条新客户端线上（10.0.12 起要求 Android 8，10.0.13 起要求 Android 9），而 8.x 这条线已不再标注具体下限。所以手机系统偏老时优先试这份；至于某台手机到底装不装得上、装完跑不跑得动，以安装时系统是否提示不兼容、以及打开后能否正常进入连接中心为准。

## 二、装之前必须确认的两件事

**第一，被控那台电脑的系统版本。** 微软的说明很直接：远程桌面只能连到 Windows 的专业版和企业版 SKU，连不到运行家庭版的电脑，Windows Server 同理。客户端装哪个版本都改变不了这条。查法：在被控电脑上进「设置 → 系统 → 关于」，看「Windows 规格」里的「版本」。是家庭版就得先升级，做法见 [电脑端怎么设置才能被远程连接.md](电脑端怎么设置才能被远程连接.md)。

**第二，被控电脑要先把远程桌面开关打开。** 这一步在电脑上做，不在手机上做。只装客户端、电脑侧没开开关，连接一定失败。

## 三、安装步骤

1. **拿到安装包**：从 [Microsoft远程桌面 安装文件资源（夸克网盘）](https://pan.quark.cn/s/69065683142b) 转存到自己的网盘，再下载到手机。手机端直接下载最省事，不必绕电脑。
2. **允许安装未知来源应用**：在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给用来打开安装包的那个应用（浏览器或文件管理器）打开开关。国产定制系统的这项开关常收在「安全」或「隐私」分类下。
3. **点击 APK 完成安装**：系统若提示「应用未经过安全检测」，选继续安装即可，这是非应用市场渠道的常规提示。
4. **装之前先清掉同包名旧版**：安卓不允许用低版本覆盖高版本，会直接报「应用未安装」；同一个 `com.microsoft.rdc.android` 的旧版残留也会挡住安装，先卸载再装。
5. **打开它**：首屏就是空的连接中心——一个列表加一个 `+`。下一步是添加第一条连接，每个填空项怎么填见 [添加连接与账号密码怎么填.md](添加连接与账号密码怎么填.md)。

关于权限：安装包把存储列为可选权限，只有在某条连接里打开了「重定向本地存储」（Redirect local storage）之后、要从远程会话访问手机上的文件和文档时才用得到，不做这件事可以不给。

## 四、装不上或打开就退，先对号入座

| 现象 | 常见原因 | 怎么处理 |
| --- | --- | --- |
| 解析软件包时出现问题 | 下载不完整 | 删掉本地文件重下，并按第一节的 MD5 核对 |
| 应用未安装 | 同包名旧版残留，或装的版本低于已装版本 | 先卸载旧版，再装这份 |
| 打开后闪退 | 系统版本与该版本线不匹配 | 8.x 线早已停止更新，在较新的安卓系统上能否正常运行没有官方保证，换新一代客户端往往更快，见 [和Windows应用有什么区别.md](和Windows应用有什么区别.md) |
| 打开后界面异常、操作无响应 | 定制系统拦截了权限或后台运行 | 到应用详情页把存储与后台运行权限给上，重启一次应用 |

## 五、装完先做一次最小验证

不必急着连很远的那台电脑。让手机和被控电脑连同一个 Wi-Fi，按 [添加连接与账号密码怎么填.md](添加连接与账号密码怎么填.md) 建一条连接并点一下：

- 能看到 Windows 的锁屏或桌面 → 客户端与电脑两侧都通了，剩下的只是手感问题，接着看 [远程画面手势与鼠标操作.md](远程画面手势与鼠标操作.md)；
- 报 0x104、0x204 之类的错误码 → 先别怀疑客户端，按 [连不上或报错怎么排查.md](连不上或报错怎么排查.md) 的顺序逐层查。
