# Microsoft远程桌面 远程资源订阅与网关怎么设置

> 只有拿到管理员给的「资源订阅地址」或「网关地址」时才用得到本篇；直连自己的电脑不需要这两项。

远程资源指的是管理员发布出来的 RemoteApp 程序、会话桌面与虚拟桌面；远程桌面网关则是让你从外网安全进入内网的一台中转服务器。这两项都是「别人给你地址、你照填」的事，前提是管理员已经把权限配给你——个人用户拿不到公开可用的订阅地址，自己家里的一台电脑也完全用不到它们。选项名按官方英文标识给，不同语言版本的显示文字可能不同。

## 一、先分清三类连接

| 类型 | 谁提供 | 你要准备什么 |
| --- | --- | --- |
| 直连一台电脑 | 你自己的电脑 | 电脑名或 IP + 一个可用账户，见 [电脑端怎么设置才能被远程连接.md](电脑端怎么设置才能被远程连接.md) |
| 远程资源（Feed） | 公司或学校的 IT 管理员 | 订阅地址，或直接填邮箱 + 域账号 |
| 远程桌面网关 | 公司或学校的 IT 管理员 | 网关服务器地址 + 网关账户 |

三类可以同时存在。只连自己电脑的人，看到本节就可以停；下面两节是给拿到地址的人的。

## 二、订阅远程资源：怎么填

1. 连接中心点 `+`，选**远程资源源**（Remote Resource Feed）——注意不是「桌面」；
2. 在「源 URL」里填管理员给你的地址；**或者填你自己的邮箱地址**。填邮箱的用法是：让客户端按管理员在服务器上的配置，自动去找与你邮箱关联的那个地址；
3. 点下一步，按提示提供登录信息。用到哪些取决于部署方式，可能是：有资源权限的用户名、该账户的密码、以及管理员配了多因子认证时的**额外验证因素**；
4. 保存后，资源会出现在连接中心里，点开即用。
5. 不想留了：对着该资源点溢出菜单 `…` → 移除，再确认一次。

## 三、配网关：怎么填

1. 连接中心 → 设置 → 网关 → 点 `+`；
2. **服务器名**填网关地址，可以带端口，例如 `RDGateway:443`、`10.0.0.1:443`；
3. 选账户，两种方式：**使用桌面用户账户**（和远程电脑共用同一套凭据）或**添加用户账户**（单独存一个网关账户）；
4. 回到那条连接的「编辑 → 显示更多选项 → 网关」，指向刚建好的这一条；
5. 删除网关：设置 → 网关 → 长按可多选 → 垃圾桶图标。

一条实用规则：**同一局域网内直连时不要走网关**。官方在新版客户端里专门加了一条提示，意思是本地地址不应使用 RD 网关——绕一圈不仅慢，还更容易在网关这一层出错。

## 四、账户存在哪，怎么批量清

两条路径的账户分开管理：远程电脑用的账户在「设置 → 用户账户」，网关账户在配网关时就地选。用户名的合法写法有三种：`user_name`、`domain\user_name`、`user_name@domain.com`；保存时必须带密码。用户账户页里长按可多选，一次删干净。

公司或学校的域账号密码长期留在个人手机上风险偏高，这类场景建议选「每次输入」，别把域账号存进手机。

## 五、能订阅什么，取决于管理员的部署

- 资源订阅的可用范围完全由管理员配置决定，你自己开不出来；
- 云侧资源（Azure 虚拟桌面、Windows 365、Microsoft Dev Box）的订阅说明，官方现在是挂在 Windows 应用这条线上写的，安卓端沿用同一个包名 `com.microsoft.rdc.androidx`。网盘里这份 8.x 客户端对这类云资源的支持范围，请以官方当页说明为准；
- 官方更新日志里 8.x 的最后一条记录停在 2020 年 5 月的 8.1.80（更换图标、并为把连接和设置迁移到新客户端做准备），此后 8.x 不再有新功能。所以如果公司只发布云资源、并且要求使用最新客户端，那就用 Windows 应用，别用网盘这份 8.x，对照见 [和Windows应用有什么区别.md](和Windows应用有什么区别.md)。

## 六、订阅成功之后，资源在哪、怎么切

资源列表就在连接中心里，和直连的电脑混在一起显示。会话内部的操作和直连一样：屏幕左侧的会话选择条用来切会话；接了发布类资源时，点会话卡片上的 `>` 展开，可以在管理员发布的多个应用之间切换；想另起一个，点「开始新的」（Start New）后从列表里挑。手势与鼠标模式仍是同一套，见 [远程画面手势与鼠标操作.md](远程画面手势与鼠标操作.md)。

订阅或网关连不上时，先按 [连不上或报错怎么排查.md](连不上或报错怎么排查.md) 第二节的第 9 条查网关这一层，再回头核对管理员给的地址有没有写错一个字符。
