# Microsoft远程桌面 连不上或报错怎么排查

> 手机端连不上的成因集中在电脑侧与网络侧。本篇先按错误码分类，再按网络、地址、开关、账号、端口、外网逐层排除。

安卓客户端给出的信息很少，多数时候只有一个错误码。好在错误码足以把范围缩小一半：0x104 偏「找不到这台电脑」，0x204 偏「找到了但连不上」。先按码分类，再按层次从上往下排除，比反复重装客户端有效得多——重装客户端治不了电脑侧的开关和路由器侧的规则。

## 一、先看错误码

| 错误码 | 常见含义 | 先查这一侧 |
| --- | --- | --- |
| 0x104 | 找不到电脑：地址不对、电脑不在线、网络不可达 | 地址、在线状态、是否同一网段 |
| 0x204 | 无法连接：能到达但被挡住或服务端不接受 | 远程桌面开关、防火墙与端口、账号权限、网络级身份验证 |
| 0xf07 | 账户密码已过期 | 在被控电脑上改密码，再用新密码重试（官方文档专门列了这一条） |

这两个码常常成对出现——同一次故障里既报 0x204、又报 0x104 的情况很常见，所以别只看其中一个码就下结论。

## 二、按顺序排除（一次只改一处）

1. **手机和被控电脑是不是在同一个网络。** 手机连 Wi-Fi、电脑接同一个路由器的有线口，通常没问题；手机用移动数据、电脑在家里的网内，一定连不上。快速验证的办法：用另一部手机开热点，把手机和被控电脑都连到这个热点上再试一次——能连上就说明问题出在原网络的隔离策略上。
2. **地址对不对。** 电脑换过 Wi-Fi、重启过路由器，局域网 IP 就变了，手机里存的旧地址随即失效。到电脑上重新看一遍 IPv4（「设置 → 网络和 Internet → 属性」，或命令行 `ipconfig`），把连接里那条地址改掉再连。
3. **电脑是不是睡着了。** 远程连接要求电脑开着、联网、没在睡眠。唤醒它，或按 [电脑端怎么设置才能被远程连接.md](电脑端怎么设置才能被远程连接.md) 第六节把睡眠关掉。
4. **远程桌面开关。** 到「设置 → 系统 → 远程桌面」确认开关是打开的。被控端是家庭版的话，这一项根本不存在——远程桌面只能连专业版、企业版这类 SKU。
5. **账号权限与密码。** 账户要在「可以选择远程访问此电脑的用户」列表里（Administrators 组成员默认在里面）；空密码的本地账户只允许本地登录，远程一定被拒。
6. **防火墙与端口。** 在被控电脑上执行：

```powershell
netstat -ano | findstr :3389
```

有 `LISTENING` 才说明本机在监听 3389。没有输出，要么远程桌面没真正生效，要么端口被改过（那就换成改后的端口再查）。有监听却还连不上，去看 Windows 防火墙里的「远程桌面」入站规则有没有被禁用；改过端口的话，官方那条默认规则不再匹配，需要自己补一条对应端口的入站规则。

7. **网络级身份验证（NLA）。** 被控端若勾了「仅允许运行使用网络级别身份验证的远程桌面的计算机连接」，某些客户端或环境会卡在认证之前。官方给的取舍是：需要从家庭网络外部远程连接时，不要选这一项。
8. **外网访问。** 人在外面要连家里电脑，得在路由器上做端口转发，或先连 VPN 进内网。**不要**把 3389 直接映射到公网——它是被扫描最多的端口之一；能用 VPN 就优先 VPN，确实要转发时远程账户必须有强密码。配完还是不通，最快的分流判据是：让同一网络下的设备搜「我的 IP」，拿到的地址与你路由器 WAN 口显示的地址不一致，就说明没有公网地址，端口转发这条路根本不成立。这两种路线的完整步骤与安全要求见 [在外网连家里电脑怎么弄.md](在外网连家里电脑怎么弄.md)。
9. **走网关的连接报错。** 这类连接先核对网关地址、网关账号、以及 443 端口有没有被公司网络挡住，细节见 [远程资源订阅与网关怎么设置.md](远程资源订阅与网关怎么设置.md)。官方在新客户端里修过一个「用 RD 网关连接时报 0x5000007」的问题，看到相近提示时，优先查网关这一层，而不是换客户端。

## 三、判断锅在哪一侧：换一个客户端试

用另一台设备连同一台被控电脑（同事的电脑、或另一部装过客户端的手机）：

- **能连上** → 网络与被控电脑侧没问题，问题在你这台手机或这条连接上：先删掉这条连接重建一条，再核对地址与账号写法；
- **同样连不上** → 回到被控电脑侧，重点看第二节的第 4 到第 7 条。

这一步的价值在于：它把「客户端配置错」和「电脑/网络没准备好」这两类完全不同的问题一次分开，省掉大量来回试。

## 四、排除了电脑和网络之后，才轮到怀疑客户端

被控电脑侧逐条确认过、另一台设备也能连上，唯独这台手机不行，且表现为闪退、黑屏、安装后打不开，那大概率是客户端本身与当前系统不搭：8.x 这条线早已停止演进，在较新的安卓系统上没有官方保证。这时换新一代客户端会比继续调设置更快——两者连的是同一台电脑，包名与取舍见 [和Windows应用有什么区别.md](和Windows应用有什么区别.md)。
