# Microsoft远程桌面 和Windows应用有什么区别

> 微软在安卓上先后有过三代远程桌面客户端，网盘里这份是最老的一代。本篇把三代的名字、包名与能力差异摆出来，帮你判断该装哪一个。

同一个远程桌面协议、同一个微软账号，安卓上却先后出现过三代客户端，而且第一代与后两代的包名不一样——这正是「我搜到的教程和我的界面不一样」的根源。三代都能连同一台 Windows 电脑，差别在维护状态、云资源支持与界面细节，跟授权类型无关。

## 一、三代对照

| 代际 | 名称 | 包名 | 现状 |
| --- | --- | --- | --- |
| 第一代（网盘里这份） | Microsoft Remote Desktop，也被叫作 Remote Desktop 8 | `com.microsoft.rdc.android` | 8.x 版本线。官方更新日志里 8.x 的记录停在 2020 年 5 月的 8.1.80，之后不再演进 |
| 第二代 | 新版远程桌面客户端（RD client） | `com.microsoft.rdc.androidx` | 从 10.x 起，官方持续更新；最低安卓版本要求逐版提高——10.0.12 起要求 Android 8，10.0.13 起要求 Android 9 |
| 第三代 | Windows 应用（Windows App） | 仍是 `com.microsoft.rdc.androidx` | 在安卓与 Chrome OS 上已正式发布，Google Play 上对应的就是同一个包名；官方说明远程桌面客户端在安卓上正被 Windows 应用取代 |

包名这一节最关键：第一代与后两代是**两个独立的应用**，可以同时装在一部手机上，各存各的连接与设置，互不覆盖。第二代起支持把 Remote Desktop 8 的连接与设置迁移过去——官方更新日志里，8.1.80 写了「为把设置与连接迁移到新客户端做准备」，10.0.7 写了「启用了从 Remote Desktop 8 迁移连接与设置」。

## 二、能力差异

| 能力 | 第一代 8.x（网盘里这份） | Windows 应用 |
| --- | --- | --- |
| 直连自己的 Windows 电脑（RDP） | 支持 | 支持 |
| 通过远程桌面网关访问 | 支持 | 支持 |
| 管理员发布的远程资源订阅 | 支持 | 支持 |
| Azure 虚拟桌面 / Windows 365 / Microsoft Dev Box | 云侧订阅说明现在挂在 Windows 应用这条线上，8.x 的支持范围以官方当页说明为准 | 支持 |
| 持续更新与新版系统兼容性 | 已停止演进，较新系统上没有官方保证 | 在维护 |
| 安装包体积 | 18.22M（本文核对值） | 以应用商店当页显示为准 |

## 三、该装哪一个

- **只想连自己的一台 Windows 电脑、手机系统不算新、不想装体积更大的客户端** → 网盘里这份 8.x 就够用，[Microsoft远程桌面 安装文件资源（夸克网盘）](https://pan.quark.cn/s/69065683142b) 就是它。
- **要接公司或学校的云资源（Azure 虚拟桌面、Windows 365、Dev Box），或想要一个还在维护、跟得上新系统的客户端** → 用 Windows 应用。发布类资源的订阅填法，两条线思路一致，见 [远程资源订阅与网关怎么设置.md](远程资源订阅与网关怎么设置.md)。
- **拿不定** → 先按 [下载与安装教程.md](下载与安装教程.md) 装网盘这份试连；一旦出现闪退、黑屏、装完打不开，并且已经排除了电脑侧的原因，就换 Windows 应用，别在老客户端上耗时间。

## 四、三个常见误解

1. **「装了客户端就能连任何电脑」** —— 不是。被控端必须是 Windows 专业版、企业版（或 Windows Server）并且已经开启远程桌面；家庭版不能作为被控端。这条限制对三代客户端一视同仁，成因在被控电脑那侧，见 [电脑端怎么设置才能被远程连接.md](电脑端怎么设置才能被远程连接.md)。
2. **「两个包名是免费版和付费版的区别」** —— 不是。它们只是不同代际的客户端，功能差异来自版本线与云资源支持，跟授权类型无关。
3. **「手机上的客户端就是 Windows 里那个『远程桌面连接』」** —— 不是。Windows 自带的那个（界面名「远程桌面连接」）只能在 Windows 上运行；手机上要用的是本文讨论的安卓客户端。

## 五、换客户端前后要注意什么

- 换之前先把老客户端的连接信息记下来：PC 名称（电脑名或 IP）、要用的账户写法。有迁移入口时优先用迁移，省得重填。
- 两个应用的图标不同——8.1.80 那次更新的内容之一就是更换图标，目的正是与当时处于预览阶段的新客户端区分开。装完别在应用列表里把两者搞混。
- 卸载老客户端不会影响被控电脑上的任何设置，也不会影响网盘里那份安装包；想换回来，重装即可，电脑侧不用重配。
