# Microsoft远程桌面 添加连接与账号密码怎么填

> 本篇把「+ → 桌面」这条路径上的每个填空项讲清：PC 名称填什么、用户名存不存、更多选项里那几项各自影响什么。

添加一条连接只有一项是必填的：PC 名称。其余全留空也能连，代价是每次都要手输密码、声音按默认走。本篇不铺陈界面，只逐项说明「填了会怎样、不填会怎样」，照着走一遍就能建好第一条连接。文中的选项名以官方文档的英文标识为准，不同语言版本里显示的文字可能不同。

## 一、两个入口别选错

在连接中心点 `+`，会出现两类入口，用途完全不同：

| 入口 | 用来连什么 | 什么时候用 |
| --- | --- | --- |
| 桌面（Desktop） | 直连一台 Windows 电脑 | 你自己的电脑、家里或公司的单台机器，最常用 |
| 远程资源源（Remote Resource Feed） | 管理员发布的 RemoteApp、会话桌面、虚拟桌面 | 拿到公司/学校给的订阅地址时，见 [远程资源订阅与网关怎么设置.md](远程资源订阅与网关怎么设置.md) |

选错入口的典型现象是：在桌面入口里填了一个订阅地址，怎么都不通。

## 二、PC 名称填什么

官方对这个字段的说明是：可以填 Windows 电脑名、Internet 域名或 IP 地址，并可以在后面接端口。这是**唯一必填**的字段。

| 你手里的信息 | 就填 |
| --- | --- |
| 电脑名（形如 `DESKTOP-8K3L1M`） | 原样填 |
| 局域网 IPv4（形如 `192.168.1.23`） | 原样填 |
| 公网域名 | 原样填 |
| 电脑改过远程桌面端口 | `地址:端口`，例如 `192.168.1.23:13389` 或 `MyDesktop:3389` |

填错的典型表现是错误码 0x104（找不到电脑），逐层排查顺序见 [连不上或报错怎么排查.md](连不上或报错怎么排查.md)。

## 三、用户名：每次输入还是保存

- **每次输入（Enter every time）**：每次连接时才问密码。手机可能外借、或者不想在手机里长期留账号密码时选这个。
- **添加用户账户（Add user account）**：把账户存下来，之后免输密码。用户名支持三种写法：`user_name`、`domain\user_name`、`user_name@domain.com`；要保存的账户必须带密码，不带密码的账户存不下来。

存过的账户统一在「设置 → 用户账户」里管理：长按可以多选，垃圾桶图标一次删掉多个。

一句实在话：保存的密码存在应用自己的本地数据里，手机落到别人手里，等于把远程账户一起交出去。公用机、或账户在电脑上有管理员权限的，建议选「每次输入」。

## 四、更多选项里的六项

点「显示更多选项」之后才会出现下面这些，都可以不填：

| 项目 | 影响什么 | 什么时候值得改 |
| --- | --- | --- |
| 网关（Gateway） | 从外网连内网电脑时走的中转服务器 | 管理员给了网关地址才填，局域网直连不要填 |
| 声音（Sound） | 远程会话的声音在本机播、在远程设备播，还是不播 | 想边远控边听声音就选本机；不想被提醒声打断就选不播 |
| 自定义显示分辨率 | 这一条连接单独用的分辨率 | 关着就用「设置 → 显示」里的全局分辨率 |
| 交换鼠标按键 | 左右键互换 | 左手使用者 |
| 连接到管理员会话 | 连到远程电脑的管理会话 | 排障需要时，且账户要有相应权限 |
| 重定向本地存储 | 让远程会话能读到手机上的文件 | 默认关闭；需要在远程电脑里读写手机文件时才开 |

注意一条容易白折腾的规则：**显示方向、分辨率这类设置改完之后只对新建立的连接生效**，当前正开着的会话要断开、重新连一次才会用上新值。

## 五、保存、首次连接与证书提示

1. 填完点保存，这条连接会出现在连接中心里；
2. 点它的名字开始连接；
3. 如果弹出证书确认，点连接继续；不想每次都看到，勾上「不再询问到这台电脑的连接」；
4. 卡在密码上并报 0xf07，说明该账户的密码已过期（官方文档专门列了这一条），在被控电脑上改密码后用新密码重试。

## 六、连上之后界面上多的三样东西

| 控件 | 默认在哪 | 干什么 |
| --- | --- | --- |
| 连接条 | 屏幕顶部中间，可左右拖 | 唤出平移控件、键盘，展开会话选择条与命令条 |
| 会话选择条 | 屏幕左侧 | 同时开着多条连接时切换；单条会话卡片上的 `X` 用来断开 |
| 命令条 | 屏幕右侧 | 切换鼠标模式（直接触摸 / 鼠标指针），回连接中心 |

点回连接中心**不会断开**正在跑的会话，再点一次连接名就能接着操作。多设备同时在线、会话之间怎么切，见 [远程画面手势与鼠标操作.md](远程画面手势与鼠标操作.md)。

## 七、连接多了以后怎么改、怎么删

在连接中心对着那条桌面点右侧的 `…`，可以编辑或删除；删除只影响手机上的这条记录，不动被控电脑上的任何设置。另外，如果你把连接钉到了安卓桌面（小组件），**在客户端里改名，桌面上那个标签不会跟着更新**——官方专门说明了这一点。
