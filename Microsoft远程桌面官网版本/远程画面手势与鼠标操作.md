这个客户端提供了两套鼠标模式，同一根手指的动作在两套模式下的含义完全不同——直接触摸（Direct touch）把你的手指当触摸屏，鼠标指针（Mouse pointer）把手指当鼠标。用错模式最典型的感觉就是「点了没反应」「右键出不来」。下面先给官方口径的对照表，再讲几个容易白折腾的开关。选项名按官方英文标识给，不同语言版本的显示文字可能不同。

## 一、两种模式怎么切

点击连接条唤出命令条，在命令条上切换。默认是直接触摸模式，适合看文档、点按钮、拖滚动条；鼠标指针模式适合操作只认鼠标的桌面程序，比如需要右键菜单、需要按住拖动窗口的场景。切换随时可以进行，当前会话不受影响。

## 二、手势对照表（官方口径）

| 鼠标模式 | 想做的事 | 手势 |
| --- | --- | --- |
| 直接触摸 | 左键单击 | 单指点按 |
| 直接触摸 | 右键单击 | 单指点住，抬起 |
| 鼠标指针 | 缩放画面 | 两指捏合或张开 |
| 鼠标指针 | 左键单击 | 单指点按 |
| 鼠标指针 | 左键拖动 | 单指双击并按住，然后拖动 |
| 鼠标指针 | 右键单击 | 双指点按 |
| 鼠标指针 | 右键拖动 | 双指双击并按住，然后拖动 |
| 鼠标指针 | 滚轮上下滚 | 双指点住，然后上下拖 |

一条前提：原生触摸手势只在直接触摸模式下、且被控系统是 Windows 8 或更高版本时才被支持。连老系统时，手指动作只能按鼠标来用。

## 三、画面缩放与平移

- **平移控件（Pan control）**：点连接条上的平移图标出现，用于放大画面并在放大的画面里移动位置；再点一次图标恢复原始大小。它只在直接触摸模式下可用。
- **怎么用**：长按平移控件，往想去的方向拖，画面同向移动；想挪动控件本身的位置，双击并按住它再拖。
- **一个会引起误会的开关**：「设置 → 通用」里有一项「双指缩放远程会话」（Pinch to zoom remote session）。如果你要操作的桌面程序本身支持多点触控（Windows 8 之后引入的那套），要把它关掉，否则捏合手势会被客户端自己吃掉，传不到远端程序里。

## 四、键盘输入

- 连接条上的键盘图标用来显示或隐藏屏幕键盘；键盘弹出时平移控件会自动出现，方便一边看一边定位。
- 用外接键盘、或远端程序对按键响应不正常时，去「设置 → 通用」里打开「可用时使用扫描码输入」（Use scancode input when available）。官方给的判据就是这一条：远端应用对键盘输入反应不对时打开；关闭状态下输入按 Unicode 发送。
- 中文输入法、组合键这类跟远端系统语言环境相关的问题，先确认被控电脑上装了对应的输入法，再回来调客户端侧的开关。

## 五、显示方向与分辨率

- 位置：连接中心 → 设置 → 显示。
- **方向（Orientation）**：设定会话偏好横屏还是竖屏。
- **分辨率（Resolution）**：设定桌面连接的全局分辨率；某条连接单独设过自定义分辨率的，不受这里影响。
- 这两项都是**全局设置**，且只对之后新建的连接生效；当前会话要应用新值，断开再连一次。
- 官方给的一个例外：被控电脑跑的是 Windows 8 或更早的系统时，设备方向一变，画面缩放就会不对。这时需要在想要的方向下断开重连；官方给的替代做法是改用 Windows 10 的电脑。

看画面不舒服时，按「你要的效果」定位到具体那一项，比在设置里挨个试快：

| 你要的效果 | 动哪一项 | 生效方式 |
| --- | --- | --- |
| 让远端内容在手机屏幕上显得更大 | 把分辨率调低一档（设置 → 显示 → 分辨率） | 断开重连 |
| 固定以横屏（或竖屏）进入会话 | 改「方向」（设置 → 显示） | 断开重连 |
| 远端程序支持多点触控、捏合手势却没传到远端 | 关掉「双指缩放远程会话」（设置 → 通用） | 立即 |
| 连 Windows 8 及更早系统、转方向后缩放错乱 | 先在想要的方向下断开重连，或改用 Windows 10 的电脑 | 断开重连 |
| 操作手感发迟 | 通常是先把分辨率降下来再看 | 断开重连 |

## 六、手机里的文件在远程会话里怎么用

默认看不到。「重定向本地存储」（Redirect local storage）在每条连接的「显示更多选项」里，**默认关闭**。打开之后，远程电脑上才能看到手机存储里的位置，用来在两端之间拷文件。它的前提是给应用存储权限——安装包把存储列为可选权限，正是为了这一项功能。

## 七、把常用连接钉到安卓桌面

这个客户端支持用安卓的小组件把连接钉到桌面：

1. 桌面长按空白处 → 小组件；
2. 找到带「Pin Remote Desktop」说明的那个图标；
3. 拖到桌面后松手，会列出已保存的连接，选一条；
4. 之后点桌面上的图标可以直接发起连接，不必先进应用。

注意：在客户端里改了连接名，桌面上这个标签**不会**同步更新（官方说明）。

## 八、同时开多条会话

可以同时开多条连接（连不同的电脑），用屏幕左侧的会话选择条切换。接了远程资源时，还会多出一层：点会话卡片上的 `>` 展开列表，在管理员发布给你的多个应用之间切换；想另起一个，点「开始新的」（Start New）后从列表里选。断开单条会话用卡片左侧的 `X`。发布类资源的订阅与网关配置见 [远程资源订阅与网关怎么设置.md](远程资源订阅与网关怎么设置.md)。
