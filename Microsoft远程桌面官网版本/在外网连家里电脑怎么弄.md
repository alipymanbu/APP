# Microsoft远程桌面 在外网连家里电脑怎么弄

> 同一个 Wi-Fi 下能连、出门用流量就连不上，这是正常的——远程桌面默认只覆盖局域网。本篇讲清官方的两条路：端口转发与 VPN。

手机与被控电脑之间是点对点连接，也就是说手机必须能直接找到那台电脑。同一个 Wi-Fi 下没问题，一旦手机走了移动数据，两者之间就隔了运营商和路由器，网关这一跳默认不放行。官方给的两条路是：在路由器上做端口转发，或者先连 VPN 再连远程桌面。本篇按顺序讲这两条路各自要准备什么、以及怎么判断自己走不通哪一条。

## 一、先确认你有没有公网 IP

端口转发这条路的前提是：你家宽带有一个真正属于你的公网地址。判断办法是拿两个值对比：

| 怎么看 | 在哪看 |
| --- | --- |
| 路由器拿到的地址 | 登录路由器管理后台，找「运行状态 / WAN 口状态 / Internet」里的 WAN IP 或公网 IP |
| 外网看到你的地址 | 用同一网络下的设备打开浏览器，搜索「我的 IP」，看显示出来的地址 |

两个值一样 → 你有公网 IP，端口转发可行；不一样、或路由器的 WAN IP 落在 `100.64.x.x`、`10.x.x.x`、`192.168.x.x` 这类内网段 → 说明运营商在中间又做了一层地址转换，端口转发做了也不生效，直接跳到第三节走 VPN 那条路。这一步的判断以你路由器上显示的实际值为准。

## 二、路线一：端口转发

需要在路由器上把「某个端口」映射到被控电脑的「IP + 端口」。动手前先备齐四项信息：

1. **被控电脑的内网地址**：在电脑上进「设置 → 网络和 Internet → 状态 → 查看网络属性」，找状态为「运行中」的那张网卡，记下它的 IPv4 地址；
2. **公网地址**：上一节第一个值；
3. **要映射的端口**：远程桌面默认是 3389；
4. **路由器的管理员权限**：不同品牌的路由器菜单名不一样，通常叫「端口转发 / 虚拟服务器 / NAT 转发 / 高级转发」。

在路由器里新建一条规则，把外部端口映射到第 1 步那个内网地址的对应端口，协议选 TCP（部分路由器要选 TCP/UDP）。保存后部分型号需要重启路由器才生效。

官方对这个做法有一句明确的提醒：**这等于把电脑开放到互联网上，不推荐这样做**。如果一定要做，必须给这台电脑设强密码；官方的原话是「更推荐使用 VPN」。

两个能显著降低风险的附加动作：

- **改掉外网端口**：不要用 3389 作为对外端口。它是被自动化扫描最多的端口之一；换成一个高位端口，并在客户端里用「地址:端口」的写法连。
- **限制来源地址**：多数路由器允许指定「只有某个来源 IP 或网段能用这条映射」。你知道自己只从公司连，就把来源限定成公司的出口地址，避免对所有人开放。

还有一个能让配置不容易失效的设置：**给被控电脑在内网里固定一个 IP**（路由器里的「DHCP 保留 / 地址保留」即可）。否则电脑重新联网后内网地址变了，端口转发就指向了一个空地址。

## 三、路线二：VPN（官方推荐的那条）

先连 VPN 再连远程桌面，逻辑上是：VPN 让你手机「像在同一张内网里」，于是手机访问被控电脑的内网地址就能通，全程不需要把电脑暴露到公网。

官方对这条路的描述是：通过 VPN 连进局域网之后，远程桌面客户端就像局域网内的一员，可以直接访问那台电脑；同时你不必对公网开放任何端口。VPN 由谁提供取决于你的环境：家里的路由器自带 VPN 服务就用它；公司环境用公司发的 VPN；也可以自建。

这条路唯一多出来的一步是：连接顺序固定为「先连 VPN，再点远程桌面」，VPN 断了远程会话也会断。

## 四、地址会变：要不要上 DDNS

家庭宽带的公网地址是运营商分配的，随时可能变。地址一变，你用旧地址连就会失败——现象和「电脑没开机」很像，容易误判。

官方给的办法是 **Dynamic DNS（DDNS）**：路由器或电脑上的一个小程序发现公网地址变了，就自动去更新一个固定域名，让你始终用同一个域名连接，而不是追着一个会变的 IP 改配置。你的路由器如果内置了某家 DDNS 服务商的配置项，直接在路由器里填账号开起来最省事；路由器不支持，就在被控电脑上装对应客户端。

另一种省事办法是给这条连接留个可维护的习惯：出门前先在电脑上确认一次当前公网地址，或者干脆依赖 DDNS。两种都行，关键别把配置写死在一个过期地址上。

## 五、在客户端里怎么填

新增或编辑那条连接时，PC 名称按下面的写法填（写法规则见 [添加连接与账号密码怎么填.md](添加连接与账号密码怎么填.md)）：

| 你用的方案 | PC 名称填什么 |
| --- | --- |
| 端口转发 + 公网地址 | `公网地址:外部端口`，例如 `203.0.113.7:45000` |
| 端口转发 + DDNS 域名 | `你的域名:外部端口`，例如 `myhome.ddns.net:45000` |
| VPN 后访问内网 | VPN 连通后，填被控电脑的内网地址，例如 `192.168.1.23` |

注意第二条：域名只负责解析到你家地址，端口仍要单独写，除非你映射的外部端口就是 3389。

## 六、安全上必须做的三件事

把家里的电脑开放到公网这件事，风险主要在「被别人试着猜密码」上。三件事必须同时做到：

1. **强密码**：远程账户用足够长的密码，别用姓名加生日的组合；
2. **限定来源**：能限定来源地址的，就别对全网开放；
3. **不长期开放**：只在需要的那段时间开着映射，用完关掉；比这更省心的是走 VPN，压根不开端口。

## 七、配好了还是不通，按这个顺序查

1. **先排除内网问题**：手机连回家里的 Wi-Fi，用被控电脑的内网地址试一次。内网都连不上，说明问题不在外网这层，回 [连不上或报错怎么排查.md](连不上或报错怎么排查.md)；
2. **确认端口真的映射出去了**：换用手机流量（脱离家里网络）再试一次，同时核对路由器里那条规则是不是启用了、内外部端口有没有写反；
3. **确认地址没变**：核对当前公网地址与连接里写的是否一致；用了 DDNS 的，确认域名解析出来的地址与当前公网地址一致；
4. **确认没有二次 NAT**：回到第一节的两个值对比，若 WAN IP 是内网段，端口转发这条路走不通，改走 VPN；
5. **确认被控电脑的防火墙**：改过远程桌面端口的，Windows 防火墙里那条默认规则不再匹配，要补一条对应端口的入站规则。
