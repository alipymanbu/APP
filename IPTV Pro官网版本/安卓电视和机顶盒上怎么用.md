# IPTV Pro 安卓电视和机顶盒上怎么用

IPTV Pro 是个安卓应用，所以能不能装，取决于你那台设备跑的是不是安卓。装上之后真正费事的两件事是：怎么把播放列表弄进去，以及怎么用一个只有方向键的遥控器操作它。本篇按这三步说。

## 一、先确认设备能不能装

| 设备类型 | 能不能装 | 说明 |
| --- | --- | --- |
| 安卓电视盒子、Android TV、Google TV | 能 | 认 APK，按下面的步骤走 |
| 国产智能电视（安卓内核的定制系统） | 多数能 | 系统里通常有「U 盘安装」或允许未知来源的开关 |
| 三星 Tizen、LG webOS 的智能电视 | 不能 | 这两套系统不认 APK，只能装它们自家应用商店里的东西 |
| 老式非智能电视 | 不能 | 需要外接一个安卓盒子 |

系统版本下限和手机一致：**标注的是 Android 5.0 及以上**（以官方页面当时显示为准）。判断办法：进「设置 → 关于」或「设置 → 设备信息」，能看到「Android 版本」的就是安卓系统。

## 二、把安装包送进设备

盒子不像手机那样随手能打开浏览器下载，四条路按通用程度排：

| 方式 | 怎么做 | 注意 |
| --- | --- | --- |
| U 盘 | 电脑上把 APK 拷到 U 盘 → 插到盒子/电视上 → 用系统自带的文件管理器打开 | U 盘要用 FAT32 或 exFAT 格式，NTFS 有些设备认不出来 |
| 局域网传输 | 电脑开一个共享，或者用局域网传输工具从手机推过去 | 设备需要能装一个文件管理器来接收 |
| 设备自带浏览器 | 在电视或盒子的浏览器里直接打开网盘链接下载 | 电视遥控器输入网址很费劲，能不用就不用 |
| 手机蓝牙发送 | 手机与设备配对后蓝牙发送 | 较大的文件速度慢，43 MB 左右还能忍 |

安装包在哪取：跟手机端是同一个地方 —— [IPTV Pro 安装文件资源（夸克网盘）](https://pan.quark.cn/s/e989e52384c8)。先在电脑或手机上转存下载，再按上表拷进设备。

打开安装包之前，先允许未知来源：安卓盒子的入口一般在「设置 → 安全 → 未知来源」或者「设置 → 应用 → 特殊应用权限 → 安装未知应用」；国产定制系统常收在「安全」或「家长控制」附近。这一步没开，点安装包只会提示「已阻止安装」。

装完记一件事：这类应用首先是给手机平板用的，界面上有些操作（拖动、长按、侧滑）在遥控器上未必有对应按键，下一节讲怎么绕开。

## 三、遥控器怎么操作它

遥控器能用的就三个键，先把它们对应上：

| 遥控器按键 | 相当于触摸屏上的 |
| --- | --- |
| 方向键 | 移动焦点（选中那一项会高亮） |
| 确认 / OK | 单击 |
| 返回 | 退回上一级 |

**最现实的麻烦是输入播放列表网址。** 用遥控器逐字敲一串带参数的地址基本不现实，所以盒子上推荐换一条路：

1. 在电脑上把播放列表保存成 `.m3u` 或 `.xspf` 文件；
2. 拷到 U 盘，插到设备上；
3. 在应用里选「添加播放列表 → 文件」，用文件选择器选中它。

这样就完全不用打字。频道的分类、频道名都能从文件里读到，和在手机上用网址导入是一样的效果（两种导入方式各自怎么做，见 [添加直播源与导入播放列表.md](添加直播源与导入播放列表.md) 第二、三节）。

如果确实只能用网址导入：把设备接一个 USB 鼠标，或者用带光标功能的飞鼠遥控器，会比方向键快得多。**播放列表是存在每台设备本地的，在手机上加过的不会自动出现在盒子上**，所以盒子上必须单独配一次。

## 四、把它用成一台传统机顶盒

付费版有两项专门为这种场景准备的开关（免费版没有，差异见 [免费版和付费版有什么区别.md](免费版和付费版有什么区别.md)）：

| 开关 | 作用 | 开着之后的效果 |
| --- | --- | --- |
| 开机自启 | 设备启动时自动打开应用 | 盒子通电后不用再去应用列表里找它 |
| 自动播放上次的频道 | 打开应用直接进上次看的那一个台 | 省掉「启动 → 选频道」这两步 |

两个都打开，行为上就接近传统机顶盒了：给盒子通电，直接出现在上次看的那个频道上。给家里不熟悉智能设备的成员用时，这两项是关键。

顺带一个使用习惯：遥控器上的「返回」在列表页按到底是退出应用，不是切到别的台。换台用方向键在列表里选，不要靠返回。如果设备支持 HDMI CEC（在电视和盒子两端都开启），还能实现「打开盒子自动切到盒子的信号源」，省掉用电视遥控器切 HDMI 的那一步。

## 五、盒子上的四个注意点

| 注意点 | 具体怎么做 |
| --- | --- |
| 存储小、缓存会涨 | 盒子存储普遍不大。频道图标和节目单会占缓存，卡了先清一次应用缓存，不必卸载重装 |
| 应用被后台清掉 | 在设备的省电/后台管理里把这个应用加进白名单，否则待机回来要重新启动 |
| 组播源必须接网线 | 电视盒子通常有网口。`udp://` 这类组播源走无线极不稳，做法见 [局域网组播与UDP代理怎么用.md](局域网组播与UDP代理怎么用.md) |
| 遥控器按不出来的操作 | 别在盒子上硬试手势。需要精细操作时接鼠标，或者改用手机端 |

盒子这条路能不能顺，很大程度上取决于你手上那台设备：网口有没有、系统是不是原生安卓、遥控器有没有光标键。这三样占齐了，体验会明显好过在手机上拼凑。
