IPTV Pro 是安卓上的一个网络电视播放器，开发方是 Alexander Sofronov，付费版与免费版是两个各自独立的安装包。它本身不含任何频道，装完的第一件事是把你自己的播放列表导进去。本篇只干两件事：确认网盘里这份包是哪一版，然后把它装进设备。

## 一、先弄清网盘里这份包是哪一版

网上搜到的版本信息是当时的最新发布版，而网盘里这份是制作文档时核对过的那一份，两者未必是同一个修订号。下面这张表是本文的唯一口径：

| 项目 | 值 |
| --- | --- |
| 应用名 | IPTV Pro |
| 版本号 | 9.1.10 |
| 包名 | `ru.iptvremote.android.iptv.pro` |
| 安装包体积 | 43.40 MB |
| MD5 | `DE2D9D8F7B5A8E05F979B725CA8DF49B` |
| 开发方 | Alexander Sofronov |
| 标注的系统要求 | Android 5.0 及以上（以官方页面当时显示为准） |

**关于版本号**：IPTV Pro 用的是「主版本.次版本.修订号」三段式，9.x 这条线里次版本号（9.1）长期不变，修订号往上递增。9.1.10 之后网上还能查到更高的修订号，这属于同一条线上的正常迭代，不影响你手上这份能用 —— 它不是「旧到不能用」的老版本，只是没跟着官网同步刷新。

**关于包名**：这一条比版本号更要紧。同一个应用有付费版和免费版两个包，`.pro` 结尾的才是付费版；免费版是 `ru.iptvremote.android.iptv`（少一个 `.pro`）。包名核对方法见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。

**关于体积**：43.40 MB 只是安装包本身的大小。播放器类应用装完之后的占用主要来自缓存和频道图标，跟你导入多少频道、看多久有关，跟这个数字关系不大。

## 二、装之前先核对包名

安卓上同名或近名的播放器很多，包名是唯一靠得住的身份标识。装之前用文件管理器看一下 APK 的属性，或者在已经装好的情况下进「设置 → 应用 → IPTV Pro → 应用信息」核对，包名应该是 `ru.iptvremote.android.iptv.pro`。

对不上就别装，说明你手上这份不是本文说的那个包，具体风险见 [同名应用与官方渠道怎么认.md](同名应用与官方渠道怎么认.md)。

如果拿到的包是 `.apk` 之外的格式（比如 `.zip`、`.apk.1`、`.xapk`），先改名或解压成 `.apk` 再装 —— 这是传输过程中被加了后缀，不是包本身有问题，但要确认改完之后 MD5 与上表一致。

## 三、两条安装路线

### 路线 A：从网盘取包，侧载安装（本文面向的方式）

1. **转存并下载**：打开 [IPTV Pro 安装文件资源（夸克网盘）](https://pan.quark.cn/s/e989e52384c8)，先把文件夹转存到自己的网盘，再下载到手机或电脑。转存这一步别省 —— 直接下载别人分享的文件，链接失效后就找不回来了。
2. **把包送到设备上**：手机平板端直接下载最省事；装电视盒子的话用 U 盘拷过去，或者用局域网传输工具推送。
3. **允许安装未知来源应用**：进「设置 → 应用 → 特殊应用权限 → 安装未知应用」，给用来打开安装包的那个程序（文件管理器 / 浏览器）打开开关。国产定制系统的这项开关常收在「安全」或「隐私」分类下。
4. **点击 APK 完成安装**：系统若提示「应用未经过安全检测」，选择继续安装，这是第三方渠道安装包的常规提示。
5. **回装低版本要先卸载**：安卓一般不允许用更低版本覆盖更高版本，会直接报「应用未安装」。设备里已经装了比 9.1.10 更高的版本，先卸载再装。

### 路线 B：从官方商店购买安装

应用在 Google Play 上有正式发布页（`https://play.google.com/store/apps/details?id=ru.iptvremote.android.iptv.pro`）。走这条路的好处是能拿到官方最新修订号、由商店负责更新；代价是需要能正常访问 Play 商店，并且要按付费版的价格购买。

注意两条路线拿到的**不是同一个修订号**：商店里是当时的最新版，网盘里是 9.1.10。如果你只是想用起来，两者都行；如果你要的是「和本地已有记录一致的那一版」，用网盘这份。

## 四、首次启动之前，先准备一个播放列表

IPTV Pro 不提供也不内置任何频道，官方描述里写得很直白：要用它，你得先有自己的一份频道列表（m3u 或 xspf）。所以别指望装完打开就能看到节目 —— 首屏停在「添加播放列表」这一步是正常的，不是装坏了。

点它就能进添加流程，两种导入方式各自怎么操作、格式上有什么讲究，写在 [添加直播源与导入播放列表.md](添加直播源与导入播放列表.md)。只想看节目单那一栏怎么跑起来，见 [节目单与EPG怎么设置.md](节目单与EPG怎么设置.md)。

播放列表从哪来：自己有权访问的源才算数 —— 运营商宽带套餐里带的 IPTV、你自己订阅的服务、或者公开授权可用的频道列表。应用本身只是解码播放这一段，播放列表的来源要你自己把关。

## 五、装完做一次最小验证

1. 打开 IPTV Pro，确认首屏出现添加播放列表的入口，说明应用正常起来了；
2. 导入一份你的 m3u 或 xspf，等频道列表加载出来（几百个频道的列表通常要几秒到十几秒）；
3. 随便点开一个频道，画面和声音都正常，说明解码与网络这条路通了；
4. 回列表页，切到另一个频道再放一次 —— 能连续切台不黑屏，才算装好了。

到这一步如果卡住，分两种情况：装完之后**根本打不开或闪退**，先回到本节第 1 步确认包是不是完整（对一遍 MD5）；**打得开但频道放不出来**，那是播放列表或网络的问题，按 [播放卡顿与连不上怎么排查.md](播放卡顿与连不上怎么排查.md) 第一节的交叉验证往下走。

再确认一次你装的是付费版还是免费版 —— 两者的差异只有四项，但广告和开机自启这两条对客厅设备影响不小，对照 [免费版和付费版有什么区别.md](免费版和付费版有什么区别.md) 看一眼。
