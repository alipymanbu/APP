# IPTV Pro 节目单与EPG怎么设置

节目单就是频道的「今天下午放什么」。IPTV Pro 支持在频道列表旁显示节目单，但前提是**播放列表本身带了节目单地址** —— 应用不内置任何节目单数据，也没有地方让你凭空变出一份来。理解了这一点，后面所有现象都好解释了。

## 一、节目单地址是跟着播放列表进来的

官方描述里对这条写得很明确：节目单支持的前提是「播放列表里有指向电视节目的链接」。

一份 m3u 播放列表的文件头通常是 `#EXTM3U` 这一行，节目单地址就挂在这一行上（常见的参数写法是 `url-tvg=` 后面跟一个 XMLTV 文件的地址）。也就是说：

- 你的播放列表里**有这个地址** → 导入后节目单会跟着一起加载，频道列表旁边就能看到当前和下一档节目；
- 你的播放列表里**没这个地址** → 频道能看，但节目单一栏永远是空的，任何设置项都救不回来。

所以看到节目单空白，第一件事不是翻设置，而是**去问提供方要一份带节目单地址的播放列表**。多数正规运营商和服务商都会提供，这属于标配，只是有的默认不给、要单独要一次。

判断方法：用记事本打开你的 `.m3u` 文件，看第一行除了 `#EXTM3U` 还有没有别的内容 —— 只有这七个字符，说明没带节目单地址。

## 二、两种格式：XMLTV 与 JTV

应用支持两种节目单格式，用法上有实质区别：

| 格式 | 常见文件形态 | 说明 |
| --- | --- | --- |
| XMLTV | `.xml` 或 `.xml.gz` | 通用性最好，绝大多数服务商给的是这一种 |
| JTV | 只支持 ZIP 压缩包 | 拿到的如果不是 ZIP，需要先转成 ZIP 再给应用 |

**JTV 只吃 ZIP 压缩包**，这一点在官方描述里明确写了。如果你手上是 JTV 格式的裸文件，应用是读不了的 —— 这种情况最省事的做法是回头找提供方要 XMLTV 版本的节目单，而不是自己去折腾格式转换。

XMLTV 文件本身不小，几千个频道的一整周节目单通常是几 MB 到几十 MB。如果它是一次性全量拉取的，导入后第一次加载会慢一点，这是正常的。

## 三、频道和节目单靠什么对上

节目单里是一堆节目，播放列表里是一堆频道，两者能显示在一起，靠的是**频道标识**匹配 —— 这是 XMLTV 那一套格式的通行做法，不是这个应用特有的。

播放列表里每个频道通常会带一个标识属性（写法一般是 `tvg-id`，有的列表用 `tvg-name`），XMLTV 文件里每个频道也带对应的标识。两边的标识**字符串完全一致**才会匹配上。

由此可以推出最常见的两种「节目单只有一个频道有、其它全空」的原因：

- **两边的标识没对齐**：播放列表里写 `CCTV1`，节目单里写 `cctv-1`，差一个横杠就对不上；
- **节目单里根本没有这个频道**：小语种频道、地方台尤其常见，节目单只覆盖了主要频道。

这两种都不是你设备上的设置问题，需要提供方在生成播放列表和节目单时对齐标识。你能做的验证是：挑一个节目单正常的频道，对比它在播放列表里的标识和节目单里的标识；对不上，就拿着这个例子去问提供方。

## 四、节目时间整体偏移怎么办

这是最能自我判断的一类问题。现象是：节目单能显示，但显示的节目名和你正在看的画面对不上，而且**差的量是固定的小时数**（常见的是差 8 小时）。

这几乎可以确定是节目单里的时间标注带了错误的时区。XMLTV 里的时间有两种写法：带时区偏移的（形如 `20260923193000 +0800`）和不带的（只写本地时间，此时按 UTC 理解）。写错哪一种，都会导致整体平移。

判断步骤：

1. 记下当前正在播的节目名，去节目单里找这个名字，看它被标在几点；
2. 算出偏移量。**凡是固定的小时数偏移，就是时区标注问题**；如果是随机对不上、有的准有的不准，那是节目单本身没过期或频道匹配错位，属于上一节的情形；
3. 固定偏移无从自行修正，需要提供方改节目单源。可以先记下偏移量，作为反馈给提供方的具体信息。

## 五、节目单空白排查表

按「最可能」到「最不可能」排：

| 现象 | 先查什么 | 结论 |
| --- | --- | --- |
| 所有频道都没有节目单 | 打开 `.m3u` 看第一行有没有带节目单地址 | 没带 → 找提供方要带节目单的列表 |
| 有地址但还是全空 | 直接在浏览器里访问那个节目单地址 | 取不到 → 地址失效或需要特定网络，找提供方 |
| 节目单地址是 JTV 且不是 ZIP | 看重定向后的文件是不是压缩包 | 不是 ZIP → 要 XMLTV 版本，或让提供方打包 |
| 只有个别频道空白 | 对比该频道在播放列表与节目单里的标识 | 标识不一致或节目单未收录该频道 |
| 节目单能显示但时间对不上 | 算偏移量是不是固定小时数 | 固定偏移 → 节目单时区标注有误 |
| 今天有、明天没有 | 看节目单覆盖到哪一天 | 节目单是按天分发的，需要提供方持续更新 |

节目单和播放本身是两条独立的路：**节目单空白完全不影响你正常看频道**。所以别为了节目单去重装应用或换播放器，问题一定在数据源那一侧。
