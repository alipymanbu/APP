# Telegram 隐藏手机号与隐私设置

> 注册必须用手机号，但手机号可以不给人看：手机号可见性、最后上线、用户名、本机密码锁、秘密聊天、账号自动删除，逐项怎么设。

Telegram 的隐私设置集中在「隐私与安全」一页里，逐项控制「谁能看到什么」「谁能通过什么找到我」。本篇按你在意的顺序讲：先把手机号收起来，再处理在线状态和头像，最后是账号层的几道锁。

## 一、手机号：谁能看到、谁能找到你

进「设置 → 隐私与安全 → 手机号」，这里有两行，别只改一行：

| 设置项 | 管什么 | 建议 |
| --- | --- | --- |
| 谁能看到我的手机号 | 别人打开你的资料页时，号码是否显示 | 没人看到就选「没有人」 |
| 谁能通过手机号找到我 | 别人在通讯录或搜索里拿号码能不能搜到你 | 不想被号码搜到就选「没有人」 |

两项都支持例外名单：可以给某几个人开「始终允许」，或给某几个人加「始终不允许」，后者优先。

**一个提醒**：你改了可见性，只影响 Telegram 里别人看到的；对方手机通讯录里存过的号码、你们之前聊过时留下的信息，收不回来。

## 二、最后上线、在线状态、头像

同一页里还有几项逐项可设：

- **最后上线时间**：可选所有人 / 我的联系人 / 没有人。
- **头像**：同上。
- **语音通话**：控制谁能给你打过来，和上一页的号码设置是分开的。
- **转发消息的来源链接**：把这关掉，别人转发你发的内容时不会带上你的账号链接。

**「最后上线」是双向的**：按官方的说明，你对某人隐藏了最后上线，也就看不到对方的最后上线，但会看到一个**模糊值**，它分四档：

| 显示 | 对应的真实时间 |
| --- | --- |
| 最近上线 | 1 秒到 2~3 天之间 |
| 一周内上线 | 2~3 天到 7 天之间 |
| 一个月内上线 | 6~7 天到一个月之间 |
| 很久以前上线 | 超过一个月（被屏蔽的人永远看到这一档） |

**在线状态也照这套规则走**：只有和你互相可见的人才能看到你「在线」。有两个例外 —— 你给对方发消息、或在一对一里读了对方的消息，接下来约 30 秒内对方会看到你在线，这与设置无关。

## 三、用用户名代替手机号被人找到

进「设置 → 用户名」，设一个 `@名字`：

- 设好之后，别人用 `@名字` 就能搜到你并开始聊天，**不需要知道你的手机号**。这是把手机号藏住之后最常用的联系方式。
- 用户名长度 5 到 32 个字符（截至 2026-09），公开可搜索。
- 不想被陌生人搜到，把用户名删掉即可；删掉后别人只能靠手机号找到你 —— 所以在删之前，先确认手机号可见性已经设好。

**默认的号码可见范围不是「所有人」**：官方口径是默认只对通讯录里存了你号码的联系人可见，你可以到上一节的设置里再收紧。但有一点收不回来 —— 对方如果早就存了你的号码，他那边始终看得到。

## 四、本机这道锁：密码锁

「设置 → 隐私与安全 → 密码锁」给应用本身加一层解锁，可以用 4 位数字，也可以用密码，再叠加指纹或面容。手机离开手边、或借给别人看时，这道锁管用。

它和两步验证不是一回事：

| | 两步验证 | 密码锁 |
| --- | --- | --- |
| 什么时候拦 | 在**新设备**上登录账号时 | 每次**打开本机**这个应用时 |
| 忘了会怎样 | 需要走重置流程，可能影响登录 | 卸载重装可绕过，但聊天记录要从云端重新拉 |

两步验证的开启方式见 [注册登录与收不到验证码怎么办.md](注册登录与收不到验证码怎么办.md)。

## 五、秘密聊天：真正端到端的那一种

聊天分两类，多数时候你用的是上面那种，秘密聊天是另一条线：

| | 普通聊天 | 秘密聊天 |
| --- | --- | --- |
| 存储 | 云端，多端同步 | 只存在参与的两台设备上 |
| 加密 | 传输与服务器侧加密 | 端到端加密 |
| 换设备 | 记录跟着账号走 | 看不到，也不在云端 |
| 转发 | 可以 | 不允许 |
| 消息自毁 | 无 | 可设计时（可选 1 到 60 秒） |
| 截图 | 无限制 | 会被尝试通知对方（不能保证百分之百） |

自毁计时对秘密聊天里的**所有消息**都可用；在普通聊天里只能对**媒体**设。计时从对方屏幕上显示那条内容开始走，到点后**双方设备上一起消失**，且只对设置之后发出的消息生效。

入口在对方的资料页里（「更多」菜单下的「开始秘密聊天」，位置随版本略有差异）。三点要记住：**秘密聊天不支持桌面端和网页版**；它按设备存在，所以想不起来在哪台手机发起的，就去那台手机上翻；**退出登录会连秘密聊天一起清掉**，退出前的清空操作只清自己这边，对方设备上要单独清。

## 六、账号多久不登录会被删

「设置 → 隐私与安全 → 如果我不登录，自动删除账号」，可选区间为 1、3、6、12、18、24 个月，默认 18 个月（截至 2026-09 的可选范围，以应用内为准）。间隔越短越安全，也越容易因为长期不用而丢掉账号，两三年用一次的账号就选长一点。

## 七、主动注销和一个容易忽略的中间态

- **注销账号**（不可恢复）走官方的账号停用页面，确认码是发到 Telegram 应用内而不是短信，官方建议用非手机的浏览器操作。注销会清掉你的消息与联系人、把你建的群和频道变成无主，且无法撤销 —— 决定之前先把要留的内容另存出来。
- **只是想不再用这台设备**：不要注销，走「退出登录」或「退出其他设备」就够，云端记录都还在，见 [注册登录与收不到验证码怎么办.md](注册登录与收不到验证码怎么办.md)。

## 八、顺手一起设的两项拦截

- **谁能把我加进群**：「隐私与安全 → 群组与频道」里改成「我的联系人」，陌生人就没法直接把你拉进群。
- **谁能给我打电话**：同一页里的语音通话项，怕接骚扰电话就设成联系人。

这两项和手机号可见性一起设，陌生人能做的事就基本被堵住了。怎么加人、怎么进群见 [加好友进群进频道怎么操作.md](加好友进群进频道怎么操作.md)，被陌生人反复拉群、机器人乱发消息这类骚扰的处理见 [机器人怎么找怎么用.md](机器人怎么找怎么用.md)。
