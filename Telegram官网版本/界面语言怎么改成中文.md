# Telegram 界面语言怎么改成中文

Telegram 装完是英文界面，中文不是它内置的母语支持，而是社区译者按官方语言包机制提供的翻译。本篇讲怎么把它切过来，以及切换之后仍看到英文时该怎么理解。

## 一、中文界面是从哪来的

官方的界面语言走「语言包」机制：语言包由社区在官方翻译平台上维护，客户端负责加载。所以有两个结论：

- 菜单、按钮的中文翻译质量取决于语言包的翻译进度，**不是所有条目都能翻到**。
- 语言可以随时换、随时切回英文，切换不需要重装应用。

## 二、手机端切换步骤

1. 打开左上角（安卓）的菜单按钮，进「Settings」。
2. 找到「Language」（语言）这一项，点进去。
3. 在语言列表里选「中文（简体）」或「Chinese (Simplified)」。选中即生效，界面立刻变中文，不用重启应用。
4. 回到主界面确认菜单文字已切换。

**如果语言列表里没有中文**：在应用的搜索框里输入 `@zh_CN`，找到中文语言包的入口（部分版本用的是这个名称，以你实际搜到的结果为准），进去按提示点「应用 / Apply」。此时会跳回设置页，语言即被应用。这类入口由译者维护，来源不明的语言包链接不要点；机器人账号的基本用法见 [机器人怎么找怎么用.md](机器人怎么找怎么用.md)。

## 三、电脑端与网页版

路径逻辑一样，位置不同：

| 客户端 | 大致路径 |
| --- | --- |
| Windows / macOS / Linux 桌面版 | 左上角菜单 → Settings → 找到 Language 一栏 → 选中文 |
| 网页版 | 左侧菜单 → Settings → Language → 选中文 |

同一账号在不同客户端的界面语言是各管各的，手机上切了中文，电脑端还得自己切一次。

## 四、切完仍看到英文，正常吗

分两种情况：

- **零星几条还是英文**：语言包没翻到，属正常现象，等译者更新即可。遇到这种情况不用反复切换语言。
- **整屏都是英文**：说明语言没真正应用。回到第二步重新选一次中文；若列表里选中后无反应，改用 `@zh_CN` 那条入口。

## 五、想切回英文或换繁体

同一路径再选一次即可：英文是 `English`，繁体是「中文（繁體）」。切换只改界面文字，**不改变聊天里别人发来的消息内容** —— 对方发英文还是显示英文，不会自动帮你翻译。

## 六、两件容易和「改语言」搞混的事

- **别人发来的外语消息看不懂**：那是消息内容，不是界面语言的问题，改语言解决不了。
- **改了语言但菜单名字和网上教程对不上**：不同语言包对同一功能的译名不完全一致（例如隐私设置里的「最后上线」「上次在线」指的是同一处），照位置找，不要照字面找。相关设置见 [隐藏手机号与隐私设置.md](隐藏手机号与隐私设置.md)。
