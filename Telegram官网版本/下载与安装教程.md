Telegram 是手机、平板、电脑都能用的云端即时通讯应用，消息、图片、文件都存在账号的云端，换一台设备登录后聊天记录会跟着过去。本篇只管一件事：把网盘里这份安卓安装包装进你的手机，并确认装完能正常用。

## 一、先核对网盘里这份包

各下载页标的版本号是他们自己的登记，与网盘里这份常常对不上。本套文档出现的版本、包名、体积一律以这张表为准：

| 项目 | 值 |
| --- | --- |
| 应用名 | Telegram |
| 版本号 | 11.13.0 |
| 包名 | `org.telegram.messenger` |
| 安装包体积 | 84.52 MB |
| MD5 | `280e49ad9c76118342aa0409d070ee43` |
| 形态 | 安卓 APK |
| 发行方署名 | Telegram FZ-LLC |
| 本文核对时间 | 2026-09-22 |

判断手里的是不是同一份包，看**包名 + MD5**，不要看文件名旁边的版本数字。三处容易混：

- 网上搜到的是官方最新版，与网盘里这份通常不是同一版，版本号不同属正常，本文只认上表。
- 中文语境里它常被叫作「纸飞机」「电报」；部分下载页和网盘把安装包名、文件夹名写作 `telegreat`，包名 `org.telegram.messenger` 对得上就是同一个应用。
- 官方站是 `telegram.org`，官方安卓包页面是 `telegram.org/android`。这两个入口用来核对信息，不改变本文的版本口径。

## 二、安卓安装步骤

1. **先转存再下载**。打开 [Telegram 安装文件资源（夸克网盘）](https://pan.quark.cn/s/0c7e5a516053)，把 APK 转存到你自己的网盘，再从手机上下载。转存这一步别省：分享链接失效后，只有转过存的那一份还在。
2. **允许安装未知来源应用**。通常在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里，给你用来打开安装包的那个应用（文件管理器、浏览器或网盘客户端）放开权限。
3. **点安装包安装**，按系统提示确认。若手机里已有同包名但签名不同的版本，会提示「应用未安装」，先卸载旧的再装。
4. **首次打开给通知权限**。不给的话应用能收消息，但手机不会有任何提醒，只能自己点进去看；给过权限仍然不响的，按 [通知推送收不到怎么办.md](通知推送收不到怎么办.md) 里的三层顺序排查。

## 三、系统要求与空间预留

| 项目 | 说明 |
| --- | --- |
| 安卓版本 | 以 `telegram.org/android` 与商店页面标注为准；当前商店与常见下载页多数标注为 Android 6.0 及以上 |
| 安装包体积 | 84.52 MB（上表口径） |
| 装机后占用 | 安装只是开始，聊天里的图片、视频、语音会持续缓存到本机，见 [缓存占用和自动下载怎么设置.md](缓存占用和自动下载怎么设置.md) |
| 网络 | 打开应用能连上服务是登录的前提；连不上时注册这一步会直接卡住 |

空间紧的话，装之前先腾出 1 GB 以上，避免登录进去就遇到「存储空间不足」。

## 四、第一次打开要做的三件事

1. **登录账号**。输入手机号、收验证码即可，换机登录的验证码还有别的到法，见 [注册登录与收不到验证码怎么办.md](注册登录与收不到验证码怎么办.md)。
2. **把界面切成中文**。默认界面是英文，中文来自社区翻译包，切换路径见 [界面语言怎么改成中文.md](界面语言怎么改成中文.md)。
3. **看一眼自动下载开关**。默认状态下打开过的图片视频都会存到本机，想省空间趁早改，见 [缓存占用和自动下载怎么设置.md](缓存占用和自动下载怎么设置.md)。

## 五、装不上、打不开怎么处理

| 现象 | 大概率原因 | 动作 |
| --- | --- | --- |
| 提示「解析包错误」 | 安装包没下完或下载中断 | 回到网盘重新下载一份完整的包 |
| 提示「应用未安装」 | 同包名但签名不同 | 先卸载手机里已有的旧版再装 |
| 点了没反应 | 没开「安装未知应用」权限 | 在系统设置里给打开安装包的应用开权限 |
| 装上就闪退 | 系统版本过老，或包与机型不匹配 | 对照官方页面确认最低安卓版本，太老的机型换设备装 |
| 显示英文看不懂 | 默认界面语言就是英文 | 见 [界面语言怎么改成中文.md](界面语言怎么改成中文.md)，登录后再改也可以 |

登录环节卡在验证码上的，直接看 [注册登录与收不到验证码怎么办.md](注册登录与收不到验证码怎么办.md)，那里按「验证码从哪来 → 逐项排查」排好了顺序。
