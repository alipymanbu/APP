Telegram 没有「好友申请」这一套，能不能找到你、能不能给你发消息，由你自己的隐私设置决定。本篇讲清四类联系方式各自的前提条件，以及群组和频道这两个容易混的东西怎么区分、怎么加。

## 一、四种找人方式

| 方式 | 怎么用 | 前提 |
| --- | --- | --- |
| 通讯录 | 允许应用读取通讯录后，已注册的联系人会出现在联系人列表 | 对方也在通讯录里，且没关掉这项匹配 |
| 手机号 | 在搜索框输入完整号码 | 对方允许「通过手机号找到我」，见 [隐藏手机号与隐私设置.md](隐藏手机号与隐私设置.md) |
| @用户名 | 搜索框输入 `@对方用户名` | 对方设了用户名，这是最通用的一种 |
| 二维码 | 打开对方的二维码扫一扫 | 谁都能生成自己的二维码 |

四种里**只有 @用户名 不依赖任何「谁可以找到我」设置**，所以想让人随时联系上你、又不给号码，就设一个用户名。反过来，不想被陌生人搜到，就去把手机号可见性和用户名一起收掉。

## 二、用自己的二维码让人扫

「设置」页里的二维码入口可以生成你的个人二维码，别人扫码后能直接打开和你的对话。二维码可以保存成图片发给别人，也可以线下面对面扫。

群组和频道同样各有二维码：在群 / 频道的资料页里能生成，扫完直接进入。这是线下场合最快的加群方式。

## 三、群组和频道的区别

| | 群组 | 频道 |
| --- | --- | --- |
| 谁能发言 | 成员都能发言，管理员可限制权限 | 只有管理员能发，订阅者只能看 |
| 用途 | 多人讨论、多人协作 | 单向广播，如公告、资讯、更新推送 |
| 规模上限 | 超级群组最多 20 万名成员 | 订阅人数没有上限 |
| 能不能评论 | 直接在里面发言 | 可以关联一个讨论群，评论落到那个群里 |

一句话选法：**要大家一起说话就用群组，只有你发给大家看就用频道。** 频道要开评论，管理员需要另建一个群并把它设为讨论群。

## 四、进群 / 进频道的四种入口

1. **公开的 @用户名**：在搜索框输入 `@名字`，搜到的结果里直接点加入。
2. **邀请链接**：形如 `t.me/名字` 或 `t.me/+一串字符` 的链接，点开后有「加入」按钮。带 `+` 的那种是私密链接，没链接的人搜不到。
3. **被人拉进来**：朋友或管理员直接把你加进去。若你把「谁能把我加进群」设成了「我的联系人」，就只有联系人能拉你。
4. **从别人转发的消息进去**：转发出来的公开群消息，点一下就能跳到那个群 / 频道。

加入公开群和频道后，往群里发的内容能被其他成员看到 —— 进之前先看清楚是什么群。

## 五、搜索里能搜到什么

搜索框不只是搜聊天记录：

- 输入关键词：会分栏显示联系人与聊天、以及消息内容；
- 输入 `@` 开头：优先匹配用户名；
- 直接输频道 / 群的名字关键词：公开的群和频道会出现在结果里，可直接加入；私密的搜不到。

找不到某个公开频道时，先确认名字拼写，再考虑它是不是已经改了用户名 —— 用户名是可变的，链接也可能失效。

## 六、进群之后先看三样

1. **置顶消息**：规则、公告、资源入口通常都钉在这里。
2. **群简介**：说明这个群干什么、有没有分群或讨论群。
3. **能不能直接发言**：部分群开了慢速模式或要求管理员审核，发言会被限制或等待通过，这不是你的账号有问题。

## 七、想退出、想屏蔽

- **退出群组**：进群资料页选退出。群内会留下一条你已退出的系统提示，介意的话退群前不用打招呼。
- **取消订阅频道**：在频道资料页取消订阅，不会给管理员发通知。
- **不想再收到某个群的消息**：可以只静音不退出，消息仍留在列表里但不再提示。
- **被陌生人反复拉群**：去「隐私与安全 → 群组与频道」把「谁能把我加进群」改成联系人即可，设置细节见 [隐藏手机号与隐私设置.md](隐藏手机号与隐私设置.md)。
