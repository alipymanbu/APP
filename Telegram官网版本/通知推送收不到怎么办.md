# Telegram 通知推送收不到怎么办

> 消息能收到、手机却不响不提示：按应用内设置 → 系统权限 → 厂商省电三层依次排查，每层给判据。

聊天记录正常、就是手机不响 —— 这类问题绝大多数出在系统层：应用被省电策略限制在后台，推送通道断了。本篇按从内到外的顺序排查，做完一层再决定要不要往下走。

## 一、先分清是哪一种「收不到」

| 现象 | 大致原因 | 去哪一节 |
| --- | --- | --- |
| 解锁打开应用才看到新消息，通知栏什么都没有 | 通知被系统或应用设置拦了 | 第二、三、四节 |
| 打开应用后消息还要转半天才出现 | 后台连接被限制 | 第三、四节 |
| 只有某个人 / 某个群不提示 | 那个会话被静音了 | 第二节 |
| 连聊天记录里也没有这条消息 | 不是通知问题，先查网络和对方是否发出 | 见 [消息发送与文件传输怎么用.md](消息发送与文件传输怎么用.md) |

## 二、第一层：应用内的通知设置

进「设置 → 通知和声音」，逐项确认：

- **聊天通知**下的私聊、群组、频道三档开关都要打开；
- 同页的「例外」会列出被你静音过的会话。只有个别会话不响的，在这里解除（也可以在聊天列表长按那条会话选取消静音）；
- **保持在线服务（Keep-Alive Service）** 与 **后台连接（Background Connection）** 要打开。这两项是应用维持推送通道用的，关掉更省电，但通知会变慢甚至不来；
- **通话通知**和消息通知是两个独立开关，别只测消息。

## 三、第二层：系统权限与应用后台

1. 长按应用图标 → 应用信息 → 通知 → 确认「允许通知」开着；展开分渠道，消息、通话等渠道也别关。
2. 应用信息 → 移动数据 → 打开「允许后台数据使用」和「流量节省程序启用时也允许数据」。
3. 电池：把它的电池优化从「优化」改成「不限制 / 无限制」。
4. 系统「勿扰模式」「睡眠模式」开着时通知会被压掉，先确认没开。

## 四、第三层：厂商的省电与自启动

国产系统的这一层最容易漏，各家菜单名称不同，认「自启动」「后台运行」「省电策略」这几个关键词：

| 品牌 | 大致位置 |
| --- | --- |
| 小米 / 红米 | 安全中心 → 应用管理 → 权限 → 自启动；再把该应用的省电策略设为「无限制」 |
| 华为 / 荣耀 | 手机管家 → 应用启动管理 → 找到该应用 → 关闭「自动管理」，勾上允许自启动、关联启动、后台活动 |
| OPPO / 一加 / realme | 设置 → 电池 → 应用耗电管理 → 允许后台运行 |
| vivo / iQOO | 设置 → 电池 → 后台高耗电 → 允许 |
| 原生 Android / Pixel | 设置 → 应用 → 该应用 → 电池 → 无限制，并关掉自适应电池对它的限制 |

菜单名称会随系统版本变化，找不到就按「自启动」「后台」搜系统设置里的搜索框。

## 五、三层都查完还不响

1. 清一次应用缓存（路径见 [缓存占用和自动下载怎么设置.md](缓存占用和自动下载怎么设置.md)）——缓存损坏偶发影响通知；
2. 重启手机，让后台白名单重新生效；
3. 只有某一条会话不响，而其他会话正常，那就是那条会话被静音或单独设成了无通知，回到第二节处理。

## 六、怎么验证已经修好

把手机锁屏放在一边 3 到 5 分钟，让别人给你的私聊发一条消息：

- **锁屏上出现通知** → 已经修好；
- **只有解锁打开应用后才看到** → 后台限制还在生效，回到第三、四节。

## 七、电脑端不响是另一回事

电脑端、网页版的通知依赖客户端当时在运行：电脑端的通知由操作系统发出，网页版要浏览器标签页活着。电脑端不响先看系统通知权限和客户端是否被关闭，与手机上的排查是两条线。多端配合的用法见 [在电脑上和网页版同时用.md](在电脑上和网页版同时用.md)。
