# Telegram 缓存占用和自动下载怎么设置

> 手机空间被 Telegram 吃掉时先做什么：占用从哪来、三种清理的区别、自动下载怎么限、单个聊天的例外怎么设。

聊天记录存在账号的云端，手机上一开始几乎不占空间；真正把存储吃满的是自动缓存 —— 你点开过的图片、视频、语音、文件，都会在本机留一份。本篇给出怎么看、清、限的完整顺序。

## 一、先看占用是谁造成的

「设置 → 数据和存储 → 存储用量」，这里会按类型列出占用，并可以按聊天大小排序，找出最占地方的那几个会话。路径与分类名称随版本略有差异，认「存储用量 / Storage Usage」这一项即可。

## 二、三种「清理」不是一回事

| 操作 | 聊天记录 | 云端数据 | 效果 |
| --- | --- | --- | --- |
| 清除缓存 | 不删 | 不动 | 释放最彻底，下次打开相关内容会重新下载 |
| 清除某个聊天的缓存 | 不删 | 不动 | 只把最占地方的那几个聊天处理掉，最有效 |
| 删除聊天 / 删除消息 | **会删** | 按选择对你自己或双方删除 | 慎用，删了就要重新找对方要 |

**一句话记法：清缓存丢的是本机副本，删聊天丢的是记录本身。** 清缓存不会让你丢消息，也不会影响你在电脑端看到的内容。

## 三、从源头限住：自动下载开关

「数据和存储 → 自动下载」里，把网络类型和文件类型交叉着关：

| 网络 | 建议 |
| --- | --- |
| 移动数据 | 图片可留，视频、文件建议关 —— 这是最耗流量和空间的一项 |
| 无线网络 | 按需开，装机和换机时尤其容易一口气缓存大量媒体 |
| 漫游 | 全部关掉 |

每一项都可以单独开关，关掉之后文件仍会显示在聊天里，只是需要点一下才下载。

## 四、不想让图片自动进系统相册

同一页里的「保存到相册」开关控制缓存之外的另一份拷贝：开着的时候，打开过的图片会额外写进手机相册，等于同一张图占两次空间。相册里攒了大量 Telegram 图像又找不到来源的，多半就是这个开关。

## 五、给个别聊天开例外

默认全关太狠、又不想全局打开时，可以进某个聊天的资料页单独设置它的自动下载策略，比如只给家人、工作群开自动下载，其余保持手动。群和频道同样支持。

## 六、空间快满时的处理顺序

1. 进「存储用量」，按大小排序，找出前几个最占地方的聊天；
2. 清除这几个聊天的缓存 —— 多数情况下这一步就能腾出大部分空间；
3. 确认「自动下载」里移动数据下的视频和文件是关的，否则清完很快又满；
4. 检查「保存到相册」是不是开着，并顺手清一下手机相册里的 Telegram 图像；
5. 仍然不够，再清除全部缓存；这一步不丢记录，只是下次打开内容会重新下载。

## 七、清完之后的两点预期

- **换机或重装后会重新下载**：新设备登录时，记录会从云端回来，但媒体文件是按需下载的，看不到内容不代表丢了，点开就会重新拉取。
- **下载过的文件仍在原来的位置**：你把文件另存到手机存储里之后，它就不再属于应用缓存，清缓存不会动它；要腾空间得自己去文件管理器里删。
