# Allway 连不上耳机怎么排查

> 本篇按现象分类，讲手机蓝牙连不上耳机、蓝牙连上了但应用里搜不到设备、只有一只耳机有声音这三类问题各自怎么排。

连不上其实是两件不同的事：一个是**手机的蓝牙**没连上耳机，一个是**蓝牙已经连上了、但 Allway 应用里扫不到设备**。两者的原因和排查顺序完全不同，先分清属于哪一种，能省掉一大半无用操作。判定方法很简单：去手机系统的蓝牙设置里看设备列表，耳机显示「已连接」却仍被应用报「找不到设备」，就是第二类。

## 一、先分清两种「连不上」

| 现象 | 症结在哪 | 从哪一节开始看 |
| --- | --- | --- |
| 手机蓝牙列表里根本没有你的耳机 | 耳机没进可被发现状态，或有信号/电量问题 | 第二节 |
| 蓝牙列表里有、点连接没反应或反复断开 | 配对信息冲突、被别的设备占着 | 第二节、第四节 |
| 蓝牙显示已连接，Allway 里搜不到设备 | 应用侧权限或识别问题 | 第三节 |

## 二、手机蓝牙连耳机的排查顺序

按下面顺序做，每做完一步先试一次，别一次全做完：

1. **确认电量**。耳机没电或刚充满但没激活时不会进配对状态。把耳机放回充电仓充几分钟再试。
2. **确认耳机真的进了配对状态**。多数 Allway 设备是出仓即开机、首次使用自动进配对；从仓里取出后留意指示灯是否在闪。具体到你的型号，以随附说明书的描述为准。
3. **确认没被别的设备占着**。耳机开机后会优先回连上一次连过的设备（手机、平板、电脑都有可能）。把那个设备的蓝牙先关掉，或者在上面断开连接，再回到你的手机搜。
4. **在手机蓝牙设置里「忽略此设备」后重连**。之前的配对信息坏了，最省事的办法是先删掉再重新配一次：手机蓝牙列表 → 找到耳机 → 忽略/取消配对 → 耳机放回仓、关盖再开盖取出 → 重新扫描。
5. **关掉再打开手机蓝牙**，不行就重启一次手机。这一步解决的是系统蓝牙栈偶发的卡死，成本最低，放在前面做不亏。

做完这五步仍然连不上，再考虑是不是耳机本身的问题，见第六节。

## 三、蓝牙已连上、应用里却搜不到设备

这类问题几乎都出在权限和后台，不在耳机上：

| 检查项 | 具体怎么看 |
| --- | --- |
| 蓝牙权限 | 「设置 → 应用 → Allway → 权限」里，确认「附近的设备」（Android 12+）或「定位」（旧版系统）是允许状态 |
| 系统蓝牙是否真的在连 | 打开手机蓝牙设置确认耳机那一行是「已连接」，不是「已配对」 |
| 后台是否被清掉 | 从多任务里划掉过应用，再打开时它需要重新扫描；熄屏久了系统回收后台也会导致列表空白 |
| 是否装了两个 Allway | 同名不同包名的应用不会互相看见对方的设备，确认你打开的是包名 `com.fenda.headset` 那一个 |
| 设备是否真的属于这个应用 | Allway 只能管 Allway 品牌的设备，别的品牌耳机连上了蓝牙也不会出现在设备列表里 |

如果上面的项目都对，把应用的后台限制放开：在电池设置里允许 Allway 后台运行，再把应用从多任务列表里彻底清掉重开一次，让它重新扫一遍。

## 四、只有一只耳机有声音

先做两件不花钱的事：

1. **两只耳机一起放回充电仓、关盖，再同时取出**。左右耳之间的配对是在出仓瞬间完成的，只取出一只时容易变成单耳工作。
2. **确认两只是不是同一对**。同一型号的两副耳机混着用，左耳和右耳来自不同的一对，也可能出现只有一只出声的情况。

都试过还是单耳，按上面第二节第 4 步在手机里忽略设备后重新配对一次。仍然不行，去 [固件升级怎么操作.md](固件升级怎么操作.md) 看看有没有可升的固件版本——左右耳固件版本不一致时，官方有时会通过升级来修复这类同步问题。

## 五、换新手机之后连不上

换机后连不上的，多数只是配对待重新做一遍，按第二节重来即可。两点补充：

- 旧手机上留着的配对记录会让耳机优先回连旧机。旧机还在手边的话，先在旧机上「忽略此设备」。
- 新手机如果系统版本较老，蓝牙相关权限的申请方式不同，按 [下载与安装教程.md](下载与安装教程.md) 第四节把权限过一遍。

## 六、什么时候该怀疑是硬件

出现下面任一种，就别再在手机上折腾了：

- 耳机完全不亮灯、放回仓里也不充电；
- 两只耳机分别单独配对，其中一只在任何设备上都连不上；
- 充电仓给耳机充不进电，或指示灯表现和说明书里写的对不上。

这类情况属于硬件问题，走官方售后渠道处理。品牌官网是 [allwaylife.com](https://allwaylife.com/)，包装或说明书上通常也印有售后联系方式；购买渠道的客服同样可以受理。
